## 명제와 연산자
**명제**는 참이나 거짓 중 하나로 정해지는 문장이다. "2는 짝수다"는 참인 명제, "3은 짝수다"는 거짓인 명제다. "x는 짝수다"처럼 x에 따라 달라지는 문장은 아직 명제가 아니다(3편에서 다룰 술어). 명제 p, q를 연산자로 묶어 더 큰 명제를 만든다.

| 기호 | 이름 | 읽는 법 | 파이썬 |
|---|---|---|---|
| `¬p` | 부정 | p가 아니다 | `not p` |
| `p ∧ q` | 논리곱 | p 그리고 q | `p and q` |
| `p ∨ q` | 논리합 | p 또는 q | `p or q` |
| `p → q` | 함의 | p이면 q | `(not p) or q` |
| `p ⇔ q` | 동치 | p와 q가 같은 값 | `p == q` |

`∨`는 둘 다 참인 경우도 참이다. 정확히 하나만 참일 때 참인 것은 **배타적 논리합**(XOR)이라 하고 `p != q`로 쓸 수 있다.

## 진리표
모든 진리값 조합에 대한 결과를 적은 표가 **진리표**다. 변수가 n개면 행이 2ⁿ개다. 코드로 만들어 보자.
```python
from itertools import product

def implies(p, q):
    return (not p) or q

TF = lambda v: "T" if v else "F"
print("p q  ¬p  p∧q  p∨q  p→q  p⇔q")
for p, q in product([True, False], repeat=2):
    cols = [not p, p and q, p or q, implies(p, q), p == q]
    print(TF(p), TF(q), "  ".join(f"{TF(v):>3}" for v in cols))
```
```text
p q  ¬p  p∧q  p∨q  p→q  p⇔q
T T   F    T    T    T    T
T F   F    F    T    F    F
F T   T    F    T    T    F
F F   T    F    F    T    T
```

가장 헷갈리는 것은 함의 `p → q`다. 거짓은 "p가 참인데 q가 거짓"인 한 줄뿐이다. "비가 오면 우산을 쓴다"는 약속은 비가 오는데 우산을 안 썼을 때만 깨지고, 비가 안 온 날에는 무엇을 하든 약속을 어긴 것이 아니다.

## 논리적 동치와 드모르간 법칙
두 식이 모든 진리값 조합에서 같은 값을 내면 **논리적으로 동치**라 하고 `≡`로 쓴다. 변수가 적으면 2ⁿ가지를 전부 대입해 보는 것이 곧 증명이다.
```python
# 앞 코드의 product, implies에 이어서
def equivalent(f, g, n=2):
    """변수 n개의 모든 진리값 조합(2ⁿ가지)에서 f와 g가 같은지 확인한다."""
    return all(f(*v) == g(*v) for v in product([True, False], repeat=n))

# 드모르간 법칙
print(equivalent(lambda p, q: not (p and q), lambda p, q: (not p) or (not q)))  # True
print(equivalent(lambda p, q: not (p or q), lambda p, q: (not p) and (not q)))  # True
# p→q 와 대우 ¬q→¬p, 그리고 역 q→p
print(equivalent(lambda p, q: implies(p, q), lambda p, q: implies(not q, not p)))  # True
print(equivalent(lambda p, q: implies(p, q), lambda p, q: implies(q, p)))          # False
```

**드모르간 법칙**은 "괄호 밖의 부정을 안으로 넣으면 ∧와 ∨가 서로 바뀐다"는 규칙이다.
```text
¬(p ∧ q) ≡ ¬p ∨ ¬q
¬(p ∨ q) ≡ ¬p ∧ ¬q
```
앞 코드의 마지막 두 줄도 중요하다. `p → q`는 **대우** `¬q → ¬p`와 동치지만 **역** `q → p`와는 동치가 아니다. 3편의 대우 증명이 이 사실에 기댄다.

## 불 대수의 법칙
참·거짓을 1·0으로, ∧·∨·¬를 연산으로 보는 대수 체계를 **불 대수**라고 한다. 조지 불이 1854년 저서 「The Laws of Thought」에서 논리를 대수처럼 다룬 데서 이름이 왔다. 교환·결합 법칙 외에 자주 쓰는 법칙은 다음과 같다.

| 법칙 | ∧ 형태 | ∨ 형태 |
|---|---|---|
| 항등 | `p ∧ T ≡ p` | `p ∨ F ≡ p` |
| 지배 | `p ∧ F ≡ F` | `p ∨ T ≡ T` |
| 멱등 | `p ∧ p ≡ p` | `p ∨ p ≡ p` |
| 보수 | `p ∧ ¬p ≡ F` | `p ∨ ¬p ≡ T` |
| 흡수 | `p ∧ (p ∨ q) ≡ p` | `p ∨ (p ∧ q) ≡ p` |
| 분배 | `p ∧ (q ∨ r)` ≡ `(p ∧ q) ∨ (p ∧ r)` | `p ∨ (q ∧ r)` ≡ `(p ∨ q) ∧ (p ∨ r)` |

표의 두 열은 ∧와 ∨, T와 F를 맞바꾸면 서로 바뀐다(**쌍대성**). 이 법칙으로 조건문을 단순하게 만들 수 있다. `if not (x < 0 or x > 100)`은 드모르간 법칙으로 `if x >= 0 and x <= 100`, 즉 `if 0 <= x <= 100`이 된다. `if is_admin or (is_admin and is_owner)`는 흡수 법칙으로 `if is_admin`이다.

## 논리 게이트: 법칙이 회로가 될 때
AND, OR, NOT을 전기 회로로 만든 것이 **논리 게이트**다. 클로드 섀넌은 1937년 석사 논문에서 스위치 회로를 불 대수로 분석할 수 있음을 보였다. 게이트를 조합하면 계산을 할 수 있다. 한 자리 2진수 두 개를 더하는 **반가산기**는 XOR 하나와 AND 하나면 된다.
```python
from itertools import product

for a, b in product([0, 1], repeat=2):
    print(f"{a} + {b} → 합 {a ^ b}, 올림 {a & b}")
```
```text
0 + 0 → 합 0, 올림 0
0 + 1 → 합 1, 올림 0
1 + 0 → 합 1, 올림 0
1 + 1 → 합 0, 올림 1
```
`1 + 1`의 결과 "올림 1, 합 0"은 2진수 `10`, 즉 2다. 반가산기 두 개로 아랫자리의 올림까지 받는 전가산기를 만들고, 전가산기를 32개 이어 붙이면 32비트 덧셈기가 된다. NAND(`¬(p ∧ q)`) 하나만으로도 NOT, AND, OR을 모두 만들 수 있다.

## 단락 평가
프로그래밍 언어의 `and`/`or`(자바스크립트의 `&&`/`||`)는 결과가 이미 정해지면 오른쪽을 계산하지 않는다. 지배 법칙 `F ∧ q ≡ F`, `T ∨ q ≡ T` 덕분에 q를 볼 필요가 없기 때문이다. 이를 **단락 평가**라고 한다.
```python
def check(name, value):
    print("평가:", name)
    return value

check("A", False) and check("B", True)   # A가 거짓이면 B는 볼 필요가 없다
check("C", True) or check("D", True)     # C가 참이면 D는 볼 필요가 없다

user = None
print(user is not None and user.name)    # 오류 없이 False
```
```text
평가: A
평가: C
False
```
`user is not None and user.name`은 앞의 검사가 거짓이면 뒤를 실행하지 않으므로 None에서 속성을 읽는 오류가 나지 않는다. 그래서 단락 평가가 있는 언어에서는 `p and q`와 `q and p`가 논리적으로 동치여도 실행 결과는 다를 수 있다.

## 정리
- 명제는 참·거짓이 정해진 문장이고, ¬ ∧ ∨ → ⇔로 묶어 새 명제를 만든다. `p → q`는 p가 참이고 q가 거짓일 때만 거짓이다.
- 두 식이 모든 진리값 조합에서 같으면 동치이며, 변수가 적으면 진리표 전체를 확인하는 것이 곧 증명이다.
- 드모르간·흡수·분배 같은 불 대수 법칙으로 조건문을 단순하게 바꿀 수 있고, 같은 법칙이 논리 회로 설계에 쓰인다.
- 단락 평가는 지배 법칙을 이용해 불필요한 계산을 건너뛰며, 안전한 None 검사에 쓰인다.
