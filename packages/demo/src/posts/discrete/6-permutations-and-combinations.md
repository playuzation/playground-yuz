## 합의 법칙과 곱의 법칙
모든 세기의 바탕은 두 법칙이다.
- **합의 법칙**: 겹치지 않는 두 경우 중 하나를 고르는 방법은 `m + n`가지다. 점심으로 한식 4종 중 하나 또는 양식 3종 중 하나를 고르면 7가지다.
- **곱의 법칙**: 단계를 차례로 거치며 고르는 방법은 `m × n`가지다. 셔츠 4벌과 바지 3벌을 하나씩 고르면 12가지다. 1편의 `∣A × B∣ = ∣A∣ × ∣B∣`와 같은 말이다.

곱의 법칙은 단계가 많아지면 거듭제곱이 된다. 숫자 4자리 비밀번호는 `10⁴ = 10,000`가지, 영어 소문자 8자리는 `26⁸ = 208,827,064,576`가지다. 자리마다 같은 후보에서 독립적으로 고르는 이런 경우를 **중복 순열**이라고 하고 `nʳ`로 센다.

## 순열: 순서가 중요할 때
서로 다른 n개에서 r개를 골라 **순서대로** 늘어놓는 것을 **순열**이라 한다. 첫 자리는 n가지, 둘째 자리는 남은 n − 1가지, …로 곱의 법칙을 쓰면 된다.
```text
P(n, r) = n × (n − 1) × … × (n − r + 1) = n! / (n − r)!
```
n!(n 팩토리얼)은 1부터 n까지의 곱이고 `0! = 1`로 정한다. 5명 중 회장과 부회장을 뽑는 방법은 `P(5, 2) = 5 × 4 = 20`가지다. (A 회장, B 부회장)과 (B 회장, A 부회장)은 다른 경우다. n개 전부를 늘어놓는 방법은 `n!`가지다.

## 조합: 순서가 상관없을 때
순서 없이 r개를 **고르기만** 하는 것은 **조합**이다. 순열로 세면 같은 r개 묶음이 순서만 바꿔 r!번씩 중복으로 세어지므로 r!로 나눈다.
```text
C(n, r) = P(n, r) / r! = n! / (r! (n − r)!)
```
5명 중 대표 2명을 뽑는 방법은 `C(5, 2) = 20 / 2 = 10`가지다. 이번에는 {A, B}와 {B, A}가 같다. 로또 6/45의 경우의 수 `C(45, 6) = 8,145,060`도 이렇게 나온다. 교과서에서는 각각 ₙPᵣ, ₙCᵣ로도 쓴다.

## 중복 조합: 같은 것을 여러 번 골라도 될 때
사과·배·귤 세 종류에서 과일 5개를 고르는데 같은 종류를 여러 개 골라도 된다면? 과일 5개를 별로, 종류의 경계를 막대 2개로 나타내면 모든 선택이 별 5개와 막대 2개의 나열 하나에 대응한다.
```text
★★|★|★★    사과 2, 배 1, 귤 2
★★★★★||    사과 5
|★★|★★★    배 2, 귤 3
```
결국 7자리 중 별이 들어갈 5자리를 고르는 문제이므로 `C(3 + 5 − 1, 5) = C(7, 5) = 21`가지다. 일반적으로 n종류에서 중복을 허용해 r개를 고르는 방법은 `C(n + r − 1, r)`가지다. 네 경우를 표로 정리하면 다음과 같다.

| 구분 | 중복 없음 | 중복 허용 |
|---|---|---|
| 순서 있음 | 순열 `P(n, r)` | 중복 순열 `nʳ` |
| 순서 없음 | 조합 `C(n, r)` | 중복 조합 `C(n + r − 1, r)` |

## 코드로 확인하기
파이썬 `math`에는 공식이, `itertools`에는 실제로 나열해 주는 함수가 있다. 둘의 개수가 같은지 보면 공식을 검산할 수 있다.
```python
import math
from itertools import permutations, combinations, combinations_with_replacement

people = ["A", "B", "C", "D", "E"]
print(math.perm(5, 2), len(list(permutations(people, 2))))     # 20 20
print(math.comb(5, 2), len(list(combinations(people, 2))))     # 10 10
fruits = ["사과", "배", "귤"]
print(math.comb(3 + 5 - 1, 5), len(list(combinations_with_replacement(fruits, 5))))  # 21 21
print(math.comb(45, 6))                                        # 8145060
```
나열은 경우의 수만큼 시간이 들기 때문에 작은 문제의 검산에만 쓰고, 큰 수는 공식으로 계산한다.

## 이항 정리와 파스칼 삼각형
`(a + b)³ = (a + b)(a + b)(a + b)`를 전개하면 세 괄호에서 a나 b를 하나씩 골라 곱한 항들의 합이 된다. `a²b`는 세 괄호 중 b를 고를 괄호 1개를 정하는 방법만큼, 즉 `C(3, 1) = 3`번 나온다. 그래서 `(a + b)³ = a³ + 3a²b + 3ab² + b³`이고, 일반적으로 다음이 성립한다(**이항 정리**).
```text
(a + b)ⁿ = Σ C(n, k) · aⁿ⁻ᵏ · bᵏ    (k = 0, 1, …, n)
```
계수 `C(n, k)`를 줄마다 늘어놓은 것이 **파스칼 삼각형**이다. 각 수는 바로 윗줄의 이웃한 두 수의 합이다(`C(n, k) = C(n − 1, k − 1) + C(n − 1, k)`). n번째 원소를 넣을지 말지로 경우를 나누면 이 식이 나온다.
```python
import math

for n in range(7):
    row = [math.comb(n, k) for k in range(n + 1)]
    print(f"n={n}: {row}  합 {sum(row)}")
```
```text
n=0: [1]  합 1
n=1: [1, 1]  합 2
n=2: [1, 2, 1]  합 4
n=3: [1, 3, 3, 1]  합 8
n=4: [1, 4, 6, 4, 1]  합 16
n=5: [1, 5, 10, 10, 5, 1]  합 32
n=6: [1, 6, 15, 20, 15, 6, 1]  합 64
```
각 줄의 합이 `2ⁿ`인 것은 이항 정리에 `a = b = 1`을 넣은 결과이고, 원소 n개짜리 집합의 부분집합 개수(원소마다 넣거나 빼거나 2가지)와 같다.

## 어디에 쓰이나
- 이 플랫폼의 로그인 토큰: 토큰은 32바이트이고 바이트 하나가 256가지이므로 곱의 법칙으로 `256³² = 2²⁵⁶ ≈ 1.16 × 10⁷⁷`가지이며, 이 수가 너무 커서 토큰을 짐작으로 맞히는 것이 사실상 불가능하다.
- 확률과 분포 6편 「이산 분포: 베르누이, 이항, 기하, 포아송」: n번 시도에서 성공이 k번 나올 확률 `C(n, k) · pᵏ · (1 − p)ⁿ⁻ᵏ`의 `C(n, k)`가 "성공할 k번을 고르는 조합"이다.
- AI 기초 4편 「컴퓨터 사이언스로 보는 AI 모델: 텐서, 연산, 메모리」: INT4 숫자 하나가 표현할 수 있는 값이 `2⁴ = 16`가지뿐이라는 것도 곱의 법칙(비트마다 2가지)이며, 양자화가 정밀도를 잃는 이유다.

## 정리
- 겹치지 않는 선택지는 더하고(합의 법칙), 단계적인 선택은 곱한다(곱의 법칙).
- 순서가 중요하면 순열 `P(n, r) = n!/(n − r)!`, 순서가 상관없으면 조합 `C(n, r) = n!/(r!(n − r)!)`이다.
- 중복을 허용하면 각각 `nʳ`과 `C(n + r − 1, r)`이 된다.
- 이항 정리의 계수는 조합이고, 파스칼 삼각형의 n번째 줄 합은 `2ⁿ`이다.
