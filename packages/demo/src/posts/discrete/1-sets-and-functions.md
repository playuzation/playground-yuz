## 집합: 들어 있는가, 아닌가
**집합**(set)은 서로 구별되는 대상의 모음이다. 집합에서 중요한 것은 오직 "어떤 것이 들어 있는가"뿐이다. 순서도 없고 중복도 없다. `{1, 2, 3}`과 `{3, 1, 2, 1}`은 같은 집합이다.
- `x ∈ A`: x는 A의 **원소**다. 아니면 `x ∉ A`.
- `A ⊂ B`: A의 모든 원소가 B에도 들어 있으면 A는 B의 **부분집합**이다. 이 시리즈에서는 A = B인 경우도 포함한다.
- `∅`: 원소가 하나도 없는 **공집합**. 모든 집합의 부분집합이다.
- `∣A∣`: 원소의 개수(크기). `∣{a, b, c}∣ = 3`.

원소를 나열하기 어려우면 조건으로 쓴다. `{x ∈ ℤ ∣ 0 < x ≤ 5}`는 `{1, 2, 3, 4, 5}`다.

## 집합 연산
| 연산 | 기호 | 뜻 |
|---|---|---|
| 합집합 | `A ∪ B` | A나 B 중 하나에라도 있는 원소 |
| 교집합 | `A ∩ B` | A와 B 둘 다에 있는 원소 |
| 차집합 | `A − B` | A에는 있고 B에는 없는 원소 |
| 여집합 | `Aᶜ` | 전체집합 U에서 A를 뺀 것 `U − A` |

여집합은 "전체"가 무엇인지 정해야 의미가 있다. 정수 전체에서 짝수의 여집합은 홀수지만, `{1, …, 10}`이 전체라면 `{1, 3, 5, 7, 9}`다. 파이썬의 `set`은 이 연산을 그대로 제공한다.
```python
A = {1, 2, 3, 4}
B = {3, 4, 5}

print(A | B)          # 합집합
print(A & B)          # 교집합
print(A - B)          # 차집합
print(3 in A, 7 in A) # 원소인가?
print({1, 2} <= A)    # 부분집합인가?

likes = set()
for user in ["alice", "bob", "alice"]:  # alice가 두 번 눌러도
    likes.add(user)
print(len(likes))     # 좋아요 수는 2
```
```text
{1, 2, 3, 4, 5}
{3, 4}
{1, 2}
True False
True
2
```

## 곱집합: 순서쌍 모으기
두 집합에서 하나씩 골라 만든 **순서쌍**(a, b) 전체의 집합을 **곱집합**(데카르트 곱)이라 하고 `A × B`로 쓴다. 집합과 달리 순서쌍은 순서가 중요해서 (1, 2)와 (2, 1)은 다르다. 크기는 `∣A × B∣ = ∣A∣ × ∣B∣`다. 티셔츠 사이즈 2가지와 색 3가지를 조합하면 6가지다.
```python
from itertools import product

sizes, colors = ["S", "M"], ["red", "blue", "green"]
pairs = list(product(sizes, colors))
print(len(pairs), pairs[:2])  # 6 [('S', 'red'), ('S', 'blue')]
```

## 함수: 정확히 하나씩 짝짓기
**함수** `f: A → B`는 A의 모든 원소 x에 B의 원소 `f(x)`를 **정확히 하나** 대응시키는 규칙이다.
- **정의역**(domain) A: 넣을 수 있는 값의 집합
- **공역**(codomain) B: 나올 수 있다고 선언한 값의 집합
- **치역**(range): 실제로 나오는 값 `{f(x) ∣ x ∈ A}`. 공역의 부분집합이다.

"정확히 하나"가 핵심이다. 같은 입력에 때에 따라 다른 값을 내놓으면 수학의 함수가 아니다. 프로그래밍에서 입력만으로 출력이 정해지는 함수를 따로 **순수 함수**라고 부르는 이유다.

## 단사, 전사, 전단사
| 성질 | 조건 | 직관 |
|---|---|---|
| 단사 | `x ≠ y`이면 `f(x) ≠ f(y)` | 겹쳐서 도착하는 값이 없다 |
| 전사 | 치역 = 공역 | 공역에 빈자리가 없다 |
| 전단사 | 단사이면서 전사 | 완벽한 1:1 짝짓기, 역함수가 있다 |

정의역이 유한하면 코드로 직접 확인할 수 있다.
```python
def is_injective(f, domain):
    images = [f(x) for x in domain]
    return len(set(images)) == len(images)

def is_surjective(f, domain, codomain):
    return {f(x) for x in domain} == set(codomain)

X = range(6)                    # 정의역 {0, 1, 2, 3, 4, 5}
f = lambda x: x % 3             # 공역 {0, 1, 2}
g = lambda x: 2 * x             # 공역 {0, 1, …, 10}
print(is_injective(f, X), is_surjective(f, X, range(3)))   # False True
print(is_injective(g, X), is_surjective(g, X, range(11)))  # True False
```
`f`는 0과 3을 같은 값 0으로 보내니 단사가 아니지만 0, 1, 2를 모두 채우니 전사다. `g`는 서로 다른 입력을 서로 다른 짝수로 보내니 단사지만 홀수에는 아무것도 도착하지 않는다. 유한집합 사이에 전단사가 있으면 두 집합의 크기가 같다. "센다"는 것은 사실 `{1, 2, …, n}`과의 전단사를 찾는 일이다.

## 함수의 합성
`f: A → B`, `g: B → C`가 있으면 둘을 이어 붙인 **합성 함수** `g ∘ f: A → C`를 만들 수 있다. `(g ∘ f)(x) = g(f(x))`로, 오른쪽의 f가 먼저 적용된다. `f(x) = x + 1`, `g(x) = x²`이면 `(g ∘ f)(2) = g(3) = 9`이지만 `(f ∘ g)(2) = f(4) = 5`다. 합성은 순서를 바꾸면 결과가 달라진다. 프로그램에서 함수 호출을 겹쳐 쓰는 `sorted(set(words))`도 set을 먼저, sorted를 나중에 적용하는 합성이다.

## 어디에 쓰이나
- 언어 기초 5편 「컴파일 언어: 실행 전에 번역하기」: 타입은 값의 집합이고 `square(n int) int`는 정수 집합에서 정수 집합으로 가는 함수 선언이므로, 정적 타입 검사는 "넘긴 값 `"5"`가 정의역에 속하는가"를 실행 전에 따지는 일이다.
- 이 플랫폼의 좋아요: 좋아요는 포스트마다 "누른 사용자의 집합"이라 같은 사람이 여러 번 눌러도 원소가 늘지 않고, 좋아요 수는 그 집합의 크기 `∣likes∣`다.
- 7편 「비둘기집 원리와 포함·배제의 원리」: 해시 함수는 같은 입력에 항상 같은 값을 내는 함수이지만 정의역(모든 문자열)이 공역보다 훨씬 커서 단사일 수 없고, 이것이 해시 충돌의 근거다.

## 정리
- 집합은 순서와 중복 없이 "들어 있는가"만 따지며, 합·교·차·여집합과 곱집합으로 새 집합을 만든다.
- 함수 `f: A → B`는 정의역의 모든 원소에 공역의 원소를 정확히 하나 대응시키고, 실제로 나오는 값의 집합이 치역이다.
- 단사는 겹침 없음, 전사는 빈자리 없음, 전단사는 완벽한 1:1이며 크기를 세는 기준이 된다.
- 합성 `g ∘ f`는 f를 먼저 적용하고, 순서를 바꾸면 결과가 달라질 수 있다.
