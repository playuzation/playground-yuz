# [이산수학 3/12] 술어 논리와 증명: '모든'과 '어떤'을 다루기

> **한 줄 요약** — 술어 논리는 "모든 x에 대해"(∀)와 "어떤 x가 있다"(∃)를 다루는 논리이며, 반례 하나는 ∀를 무너뜨리지만 ∀를 세우려면 경우를 하나하나 확인하는 대신 증명이 필요하다.

## 이 글에서 다루는 것
- 술어와 한정자 ∀, ∃
- 한정자의 부정: `¬∀ ≡ ∃¬`
- 직접 증명, 대우 증명, 귀류법
- 반례: ∀ 명제를 무너뜨리는 한 개의 예
- 테스트와 증명·타입 검사의 차이

## 술어와 한정자
"x는 짝수다"는 x가 정해지기 전에는 참도 거짓도 아니다. 이렇게 변수에 따라 참·거짓이 정해지는 문장을 **술어**라고 하고 `P(x)`로 쓴다. 술어를 명제로 만드는 방법은 두 가지다. x에 값을 넣거나(`P(4)`는 참), **한정자**로 묶는다.
- **전칭 한정자** `∀x P(x)`: 모든 x에 대해 P(x)가 참이다.
- **존재 한정자** `∃x P(x)`: P(x)가 참인 x가 적어도 하나 있다.

x가 어떤 범위에서 움직이는지(**논의 영역**)를 정해야 참·거짓이 정해진다. `∃x (x² = 2)`는 실수에서는 참이지만 정수에서는 거짓이다. 논의 영역이 유한하면 ∀는 거대한 ∧, ∃는 거대한 ∨이고, 파이썬의 `all`과 `any`가 정확히 그 역할을 한다.
```python
xs = range(1, 11)
print(all(x > 0 for x in xs))         # ∀x (x > 0) → True
print(any(x % 7 == 0 for x in xs))    # ∃x (x가 7의 배수) → True
# ¬∀x 짝수(x)  ≡  ∃x ¬짝수(x)
print((not all(x % 2 == 0 for x in xs)) == any(x % 2 != 0 for x in xs))  # True
```

한정자는 순서가 중요하다. 정수에서 `∀x ∃y (y > x)`는 "어떤 수를 골라도 그보다 큰 수가 있다"로 참이지만, `∃y ∀x (y > x)`는 "모든 수보다 큰 수 하나가 있다"로 거짓이다.

## 한정자의 부정
∀와 ∃를 부정하는 규칙은 2편 드모르간 법칙의 확장이다.
```text
¬∀x P(x) ≡ ∃x ¬P(x)
¬∃x P(x) ≡ ∀x ¬P(x)
```
"모든 테스트가 통과했다"의 부정은 "모든 테스트가 실패했다"가 아니라 "통과하지 못한 테스트가 하나 이상 있다"다. "버그가 있는 함수가 존재한다"의 부정은 "모든 함수에 버그가 없다"다. 부정을 안으로 넣을 때마다 ∀와 ∃가 맞바뀐다고 기억하면 된다.

## 증명의 세 가지 기본기
**증명**은 이미 참으로 받아들인 사실에서 출발해 논리 규칙만으로 결론에 도달하는 논증이다.

| 방법 | 보이는 방식 | 잘 맞는 경우 |
|---|---|---|
| 직접 증명 | p를 가정하고 q를 끌어낸다 | 정의를 풀어 쓰면 바로 이어질 때 |
| 대우 증명 | ¬q를 가정하고 ¬p를 끌어낸다 | 결론의 부정이 다루기 쉬울 때 |
| 귀류법 | 결론의 부정에서 모순을 끌어낸다 | "~가 아니다", "무한하다"류 |

**직접 증명** — "짝수 더하기 짝수는 짝수다." 짝수 a, b는 정수 m, n에 대해 `a = 2m`, `b = 2n`으로 쓸 수 있다. 그러면 `a + b = 2(m + n)`이고 m + n은 정수이므로 a + b는 짝수다. 특정한 숫자가 아니라 임의의 m, n으로 보였으므로 모든 짝수 쌍에 대해 성립한다.

**대우 증명** — "n²이 짝수면 n은 짝수다." 2편에서 확인했듯 `p → q`는 대우 `¬q → ¬p`와 동치이므로 "n이 홀수면 n²도 홀수다"를 보이면 된다. `n = 2k + 1`이면 `n² = 4k² + 4k + 1 = 2(2k² + 2k) + 1`로 홀수다.

**귀류법** — "√2는 무리수다." 결론을 부정해 √2가 유리수라고 가정하자. 그러면 더 이상 약분되지 않는 자연수 a, b로 `√2 = a/b`라고 쓸 수 있다.
```text
√2 = a/b  ⇒  a² = 2b²       → a²이 짝수 → (대우 증명의 결과) a도 짝수, a = 2c
          ⇒  4c² = 2b²       → b² = 2c² → b²이 짝수 → b도 짝수
          ⇒  a, b가 모두 2로 약분된다 → "더 이상 약분되지 않는다"와 모순
```
가정에서 모순이 나왔으므로 가정이 거짓이고, √2는 무리수다.

## 반례: ∀를 무너뜨리는 한 개의 예
`∀x P(x)`가 거짓임을 보이려면 부정 규칙에 따라 `∃x ¬P(x)`, 즉 P가 성립하지 않는 x 하나만 찾으면 된다. 이것이 **반례**다. "n² + n + 41은 항상 소수다"라는 주장은 n = 0부터 39까지 모두 맞아떨어져서 그럴듯해 보인다.
```python
from math import isqrt

def is_prime(n):
    return n >= 2 and all(n % d for d in range(2, isqrt(n) + 1))

P = lambda n: is_prime(n * n + n + 41)
print(all(P(n) for n in range(40)))              # True: n = 0~39는 전부 소수
print(next(n for n in range(1000) if not P(n)))  # 40: 첫 반례
print(40 * 40 + 40 + 41, 41 * 41)                # 1681 1681
```
40개의 맞는 예보다 반례 하나가 더 강하다. n = 40이면 값이 `41²`이라 소수가 아니다.

거꾸로, 예를 아무리 많이 확인해도 ∀가 증명되지는 않는다. 위의 귀류법이 보인 "a² = 2b²인 자연수는 없다"를 b ≤ 10,000에서 찾아보면 아무것도 나오지 않는다. 하지만 이 결과만으로는 b = 10,001에 대해 아무것도 말할 수 없다. 모든 b를 한 번에 다루는 것은 증명뿐이다.
```python
from math import isqrt

found = [(a, b) for b in range(1, 10_001) if (a := isqrt(2 * b * b)) ** 2 == 2 * b * b]
print(found)  # []
```

## 테스트는 ∃, 증명은 ∀
"이 함수는 모든 입력에서 올바르다"는 ∀ 명제다. **테스트**는 입력 몇 개를 넣어 보는 일이므로 실패하는 입력, 즉 반례(∃)를 찾으면 버그를 확정할 수 있지만, 통과했다고 해서 ∀가 보장되지는 않는다. 데이크스트라의 유명한 말처럼 테스트는 버그가 있음을 보일 수는 있어도 없음을 보일 수는 없다. 반면 증명과 **정적 타입 검사**는 프로그램을 실행하지 않고 "모든 실행에서 이런 종류의 오류는 없다"는 ∀를 보장한다. 대신 타입 검사가 보장하는 성질은 "타입이 맞는다"처럼 범위가 정해져 있어서, 둘은 서로를 대신하지 않고 보완한다.

## 어디에 쓰이나
- 언어 기초 4편 「러스트: 가비지 컬렉터 없이 메모리 안전하게」: 빌림 규칙 "어느 시점이든 불변 참조 여러 개 또는 가변 참조 하나"는 "∀ 시점에 대해 (가변 참조가 없다) ∨ (가변 참조 하나뿐이고 불변 참조가 없다)"라는 ∀ 명제이고, 빌림 검사기는 이를 실행 없이 증명한다.
- 언어 기초 5편 「컴파일 언어: 실행 전에 번역하기」: "테스트로 모든 경로를 실행해 보지 않아도 이런 종류의 실수가 전부 걸러진다"는 문장은 정적 타입 검사가 ∃(반례 찾기)가 아니라 ∀(모든 경우의 보장)를 다룬다는 뜻이다.
- 4편 「수학적 귀납법과 재귀」: 자연수 전체에 대한 ∀ 명제를 무한히 확인하지 않고 증명하는 표준 도구가 수학적 귀납법이다.

## 정리
- 술어 `P(x)`는 한정자 ∀(모든)나 ∃(어떤)로 묶여야 명제가 되고, 논의 영역에 따라 참·거짓이 달라진다.
- 부정을 안으로 넣으면 ∀와 ∃가 맞바뀐다: `¬∀x P(x) ≡ ∃x ¬P(x)`.
- 직접 증명, 대우 증명, 귀류법이 기본 도구이며, ∀ 명제는 반례 하나로 무너진다.
- 테스트는 반례(∃)를 찾고, 증명과 타입 검사는 모든 경우(∀)를 보장한다.
