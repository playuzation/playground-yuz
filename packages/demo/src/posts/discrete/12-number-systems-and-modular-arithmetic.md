## 이 글에서 다루는 것

## 자리값과 진법
10진수 237은 `2 × 10² + 3 × 10¹ + 7 × 10⁰`이다. 자리마다 밑(10)의 거듭제곱을 곱하는 것이 **자리값** 표기다. 밑을 2로 바꾸면 2진수, 16으로 바꾸면 16진수다.
- 2진수 `110111₂` = 32 + 16 + 4 + 2 + 1 = 55
- 16진수 `0x37` = 3 × 16 + 7 = 55. 16진수는 10~15를 a~f로 쓴다.

16 = 2⁴이므로 16진수 한 자리는 정확히 2진수 네 자리(4비트)에 대응한다. `0x37`의 3은 `0011`, 7은 `0111`이라 이어 붙이면 `00110111`이다. 그래서 바이트(8비트) 하나를 16진수 두 자리로 쓰는 것이 관례가 되었다.

10진수를 다른 진법으로 바꿀 때는 밑으로 나눈 **나머지**를 반복해서 구한다. 첫 나머지가 가장 낮은 자리가 된다.
```python
def to_base(n, b):
    digits = "0123456789abcdef"
    s = ""
    while n > 0:
        s = digits[n % b] + s      # 나머지가 가장 낮은 자리가 된다
        n //= b
    return s or "0"

print(to_base(55, 2), bin(55), int("110111", 2))   # 110111 0b110111 55
print(to_base(55, 16), hex(55), int("37", 16))     # 37 0x37 55
```

## 2의 보수: 음수를 비트로 쓰기
8비트로는 2⁸ = 256가지 패턴만 만들 수 있다(6편의 곱의 법칙). 이 패턴을 0~255로 읽으면 **부호 없는 정수**, 절반을 음수에 배정하면 **부호 있는 정수**다. 거의 모든 CPU는 음수를 **2의 보수**로 표현한다. 8비트에서 −x는 `256 − x`의 비트 패턴으로 저장한다.

| 비트 패턴 | 부호 없음 | 2의 보수 |
|---|---|---|
| `00000000` | 0 | 0 |
| `01111111` | 127 | 127 |
| `10000000` | 128 | −128 |
| `11111011` | 251 | −5 |
| `11111111` | 255 | −1 |

맨 앞 비트가 1이면 음수이고, 범위는 −128~127이다. 손으로 구할 때는 "모든 비트를 뒤집고 1을 더한다". 5는 `00000101`, 뒤집으면 `11111010`, 1을 더하면 `11111011`로 −5가 된다. 2의 보수의 진짜 장점은 덧셈 회로를 따로 만들 필요가 없다는 것이다. `−5 + 7`을 비트 그대로 더하면 `251 + 7 = 258`이고, 8비트를 넘친 자리를 버리면 258 − 256 = 2로 정답이다. 2편의 가산기 하나로 양수와 음수를 모두 처리한다.

## 오버플로 = 나머지 연산
고정 폭 정수가 범위를 넘으면 넘친 자리가 버려진다. "넘친 자리를 버린다"는 것은 정확히 2ⁿ으로 나눈 나머지를 취하는 것이다. 파이썬의 정수는 크기 제한이 없으므로 직접 흉내 내 보자.
```python
def to_signed(x, bits):
    x %= 2 ** bits                         # 아래 bits비트만 남긴다 = mod 2^bits
    return x - 2 ** bits if x >= 2 ** (bits - 1) else x

print(format(-5 % 256, "08b"), -5 % 256)   # 11111011 251: 8비트에서 −5의 비트 패턴
print(to_signed(127 + 1, 8))               # -128: INT8 최댓값 + 1
print(to_signed(2**31 - 1 + 1, 32))        # -2147483648: INT32 최댓값 + 1
print(to_signed(100 + 200, 8))             # 44: 300 mod 256
```
32비트 정수의 최댓값 2,147,483,647에 1을 더하면 −2,147,483,648이 된다. 자바의 `int`는 이렇게 mod 2³²로 돌도록 정해져 있다. C에서는 부호 없는 정수가 mod 2ⁿ으로 돌고, 부호 있는 정수의 오버플로는 "정의되지 않은 동작"이라 더 위험하다. 자바스크립트에서도 `(2147483647 + 1) | 0`처럼 비트 연산을 거치면 32비트로 잘려 −2147483648이 된다.

## 모듈러 연산과 합동
`a mod n`은 a를 n으로 나눈 나머지(0 이상 n 미만)다. 시계가 대표적인 예다. 10시에서 5시간 뒤는 `15 mod 12 = 3`시다. 두 정수의 나머지가 같으면 **합동**이라 하고 `a ≡ b (mod n)`으로 쓴다. 이것은 5편에서 본 동치 관계이고, 정수 전체를 나머지 0, 1, …, n − 1의 n개 동치류로 나눈다.

모듈러 연산의 핵심 성질은 덧셈과 곱셈을 하는 도중에 언제든 나머지를 취해도 결과가 같다는 것이다.
```text
(a + b) mod n = ((a mod n) + (b mod n)) mod n
(a × b) mod n = ((a mod n) × (b mod n)) mod n
```
그래서 7¹⁰⁰처럼 거대한 수의 일의 자리도 쉽게 구한다. `7⁴ = 2401 ≡ 1 (mod 10)`이므로 `7¹⁰⁰ = (7⁴)²⁵ ≡ 1`이다. 고정 폭 정수의 오버플로가 덧셈·곱셈 결과를 망가뜨리지 않고 "mod 2³²로는 정확한" 이유도 이 성질이다.
```python
from zlib import crc32

print(15 % 12)                 # 3: 10시 + 5시간 = 3시
print(pow(7, 100, 10))         # 1: 7¹⁰⁰의 일의 자리
print(-7 % 3)                  # 2: 파이썬은 나누는 수의 부호를 따른다

h = crc32(b"alice")            # 키의 해시값
print(h, h % 8, h & 7)         # 663665735 7 7: 칸이 8개일 때의 인덱스
```
음수의 나머지는 언어마다 다르다. 파이썬의 `-7 % 3`은 2지만 자바스크립트와 C는 −1이다. 해시나 인덱스 계산에 음수가 섞일 수 있으면 확인이 필요하다.

## 해시 테이블 인덱스: h mod m
해시 테이블은 키의 해시값 h를 칸 수 m으로 나눈 나머지 `h mod m`을 칸 번호로 쓴다. 해시값이 아무리 커도 결과는 항상 0~m − 1 사이에 들어온다. m이 2의 거듭제곱이면 `h mod 2ᵏ`은 h의 아래 k비트와 같아서, 나눗셈 대신 빠른 비트 연산 `h & (m − 1)`로 계산할 수 있다. 위 코드에서 `h % 8`과 `h & 7`이 같은 이유다. 서로 다른 키가 같은 나머지를 가지면 충돌이고, 7편의 비둘기집 원리 때문에 충돌은 피할 수 없다.

## 어디에 쓰이나
- 언어 기초 6편 「어셈블리와 컴파일·링크: 소스 코드가 실행 파일이 되기까지」: `mov eax, 55`의 기계어 `b8 37 00 00 00`에서 `b8`은 "eax에 뒤따르는 4바이트 값을 넣는다"는 명령 코드, 뒤의 네 바이트는 `0x37 = 55`를 낮은 바이트부터 적은 **리틀 엔디언** 표기이며, 파이썬 `(55).to_bytes(4, "little").hex(" ")`도 `37 00 00 00`을 돌려준다.
- 이 플랫폼의 로그인 토큰: 32바이트 난수를 바이트마다 16진수 두 자리로 써서 64글자가 되고, 16진수 한 글자가 4비트이므로 64 × 4 = 256비트다.
- AI 기초 4편 「컴퓨터 사이언스로 보는 AI 모델: 텐서, 연산, 메모리」: INT8 양자화의 값 범위 −128~127은 8비트 2의 보수의 범위이고, INT4라면 −8~7의 16가지다.
- 5편 「관계: 동치 관계와 순서 관계」: 합동 `a ≡ b (mod n)`은 나머지가 같은 정수를 묶는 동치 관계로, 해시 테이블의 각 칸은 그 동치류 하나에 해당한다.

## 정리
- 자리값 표기에서 16진수 한 자리는 4비트, 바이트 하나는 16진수 두 자리이며, 진법 변환은 나머지를 반복해서 구하는 일이다.
- 2의 보수는 −x를 `2ⁿ − x`로 저장해 덧셈 회로 하나로 음수까지 처리하고, 8비트의 범위는 −128~127이다.
- 고정 폭 정수 연산은 mod 2ⁿ 연산이라, 최댓값을 넘으면 최솟값 쪽으로 돌아간다.
- 합동은 동치 관계이고, 해시 테이블은 `h mod m`으로 무한한 해시값을 m개의 칸에 나눠 담는다.
