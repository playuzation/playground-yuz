# [이산수학 5/12] 관계: 동치 관계와 순서 관계

> **한 줄 요약** — 관계는 "두 원소가 어떤 사이인가"를 순서쌍의 집합으로 나타낸 것이며, 반사·대칭·추이를 갖춘 동치 관계는 원소를 묶어 나누고, 반사·반대칭·추이를 갖춘 순서 관계는 원소를 줄 세운다.

## 이 글에서 다루는 것
- 관계의 정의와 네 가지 성질
- 동치 관계와 동치류: 같은 것끼리 묶기
- 부분 순서와 전순서, 비교 불가능한 원소
- 버전 비교와 정렬에 숨은 순서 관계

## 관계는 순서쌍의 집합이다
집합 A 위의 **관계** R은 곱집합 `A × A`의 부분집합이다(1편). `(a, b) ∈ R`이면 "a와 b가 관계 R에 있다"고 하고 `a R b`로 쓴다. `≤`도 관계다. 정수에서 `≤`는 (1, 2), (2, 2), (3, 7) 같은 순서쌍을 모두 모은 거대한 집합이다. "a는 b의 약수다", "a와 b는 3으로 나눈 나머지가 같다", "패키지 a가 패키지 b에 의존한다"도 모두 관계다. 관계를 분류하는 기준은 다음 네 가지 성질이다.

| 성질 | 정의 | 예 |
|---|---|---|
| 반사 | 모든 a에 대해 `a R a` | `≤`, `=` |
| 대칭 | `a R b`이면 `b R a` | `=`, "친구다" |
| 반대칭 | `a R b`이고 `b R a`이면 `a = b` | `≤`, `⊂` |
| 추이 | `a R b`이고 `b R c`이면 `a R c` | `<`, "조상이다" |

유한집합이면 정의를 그대로 코드로 옮겨 확인할 수 있다.
```python
from itertools import product

def properties(R, A):
    pairs = list(product(A, repeat=2))
    checks = {
        "반사": all(R(a, a) for a in A),
        "대칭": all(R(b, a) for a, b in pairs if R(a, b)),
        "반대칭": all(a == b for a, b in pairs if R(a, b) and R(b, a)),
        "추이": all(R(a, c) for a, b in pairs if R(a, b) for c in A if R(b, c)),
    }
    return [name for name, ok in checks.items() if ok]

A = range(1, 13)
print("≤    ", properties(lambda a, b: a <= b, A))
print("<    ", properties(lambda a, b: a < b, A))
print("약수 ", properties(lambda a, b: b % a == 0, A))
print("mod 3", properties(lambda a, b: a % 3 == b % 3, A))
```
```text
≤     ['반사', '반대칭', '추이']
<     ['반대칭', '추이']
약수  ['반사', '반대칭', '추이']
mod 3 ['반사', '대칭', '추이']
```
`<`가 반대칭인 것은 `a < b`와 `b < a`가 동시에 성립하는 경우가 아예 없어서 조건이 공허하게 참이기 때문이다. 결과를 보면 두 무리로 나뉜다. "mod 3"은 반사·대칭·추이, "≤"와 "약수"는 반사·반대칭·추이다.

## 동치 관계: 같은 것끼리 묶기
반사·대칭·추이를 모두 만족하는 관계를 **동치 관계**라고 한다. "어떤 기준으로 보면 같다"를 정확히 말한 것이다. 원소 a와 동치인 원소를 전부 모은 집합을 a의 **동치류** `[a]`라고 한다. 동치류들은 서로 겹치지 않으면서 전체를 빠짐없이 덮는다. 즉 동치 관계는 집합을 **분할**한다.
```python
from collections import defaultdict

classes = defaultdict(list)
for n in range(12):
    classes[n % 3].append(n)       # 3으로 나눈 나머지가 같은 수끼리 한 동치류
print(dict(classes))

groups = defaultdict(list)
for s in ["Alice", "alice", "Bob", "ALICE", "bob"]:
    groups[s.lower()].append(s)    # 대소문자를 무시한 비교도 동치 관계
print(dict(groups))
```
```text
{0: [0, 3, 6, 9], 1: [1, 4, 7, 10], 2: [2, 5, 8, 11]}
{'alice': ['Alice', 'alice', 'ALICE'], 'bob': ['Bob', 'bob']}
```
두 예는 같은 원리다. 어떤 함수 f에 대해 "`f(a) = f(b)`이면 같다고 본다"는 관계는 언제나 동치 관계이고, 동치류는 f의 값마다 하나씩 생긴다. 나머지가 같은 정수의 관계는 12편에서 **합동** `a ≡ b (mod n)`이라는 이름으로 다시 만난다.

프로그래밍 언어의 `==`도 동치 관계라고 기대된다. 딕셔너리나 집합은 이 가정 위에서 동작한다. 그런데 부동소수점의 NaN은 `x == x`가 `False`라서 반사성이 깨진다. 그래서 `len({float('nan'), float('nan')})`이 2가 되는 것처럼 집합이나 딕셔너리에서 예상과 다르게 동작한다.

## 순서 관계: 줄 세우기
반사·반대칭·추이를 만족하는 관계를 **부분 순서**라고 한다. 대표적인 예가 집합의 포함 `⊂`와 양의 정수의 약수 관계다. "부분"이라는 말이 붙은 이유는 **비교할 수 없는 원소**가 있기 때문이다. 2와 3은 어느 쪽도 다른 쪽의 약수가 아니고, `{1}`과 `{2}`는 어느 쪽도 다른 쪽에 포함되지 않는다. 12의 약수를 약수 관계로 그리면 위아래가 정해진 그물 모양이 된다(아래가 위의 약수, 추이로 따라오는 선은 생략).
```text
        12
       /  \
      4    6
       \  / \
        2    3
         \  /
          1
```
4와 6, 2와 3은 선으로 이어진 위아래 관계가 없으므로 비교할 수 없다. 반면 `≤`처럼 **모든 두 원소가 비교 가능한** 부분 순서를 **전순서**라고 한다. 수의 크기, 사전식 문자열 순서가 전순서다. 정렬 알고리즘이 "한 줄"로 결과를 내려면 전순서가 필요하다.

## 버전 비교와 정렬
파이썬에서도 순서의 종류가 드러난다. 집합의 `<`(진부분집합)는 부분 순서라 비교 불가능한 쌍이 있고, 버전 문자열은 문자열 순서로 비교하면 틀린 답이 나온다.
```python
print({1} < {1, 2}, {1} < {2}, {2} < {1})   # True False False: {1}과 {2}는 비교 불가능
print("1.10.0" < "1.9.0")                    # True: 문자열 순서로는 틀린 답
v = lambda s: tuple(map(int, s.split(".")))
print(v("1.10.0") < v("1.9.0"))              # False: 숫자 튜플의 사전식 순서
print(sorted(["1.10.0", "1.9.0", "1.2.3", "2.0.0"], key=v))
# ['1.2.3', '1.9.0', '1.10.0', '2.0.0']
```
(주, 부, 수) 숫자 튜플을 앞자리부터 비교하는 사전식 순서는 전순서라서 어떤 두 버전이든 앞뒤를 정할 수 있다.

## 정리
- 관계는 곱집합의 부분집합이고, 반사·대칭·반대칭·추이로 성질을 분류한다.
- 동치 관계(반사·대칭·추이)는 집합을 겹치지 않는 동치류로 나눈다. 나머지가 같은 정수, 대소문자를 무시한 문자열이 예다.
- 부분 순서(반사·반대칭·추이)에는 비교 불가능한 원소가 있을 수 있고, 모든 쌍이 비교 가능하면 전순서다.
- 버전 비교나 정렬처럼 "줄 세우기"가 필요한 곳에는 알맞은 전순서를 골라야 한다.
