## 비둘기집 원리
**비둘기집 원리**의 기본형은 이렇다. 비둘기 n + 1마리가 집 n개에 들어가면 어떤 집에는 반드시 두 마리 이상이 있다. 너무 당연해 보이지만 결과는 강력하다. 13명이 모이면 태어난 달이 같은 사람이 반드시 있다. 달은 12개뿐이기 때문이다.

**일반형**: 물건 N개를 칸 k개에 나눠 넣으면 어떤 칸에는 적어도 `⌈N/k⌉`개가 들어간다(`⌈x⌉`는 x 이상인 가장 작은 정수, 올림). 100명이면 `⌈100/12⌉ = 9`이므로 같은 달에 태어난 사람이 적어도 9명 있다. 증명은 3편의 귀류법이다. 모든 칸이 `⌈N/k⌉ − 1`개 이하라면 전체는 `k × (⌈N/k⌉ − 1)`개 이하인데, 이 값은 N보다 작아서 N개를 다 넣었다는 사실과 모순이다.

이 원리는 "어딘가에 있다"(∃)는 것만 말하고 어느 칸인지는 알려 주지 않는다. 그래서 무언가가 **불가능하다**는 것을 보일 때 특히 강하다.

## 해시 충돌은 피할 수 없다
해시 테이블은 키를 해시 함수로 칸 번호에 대응시킨다(1편의 함수). 키의 종류(모든 문자열)는 무한하고 칸은 유한하므로, 어떤 해시 함수를 쓰든 서로 다른 두 키가 같은 칸으로 가는 **충돌**은 반드시 생긴다. 함수가 단사일 수 없다는 뜻이다. 칸 10개짜리 테이블에 키 11개를 넣어 보자.
```python
from zlib import crc32

m = 10                                   # 칸이 10개인 해시 테이블
seen = {}
for i in range(m + 1):                   # 키 11개를 넣으면 충돌이 반드시 생긴다
    key = f"user{i}"
    slot = crc32(key.encode()) % m
    if slot in seen:
        print(f"충돌: {seen[slot]}, {key} → 칸 {slot}")
        break
    seen[slot] = key
```
```text
충돌: user0, user8 → 칸 3
```
비둘기집 원리는 "늦어도 11번째 키에서는 충돌한다"는 상한을 보장할 뿐이고, 실제로는 9번째 키에서 이미 충돌했다. 생각보다 훨씬 일찍 충돌이 일어나는 현상은 23명만 모여도 생일이 같은 쌍이 있을 확률이 50%를 넘는다는 **생일 문제**와 같은 원리이며, 확률 계산은 확률과 분포 2편 「조건부 확률과 독립」에서 다룬다. 그래서 해시 테이블은 충돌을 없애는 대신 충돌이 나도 동작하도록(같은 칸에 목록으로 잇거나 다른 칸을 찾아가도록) 설계한다.

## 모든 파일을 줄이는 압축은 불가능하다
"어떤 파일이든 넣으면 반드시 더 작아지는 무손실 압축 프로그램"은 존재할 수 없다. 비둘기집 원리로 바로 보일 수 있다.
```text
길이가 정확히 n비트인 파일의 수    2ⁿ
n비트보다 짧은 파일의 수          2⁰ + 2¹ + … + 2ⁿ⁻¹ = 2ⁿ − 1
```
2ⁿ개의 파일을 2ⁿ − 1개의 더 짧은 파일에 대응시키면 서로 다른 두 파일이 같은 압축 결과를 갖게 된다. 그러면 압축을 풀 때 둘 중 무엇이었는지 알 수 없으므로 "무손실"이 깨진다. n = 8이면 256개의 파일을 255개의 칸에 넣는 셈이다. 실제 압축기는 반복이 많은 파일을 줄이는 대신 무작위에 가까운 파일은 오히려 조금 키운다. 파일을 평균적으로 얼마나 줄일 수 있는지의 한계는 정보 이론 1편 「정보량과 엔트로피」에서 다룬다.

## 포함·배제의 원리
두 집합의 합집합 크기를 셀 때 각 집합의 크기를 그냥 더하면 교집합이 두 번 세어진다. 한 번 빼 주면 된다.
```text
∣A ∪ B∣ = ∣A∣ + ∣B∣ − ∣A ∩ B∣
```
1부터 100까지 2나 3의 배수는 몇 개일까? 2의 배수 50개, 3의 배수 33개, 둘 다인 6의 배수 16개이므로 `50 + 33 − 16 = 67`개다. 세 집합이면 둘씩 겹친 부분을 빼고, 그러면 셋 다 겹친 부분이 한 번도 안 세어지므로 다시 더한다.
```text
∣A ∪ B ∪ C∣ = ∣A∣ + ∣B∣ + ∣C∣ − ∣A ∩ B∣ − ∣A ∩ C∣ − ∣B ∩ C∣ + ∣A ∩ B ∩ C∣
```
5의 배수까지 넣으면 `50 + 33 + 20 − 16 − 10 − 6 + 3 = 74`개다. 파이썬 집합으로 직접 세어 확인할 수 있다.
```python
N = range(1, 101)
A = {n for n in N if n % 2 == 0}
B = {n for n in N if n % 3 == 0}
C = {n for n in N if n % 5 == 0}

print(len(A | B), len(A) + len(B) - len(A & B))   # 67 67
print(len(A | B | C),
      len(A) + len(B) + len(C) - len(A & B) - len(A & C) - len(B & C) + len(A & B & C))  # 74 74
```

"적어도 하나"를 셀 때는 여집합과 함께 쓰면 편하다. 영어 소문자와 숫자로 된 8자리 비밀번호 중 "문자와 숫자가 둘 다 들어간" 것은 전체 `36⁸`에서 문자만 쓴 `26⁸`과 숫자만 쓴 `10⁸`을 빼면 된다(둘은 겹치지 않는다). 결과는 2,612,182,842,880가지다.

## 어디에 쓰이나
- 12편 「수 체계와 모듈러 연산: 2진수에서 해시까지」: 해시 테이블은 해시값 h를 칸 수 m으로 나눈 나머지 `h mod m`으로 칸을 정하는데, 비둘기집 원리 때문에 충돌 처리는 선택이 아니라 필수다.
- AI 기초 4편 「컴퓨터 사이언스로 보는 AI 모델: 텐서, 연산, 메모리」: FP32 값을 16가지 값만 있는 INT4로 양자화하면 서로 다른 가중치들이 같은 값으로 뭉쳐지는데, 이는 칸이 부족한 비둘기집이라 원래 값을 정확히 되돌릴 수 없다는 뜻이다.
- 이 플랫폼의 좋아요: 두 포스트 중 하나라도 좋아요를 누른 사용자 수는 각 포스트의 좋아요 수를 더한 뒤 둘 다 누른 사용자 수를 빼서 `∣A ∪ B∣`로 센다.

## 정리
- 물건 N개를 칸 k개에 넣으면 어떤 칸에는 적어도 `⌈N/k⌉`개가 있다. 이 원리는 존재만 보장하며 불가능성 증명에 강하다.
- 무한한 키를 유한한 칸에 보내는 해시 함수는 충돌을 피할 수 없고, 모든 파일을 줄이는 무손실 압축은 존재하지 않는다.
- 포함·배제의 원리는 겹친 부분을 빼고 더하기를 번갈아 하며 합집합의 크기를 정확히 센다.
