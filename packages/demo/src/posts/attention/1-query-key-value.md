# [어텐션 1/9] 어텐션의 기본: 쿼리, 키, 값

> **한 줄 요약** — 어텐션은 쿼리를 모든 키와 내적해 유사도를 재고, softmax로 바꾼 가중치로 값들을 섞는 "부드러운 사전 조회"이며, √d_k로 나누는 것은 내적의 분산을 1로 맞춰 softmax가 한쪽으로 쏠리지 않게 하기 위해서다.

## 이 글에서 다루는 것
- 고정 길이 벡터의 병목과 어텐션의 등장
- 소프트한 사전 조회로 보는 쿼리·키·값
- `softmax(QKᵀ/√d_k)V`의 세 단계와 NumPy 구현
- √d_k로 나누는 이유: 내적 분산 실험
- 비용: O(n²·d) 연산과 n×n 점수 행렬

## 출발점: 벡터 하나에 문장 전체를 담는 병목
RNN 인코더-디코더 번역기는 입력 문장 전체를 고정 길이 벡터 하나에 눌러 담고, 디코더는 그 벡터만 보고 번역했다. 문장이 길수록 정보가 빠져나가자 바다나우(Bahdanau) 등(2014)은 디코더가 단어를 하나 낼 때마다 인코더의 모든 시점 상태를 다시 보고, 지금 필요한 위치에 큰 가중치를 주어 섞는 방법을 제안했다. 이것이 **어텐션**(attention)이고, 2017년 트랜스포머(「Attention Is All You Need」)는 순환을 빼고 어텐션만으로 모델을 만들었다. 이 역사는 신경망 레이어 6편 「트랜스포머의 인코더와 디코더」에서 이어진다.

## 소프트한 사전 조회
파이썬 딕셔너리의 `d[key]`는 키가 정확히 일치하는 값 하나를 돌려준다. 어텐션은 이 조회를 부드럽게 바꾼 것이다.
- **쿼리**(query): 찾는 것. "지금 이 토큰에 필요한 정보는 무엇인가?"
- **키**(key): 각 항목의 색인. 쿼리와 얼마나 맞는지 비교되는 쪽이다.
- **값**(value): 각 항목이 실제로 내주는 내용.

정확히 일치하는 키 하나를 고르는 대신, 쿼리와 모든 키의 유사도를 재고 유사도가 높을수록 큰 가중치를 주어 값들을 **가중 평균**한다. 가중치가 한 항목에 1, 나머지에 0이면 보통의 사전 조회와 같아진다.

## 정의: softmax(QKᵀ/√d_k)V
토큰 n개가 각자 쿼리를 내고, m개 항목이 각자 키와 값을 낸다. 셀프 어텐션에서는 같은 입력 X(n × d)에 서로 다른 가중치 행렬을 곱해 셋을 만든다: `Q = X·W_Q`, `K = X·W_K`, `V = X·W_V`.
```text
Attention(Q, K, V) = softmax(Q·Kᵀ / √d_k) · V

Q: n × d_k    K: m × d_k    V: m × d_v
Q·Kᵀ: n × m  (i행 j열 = 쿼리 i와 키 j의 내적)
softmax: 행마다 적용 → 각 행의 합이 1
결과: n × d_v (쿼리마다 값들의 가중 평균)
```

세 단계로 읽으면 된다. ① 내적으로 유사도를 잰다. ② softmax로 양수이면서 합이 1인 가중치로 바꾼다. ③ 그 가중치로 값 벡터를 섞는다. 키 3개, 값 3개짜리 작은 사전으로 해 보자.
```python
import numpy as np

def softmax(x, axis=-1):
    x = x - x.max(axis=axis, keepdims=True)   # 넘침 방지(결과는 같다)
    e = np.exp(x)
    return e / e.sum(axis=axis, keepdims=True)

def attention(Q, K, V):
    scores = Q @ K.T / np.sqrt(Q.shape[-1])   # (n, m) 유사도
    weights = softmax(scores)                 # 행마다 합이 1
    return weights @ V, weights

K = np.array([[2.0, 0.0], [0.0, 2.0], [-2.0, 0.0]])   # 키 3개
V = np.array([[10.0], [20.0], [30.0]])                # 키마다 값 하나
q = np.array([[1.0, 1.5]])                            # 2번 키 쪽 쿼리
out, w = attention(q, K, V)
print("가중치:", w.round(3), "출력:", out.round(2))
```
```text
가중치: [[0.324 0.657 0.019]] 출력: [[16.95]]
```

쿼리는 2번 키와 가장 비슷하지만 1번 키와도 어느 정도 비슷하다. 그래서 출력은 20도 10도 아닌 그 사이의 16.95다. 가중치가 미분 가능한 연속 함수라서 경사 하강법으로 W_Q, W_K, W_V를 학습할 수 있다는 점이 딱 하나를 고르는 사전 조회와의 결정적인 차이다.

## √d_k로 나누는 이유
q와 k의 성분이 서로 독립이고 평균 0, 분산 1이면, 내적 `q·k = Σ qᵢkᵢ`는 분산 1짜리 항 d_k개의 합이라 분산이 d_k다. 차원이 크면 점수의 크기가 √d_k에 비례해 커지고, 지수 함수인 softmax는 가장 큰 점수 하나에 가중치를 몰아준다. 거의 원-핫(one-hot)이 된 softmax는 기울기 pᵢ(1 − pᵢ)가 0에 가까워 학습이 잘 되지 않는다. √d_k로 나누면 분산이 다시 1이 된다.
```python
rng = np.random.default_rng(0)
n = 128                                   # 키 개수
for d in [16, 64, 256, 1024]:
    q = rng.normal(size=(1000, d))        # 성분이 평균 0, 분산 1
    k = rng.normal(size=(n, d))
    s = q @ k.T                           # (1000, n) 내적
    raw = softmax(s).max(axis=1).mean()   # 가장 큰 가중치의 평균
    sc = softmax(s / np.sqrt(d)).max(axis=1).mean()
    print(f"d={d:4d}  분산 {s.var():7.1f} → {(s / np.sqrt(d)).var():.2f}"
          f"  최대 가중치 {raw:.2f} → {sc:.2f}")
```
```text
d=  16  분산    15.6 → 0.98  최대 가중치 0.52 → 0.07
d=  64  분산    66.0 → 1.03  최대 가중치 0.78 → 0.07
d= 256  분산   260.3 → 1.02  최대 가중치 0.88 → 0.07
d=1024  분산  1023.7 → 1.00  최대 가중치 0.94 → 0.07
```

나누지 않으면 d = 1024에서 키 128개 중 하나가 평균 94%의 가중치를 가져간다. 나누면 차원과 상관없이 분산이 약 1로 유지되고 가중치 분포의 모양도 같아진다. √d_k는 softmax의 온도를 차원에 맞춰 고정해 두는 장치인 셈이다.

## 비용: O(n²·d)와 n×n 행렬
길이 n인 셀프 어텐션에서 `Q·Kᵀ`는 (n × d)·(d × n) 곱이라 약 2·n²·d FLOPs이고, 가중치와 V의 곱도 2·n²·d FLOPs다. 게다가 중간에 n × n 점수 행렬이 생긴다. 헤드 하나(d = 128), 층 하나 기준으로 계산해 보자.
```python
d = 128                                    # 헤드 하나의 차원
for n in [1024, 8192, 131072]:
    flops = 2 * 2 * n * n * d              # QKᵀ와 가중치·V, 각 2·n·n·d
    mem = n * n * 2                        # BF16 점수 행렬
    print(f"n={n:6d}  {flops / 1e9:9.1f} GFLOPs  점수 행렬 {mem / 2**20:8.0f} MiB")
```
```text
n=  1024        0.5 GFLOPs  점수 행렬        2 MiB
n=  8192       34.4 GFLOPs  점수 행렬      128 MiB
n=131072     8796.1 GFLOPs  점수 행렬    32768 MiB
```

n이 8배가 되면 연산과 메모리는 64배가 된다. 13만 토큰이면 점수 행렬 하나가 헤드 하나에 32GiB라서 그대로 메모리에 만들어 둘 수 없다. 실제 구현은 이 행렬을 통째로 만들지 않거나(7편 플래시 어텐션), 볼 토큰 수 자체를 줄이거나(5편 슬라이딩 윈도), softmax를 빼서 계산 순서를 바꾸는(6편 리니어 어텐션) 방식으로 이 문제를 푼다.

## 어디에 쓰이나
- 선형대수 2편 「내적과 코사인 유사도」: 쿼리와 키의 일치도를 내적으로 재는 것이 어텐션의 첫 단계이며, `Q·Kᵀ`는 모든 쌍의 내적을 행렬 곱 하나로 계산한 것이다.
- 확률과 분포 5편 「분산, 공분산, 상관계수」: 독립인 확률 변수 합의 분산은 각 분산의 합이라는 성질이 내적의 분산 d_k를 설명하고 √d_k 스케일링을 정당화한다.
- AI 기초 4편 「컴퓨터 사이언스로 보는 AI 모델: 텐서, 연산, 메모리」: 그 글의 어텐션 O(n²)는 n × n 점수 행렬에서 나오며, 길이를 8배 늘리면 연산과 메모리가 64배가 된다.
- 2편 「멀티헤드 어텐션과 마스크」: 이 글의 어텐션을 여러 헤드로 나눠 병렬로 돌리고, 마스크로 볼 수 있는 키를 제한한다.

## 정리
- 어텐션은 쿼리와 모든 키의 유사도로 가중치를 만들어 값을 가중 평균하는, 미분 가능한 사전 조회다.
- 식은 `softmax(QKᵀ/√d_k)V`이며, softmax를 행마다 적용해 쿼리마다 합이 1인 가중치를 만든다.
- 내적의 분산은 d_k에 비례하므로 √d_k로 나눠 1로 맞춘다. 나누지 않으면 softmax가 원-핫에 가까워져 학습이 어려워진다.
- 비용은 O(n²·d)이고 n × n 점수 행렬이 생기므로, 긴 문맥에서는 메모리가 먼저 한계에 닿는다.
