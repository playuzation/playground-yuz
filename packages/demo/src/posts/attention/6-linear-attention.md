# [어텐션 6/9] 리니어 어텐션: 소프트맥스 없이 순서를 바꾸기

> **한 줄 요약** — softmax 대신 특징 함수 φ의 내적으로 유사도를 재면 결합 법칙으로 (φ(Q)φ(K)ᵀ)V를 φ(Q)(φ(K)ᵀV)로 바꿔 비용을 O(n·d²)로 줄일 수 있고, 인과 버전은 d×d 상태를 누적하는 RNN이 되지만 고정 크기 상태 때문에 정확한 검색에는 약하다.

## 이 글에서 다루는 것
- softmax를 특징 함수 φ로 바꾸기
- 결합 법칙으로 곱하는 순서를 바꿔 O(n·d²) 만들기
- 인과 버전 = 상태를 누적하는 RNN, 병렬형 = 순환형 확인
- 정규화 항과 한계: 고정 크기 상태의 검색 능력
- 감쇠·게이트 변형(RetNet, GLA)

## softmax가 계산 순서를 묶어 둔다
1편의 어텐션 출력을 쿼리 하나에 대해 풀어 쓰면 다음과 같다.
```text
yᵢ = Σⱼ sim(qᵢ, kⱼ)·vⱼ / Σⱼ sim(qᵢ, kⱼ)
sim(q, k) = exp(q·k / √d)
```

exp(q·k)는 q만의 함수와 k만의 함수로 쪼개지지 않으므로 모든 (i, j) 쌍의 점수를 먼저 계산해야 하고, 그래서 n × n 행렬이 생긴다. **리니어 어텐션**(linear attention, Katharopoulos 등, 2020)은 유사도를 특징 함수의 내적 `sim(q, k) = φ(q)·φ(k)`로 바꾼다. 논문은 항상 양수인 `φ(x) = elu(x) + 1`을 썼다.

## 결합 법칙으로 순서 바꾸기
유사도가 내적이 되면 (정규화 전) 출력은 행렬 곱 세 개의 연쇄 `φ(Q)·φ(K)ᵀ·V`다. 행렬 곱은 결합 법칙이 성립하므로 어느 쪽부터 곱해도 결과가 같지만 비용은 다르다.
```text
(φ(Q)·φ(K)ᵀ)·V   n×n 행렬을 먼저: 4·n²·d FLOPs
φ(Q)·(φ(K)ᵀ·V)   d×d 행렬을 먼저: 4·n·d² FLOPs
```
```python
import numpy as np

def phi(x):                               # elu(x) + 1: 항상 양수
    return np.where(x > 0, x + 1.0, np.exp(x))

rng = np.random.default_rng(0)
n, d = 512, 16
Q, K, V = (rng.normal(size=(n, d)) for _ in range(3))
fQ, fK = phi(Q), phi(K)

left = (fQ @ fK.T) @ V                    # n×n 행렬을 먼저 만든다
right = fQ @ (fK.T @ V)                   # d×d 행렬을 먼저 만든다
print(np.abs(left - right).max() / np.abs(left).max())   # 상대 오차
for n_ in [1024, 8192, 65536]:            # FLOPs: 4·n²·d 대 4·n·d²
    print(n_, f"{4 * n_ * n_ * d:.1e}", f"{4 * n_ * d * d:.1e}")
```
```text
1.23496505207044e-15
1024 6.7e+07 1.0e+06
8192 4.3e+09 8.4e+06
65536 2.7e+11 6.7e+07
```

두 순서의 결과는 상대 오차 10⁻¹⁵ 수준으로 같다. d = 16, 길이 65,536이면 n×n 쪽은 2.7 × 10¹¹, d×d 쪽은 6.7 × 10⁷ FLOPs로 n/d = 4,096배 차이다. n이 d보다 크면 오른쪽 순서가 이기고, 비용이 길이에 선형이 된다. 미적분 8편에서 야코비 행렬을 출력 쪽부터 곱하는 순서가 싼 것과 같은 원리다.

## 인과 버전은 RNN이다
언어 모델에는 인과 마스크가 필요하다. 토큰 t까지의 합만 쓰면 되므로, 합을 누적하는 상태 두 개를 두면 된다.
```text
S_t = S_(t−1) + φ(k_t)·v_tᵀ    (d × d_v 행렬)
z_t = z_(t−1) + φ(k_t)         (d 벡터)
y_t = φ(q_t)ᵀ·S_t / φ(q_t)ᵀ·z_t
```

토큰마다 고정된 비용으로 상태를 갱신하는 RNN이다. 학습 때는 마스크를 씌운 병렬형으로 GPU를 꽉 채워 계산하고, 생성 때는 순환형으로 토큰당 O(d²)에 계산한다. 둘이 정말 같은지 확인해 보자.
```python
# 병렬형: 인과 마스크를 씌운 n×n 계산 (학습 때)
A = np.tril(fQ @ fK.T)                    # 미래 칸은 0
par = (A @ V) / A.sum(axis=1, keepdims=True)

# 순환형: 상태 S(d×d)와 z(d)만 들고 한 토큰씩 (추론 때)
S, z = np.zeros((d, d)), np.zeros(d)
rec = np.empty_like(V)
for t in range(n):
    S += np.outer(fK[t], V[t])            # S_t = S_(t−1) + φ(k_t) v_tᵀ
    z += fK[t]                            # z_t = z_(t−1) + φ(k_t)
    rec[t] = (fQ[t] @ S) / (fQ[t] @ z)
print(np.abs(par - rec).max())
```
```text
4.440892098500626e-16
```

병렬형과 순환형이 반올림 오차(4.4 × 10⁻¹⁶)만큼만 다르다. 생성할 때 들고 다닐 것은 KV 캐시 대신 크기가 고정된 S와 z뿐이라, 문맥이 아무리 길어도 메모리와 토큰당 비용이 늘지 않는다. 병렬형은 다시 n×n이 필요하므로, 실제 구현은 시퀀스를 청크로 나눠 청크 안은 병렬형으로, 청크 사이는 상태를 넘겨 가며 계산한다.

## 정규화 항
분모 `φ(q_t)ᵀ·z_t`는 softmax의 분모 역할을 한다. 가중치 `φ(q)·φ(kⱼ)`의 합으로 나누는데, 가중치가 모두 양수여야 분모가 0이나 음수가 되지 않는다. φ를 항상 양수인 함수로 고르는 이유다. 그래도 분모가 작아지면 수치가 불안정해질 수 있어서, 분모로 나누는 대신 출력에 정규화 층을 두는 변형들도 나왔다.

## 한계: 고정 크기 상태
상태 S = Σ φ(kⱼ)vⱼᵀ는 키-값 쌍을 모두 더해 넣은 **연상 메모리**다. 키 kᵢ로 조회하면 vᵢ에 다른 쌍들이 섞여 나온다. 키가 d차원이면 서로 직교할 수 있는 키는 d개뿐이므로, 저장한 쌍이 d를 넘으면 간섭이 커진다. 설명을 위해 φ를 항등 함수로, 키를 단위 벡터로 두고 softmax 어텐션과 회상 정확도(코사인 유사도)를 비교해 보자.
```python
def softmax(x):
    e = np.exp(x - x.max())
    return e / e.sum()

d = 64
for N in [16, 64, 256, 1024]:             # 저장할 (키, 값) 쌍의 수
    Kn = rng.normal(size=(N, d))
    Kn /= np.linalg.norm(Kn, axis=1, keepdims=True)
    Vn = rng.normal(size=(N, d))
    S = Kn.T @ Vn                         # 고정 크기 상태 d×d
    cos_lin, cos_soft = [], []
    for i in range(N):                    # 키 i로 값 i를 꺼낸다
        got_lin = Kn[i] @ S
        got_soft = softmax(20.0 * (Kn @ Kn[i])) @ Vn
        for got, out in [(got_lin, cos_lin), (got_soft, cos_soft)]:
            out.append(got @ Vn[i] / np.linalg.norm(got)
                       / np.linalg.norm(Vn[i]))
    print(f"N={N:4d}  리니어 {np.mean(cos_lin):.2f}"
          f"  softmax {np.mean(cos_soft):.2f}")
```
```text
N=  16  리니어 0.90  softmax 1.00
N=  64  리니어 0.71  softmax 1.00
N= 256  리니어 0.44  softmax 1.00
N=1024  리니어 0.24  softmax 1.00
```

d = 64에서 쌍이 16개일 때는 리니어 쪽도 0.90이지만 1,024개면 0.24로 떨어진다. softmax 어텐션은 모든 키를 KV 캐시에 그대로 두고 뾰족한 가중치로 하나를 골라내므로 1.00을 유지한다. 긴 문서에서 특정 문장을 그대로 찾아 오는 작업(검색, 복사)에 리니어 어텐션이 약한 이유이고, 하이브리드 모델이 리니어 층 사이에 softmax 어텐션 층을 일부 섞는 이유다(오픈 웨이트 모델 4편).

## 감쇠와 게이트
단순 누적은 오래된 정보가 영원히 남아 새 정보를 가린다. 그래서 상태에 잊는 장치를 더한 변형들이 나왔다.
- **RetNet**(2023): 고정된 감쇠율 γ로 `S_t = γ·S_(t−1) + k_t·v_tᵀ`를 쓴다. 오래된 기억이 지수적으로 흐려진다.
- **GLA**(gated linear attention, 2023): 감쇠를 입력에 따라 달라지는 게이트로 바꿔, 무엇을 얼마나 잊을지 모델이 정한다.

덧셈 대신 기존 기억을 고쳐 쓰는 델타 규칙과 이를 게이트와 결합한 Gated DeltaNet은 신경망 레이어 11편에서, 상태 공간 모델에서 출발해 비슷한 구조에 도달하는 맘바는 신경망 레이어 10편 「상태 공간 모델과 맘바」에서 다룬다.

## 어디에 쓰이나
- 선형대수 3편 「행렬과 행렬 곱」: 행렬 곱의 결합 법칙과 (m × k)·(k × n) 곱의 비용 m·k·n이, 곱하는 순서만 바꿔 O(n²)을 O(n)으로 만드는 근거다.
- 미적분 8편 「다변수 연쇄 법칙과 야코비 행렬」: 역전파가 출력 쪽부터 곱해 비용을 줄이듯, 리니어 어텐션은 φ(K)ᵀV를 먼저 곱해 n × n 중간 결과를 피한다.
- 신경망 레이어 3편 「순환 층(RNN): 상태를 이어 가는 레이어」: 인과 리니어 어텐션도 상태를 갱신하는 RNN이지만, 갱신이 선형이라 학습 때 병렬형으로 바꿔 계산할 수 있다.
- 신경망 레이어 11편 「델타 규칙과 Gated DeltaNet」: 이 글의 연상 메모리 간섭 문제를 델타 규칙과 게이트 감쇠로 완화한다.

## 정리
- 리니어 어텐션은 유사도를 φ(q)·φ(k)로 바꿔 결합 법칙으로 φ(Q)(φ(K)ᵀV)를 계산하며, 비용이 O(n·d²)로 길이에 선형이다.
- 인과 버전은 상태 S_t, z_t를 누적하는 RNN이고, 학습용 병렬형과 생성용 순환형의 결과가 같다.
- φ가 양수여야 정규화 분모가 안전하다.
- 상태 크기가 고정이라 저장한 쌍이 차원을 넘으면 간섭으로 회상이 무너지며, 감쇠·게이트·델타 규칙이 이를 보완한다.
