# [그래프 알고리즘 11/14] 디닉 알고리즘과 최대 유량 최소 컷 정리

## 컷: 유량의 상한
10편 「네트워크 플로우: 포드-풀커슨과 에드몬즈-카프」에서 증가 경로가 없으면 멈췄다. 그때의 유량이 정말 최대일까? 이를 확인하는 도구가 **컷**(cut)이다. 정점을 s가 든 쪽 S와 t가 든 쪽 T로 나누고, S에서 T로 가는 간선 용량의 합을 컷의 용량 c(S, T)라 한다. T에서 S로 가는 간선은 세지 않는다.

어떤 유량 f든, s에서 나온 물은 결국 S와 T의 경계를 넘어야 t에 닿는다. 보존 법칙으로 S 안의 정점을 모두 더하면 다음이 나온다.
```text
∣f∣ = (S→T 유량 합) − (T→S 유량 합)
    ≤ (S→T 용량 합) − 0
    = c(S, T)
```
그러므로 **모든 유량 ≤ 모든 컷**이다. 어떤 유량과 어떤 컷의 값이 같아지면 그 유량은 최대, 그 컷은 최소임이 동시에 확정된다.

## 최대 유량 최소 컷 정리
**정리**: 최대 유량의 값은 최소 컷의 용량과 같다. 1956년 포드와 풀커슨, 그리고 엘라이어스(Peter Elias)·파인스타인(Amiel Feinstein)·섀넌(Claude Shannon)이 각각 독립적으로 발표했다.

증명은 "증가 경로가 없다"에서 시작한다. 잔여 그래프에서 s가 닿는 정점을 S, 나머지를 T라 하자. 증가 경로가 없으므로 t ∈ T다.
- S → T 간선 u → v는 꽉 차 있다. 남은 용량이 있었다면 v도 닿았을 것이다.
- T → S 간선 v → u에는 유량이 0이다. 유량이 있었다면 역간선 u → v로 v에 닿았을 것이다.

그러면 위 식의 부등호가 등호가 되어 ∣f∣ = c(S, T)다. 따라서 세 문장이 같은 말이 된다. (1) f가 최대 유량이다. (2) 잔여 그래프에 증가 경로가 없다. (3) 용량이 ∣f∣인 컷이 있다. 포드-풀커슨 방법이 옳은 이유이자, 최소 컷을 찾는 방법이기도 하다. 알고리즘이 끝난 뒤 잔여 그래프에서 s부터 한 번 더 탐색하면 된다.

## 디닉 알고리즘
에드몬즈-카프는 가장 짧은 증가 경로를 하나 찾을 때마다 BFS를 새로 돈다. 디니츠(Yefim Dinitz)가 1970년에 발표한 방법은 같은 길이의 경로를 한 단계에 모두 처리한다.
1. **레벨 그래프**: 잔여 그래프에서 s부터 BFS로 층 번호 level을 매기고, level이 정확히 1 커지는 간선만 남긴다. s → t 최단 경로는 모두 이 안에 있다.
2. **차단 유량**(blocking flow): 레벨 그래프의 모든 s → t 경로에 꽉 찬 간선이 하나 이상 생길 때까지 DFS로 경로를 찾아 흘린다.
3. t에 닿지 못할 때까지 1~2를 반복한다.

차단 유량 뒤에는 남은 최단 경로가 모두 끊겼으므로 s에서 t까지의 거리가 반드시 1 이상 늘어난다. 거리는 V − 1을 넘지 못하니 단계는 V − 1번 이하다.

단계 안의 효율은 **현재 간선 포인터**(current-edge pointer) `it[v]`가 만든다. DFS가 v에서 간선 하나를 시도했다가 실패하면, 그 간선은 이번 단계에서 다시 성공할 수 없다. 레벨 그래프 안에서는 새 간선이 생기지 않기 때문이다(역간선은 층을 거꾸로 가서 쓰이지 않는다). 그래서 포인터를 넘기고 다시 보지 않는다. 경로 하나를 찾는 데 O(V)(층을 따라 내려간 길이)와 포인터 전진이 들고, 포인터 전진은 단계 전체에서 O(E), 경로마다 꽉 차는 간선이 하나 이상이라 경로는 E개 이하다. 한 단계가 O(VE), 전체는 O(V²E)다.
```python
from collections import deque

def dinic(n, edges, s, t, keep_ptr=True):
    g, to, cap = [[] for _ in range(n)], [], []
    for u, v, c in edges:                 # 간선 2k와 역간선 2k+1이 짝
        g[u].append(len(to)); to.append(v); cap.append(c)
        g[v].append(len(to)); to.append(u); cap.append(0)
    st = {"단계": 0, "경로": 0, "간선 검사": 0}
    def bfs():                            # 잔여 그래프의 BFS 층 번호
        level = [-1] * n; level[s] = 0
        q = deque([s])
        while q:
            v = q.popleft()
            for i in g[v]:
                if cap[i] > 0 and level[to[i]] < 0:
                    level[to[i]] = level[v] + 1; q.append(to[i])
        return level
    def dfs(v, f):                        # 층을 하나씩 내려가는 경로만
        if v == t:
            return f
        while it[v] < len(g[v]):
            i = g[v][it[v]]; st["간선 검사"] += 1
            if cap[i] > 0 and level[to[i]] == level[v] + 1:
                d = dfs(to[i], min(f, cap[i]))
                if d:
                    cap[i] -= d; cap[i ^ 1] += d
                    return d
            it[v] += 1                    # 이 간선은 이번 단계에서 끝났다
        return 0
    flow = 0
    while (level := bfs())[t] >= 0:
        st["단계"] += 1
        it = [0] * n                      # 현재 간선 포인터
        while f := dfs(s, float("inf")):
            flow += f; st["경로"] += 1
            if not keep_ptr:
                it = [0] * n
    side = [v for v in range(n) if level[v] >= 0]  # s가 닿는 정점
    return flow, side, cap, st

S, A, B, C, D, T = range(6)
E = [(S, A, 10), (S, B, 10), (A, B, 2), (A, C, 4), (A, D, 8),
     (B, D, 9), (D, C, 6), (C, T, 10), (D, T, 10)]
flow, side, cap, st = dinic(6, E, S, T)
cut = [(u, v, c) for u, v, c in E if u in side and v not in side]
print("최대 유량", flow, "단계", st["단계"], "경로", st["경로"])
print("s 쪽", side, "컷 용량", sum(c for *_, c in cut))
print("컷 간선", cut)
```
```text
최대 유량 19 단계 2 경로 4
s 쪽 [0, 2] 컷 용량 19
컷 간선 [(0, 1, 10), (2, 4, 9)]
```
마지막 BFS에서 s가 닿은 정점이 S = {S, B}이고, 그 밖으로 나가는 간선 S → A(10)와 B → D(9)의 합 19가 유량과 같다. A → B는 T 쪽에서 S 쪽으로 들어오는 간선이라 세지 않으며, 실제로 그 위의 유량(역간선 `cap[5]`)은 0이다. 증명의 두 성질이 그대로 보인다. 별도 탐색 없이 마지막 BFS의 `level`을 재사용한 것이다.

## 무작위 대조 검사
최대 유량이 완전 탐색 최소 컷과 같은지, 찾은 S의 컷 용량이 유량과 같은지, 그리고 각 간선 유량이 용량 제한과 보존 법칙을 지키는지 함께 본다. 이어서 정점 300개 무작위 그래프에서 포인터를 단계 내내 유지할 때와 경로마다 처음부터 다시 볼 때의 간선 검사 횟수를 센다. 앞 코드에 이어서 실행한다.
```python
import random

def brute_min_cut(n, edges, s, t):
    return min(sum(c for u, v, c in edges if m >> u & 1 and not m >> v & 1)
               for m in range(1 << n) if m >> s & 1 and not m >> t & 1)

def valid(n, edges, cap, s, t):           # 용량 제한과 보존 법칙
    net = [0] * n
    for k, (u, v, c) in enumerate(edges):
        f = cap[2 * k + 1]                # 역간선에 쌓인 양 = 흐른 양
        if not 0 <= f <= c:
            return False
        net[u] -= f; net[v] += f
    return all(net[v] == 0 for v in range(n) if v not in (s, t))

rng = random.Random(11)
for _ in range(500):
    n = rng.randint(2, 7)
    E = [(u, v, rng.randint(1, 20)) for u in range(n) for v in range(n)
         if u != v and rng.random() < 0.4]
    flow, side, cap, _ = dinic(n, E, 0, n - 1)
    cut = sum(c for u, v, c in E if u in side and v not in side)
    assert flow == cut == brute_min_cut(n, E, 0, n - 1), E
    assert valid(n, E, cap, 0, n - 1)
print("무작위 500개 비교: 모두 일치")

n = 300
E = [(u, v, rng.randint(1, 100)) for u in range(n) for v in range(n)
     if u != v and rng.random() < 0.03]
for keep in (True, False):
    st = dinic(n, E, 0, n - 1, keep)[3]
    print("유지" if keep else "리셋", st["단계"], st["경로"], st["간선 검사"])
```
```text
무작위 500개 비교: 모두 일치
유지 3 22 10791
리셋 3 22 45538
```
단계는 3번, 경로는 22개로 같지만, 포인터를 리셋하면 이미 막힌 간선을 경로마다 다시 훑어 간선 검사가 4배 넘게 늘었다. 막다른 간선이 많은 그래프일수록 차이가 커지고, 최악에는 한 단계가 O(VE)가 아니라 O(E²)가 된다.

## 자주 하는 실수와 변형
- DFS 조건을 `level[w] > level[v]`로 느슨하게 쓰면 레벨 그래프가 아니게 되어 단계 수 상한이 깨진다. 정확히 1 큰 층으로만 간다.
- 경로를 찾아 성공한 간선은 포인터를 넘기지 않는다. 아직 용량이 남았을 수 있기 때문이다. 실패했을 때만 넘긴다.
- 최소 컷은 알고리즘이 **끝난 뒤**의 잔여 그래프에서 구한다. 컷 간선은 원래 간선 중 S → T 방향인 것만이다.
- 최소 컷은 하나가 아닐 수 있다. s에서 닿는 집합은 S가 가장 작은 최소 컷이고, 역방향으로 t에 닿을 수 있는 정점을 T로 잡으면 T가 가장 작은 최소 컷이 나온다.
- 모든 용량이 1이면 단계 수가 O(√E)로 줄어 O(E√E)가 되고, 이분 매칭에서는 O(E√V)가 된다. 12편의 호프크로프트-카프 알고리즘이 바로 이 경우다.

## 복잡도
| 방법 | 시간 | 단계·증가 횟수 |
|---|---|---|
| 에드몬즈-카프 | O(VE²) | 증가 O(VE)번 |
| 디닉 | O(V²E) | 단계 V − 1번 이하 |
| 디닉(용량 1) | O(E√E) | 단계 O(√E)번 |

공간은 모두 O(V + E)다. 최소 컷 찾기는 끝난 뒤 탐색 한 번이라 O(V + E)가 더 든다.

## 정리
- 컷 용량은 유량의 상한이고, 값이 같은 유량과 컷을 찾으면 둘 다 최적이다.
- 증가 경로가 없을 때 s에서 닿는 집합이 용량이 유량과 같은 컷을 이루므로, 최대 유량 = 최소 컷이다.
- 디닉은 레벨 그래프에서 차단 유량을 반복하며, 단계마다 s–t 거리가 늘어 V − 1단계 안에 끝난다.
- 현재 간선 포인터가 한 단계를 O(VE)로 묶는다. 500개 대조와 간선 검사 횟수 측정으로 확인했다.
