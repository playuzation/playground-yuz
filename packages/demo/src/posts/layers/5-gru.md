# [신경망 레이어 5/11] GRU: 더 단순한 게이트 순환 층

> **한 줄 요약** — GRU는 LSTM의 셀 상태를 없애고 게이트를 업데이트·리셋 두 개로 줄인 순환 층으로, 새 상태를 옛 상태와 후보 상태의 보간 `(1 − z) ⊙ h_prev + z ⊙ h̃`로 만들어 파라미터를 LSTM의 4분의 3으로 줄이면서 비슷한 성능을 내며, "입력이 정하는 보간 비율"이라는 아이디어는 맘바와 Gated DeltaNet으로 이어진다.

## 이 글에서 다루는 것
- 업데이트 게이트와 리셋 게이트
- 보간 `h = (1 − z) ⊙ h_prev + z ⊙ h̃`가 기억을 지키는 방식과 NumPy 실험
- RNN·LSTM·GRU 파라미터와 구조 비교 표
- 2014년 조경현 등의 제안과 이후 모델로 이어진 게이트 아이디어

## 게이트 두 개로 충분하다
4편의 LSTM은 셀 상태 c와 은닉 상태 h를 따로 들고, 게이트 세 개로 지우기·쓰기·내보내기를 각각 조절했다. 2014년 조경현(Kyunghyun Cho) 등은 RNN 인코더-디코더로 기계 번역을 하는 논문에서 더 단순한 순환 유닛을 제안했고, 이것이 나중에 **GRU**(Gated Recurrent Unit)라는 이름으로 불리게 되었다. 핵심 단순화는 두 가지다.
- 셀 상태를 없애고 h 하나만 둔다. 출력 게이트도 없다.
- 망각과 입력을 하나의 **업데이트 게이트** z로 묶는다. "옛 것을 얼마나 지울지"와 "새 것을 얼마나 쓸지"가 늘 합이 1이 되도록 묶은 것이다.

여기에 후보 상태를 만들 때 옛 상태를 얼마나 참고할지 정하는 **리셋 게이트** r을 더한다.
```text
z  = σ(x_t W_z + h_(t−1) U_z + b_z)              업데이트 게이트
r  = σ(x_t W_r + h_(t−1) U_r + b_r)              리셋 게이트
h̃  = tanh(x_t W_h + (r ⊙ h_(t−1)) U_h + b_h)     후보 상태
h_t = (1 − z) ⊙ h_(t−1) + z ⊙ h̃                  보간
```

r ≈ 0이면 후보 상태가 과거를 무시하고 현재 입력만으로 만들어진다. 문장이 바뀌는 지점처럼 새로 시작해야 할 때 쓸모 있다. z는 원소마다 "이 칸은 새 후보로 바꿀지, 옛 값을 유지할지"를 정한다. 표기에 주의할 점이 있다. 원 논문과 PyTorch는 z를 반대 의미로 써서 `h_t = z ⊙ h_(t−1) + (1 − z) ⊙ h̃`로 적는다. z와 1 − z의 이름만 바꾼 것이라 같은 모델이다. PyTorch는 또 r을 U_h를 곱한 뒤에 곱하는 약간 다른 변형을 쓴다.

## 보간이 기억을 지킨다
마지막 식은 옛 상태와 후보의 가중 평균이다. h_(t−1)과 h̃가 모두 −1~1 사이면 h_t도 그 안에 머문다. 그리고 h_(t−1)에서 h_t로 가는 직접 경로의 미분은 `diag(1 − z)`다. LSTM의 셀 상태가 f로 이어졌듯이, z ≈ 0인 칸은 가중치 행렬 곱셈 없이 상태와 기울기를 그대로 다음 스텝으로 넘긴다. z를 상수로 고정하면 이 식은 지수 이동 평균이고, 기억이 유지되는 길이는 대략 1/z 스텝이다.

한 스텝 구현과 파라미터 수, 그리고 4편과 같은 방식으로 50스텝 뒤 상태가 처음 상태에 얼마나 민감한지를 재 보자. z의 편향을 낮출수록 z가 0에 가까워진다.
```python
import numpy as np

def sigmoid(a):
    return 1 / (1 + np.exp(-a))

def gru_step(x, h, W, U, b):
    # W: (d_in, 3·d_h), U: (d_h, 3·d_h), b: (3·d_h,)  순서: z, r, 후보
    d = h.shape[-1]
    ax, ah = x @ W + b, h @ U
    z = sigmoid(ax[..., :d] + ah[..., :d])        # 업데이트 게이트
    r = sigmoid(ax[..., d:2*d] + ah[..., d:2*d])  # 리셋 게이트
    h_new = np.tanh(ax[..., 2*d:] + (r * h) @ U[:, 2*d:])
    return (1 - z) * h + z * h_new                # 옛 상태와 후보의 보간

rng = np.random.default_rng(0)
def init(d_in, d_h):
    return (rng.normal(0, 1 / np.sqrt(d_in), (d_in, 3 * d_h)),
            rng.normal(0, 1 / np.sqrt(d_h), (d_h, 3 * d_h)), np.zeros(3 * d_h))

W, U, b = init(256, 256)
h = gru_step(rng.normal(size=(4, 256)), np.zeros((4, 256)), W, U, b)
print(h.shape, f"GRU {W.size + U.size + b.size:,}")
cell = (256 + 256) * 256 + 256                    # 게이트(또는 RNN 셀) 하나
print(f"RNN {cell:,} / GRU {3 * cell:,} / LSTM {4 * cell:,}")

# 업데이트 게이트 편향을 낮추면(z ≈ 0) 50스텝 뒤에도 처음 상태가 남는다
d, eps = 32, 1e-6
W, U, b = init(d, d)
xs, u = rng.normal(size=(50, d)), np.ones(d) / np.sqrt(d)
def run(h):
    for x in xs:
        h = gru_step(x, h, W, U, b)
    return h
for zb in [0.0, -2.0, -4.0]:
    b[:d] = zb
    s = np.linalg.norm(run(eps * u) - run(np.zeros(d))) / eps
    print(f"z 편향 {zb}: 50스텝 뒤 민감도 {s:.2e}")
```
```text
(4, 256) GRU 393,984
RNN 131,328 / GRU 393,984 / LSTM 525,312
z 편향 0.0: 50스텝 뒤 민감도 5.64e-10
z 편향 -2.0: 50스텝 뒤 민감도 1.97e-03
z 편향 -4.0: 50스텝 뒤 민감도 2.81e-01
```

z가 0.5 근처(편향 0)면 3편의 RNN처럼 처음 상태를 10⁻¹⁰ 수준으로 잊지만, 편향을 −4로 내리면(σ(−4) ≈ 0.018) 50스텝 뒤에도 민감도가 0.28로 남는다. 4편 LSTM의 망각 게이트 편향 실험과 같은 그림이다. 실제 학습에서는 z가 입력에 따라 매 스텝 달라지므로, 기억할 칸은 열어 두고 갱신할 칸만 바꾸는 식으로 쓰인다.

## RNN·LSTM·GRU 비교
| 항목 | RNN | LSTM | GRU |
|---|---|---|---|
| 상태 | h | h와 c | h |
| 게이트 | 없음 | f, i, o | z, r |
| 배수 | 1 | 4 | 3 |
| d=256 | 131,328 | 525,312 | 393,984 |
| 제안 | 1980년대 | 1997 | 2014 |

배수는 파라미터 `(d_in + d_h)·d_h + d_h` 덩어리가 몇 개인지다. GRU는 같은 크기의 LSTM보다 파라미터와 계산이 25% 적다. 성능은 과제에 따라 엇갈려서, 2014년 Chung 등의 비교 실험도 GRU와 LSTM 사이에 뚜렷한 승자가 없고 둘 다 게이트 없는 RNN보다 확실히 낫다고 보고했다. 차이는 게이트가 있느냐 없느냐에서 크게 나고, 게이트를 어떻게 나누느냐에서는 작게 난다는 뜻이다.

## 게이트 아이디어의 후손
GRU의 보간 `h_t = (1 − z_t) ⊙ h_(t−1) + z_t ⊙ (새 정보)`는 이후 순환형 모델의 기본 문형이 되었다. 맘바(10편)의 선택적 SSM에서 입력에 따라 정해지는 Δ가 바로 이 z 역할을 하며, 맘바 논문은 상태 크기 1, A = −1인 선택적 SSM이 정확히 `g_t = σ(Linear(x_t))`, `h_t = (1 − g_t)h_(t−1) + g_t x_t` 꼴이 된다는 것을 보였다. Gated DeltaNet(11편)의 감쇠 게이트 α_t도 "옛 기억을 얼마나 남길지를 입력이 정한다"는 같은 원리다. 달라진 점은 비선형 tanh를 걷어 내고 상태 갱신을 선형으로 만들었다는 것이다. 선형이 되면 순차 계산을 병렬 스캔이나 행렬 곱으로 바꿀 수 있어서, 3편에서 본 병렬화의 벽을 넘는다.

## 어디에 쓰이나
- 미적분 10편 「경사 하강법의 수학」: Adam의 `m ← β₁·m + (1 − β₁)·g`는 z를 1 − β₁로 고정한 GRU 보간과 같은 지수 이동 평균이고, GRU는 이 비율을 입력에 따라 매 스텝 새로 정한다.
- 미적분 3편 「미분 규칙과 연쇄 법칙」: 보간 식의 직접 경로 미분은 `1 − z`라서, z ≈ 0이면 연쇄 법칙으로 이어지는 기울기가 깎이지 않는다.
- 6편 「트랜스포머의 인코더와 디코더」: GRU를 제안한 조경현 등의 논문이 RNN 인코더-디코더 구조를 함께 제안했고, 그 고정 길이 병목을 풀려고 어텐션이 등장했다.
- 10편 「상태 공간 모델과 맘바」: 맘바의 Δ는 GRU의 업데이트 게이트처럼 입력에 따라 "얼마나 새로 쓸지"를 정하며, 상태 크기 1인 특수한 경우 GRU식 보간과 정확히 같아진다.

## 정리
- GRU는 셀 상태 없이 업데이트 게이트 z와 리셋 게이트 r 두 개로 기억을 관리한다.
- 새 상태는 `(1 − z) ⊙ h_prev + z ⊙ h̃`라는 보간이고, z ≈ 0인 칸은 상태와 기울기를 그대로 넘긴다(편향 −4에서 50스텝 뒤 민감도 0.28).
- 파라미터는 같은 크기 LSTM의 4분의 3이고, 성능은 과제에 따라 비슷하다.
- 입력이 정하는 보간 비율이라는 아이디어는 맘바의 Δ와 Gated DeltaNet의 α로 이어진다.
