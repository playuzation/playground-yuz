# [신경망 레이어 1/11] 선형 층: 모든 신경망의 기본 부품

> **한 줄 요약** — 선형 층 `y = xW + b`는 뉴런 여러 개의 가중합을 행렬 곱 한 번으로 계산하는 부품이며, 비용은 파라미터 수와 토큰당 2·입력·출력 FLOPs로 정확히 셀 수 있고, 비선형 함수 없이 쌓으면 아무리 깊어도 층 하나와 같다.

## 이 글에서 다루는 것
- `y = xW + b`의 모양과 배치 행렬 곱
- 파라미터 수와 FLOPs 세기
- 비선형 없이 쌓은 선형 층이 하나로 접히는 것을 수치로 확인
- 초기화: Xavier와 He가 활성값의 크기를 지키는 원리
- 최근 LLM이 편향 없는 선형 층을 쓰는 이유

## y = xW + b: 가중합을 한꺼번에
AI 기초 1편의 뉴런은 입력의 가중합 `w·x + b`를 계산했다. 출력이 d_out개인 층은 이런 뉴런 d_out개를 나란히 둔 것이고, 각 뉴런의 가중치 벡터를 열로 모으면 행렬 W가 된다. 그래서 **선형 층**(linear layer, 완전 연결 층·dense 층이라고도 한다)은 한 줄로 쓴다.
```text
y = x W + b
x: (d_in,)   W: (d_in, d_out)   b: (d_out,)   y: (d_out,)
```

출력 yⱼ는 W의 j번째 열과 x의 내적에 bⱼ를 더한 값이다. 입력의 모든 원소가 모든 출력에 연결되어 있다는 점이 다음 글들의 합성곱 층, 순환 층과 다른 점이다. 참고로 PyTorch의 `nn.Linear`는 가중치를 (d_out, d_in) 모양으로 저장하고 `x @ W.T + b`를 계산한다. 같은 층을 전치해서 보관할 뿐이다.

## 배치와 토큰: 마지막 축만 곱한다
실제로는 입력 하나가 아니라 (배치, 토큰, d_in) 모양의 텐서가 들어온다. 행렬 곱은 마지막 축끼리만 일어나고 앞쪽 축은 그대로 따라간다. 모든 토큰에 같은 W를 쓰므로 토큰마다 독립적으로 계산되고, GPU는 이를 큰 행렬 곱 하나로 처리한다.
```python
import numpy as np

x = np.ones((2, 3, 4))                 # (배치, 토큰, d_in)
W, b = np.ones((4, 5)), np.zeros(5)    # (d_in, d_out), (d_out,)
print((x @ W + b).shape)               # 마지막 축끼리만 곱해진다

d_in, d_out, tokens = 4096, 4096, 8 * 1024
params = d_in * d_out + d_out
flops = 2 * d_in * d_out * tokens
print(f"{params:,} 파라미터, 배치 전체 {flops / 1e9:.0f} GFLOPs")
```
```text
(2, 3, 5)
16,781,312 파라미터, 배치 전체 275 GFLOPs
```

## 파라미터 수와 FLOPs
선형 층의 비용은 공식 두 개로 끝난다.
- 파라미터: `d_in·d_out + d_out` (편향이 없으면 `d_in·d_out`)
- 토큰당 FLOPs: 출력 하나에 곱셈·덧셈이 d_in번씩이므로 `2·d_in·d_out`

4096 → 4096 층 하나가 약 1,678만 개의 파라미터를 갖고, 토큰 8,192개(배치 8 × 길이 1024)를 통과시키는 데 약 275 GFLOPs가 든다. 언어 모델의 파라미터는 거의 전부 이런 선형 층의 W이고, AI 기초 4편의 "토큰당 추론 약 2 × 파라미터 수 FLOPs"라는 어림 규칙도 여기서 나온다. 파라미터 하나가 토큰마다 곱셈 한 번, 덧셈 한 번에 쓰이기 때문이다.

## 비선형 없이 쌓으면 한 층이다
선형 층 두 개를 이어 붙이면 `(xW₁ + b₁)W₂ + b₂ = x(W₁W₂) + (b₁W₂ + b₂)`이다. 행렬 곱의 결합 법칙 때문에 W = W₁W₂, b = b₁W₂ + b₂인 선형 층 하나와 똑같다. 100층을 쌓아도 마찬가지다. 사이에 ReLU 같은 비선형 함수를 넣어야 층을 쌓는 의미가 생긴다.
```python
import numpy as np

rng = np.random.default_rng(0)
x = rng.normal(size=(5, 8))                       # 배치 5, 입력 8
W1, b1 = rng.normal(size=(8, 16)), rng.normal(size=16)
W2, b2 = rng.normal(size=(16, 4)), rng.normal(size=4)

deep = (x @ W1 + b1) @ W2 + b2                    # 선형 층 2개
W, b = W1 @ W2, b1 @ W2 + b2                      # 하나로 합친 층
print(np.abs(deep - (x @ W + b)).max())

# ReLU를 넣으면? 최소제곱으로 고른 '가장 좋은 선형 층 하나'와 비교
X = rng.normal(size=(1000, 8))
Xa = np.hstack([X, np.ones((1000, 1))])           # 편향용 1 열
for name, act in [("선형", lambda z: z), ("ReLU", lambda z: np.maximum(z, 0))]:
    Y = act(X @ W1 + b1) @ W2 + b2
    coef = np.linalg.lstsq(Xa, Y, rcond=None)[0]
    err = np.linalg.norm(Xa @ coef - Y) / np.linalg.norm(Y)
    print(f"{name}: 상대 오차 {err:.4f}")
```
```text
5.329070518200751e-15
선형: 상대 오차 0.0000
ReLU: 상대 오차 0.3292
```

두 층의 출력과 합친 한 층의 출력 차이는 부동소수점 오차(10⁻¹⁵) 수준이다. 반면 ReLU를 넣은 2층 신경망은 어떤 선형 층 하나로도 흉내 낼 수 없어서, 최소제곱으로 고른 최선의 선형 층도 33%의 오차를 남긴다. 은닉 크기 16이 입력 8보다 크다는 것도 비선형이 없으면 의미가 없다. 합친 W는 8×4 행렬일 뿐이다.

## 초기화: 분산을 지키는 법
층을 깊게 쌓으면 초기 가중치의 크기가 결정적이다. 입력 원소들이 서로 독립이고 W의 원소 분산이 Var(W)라면 출력 하나의 분산은 다음과 같다.
```text
Var(yⱼ) = d_in · Var(W) · E[x²]
```

층마다 d_in·Var(W)배가 곱해지므로, 이 값이 1보다 크면 깊이에 따라 지수적으로 폭발하고 작으면 사라진다. 그래서 분산을 유지하도록 W를 뽑는다.
- **Xavier 초기화**(Glorot·Bengio, 2010): `Var(W) = 2 / (d_in + d_out)`. 순전파와 역전파의 분산을 함께 맞추는 절충으로, 0 근처에서 기울기가 1인 tanh 같은 대칭 활성화를 가정해 유도했다.
- **He 초기화**(He 등, 2015): `Var(W) = 2 / d_in`. ReLU는 입력의 절반을 0으로 만들어 제곱 평균을 반으로 줄이므로 2배를 보상한다.

ReLU 층 20개를 쌓아 활성값의 제곱 평균 제곱근(RMS)이 어떻게 변하는지 보자.
```python
import numpy as np

rng = np.random.default_rng(0)
n, depth = 512, 20
x0 = rng.normal(size=(256, n))                    # 입력 256개, 표준편차 1

inits = {
    "N(0, 1)":        lambda: rng.normal(0, 1, (n, n)),
    "N(0, 0.01²)":    lambda: rng.normal(0, 0.01, (n, n)),
    "Xavier":         lambda: rng.normal(0, np.sqrt(2 / (n + n)), (n, n)),
    "He":             lambda: rng.normal(0, np.sqrt(2 / n), (n, n)),
}
for name, init in inits.items():
    h, rms = x0, []
    for layer in range(depth):
        h = np.maximum(h @ init(), 0)             # 선형 층 + ReLU
        if layer + 1 in (1, 5, 10, 20):
            rms.append(f"{np.sqrt((h**2).mean()):.3g}")
    print(f"{name:12s}", rms)
```
```text
N(0, 1)      ['16', '1.04e+06', '1.08e+12', '1.12e+24']
N(0, 0.01²)  ['0.16', '0.000101', '1.07e-08', '9.7e-17']
Xavier       ['0.708', '0.172', '0.0316', '0.000989']
He           ['1', '1.03', '1.08', '0.878']
```

표준편차 1로 뽑으면 층마다 √(512/2) = 16배씩 커져 20층에서 10²⁴에 이르고, 0.01로 뽑으면 층마다 0.16배가 되어 사라진다. Xavier는 ReLU와 함께 쓰면 층마다 1/√2 ≈ 0.707배로 줄어든다. He만 20층을 지나도 크기 1 근처를 유지한다. 활성값이 폭발하거나 사라지면 역전파 기울기도 같은 운명을 겪으므로, 초기화는 학습이 시작될 수 있느냐를 가르는 문제다. 트랜스포머에서는 잔차 연결과 정규화 층(7편)이 이 역할을 크게 덜어 주지만, GPT-2처럼 잔차 경로로 들어가는 층의 가중치를 층 수에 맞춰 줄여 초기화하는 식의 조정은 여전히 쓰인다.

## 편향 없는 선형 층
라마 계열을 비롯한 최근 LLM은 선형 층에 편향 b를 아예 두지 않는 경우가 많다. PaLM 논문은 선형 층과 정규화 층의 편향을 없앴더니 큰 모델의 학습 안정성이 좋아졌다고 보고했다. 편향은 파라미터 수로 보면 W의 1/d_in에 불과해서 없애도 표현력 손해가 작다. 다만 일부만 남기는 선택도 있다. Qwen2는 어텐션의 Q·K·V 투영에만 편향을 남겼고, Qwen3는 그것마저 없애는 대신 QK-Norm을 넣었다(7편).

## 어디에 쓰이나
- AI 기초 1편 「딥러닝: 특징까지 스스로 배우는 머신러닝」: XOR 예제의 `X @ W1`이 바로 배치 입력에 대한 선형 층이고, 뉴런 가중합 w·x + b를 열 개수만큼 한꺼번에 계산한 것이다.
- AI 기초 4편 「컴퓨터 사이언스로 보는 AI 모델: 텐서, 연산, 메모리」: 행렬 곱 FLOPs 2·m·k·n과 "토큰당 약 2N FLOPs" 어림은 선형 층의 `2·d_in·d_out`을 모든 층에 대해 더한 것이다.
- 선형대수 4편 「선형 변환으로서의 행렬」: 선형 층 두 개가 하나로 접히는 것은 선형 변환의 합성이 행렬 곱 하나라는 사실 그대로다.
- 8편 「피드포워드 층의 진화: GELU에서 SwiGLU까지」: 트랜스포머의 FFN은 선형 층 2~3개 사이에 활성화 함수를 끼운 것이고, 모델 파라미터의 대부분이 여기에 있다.

## 정리
- 선형 층 `y = xW + b`는 마지막 축끼리의 행렬 곱이며, 파라미터는 `d_in·d_out (+ d_out)`, 토큰당 FLOPs는 `2·d_in·d_out`이다.
- 비선형 함수가 없으면 선형 층을 몇 개 쌓아도 W₁W₂…인 층 하나와 같다(오차 10⁻¹⁵).
- 초기화는 층을 지날 때 분산이 유지되도록 `Var(W)`를 고른다: tanh 계열에는 Xavier, ReLU에는 He.
- 최근 LLM은 안정성과 단순함을 위해 편향 없는 선형 층을 많이 쓴다.
