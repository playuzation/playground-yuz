# [신경망 레이어 2/11] 합성곱 층: 가까운 것끼리 보는 레이어

## 커널을 밀면서 같은 계산을 반복한다
이미지에서 "여기에 세로 경계선이 있다"는 사실은 주변 몇 픽셀만 보면 알 수 있고, 같은 경계선 검출기는 이미지의 왼쪽 위에서도 오른쪽 아래에서도 똑같이 쓸모 있다. **합성곱 층**(convolution layer)은 이 두 가지 가정을 구조로 박아 넣는다.
- **지역성**(locality): 출력 한 칸은 입력의 작은 창(k × k)만 본다.
- **가중치 공유**(weight sharing): 모든 위치에서 같은 커널을 쓴다.

계산은 커널을 한 칸씩(보폭 s) 밀면서 창과 커널의 원소별 곱을 모두 더하는 것이다. 엄밀히 말하면 수학의 합성곱은 커널을 뒤집어서 곱하고, 딥러닝 라이브러리가 계산하는 것은 뒤집지 않는 상호상관(cross-correlation)이다. 커널은 어차피 학습되므로 차이가 없어서 그냥 합성곱이라 부른다.
```text
입력 5×5 (■ = 지금 보는 3×3 창)
■ ■ ■ □ □
■ ■ ■ □ □
■ ■ ■ □ □  → 출력[0][0] = Σ 창 ⊙ 커널
□ □ □ □ □
□ □ □ □ □
창을 한 칸씩 밀면 출력 3×3이 채워진다
```

## 출력 크기와 채널
입력 크기 n, 커널 크기 k, 가장자리에 덧대는 패딩 p, 보폭 s라면 출력 크기는 다음과 같다. 나누어떨어지지 않으면 내림한다.
```text
출력 = ⌊(n + 2p − k) / s⌋ + 1
```

k = 3, p = 1, s = 1이면 크기가 그대로이고, s = 2면 절반이 된다. 컬러 이미지는 채널이 3개(RGB)이므로 커널도 (C_in, k, k) 모양의 입체이고, 이런 커널을 C_out개 두면 출력 채널이 C_out개가 된다. 가중치 텐서는 (C_out, C_in, k, k)이고 파라미터는 `C_out·C_in·k² + C_out`이다. 출력 크기와는 상관이 없다는 점이 핵심이다.
```python
import numpy as np

def conv2d(x, w, b, stride=1, pad=0):
    # x: (C_in, H, W), w: (C_out, C_in, k, k), b: (C_out,)
    x = np.pad(x, ((0, 0), (pad, pad), (pad, pad)))
    c_out, _, k, _ = w.shape
    H = (x.shape[1] - k) // stride + 1
    W = (x.shape[2] - k) // stride + 1
    y = np.empty((c_out, H, W))
    for i in range(H):
        for j in range(W):
            patch = x[:, i*stride:i*stride+k, j*stride:j*stride+k]
            y[:, i, j] = (w * patch).sum(axis=(1, 2, 3)) + b
    return y

rng = np.random.default_rng(0)
x = rng.normal(size=(3, 32, 32))                  # RGB 32×32
for k, s, p in [(3, 1, 1), (3, 2, 1), (5, 1, 0), (7, 2, 3)]:
    w, b = rng.normal(size=(64, 3, k, k)), np.zeros(64)
    print(f"k={k} s={s} p={p} →", conv2d(x, w, b, s, p).shape,
          "공식:", (32 + 2*p - k) // s + 1)

conv = 64 * 3 * 3 * 3 + 64                        # 3×3 합성곱, 64채널
dense = (3 * 32 * 32) * (64 * 32 * 32) + 64 * 32 * 32
print(f"합성곱 {conv:,}개 vs 선형 층 {dense:,}개 ({dense / conv:,.0f}배)")
```
```text
k=3 s=1 p=1 → (64, 32, 32) 공식: 32
k=3 s=2 p=1 → (64, 16, 16) 공식: 16
k=5 s=1 p=0 → (64, 28, 28) 공식: 28
k=7 s=2 p=3 → (64, 16, 16) 공식: 16
합성곱 1,792개 vs 선형 층 201,392,128개 (112,384배)
```

## 선형 층과 비교하면
32×32 RGB 이미지(3,072개 값)를 32×32×64 특징 맵(65,536개 값)으로 바꾸는 일을 1편의 선형 층으로 하면 모든 입력과 모든 출력을 잇느라 파라미터가 약 2억 개 필요하다. 3×3 합성곱은 1,792개면 된다. 약 11만 배 차이다. 합성곱 층은 "멀리 떨어진 픽셀끼리는 직접 연결하지 않는다"와 "모든 위치가 같은 가중치를 쓴다"는 제약을 건 선형 층이라고 볼 수 있다. 실제로 합성곱도 행렬 곱으로 바꿀 수 있는데, 그 행렬은 대부분이 0이고 같은 값이 대각선 방향으로 반복된다.

가중치 공유에는 덤이 있다. 입력이 한 칸 움직이면 출력도 한 칸 움직인다(**이동 등변성**). 고양이가 사진 어디에 있든 같은 검출기가 반응한다. 반대로 위치마다 다른 패턴을 배워야 하는 문제에서는 이 가정이 제약이 된다.

## 수용 영역: 쌓아서 넓게 본다
출력 한 칸이 입력에서 영향을 받는 범위를 **수용 영역**(receptive field)이라 한다. 보폭 1인 k × k 합성곱을 L층 쌓으면 수용 영역은 `1 + L·(k − 1)`이다. 3×3을 두 번 쌓으면 5×5를 보면서 가중치는 채널 쌍당 18개로 5×5 한 번(25개)보다 적고 비선형도 하나 더 들어간다. VGG가 3×3 합성곱만 깊게 쌓은 이유다. 보폭이나 풀링으로 해상도를 줄이면 수용 영역이 더 빨리 넓어지고, 커널 사이를 띄워 보는 팽창(dilated) 합성곱을 층마다 2배씩 띄우면 층 수에 지수적으로 넓어진다(WaveNet).

이것이 합성곱의 한계이기도 하다. 멀리 떨어진 두 위치가 정보를 주고받으려면 그 거리를 덮을 만큼 층을 쌓아야 한다. 모든 위치를 한 번에 연결하는 어텐션이 긴 문맥에서 이기는 이유가 여기 있다.

## 1D 인과 합성곱
텍스트나 오디오 같은 시퀀스에는 시간 축 하나로 미는 1D 합성곱을 쓴다. 언어 모델처럼 미래를 보면 안 되는 경우에는 왼쪽(과거)에만 k − 1칸 패딩을 넣어서 출력 t가 입력 t − k + 1 … t만 보게 만든다. 이것이 **인과 합성곱**(causal convolution)이다. 채널마다 따로 커널을 두는 depthwise 방식이면 파라미터는 `k·C`뿐이다.
```python
import numpy as np

def causal_conv1d(x, w):
    # x: (T, C) 시퀀스, w: (k, C) 채널마다 따로인 커널(depthwise)
    k = w.shape[0]
    xp = np.pad(x, ((k - 1, 0), (0, 0)))          # 왼쪽(과거)에만 k−1칸 패딩
    return np.stack([(xp[t:t + k] * w).sum(axis=0) for t in range(len(x))])

rng = np.random.default_rng(0)
x, w = rng.normal(size=(12, 8)), rng.normal(size=(4, 8))
y = causal_conv1d(x, w)

x2 = x.copy()
x2[5] += 1.0                                      # 6번째 토큰(t=5)만 바꾼다
changed = np.abs(causal_conv1d(x2, w) - y).max(axis=1) > 0
print(y.shape, "바뀐 출력 위치:", np.nonzero(changed)[0])
```
```text
(12, 8) 바뀐 출력 위치: [5 6 7 8]
```

t = 5의 입력을 바꾸면 출력 5~8만 바뀐다. 커널 크기 4만큼 미래 쪽으로만 영향이 퍼지고, 과거 출력 0~4는 그대로다. 인과성이 지켜진다는 뜻이다.

이 작은 부품이 최신 시퀀스 모델에서 다시 쓰인다. 맘바(10편)는 SSM 앞에 커널 크기 4(기본값)의 depthwise 인과 합성곱을 두고, Gated DeltaNet(11편)도 q·k·v를 만들 때마다 짧은 인과 합성곱을 거친다. 바로 앞 몇 토큰을 섞는 지역 패턴은 값싼 합성곱에 맡기고, 긴 범위의 기억은 순환 상태에 맡기는 분업이다.

## 정리
- 합성곱 층은 지역성과 가중치 공유를 가정한 선형 층이며, 파라미터는 `C_out·C_in·k² + C_out`으로 입력 크기와 무관하다.
- 출력 크기는 `⌊(n + 2p − k)/s⌋ + 1`이다.
- 수용 영역은 층을 쌓을수록 `1 + L·(k − 1)`로 넓어지지만, 먼 위치를 연결하려면 깊이가 필요하다.
- 왼쪽에만 패딩한 1D 인과 합성곱은 과거만 보며, 맘바·Gated DeltaNet의 짧은 합성곱으로 쓰인다.
