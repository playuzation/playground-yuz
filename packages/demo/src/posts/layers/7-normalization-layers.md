# [신경망 레이어 7/11] 정규화 층: LayerNorm에서 RMSNorm까지

> **한 줄 요약** — 정규화 층은 활성값의 크기를 매 층 다시 맞춰 깊은 신경망의 학습을 안정시키는 부품으로, 트랜스포머는 토큰마다 특징 축으로 정규화하는 LayerNorm을 쓰다가 평균 빼기를 생략한 RMSNorm으로 옮겨 갔고, 정규화를 잔차 경로 밖에 두는 Pre-LN과 쿼리·키에 거는 QK-Norm이 깊고 큰 모델의 학습을 버티게 한다.

## 이 글에서 다루는 것
- 배치 정규화와 층 정규화: 어느 축으로 정규화하나
- RMSNorm: 평균 빼기를 생략하면 무엇이 달라지나
- 게인 파라미터
- Post-LN과 Pre-LN, 깊은 모델의 학습 안정성
- QK-Norm이 어텐션 로짓 폭주를 막는 원리

## 왜 정규화하나
1편에서 초기화로 층을 지나는 활성값의 분산을 맞췄지만, 그것은 학습 시작 시점의 이야기다. 가중치가 바뀌면 각 층 입력의 크기와 분포가 계속 변하고, 수십 층을 지나면서 작은 어긋남이 쌓인다. **정규화 층**(normalization layer)은 매 층에서 활성값을 평균 0, 크기 1 근처로 다시 맞춘 뒤, 학습 가능한 파라미터로 필요한 만큼 크기를 되돌린다. 확률과 분포 8편의 표준화 `z = (x − μ)/σ`를 신경망 안에서 매번 하는 것이다.

## 배치 정규화 vs 층 정규화
두 방법은 같은 표준화를 서로 다른 축으로 한다.
- **배치 정규화**(batch normalization, 2015): 특징 하나를 고정하고 배치 안의 샘플들에 걸쳐 평균·분산을 구한다. 합성곱 신경망에서 크게 성공했지만, 결과가 같은 배치의 다른 샘플에 의존하고, 추론 때는 학습 중에 모아 둔 이동 평균 통계를 써야 한다. 배치가 작거나 시퀀스 길이가 제각각이면 통계가 불안정하고, 토큰을 하나씩 생성하는 언어 모델과도 맞지 않는다.
- **층 정규화**(layer normalization, 2016): 토큰 하나의 d개 특징에 걸쳐 평균·분산을 구한다. 다른 샘플과 무관하고 학습과 추론의 계산이 같다. 트랜스포머가 처음부터 이것을 썼다.
```text
LayerNorm(x) = (x − μ) / √(σ² + ε) ⊙ γ + β
RMSNorm(x)   = x / √(mean(x²) + ε) ⊙ g
μ, σ²: x의 d개 원소의 평균과 분산
RMSNorm은 평균을 빼지 않고 RMS로만 나눈다
```

## RMSNorm: 크기만 맞춘다
**RMSNorm**(Zhang·Sennrich, 2019)은 LayerNorm에서 평균을 빼는 단계(re-centering)와 편향 β를 없애고, 제곱 평균 제곱근(RMS)으로 나누는 크기 조정(re-scaling)만 남겼다. 논문의 가설은 LayerNorm의 효과가 주로 크기 조정에서 나온다는 것이고, 실제로 품질은 비슷하면서 평균을 구하는 리덕션 하나가 빠져 계산이 가볍다. 파라미터도 LayerNorm은 2d(γ, β), RMSNorm은 d(g)다. 라마 이후 대부분의 오픈 웨이트 LLM이 RMSNorm을 쓴다. 둘의 차이를 숫자로 확인해 보자.
```python
import numpy as np

def layer_norm(x, g, b, eps=1e-5):
    mu = x.mean(-1, keepdims=True)
    var = ((x - mu) ** 2).mean(-1, keepdims=True)
    return (x - mu) / np.sqrt(var + eps) * g + b

def rms_norm(x, g, eps=1e-5):
    return x / np.sqrt((x ** 2).mean(-1, keepdims=True) + eps) * g

rng = np.random.default_rng(0)
d = 8
x = rng.normal(2.0, 3.0, size=(4, d))             # 토큰 4개, 평균 2·표준편차 3
g, b = np.ones(d), np.zeros(d)

bn = (x - x.mean(0)) / x.std(0)                   # BN: 특징마다 배치 축으로
ln = layer_norm(x, g, b)                          # LN: 토큰마다 특징 축으로
print("BN 특징별 평균·표준편차:", abs(bn.mean(0)).max().round(6), bn.std(0)[:2])
print("LN 토큰별 평균·표준편차:", abs(ln.mean(1)).max().round(6), ln.std(1)[:2])

# 불변성: LN은 이동·배율 모두에, RMSNorm은 배율에만 불변
print("LN  (5x+7) 차이:", np.abs(layer_norm(5 * x + 7, g, b) - ln).max())
print("RMS (5x)   차이:", np.abs(rms_norm(5 * x, g) - rms_norm(x, g)).max())
print("RMS (x+7)  차이:", np.abs(rms_norm(x + 7, g) - rms_norm(x, g)).max())
xc = x - x.mean(-1, keepdims=True)                # 평균이 0인 입력이면 둘이 같다
diff = np.abs(layer_norm(xc, g, b) - rms_norm(xc, g)).max()
print("평균 0일 때 LN vs RMS:", diff)
```
```text
BN 특징별 평균·표준편차: 0.0 [1. 1.]
LN 토큰별 평균·표준편차: 0.0 [0.99999821 0.99999882]
LN  (5x+7) 차이: 2.944744037503e-06
RMS (5x)   차이: 2.3641470670021647e-06
RMS (x+7)  차이: 2.60491693626251
평균 0일 때 LN vs RMS: 2.220446049250313e-16
```

BN은 특징(열)마다, LN은 토큰(행)마다 평균 0·표준편차 1이 된다. LayerNorm은 입력을 5배 하고 7을 더해도 결과가 같고(차이 10⁻⁶은 ε 때문이다), RMSNorm은 5배에는 불변이지만 7을 더하면 결과가 크게 달라진다. 평균을 빼지 않으니 이동에는 불변이 아니다. 대신 입력의 평균이 이미 0이면 둘은 정확히 같다(10⁻¹⁶). 평균 빼기가 주는 이동 불변성을 포기해도 학습 품질이 거의 같았다는 것이 RMSNorm 논문의 실험 결과다.

## 게인 파라미터
정규화 뒤에 곱하는 γ(RMSNorm에서는 g)는 특징마다 하나씩 있는 **게인**(gain) 파라미터로, 1로 초기화한다. 정규화가 모든 특징의 크기를 강제로 1 근처로 맞추면 "이 특징은 크게, 저 특징은 작게"라는 정보가 사라지므로, 게인이 특징별 크기를 학습으로 되돌린다. 구현에 따라 젬마처럼 `(1 + w)`를 곱하고 w를 0으로 초기화하는 변형도 있는데, 처음에는 항등이라는 점에서 같은 출발이다.

## Post-LN과 Pre-LN
정규화를 잔차 연결의 어디에 두느냐가 깊은 모델의 학습 안정성을 가른다.
```text
Post-LN:  x ← LN(x + F(x))     원 트랜스포머(6편)
Pre-LN:   x ← x + F(LN(x))     GPT-2 이후 대부분
                               (맨 끝에 LN 한 번 더)
```

Post-LN에서는 잔차 경로가 매 층 LN을 통과하므로, 출력에서 입력까지 순수한 항등 경로가 없다. Pre-LN에서는 `x_L = x_0 + Σ F_l(LN(x_l))`이라 출력이 입력과 각 층 기여의 단순한 합이고, 미분하면 항등 행렬 I가 항상 남는다. 4편 LSTM의 셀 상태처럼 기울기가 덧셈 경로를 따라 모든 층에 직접 닿는다. 시옹(Xiong) 등(2020)은 Post-LN에서 초기화 직후 출력 근처 층의 기울기가 커서 학습률 워밍업 없이는 학습이 불안정하고, Pre-LN은 워밍업 없이도 잘 학습된다는 것을 분석과 실험으로 보였다. 층이 수십 개에 이르는 LLM이 Pre-LN을 택한 이유다.

Pre-LN에도 약점은 있다. 각 층이 잔차 스트림에 값을 더하기만 하므로 깊어질수록 스트림의 크기가 커지고, 뒤쪽 층의 기여가 상대적으로 작아진다. 그래서 어텐션·FFN의 출력에도 정규화를 한 번 더 거는 변형이 쓰인다. 예를 들어 젬마 3는 어텐션과 FFN의 앞과 뒤에 모두 RMSNorm을 둔다.

## QK-Norm: 어텐션 로짓 폭주 막기
어텐션 점수는 `q·k / √d_h`다. 학습 중 W_Q, W_K가 s배로 커지면 점수는 s²배가 되어, softmax가 거의 원-핫 분포로 무너지고(엔트로피 붕괴) 기울기가 불안정해진다. 큰 모델의 학습 중 손실이 갑자기 튀는 원인 중 하나로 지목된 현상이다. **QK-Norm**은 내적 직전에 q와 k를 헤드마다 정규화해서, 가중치 크기가 아무리 커져도 로짓의 범위가 정해지게 만든다.
```python
import numpy as np

def rms_norm(x, eps=1e-6):
    return x / np.sqrt((x ** 2).mean(-1, keepdims=True) + eps)

def entropy(s):                                   # 어텐션 분포의 평균 엔트로피
    p = np.exp(s - s.max(-1, keepdims=True))
    p /= p.sum(-1, keepdims=True)
    return -(p * np.log(p + 1e-30)).sum(-1).mean()

rng = np.random.default_rng(0)
n, d, dh = 128, 256, 64
x = rng.normal(size=(n, d))
Wq, Wk = rng.normal(0, d ** -0.5, (2, d, dh))
print(f"균등 분포의 엔트로피 ln {n} = {np.log(n):.2f}")
for s in [1, 4, 16]:                              # 학습 중 가중치가 커진 상황
    q, k = x @ (s * Wq), x @ (s * Wk)
    plain = q @ k.T / np.sqrt(dh)
    qkn = rms_norm(q) @ rms_norm(k).T / np.sqrt(dh)   # QK-Norm
    print(f"배율 {s:2d}: 최대 로짓 {plain.max():8.1f} 엔트로피 {entropy(plain):.2f}"
          f" │ QK-Norm {qkn.max():.1f} 엔트로피 {entropy(qkn):.2f}")
```
```text
균등 분포의 엔트로피 ln 128 = 4.85
배율  1: 최대 로짓      4.0 엔트로피 4.37 │ QK-Norm 3.3 엔트로피 4.38
배율  4: 최대 로짓     63.4 엔트로피 0.36 │ QK-Norm 3.3 엔트로피 4.38
배율 16: 최대 로짓   1014.1 엔트로피 0.02 │ QK-Norm 3.3 엔트로피 4.38
```

정규화가 없으면 가중치 배율 16에서 최대 로짓이 1,000을 넘고 엔트로피가 0.02로, 균등 분포(4.85)는커녕 사실상 토큰 하나만 보는 분포가 된다. QK-Norm을 쓰면 배율과 상관없이 같은 결과가 나온다. 정규화된 q·k는 크기가 고정되어 내적이 코사인 유사도에 비례하기 때문이다. 실제 구현은 RMSNorm에 학습 가능한 게인을 붙여서, 날카로운 어텐션이 필요하면 게인을 키워 로짓 범위를 넓힐 수 있다. 젬마 3는 젬마 2의 로짓 소프트캡을 QK-Norm으로 바꾸었고, Qwen3는 Qwen2의 QKV 편향을 없애면서 QK-Norm을 도입했다.

## 어디에 쓰이나
- 확률과 분포 8편 「정규 분포: 종 모양 곡선의 정체」: LayerNorm은 토큰마다 z 점수 `(x − μ)/σ`를 계산하는 표준화이고, RMSNorm은 그중 평균 빼기를 생략한 것이다.
- 선형대수 2편 「내적과 코사인 유사도」: QK-Norm을 거친 q·k는 크기가 고정되어 내적이 코사인 유사도에 비례하므로, 로짓이 가중치 크기와 무관하게 일정한 범위에 머문다.
- 정보 이론 1편 「정보량과 엔트로피」: 어텐션 분포의 엔트로피가 ln n에서 0 근처로 떨어지는 것이 엔트로피 붕괴이고, 실험에서 QK-Norm은 이를 4.38로 유지했다.
- 6편 「트랜스포머의 인코더와 디코더」: 원 논문 블록은 Post-LN이고, 오늘날 LLM은 같은 블록을 Pre-RMSNorm으로 바꿔 쓴다.

## 정리
- 배치 정규화는 특징마다 배치 축으로, 층 정규화는 토큰마다 특징 축으로 표준화하며, 시퀀스 모델은 후자를 쓴다.
- RMSNorm은 평균 빼기와 β를 없앤 LayerNorm으로, 배율에만 불변이고 평균 0인 입력에서는 LayerNorm과 같다.
- Pre-LN은 잔차 경로에 항등 경로를 남겨 깊은 모델을 워밍업 없이도 안정적으로 학습시킨다.
- QK-Norm은 q·k를 정규화해 가중치가 커져도 로짓이 폭주하지 않게 한다(배율 16에서 1,014 → 3.3).
