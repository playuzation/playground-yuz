# [신경망 레이어 10/11] 상태 공간 모델과 맘바

> **한 줄 요약** — 상태 공간 모델(SSM)은 연속 시간의 선형 시스템 `h′ = Ah + Bx, y = Ch`를 이산화한 선형 순환 층으로, 계수가 시간에 따라 변하지 않으면 긴 합성곱 하나와 정확히 같고, 맘바는 Δ·B·C를 입력에 따라 바꾸는 선택성을 넣는 대신 합성곱을 버리고 병렬 스캔으로 계산하며, 맘바-2는 이것을 감쇠 마스크가 붙은 리니어 어텐션과 같은 행렬 형태로 다시 썼다.

## 이 글에서 다루는 것
- 연속 상태 공간 모델과 이산화(ZOH)
- 시불변 선형 순환 = 합성곱(NumPy 확인), S4
- 선택적 SSM: 입력에 따라 변하는 Δ·B·C와 병렬 스캔
- 맘바 블록의 구성
- 맘바-2와 리니어 어텐션의 관계

## 연속 시간에서 출발한다
제어 공학과 신호 처리에서 오래 써 온 **상태 공간 모델**(state space model, SSM)은 입력 신호 x(t)가 내부 상태 h(t)를 거쳐 출력 y(t)가 되는 선형 시스템이다.
```text
h′(t) = A h(t) + B x(t)        h: 상태 (N차원)
y(t)  = C h(t)                  A: N×N,  B: N×1,  C: 1×N
```

토큰은 연속 신호가 아니라 이산 시퀀스이므로 간격 Δ로 이산화한다. 한 구간 동안 입력이 일정하다고 보고 미분 방정식을 정확히 푸는 **영차 유지**(zero-order hold, ZOH)를 쓰면 다음과 같다. 스칼라라면 `h′ = ah + bx`의 해가 `e^(aΔ)·h + (e^(aΔ) − 1)/a · b·x`인데, 뒤쪽 계수는 e^(a(Δ−τ))를 0부터 Δ까지 적분한 값이다.
```text
Ā = exp(ΔA)                    B̄ = (ΔA)⁻¹ (exp(ΔA) − I) · ΔB
h_t = Ā h_(t−1) + B̄ x_t        y_t = C h_t
```

3편의 RNN과 같은 꼴이지만 tanh가 없는 **선형** 순환이다. A의 고유값이 음수면(선형대수 8편) Ā의 고유값은 0과 1 사이라 상태가 지수적으로 감쇠하며 안정적이다. 실제 모델은 채널마다 이런 SSM을 따로 두고, A를 대각 행렬로 제한해 계산을 원소별로 만든다.

## 시불변이면 합성곱이다
Ā, B̄, C가 시간에 따라 변하지 않는(linear time-invariant, LTI) 경우, 순환을 펼치면 `y_t = Σⱼ C Āʲ B̄ · x_(t−j)`다. 커널 `K = (CB̄, CĀB̄, CĀ²B̄, …)`와 입력의 인과 합성곱(2편)이다.
```python
import numpy as np

rng = np.random.default_rng(0)
N, T, dt = 4, 64, 0.1
A = -np.array([0.5, 1.0, 2.0, 4.0])               # 대각 A (안정하려면 음수)
B, C = rng.normal(size=N), rng.normal(size=N)
x = rng.normal(size=T)

A_bar = np.exp(dt * A)                            # ZOH 이산화
B_bar = (A_bar - 1) / A * B                       # (ΔA)⁻¹(exp(ΔA) − I)·ΔB

h, y_rec = np.zeros(N), []                        # ① 순환: 한 스텝씩
for t in range(T):
    h = A_bar * h + B_bar * x[t]
    y_rec.append(C @ h)

K = np.array([C @ (A_bar**j * B_bar) for j in range(T)])  # ② 커널 C·Āʲ·B̄
y_conv = np.convolve(x, K)[:T]                    # 인과 합성곱
print(np.abs(np.array(y_rec) - y_conv).max())
print("커널 앞부분:", K[:4].round(3), "… 끝:", K[-1].round(6))
```
```text
8.326672684688674e-17
커널 앞부분: [0.073 0.057 0.045 0.035] … 끝: -0.00029
```

순환으로 한 스텝씩 계산한 출력과 커널을 한 번 만들어 합성곱한 출력이 10⁻¹⁷ 수준으로 같다. 커널이 지수적으로 줄어드는 것은 A의 감쇠 때문이다. 이 이중성이 SSM의 매력이다. 학습 때는 전체 시퀀스를 FFT 합성곱으로 병렬 계산하고, 추론 때는 RNN처럼 고정 크기 상태 하나로 토큰마다 일정한 비용에 계산한다. **S4**(Gu·Goel·Ré, 2021)는 긴 기억에 유리하도록 A를 특별한 구조로 초기화하고 커널을 효율적으로 계산하는 방법을 고안해, 길이가 수천~1만여 토큰인 장거리 의존 벤치마크에서 트랜스포머를 크게 앞섰다.

## 선택적 SSM: 입력이 계수를 정한다
LTI의 약점은 모든 입력을 같은 커널로 섞는다는 것이다. "음…", "그러니까" 같은 군더더기는 건너뛰고 중요한 단어만 기억하는 식의 판단, 즉 내용에 따라 무엇을 기억할지 고르는 일을 할 수 없다. **맘바**(Mamba, Gu·Dao, 2023)는 Δ, B, C를 입력 x_t의 함수(선형 층, Δ에는 softplus)로 만들어 이 문제를 풀었다. 이것이 **선택적 SSM**(selective SSM)이다. A는 입력과 무관한 파라미터로 남는다.

Δ의 역할은 5편 GRU의 업데이트 게이트와 같다. Δ가 크면 Ā = exp(ΔA)가 0에 가까워져 옛 상태를 지우고 현재 입력을 크게 쓰고, Δ가 작으면 Ā ≈ 1이라 현재 입력을 거의 무시하고 상태를 유지한다. 맘바 논문은 상태 크기 1, A = −1, B = 1이면 선택적 SSM이 정확히 GRU식 게이트 `h_t = (1 − g_t)h_(t−1) + g_t x_t`, `g_t = σ(Linear(x_t))`가 된다는 것을 보였다.
```python
import numpy as np

z = np.linspace(-3, 3, 7)                         # 입력에서 나온 로짓
dt = np.log1p(np.exp(z))                          # Δ = softplus(z)
A_bar = np.exp(-dt)                               # A = −1의 ZOH: Ā = e^(−Δ)
B_bar = 1 - np.exp(-dt)                           # B = 1이면 B̄ = 1 − e^(−Δ)
sig = 1 / (1 + np.exp(-z))
print(np.abs(A_bar - (1 - sig)).max(), np.abs(B_bar - sig).max())
print("Δ:", dt.round(2))
print("Ā:", A_bar.round(2))
```
```text
1.5265566588595902e-16 1.1102230246251565e-16
Δ: [0.05 0.13 0.31 0.69 1.31 2.13 3.05]
Ā: [0.95 0.88 0.73 0.5  0.27 0.12 0.05]
```

대가는 커널이 매 스텝 달라져 합성곱 하나로 바꿀 수 없다는 것이다. 그래도 순환은 여전히 상태에 대해 선형이다. `h_t = a_t·h_(t−1) + u_t`의 두 스텝을 합치는 연산 `(a₁, u₁)∘(a₂, u₂) = (a₁a₂, a₂u₁ + u₂)`는 결합 법칙을 만족하므로, 누적 합처럼 log₂T 단계의 **병렬 스캔**으로 계산할 수 있다. 맘바는 확장된 상태를 GPU의 느린 메모리(HBM)에 쓰지 않고 빠른 SRAM 안에서 스캔을 끝내는 융합 커널과, 역전파 때 상태를 다시 계산하는 방법으로 이를 실용적인 속도로 만들었다. 아래 코드는 입력마다 Δ·B·C가 다른 선택적 SSM을 세 가지 방법으로 계산한다. 맘바 구현처럼 B̄ ≈ Δ·B로 단순화하고, A는 맘바-2처럼 스칼라로 두었다.
```python
import numpy as np

softplus = lambda z: np.log1p(np.exp(z))
rng = np.random.default_rng(0)
T, D, N = 16, 8, 4                                # 길이, 채널, 상태 크기
X = rng.normal(size=(T, D))
W_dt, W_B, W_C = (rng.normal(0, D**-0.5, (D, n)) for n in (1, N, N))

dt = softplus(X @ W_dt)[:, 0]                     # Δ_t: 입력마다 다르다
B, C = X @ W_B, X @ W_C                           # B_t, C_t도 입력마다
a = np.exp(-1.0 * dt)                             # 맘바-2식 스칼라 A = −1
U = (dt[:, None] * B)[:, :, None] * X[:, None, :] # 쓰기 항 Δ_t·B_t·x_tᵀ

H, Y_rec = np.zeros((N, D)), []                   # ① 순차 순환
for t in range(T):
    H = a[t] * H + U[t]
    Y_rec.append(C[t] @ H)

def scan(a, u):                                   # ② 병렬 스캔: log₂T 단계
    a, u, step = a.copy(), u.copy(), 1
    while step < len(a):
        u[step:] = a[step:, None, None] * u[:-step] + u[step:]
        a[step:] = a[step:] * a[:-step]
        step *= 2
    return u                                      # 모든 t의 H_t
Y_scan = np.einsum("tn,tnd->td", C, scan(a, U))

ca = np.cumsum(np.log(a))                         # ③ 행렬 형태 (L ⊙ CBᵀ)X
L = np.tril(np.exp(ca[:, None] - ca[None, :]))   # L[t,s] = a_(s+1)⋯a_t
Y_mat = (L * (C @ B.T) * dt[None, :]) @ X
print(np.abs(Y_scan - Y_rec).max(), np.abs(Y_mat - Y_rec).max())

```
```text
8.881784197001252e-16 2.220446049250313e-15
```

순차 순환, 병렬 스캔, 행렬 형태가 모두 10⁻¹⁵ 이내로 같다.

## 맘바 블록
맘바는 어텐션과 FFN을 따로 두지 않고 같은 블록 하나를 정규화·잔차 연결과 함께 반복해 쌓는다.
```text
          입력 x (d)
      ┌───────┴───────┐
   선형 d→2d       선형 d→2d
      ↓               ↓
 인과 합성곱(k=4)     SiLU
      ↓               │
     SiLU             │
      ↓               │
     SSM              │
      └────── ⊙ ──────┘
              ↓
          선형 2d→d
```

입력을 두 배 폭으로 넓힌 뒤, 한 갈래는 짧은 인과 합성곱(2편)으로 바로 앞 몇 토큰을 섞고 선택적 SSM을 지나며, 다른 갈래는 SiLU를 거쳐 출력 게이트가 된다. 두 갈래를 원소별로 곱하는 구조는 8편의 SwiGLU와 같은 발상이다. 채널마다 상태 크기는 기본 N = 16이다.

## 맘바-2: SSM은 리니어 어텐션이다
맘바-2(Dao·Gu, 2024)는 A를 헤드마다 스칼라 × 단위 행렬로 제한했다. 그러면 위 코드의 ③처럼 출력 전체를 `Y = (L ⊙ C Bᵀ) X`로 쓸 수 있다(Δ는 B에 곱해 넣었다고 보자). L[t, s]는 s+1부터 t까지의 감쇠 a를 곱한 하삼각 마스크다. C를 쿼리, B를 키, X를 값으로 읽으면 소프트맥스 대신 감쇠 마스크 L을 곱한 **리니어 어텐션**(어텐션 6편)과 똑같다. 논문은 이 대응을 구조적 상태 공간 이중성(SSD)이라 불렀다.

이 관점은 계산 방법도 바꾼다. 시퀀스를 청크로 나눠 청크 안에서는 행렬 곱(텐서 코어)으로, 청크 사이에서는 상태를 넘기는 순환으로 계산해서, 맘바보다 훨씬 큰 상태를 빠르게 다룬다. 또 상태 갱신 `H_t = a_t·H_(t−1) + B_t x_tᵀ`는 리니어 어텐션의 상태 `S_t = S_(t−1) + v_t k_tᵀ`에 감쇠 게이트를 붙인 것이다. 다음 글의 Gated DeltaNet은 여기에 델타 규칙을 더해, 이 고정 크기 상태를 더 정확한 기억 장치로 만든다.

## 어디에 쓰이나
- 미적분 5편 「적분: 넓이와 누적」: ZOH의 B̄는 구간 안에서 입력이 상태에 기여하는 정도 e^(a(Δ−τ))를 0부터 Δ까지 적분한 값이다.
- 선형대수 8편 「고유값과 고유벡터」: A를 대각화하면 Āʲ는 고유값의 거듭제곱이고, 고유값이 음수여야 커널이 감쇠해 안정적이다.
- 어텐션 6편 「리니어 어텐션: 소프트맥스 없이 순서를 바꾸기」: 맘바-2의 행렬 형태 `(L ⊙ CBᵀ)X`는 감쇠 마스크가 붙은 인과 리니어 어텐션이다.
- 5편 「GRU: 더 단순한 게이트 순환 층」: 맘바의 Δ는 업데이트 게이트 역할을 하며, 상태 크기 1에서는 GRU식 보간과 정확히 같다.

## 정리
- SSM은 `h′ = Ah + Bx, y = Ch`를 ZOH로 이산화한 선형 순환이며, 시불변이면 커널 `CĀʲB̄`의 합성곱과 정확히 같다.
- 맘바는 Δ·B·C를 입력에 따라 바꿔 무엇을 기억할지 고르게 했고, 합성곱 대신 결합 법칙을 이용한 병렬 스캔으로 계산한다.
- 맘바 블록은 확장 → 짧은 합성곱 → SiLU → 선택적 SSM에 SiLU 게이트를 곱하는 구조다.
- 맘바-2는 스칼라 A로 SSM을 감쇠 마스크가 붙은 리니어 어텐션 `(L ⊙ CBᵀ)X`로 다시 썼다.
