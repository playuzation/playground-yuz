# [신경망 레이어 3/11] 순환 층(RNN): 상태를 이어 가는 레이어

> **한 줄 요약** — 순환 층은 같은 가중치로 `h_t = tanh(x_t W_x + h_(t−1) W_h + b)`를 반복해 지금까지 본 시퀀스를 고정 크기 상태 하나에 요약하지만, 역전파 때 W_h가 시간 스텝마다 곱해져서 기울기가 지수적으로 사라지거나 폭발하고, 스텝을 순서대로만 계산할 수 있어 병렬화가 어렵다.

## 이 글에서 다루는 것
- 순환 층의 식과 시간 방향으로 펼친 모습
- 시간 역전파(BPTT)
- 기울기 소실·폭발이 W_h의 크기에서 나오는 이유와 NumPy 실험
- 순차 계산이라는 구조적 한계와 그 유산

## 상태를 들고 다니는 층
1편의 선형 층과 2편의 합성곱 층은 입력 길이가 정해져 있거나 창 밖을 보지 못한다. 문장처럼 길이가 제각각인 시퀀스를 처음부터 끝까지 읽으려면 "지금까지 읽은 내용"을 들고 다닐 장소가 필요하다. **순환 층**(recurrent layer, RNN)은 그것을 은닉 상태(hidden state) 벡터 h로 둔다.
```text
h_t = tanh(x_t W_x + h_(t−1) W_h + b)        h₀ = 0
y_t = h_t W_y                                 (필요하면 출력 층)
```

매 스텝 새 입력 x_t와 직전 상태 h_(t−1)을 각각 선형 변환해 더하고 tanh로 눌러 새 상태를 만든다. 핵심은 모든 스텝이 **같은** W_x, W_h, b를 쓴다는 것이다. 2편의 합성곱이 공간 방향으로 가중치를 공유했다면, 순환 층은 시간 방향으로 공유한다. 그래서 시퀀스가 아무리 길어도 파라미터 수는 `d_in·d_h + d_h² + d_h`로 고정이다. d_in = d_h = 256이면 131,328개다.

이 반복을 시간 방향으로 펼치면 층이 T개인 깊은 신경망이 되는데, 모든 층이 가중치를 공유한다.
```text
     x₁      x₂      x₃
     ↓       ↓       ↓
h₀ →[셀]→ h₁ →[셀]→ h₂ →[셀]→ h₃
        (모든 셀이 같은 W_x, W_h, b)
```

## 시간 역전파(BPTT)
펼친 그래프에서 보통의 역전파를 하는 것을 **시간 역전파**(backpropagation through time, BPTT)라 한다. 미적분 8편의 벡터-야코비 곱을 한 스텝에 적용하면, 행벡터 표기에서 상태에 대한 기울기는 이렇게 한 스텝씩 거꾸로 전해진다.
```text
∂L/∂h_(t−1) = (∂L/∂h_t ⊙ (1 − h_t²)) W_hᵀ
              (+ 그 스텝의 출력에서 오는 기울기)
∂L/∂W_h     = Σ_t h_(t−1)ᵀ (∂L/∂h_t ⊙ (1 − h_t²))
```

W_h의 기울기는 모든 스텝의 기여를 더한 것이다. 가중치를 공유하니 각 스텝에서 구한 기울기를 합치는 것인데, 미적분 8편에서 본 "한 값이 여러 곳에 쓰이면 기울기를 더한다"는 규칙 그대로다. 문제는 첫 줄이다. k 스텝 전까지 기울기를 보내려면 `diag(1 − h²) · W_hᵀ`를 k번 곱해야 한다.

## 기울기 소실과 폭발
tanh의 미분 1 − h²은 1 이하이므로, 한 스텝마다 기울기의 크기는 대략 W_h의 특이값(선형대수 10편)만큼 늘거나 줄고 tanh가 거기서 조금 더 깎는다. 같은 배율이 k번 곱해지니 결과는 배율의 k제곱이다. 배율이 1보다 작으면 지수적으로 사라지고(**기울기 소실**), 1보다 충분히 크면 지수적으로 폭발한다(**기울기 폭발**). 직교 행렬에 배율을 곱해 W_h의 특이값을 모두 같은 값(scale)으로 맞추고 실험해 보자.
```python
import numpy as np

rng = np.random.default_rng(0)
d_in, d_h, T = 16, 64, 50
xs = rng.normal(size=(T, d_in))
W_x = rng.normal(0, 0.3 / np.sqrt(d_in), (d_in, d_h))
Q = np.linalg.qr(rng.normal(size=(d_h, d_h)))[0]  # 직교 행렬: 모든 특이값 1

for scale in [0.5, 1.0, 1.5, 3.0]:
    W_h = scale * Q                               # 특이값이 모두 scale
    h, hs = np.zeros(d_h), []
    for x in xs:                                  # 순전파: 상태를 이어 간다
        h = np.tanh(x @ W_x + h @ W_h)
        hs.append(h)
    g = np.ones(d_h) / np.sqrt(d_h)               # ∂L/∂h_T (크기 1)
    norms = {}
    for back, h in enumerate(reversed(hs), start=1):
        g = (g * (1 - h**2)) @ W_h.T              # 한 스텝 거꾸로: BPTT
        if back in (1, 10, 25, 50):
            norms[back] = f"{np.linalg.norm(g):.1e}"
    print(f"scale={scale}", norms)
```
```text
scale=0.5 {1: '4.7e-01', 10: '3.9e-04', 25: '3.1e-09', 50: '1.1e-17'}
scale=1.0 {1: '8.6e-01', 10: '1.6e-01', 25: '1.2e-02', 50: '2.6e-04'}
scale=1.5 {1: '1.0e+00', 10: '8.6e-01', 25: '1.7e+00', 50: '4.0e+00'}
scale=3.0 {1: '1.3e+00', 10: '1.3e+01', 25: '1.7e+03', 50: '2.6e+06'}
```

출력의 키는 "몇 스텝 전 상태에 대한 기울기인가"다. scale 0.5에서는 10스텝 전에 이미 10⁻⁴, 50스텝 전에는 10⁻¹⁷로 사실상 0이다. 50토큰 앞의 단어가 지금의 손실에 아무 신호도 주지 못하니, 그런 장거리 관계는 배울 수 없다. 특이값이 정확히 1이어도 tanh의 미분이 매번 조금씩 깎아서 50스텝이면 10⁻⁴로 줄어든다. scale 1.5에서는 커지는 몫과 tanh가 깎는 몫이 비슷해 완만하게 늘고, scale 3.0에서는 50스텝 만에 10⁶배로 폭발한다. 기울기 폭발은 기울기의 노름이 기준을 넘으면 잘라 내는 **기울기 클리핑**(gradient clipping)으로 비교적 쉽게 막지만, 소실은 신호 자체가 없어지는 것이라 학습 요령으로는 고치기 어렵다. 이 문제는 1990년대 초에 이미 분석되었고(호흐라이터의 1991년 학위 논문, 벤지오 등 1994년), 구조를 바꿔 해결한 것이 다음 글의 LSTM이다.

## 순서대로만 계산할 수 있다
h_t를 계산하려면 h_(t−1)이 먼저 있어야 한다. 그래서 길이 T인 시퀀스는 아무리 GPU가 크더라도 T번의 순차 단계를 거쳐야 하고, 한 스텝의 계산은 (배치, d_h) × (d_h, d_h) 정도의 작은 행렬 곱이라 GPU를 채우지 못한다. 병렬화할 수 있는 축은 배치뿐이다. 트랜스포머가 학습 때 모든 토큰을 한 번에 처리하며 RNN을 밀어낸 가장 큰 이유가 이것이다(6편).

대신 RNN에는 트랜스포머가 갖지 못한 장점이 있다. 추론할 때 토큰 하나를 처리하는 비용과 메모리가 문맥 길이와 상관없이 일정하다. 들고 다니는 것은 크기 d_h인 상태 하나뿐이고, 트랜스포머처럼 지난 토큰 전부의 KV 캐시를 쌓지 않는다. 최근의 상태 공간 모델(10편)과 Gated DeltaNet(11편)은 순환을 선형으로 만들어 학습 때는 병렬로 계산하고 추론 때는 RNN처럼 고정 크기 상태로 도는, 두 장점을 모두 잡는 방향이다.

- 선형대수 10편 「특이값 분해(SVD)」: 기울기가 스텝마다 커지거나 작아지는 배율은 W_h의 특이값이 정하며, 실험에서는 특이값을 0.5~3으로 맞춰 소실과 폭발을 재현했다.
- AI 기초 1편 「딥러닝: 특징까지 스스로 배우는 머신러닝」: tanh 활성화와 경사 하강법이 그대로 쓰이지만, 미분 1 − h²이 스텝마다 곱해진다는 점이 순환 구조에서 새로 생기는 문제다.
- 4편 「LSTM: 게이트로 기억을 관리하기」: 곱셈이 반복되는 경로 옆에 덧셈으로 갱신되는 셀 상태를 두어 기울기 소실을 줄인다.

## 정리
- 순환 층은 같은 가중치로 `h_t = tanh(x_t W_x + h_(t−1) W_h + b)`를 반복하며, 파라미터 수는 시퀀스 길이와 무관하다.
- BPTT는 펼친 그래프의 역전파이고, k 스텝 전으로 가는 기울기에는 `diag(1 − h²)·W_hᵀ`가 k번 곱해진다.
- W_h의 특이값이 1보다 작으면 기울기가 지수적으로 사라지고(50스텝에 10⁻¹⁷), 크면 폭발한다(10⁶배).
- 스텝을 순서대로만 계산할 수 있어 학습 병렬화가 어렵지만, 추론 비용이 문맥 길이와 무관하다는 장점은 최신 순환형 모델로 이어진다.
