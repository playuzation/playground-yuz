# [추상 데이터 타입 심화 13/21] k-d 트리: 다차원 범위 검색과 최근접 이웃

> **한 줄 요약** — k-d 트리는 깊이마다 축을 바꿔 가며 중앙값에서 점들을 반으로 가르는 이진 트리라서, 2차원 직사각형 범위 검색을 O(√n + k)에, 최근접 이웃 검색을 "가르는 면이 지금 최선보다 멀면 건너뛰기"로 낮은 차원에서는 몇십 개 노드 방문으로 끝내지만, 차원이 log₂ n에 가까워지면 거의 모든 노드를 보게 된다.

## 이 글에서 다루는 것
- 다차원 점 집합 ADT: 직사각형 범위 검색과 최근접 이웃
- 축을 번갈아 중앙값으로 나누는 구성과 두 검색의 가지치기
- 범위 검색 방문 노드가 √n에 비례함을 실험으로 확인
- 차원의 저주 실험, 쿼드트리·BVH와 비교

## 예제 문제: 지도 위의 가게
가게 n곳의 좌표가 있다. ① "경도 x₁~x₂, 위도 y₁~y₂ 안의 가게를 모두" ② "지금 위치에서 가장 가까운 가게"를 반복해서 묻는다. 전부 훑으면 질의마다 O(n)이다. 1차원이면 정렬해 두고 이분 탐색하면 되지만(7~12편의 정렬 맵), 2차원에서 x로 정렬하면 y 조건을 거를 수 없고 y로 정렬하면 x 조건을 거를 수 없다. 축이 여럿인 점 집합에 맞는 탐색 트리가 필요하다.

## 아이디어: 축을 번갈아 반으로
벤틀리(Jon Bentley)가 1975년 발표한 **k-d 트리**(k-dimensional tree)는 이진 탐색 트리를 다차원으로 넓힌다. 뿌리에서는 x좌표의 중앙값인 점으로 왼쪽(x가 작은 쪽)과 오른쪽을 가르고, 그 아래에서는 y좌표의 중앙값으로, 다시 x로… 깊이 d에서 축 d mod k를 쓴다. 매번 중앙값에서 가르므로 높이가 ⌈log₂(n + 1)⌉이다. 노드 하나는 평면을 축에 나란한 직선으로 자르고, 노드마다 자기 몫의 직사각형 **칸**을 맡는다. 아래 그림에서 x·y는 그 노드가 가르는 축이다.
```text
        (7,2) x
       /       \
   (5,4) y   (9,6) y
   /    \      /
(2,3) (4,7) (8,1)
```
여기서는 노드를 따로 만들지 않고 점 배열을 제자리에서 정렬해, 구간 `pts[lo:hi]`의 가운데 점을 그 구간의 뿌리로 삼는다. 구성은 층마다 정렬하므로 O(n log² n)이다(선형 시간 중앙값 선택을 쓰면 O(n log n)).

**범위 검색**은 질의 상자가 가르는 직선의 왼쪽에 걸치면 왼쪽으로, 오른쪽에 걸치면 오른쪽으로 내려간다. 그러면 칸이 질의 상자와 겹치는 노드만 방문한다. 2차원에서 질의 상자의 변 하나가 가로지르는 칸은 O(√n)개라서, 전체 비용은 O(√n + k)다(k는 답의 개수). 직선이 한 노드의 칸을 지나면 두 층 아래 손자 넷 중 둘의 칸만 지나므로, 방문 수가 T(n) = 2·T(n/4) + O(1) = O(√n)을 따르기 때문이다.

**최근접 이웃**은 질의점이 있는 쪽 자식부터 내려가 지금까지의 최선 거리를 얻고, 돌아오면서 "가르는 직선까지의 거리"가 최선 거리보다 짧을 때만 반대쪽을 본다. 직선 너머의 점은 적어도 그 거리만큼 멀기 때문이다.
```python
import random, math

class KDTree:                            # 노드 = pts[lo:hi]의 가운데 점
    def __init__(self, pts):
        self.pts, self.k = list(pts), len(pts[0])
        self._build(0, len(self.pts), 0)

    def _build(self, lo, hi, d):         # 축 d % k로 정렬해 중앙값에서 가른다
        if hi - lo <= 1: return
        a = d % self.k
        self.pts[lo:hi] = sorted(self.pts[lo:hi], key=lambda p: p[a])
        m = (lo + hi) // 2
        self._build(lo, m, d + 1); self._build(m + 1, hi, d + 1)

    def range(self, qlo, qhi):           # 상자 [qlo, qhi] 안의 점, 방문 수
        out, vis = [], [0]
        def go(lo, hi, d):
            if lo >= hi: return
            vis[0] += 1
            m = (lo + hi) // 2; p = self.pts[m]; a = d % self.k
            if all(l <= x <= h for l, x, h in zip(qlo, p, qhi)): out.append(p)
            if qlo[a] <= p[a]: go(lo, m, d + 1)      # 왼쪽은 p[a] 이하
            if p[a] <= qhi[a]: go(m + 1, hi, d + 1)  # 오른쪽은 p[a] 이상
        go(0, len(self.pts), 0)
        return out, vis[0]

    def nearest(self, q):                # (거리², 점), 방문 수
        best, vis = [math.inf, None], [0]
        def go(lo, hi, d):
            if lo >= hi: return
            vis[0] += 1
            m = (lo + hi) // 2; p = self.pts[m]; a = d % self.k
            dist = sum((x - y) ** 2 for x, y in zip(p, q))
            if dist < best[0]: best[:] = [dist, p]
            diff = q[a] - p[a]
            near, far = ((lo, m), (m + 1, hi)) if diff < 0 else \
                        ((m + 1, hi), (lo, m))
            go(*near, d + 1)             # 질의점 쪽부터
            if diff * diff < best[0]:    # 가르는 면이 최선보다 가까우면
                go(*far, d + 1)
        go(0, len(self.pts), 0)
        return tuple(best), vis[0]

pts = [(2, 3), (5, 4), (9, 6), (4, 7), (8, 1), (7, 2)]
kd = KDTree(pts)
print(kd.pts[3], kd.pts[1], kd.pts[5])   # 뿌리와 두 자식
print(kd.range((3, 1), (8, 5)))
print(kd.nearest((9, 2)))
```
```text
(7, 2) (5, 4) (9, 6)
([(7, 2), (5, 4), (8, 1)], 6)
((2, (8, 1)), 3)
```
위키백과의 유명한 예제 6점으로 지으면 뿌리는 x 중앙값 (7, 2), 자식은 각각 y 중앙값인 (5, 4)와 (9, 6)이다. 상자 [3, 8] × [1, 5] 안의 점은 셋이고, (9, 2)에서 가장 가까운 점은 거리² 2인 (8, 1)이다. 6점 중 3개만 보고 답을 냈다.

## 무작위 대조 검사
앞 코드에 이어서, 1~3차원 점을 좌표 0~9의 정수로 뽑아 같은 좌표가 자주 겹치게 하고, 범위 검색 결과와 최근접 거리를 전수 검색과 비교한다. 같은 거리의 점이 여럿일 수 있으므로 최근접은 점이 아니라 거리로 비교한다.
```python
rng, ok = random.Random(13), 0
for _ in range(500):                     # 작은 정수 좌표로 겹치는 점을 일부러
    k, n = rng.choice([1, 2, 3]), rng.randint(1, 60)
    pts = [tuple(rng.randrange(10) for _ in range(k)) for _ in range(n)]
    kd = KDTree(pts)
    lo = [rng.randrange(10) for _ in range(k)]
    hi = [l + rng.randrange(5) for l in lo]
    want = sorted(p for p in pts if all(a <= x <= b
                                        for a, x, b in zip(lo, p, hi)))
    q = tuple(rng.uniform(-1, 11) for _ in range(k))
    best = min(sum((x - y) ** 2 for x, y in zip(p, q)) for p in pts)
    ok += sorted(kd.range(lo, hi)[0]) == want and kd.nearest(q)[0][0] == best
print(f"무작위 500개 비교: {ok}개 일치")
```
```text
무작위 500개 비교: 500개 일치
```

## 실험 1: 범위 검색은 √n
앞 코드에 이어서, 단위 정사각형에 고르게 뿌린 점에 대해 세로선 x = c를 질의한다. 답은 거의 없으므로 방문 수가 곧 "직선이 가로지르는 칸 수"다.
```python
rng = random.Random(7)
for n in (4 ** 6, 4 ** 7, 4 ** 8):       # 세로선 x = c 위의 점 찾기
    kd = KDTree([(rng.random(), rng.random()) for _ in range(n)])
    v = sum(kd.range((c, 0), (c, 1))[1]
            for c in (rng.random() for _ in range(100))) / 100
    print(f"n = {n}: 방문 {v:.0f}개, √n = {math.isqrt(n)}, "
          f"방문/√n = {v / math.sqrt(n):.2f}")
```
```text
n = 4096: 방문 126개, √n = 64, 방문/√n = 1.97
n = 16384: 방문 254개, √n = 128, 방문/√n = 1.98
n = 65536: 방문 510개, √n = 256, 방문/√n = 1.99
```
n이 4배가 될 때마다 방문 수가 2배가 되어 방문/√n이 2.0 근처에서 일정하다. 앞의 점화식 T(n) = 2·T(n/4) + O(1)이 그대로 보인다. k차원에서는 같은 논리로 O(n^(1 − 1/k) + k)다.

## 실험 2: 차원의 저주
앞 코드에 이어서, 점 8,192개를 2·4·8·16차원 단위 초입방체에 뿌리고 무작위 질의점 50개의 최근접 이웃을 찾으며 방문 노드를 센다.
```python
n = 1 << 13
for k in (2, 4, 8, 16):                  # 차원을 키우며 최근접 이웃
    kd = KDTree([tuple(rng.random() for _ in range(k)) for _ in range(n)])
    v = sum(kd.nearest(tuple(rng.random() for _ in range(k)))[1]
            for _ in range(50)) / 50
    print(f"{k}차원: 방문 {v:.0f}개 ({v / n:.1%})")
```
```text
2차원: 방문 20개 (0.2%)
4차원: 방문 52개 (0.6%)
8차원: 방문 659개 (8.0%)
16차원: 방문 8038개 (98.1%)
```
2차원에서는 노드 20개(0.2%)만 보고 끝나지만, 16차원에서는 98%를 본다. 이유는 둘이다. 첫째, 고차원에서는 가장 가까운 점까지의 거리와 가르는 면까지의 거리가 비슷해져 가지치기 조건이 거의 늘 참이 된다. 둘째, 높이가 log₂ 8192 = 13인데 축이 16개라 한 경로에서 한 번도 갈리지 않는 축이 생긴다. 경험칙으로 k-d 트리는 n이 2ᵏ보다 훨씬 클 때만 쓸모가 있다. 고차원 임베딩 검색에서 근사 최근접 이웃(ANN) 기법을 쓰는 이유다.

## 쿼드트리·BVH와 비교
게임 자원 관리 8편 「공간 분할 2: 쿼드트리와 BVH」의 두 구조와 견주면 다음과 같다.
- 쿼드트리는 칸의 **가운데**에서 공간을 넷(k차원이면 2ᵏ개)으로 자른다. 점이 몰리면 깊어지지만 삽입·삭제가 쉽다. 차원이 크면 자식 수가 폭발한다.
- k-d 트리는 **점의 중앙값**에서 한 축씩 둘로 자른다. 높이가 log₂ n으로 보장되고 어느 차원에서나 이진이지만, 정적 구조다.
- BVH는 공간이 아니라 **물체**를 묶어 상자를 씌운다. 크기가 있는 물체와 움직이는 물체에 맞고, 상자끼리 겹쳐도 된다.

## 자주 하는 실수와 변형
- 축은 깊이로 정해야 한다. 중앙값과 같은 좌표가 양쪽에 다 있을 수 있으니 범위 검색의 두 조건에 모두 등호를 넣는다(`<=`). 하나라도 빠지면 경계의 점을 놓친다.
- 최근접 가지치기는 거리의 제곱끼리 비교한다. 한쪽만 제곱하는 실수가 흔하다.
- 삽입·삭제: 그대로 넣으면 균형이 깨지고 회전도 할 수 없다(축 규칙이 깨진다). 11편 「희생양 트리와 무게 균형 트리: 회전 대신 다시 짓기」처럼 기울어진 서브트리를 다시 짓는다.
- 변형: 가장 긴 변을 가르는 축 선택, 칸의 가운데에서 가르다 빈 쪽이 생기면 밀어내는 sliding midpoint 규칙, k개 최근접 이웃(최선 거리 대신 크기 k인 최대 힙).

## 복잡도
| 연산 | k-d 트리 | 전수 검색 |
|---|---|---|
| 구성 | O(n log n) | 없음 |
| 2차원 범위 검색 | O(√n + k) | O(n) |
| k차원 범위 검색 | O(n^(1−1/k) + k) | O(n) |
| 최근접 이웃 | 저차원 평균 O(log n), 최악 O(n) | O(n) |

- 근거: 높이가 log₂ n이고, 범위 검색은 경계가 가로지르는 칸 수가 2·T(n/4) 점화식을 따른다. 최근접 이웃은 점 분포와 차원에 크게 좌우된다. 공간 O(n).

## 어디에 쓰이나
- 게임 자원 관리 8편 「공간 분할 2: 쿼드트리와 BVH」: 정적인 점(지형 위 고정 물체, 경로 노드)의 범위·근접 질의에는 k-d 트리, 움직이는 물체에는 BVH나 격자를 쓴다.
- SciPy: `scipy.spatial.KDTree`가 최근접 이웃 질의용 k-d 트리이고, 문서에 "20차원이면 이미 큰 차원이라 전수 검색보다 크게 빠르지 않다"고 경고한다. 실험 2와 같은 이야기다.
- 11편 「희생양 트리와 무게 균형 트리: 회전 대신 다시 짓기」: 동적 k-d 트리는 회전 대신 부분 재구성으로 균형을 지킨다.

## 정리
- k-d 트리는 축을 번갈아 중앙값에서 가르는 이진 트리이고, 노드마다 직사각형 칸을 맡는다.
- 범위 검색은 질의와 겹치는 칸만 방문해 2차원 O(√n + k)이다. 실험에서 방문/√n이 2.0으로 일정했다.
- 최근접 이웃은 가르는 면까지의 거리로 가지를 치며, 2차원에서는 노드 20개, 16차원에서는 98%를 봤다.
- 저차원·정적 점 집합에 강하고, 고차원에서는 근사 기법, 움직이는 물체에는 BVH가 낫다.
