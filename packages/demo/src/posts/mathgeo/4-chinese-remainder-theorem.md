# [수학·기하 알고리즘 4/12] 중국인의 나머지 정리

> **한 줄 요약** — 쌍마다 서로소인 법들에 대한 나머지가 주어지면 법들의 곱 M 안에서 답이 정확히 하나 있다는 중국인의 나머지 정리(CRT)는, 모듈러 역원으로 답을 직접 조립하거나 식을 두 개씩 합쳐 구하며, 법이 서로소가 아니어도 gcd 조건만 맞으면 lcm 안에서 답이 하나다.

## 이 글에서 다루는 것
- 손자산경의 문제와 "하나씩 맞춰 가기" 완전 탐색
- 서로소 법: 해가 하나뿐인 이유와 구성적 풀이
- 서로소가 아닌 법: 두 식씩 합치기와 해가 없는 경우
- RSA 복호화를 CRT로 빠르게 하기, 무작위 대조 검사

## 예제 문제: 3, 5, 7로 나눈 나머지
"어떤 수를 3으로 나누면 2가 남고, 5로 나누면 3이 남고, 7로 나누면 2가 남는다. 이 수는?" 3~5세기 무렵 중국의 『손자산경(孫子算經)』에 실린 문제로, 이 정리 이름의 유래다. 일반적인 풀이법은 1247년 진구소(秦九韶)의 『수서구장(數書九章)』에 정리되었다. 게임으로 바꾸면 "주기가 3, 5, 7턴인 세 이벤트가 각각 2, 3, 2턴째에 처음 일어났을 때 세 이벤트가 같은 턴에 겹치는 때는?" 같은 문제다.

가장 단순한 방법은 x = 0, 1, 2, …를 하나씩 넣어 보는 것으로, 답이 법의 곱 M = 105 안에 있다면 O(M)이다. 조금 나은 방법은 식을 하나씩 맞춰 가는 것이다. 첫 식을 만족하는 수 2, 5, 8, …(3씩 증가) 중에서 5로 나눈 나머지가 3인 수를 찾으면 8이고, 이제 8, 23, 38, …(15씩 증가) 중에서 7로 나눈 나머지가 2인 수를 찾으면 23이다. 단계마다 많아야 mᵢ번 시도하므로 O(m₁ + m₂ + …)이지만, 법이 10⁹ 근처면 여전히 느리다.

## 정리: 서로소 법에서는 답이 하나
법 m₁, …, mₖ가 쌍마다 서로소이고 M = m₁ × … × mₖ이면, 연립 합동식 `x ≡ rᵢ (mod mᵢ)`의 해는 0 이상 M 미만에 **정확히 하나** 있다.
- **많아야 하나**: x와 y가 둘 다 해라면 x − y는 모든 mᵢ로 나누어떨어진다. 법들이 서로소이므로 x − y는 그 곱 M으로 나누어떨어지고, 0 ≤ x, y < M이면 x = y다.
- **적어도 하나**: 직접 만든다. `Mᵢ = M / mᵢ`는 mᵢ를 뺀 나머지 법들의 곱이라 mᵢ와 서로소이고, 1편의 모듈러 역원 `yᵢ = Mᵢ⁻¹ mod mᵢ`가 있다. 그러면 `eᵢ = Mᵢ·yᵢ`는 법 mᵢ로는 1, 다른 모든 법으로는 0이다(Mᵢ가 그 법의 배수). 이런 "스위치"들을 rᵢ배 해서 더한다.
```text
x ≡ r₁e₁ + r₂e₂ + … + rₖeₖ (mod M)
eᵢ ≡ 1 (mod mᵢ)
eᵢ ≡ 0 (mod mⱼ),  j ≠ i
```
사실 유일성만으로도 존재가 따라 나온다. 0~M − 1의 수 M개는 모두 서로 다른 나머지 조합 (r₁, …, rₖ)로 가는데 조합도 M가지뿐이므로, 모든 조합이 정확히 한 번씩 나온다. 손자산경의 수에서는 e₁ = 70, e₂ = 21, e₃ = 15이고 `2·70 + 3·21 + 2·15 = 233 ≡ 23 (mod 105)`이다.
```python
from math import prod

def crt_coprime(rs, ms):
    """법들이 쌍마다 서로소일 때 x mod M (M = 법의 곱)."""
    M = prod(ms)
    x = 0
    for r, m in zip(rs, ms):
        Mi = M // m                     # 나머지 법들의 곱
        yi = pow(Mi, -1, m)             # Mi·yi ≡ 1 (mod m)
        x += r * Mi * yi                # m에서만 r, 다른 법에선 0
    return x % M, M

def crt_sieve(rs, ms):
    """x = r1, r1 + m1, …를 차례로 시도해 식을 하나씩 맞춘다."""
    x, step, tries = rs[0], ms[0], 0
    for r, m in zip(rs[1:], ms[1:]):
        while x % m != r:
            x += step
            tries += 1
        step *= m
    return x, step, tries

print(crt_coprime([2, 3, 2], [3, 5, 7]))
print(crt_sieve([2, 3, 2], [3, 5, 7]))
ms = [10007, 10009, 10037]
rs = [1234, 5678, 9012]
print(crt_coprime(rs, ms)[0], crt_sieve(rs, ms))
```
```text
(23, 105)
(23, 105, 3)
598534302168 (598534302168, 1005306552331, 13762)
```
법이 10⁴ 근처인 세 식에서 하나씩 맞추기는 13,762번을 시도했지만, 구성적 풀이는 역원 세 번으로 끝난다. 역원은 1편처럼 O(log m)이므로 전체가 O(k log M)이다.

## 서로소가 아닌 법: 두 식씩 합치기
`x ≡ 3 (mod 4)`, `x ≡ 5 (mod 6)`처럼 법이 서로소가 아니면 위 공식의 역원이 없다. 이때는 식을 두 개씩 합친다. 지금까지 합친 결과가 `x ≡ a (mod m)`이고 새 식이 `x ≡ r (mod n)`이라 하자. 첫 식의 해는 `x = a + m·t`꼴이므로, 이것을 둘째 식에 넣으면 t에 대한 합동식이 된다.
```text
a + m·t ≡ r (mod n)
m·t ≡ r − a (mod n)
해 조건: g = gcd(m, n) ∣ (r − a)
t ≡ (r − a)/g · p (mod n/g)
(p는 m·p + n·q = g의 계수)
```
g가 r − a를 나누지 않으면 두 식은 g로 나눈 나머지에서 서로 모순이라 해가 없다. 예를 들어 `x ≡ 3 (mod 4)`는 x가 홀수라는 뜻이고 `x ≡ 4 (mod 6)`은 짝수라는 뜻이다. 해가 있으면 합친 법은 `lcm(m, n)`이고 그 안에서 해가 하나다. 1편의 일차 부정방정식 풀이와 같은 계산이다. 모든 x를 lcm 미만에서 시도하는 완전 탐색과 대조한다.
```python
import random
from math import lcm

def ext_gcd(a, b):
    if b == 0:
        return a, 1, 0
    g, x1, y1 = ext_gcd(b, a % b)
    return g, y1, x1 - (a // b) * y1

def crt(rs, ms):
    """x ≡ rs[i] (mod ms[i])를 모두 만족하는 (x, lcm), 없으면 None."""
    x, m = 0, 1                         # 처음엔 '모든 정수' = x ≡ 0 (mod 1)
    for r, n in zip(rs, ms):
        g, p, _ = ext_gcd(m, n)         # m·p + n·q = g
        if (r - x) % g:
            return None                 # 두 식이 g로 나눈 나머지에서 충돌
        t = (r - x) // g * p % (n // g)
        x += m * t                      # 이제 x ≡ r (mod n)도 만족
        m = m // g * n                  # lcm(m, n)
        x %= m
    return x, m

def crt_brute(rs, ms):
    L = lcm(*ms)
    for x in range(L):
        if all(x % m == r for r, m in zip(rs, ms)):
            return x, L
    return None

print(crt([2, 3, 2], [3, 5, 7]), crt([3, 5], [4, 6]), crt([3, 4], [4, 6]))
rng = random.Random(8)
found = 0
for _ in range(500):
    k = rng.randint(1, 4)
    ms = [rng.randint(1, 30) for _ in range(k)]
    rs = [rng.randrange(m) for m in ms]
    ans = crt(rs, ms)
    assert ans == crt_brute(rs, ms), (rs, ms)
    found += ans is not None
print("무작위 500개 비교: 모두 일치", f"(해 있음 {found}개)")
```
```text
(23, 105) (11, 12) None
무작위 500개 비교: 모두 일치 (해 있음 305개)
```
500개 중 195개는 해가 없는 경우였고, 완전 탐색도 똑같이 "없음"이라고 답했다. 법이 서로소이든 아니든 이 함수 하나로 처리되므로 실전에서는 이 형태를 쓰는 것이 안전하다.

## 응용: RSA 복호화를 CRT로
RSA의 복호화 `cᵈ mod n`(n = pq)은 수천 비트 지수의 거듭제곱이다. 개인 키를 가진 쪽은 p와 q를 알므로, 법 p와 법 q에서 따로 계산한 뒤 CRT로 합칠 수 있다. 법의 크기가 절반이 되고 지수도 페르마 소정리로 `d mod (p − 1)`까지 줄어든다. PKCS #1 표준의 개인 키 형식에 n, d 외에 p, q와 dP, dQ, qInv가 들어 있는 이유가 이것이다. 교과서용 작은 키로 3,233개의 모든 암호문에서 직접 계산과 비교한다.
```python
p, q, e = 61, 53, 17                    # 교과서용 작은 RSA 키
n, d = p * q, pow(e, -1, (p - 1) * (q - 1))
dP, dQ, qInv = d % (p - 1), d % (q - 1), pow(q, -1, p)

def decrypt_crt(c):
    m1 = pow(c, dP, p)                  # 법 p에서 (지수도 p − 1로 줄임)
    m2 = pow(c, dQ, q)                  # 법 q에서
    h = qInv * (m1 - m2) % p            # 두 결과를 CRT로 합친다
    return m2 + h * q

c = pow(65, e, n)
print(n, d, (dP, dQ, qInv), c, pow(c, d, n), decrypt_crt(c))
print("모든 c 비교:", all(decrypt_crt(c) == pow(c, d, n) for c in range(n)))
```
```text
3233 2753 (53, 49, 38) 2790 65 65
모든 c 비교: True
```
`m2 + h·q`는 법 q로 m2이고, 법 p로는 `m2 + (m1 − m2) = m1`이다. 두 식을 합치는 위의 방법을 식 두 개에 맞게 줄여 쓴 것이다.

## 자주 하는 실수와 변형
- **서로소 가정**: `pow(Mi, -1, m)`은 법이 서로소가 아니면 `ValueError`를 낸다. 입력이 서로소라는 보장이 없으면 두 식씩 합치는 형태를 쓴다.
- **나머지 정규화**: 입력의 rᵢ가 음수이거나 mᵢ 이상일 수 있다. 미리 `r % m`으로 바꾼다.
- **가장 작은 양의 해**: 답이 0으로 나오면 문제에 따라 M(또는 lcm)을 답해야 한다.
- **중간 값 크기**: C++·자바에서는 `m·t`나 lcm이 64비트를 넘을 수 있다. 파이썬은 걱정 없지만 다른 언어로 옮길 때 주의한다.
- **변형 유형**: 주기가 다른 두 달력에서 "x년째이자 y년째"인 해 찾기, 여러 주기 이벤트가 동시에 일어나는 때 찾기, 합성수 법의 답을 소인수별 법으로 나눠 구한 뒤 합치기.

## 복잡도
| 방법 | 시간 |
|---|---|
| 모든 x 시도 | O(M) |
| 하나씩 맞추기 | O(m₁ + … + mₖ) |
| 구성적 풀이 / 두 식씩 합치기 | O(k log M) |

공간은 모두 O(k)다. 구성적 풀이는 역원 k번, 합치기는 확장 유클리드 k번이며 각각이 O(log M)이다. 수가 아주 크면 곱셈·나눗셈 자체의 비용이 자릿수에 따라 붙는다.

## 어디에 쓰이나
- RSA 암호의 개인 키 연산: 위 실험처럼 법 p, q에서 따로 거듭제곱한 뒤 qInv로 합치며, 개인 키 파일에 dP, dQ, qInv가 함께 저장된다.
- 7편 「FFT와 NTT: 다항식 곱셈을 O(n log n)에」: 계수가 한 소수 법보다 커질 때 서로 다른 NTT 소수 몇 개로 따로 곱한 뒤 CRT로 진짜 계수를 복원한다.
- 이산수학 5편 「관계: 동치 관계와 순서 관계」: 법 M의 동치류 M개가 각 법의 동치류 조합 M가지와 일대일로 대응한다는 것이 이 정리의 내용이다.
- 5편 「이항 계수 나머지: 페르마 역원과 뤼카 정리」: 법이 서로 다른 소수의 곱이면 소수마다 뤼카 정리로 구한 뒤 CRT로 합친다.

## 정리
- 법이 쌍마다 서로소이면 연립 합동식의 해는 법의 곱 M 안에 정확히 하나다. 차가 모든 법의 배수라는 것으로 유일성을 보인다.
- 구성적 풀이는 "법 mᵢ에서만 1인 스위치" `Mᵢ·(Mᵢ⁻¹ mod mᵢ)`를 rᵢ배 해서 더한다.
- 서로소가 아니면 두 식씩 합치며, gcd가 나머지의 차를 나누지 않으면 해가 없고 있으면 lcm 안에서 하나다.
- RSA 복호화는 p, q 법으로 나눠 계산한 뒤 CRT로 합쳐 빠르게 한다.
