# [수학·기하 알고리즘 5/12] 이항 계수 나머지: 페르마 역원과 뤼카 정리

> **한 줄 요약** — 소수 p에 대해 `a^(p−2)`가 a의 역원이라는 페르마 소정리 덕분에 팩토리얼과 역팩토리얼 표를 O(n)에 만들어 두면 `C(n, k) mod p`를 질의마다 O(1)에 답할 수 있고, n이 p보다 큰 작은 소수 법에서는 n과 k를 p진법 자리별로 나누는 뤼카 정리를 쓴다.

## 이 글에서 다루는 것
- 파스칼 삼각형과 큰 정수 계산이 큰 n에서 안 되는 이유
- 페르마 소정리와 `a^(p−2)` 역원
- 팩토리얼·역팩토리얼 표로 질의당 O(1)
- n ≥ p일 때의 뤼카 정리, 2로 나눈 파스칼 삼각형

## 예제 문제: 격자 경로 수를 10⁹ + 7로
격자에서 오른쪽으로 a칸, 위로 b칸 가는 최단 경로의 수는 a + b번의 이동 중 오른쪽으로 갈 a번을 고르는 수 `C(a + b, a)`다(이산수학 6편 「경우의 수: 순열과 조합」). a, b ≤ 10⁶인 질의가 10⁵개 오고 답을 10⁹ + 7로 나눈 나머지로 출력해야 한다고 하자.

단순한 방법은 둘이다. 하나는 파스칼 삼각형 `C(n, k) = C(n−1, k−1) + C(n−1, k)`다. 덧셈만 쓰므로 나머지 연산과 잘 맞지만 n = 2·10⁶까지 채우면 칸이 약 2·10¹²개다. 다른 하나는 `n! / (k!·(n−k)!)`을 큰 정수로 정확히 계산하는 것인데, 2·10⁶!은 1,173만 자리 수라 질의마다 하기엔 너무 무겁다. 남은 길은 팩토리얼을 나머지로 들고 다니면서 **나눗셈을 역원 곱셈으로** 바꾸는 것이다. 1편의 확장 유클리드로도 되지만, 법이 소수일 때는 더 간단한 도구가 있다.

## 페르마 소정리: 소수 법의 역원
p가 소수이고 a가 p의 배수가 아니면 다음이 성립한다.
```text
a^(p−1) ≡ 1 (mod p)
⇒ a · a^(p−2) ≡ 1, 즉 a⁻¹ ≡ a^(p−2)
```
이것이 **페르마 소정리**(Fermat's little theorem)다. 페르마는 1640년 프레니클(Frénicle de Bessy)에게 보낸 편지에서 증명 없이 이를 적었고, 처음 출판된 증명은 1736년 오일러의 것이다. 증명의 핵심은 짧다. a, 2a, …, (p−1)a를 p로 나눈 나머지는 1, …, p − 1을 섞은 순열이다(두 개가 같다면 `a(i − j)`가 p의 배수가 되는데, p가 소수라 불가능하다). 그래서 모두 곱하면 `a^(p−1)·(p−1)! ≡ (p−1)!`이고, (p−1)!은 p와 서로소라 양변에서 지울 수 있다. 2편의 오일러 정리에서 m = p, φ(p) = p − 1인 경우다.
```python
p, a = 7, 3
print([a * i % p for i in range(1, p)])          # 1~6을 섞은 순열
print(all(pow(a, q - 1, q) == 1 for q in (5, 7, 11, 13, 10**9 + 7)
          for a in range(1, 50) if a % q))
print(pow(2, 14, 15))                            # 15는 소수가 아니다
```
```text
[3, 6, 2, 5, 1, 4]
True
4
```
역원은 `pow(a, p − 2, p)` 한 번, 곱셈 O(log p)번이다. 법이 합성수 15면 `2¹⁴ mod 15 = 4`로 성질이 깨지므로 이 방법은 소수 법에서만 쓴다. 이 "깨짐"을 거꾸로 이용한 소수 판정이 6편이다.

## 팩토리얼과 역팩토리얼 표
`fact[i] = i! mod p`는 앞에서부터 곱하면 된다. 역팩토리얼 `inv_fact[i] = (i!)⁻¹ mod p`도 하나씩 pow로 구할 필요가 없다. 맨 끝의 `inv_fact[n]`만 페르마로 구하고, `1/(i−1)! = i · 1/i!`을 써서 뒤에서부터 곱해 내려오면 된다. 그러면 전처리는 O(n + log p), 질의는 곱셈 두 번이다. 파스칼 삼각형(n ≤ 400)과 대조한다.
```python
import random
MOD = 10**9 + 7                         # 소수

def build(n, p=MOD):
    fact = [1] * (n + 1)
    for i in range(1, n + 1):
        fact[i] = fact[i - 1] * i % p
    inv_fact = [1] * (n + 1)
    inv_fact[n] = pow(fact[n], p - 2, p)     # 페르마: a⁻¹ = a^(p−2)
    for i in range(n, 0, -1):
        inv_fact[i - 1] = inv_fact[i] * i % p  # 1/(i−1)! = i · 1/i!
    return fact, inv_fact

def comb(n, k, fact, inv_fact, p=MOD):
    if k < 0 or k > n:
        return 0
    return fact[n] * inv_fact[k] % p * inv_fact[n - k] % p

fact, inv_fact = build(2 * 10**6)
print(comb(10, 3, fact, inv_fact), comb(2 * 10**6, 10**6, fact, inv_fact))

N = 400
pascal = [[1]]
for n in range(1, N + 1):
    prev = pascal[-1]
    pascal.append([1] + [(prev[k - 1] + prev[k]) % MOD
                         for k in range(1, n)] + [1])
rng = random.Random(9)
for _ in range(500):
    n = rng.randint(0, N)
    k = rng.randint(-2, n + 2)
    want = pascal[n][k] if 0 <= k <= n else 0
    assert comb(n, k, fact, inv_fact) == want
print("무작위 500개 비교: 모두 일치")
```
```text
120 192151600
무작위 500개 비교: 모두 일치
```
`C(2·10⁶, 10⁶) mod (10⁹ + 7) = 192151600`은 표를 한 번 만든 뒤 곱셈 두 번으로 나온다. 대조 검사에 범위 밖의 k(음수, n 초과)를 일부러 섞은 것은 그 경우 0을 돌려주는지 확인하기 위해서다.

## 뤼카 정리: n이 p보다 클 때
법이 작은 소수(예: 7이나 10007)이고 n이 10¹⁸이라면 위 표는 쓸 수 없다. n ≥ p이면 n!에 인수 p가 들어가 `fact[n] ≡ 0`이 되고, 0에는 역원이 없다. 이때 **뤼카 정리**(Lucas's theorem, 1878년 에두아르 뤼카)를 쓴다. n과 k를 p진법으로 `n = n₀ + n₁p + n₂p² + …`, `k = k₀ + k₁p + …`처럼 쓰면 다음이 성립한다.
```text
C(n, k) ≡ C(n₀, k₀)·C(n₁, k₁)·…
(mod p, 어느 자리든 kᵢ > nᵢ이면 0)
예: p = 7, 10 = 13₇, 3 = 3₇
C(10, 3) ≡ C(1, 0)·C(3, 3) = 1
```
실제로 C(10, 3) = 120 = 17·7 + 1이다. 근거는 `(1 + x)^p ≡ 1 + x^p (mod p)`다. 0 < i < p인 C(p, i)는 분자 p!에만 소인수 p가 있어 p의 배수이기 때문이다. 그러면 `(1 + x)ⁿ ≡ (1 + x)^n₀ · (1 + x^p)^n₁ · (1 + x^p²)^n₂ ⋯`이고, 우변에서 xᵏ을 만드는 방법은 p진법 표현이 하나뿐이라 각 인수에서 `x^(kᵢ·pⁱ)`를 고르는 한 가지다. 그 계수가 `C(nᵢ, kᵢ)`들의 곱이다.

각 자리의 `C(nᵢ, kᵢ)`는 p 미만이므로 크기 p의 팩토리얼 표로 구한다. 정확한 정수 `math.comb`의 나머지와 대조한다.
```python
import random
from math import comb

def make_lucas(p):
    """C(n, k) mod p를 구하는 함수(p는 작은 소수, n은 아무리 커도 된다)."""
    fact = [1] * p
    for i in range(1, p):
        fact[i] = fact[i - 1] * i % p
    inv = [1] * p
    inv[p - 1] = pow(fact[p - 1], p - 2, p)
    for i in range(p - 1, 0, -1):
        inv[i - 1] = inv[i] * i % p

    def lucas(n, k):
        result = 1
        while n or k:
            ni, ki = n % p, k % p                 # p진법의 한 자리씩
            if ki > ni:
                return 0                          # 한 자리라도 k가 크면 0
            result = result * fact[ni] * inv[ki] * inv[ni - ki] % p
            n, k = n // p, k // p
        return result
    return lucas

print(make_lucas(7)(10, 3), comb(10, 3) % 7)     # 10 = 13₇, 3 = 3₇
print(make_lucas(10007)(10**18, 12345678))
rng = random.Random(10)
for _ in range(500):
    p = rng.choice([2, 3, 5, 7, 13, 97, 1009])
    n = rng.randint(0, 5000)
    k = rng.randint(0, n)
    assert make_lucas(p)(n, k) == comb(n, k) % p
print("무작위 500개 비교: 모두 일치")
odd = make_lucas(2)
for n in range(8):                               # 2로 나눈 파스칼 삼각형
    print(" " * (7 - n) + " ".join("#" if odd(n, k) else "."
                                   for k in range(n + 1)))
```
```text
1 1
7840
무작위 500개 비교: 모두 일치
       #
      # #
     # . #
    # # # #
   # . . . #
  # # . . # #
 # . # . # . #
# # # # # # # #
```
p = 2이면 자리가 비트이고 `C(1, 0) = C(1, 1) = C(0, 0) = 1`, `C(0, 1) = 0`이므로, "C(n, k)가 홀수 ⇔ k의 1인 비트가 모두 n에도 1"(`n & k == k`)이다. 홀수 칸(#)이 시에르핀스키 삼각형 모양을 그리는 이유다.

## 자주 하는 실수와 변형
- **범위 밖의 k**: k < 0이나 k > n은 0이다. 이 검사를 빼면 음수 인덱스가 파이썬에서는 조용히 뒤에서부터 읽힌다.
- **법이 소수인지**: 10⁹ + 7과 998244353은 소수라 페르마를 쓸 수 있다. 법이 합성수면 역원이 없는 수가 생긴다.
- **n ≥ p**: 팩토리얼 표가 0을 품어 답이 틀린다. 법이 작으면 뤼카로 바꾼다.
- **합성수 법**: 서로 다른 소수의 곱(예: 2·3·5·7)이면 소수마다 뤼카로 구해 4편의 CRT로 합친다. 소수의 거듭제곱 법은 뤼카 정리를 확장한 별도의 방법이 필요하다.
- **1~n의 역원 표**: `inv[i] = −(p // i) · inv[p mod i] mod p`로 O(n)에 만든다. `p = (p // i)·i + (p mod i)`를 법 p로 정리하면 나온다.
- **변형 유형**: 중복 조합 `C(n + r − 1, r)`, 카탈랑 수 `C(2n, n)/(n + 1)`, 막힌 칸이 있는 격자 경로(포함·배제), 확률을 기약분수로 구해 `분자 × 분모⁻¹ mod p`로 출력하기.

## 복잡도
| 방법 | 전처리 | 질의 |
|---|---|---|
| 파스칼 삼각형 | O(n²) | O(1) |
| 팩토리얼 표 + 페르마 | O(n + log p) | O(1) |
| 뤼카(작은 p) | O(p) | O(log_p n) |

공간은 각각 O(n²), O(n), O(p)다. 질의가 하나뿐이면 팩토리얼 표 대신 k개 곱하고 역원 한 번을 쓰는 O(k + log p)도 된다.

## 어디에 쓰이나
- 이산수학 6편 「경우의 수: 순열과 조합」: 그 글의 `C(n, r) = n!/(r!(n − r)!)`과 파스칼 삼각형 점화식을 나머지 세계로 옮긴 것이 이 글의 표와 대조 기준이다.
- 확률과 분포 6편 「이산 분포: 베르누이, 이항, 기하, 포아송」: 이항 분포의 `C(n, k)·pᵏ·(1 − p)ⁿ⁻ᵏ`를 정확한 분수로 구해 소수 법으로 출력하라는 문제에서 팩토리얼 표와 역원을 그대로 쓴다.
- 4편 「중국인의 나머지 정리」: 법이 서로 다른 소수의 곱이면 소수별 뤼카 결과를 CRT로 합친다.
- 6편 「밀러-라빈과 폴라드 로: 큰 수 소인수분해」: 페르마 소정리가 거꾸로 "이 성질이 깨지면 소수가 아니다"라는 판정법이 된다.

## 정리
- 소수 p에 대해 `a^(p−1) ≡ 1`이므로 역원은 `a^(p−2) mod p`이고, 증명은 a의 배수들이 나머지의 순열을 이룬다는 것이다.
- 팩토리얼 표와, 끝값 하나만 페르마로 구한 뒤 거꾸로 채운 역팩토리얼 표로 `C(n, k) mod p`를 O(1)에 답한다.
- n ≥ p이면 팩토리얼이 0이 되므로 뤼카 정리로 p진법 자리마다 나눠 곱한다.
- p = 2의 뤼카 정리는 "C(n, k)가 홀수 ⇔ `n & k == k`"이다.
