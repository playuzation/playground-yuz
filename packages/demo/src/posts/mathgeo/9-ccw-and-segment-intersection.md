## 예제 문제: 두 선분이 만나는가
게임에서 총알이 이번 프레임에 지나간 선분이 벽과 만나는지, 지도에서 두 도로가 교차하는지 알고 싶다. 학교에서 배운 대로라면 두 직선의 방정식 `y = mx + k`를 세우고 교점을 구한 뒤 그 점이 두 선분 위에 있는지 본다. 그런데 이 방법은 수직선(기울기 ∞)을 따로 처리해야 하고, 나눗셈이 들어가 실수 오차가 생긴다. 같은 직선 `y = 3x` 위의 세 점 (0.1, 0.3), (0.2, 0.6), (0.7, 2.1)의 기울기를 실수로 비교하면 같은 값이 나오지 않는다(아래 코드 첫 줄).

## 외적과 CCW
벡터 `u = (u₁, u₂)`, `v = (v₁, v₂)`의 **외적**(2차원에서는 스칼라) `u × v = u₁v₂ − u₂v₁`은 2×2 행렬식이고, 크기는 두 벡터가 만드는 평행사변형의 넓이, 부호는 u에서 v로 도는 방향이다(선형대수 7편). 세 점 o, a, b에 대해 `(a − o) × (b − o)`가 양수면 o → a → b가 **반시계 방향**(b가 직선 oa의 왼쪽), 음수면 시계 방향, 0이면 일직선이다. 이것을 **CCW**(counterclockwise) 판정이라 한다.
```text
        b
       ╱      (a−o)×(b−o) > 0
      ╱       b는 o→a의 왼쪽
     o ────── a
```
곱셈과 뺄셈만 쓰므로 좌표가 정수면 결과도 정확한 정수다. 실수 좌표가 소수 몇째 자리까지로 주어지면 10의 거듭제곱을 곱해 정수로 바꾸고 시작한다. 파이썬 정수는 넘치지 않지만, C++·자바에서 좌표 절댓값이 10⁹이면 차는 2 × 10⁹, 곱은 4 × 10¹⁸까지 가므로 64비트 정수(약 9.2 × 10¹⁸)를 써야 한다.
```python
def cross(o, a, b):                   # (a − o) × (b − o)
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])

def ccw(o, a, b):                     # 1: 반시계(왼쪽), −1: 시계, 0: 일직선
    c = cross(o, a, b)
    return (c > 0) - (c < 0)

p, q, r = (0.1, 0.3), (0.2, 0.6), (0.7, 2.1)          # 모두 y = 3x 위
print((q[1] - p[1]) / (q[0] - p[0]), (r[1] - p[1]) / (r[0] - p[0]))
print(cross(p, q, r), cross((1, 3), (2, 6), (7, 21)))
print(ccw((0, 0), (4, 0), (1, 2)), ccw((0, 0), (4, 0), (1, -2)))
```
```text
2.9999999999999996 3.0
2.7755575615628914e-17 0
1 -1
```
실수로는 두 기울기가 다르게 나오고 외적도 0이 아니지만, 10을 곱한 정수 좌표로는 외적이 정확히 0이다.

## 선분 교차: 경우 나누기
선분 AB와 CD가 일반적인 위치에서 교차하려면 C와 D가 직선 AB의 서로 반대쪽에 있고, A와 B도 직선 CD의 반대쪽에 있어야 한다. 즉 `ccw(A,B,C)·ccw(A,B,D) < 0`이고 `ccw(C,D,A)·ccw(C,D,B) < 0`이다. 끝점이 다른 선분 위에 닿는 T자 모양은 곱이 0이 되므로 부등호를 `≤ 0`으로 바꾸면 함께 잡힌다. 남는 것은 **네 점이 모두 일직선**인 경우다. 이때는 CCW 넷이 모두 0이라 위 조건이 늘 참이므로, 두 선분의 x 구간과 y 구간이 겹치는지 따로 본다.
```text
 X자      T자      일직선 겹침
 ╲ ╱      ──┬──     ━━━━
  ╳         │         ━━━━
 ╱ ╲        │
```
앞 코드에 이어서 쓴다. `on_segment`는 아래 다각형 판정에서 쓴다.
```python
def on_segment(a, b, p):              # 일직선이고 a, b를 대각으로 한 상자 안
    return (cross(a, b, p) == 0 and min(a[0], b[0]) <= p[0] <= max(a[0], b[0])
            and min(a[1], b[1]) <= p[1] <= max(a[1], b[1]))

def intersects(a, b, c, d):
    d1, d2 = ccw(a, b, c), ccw(a, b, d)
    d3, d4 = ccw(c, d, a), ccw(c, d, b)
    if d1 == d2 == d3 == d4 == 0:     # 네 점이 일직선: 구간이 겹치는가
        return (max(min(a[0], b[0]), min(c[0], d[0]))
                <= min(max(a[0], b[0]), max(c[0], d[0])) and
                max(min(a[1], b[1]), min(c[1], d[1]))
                <= min(max(a[1], b[1]), max(c[1], d[1])))
    return d1 * d2 <= 0 and d3 * d4 <= 0

tests = {"X자": ((0, 0), (4, 4), (0, 4), (4, 0)),
         "T자": ((0, 0), (4, 0), (2, 0), (2, 3)),
         "평행": ((0, 0), (4, 0), (0, 1), (4, 1)),
         "일직선 겹침": ((0, 0), (4, 0), (3, 0), (6, 0)),
         "일직선 떨어짐": ((0, 0), (2, 0), (3, 0), (6, 0)),
         "연장선만 교차": ((0, 0), (1, 1), (3, 0), (2, 1))}
for i, (k, v) in enumerate(tests.items()):
    print(f"{k} {intersects(*v)}", end="\n" if i % 3 == 2 else ", ")
```
```text
X자 True, T자 True, 평행 False
일직선 겹침 True, 일직선 떨어짐 False, 연장선만 교차 False
```
마지막 예는 두 직선이 (1.5, 1.5)에서 만나지만 그 점이 두 선분 밖이라 거짓이다. 일직선 검사를 빼먹으면 "일직선 떨어짐"이 참으로 나온다. 길이 0인 선분(점)도 같은 코드로 맞게 처리된다.

## 대조 검사: 분수로 푼 교점
앞 코드에 이어서, 부호 비교를 쓰지 않는 다른 방법과 비교한다. 정의대로 "두 선분에 공통점이 있는가"를 묻는다. 먼저 어느 끝점이 다른 선분 위에 있는지 `p = a + t(b − a)`, `0 ≤ t ≤ 1`인 t를 분수로 구해 확인하고, 아니면 `a + t·r = c + u·s`를 크라메르 공식으로 정확히 풀어 t, u가 [0, 1]에 있는지 본다. 좌표를 0~4로 좁혀 일직선·끝점 닿음 같은 경계 경우가 자주 나오게 했다.
```python
import random
from fractions import Fraction

def on_seg_def(p, a, b):              # p = a + t(b − a), 0 ≤ t ≤ 1 인 t가 있나
    ts = set()
    for k in (0, 1):
        if a[k] != b[k]:
            ts.add(Fraction(p[k] - a[k], b[k] - a[k]))
        elif p[k] != a[k]:
            return False
    return not ts or (len(ts) == 1 and 0 <= min(ts) <= 1)

def brute(a, b, c, d):
    if any(on_seg_def(p, c, d) for p in (a, b)) or \
       any(on_seg_def(p, a, b) for p in (c, d)):
        return True
    rx, ry, sx, sy = b[0] - a[0], b[1] - a[1], d[0] - c[0], d[1] - c[1]
    den = rx * sy - ry * sx           # a + t·r = c + u·s 의 행렬식
    if den == 0:
        return False                  # 평행인데 끝점도 안 겹침
    t = Fraction((c[0] - a[0]) * sy - (c[1] - a[1]) * sx, den)
    u = Fraction((c[0] - a[0]) * ry - (c[1] - a[1]) * rx, den)
    return 0 <= t <= 1 and 0 <= u <= 1

rng = random.Random(9)
pt = lambda: (rng.randint(0, 4), rng.randint(0, 4))
same = hit = line = 0
for _ in range(2000):
    seg = [pt() for _ in range(4)]
    same += intersects(*seg) == brute(*seg)
    hit += brute(*seg)
    line += {ccw(*seg[:2], seg[2]), ccw(*seg[:2], seg[3]),
             ccw(*seg[2:], seg[0]), ccw(*seg[2:], seg[1])} == {0}
print(f"무작위 2000쌍(교차 {hit}, 일직선 분기 {line}): {same}쌍 일치")
```
```text
무작위 2000쌍(교차 771, 일직선 분기 64): 2000쌍 일치
```

## 점과 다각형 포함 판정
점 p에서 오른쪽으로 수평 반직선을 쏘아 다각형의 변을 몇 번 가로지르는지 센다. 홀수면 안, 짝수면 밖이다(**반직선 교차 판정**, ray casting). 반직선이 꼭짓점을 정확히 지나면 두 번 셀 수 있으므로, 변의 두 끝 중 "p보다 위에 있는 쪽이 정확히 하나"일 때만 센다. p와 높이가 같은 꼭짓점은 '위가 아닌' 쪽이 되어, 그 꼭짓점에서 위로 가는 변만 세므로 이중 계산이 없다(반열린 규칙). 교점이 p의 오른쪽인지는 나눗셈 없이 `ccw(a, b, p)`의 부호와 변의 방향으로 판정하고, 경계 위의 점은 `on_segment`로 먼저 거른다. 대조용 정의는 **감은 수**(winding number)다. p에서 본 꼭짓점의 각도 변화를 한 바퀴 더하면 안에서는 ±2π, 밖에서는 0이다. 앞 코드에 이어서, 중심 둘레로 각도순 정렬한 무작위 단순 다각형에서 격자점을 모두 검사한다.
```python
import math

def point_in_polygon(poly, p):        # 1: 안, 0: 경계, −1: 밖
    inside = False
    for i in range(len(poly)):
        a, b = poly[i], poly[i - 1]
        if on_segment(a, b, p):
            return 0
        if (a[1] > p[1]) != (b[1] > p[1]):         # p의 높이를 가로지르는 변
            if ccw(a, b, p) * (b[1] - a[1]) > 0:   # 교점이 p의 오른쪽
                inside = not inside
    return 1 if inside else -1

def winding(poly, p):                 # 대조용: 각도 변화를 모두 더한다
    if any(on_seg_def(p, poly[i], poly[i - 1]) for i in range(len(poly))):
        return 0
    total = 0.0
    for i in range(len(poly)):
        a, b = poly[i - 1], poly[i]
        t = (math.atan2(b[1] - p[1], b[0] - p[0])
             - math.atan2(a[1] - p[1], a[0] - p[0]))
        total += (t + math.pi) % (2 * math.pi) - math.pi
    return 1 if abs(total) > math.pi else -1

def star_polygon(rng, k):             # (5, 5) 둘레 각도순 = 단순 다각형
    while True:
        pts = {(rng.randint(0, 10), rng.randint(0, 10)) for _ in range(k)}
        ang = sorted((math.atan2(y - 5, x - 5), (x, y)) for x, y in pts
                     if (x, y) != (5, 5))
        gaps = [b[0] - a[0] for a, b in zip(ang, ang[1:])]
        gaps.append(ang[0][0] + 2 * math.pi - ang[-1][0])
        if len(ang) >= 3 and min(gaps) > 1e-9 and max(gaps) < math.pi:
            return [p for _, p in ang]

sq = [(0, 0), (4, 0), (4, 4), (0, 4)]
print([point_in_polygon(sq, p) for p in [(2, 2), (4, 1), (5, 2), (0, 0)]])
rng, ok, kinds = random.Random(99), 0, {1: 0, 0: 0, -1: 0}
for _ in range(200):
    poly = star_polygon(rng, rng.randint(3, 9))
    for x in range(11):
        for y in range(11):
            got = point_in_polygon(poly, (x, y))
            ok += got == winding(poly, (x, y))
            kinds[got] += 1
print(f"24200번 중 {ok}번 일치 (안 {kinds[1]}, 경계 {kinds[0]}, 밖 {kinds[-1]})")
```
```text
[1, 0, -1, 0]
24200번 중 24200번 일치 (안 5429, 경계 1971, 밖 16800)
```

## 자주 하는 실수와 변형
- 실수 좌표 그대로 `== 0`으로 일직선을 판정한다. 정수로 바꾸거나, 크기에 맞는 허용 오차를 둔다.
- 네 점 일직선 경우를 빼먹거나, `< 0`만 써서 끝점이 닿는 경우를 놓친다. 문제에 따라 "닿음은 교차가 아님"일 수도 있으니 경계 정의를 먼저 읽는다.
- 반직선이 꼭짓점을 지날 때 두 번 센다. 반열린 규칙(`>` 한쪽만)으로 막는다.
- 변형 유형: 교점 좌표 구하기(위 t를 분수로), 볼록 다각형 포함 판정 O(log n)(한 꼭짓점에서 부채꼴로 나눠 이분 탐색), 선분 n개 중 교차하는 쌍이 있는지(스위핑으로 O(n log n), 알고리즘 기법 10편 참조).

## 복잡도
| 연산 | 시간 | 근거 |
|---|---|---|
| CCW | O(1) | 곱셈 2번 |
| 선분 교차 | O(1) | CCW 4번 |
| 점 포함 | O(n) | 변마다 한 번 |

- 공간은 모두 O(1)(입력 제외)이다. 대조용 분수 풀이도 O(1)이지만 분수 객체라 훨씬 느리고, 각도 합은 답이 0과 ±2π로 크게 갈라지기 때문에 실수로도 믿을 수 있다.

## 어디에 쓰이나
- 선형대수 7편 「행렬식: 부피가 변하는 비율」: 외적은 두 벡터를 열로 둔 2×2 행렬식이며, CCW의 부호는 그 글의 "공간이 뒤집혔는가"와 같은 뜻이다.
- 게임 자원 관리 7편 「공간 분할 1: 균일 격자와 공간 해싱」: 격자로 후보를 줄이는 넓은 단계 뒤에, 좁은 단계에서 총알 궤적과 벽 같은 선분 쌍을 이 글의 교차 판정으로 확인한다.
- 10편 「볼록 껍질: 모노톤 체인과 그레이엄 스캔」: 스택 맨 위 두 점과 새 점의 CCW 하나로 껍질에서 뺄 점을 정한다.

## 정리
- 세 점의 방향은 외적 `(a − o) × (b − o)`의 부호이고, 정수 좌표면 오차 없이 정확하다.
- 선분 교차는 서로의 직선에 대해 반대쪽에 있는지(곱 ≤ 0)로 보고, 네 점 일직선은 구간 겹침으로 따로 처리한다.
- 점의 다각형 포함은 반열린 규칙의 반직선 교차 수로 O(n)에 판정하며, 경계를 먼저 거른다.
- 분수로 푼 교점 2,000쌍, 감은 수로 본 격자점 24,200개와 모두 일치했다.
