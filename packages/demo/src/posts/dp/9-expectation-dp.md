# [동적 계획법 9/12] 확률과 기댓값 DP

> **한 줄 요약** — 기댓값 DP는 "지금 상태에서 끝날 때까지 남은 비용의 기댓값"을 한 걸음 뒤 상태들의 기댓값으로 쓰는 점화식(첫걸음 분석)을 목표 쪽부터 채우는 방법이고, 자기 자신으로 돌아오는 전이는 식을 정리해 풀며, 연립방정식과 몬테카를로 시뮬레이션으로 답을 검증한다.

## 이 글에서 다루는 것
- 기댓값의 선형성과 첫걸음 분석: 점화식이 나오는 이유
- 주사위로 N에 도달하는 기대 횟수: 뒤에서부터 채우기
- 확률 DP는 앞에서부터: 합이 정확히 s가 될 확률
- 자기 자신으로 돌아오는 전이: 양변의 E를 모아 풀기
- 연립방정식(정확한 분수)·몬테카를로와 대조

## 예제 문제: 말판 끝까지 몇 번 굴리나
칸 0에서 출발해 공정한 주사위를 굴려 나온 눈만큼 앞으로 간다. 칸 N 이상에 닿으면 끝난다. 평균 몇 번 굴려야 할까? 굴리는 순서를 모두 나열하면 경우의 수가 N에 대해 지수적으로 늘고, 뒤에서 볼 "넘치면 제자리" 규칙이 붙으면 끝없이 길어지는 경로까지 생겨 나열 자체가 불가능하다. 시뮬레이션은 근삿값만 주고 오차가 시행 횟수 T의 1/√T로만 줄어든다(확률과 분포 10편 「큰 수의 법칙과 중심 극한 정리」).

## 아이디어: 첫걸음 분석
`E[i]`를 "칸 i에 서 있을 때 앞으로 굴릴 횟수의 기댓값"이라 하자. 칸 i에서의 전체 횟수는 "이번 한 번 + 이동한 칸에서 남은 횟수"다. 기댓값은 독립이 아니어도 덧셈을 통과하므로(확률과 분포 4편 「확률 변수와 기댓값」의 선형성) `1 + E[남은 횟수]`가 되고, 남은 횟수의 기댓값은 첫 눈 d에 따라 나눠 확률로 가중 평균하면 된다. 앞으로의 일이 현재 칸에만 달려 있다는 마르코프 성질 덕분에 "칸 i + d에서 남은 횟수"는 그냥 `E[i + d]`다.
```text
E[i] = 1 + Σ P(d) · E[i + d]
E[i] = 0          (i ≥ N)
```
`E[i]`는 더 큰 칸의 값에만 기대므로 N − 1부터 0까지 거꾸로 채운다. **기댓값은 목표에서 출발점 쪽으로**, 다음 절의 **확률은 출발점에서 앞으로** 채운다는 방향 차이를 기억해 두자.
```python
def expected_rolls(N, faces=6):
    """0에서 출발해 N 이상에 닿을 때까지 굴리는 횟수의 기댓값"""
    E = [0.0] * (N + faces)            # N 이상인 칸은 0
    for i in range(N - 1, -1, -1):     # 목표에 가까운 칸부터
        E[i] = 1 + sum(E[i + d] for d in range(1, faces + 1)) / faces
    return E[0]

for N in [1, 2, 6, 10, 100, 1000]:
    e = expected_rolls(N)
    print(N, round(e, 4), "N/3.5 와의 차:", round(e - N / 3.5, 4))
```
```text
1 1.0 N/3.5 와의 차: 0.7143
2 1.1667 N/3.5 와의 차: 0.5952
6 2.1614 N/3.5 와의 차: 0.4471
10 3.3237 N/3.5 와의 차: 0.4666
100 29.0476 N/3.5 와의 차: 0.4762
1000 286.1905 N/3.5 와의 차: 0.4762
```
한 번에 평균 3.5칸 가므로 대략 N/3.5번이고, 마지막 굴림이 N을 넘어서며 낭비되는 몫 때문에 상수(약 0.4762)가 더 붙는다. 상태 N개마다 눈 6개를 보므로 O(6N)이다.

## 확률은 앞에서부터
"주사위 눈의 누적 합이 정확히 s가 되는 순간이 있을 확률" `P[s]`는 반대 방향이다. 합 s에 도달하려면 직전 합이 s − d였고 그다음 d가 나와야 하므로 `P[s] = Σ P[s − d] / 6`, 출발점 `P[0] = 1`에서 앞으로 채운다.
```python
def hit_prob(M, faces=6):
    """합이 정확히 s가 되는 순간이 있을 확률 P[s]"""
    P = [1.0] + [0.0] * M
    for s in range(1, M + 1):          # 출발점에서 앞으로
        P[s] = sum(P[s - d] for d in range(1, faces + 1) if s >= d) / faces
    return P

P = hit_prob(100)
print([round(p, 4) for p in P[1:8]])
print(round(P[100], 6), round(2 / 7, 6))
```
```text
[0.1667, 0.1944, 0.2269, 0.2647, 0.3088, 0.3602, 0.2536]
0.285714 0.285714
```
멀리 가면 확률이 2/7 = 1/3.5로 수렴한다. 평균 3.5칸마다 한 칸씩 밟으니 밟히는 칸의 비율이 1/3.5라는 직관과 맞는다.

## 자기 자신으로 돌아오는 전이
규칙을 바꿔, **정확히** 칸 N에 서야 끝나고 N을 넘치는 눈이 나오면 제자리에 머문다고 하자. 그러면 `E[i]`의 식 오른쪽에 `E[i]` 자신이 나타난다. 넘치는 눈의 확률 합을 q라 하면 양변의 `E[i]`를 모아 풀면 된다.
```text
E[i] = 1 + Σ P(d)·E[i+d] + q·E[i]
(1 − q)·E[i] = 1 + Σ P(d)·E[i+d]
E[i] = (1 + Σ P(d)·E[i+d]) / (1 − q)
```
여기서 Σ는 넘치지 않는 눈(d ≤ N − i)만 더한다. 오차 없이 비교하려고 `Fraction`으로 계산하고, 눈마다 확률이 다른 주사위도 받게 한다. 앞 코드에 이어서 쓴다.
```python
from fractions import Fraction

def exact_landing(N, probs):
    """정확히 N에 서야 끝난다. 넘치는 눈이 나오면 제자리.
    probs[d] = 눈 d가 나올 확률"""
    E = [Fraction(0)] * (N + 1)
    for i in range(N - 1, -1, -1):
        stay = sum(p for d, p in probs.items() if i + d > N)
        move = sum(p * E[i + d] for d, p in probs.items() if i + d <= N)
        E[i] = (1 + move) / (1 - stay)  # E = 1 + move + stay·E 정리
    return E[0]

die = {d: Fraction(1, 6) for d in range(1, 7)}
for N in [1, 2, 3, 10]:
    e = exact_landing(N, die)
    print(N, e, round(float(e), 4))
```
```text
1 6 6.0
2 6 6.0
3 6 6.0
10 1639/216 7.588
```
N이 6 이하면 답이 언제나 6이다. N까지 6칸 안쪽인 칸에서는 곧바로 끝내는 눈이 정확히 하나 있고, 나머지 눈은 제자리이거나 역시 6칸 안쪽 칸으로 보낼 뿐이라, 결국 "1/6 확률의 성공을 기다리는" 기하 분포(확률과 분포 6편 「이산 분포: 베르누이, 이항, 기하, 포아송」, 평균 1/p = 6)가 되기 때문이다. 같은 정리 방법으로 "주사위 여섯 눈을 모두 볼 때까지 굴리는 횟수"도 풀린다. 본 눈이 k가지일 때 새 눈이 나올 확률이 (6 − k)/6이고 나머지는 제자리이므로 `E[k] = 6/(6 − k) + E[k + 1]`, 합하면 6 × (1 + 1/2 + … + 1/6) = 14.7번이다.

## 대조 검사 1: 연립방정식으로 정확히 풀기
느리지만 확실한 방법은 칸 순서를 이용하지 않고 칸마다 식 하나씩, N개의 연립일차방정식 `(I − Q)E = 1`을 세워 가우스 소거로 푸는 것이다(Q는 끝나지 않는 칸 사이의 전이 확률). 앞 코드에 이어서, 눈 2~8개에 무작위 가중치를 준 주사위 500개로 두 규칙을 모두 비교한다.
```python
import random

def solve_chain(N, probs, nxt):
    """흡수 마르코프 연쇄 (I − Q)E = 1 을 가우스 소거로 푼다"""
    A = [[Fraction(0)] * N + [Fraction(1)] for _ in range(N)]
    for i in range(N):
        A[i][i] += 1
        for d, p in probs.items():
            j = nxt(i, d)
            if j < N:                  # j == N은 끝(기댓값 0)
                A[i][j] -= p
    for c in range(N):
        r = next(r for r in range(c, N) if A[r][c] != 0)
        A[c], A[r] = A[r], A[c]
        for r in range(N):
            if r != c and A[r][c] != 0:
                f = A[r][c] / A[c][c]
                A[r] = [a - f * b for a, b in zip(A[r], A[c])]
    return A[0][N] / A[0][0]

rng = random.Random(9)
for t in range(500):
    N, k = rng.randint(1, 10), rng.randint(2, 8)
    w = [rng.randint(1, 5) for _ in range(k)]   # 1의 눈은 늘 가능
    probs = {d + 1: Fraction(w[d], sum(w)) for d in range(k)}
    land = solve_chain(N, probs, lambda i, d: i + d if i + d <= N else i)
    assert exact_landing(N, probs) == land
    uni = {d: Fraction(1, k) for d in range(1, k + 1)}
    reach = solve_chain(N, uni, lambda i, d: min(i + d, N))
    assert abs(expected_rolls(N, k) - reach) < 1e-9
print("무작위 500개 비교: 모두 일치")
```
```text
무작위 500개 비교: 모두 일치
```
분수끼리 비교했으므로 "정확히 N" 규칙은 오차 없이 같은 값이다.

## 대조 검사 2: 몬테카를로 시뮬레이션
점화식을 세우는 과정 자체가 틀렸을 수도 있으니, 규칙 그대로 게임을 10만 번 해 본 평균과도 비교한다(확률과 분포 11편 「표본 추출과 몬테카를로 방법」). 앞 코드에 이어서 쓴다.
```python
def simulate(N, trials, rng):
    total = sq = 0
    for _ in range(trials):
        pos = rolls = 0
        while pos != N:
            d = rng.randint(1, 6)
            rolls += 1
            if pos + d <= N:           # 넘치면 제자리
                pos += d
        total += rolls
        sq += rolls * rolls
    mean = total / trials
    se = ((sq / trials - mean ** 2) / trials) ** 0.5  # 표준 오차
    return mean, se

exact = float(exact_landing(20, die))
mean, se = simulate(20, 100_000, random.Random(2024))
print("DP 정확값 :", round(exact, 4))
print("시뮬레이션:", round(mean, 4), "± 표준오차", round(se, 4))
print("차이/표준오차:", round((mean - exact) / se, 2))
```
```text
DP 정확값 : 10.4765
시뮬레이션: 10.4658 ± 표준오차 0.0176
차이/표준오차: -0.6
```
차이가 표준 오차의 0.6배라 우연한 흔들림 범위 안이다. 2~3배를 넘으면 식이나 시뮬레이션 중 하나를 의심한다.

## 변형과 자주 하는 실수
- 뒤로 가는 전이(뱀 사다리 게임의 뱀): 채울 순서가 없으므로 위의 `solve_chain`처럼 연립방정식을 풀거나(수학·기하 알고리즘 8편 「가우스 소거법: 연립방정식과 XOR 기저」), 값이 수렴할 때까지 점화식을 반복 대입한다.
- 답을 "P/Q를 소수 p로 나눈 나머지"로 내라는 문제: 나눗셈을 모듈러 역원 곱셈으로 바꿔 같은 점화식을 돌린다(수학·기하 알고리즘 1편 「유클리드 호제법과 확장 유클리드: 모듈러 역원 구하기」).
- "기대 개수"는 DP 없이 지표 변수의 합으로 끝나는 경우가 많다. 각 대상이 세어질 확률을 더하면 된다.
- 실수: 기댓값을 출발점부터 채우기(아직 모르는 값을 쓴다), q = 1인 칸(영영 끝나지 않음)에서 0으로 나누기, 확률 합이 1인지 확인하지 않기, 긴 부동소수 누적 오차.

## 복잡도
| 방법 | 시간 | 비고 |
|---|---|---|
| 경로 나열 | 지수 이상 | 제자리 규칙이면 무한 |
| 기댓값 DP | O(N·K) | K = 눈의 개수 |
| 연립방정식 | O(N³) | 순환이 있어도 된다 |
| 몬테카를로 | O(T × 게임 길이) | 오차 ∝ 1/√T |

- 기댓값 DP는 상태마다 전이 K개를 한 번씩 보고, 자기 자신으로 돌아오는 전이는 나눗셈 한 번으로 처리하므로 비용이 늘지 않는다.

## 어디에 쓰이나
- 확률과 분포 4편 「확률 변수와 기댓값」: "1 + 남은 횟수"를 나눠 더하는 첫걸음 분석은 그 글의 선형성과 조건별 가중 평균을 그대로 쓴 것이다.
- 확률과 분포 12편 「마르코프 연쇄: 현재만 기억하는 확률 과정」: 말판은 칸 N이 흡수 상태인 마르코프 연쇄이고, `E[i]`는 흡수까지의 기대 단계 수, 대조에 쓴 `(I − Q)E = 1`은 그 전이 행렬로 세운 식이다.
- AI 기초 2편 「강화학습: 보상으로 배우는 머신러닝」: 상태의 가치(앞으로 받을 보상의 기댓값)를 다음 상태들의 가치로 쓰는 벨만 방정식이 이 글의 점화식과 같은 꼴이고, 그 글의 Q-러닝은 이 식을 직접 풀지 않고 경험한 표본으로 조금씩 맞춰 가는 방법이다.

## 정리
- 기댓값 DP는 "이번 한 걸음 + 다음 상태의 기댓값"이라는 첫걸음 분석으로 점화식을 세우고, 목표 쪽부터 채운다.
- 확률 DP는 반대로 출발점에서 앞으로 채운다.
- 자기 자신으로 돌아오는 전이는 `(1 − q)·E[i]`로 모아 나눗셈 한 번으로 푼다.
- 분수로 연립방정식을 푼 값, 몬테카를로 평균과 비교해 식 세우기의 실수까지 잡는다.
