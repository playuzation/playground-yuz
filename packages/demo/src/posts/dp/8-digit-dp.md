# [동적 계획법 8/12] 자릿수 DP: 조건을 만족하는 수 세기

> **한 줄 요약** — 자릿수 DP는 N 이하의 수를 왼쪽 자리부터 한 자리씩 정하면서 "지금까지 N과 똑같은가(tight)"와 조건에 필요한 최소한의 요약(자릿수 합, 나머지 등)만 상태로 남겨, 10¹⁸까지의 수를 하나씩 보지 않고 상태 수천 개로 센다.

## 이 글에서 다루는 것
- N 이하에서 자릿수 합이 k인 수 세기: 하나씩 보면 왜 안 되나
- 상태 `(pos, tight, 요약)`과 tight 플래그의 의미
- 앞자리 0 함정: 특정 숫자를 포함하지 않는 수
- 상태 기계로 일반화: 7의 배수이면서 7이 없는 수
- 완전 탐색과의 무작위 대조

## 예제 문제: 자릿수 합이 k인 수
"1 이상 N 이하의 정수 중 각 자리 숫자의 합이 k인 것은 몇 개인가?" N이 100, k가 5라면 5, 14, 23, 32, 41, 50의 6개다. 그런데 N이 10¹⁸까지 주어진다. 하나씩 자릿수 합을 구하면 수 하나에 19자리씩, 대략 2 × 10¹⁹번의 연산이 든다. 알고리즘 기법 1편 「입력 크기로 알고리즘 고르기: 복잡도 어림과 문제 읽기」의 어림대로라면 C로도 수천 년이 걸리는 양이다.

## 아이디어: 왼쪽부터 정하고, N에 붙어 있는지만 기억한다
N 이하의 수를 모두 N과 같은 자릿수로 맞춰 앞에 0을 채우자(N = 352라면 7은 007). 두 수의 크기는 처음으로 다른 자리에서 결정되므로, 왼쪽부터 숫자를 고를 때 "N 이하"라는 조건에 필요한 정보는 하나뿐이다. 지금까지 고른 앞부분이 N의 앞부분과 **똑같은가**(tight), 아니면 이미 **작아졌는가**다.
```text
N = 3 5 2, 첫 자리를 고른다
  0, 1, 2 → 이미 작다: 뒤는 0~9 자유
  3       → 아직 같다: 다음 자리 ≤ 5
둘째 자리(아직 같을 때)
  0~4     → 이제 작다: 뒤는 자유
  5       → 아직 같다: 다음 자리 ≤ 2
```
자릿수 합 조건에는 앞부분의 합만 있으면 된다. 그러면 앞부분이 달라도 `(다음 자리 위치, tight, 지금까지의 합)`이 같으면 남은 자리를 채우는 방법의 수가 완전히 같다. 앞부분 수억 개가 상태 하나로 합쳐지는 것, 이것이 겹치는 부분 문제다. 1편의 4단계로 정리하면 이렇다.
- 상태: `go(pos, tight, s)` = pos번째 자리부터 끝까지 채워서 조건을 맞추는 방법의 수
- 전이: 고를 수 있는 숫자 d는 tight면 0~`N[pos]`, 아니면 0~9. tight는 d가 `N[pos]`와 같을 때만 이어진다.
- 초기값: 끝까지 왔으면 합이 k인지에 따라 1 또는 0
- 답: `go(0, True, 0)`

## 구현
자리 수가 많아야 19개라 재귀 깊이는 걱정 없다. `lru_cache`로 메모하고, 방문한 상태 수도 함께 돌려준다.
```python
from functools import lru_cache

def count_digit_sum(N, k):
    """0 이상 N 이하에서 자릿수 합이 k인 수의 개수"""
    ds = list(map(int, str(N)))

    @lru_cache(maxsize=None)
    def go(pos, tight, s):
        if s > k:
            return 0                   # 이미 넘쳤으면 가망 없음
        if pos == len(ds):
            return 1 if s == k else 0
        hi = ds[pos] if tight else 9   # tight면 N의 숫자까지만
        return sum(go(pos + 1, tight and d == hi, s + d)
                   for d in range(hi + 1))
    ans = go(0, True, 0)
    return ans, go.cache_info().currsize

print(count_digit_sum(100, 5))
print(count_digit_sum(10**18, 100))
print(count_digit_sum(10**18, 81))
```
```text
(6, 30)
(9869362547411187, 1395)
(32458256583753952, 1254)
```
10¹⁸ 이하를 세는 데 상태가 1,400개도 안 된다. 0도 "자릿수 합 0인 수"로 세어지므로 k = 0일 때만 1을 빼면 1 이상 N 이하의 답이 된다. 구간 [A, B]의 답은 `f(B) − f(A − 1)`로 구한다. k = 81일 때 개수가 더 많은 것은 18자리 각각의 평균이 4.5라 합이 81 근처에 몰리기 때문이다.

## 무작위 대조 검사
앞 코드에 이어서, 10만 이하의 모든 수의 자릿수 합을 정의대로 구해 두고 무작위 N, k 500쌍에서 비교한다.
```python
import random

MAX = 100_000
dsum = [sum(map(int, str(x))) for x in range(MAX + 1)]  # 정의 그대로

rng = random.Random(8)
for t in range(500):
    N = rng.randint(0, MAX)
    k = rng.randint(0, 45)
    assert count_digit_sum(N, k)[0] == dsum[:N + 1].count(k)
print("무작위 500개 비교: 모두 일치")
```
```text
무작위 500개 비교: 모두 일치
```

## 앞자리 0 함정과 상태 기계
"숫자 0이 한 번도 나오지 않는 수"를 세면 함정이 드러난다. 0을 채워 자릿수를 맞췄으므로 7은 007이 되는데, 이 앞자리 0은 실제 숫자가 아니다. 그래서 상태에 "수가 이미 시작되었는가"를 넣어야 한다. 조건이 바뀔 때마다 DP를 새로 짜지 않도록, 상태와 전이를 함수로 받는 틀을 만들자. 상태는 숫자를 하나씩 먹으며 바뀌는 작은 **상태 기계**(automaton)이고, 조건을 이미 어긴 상태는 `None`(죽은 상태)으로 둔다. 앞 코드에 이어서 쓴다.
```python
def digit_dp(N, start, step, accept):
    """1 이상 N 이하에서 상태 기계가 받아들이는 수의 개수"""
    ds = list(map(int, str(N)))

    @lru_cache(maxsize=None)
    def go(pos, tight, st):
        if st is None:
            return 0                   # 죽은 상태: 조건을 이미 어겼다
        if pos == len(ds):
            return 1 if accept(st) else 0
        hi = ds[pos] if tight else 9
        return sum(go(pos + 1, tight and d == hi, step(st, d))
                   for d in range(hi + 1))
    return go(0, True, start)

def no_digit(bad):                     # 상태 = 수가 시작되었는가
    def step(started, d):
        now = started or d != 0        # 앞자리 0은 아직 숫자가 아니다
        return None if now and d == bad else now
    return step

def wrong_step(st, d):                 # 앞자리 0도 숫자로 친 실수
    return None if d == 0 else True

def m7_step(st, d):                    # 상태 = (시작했나, 7로 나눈 나머지)
    started, r = st
    if d == 7:
        return None
    return (started or d != 0, (r * 10 + d) % 7)

def m7_accept(st):
    return st[0] and st[1] == 0

print(digit_dp(100, False, no_digit(0), bool))
print(digit_dp(100, False, wrong_step, bool))
print(digit_dp(10**18, (False, 0), m7_step, m7_accept))
```
```text
90
0
21442090756714160
```
100 이하에서 0이 없는 수는 한 자리 9개와 두 자리 9 × 9 = 81개를 더한 90개다. 앞자리 0을 숫자로 치면 007, 042 같은 표현이 모두 죽어 0개가 나온다. 7의 배수 조건은 나머지를 상태로 들고 다니며 `r ← (r·10 + d) mod 7`로 갱신한다. 수 전체를 기억하지 않아도 되는 이유는 나머지끼리의 덧셈·곱셈이 원래 수의 나머지를 보존하기 때문이다. 상태가 (시작 여부 2가지) × (나머지 7가지)뿐이라 10¹⁸까지도 순식간이다.

앞 코드에 이어서, 두 조건을 무작위 N(2만 이하)에서 정의대로 센 값과 비교한다.
```python
rng = random.Random(88)
for t in range(500):
    N = rng.randint(1, 20_000)
    if t % 2 == 0:
        b = rng.randint(0, 9)
        got = digit_dp(N, False, no_digit(b), bool)
        want = sum(str(b) not in str(x) for x in range(1, N + 1))
    else:
        got = digit_dp(N, (False, 0), m7_step, m7_accept)
        want = sum(x % 7 == 0 and "7" not in str(x)
                   for x in range(1, N + 1))
    assert got == want
print("무작위 500개 비교: 모두 일치")
```
```text
무작위 500개 비교: 모두 일치
```

## 변형 문제 유형
- k번째 수: "조건을 만족하는 수 중 k번째"는 앞자리부터 숫자 d를 하나씩 놓아 보며 그 뒤를 자유롭게 채우는 개수를 세고, 누적이 k를 넘는 숫자를 확정하며 내려간다. 세는 함수에 알고리즘 기법 3편 「이분 탐색과 매개 변수 탐색: 답을 정해 놓고 판정하기」의 이분 탐색을 씌워도 된다.
- 합 구하기: "1~N의 자릿수 합의 총합"처럼 개수가 아니라 합이 필요하면 `go`가 (개수, 합) 쌍을 돌려주게 하고, 숫자 d를 붙일 때 합에 `d × 개수`를 더한다.
- 금지 패턴: "13이 들어가지 않는 수"는 상태를 "지금까지 패턴의 앞부분과 몇 글자 맞았나"로 둔다. 패턴이 여럿이면 아호-코라식 상태를 쓴다.
- 2진수: 자리를 비트로 바꾸면 "N 이하에서 1인 비트가 k개인 수"도 같은 틀이다.
- 자주 하는 실수: 메모 키에서 tight를 빼먹기, 상태에 수 전체를 넣어 상태가 폭발하기, 여러 N에 같은 메모를 재사용하기(tight 상태의 값은 N마다 다르다. 위 코드는 함수 안에서 캐시를 새로 만든다).

## 복잡도
자릿수를 D(10¹⁸이면 19), 요약 상태 수를 S라 하면 상태는 `D × 2 × S`개, 상태마다 숫자 10개를 본다.

| 방법 | 시간 | N = 10¹⁸, 합 조건 |
|---|---|---|
| 하나씩 세기 | O(N·D) | 약 2 × 10¹⁹ 연산 |
| 자릿수 DP | O(D·S·10) | 상태 1,395개 |

- 공간은 메모한 상태 수 O(D·S)다. 자릿수 합이면 S ≤ 9D + 1, 7의 배수 조건이면 S = 2 × 7이다.
- 비용이 N이 아니라 log N(자릿수)에 비례하는 것이 핵심이다.

## 어디에 쓰이나
- 이산수학 12편 「수 체계와 모듈러 연산: 2진수에서 해시까지」: 자리값 표기 덕분에 "앞에서부터 한 자리씩 고르기"가 가능하고, 나머지를 `(r·10 + d) mod m`으로 갱신해도 되는 것은 그 글의 덧셈·곱셈 나머지 성질이다.
- 이산수학 6편 「경우의 수: 순열과 조합」: tight가 풀린 뒤 남은 r자리는 자유롭게 채우므로 "숫자 b가 없는 수"라면 곱의 법칙으로 9ʳ가지다. 자릿수 DP는 이 곱셈을 상태별로 자동으로 해 준다.
- 문자열 알고리즘 4편 「아호-코라식: 여러 패턴을 한 번에 찾기」: 금지 패턴이 여러 개일 때 그 오토마톤의 상태를 그대로 `digit_dp`의 상태로 넣으면 된다.

## 정리
- N 이하의 수는 왼쪽부터 정하면 "N과 아직 같은가(tight)"만으로 범위 조건을 다룰 수 있다.
- 조건은 수 전체 대신 최소한의 요약(합, 나머지, 패턴 상태)으로 들고 다니고, 같은 상태는 메모로 합친다.
- 앞자리 0은 실제 숫자가 아니므로 "시작했는가" 상태로 구분한다.
- 구간은 `f(B) − f(A − 1)`, 비용은 자릿수 × 상태 수 × 10이다.
