# [미적분 8/10] 다변수 연쇄 법칙과 야코비 행렬

> **한 줄 요약** — 변수가 여러 경로로 출력에 영향을 줄 때는 경로마다 국소 미분을 곱해 모두 더하며, 이를 행렬로 쓰면 연쇄 법칙은 야코비 행렬의 곱이 되고, 역전파는 이 곱을 출력 쪽부터 벡터 하나로 계산해 나가는 방법이다.

## 이 글에서 다루는 것
- 다변수 연쇄 법칙: 경로마다 곱하고 모두 더하기
- 야코비 행렬: 벡터 함수의 미분
- 연쇄 법칙 = 야코비 행렬의 곱
- 역전파 = 출력 쪽부터 벡터-야코비 곱
- AI 기초 1편 XOR 코드의 역전파 한 줄 해부와 수치 검증

## 경로마다 곱하고, 모두 더한다
`z = f(x, y)`에서 x와 y가 모두 t에 따라 변한다면, t를 조금 바꿀 때 z는 x를 거치는 경로와 y를 거치는 경로 두 가지로 변한다. 각 경로에서는 3편처럼 국소 미분을 곱하고, 경로들의 효과는 더한다.
```text
dz/dt = ∂f/∂x · dx/dt + ∂f/∂y · dy/dt
```

7편의 `f(x, y) = x² + 3y²`에 x = t, y = t²을 넣어 보자. `dz/dt = 2x · 1 + 6y · 2t = 2t + 12t³`이고 t = 1이면 14다. 직접 대입한 `z = t² + 3t⁴`를 미분해도 2t + 12t³이 나오고, t = 1에서 수치 미분으로 구해도 약 14다.

3편에서 미뤄 둔 `L = w·w`도 이제 풀 수 있다. w가 곱셈의 두 입력으로 두 번 쓰이므로 경로가 둘이고, 각 경로의 국소 미분은 상대편 입력인 w다. 그래서 `dL/dw = w + w = 2w`이고 (w²)′ = 2w와 일치한다. 계산 그래프에서 한 값이 여러 곳에 쓰이면 역전파 때 기울기를 더한다는 규칙이 여기서 나온다.

## 야코비 행렬
입력이 n개, 출력이 m개인 함수의 미분은 모든 (출력, 입력) 쌍의 편미분을 모은 m × n 행렬이다. 이것을 **야코비 행렬**이라 한다. i행 j열은 ∂gᵢ/∂xⱼ, 즉 "j번째 입력을 조금 바꿀 때 i번째 출력이 변하는 비율"이다.
```text
g(x, y) = (x·y, x + y, x²)          입력 2개, 출력 3개

     ┌ ∂g₁/∂x  ∂g₁/∂y ┐   ┌ y   x ┐
J =  │ ∂g₂/∂x  ∂g₂/∂y │ = │ 1   1 │       3 × 2 행렬
     └ ∂g₃/∂x  ∂g₃/∂y ┘   └ 2x  0 ┘
```

출력이 하나(m = 1)면 야코비 행렬은 1 × n 행벡터이고, 7편의 그래디언트와 같은 정보다. 신경망에서 자주 나오는 야코비 행렬 두 가지를 알아 두면 좋다.
- **선형 층** `a = W·h`: 야코비 행렬은 W 자신이다. 선형 변환을 미분하면 그 변환 자체가 나온다.
- **원소별 활성화** `h = tanh(a)`: hᵢ는 aᵢ에만 의존하므로 대각 행렬이고, 대각 성분은 `tanh′(aᵢ) = 1 − hᵢ²`이다. tanh를 몫 규칙으로 미분하면 이렇게 자기 자신으로 정리된다.

## 연쇄 법칙 = 야코비 행렬의 곱
함수를 `x → h → y`로 이어 붙이면, 각 단계의 야코비 행렬을 곱한 것이 전체의 야코비 행렬이다.
```text
J(x→y) = J(h→y) · J(x→h)          (m × k) · (k × n) = (m × n)
```

행렬 곱의 한 성분을 풀어 쓰면 `Σₖ ∂yᵢ/∂hₖ · ∂hₖ/∂xⱼ`, 즉 "중간 변수 hₖ를 거치는 모든 경로에 대해 곱하고 더하기"다. 앞 절의 규칙이 행렬 곱 안에 그대로 들어 있다. 행렬 곱 자체는 선형대수 3편 「행렬과 행렬 곱」에서 다룬다.

## 역전파: 출력 쪽부터 곱하기
신경망은 층이 여럿이고 마지막에 손실이라는 숫자 하나를 낸다. `x → h₁ → h₂ → L`이라면 다음과 같다.
```text
∂L/∂x = J(L) · J(h₂) · J(h₁)        J(L): 1 × k 행벡터,  J(h₂), J(h₁): k × k
```

행렬 곱은 결합 법칙이 성립하므로 어느 쪽부터 곱해도 결과는 같지만, 비용은 크게 다르다. 폭 k = 1000인 경우를 보자.
- 입력 쪽부터: J(h₂) · J(h₁)은 (1000 × 1000) · (1000 × 1000)이라 곱셈이 약 10⁹번이다.
- 출력 쪽부터: J(L) · J(h₂)는 (1 × 1000) · (1000 × 1000)이라 곱셈이 약 10⁶번이고, 결과가 다시 행벡터라 다음 곱도 10⁶번이다.

출력 쪽부터 곱하면 중간 결과가 늘 행벡터 하나다. 그래서 계산 전체가 **벡터-야코비 곱**(VJP)의 반복이 되고, 비용이 순전파와 비슷한 수준에 머문다. 게다가 야코비 행렬을 실제로 만들 필요도 없다. tanh의 대각 야코비를 곱하는 것은 원소별 곱셈이고, 선형 층의 야코비를 곱하는 것은 가중치 행렬의 전치를 곱하는 것이다. 출력은 하나(손실)이고 입력은 많은(파라미터) 딥러닝에서 역방향 계산이 압도적으로 유리한 이유다.

## XOR 코드의 한 줄 해부
AI 기초 1편의 XOR 코드에서 역전파의 핵심은 이 한 줄이다.
```python
dz1 = (dz2 @ W2.T) * (1 - h**2)   # 연쇄 법칙으로 한 층 더 거꾸로
```

- `dz2`: 출력층 입력 z2에 대한 손실의 기울기다. 시그모이드와 교차 엔트로피를 연쇄 법칙으로 이어 미분하면 `(−y/p + (1 − y)/(1 − p)) · p(1 − p) = p − y`로 깔끔하게 정리되어 코드의 `(p - y)`가 된다. 배치 평균이라 데이터 수로 나눈다.
- `dz2 @ W2.T`: 선형 층 `z2 = h @ W2`의 벡터-야코비 곱이다. 코드는 데이터를 행벡터로 두고 오른쪽에 행렬을 곱하므로, 야코비 곱이 W2의 전치를 곱하는 모양이 된다. 결과는 h에 대한 기울기다.
- `(1 - h**2)`와의 원소별 곱: tanh의 대각 야코비를 곱하는 것이다.

3편의 "국소 미분을 곱해 나간다"가 벡터 버전으로 그대로 구현되어 있다. 정말 맞는지 2편의 수치 미분과 비교해 보자. 은닉 뉴런만 3개로 줄인 같은 구조다.
```python
import numpy as np

rng = np.random.default_rng(0)
X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], dtype=float)
y = np.array([[0], [1], [1], [0]], dtype=float)
W1, b1 = rng.normal(size=(2, 3)), np.zeros(3)
W2, b2 = rng.normal(size=(3, 1)), np.zeros(1)

def loss_fn(W1):                                   # 순전파 → 평균 교차 엔트로피
    h = np.tanh(X @ W1 + b1)
    p = 1 / (1 + np.exp(-(h @ W2 + b2)))
    return -np.mean(y * np.log(p) + (1 - y) * np.log(1 - p))

# 해석적 기울기: AI 기초 1편 XOR 코드의 역전파 그대로
h = np.tanh(X @ W1 + b1)
p = 1 / (1 + np.exp(-(h @ W2 + b2)))
dz2 = (p - y) / len(X)
dz1 = (dz2 @ W2.T) * (1 - h**2)
dW1 = X.T @ dz1

# 수치 기울기: W1의 원소를 하나씩 ±ε 움직여 본다
eps = 1e-6
num = np.zeros_like(W1)
for idx in np.ndindex(W1.shape):
    Wp, Wm = W1.copy(), W1.copy()
    Wp[idx] += eps
    Wm[idx] -= eps
    num[idx] = (loss_fn(Wp) - loss_fn(Wm)) / (2 * eps)

print(dW1.round(6))
print(num.round(6))
print(np.abs(dW1 - num).max())
```
```text
[[-0.092652 -0.088384  0.047564]
 [-0.109771 -0.066408  0.075993]]
[[-0.092652 -0.088384  0.047564]
 [-0.109771 -0.066408  0.075993]]
5.988690099378857e-11
```

두 기울기가 10⁻¹⁰ 수준까지 일치한다. 수치 미분은 W1의 원소 6개마다 손실을 두 번씩 다시 계산했지만, 역전파는 역방향 계산 한 번으로 모든 기울기를 얻었다. 이런 비교를 **그래디언트 체크**라 부르며, 역전파를 직접 구현할 때 버그를 잡는 표준적인 방법이다.

## 어디에 쓰이나
- AI 기초 1편 「딥러닝: 특징까지 스스로 배우는 머신러닝」: XOR 코드의 `dz1 = (dz2 @ W2.T) * (1 - h**2)`는 선형 층의 벡터-야코비 곱에 tanh의 미분 1 − h²을 곱하는, 이 글의 계산 그대로다.
- AI 기초 4편 「컴퓨터 사이언스로 보는 AI 모델: 텐서, 연산, 메모리」: 역방향 자동 미분이 순전파의 몇 배 정도 비용으로 수십억 개의 기울기를 한 번에 구하는 것은, 출력 쪽부터 곱하면 중간 결과가 늘 행벡터 하나로 유지되기 때문이다.
- 선형대수 3편 「행렬과 행렬 곱」: 연쇄 법칙이 행렬 곱이 되므로, (m × k) · (k × n) 곱의 비용 m·k·n이 곱하는 순서의 선택을 결정한다.

## 정리
- 다변수 연쇄 법칙: 중간 변수를 거치는 경로마다 국소 미분을 곱하고, 모든 경로를 더한다.
- 야코비 행렬(출력 m × 입력 n)을 쓰면 연쇄 법칙은 야코비 행렬의 곱이다.
- 출력이 스칼라 하나일 때는 출력 쪽부터 곱하는 벡터-야코비 곱이 훨씬 싸며, 이것이 역전파다.
- XOR 코드의 `dz1` 한 줄은 선형 층의 VJP와 tanh 미분의 원소별 곱이며, 수치 기울기와 10⁻¹⁰ 수준까지 일치한다.
