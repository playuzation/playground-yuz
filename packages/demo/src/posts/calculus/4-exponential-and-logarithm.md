# [미적분 4/10] 지수 함수와 로그 함수

> **한 줄 요약** — 미분해도 자기 자신인 함수 eˣ와 그 역함수 ln x는 곱셈을 덧셈으로 바꿔 주는 도구로, 확률의 곱을 다루는 로그 가능도, 시그모이드·소프트맥스, 그리고 넘치지 않는 수치 계산의 기초가 된다.

## 이 글에서 다루는 것

- eˣ의 미분이 자기 자신인 이유
- 로그: 곱을 합으로 바꾸기, (ln x)′ = 1/x
- 시그모이드와 소프트맥스
- log-sum-exp: 최댓값을 빼서 오버플로 막기

## 지수 성장과 e
같은 비율로 계속 곱해지는 증가를 **지수 성장**이라 한다. 매시간 두 배가 되는 박테리아는 10시간 뒤 1024배, 20시간 뒤 약 100만 배가 된다. 지수 함수 `aˣ`는 x가 1 늘 때마다 값이 a배가 된다. 밑으로 가장 많이 쓰는 수는 1편에서 `(1 + 1/n)ⁿ`의 극한으로 만난 **자연 상수** e = 2.71828…이다. 왜 하필 e일까? 미분해 보면 답이 나온다.

## eˣ: 미분해도 자기 자신
2편의 정의대로 aˣ를 미분하면 aˣ를 밖으로 묶어 낼 수 있다.
```text
(aˣ)′ = lim(h→0) (aˣ⁺ʰ − aˣ)/h = aˣ · lim(h→0) (aʰ − 1)/h
```

aˣ의 기울기는 자기 자신에 상수 하나를 곱한 것이다. 그 상수를 숫자로 재 보자.
```python
import math

h = 1e-6
for name, a in [("2", 2), ("3", 3), ("e", math.e)]:
    print(f"a = {name}:  (a^h − 1)/h = {(a ** h - 1) / h:.4f},  ln a = {math.log(a):.4f}")
```
```text
a = 2:  (a^h − 1)/h = 0.6931,  ln a = 0.6931
a = 3:  (a^h − 1)/h = 1.0986,  ln a = 1.0986
a = e:  (a^h − 1)/h = 1.0000,  ln a = 1.0000
```

상수는 자연로그 ln a이고, 그 값이 정확히 1이 되는 밑이 e다. 그래서 `(aˣ)′ = aˣ · ln a`, 특히 `(eˣ)′ = eˣ`다. "현재 크기에 비례해 자란다"는 지수 성장을 가장 깔끔하게 표현하는 함수가 eˣ인 셈이다. 3편의 연쇄 법칙과 합치면 `(e^(kx))′ = k·e^(kx)`도 바로 나온다.

## 로그: 곱을 합으로
**자연로그** ln x는 eˣ의 역함수다. `ln x = y`는 `eʸ = x`라는 뜻이다. 지수 법칙 `eᵃ · eᵇ = eᵃ⁺ᵇ`을 거꾸로 읽으면 로그 법칙이 된다.
```text
ln(a·b) = ln a + ln b        곱 → 합
ln(a/b) = ln a − ln b        나눗셈 → 뺄셈
ln(aⁿ)  = n · ln a           거듭제곱 → 곱
```

로그의 미분은 역함수 관계에서 나온다. y = ln x면 x = eʸ이고, 양변을 x로 미분하면 연쇄 법칙으로 `1 = eʸ · dy/dx`, 즉 `dy/dx = 1/eʸ = 1/x`다. 그래서 `(ln x)′ = 1/x`다.

### 로그 가능도: 곱 대신 합
데이터가 서로 독립이면 모델이 데이터 전체에 주는 확률(가능도)은 각 확률의 곱이다. 이 곱은 컴퓨터에서 금방 문제가 된다.
```python
import math

probs = [0.5] * 2000                 # 동전 2000번, 각 결과의 확률 0.5

product = 1.0
for p in probs:
    product *= p
print(product)                       # 가능도(곱): 0.0

print(sum(math.log(p) for p in probs))   # 로그 가능도(합): -1386.2943611198225
```

0.5를 2000번 곱한 참값은 약 10⁻⁶⁰²인데, float64가 표현할 수 있는 가장 작은 양수(약 5 × 10⁻³²⁴)보다 작아 0.0이 된다(언더플로). 로그를 씌우면 곱이 합으로 바뀌어 −1386.29처럼 평범한 크기의 수가 된다. log는 증가 함수라서 가능도를 최대로 하는 파라미터와 로그 가능도를 최대로 하는 파라미터는 같다. 게다가 합은 곱보다 미분하기 쉽다. 각 항을 따로 미분해 더하면 되기 때문이다. 그래서 머신러닝은 거의 언제나 로그 가능도를 쓰고, 그 부호를 바꿔 평균 낸 것이 교차 엔트로피 손실이다. 통계적 의미는 통계학 4편 「최대 우도 추정」에서 다룬다.

## 시그모이드와 소프트맥스
지수 함수는 어떤 실수든 양수로 바꾼다. 이 성질로 점수를 확률로 바꾸는 두 함수가 만들어진다.
```text
시그모이드:  σ(z) = 1 / (1 + exp(−z))                  실수 → (0, 1)
소프트맥스:  softmax(z)ᵢ = exp(zᵢ) / Σⱼ exp(zⱼ)          벡터 → 합이 1인 확률 벡터
```

시그모이드는 이진 분류에서 "1일 확률"을 내고, 도함수가 `σ′(z) = σ(z)·(1 − σ(z))`로 자기 자신으로 표현된다. 소프트맥스는 여러 클래스에 확률을 나눠 주며, z = (1, 2, 3)이면 (0.0900, 0.2447, 0.6652)다. 소프트맥스 확률에 로그를 씌우면 `log softmax(z)ᵢ = zᵢ − log Σⱼ exp(zⱼ)`로 지수와 로그가 상쇄되고, 마지막 항만 남는다. 이 항을 **log-sum-exp**라 부른다.

## log-sum-exp: 최댓값을 빼서 넘침 막기
신경망의 출력 점수(로짓)가 크면 exp가 float64의 한계(약 1.8 × 10³⁰⁸)를 넘는다. e¹⁰⁰⁰은 이미 표현할 수 없다.
```python
import numpy as np

z = np.array([1000.0, 1001.0, 1002.0])     # 큰 로짓

# 그대로 계산: e¹⁰⁰⁰이 float64 범위(약 1.8 × 10³⁰⁸)를 넘는다
print(np.log(np.sum(np.exp(z))))           # inf
print(np.exp(z) / np.sum(np.exp(z)))       # [nan nan nan]

# 최댓값 m을 빼고 계산: log Σ e^zᵢ = m + log Σ e^(zᵢ − m)
m = z.max()
print(m + np.log(np.sum(np.exp(z - m))))         # 1002.4076059644444
print(np.exp(z - m) / np.sum(np.exp(z - m)))     # [0.09003057 0.24472847 0.66524096]
```

그대로 계산하면 NumPy가 `RuntimeWarning: overflow encountered in exp` 경고와 함께 inf를 내고, 소프트맥스는 inf / inf가 되어 nan이 된다. 해결책은 지수 법칙 하나다. 모든 점수에서 최댓값 m을 빼도 값은 그대로다.
```text
log Σ exp(zᵢ) = m + log Σ exp(zᵢ − m)
softmax(z)ᵢ   = exp(zᵢ − m) / Σⱼ exp(zⱼ − m)
```

m을 빼면 지수의 가장 큰 값이 e⁰ = 1이라 넘칠 수 없고, 적어도 한 항이 1이라 합이 0이 되어 log가 −∞로 가지도 않는다. 결과 확률이 z = (1, 2, 3)일 때와 같다는 점에도 주목하자. 소프트맥스는 모든 점수에 같은 수를 더하거나 빼도 변하지 않는다. 그래서 라이브러리는 소프트맥스와 로그를 따로 계산하지 않고 log-sum-exp로 묶어 안정적으로 계산하는 함수를 제공한다. PyTorch의 `cross_entropy`가 확률이 아니라 로짓을 그대로 받는 이유다.

## 어디에 쓰이나
- AI 기초 3편 「데이터 분포로 보는 AI 모델」: KL 발산과 교차 엔트로피 식의 `log p_θ(x)`는 곱으로 된 가능도를 합으로 바꾸는 로그이며, "최대 우도 = 교차 엔트로피 최소화"라는 설명이 이 위에 서 있다.
- AI 기초 1편 「딥러닝: 특징까지 스스로 배우는 머신러닝」: XOR 예제 출력층의 `1 / (1 + np.exp(-z))`가 이 글의 시그모이드다.
- 통계학 4편 「최대 우도 추정」, 통계학 9편 「로지스틱 회귀: 확률을 예측하는 회귀」: 로그 가능도를 미분해 최대점을 찾는 계산과, 시그모이드로 확률을 내는 모델이 이 글의 도구로 이루어진다.
- 정보 이론 1편 「정보량과 엔트로피」: 정보량을 −log p로 정의하는 것은 "독립 사건의 확률은 곱해지지만 정보량은 더해져야 한다"는 요구를 로그의 곱 → 합 성질이 채워 주기 때문이다.

## 정리
- (aˣ)′ = aˣ·ln a이고, ln e = 1이라 (eˣ)′ = eˣ다. 역함수인 ln x의 도함수는 1/x다.
- 로그는 곱을 합으로 바꿔, 언더플로를 막고 미분을 쉽게 한다. 그래서 가능도 대신 로그 가능도를 쓴다.
- 시그모이드와 소프트맥스는 지수 함수로 점수를 확률로 바꾸며, 큰 로짓에서는 최댓값을 빼는 log-sum-exp로 오버플로를 막는다.
