# [미적분 2/10] 미분: 순간 변화율

> **한 줄 요약** — 미분은 "입력을 아주 조금 바꿀 때 출력이 몇 배로 바뀌는가"를 평균 변화율의 극한으로 정의한 것이며, 그래프에서는 접선의 기울기이고 머신러닝에서는 파라미터를 어느 쪽으로 고칠지 알려 주는 기울기다.

## 이 글에서 다루는 것
- 평균 변화율에서 순간 변화율로
- 도함수의 정의와 접선
- 수치 미분: h를 줄이면 정말 정확해지는가
- 미분할 수 없는 점: ∣x∣와 ReLU

## 평균 변화율에서 순간 변화율로
공을 떨어뜨리면 t초 동안 약 `s(t) = 5t²`미터를 떨어진다(중력 가속도를 10m/s²로 어림). 1초에서 2초 사이의 평균 속도는 `(s(2) − s(1)) / (2 − 1) = 15`m/s다. 그렇다면 "정확히 1초일 때의 속도"는 어떻게 구할까? 구간을 줄여 보면 된다.

| 구간 | 평균 속도 (m/s) |
|---|---|
| 1 ~ 2초 | 15 |
| 1 ~ 1.1초 | 10.5 |
| 1 ~ 1.01초 | 10.05 |
| 1 ~ 1.001초 | 10.005 |

구간을 좁힐수록 평균 속도는 10에 다가간다. 이 극한값 10m/s가 t = 1에서의 **순간 변화율**, 즉 순간 속도다.

## 도함수: 평균 변화율의 극한
x에서 x + h까지의 평균 변화율은 `(f(x + h) − f(x)) / h`이고, h → 0일 때의 극한을 x에서의 **미분계수**라 한다. 이것을 모든 x에 대해 모은 함수가 **도함수** f′(x)다.
```text
f′(x) = lim(h→0) [f(x + h) − f(x)] / h        다른 표기: df/dx, dy/dx
```

`f(x) = x²`이면 정의만으로 계산할 수 있다.
```text
[(x + h)² − x²] / h = (2xh + h²) / h = 2x + h  →  2x   (h → 0)
```

그래서 (x²)′ = 2x이고, 같은 방법으로 s(t) = 5t²의 도함수는 10t, t = 1이면 10이다. 1편에서 본 "0/0 꼴이어도 극한은 존재한다"가 바로 여기서 쓰인다. 도함수의 부호는 함수의 방향을 알려 준다. f′ > 0이면 증가, f′ < 0이면 감소하는 중이고, f′ = 0이면 그 점에서 평평하다(9편에서 최솟값을 찾는 단서가 된다).

### 접선
그래프에서 평균 변화율은 두 점을 잇는 할선의 기울기이고, h → 0이면 할선이 한 점에서 곡선에 닿는 **접선**이 된다. 점 a에서의 접선은 `y = f(a) + f′(a)·(x − a)`다. 예를 들어 y = x²의 x = 3에서 접선은 `y = 9 + 6(x − 3)`이다. 접점 근처에서는 곡선과 접선이 거의 겹친다. "아주 가까이서 보면 곡선도 직선"이라는 이 생각은 6편의 선형 근사와 10편의 경사 하강법으로 이어진다.

## 수치 미분: h를 줄이면 정말 정확해질까
도함수 공식을 모르면 작은 h를 직접 넣어 평균 변화율을 계산하면 된다. 이것이 **수치 미분**이다. 답을 아는 `(sin x)′ = cos x`로 x = 1에서 실험해 보자. 참값은 cos 1 = 0.540302305868…이다.
```python
import math

x = 1.0
true = math.cos(x)                                 # (sin x)′ = cos x
for k in range(1, 16):
    h = 10.0 ** -k
    approx = (math.sin(x + h) - math.sin(x)) / h   # 평균 변화율
    print(f"1e-{k}  {approx:.12f}  {abs(approx - true):.1e}")
```

실행 결과를 표로 옮기면 다음과 같다.

|---|---|---|
| 1e-1 | 0.497363752535 | 4.3e-02 |
| 1e-2 | 0.536085981012 | 4.2e-03 |
| 1e-3 | 0.539881480360 | 4.2e-04 |
| 1e-4 | 0.540260231419 | 4.2e-05 |
| 1e-5 | 0.540298098506 | 4.2e-06 |
| 1e-6 | 0.540301885121 | 4.2e-07 |
| 1e-7 | 0.540302264040 | 4.2e-08 |
| 1e-8 | 0.540302302898 | 3.0e-09 |
| 1e-9 | 0.540302358409 | 5.3e-08 |
| 1e-10 | 0.540302247387 | 5.8e-08 |
| 1e-11 | 0.540301137164 | 1.2e-06 |
| 1e-12 | 0.540345546085 | 4.3e-05 |

| 1e-14 | 0.544009282066 | 3.7e-03 |
| 1e-15 | 0.555111512313 | 1.5e-02 |

오차는 h를 10배 줄일 때마다 10배씩 줄다가 h = 10⁻⁸에서 가장 작아지고, 그보다 작게 하면 오히려 커진다. 두 가지 오차가 겨루기 때문이다.
- **절단 오차**: 극한 대신 유한한 h를 쓰는 데서 생긴다. 대략 `h/2 · ∣f″(x)∣`라 h에 비례한다. 여기서는 ∣f″(1)∣ = sin 1 ≈ 0.84라서 오차 ≈ 0.42h이고, 표의 윗부분(4.2e-02, 4.2e-03, …)과 정확히 맞는다.
- **반올림 오차**: f(x + h)와 f(x)는 거의 같은 수라서, 빼면 유효숫자 대부분이 지워진다. float64의 상대 오차가 약 10⁻¹⁶이므로 이 오차는 대략 `10⁻¹⁶/h`로, h가 작을수록 커진다.

두 오차의 합은 h ≈ √(10⁻¹⁶) = 10⁻⁸ 근처에서 가장 작고, 실행 결과도 그렇다. 1편에서 본 "컴퓨터는 극한을 흉내만 낸다"의 실제 모습이다. 양쪽으로 벌린 중앙 차분 `(f(x + h) − f(x − h)) / (2h)`는 절단 오차가 h²에 비례해 더 정확하지만(같은 예에서 h = 10⁻⁵일 때 오차 약 10⁻¹¹), 반올림 오차의 벽은 그대로 남는다.

## 미분할 수 없는 점
∣x∣의 x = 0에서 평균 변화율은 `(∣0 + h∣ − ∣0∣)/h = ∣h∣/h`다. 1편에서 본 대로 이 값은 h < 0이면 −1, h > 0이면 1이라 극한이 없다. 그래프가 뾰족하게 꺾인 점에서는 접선을 하나로 정할 수 없고, 미분도 정의되지 않는다. ∣x∣는 연속이지만 미분 가능하지 않다. 반대로 미분 가능한 함수는 반드시 연속이다.

ReLU `max(0, x)`도 마찬가지다. x < 0에서 기울기는 0, x > 0에서 기울기는 1이고, x = 0에서는 왼쪽 기울기 0과 오른쪽 기울기 1이 달라 미분할 수 없다. 그래도 신경망 학습에 문제가 되지 않는 이유는 두 가지다. 실수 입력이 정확히 0이 되는 경우가 드물고, 딥러닝 프레임워크는 x = 0에서의 기울기를 관례로 0이나 1 중 하나로 정해 둔다. 이렇게 꺾인 점에서 왼쪽과 오른쪽 기울기 사이의 값을 골라 쓰는 것을 **서브그래디언트**(subgradient)라고 한다.

## 어디에 쓰이나
- AI 기초 1편 「딥러닝: 특징까지 스스로 배우는 머신러닝」: 역전파가 구하는 "기울기"는 손실을 파라미터로 미분한 도함수 값이고, ReLU의 기울기가 0 또는 1인 것도 이 글의 정의에서 나온다.
- AI 기초 4편 「컴퓨터 사이언스로 보는 AI 모델: 텐서, 연산, 메모리」: 수치 미분은 파라미터 하나마다 손실을 다시 계산해야 하고 위에서 본 정밀도의 벽도 있어서, 수십억 파라미터의 기울기는 수치 미분이 아니라 자동 미분으로 구한다.
- 8편 「다변수 연쇄 법칙과 야코비 행렬」: 수치 미분은 느리지만 구현이 쉬워서, 직접 짠 역전파가 맞는지 확인하는 그래디언트 체크에 쓴다.

## 정리
- 도함수 f′(x)는 평균 변화율 (f(x + h) − f(x))/h의 h → 0 극한이며, 그래프에서는 접선의 기울기다.
- 정의만으로 (x²)′ = 2x 같은 결과를 계산할 수 있고, 도함수의 부호는 증가·감소를 알려 준다.
- 수치 미분의 오차는 절단 오차와 반올림 오차의 싸움이라 float64에서는 h ≈ 10⁻⁸ 근처가 가장 정확하다.
- ∣x∣와 ReLU처럼 꺾인 점에서는 미분할 수 없지만, 실무에서는 관례로 정한 기울기를 쓴다.
