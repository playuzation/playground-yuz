# [미적분 3/10] 미분 규칙과 연쇄 법칙

> **한 줄 요약** — 몇 가지 미분 규칙만 알면 복잡한 식도 기계적으로 미분할 수 있고, 그중 연쇄 법칙은 "합성 함수의 미분은 각 단계 국소 미분의 곱"이라는 사실로 역전파의 수학적 뼈대가 된다.

## 이 글에서 다루는 것
- 거듭제곱·합·곱·몫 규칙
- 연쇄 법칙: 함수 안의 함수를 미분하기
- (2w − 4)²을 손으로 미분해 AI 기초 4편의 `tensor(8.)` 재현하기
- 계산 그래프 위에서 국소 미분을 곱해 나가기

## 매번 극한을 계산하지 않기 위해
2편처럼 정의로 미분하면 확실하지만 번거롭다. 다행히 자주 쓰는 함수의 도함수와, 함수를 조합할 때의 규칙 몇 개만 알면 대부분의 식을 기계적으로 미분할 수 있다. 모두 2편의 정의에서 유도된다.

| 규칙 | 공식 | 예 |
|---|---|---|
| 거듭제곱 | (xⁿ)′ = n·xⁿ⁻¹ | (x³)′ = 3x² |
| 상수배·합 | (a·f + g)′ = a·f′ + g′ | (5x² + x)′ = 10x + 1 |
| 곱 | (f·g)′ = f′·g + f·g′ | (x·sin x)′ = sin x + x·cos x |
| 몫 | (f/g)′ = (f′·g − f·g′)/g² | (1/x)′ = −1/x² |

여기에 기본 함수의 도함수 몇 개를 더하면 된다. `(sin x)′ = cos x`, `(cos x)′ = −sin x`이고, `(eˣ)′ = eˣ`와 `(ln x)′ = 1/x`는 4편에서 다룬다.

곱 규칙은 직사각형 넓이로 이해할 수 있다. 가로 f, 세로 g인 직사각형에서 가로가 Δf, 세로가 Δg만큼 늘면 넓이는 `g·Δf + f·Δg + Δf·Δg`만큼 는다. 마지막 항은 아주 작은 수끼리의 곱이라 변화량이 0으로 갈 때 사라지고, 남은 두 항이 곱 규칙이 된다.

## 연쇄 법칙: 함수 안의 함수
`y = (2w − 4)²`처럼 함수 안에 함수가 들어 있는 것을 **합성 함수**라고 한다. 바깥 함수 f(u) = u²와 안쪽 함수 u = g(w) = 2w − 4로 나누면 y = f(g(w))다. 합성 함수는 **연쇄 법칙**으로 미분한다.
```text
(f∘g)′(x) = f′(g(x)) · g′(x)
라이프니츠 표기:  dy/dx = dy/du · du/dx
```

톱니바퀴로 생각하면 쉽다. u가 x보다 2배 빨리 돌고 y가 u보다 3배 빨리 돌면, y는 x보다 2 × 3 = 6배 빨리 돈다. 변화율은 단계마다 곱해진다. `dy/du · du/dx`에서 du가 약분되는 것처럼 보이는 것은 엄밀한 증명은 아니지만 좋은 기억법이다.

앞의 예를 단계별로 풀면 다음과 같다.
```text
y = u²,  u = 2w − 4
dy/du = 2u,   du/dw = 2
dy/dw = 2u · 2 = 4(2w − 4)
w = 3 이면  u = 2,  dy/dw = 4 × 2 = 8
```

AI 기초 4편에서 PyTorch의 `loss.backward()`가 내놓은 `tensor(8.)`이 바로 이 값이다. 다른 예로 `(sin(x²))′ = cos(x²)·2x`다. 바깥의 sin을 미분해 cos(x²)을 얻고, 안쪽 x²의 미분 2x를 곱한다. 합성이 세 겹이면 `f(g(h(x)))′ = f′ · g′ · h′`처럼 국소 미분 세 개를 곱하면 된다.

## 계산 그래프 위의 연쇄 법칙
프로그램은 큰 식을 한 번에 계산하지 않고 작은 연산을 차례로 실행한다. 이 순서를 그래프로 그린 것이 **계산 그래프**다. 연쇄 법칙은 이 그래프 위에서 아주 단순한 절차가 된다.
```text
순전파 →   w = 3 ──[2w − 4]──▶ u = 2 ──[u²]──▶ L = 4
역전파 ←   dL/dw = 8 ◀──(× 2)── dL/du = 4 ◀──(× 2u)── dL/dL = 1
```

1. 순전파로 중간값(u = 2)을 계산하며 기록해 둔다.
2. 출력에서 출발한다. 자기 자신에 대한 미분은 dL/dL = 1이다.
3. 노드를 하나 거꾸로 지날 때마다 그 연산 하나만의 도함수, 즉 **국소 미분**을 곱한다.

각 노드는 자기 연산의 미분만 알면 되고 전체 식을 알 필요가 없다. 노드가 수천 개여도 같은 절차를 반복할 뿐이다. 코드로 그대로 옮기면 다음과 같다.
```python
w = 3.0

# 순전파: 중간값을 기록해 둔다
u = 2 * w - 4             # u = 2
L = u ** 2                # L = 4

# 역전파: 출력 쪽부터 국소 미분을 곱해 나간다
dL_dL = 1.0
dL_du = dL_dL * (2 * u)   # (u²)′ = 2u
dL_dw = dL_du * 2         # (2w − 4)′ = 2
print(dL_du, dL_dw)       # 4.0 8.0

# 수치 미분으로 확인 (중앙 차분)
loss = lambda w: (2 * w - 4) ** 2
h = 1e-6
print((loss(w + h) - loss(w - h)) / (2 * h))   # 8.000000001340268
```

중요한 점은 `dL_du`를 한 번 구한 뒤 그대로 재사용해 `dL_dw`를 구했다는 것이다. 출력 쪽에서 계산한 결과를 입력 쪽으로 넘겨 가며 재사용하므로, 파라미터가 아무리 많아도 역방향으로 한 번 훑으면 모든 기울기를 얻는다. 한 변수가 여러 경로로 출력에 영향을 줄 때(예: `w·w`처럼 같은 값이 두 번 쓰일 때)는 경로마다 곱한 값을 더해야 하는데, 이것은 8편의 주제다.

## 어디에 쓰이나
- AI 기초 1편 「딥러닝: 특징까지 스스로 배우는 머신러닝」: "미분의 연쇄 법칙으로 기울기를 출력층에서부터 거꾸로 계산한다"는 역전파의 설명이 이 글의 계산 그래프 절차 그대로다.
- AI 기초 4편 「컴퓨터 사이언스로 보는 AI 모델: 텐서, 연산, 메모리」: 자동 미분 예제의 `tensor(8.)`은 4(2w − 4)에 w = 3을 넣은 값이며, 프레임워크는 순전파 때 계산 그래프를 기록했다가 거꾸로 따라가며 국소 미분을 곱한다.
- 8편 「다변수 연쇄 법칙과 야코비 행렬」: 변수와 출력이 벡터가 되면 국소 미분은 야코비 행렬이 되고, 국소 미분의 곱은 행렬 곱이 된다.

## 정리
- 거듭제곱·합·곱·몫 규칙과 기본 함수의 도함수만 알면 대부분의 식을 기계적으로 미분할 수 있다.
- 연쇄 법칙 (f∘g)′(x) = f′(g(x))·g′(x): 합성 함수의 변화율은 단계별 변화율의 곱이다.
- 계산 그래프에서는 출력의 dL/dL = 1에서 출발해 국소 미분을 곱해 나가면 되고, 이것이 역전파다.
