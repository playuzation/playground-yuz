# [미적분 6/10] 테일러 급수: 복잡한 함수를 다항식으로

> **한 줄 요약** — 테일러 급수는 한 점에서의 함숫값과 도함수들만으로 함수를 다항식으로 근사하는 방법으로, 1차 항은 직선 근사(선형화), 2차 항은 휘어짐(곡률)을 담으며 경사 하강법과 수치 계산의 바탕이 된다.

## 이 글에서 다루는 것
- 한 점의 정보로 함수 흉내 내기: 테일러 급수의 공식
- eˣ, sin x, ln(1 + x)의 급수
- 1차 근사 = 선형화, 2차 근사 = 곡률
- 항 수에 따른 오차와 수렴 범위
- 컴퓨터가 sin을 계산하는 방법

## 한 점의 정보로 함수 흉내 내기
다항식은 덧셈과 곱셈만으로 계산되는, 가장 다루기 쉬운 함수다. 그렇다면 sin x나 eˣ 같은 함수를 점 a 근처에서 다항식으로 흉내 낼 수 있을까? 아이디어는 a에서 값, 기울기, 휘어짐을 차례로 맞추는 것이다.
- 0차: 값만 맞춘다. `f(x) ≈ f(a)` (수평선)
- 1차: 기울기까지 맞춘다. `f(x) ≈ f(a) + f′(a)(x − a)` (2편의 접선)
- 2차: 기울기의 변화율 f″까지 맞추도록 (x − a)² 항을 더한다.

이렇게 도함수를 차례로 모두 맞추면 다음 식이 된다.
```text
f(x) ≈ f(a) + f′(a)(x − a) + f″(a)/2! · (x − a)² + f‴(a)/3! · (x − a)³ + …
```

끝없이 이어 쓴 것을 **테일러 급수**, 유한한 항에서 자른 다항식을 **테일러 다항식**이라고 한다. k차 항을 k!로 나누는 이유는 (x − a)ᵏ을 k번 미분하면 k!이 나오기 때문이다. 그래야 다항식의 k계 도함수가 a에서 정확히 f의 k계 도함수와 같아진다. a = 0일 때를 특히 **매클로린 급수**라고 부른다.

## 대표적인 세 급수
```text
eˣ        = 1 + x + x²/2! + x³/3! + x⁴/4! + …        모든 x에서 수렴
sin x     = x − x³/3! + x⁵/5! − x⁷/7! + …            모든 x에서 수렴
ln(1 + x) = x − x²/2 + x³/3 − x⁴/4 + …               −1 < x ≤ 1 에서만 수렴
```

eˣ는 몇 번 미분해도 eˣ이고 e⁰ = 1이라 모든 계수가 1/k!이다. sin x는 미분할 때마다 sin → cos → −sin → −cos로 돌고, 0에서의 값이 0, 1, 0, −1이라 홀수 차 항만 남는다. 1편의 `sin(x)/x → 1`은 이 급수의 첫 항이 x라는 말과 같다.

## 1차 근사와 2차 근사
1차 테일러 다항식은 접선이고, 함수를 직선으로 바꾸는 **선형화**다. √4.1을 계산기 없이 구해 보자. f(x) = √x, a = 4로 두면 f(4) = 2이고, `f′(x) = 1/(2√x)`이므로 f′(4) = 1/4다. 한 번 더 미분하면 `f″(4) = −1/32`이다.
```text
1차:  √4.1 ≈ 2 + (1/4)·(0.1)                      = 2.025
2차:  √4.1 ≈ 2.025 + (−1/32)/2! · (0.1)²          = 2.02484375
참값: √4.1 = 2.0248456731…
```

1차 근사의 오차는 약 1.5 × 10⁻⁴이고, 2차 항을 더하면 약 1.9 × 10⁻⁶로 줄어든다. 2차 항은 함수가 접선에서 얼마나 휘어져 멀어지는지, 즉 **곡률**을 담는다. f″ > 0이면 곡선이 접선 위쪽으로 휘고(아래로 볼록), f″ < 0이면 아래쪽으로 휜다(위로 볼록). 9편에서 극소와 극대를 가르는 2차 조건이 바로 이것이다.

## 항을 늘리면 얼마나 정확해지나
```python
import math

def exp_taylor(x, n):            # 1 + x + x²/2! + … (n개 항)
    return sum(x ** k / math.factorial(k) for k in range(n))

def sin_taylor(x, n):            # x − x³/3! + x⁵/5! − … (n개 항)
    return sum((-1) ** k * x ** (2 * k + 1) / math.factorial(2 * k + 1) for k in range(n))

for n in [1, 2, 3, 5, 10]:
    print(f"항 {n:>2}개  e¹ 오차 {abs(exp_taylor(1, n) - math.e):.1e}"
          f"   sin(1) 오차 {abs(sin_taylor(1, n) - math.sin(1)):.1e}")
```
```text
항  1개  e¹ 오차 1.7e+00   sin(1) 오차 1.6e-01
항  2개  e¹ 오차 7.2e-01   sin(1) 오차 8.1e-03
항  3개  e¹ 오차 2.2e-01   sin(1) 오차 2.0e-04
항  5개  e¹ 오차 9.9e-03   sin(1) 오차 2.5e-08
항 10개  e¹ 오차 3.0e-07   sin(1) 오차 0.0e+00
```

x = 1에서 eˣ는 항 10개(9차)면 오차가 약 3 × 10⁻⁷이고, sin은 항 10개(19차)면 float64로는 참값과 구별되지 않는다. 분모의 k!이 분자의 xᵏ보다 훨씬 빨리 커지기 때문이다. 하지만 모든 급수가 이렇게 착하지는 않다.
```python
import math

def log1p_taylor(x, n):          # x − x²/2 + x³/3 − … (n개 항)
    return sum((-1) ** (k + 1) * x ** k / k for k in range(1, n + 1))

for x in [0.5, 2.0]:
    approx = [round(log1p_taylor(x, n), 4) for n in (5, 10, 20)]
    print(f"x = {x}: 참값 {math.log(1 + x):.4f}, 항 5·10·20개 {approx}")
```
```text
x = 0.5: 참값 0.4055, 항 5·10·20개 [0.4073, 0.4054, 0.4055]
x = 2.0: 참값 1.0986, 항 5·10·20개 [5.0667, -64.8254, -34359.7081]
```

ln(1 + x)는 x = 0.5에서 잘 수렴하지만, 수렴 범위 밖인 x = 2에서는 항을 늘릴수록 오히려 발산한다. 각 항 xᵏ/k에서 분모 k는 천천히 크는데 분자 2ᵏ은 빠르게 커지기 때문이다. 테일러 근사는 기준점 a 근처에서 믿을 수 있는 도구이고, 얼마나 멀리까지 믿을 수 있는지는 함수마다 다르다.

## 컴퓨터는 sin을 어떻게 계산할까
CPU가 직접 하는 일은 덧셈, 곱셈 같은 기본 연산이다. 그래서 수학 라이브러리는 sin, exp, log를 다항식 계산으로 바꾼다. 일반적으로는 먼저 주기성 같은 성질을 이용해 입력을 0 근처의 좁은 구간으로 옮기고, 그 구간에서 오차가 아주 작은 다항식으로 계산한다. 실제로 쓰는 다항식은 테일러 다항식 그대로가 아니라 구간 전체의 최대 오차가 작아지도록 계수를 다듬은 것인 경우가 많지만, "좁은 구간에서는 다항식으로 충분하다"는 발상은 테일러 급수와 같다. 위의 실험에서 x = 1처럼 0에 가까운 입력은 항 몇 개로 충분했다는 점을 떠올리면 된다.

## 어디에 쓰이나
- 10편 「경사 하강법의 수학」: `f(θ + Δ) ≈ f(θ) + ∇f(θ)·Δ`라는 1차 근사에서 "기울기 반대 방향으로 조금 움직이면 값이 준다"는 경사 하강법이 유도되고, 학습률이 너무 크면 이 근사가 깨진다.
- AI 기초 1편 「딥러닝: 특징까지 스스로 배우는 머신러닝」: 경사 하강법 `θ ← θ − η·∇L(θ)`은 손실을 현재 위치에서 1차 근사한 평면을 믿고 짧게 한 걸음 내딛는 것이다.
- 9편 「최적화: 극값과 볼록 함수」: 2차 항의 부호(1변수는 f″, 다변수는 헤시안)가 극소인지 극대인지를 판정하는 2차 조건이 된다.

## 정리
- 테일러 급수는 a에서의 값과 도함수들로 함수를 f(a) + f′(a)(x − a) + f″(a)/2!·(x − a)² + … 꼴의 다항식으로 근사한다.
- 1차 근사는 접선(선형화), 2차 항은 곡률이며, 항을 늘릴수록 a 근처에서 더 정확해진다.
- eˣ와 sin x는 모든 x에서 수렴하지만, ln(1 + x)는 −1 < x ≤ 1에서만 수렴하므로 근사를 믿을 수 있는 범위를 따져야 한다.
