## 리만 합: 잘게 잘라 더하기
2편의 낙하하는 공은 t초일 때 속도가 `v(t) = 10t`m/s였다. 0초에서 2초까지 떨어진 거리는 얼마일까? 속도가 일정하면 속도 × 시간이지만, 속도는 계속 변한다. 그래서 시간을 잘게 나눈다. 짧은 구간 Δt 동안은 속도가 거의 일정하다고 보고 `v(tᵢ) · Δt`를 모두 더하면 거리의 근삿값이 된다. 이것이 **리만 합**이다. 그래프로 보면 v(t) 아래를 폭 Δt인 직사각형으로 채운 넓이다.

구간을 n개로 나누고 n → ∞(조각의 폭 → 0)으로 보낸 극한이 **정적분**이다.
```text
∫ₐᵇ f(x) dx = lim(n→∞) Σᵢ f(xᵢ) · Δx,     Δx = (b − a)/n
```

∫는 합(Sum)의 S를 길게 늘인 기호이고, dx는 "아주 얇은 폭"을 뜻한다. f가 음수인 구간의 넓이는 빼는 것으로 센다.

## 미적분학의 기본 정리
넓이를 매번 극한으로 구하기는 힘들다. 다행히 놀라운 연결이 있다. a부터 x까지의 넓이를 x의 함수 `A(x) = ∫ₐˣ f(t) dt`로 보자. x를 h만큼 늘리면 폭 h, 높이 약 f(x)인 띠만큼 넓이가 늘어나므로 `(A(x + h) − A(x)) / h ≈ f(x)`다. h → 0이면 다음 두 결과를 얻는다.
```text
1) A′(x) = f(x)                      누적한 넓이를 미분하면 원래 함수
2) ∫ₐᵇ f(x) dx = F(b) − F(a)         F′ = f 인 함수 F 하나만 찾으면 된다
```

이것이 **미적분학의 기본 정리**다. 미분(순간 변화율)과 적분(누적)은 서로 역연산이다. 낙하 거리 문제에서 `(5t²)′ = 10t`이므로 `∫₀² 10t dt = 5·2² − 5·0² = 20`m다. 2편의 위치 함수 s(t) = 5t²가 그대로 돌아왔다. 속도를 누적하면 위치가 되고, 위치를 미분하면 속도가 된다.

## 부정적분: 미분을 거꾸로
F′ = f인 F를 f의 **부정적분**(원시함수)이라 하고 `∫ f(x) dx = F(x) + C`로 쓴다. 상수는 미분하면 사라지므로 어떤 상수 C든 붙을 수 있다는 뜻이다. 3·4편의 미분 규칙을 거꾸로 읽으면 된다.

| f(x) | ∫ f(x) dx |
|---|---|
| xⁿ (n ≠ −1) | xⁿ⁺¹/(n + 1) + C |
| 1/x | ln∣x∣ + C |
| eˣ | eˣ + C |
| cos x | sin x + C |

미분은 규칙만 따르면 언제나 계산되지만, 부정적분은 식으로 구할 수 없는 경우가 많다. 정규 분포의 밀도에 들어 있는 `e^(−x²/2)`의 부정적분은 기본 함수로 쓸 수 없는 대표적인 예다. 그럴 때는 수치 적분을 쓴다.

## 사다리꼴 공식: 수치 적분
리만 합은 각 조각을 직사각형으로 보지만, 조각의 양 끝을 직선으로 이어 사다리꼴로 보면 훨씬 정확해진다. 답을 아는 `∫₀¹ x² dx = 1/3`(F(x) = x³/3)으로 비교해 보자.
```python
def left_riemann(f, a, b, n):
    dx = (b - a) / n
    return sum(f(a + i * dx) for i in range(n)) * dx

def trapezoid(f, a, b, n):
    dx = (b - a) / n
    inner = sum(f(a + i * dx) for i in range(1, n))
    return (f(a) / 2 + inner + f(b) / 2) * dx

f = lambda x: x ** 2              # ∫₀¹ x² dx = 1/3
for n in [4, 16, 64, 256]:
    r, t = left_riemann(f, 0, 1, n), trapezoid(f, 0, 1, n)
    print(f"n={n:<4} 리만 오차 {abs(r - 1/3):.2e}  사다리꼴 오차 {abs(t - 1/3):.2e}")
```
```text
n=4    리만 오차 1.15e-01  사다리꼴 오차 1.04e-02
n=16   리만 오차 3.06e-02  사다리꼴 오차 6.51e-04
n=64   리만 오차 7.77e-03  사다리꼴 오차 4.07e-05
n=256  리만 오차 1.95e-03  사다리꼴 오차 2.54e-06
```

구간 수를 4배로 늘릴 때마다 리만 합의 오차는 약 1/4로, 사다리꼴의 오차는 약 1/16로 준다. 오차가 각각 1/n과 1/n²에 비례하기 때문이다. 같은 계산량이라면 조각의 모양을 잘 고르는 쪽이 압도적으로 유리하다. 과학 계산 라이브러리는 이보다 정교한 방법을 쓰지만 "잘게 잘라 더한다"는 발상은 같다.

## 확률 밀도와 기댓값
연속 확률 변수는 한 점의 확률이 0이고, 확률은 **확률 밀도 함수** p(x) 아래의 넓이로 주어진다. `P(a ≤ X ≤ b) = ∫ₐᵇ p(x) dx`이고, 전체 넓이는 1이어야 한다. 이산 분포의 기댓값 `Σ x·p(x)`도 합이 적분으로 바뀌어 `E[X] = ∫ x·p(x) dx`가 된다. 구간 [0, 1]에서 `p(x) = 2x`인 분포로 확인해 보자. 손으로 계산하면 `∫₀¹ 2x dx = 1`, `∫₀¹ x·2x dx = 2/3`이다.
```python
import math
# 앞의 trapezoid 함수를 이어서 쓴다

p = lambda x: 2 * x                                  # [0, 1]에서의 밀도
print(trapezoid(p, 0, 1, 1000))                      # 전체 넓이: 1.0
print(trapezoid(lambda x: x * p(x), 0, 1, 1000))     # 기댓값: 0.6666669999999999

normal = lambda x: math.exp(-x * x / 2) / math.sqrt(2 * math.pi)   # 표준 정규 분포
print(trapezoid(normal, -10, 10, 1000))                            # 0.9999999999999989
print(trapezoid(lambda x: x * x * normal(x), -10, 10, 1000))       # E[X²]: 0.9999999999999999
```

기댓값은 2/3과 약 3 × 10⁻⁷ 차이로 맞는다. 정규 분포 밀도는 부정적분을 식으로 쓸 수 없지만, 수치 적분으로 전체 넓이가 1이고 `E[X²]`(평균이 0이므로 분산)이 1임을 확인할 수 있다. 기본 정리 덕분에 누적 분포 함수 `F(x) = P(X ≤ x)`를 미분하면 밀도 p(x)가 된다는 관계도 바로 나온다. 분포 자체는 확률과 분포 7편 「연속 분포와 확률 밀도 함수」와 확률과 분포 8편 「정규 분포: 종 모양 곡선의 정체」에서 다룬다.

## 정리
- 정적분은 리만 합의 극한, 즉 얇은 조각들의 합이며 그래프 아래의 넓이이자 변화율의 누적이다.
- 미적분학의 기본 정리: 누적한 넓이를 미분하면 원래 함수이고, ∫ₐᵇ f dx = F(b) − F(a)다.
- 식으로 풀 수 없는 적분은 사다리꼴 같은 수치 적분으로 구하며, 구간을 늘리면 오차가 1/n²로 준다.
- 확률 밀도의 전체 넓이는 1이고, 기댓값은 E[X] = ∫ x·p(x) dx다.
