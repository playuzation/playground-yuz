# [미적분 10/10] 경사 하강법의 수학

> **한 줄 요약** — 경사 하강법은 1차 테일러 근사에서 "기울기의 반대 방향으로 조금 가면 값이 준다"는 사실을 이용해 θ ← θ − η·∇f를 반복하는 방법이며, 학습률 선택, 미니배치, 모멘텀, Adam은 모두 이 한 걸음을 더 잘 내딛기 위한 장치다.

## 이 글에서 다루는 것
- 1차 테일러 근사로 경사 하강법 유도하기
- 학습률: 수렴, 진동, 발산
- 확률적 경사 하강법과 미니배치
- 모멘텀: 좁은 골짜기를 빠르게 지나기
- Adam: 기울기의 1차·2차 모멘트

## 왜 기울기의 반대 방향인가
현재 위치 θ에서 작은 걸음 Δ를 내디디면 함숫값은 6편의 1차 테일러 근사로 어림할 수 있다.
```text
f(θ + Δ) ≈ f(θ) + ∇f(θ) · Δ
```

값을 줄이려면 `∇f(θ) · Δ`가 음수여야 한다. 걸음의 길이를 고정하면 이 내적이 가장 작은 방향은 ∇f와 정반대 방향이다(7편: 방향 도함수 ‖∇f‖·cos φ는 φ = 180°에서 최소). 그래서 Δ = −η·∇f(θ)로 고른다.
```text
θ ← θ − η·∇f(θ)
f(θ − η·∇f) ≈ f(θ) − η·‖∇f(θ)‖²   ≤ f(θ)
```

기울기가 0이 아닌 한, η가 충분히 작으면 값은 반드시 줄어든다. 이 η가 **학습률**이다. "충분히 작으면"이 핵심 단서다. 1차 근사는 가까운 곳에서만 맞으므로, 걸음이 크면 무시했던 2차 항(곡률)이 끼어든다.

## 학습률: 수렴, 진동, 발산
`f(x) = x²`에서 시작점 x = 1, 학습률 세 가지를 비교해 보자. f′(x) = 2x이므로 갱신식은 `x ← x − η·2x = (1 − 2η)·x`다.
```python
for lr in [0.1, 0.9, 1.1]:
    x, xs = 1.0, []
    for _ in range(10):
        x = x - lr * 2 * x            # f(x) = x², f′(x) = 2x
        xs.append(round(x, 3))
    print(f"η = {lr}: {xs[:4]} … {xs[-1]}")
```
```text
η = 0.1: [0.8, 0.64, 0.512, 0.41] … 0.107
η = 0.9: [-0.8, 0.64, -0.512, 0.41] … 0.107
η = 1.1: [-1.2, 1.44, -1.728, 2.074] … 6.192
```

| η | 1 − 2η | 결과 |
|---|---|---|
| 0.1 | 0.8 | 0을 향해 꾸준히 수렴 |
| 0.9 | −0.8 | 부호를 바꾸며 진동하면서 수렴 |
| 1.1 | −1.2 | 진동하며 발산 |

η = 0.1과 0.9는 10걸음 뒤 같은 크기(0.107)에 도달하지만, 0.9는 골짜기 양쪽 벽을 오가며 내려간다. η = 1.1은 매번 골짜기를 넘어 더 높은 반대편에 떨어진다. 일반적으로 곡률(f″, 다변수에서는 헤시안의 가장 큰 고유값)이 L이면 η < 2/L이어야 수렴한다. x²은 f″ = 2라서 η < 1이 경계다. 실제 신경망은 곡률을 미리 알 수 없으므로 학습률을 실험으로 고르고, 학습이 진행되면서 학습률을 줄여 가는 스케줄을 흔히 쓴다.

## 확률적 경사 하강법
손실은 보통 데이터 N개에 대한 평균 `L(θ) = (1/N) Σᵢ ℓᵢ(θ)`이므로, 기울기도 데이터별 기울기의 평균이다. N이 수백만이면 한 걸음마다 전체를 계산하기에는 너무 비싸다. **확률적 경사 하강법**(SGD)은 무작위로 뽑은 B개, 즉 **미니배치**의 평균 기울기로 대신한다.
```text
g = (1/B) Σ ∇ℓᵢ(θ)   (i는 미니배치에 뽑힌 데이터)        E[g] = ∇L(θ)
```

무작위 표본의 평균이므로 기댓값은 전체 기울기와 같고(편향 없음), 배치가 클수록 흔들림(분산)이 대략 1/B에 비례해 줄어든다. 확률과 분포 10편 「큰 수의 법칙과 중심 극한 정리」의 내용 그대로다. 한 걸음은 부정확하지만 훨씬 싸서 같은 시간에 훨씬 많이 걸을 수 있고, 약간의 잡음은 안장점이나 얕은 지역 최소(9편)에서 빠져나오는 데 도움이 되기도 한다.

## 모멘텀: 좁은 골짜기를 빠르게
7편에서 본 것처럼 방향마다 가파른 정도가 크게 다르면 문제가 생긴다. `f(x, y) = x² + 100y²`는 y 방향 곡률이 200이라 η < 2/200 = 0.01이어야 발산하지 않는데, 그 작은 학습률로는 완만한 x 방향을 따라 내려가는 데 한참 걸린다. **모멘텀**은 기울기를 누적한 "속도" v로 움직인다. 매번 부호가 바뀌는 y 방향 기울기는 누적하면 서로 상쇄되고, 꾸준히 같은 방향인 x 방향 기울기는 쌓여서 가속된다. 언덕을 굴러 내려가는 공의 관성과 같다.
```python
import numpy as np

grad = lambda p: np.array([2 * p[0], 200 * p[1]])    # f(x, y) = x² + 100y²: 좁고 긴 골짜기
f = lambda p: p[0]**2 + 100 * p[1]**2

def steps_to_converge(beta, lr=0.009):
    p, v = np.array([10.0, 1.0]), np.zeros(2)
    for t in range(1, 10_000):
        v = beta * v + grad(p)            # 모멘텀: 기울기를 누적한 "속도"
        p = p - lr * v                    # beta = 0 이면 그냥 경사 하강법
        if f(p) < 1e-6:
            return t

print("경사 하강법:", steps_to_converge(beta=0.0))     # 508
print("모멘텀(β=0.9):", steps_to_converge(beta=0.9))   # 160
```

같은 학습률에서 모멘텀(β = 0.9)은 약 3분의 1의 걸음으로 목표에 도착했다.

## Adam: 파라미터마다 보폭을 맞추기
**Adam**은 모멘텀에 "파라미터마다 다른 보폭"을 더한 방법으로, 킹마와 바의 논문 「Adam: A Method for Stochastic Optimization」에서 제안되어 지금 가장 널리 쓰이는 옵티마이저 중 하나가 되었다. 파라미터마다 기울기 g의 이동 평균 두 가지를 기억한다.
```text
m ← β₁·m + (1 − β₁)·g          1차 모멘트: 기울기의 평균 (모멘텀 역할)
v ← β₂·v + (1 − β₂)·g²         2차 모멘트: 기울기 제곱의 평균 (크기 추정)
m̂ = m/(1 − β₁ᵗ),  v̂ = v/(1 − β₂ᵗ)      0에서 시작한 탓에 생기는 편향 보정
θ ← θ − η · m̂ / (√v̂ + ε)
```

기본값은 흔히 β₁ = 0.9, β₂ = 0.999다. m̂/√v̂는 "기울기 ÷ 기울기의 전형적인 크기"라서, 기울기가 늘 큰 파라미터와 늘 작은 파라미터가 비슷한 보폭으로 움직인다. 위의 좁은 골짜기처럼 방향마다 기울기 크기가 다른 문제를 자동으로 보정하는 셈이다. 대신 파라미터 하나마다 m과 v 두 값을 더 저장해야 한다.

## 어디에 쓰이나
- AI 기초 1편 「딥러닝: 특징까지 스스로 배우는 머신러닝」: `θ ← θ − η·∇L(θ)`가 이 글에서 유도한 식이고, XOR 예제의 `param -= 0.5 * grad`는 학습률 0.5로 전체 데이터 4개의 기울기를 쓰는 경사 하강법이다.
- AI 기초 4편 「컴퓨터 사이언스로 보는 AI 모델: 텐서, 연산, 메모리」: Adam은 파라미터마다 m과 v를 저장하므로 FP32라면 파라미터당 8바이트가 옵티마이저 상태로 더 들고, 이것이 "학습에는 파라미터당 약 16바이트"라는 계산의 큰 부분을 차지한다.
- 확률과 분포 10편 「큰 수의 법칙과 중심 극한 정리」: 미니배치 기울기가 전체 기울기의 편향 없는 추정값이고 배치가 클수록 덜 흔들리는 이유를 설명한다.

## 정리
- 1차 테일러 근사에서 f(θ − η·∇f) ≈ f(θ) − η·‖∇f‖²이므로, 작은 η로 기울기 반대 방향으로 가면 값이 준다.
- 학습률이 곡률에 비해 크면 진동하거나 발산한다(x²에서는 η < 1).
- SGD는 미니배치로 기울기를 싸게 추정하고, 모멘텀은 기울기를 누적해 좁은 골짜기를 빠르게 지나며, Adam은 1·2차 모멘트로 파라미터마다 보폭을 맞춘다.
