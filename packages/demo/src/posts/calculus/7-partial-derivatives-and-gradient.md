# [미적분 7/10] 편미분과 그래디언트

> **한 줄 요약** — 입력이 여러 개인 함수는 변수 하나만 움직이고 나머지를 고정해 미분(편미분)하며, 편미분을 모은 벡터인 그래디언트 ∇f는 함수가 가장 가파르게 증가하는 방향과 그 기울기를 알려 준다.

## 이 글에서 다루는 것
- 다변수 함수와 등고선
- 편미분: 다른 변수를 고정하고 미분하기
- 그래디언트 ∇f와 방향 도함수
- 그래디언트가 가장 가파른 방향이고 등고선과 수직인 이유
- f(x, y) = x² + 3y²로 수치 확인하기

## 입력이 여러 개인 함수
신경망의 손실은 파라미터 수백만 개의 함수 `L(θ₁, θ₂, …, θₙ)`이다. 이런 **다변수 함수**를 이해하기 위해 가장 작은 예 `f(x, y) = x² + 3y²`를 쓰자. 입력은 평면 위의 점 (x, y)이고 출력은 높이라서, 그래프는 원점이 가장 낮은 그릇 모양의 곡면이다.

높이가 같은 점들을 이은 곡선이 **등고선**이다. 지도의 등고선과 같다. f(x, y) = 13인 등고선은 x² + 3y² = 13인 타원이고 점 (1, 2)를 지난다. y의 계수가 3이라 타원은 y 방향으로 납작하다. 같은 거리를 움직여도 y 방향으로 움직일 때 높이가 더 빨리 변한다는 뜻이다.

## 편미분: 하나만 움직이기
변수가 여럿이면 "입력을 조금 바꾼다"의 방향도 여럿이다. 가장 단순한 방법은 한 변수만 움직이고 나머지는 상수로 고정하는 것이다. 이것이 **편미분**이고 기호 ∂를 쓴다.
```text
∂f/∂x = lim(h→0) [f(x + h, y) − f(x, y)] / h      y를 상수로 보고 x로 미분

f(x, y) = x² + 3y²   →   ∂f/∂x = 2x,   ∂f/∂y = 6y
```

∂f/∂x를 구할 때 3y²은 상수라서 미분하면 0이 된다. 계산 규칙은 1변수 미분(3편)과 똑같다.

## 그래디언트: 편미분을 모은 벡터
모든 편미분을 벡터로 모은 것을 **그래디언트**라 하고 ∇f(나블라 f)로 쓴다.
```text
∇f(x, y) = (∂f/∂x, ∂f/∂y) = (2x, 6y)
점 (1, 2)에서  ∇f = (2, 12)
```

그래디언트는 점마다 하나씩 정해지는 벡터이고, 두 가지 중요한 성질이 있다.

### 방향 도함수와 가장 가파른 방향
축 방향이 아닌 임의의 방향 u(길이 1인 벡터)로 움직일 때의 기울기를 **방향 도함수** Dᵤf라 한다. 아주 가까이서 보면 곡면은 평면처럼 보이므로(6편의 1차 근사), 기울기는 축 방향 기울기들을 u의 성분만큼 섞은 것, 즉 내적이 된다.
```text
Dᵤf = ∇f · u = ‖∇f‖ · ‖u‖ · cos φ = ‖∇f‖ · cos φ      φ: ∇f와 u 사이의 각
```

cos φ는 φ = 0°에서 최대 1, φ = 180°에서 최소 −1, φ = 90°에서 0이다. 따라서 다음이 성립한다.
- u가 ∇f와 같은 방향일 때 기울기가 최대 ‖∇f‖다. 즉 그래디언트는 가장 가파르게 올라가는 방향을 가리킨다.
- 정반대 방향 −∇f가 가장 가파르게 내려가는 방향이고, 그때 기울기는 −‖∇f‖다.
- ∇f에 수직인 방향으로는 기울기가 0이다. 높이가 변하지 않는 방향이 바로 등고선 방향이므로, 그래디언트는 등고선과 수직이다.

## 숫자로 확인하기
```python
import numpy as np

def f(p):
    x, y = p
    return x ** 2 + 3 * y ** 2

def numerical_grad(f, p, h=1e-6):
    g = np.zeros_like(p)
    for i in range(len(p)):
        e = np.zeros_like(p)
        e[i] = h                         # i번째 변수만 살짝 움직인다
        g[i] = (f(p + e) - f(p - e)) / (2 * h)
    return g

p = np.array([1.0, 2.0])
g = numerical_grad(f, p)
print(g, np.array([2 * p[0], 6 * p[1]]))     # 수치 vs 해석적 (2x, 6y)

# 방향 도함수 D_u f = ∇f · u 를 1° 간격 360개 방향에서 재 본다
deg = np.arange(360)
u = np.stack([np.cos(np.radians(deg)), np.sin(np.radians(deg))], axis=1)
slopes = u @ g
print(deg[slopes.argmax()], np.degrees(np.arctan2(g[1], g[0])).round(1))
print(slopes.max().round(2), np.linalg.norm(g).round(2))
print(deg[slopes.argmin()], slopes.min().round(2))  # 가장 가파르게 내려가는 방향

t = np.array([g[1], -g[0]]) / np.linalg.norm(g)    # ∇f에 수직 = 등고선 방향
print(abs(t @ g))
```
```text

81 80.5
12.17 12.17
261 -12.17
8.705851756093729e-17
```

변수마다 2편의 중앙 차분을 한 번씩 적용한 수치 그래디언트가 해석적 결과 (2, 12)와 일치한다. 360개 방향 중 기울기가 가장 큰 방향은 81°로, ∇f의 방향 80.5°와 1° 간격의 한계 안에서 같고, 그때의 기울기는 ‖∇f‖ = √148 ≈ 12.17이다. 정반대인 261°에서 가장 가파르게 내려가고, ∇f에 수직인 등고선 방향의 기울기는 10⁻¹⁷ 수준, 즉 부동소수점 오차만 남은 0이다.

그래디언트 (2, 12)는 y 성분이 x 성분의 6배다. 앞서 본 대로 이 점에서는 y 방향이 훨씬 가파르기 때문이다. 이렇게 방향마다 가파른 정도가 크게 다른 "좁고 긴 골짜기"는 경사 하강법을 느리게 만드는 원인이 되며, 10편에서 다시 만난다.

## 정리
- 편미분은 다른 변수를 상수로 고정하고 한 변수로만 미분한 것이고, 그래디언트 ∇f는 편미분을 모은 벡터다.
- 방향 u로의 기울기는 ∇f · u이므로, ∇f 방향이 가장 가파른 오르막, −∇f 방향이 가장 가파른 내리막이다.
- 그래디언트는 등고선과 수직이며, f(x, y) = x² + 3y²의 (1, 2)에서 ∇f = (2, 12)를 수치 미분으로 확인했다.
