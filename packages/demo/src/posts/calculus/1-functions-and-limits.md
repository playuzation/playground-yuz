## 함수, 그리고 미적분의 질문
**함수** f는 입력 x마다 출력 f(x)를 정확히 하나씩 정하는 규칙이다. 파이썬의 `def f(x): return x ** 2`처럼 같은 입력에 늘 같은 출력을 내는 순수 함수를 떠올리면 된다. 미적분이 묻는 질문은 하나로 모인다. "입력을 아주 조금 바꾸면 출력은 얼마나 바뀌는가?" 이 질문에 답하려면 먼저 "아주 조금"을 정확하게 말하는 방법이 필요하다. 그것이 **극한**이다.

## 극한: 가까이 가면 어디에 닿는가
`f(x) = (x² − 1)/(x − 1)`은 x = 1에서 0/0이 되어 값이 없다. 그래도 1 근처에서는 얼마든지 계산할 수 있다.

| x | f(x) |
|---|---|
| 0.9 | 1.9 |
| 0.99 | 1.99 |
| 0.999 | 1.999 |
| 1.001 | 2.001 |
| 1.01 | 2.01 |

x가 1에 다가갈수록 f(x)는 2에 다가간다. 이를 `lim(x→1) f(x) = 2`라고 쓰고 "x가 1로 갈 때 f(x)의 극한은 2"라고 읽는다. 핵심은 x = 1에서의 값이 아니라 1 근처의 값들이 향하는 곳을 묻는다는 점이다. 실제로 x ≠ 1이면 분자를 인수분해해 `f(x) = x + 1`이 되므로 2가 나오는 것이 당연하다.

### 정확한 정의: ε-δ 맛보기
"한없이 가까이"는 다음과 같이 정확하게 쓸 수 있다.
```text
lim(x→a) f(x) = L 이란,
모든 ε > 0 에 대해 어떤 δ > 0 이 있어서
0 < ∣x − a∣ < δ 이면 ∣f(x) − L∣ < ε 이 된다는 뜻이다.
```

일종의 게임이다. 상대가 허용 오차 ε을 아무리 작게 불러도, 나는 "x를 a에서 δ 안쪽으로만 가져오면 f(x)는 L에서 ε 안쪽에 있다"는 δ를 늘 내놓을 수 있어야 한다. 위의 예에서는 `∣f(x) − 2∣ = ∣x − 1∣`이므로 상대가 ε = 0.001을 부르면 δ = 0.001로 답하면 된다. 조건의 `0 < ∣x − a∣` 부분은 x = a 자체는 따지지 않는다는 뜻이다. 그래서 f(1)이 정의되지 않아도 극한은 존재한다.

## 좌극한, 우극한, 연속
x가 a보다 작은 쪽에서 다가갈 때의 극한을 **좌극한**(`x → a⁻`), 큰 쪽에서 다가갈 때의 극한을 **우극한**(`x → a⁺`)이라고 한다. 극한이 존재하려면 둘이 같아야 한다. `g(x) = ∣x∣/x`를 보자. x가 음수면 g(x) = −1, 양수면 g(x) = 1이므로 좌극한은 −1, 우극한은 1이다. 둘이 다르니 x = 0에서 g의 극한은 없다. 이 함수는 2편에서 ∣x∣의 미분을 따질 때 그대로 다시 나온다.

함수 f가 x = a에서 **연속**이라는 것은 세 가지가 모두 성립한다는 뜻이다. f(a)가 정의되어 있고, `lim(x→a) f(x)`가 존재하며, 둘이 같다. 직관적으로는 그 점 근처의 그래프를 펜을 떼지 않고 그릴 수 있다는 뜻이다.

| 함수와 점 | 연속? | 이유 |
|---|---|---|
| (x² − 1)/(x − 1), x = 1 | 아니오(구멍) | f(1)이 없다 |
| ∣x∣/x, x = 0 | 아니오(점프) | 좌극한 −1 ≠ 우극한 1 |
| max(0, x), x = 0 | 예 | 좌우 극한 0 = f(0) |

다항식, sin, cos, eˣ는 모든 점에서 연속이다. 마지막 줄의 `max(0, x)`는 신경망의 ReLU인데, 연속이지만 x = 0에서 꺾여 있다. 연속인 것과 매끄러운(미분 가능한) 것은 다르며, 이 차이는 2편에서 다룬다.

## 무한대로 갈 때
`lim(x→∞) 1/x = 0`은 x가 커질수록 1/x가 0에 얼마든지 가까워진다는 뜻이고, `lim(x→0⁺) 1/x = ∞`는 값이 한없이 커진다는 뜻이다. ∞는 숫자가 아니라 "어떤 수보다도 커진다"는 상태를 가리키는 기호다. 끝없는 합도 극한으로 정의한다. 1/2 + 1/4 + 1/8 + …은 처음 n개의 합이 n → ∞일 때 다가가는 값, 즉 1이다. 이 생각은 6편의 테일러 급수로 이어진다.

## 유명한 두 극한을 숫자로 확인하기
```python
import math

# x → 0 일 때 sin(x)/x
for x in [0.1, 0.01, 0.001, 0.0001]:
    print(f"x = {x:<6}  sin(x)/x = {math.sin(x) / x:.10f}")

# n → ∞ 일 때 (1 + 1/n)ⁿ
for n in [1, 10, 100, 10_000, 1_000_000]:
    print(f"n = {n:<7}  (1 + 1/n)^n = {(1 + 1 / n) ** n:.10f}")
print(f"math.e       = {math.e:.10f}")
```
```text
x = 0.1     sin(x)/x = 0.9983341665
x = 0.01    sin(x)/x = 0.9999833334
x = 0.001   sin(x)/x = 0.9999998333
x = 0.0001  sin(x)/x = 0.9999999983
n = 1        (1 + 1/n)^n = 2.0000000000
n = 10       (1 + 1/n)^n = 2.5937424601
n = 100      (1 + 1/n)^n = 2.7048138294
n = 10000    (1 + 1/n)^n = 2.7181459268
n = 1000000  (1 + 1/n)^n = 2.7182804691
math.e       = 2.7182818285
```

- `sin(x)/x → 1`: 0/0 꼴이지만 극한은 1이다. 라디안으로 잰 각이 0 근처면 `sin x ≈ x`라는 뜻이다. (sin x)′ = cos x라는 사실이 이 극한에서 유도되고, 6편에서 sin의 다항식 근사의 첫 항이 x인 것으로 다시 나온다.
- `(1 + 1/n)ⁿ → e`: 연 이율 100%를 n번 나눠 복리로 받으면 1원이 (1 + 1/n)ⁿ원이 된다. 잘게 나눌수록 늘어나지만 한없이 늘지는 않고 2.71828…에 다가간다. 이 수가 자연 상수 e이며, 4편 「지수 함수와 로그 함수」의 주인공이다.

## 컴퓨터는 극한을 흉내만 낸다
n을 더 키우면 이상한 일이 생긴다.
```python
>>> for n in [10**8, 10**12, 10**15, 10**16]:
...     print(n, (1 + 1 / n) ** n)
...
100000000 2.7182817983473577
1000000000000 2.7185234960372378
1000000000000000 3.035035206549262
10000000000000000 1.0
```

n이 커질수록 e에 가까워져야 하는데, 10¹²에서는 소수 넷째 자리부터 틀리고 10¹⁵에서는 3을 넘더니 10¹⁶에서는 1.0이 된다. float64는 유효숫자를 십진수로 15~16자리 정도만 저장하기 때문이다. 10¹⁵에서는 `1 + 10⁻¹⁵`가 가장 가까운 표현 가능한 수 `1 + 1.11 × 10⁻¹⁵`로 저장되어 결과가 `e^1.11 ≈ 3.035`가 되고, 10¹⁶에서는 `1 + 10⁻¹⁶`이 1과 구별되지 않는다. 수학의 극한은 "한없이" 다가가지만 컴퓨터는 유한한 자릿수에서 멈춘다. 2편의 수치 미분에서도 같은 벽을 만난다.

## 정리
- 극한은 x = a에서의 값이 아니라, x가 a에 한없이 가까워질 때 f(x)가 향하는 값이다.
- 좌극한과 우극한이 같아야 극한이 존재하고, 극한값과 함숫값이 같으면 연속이다.
- sin(x)/x → 1, (1 + 1/n)ⁿ → e는 앞으로 미분과 지수 함수에서 다시 쓰인다.
- 부동소수점은 유효숫자가 유한해서, 컴퓨터는 극한을 어느 지점까지만 흉내 낼 수 있다.
