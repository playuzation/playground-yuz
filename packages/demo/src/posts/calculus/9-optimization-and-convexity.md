# [미적분 9/10] 최적화: 극값과 볼록 함수

> **한 줄 요약** — 함수의 최솟값 후보는 기울기가 0인 점이고, 2차 도함수(헤시안)로 극소·극대·안장점을 가르며, 볼록 함수에서는 지역 최소가 곧 전역 최소라 최적화가 쉽지만 신경망의 손실은 볼록하지 않다.

## 이 글에서 다루는 것
- 극대·극소, 전역 최소와 지역 최소, 안장점
- 1차 조건: 기울기 = 0
- 2차 조건과 헤시안
- 볼록 함수: 지역 최소 = 전역 최소
- 신경망 손실이 비볼록이라는 것의 의미

## 최적화: 가장 낮은 곳 찾기
머신러닝의 학습은 손실 L(θ)를 가장 작게 만드는 θ를 찾는 **최적화** 문제다. 용어부터 정리하자.
- **전역 최소**: 정의역 전체에서 가장 작은 값.
- **지역 최소**(극소): 가까운 주변의 점들보다만 작은 값. 극대도 마찬가지로 정의한다.
- **안장점**: 어떤 방향으로는 올라가고 어떤 방향으로는 내려가는 점. 말안장의 가운데처럼 기울기는 0이지만 극값이 아니다.

## 1차 조건: 기울기가 0인 곳
미분 가능한 함수가 어떤 점에서 극값을 가지면 그 점의 접선은 수평이다. 즉 `f′(x) = 0`이고, 이것을 **1차 조건**이라 한다. 극소 직전에는 내려가다가(f′ < 0) 직후에는 올라가므로(f′ > 0) 그 사이에서 0을 지나기 때문이다. 다변수에서는 모든 편미분이 0, 즉 `∇f = 0`이다. 기울기가 0인 점을 **임계점**이라 한다.

거꾸로는 성립하지 않는다는 점을 조심해야 한다. `f(x) = x³`은 f′(0) = 0이지만 x = 0은 극값이 아니다. 임계점은 후보일 뿐이고, 무엇인지는 더 따져 봐야 한다.

통계학의 최대 우도 추정이 이 방법을 그대로 쓴다. 동전을 10번 던져 앞면이 7번 나왔다면 로그 가능도는 `ℓ(p) = 7 ln p + 3 ln(1 − p)`이고, `ℓ′(p) = 7/p − 3/(1 − p) = 0`을 풀면 p = 0.7이다. 4편의 (ln x)′ = 1/x와 3편의 연쇄 법칙만으로 계산된다. 통계적 의미는 통계학 4편 「최대 우도 추정」에서 다룬다.

## 2차 조건과 헤시안
임계점이 극소인지 극대인지는 휘어진 방향, 즉 2차 도함수로 가린다. 임계점에서는 f′(a) = 0이므로 6편의 2차 근사가 `f(x) ≈ f(a) + f″(a)/2 · (x − a)²`가 된다.
- f″(a) > 0: 위로 열린 포물선 모양이라 극소다.
- f″(a) < 0: 아래로 열린 모양이라 극대다.
- f″(a) = 0: 이것만으로는 판정할 수 없다(x³의 x = 0).

다변수에서는 2차 편미분을 모은 행렬인 **헤시안** H를 쓴다. `f(x, y) = x² + 3y²`이면 `H = [[2, 0], [0, 6]]`으로 모든 방향으로 위로 휘어 원점이 극소다. `f(x, y) = x² − y²`이면 `H = [[2, 0], [0, −2]]`로 x 방향은 위로, y 방향은 아래로 휘어 원점이 안장점이다. 일반적으로는 헤시안의 고유값이 모두 양수면 극소, 모두 음수면 극대, 부호가 섞여 있으면 안장점이다(선형대수 8편 「고유값과 고유벡터」).

1차·2차 조건을 코드로 적용해 보자. `f(x) = x⁴ − 3x² + x`는 골짜기가 둘인 함수다.
```python
import numpy as np

f   = lambda x: x**4 - 3 * x**2 + x
df  = lambda x: 4 * x**3 - 6 * x + 1      # f′
d2f = lambda x: 12 * x**2 - 6             # f″

# 1차 조건: f′(x) = 0 인 점(임계점)을 찾고, 2차 조건으로 분류한다
for x in sorted(np.roots([4, 0, -6, 1]).real):
    kind = "극소" if d2f(x) > 0 else "극대"
    print(f"x = {x:6.3f}  f(x) = {f(x):6.3f}  f″(x) = {d2f(x):6.2f}  → {kind}")

# 경사 하강법은 출발점에 따라 다른 골짜기에 도착한다
for x in [-2.0, 2.0]:
    start = x
    for _ in range(200):
        x -= 0.01 * df(x)
    print(f"출발 {start:+.0f} → 도착 x = {x:.3f}, f(x) = {f(x):.3f}")
```
```text
x = -1.301  f(x) = -3.514  f″(x) =  14.31  → 극소
x =  0.170  f(x) =  0.084  f″(x) =  -5.65  → 극대
x =  1.131  f(x) = -1.070  f″(x) =   9.35  → 극소
출발 -2 → 도착 x = -1.301, f(x) = -3.514
출발 +2 → 도착 x = 1.131, f(x) = -1.070
```

임계점 세 개 중 두 개가 극소, 하나가 극대다. 극소 중에서도 x = −1.301(f = −3.514)이 전역 최소이고, x = 1.131(f = −1.070)은 지역 최소일 뿐이다. 그런데 경사 하강법은 +2에서 출발하면 지역 최소에 도착해 멈춘다. 그 점에서도 기울기가 0이라, 기울기만 보는 방법으로는 더 깊은 골짜기가 있는지 알 수 없다.

## 볼록 함수: 지역 최소가 곧 전역 최소
**볼록 함수**는 그래프 위의 어떤 두 점을 이은 선분도 그래프 아래로 내려가지 않는 함수다.
```text
f(λa + (1 − λ)b) ≤ λ·f(a) + (1 − λ)·f(b)       모든 a, b와 0 ≤ λ ≤ 1에 대해
```

1변수에서는 모든 x에서 f″(x) ≥ 0이면 볼록이고, 다변수에서는 헤시안의 고유값이 모두 0 이상이면 볼록이다. x², eˣ, ∣x∣, ReLU가 볼록 함수다.

볼록 함수의 가장 중요한 성질은 **지역 최소가 곧 전역 최소**라는 것이다. 골짜기가 하나뿐이라 기울기를 따라 내려가기만 하면 가장 낮은 곳에 닿는다. 선형 회귀의 제곱 오차 손실이 대표적인 예이고, 위의 동전 예에서도 −ℓ(p)의 2차 도함수 `7/p² + 3/(1 − p)²`가 늘 양수라 볼록이므로 p = 0.7이 전역 최적이다.

## 신경망의 손실은 볼록하지 않다
신경망의 손실은 비선형 함수가 층층이 겹쳐 만들어지므로 볼록하지 않다(**비볼록**). 간단한 논증이 있다. 은닉 뉴런 두 개의 역할을 서로 바꾼 파라미터는 같은 함수를 나타내므로 손실도 같다. 최소점 하나를 찾으면 이렇게 뉴런을 바꾼 또 다른 최소점이 생기는데, 두 점의 중간(평균)은 보통 좋은 해가 아니다. 볼록 함수라면 두 최소점 사이의 선분 위가 모두 최소여야 하므로, 손실은 볼록일 수 없다.

그래서 위의 x⁴ 예처럼 출발점(초기화)에 따라 도착점이 달라질 수 있고, 전역 최소라는 보장도 없다. 그런데도 실제로는 잘 학습된다. 고차원에서는 기울기가 0인 점의 상당수가 지역 최소보다 안장점이라 빠져나갈 방향이 있고, 충분히 좋은 지역 최소가 많다는 관찰이 그 이유로 흔히 거론된다. 다만 이 부분은 아직 이론적으로 완전히 설명되지는 않았다.

## 정리
- 미분 가능한 함수의 극값은 기울기가 0인 임계점에서 생기지만, 임계점이 모두 극값은 아니다(안장점, x³).
- 2차 도함수나 헤시안의 부호로 극소·극대·안장점을 가린다.
- 볼록 함수는 지역 최소가 곧 전역 최소라 최적화가 쉽고, 신경망 손실은 비볼록이라 출발점에 따라 결과가 달라질 수 있다.
