# [오픈 웨이트 모델 1/5] 오픈 웨이트 모델의 표준 블록: 라마 3 해부

> **한 줄 요약** — 라마 3 8B는 Pre-RMSNorm, RoPE, GQA, SwiGLU, 편향 없는 선형 층으로 만든 디코더 블록 32개를 쌓은 모델이며, 공개된 설정값 몇 개만으로 파라미터 8,030,261,248개를 정확히 셀 수 있고, 이 블록이 이후 오픈 웨이트 모델들의 출발점이 된다.

## "오픈 웨이트"는 무엇을 공개한 것인가
**오픈 웨이트**(open weight) 모델은 학습이 끝난 가중치 파일을 누구나 내려받아 실행하고 미세 조정할 수 있게 공개한 모델이다. AI 기초 4편에서 본 것처럼 모델은 "파라미터 + 계산 그래프"이므로, 가중치와 구조 설정만 있으면 내 컴퓨터에서 그대로 돌릴 수 있다. 하지만 학습 데이터와 학습 코드는 대개 공개하지 않아서, 같은 모델을 처음부터 다시 만들 수는 없다.

**오픈 소스**(open source)는 더 넓은 요구다. 오픈 소스 이니셔티브(OSI)가 2024년 10월 발표한 오픈 소스 AI 정의는 가중치뿐 아니라 학습 코드와, 모델을 다시 만들 수 있을 만큼의 학습 데이터 정보까지 요구한다. 라이선스도 제각각이다. 미스트랄 7B, 믹스트랄, gpt-oss, Qwen3는 Apache 2.0으로 공개되었고, 라마 3는 월간 활성 사용자가 7억 명을 넘는 서비스는 메타의 별도 허가를 받아야 하는 등 조건이 붙은 자체 라이선스를 쓴다. 이 시리즈는 라이선스가 아니라 구조에 집중한다. 가중치가 공개된 덕분에 설정 파일과 코드로 내부를 정확히 들여다볼 수 있다.

## 라마 3 8B의 설정값
메타(Meta)가 2024년 4월 공개한 라마 3 8B의 설정 파일(config.json) 값은 다음과 같다. 필드 이름은 5편 「config.json으로 모델 구조 읽기」에서 자세히 다룬다.

| 항목 | 값 |
|---|---|
| 블록(층) 수 | 32 |
| 은닉 크기 d | 4,096 |
| 쿼리 헤드 / KV 헤드 | 32 / 8 |
| 헤드 차원 | 128 |
| FFN 은닉 크기 | 14,336 |
| 어휘 크기 | 128,256 |
| RoPE 기저 θ | 500,000 |
| 문맥 길이 | 8,192 |

뒤이어 나온 라마 3.1 8B도 블록 구조와 크기는 같고, RoPE 주파수를 조정하는 방식으로 문맥을 128K 토큰까지 늘렸다.

## 원조 트랜스포머에서 무엇이 바뀌었나
2017년 「Attention Is All You Need」의 트랜스포머와 비교하면 큰 틀(어텐션 + FFN + 잔차 연결)은 그대로이고 부품이 바뀌었다.

| 부품 | 2017 트랜스포머 | 라마 3 |
|---|---|---|
| 전체 구조 | 인코더-디코더 | 디코더 전용 |
| 정규화 | Post-LN, LayerNorm | Pre-LN, RMSNorm |
| FFN | ReLU, 4d | SwiGLU, 3.5d |
| 위치 정보 | 사인 위치 인코딩 | RoPE |
| 어텐션 | MHA | GQA (32 : 8) |
| 선형 층 편향 | 있음 | 없음 |

- 정규화: 서브층에 들어가기 전에 정규화하고(Pre-LN), 평균을 빼지 않는 RMSNorm을 쓴다. 깊은 모델이 안정적으로 학습되는 이유는 신경망 레이어 7편 「정규화 층: LayerNorm에서 RMSNorm까지」에서 다룬다.
- FFN: SwiGLU는 행렬이 3개라 은닉 크기를 4d보다 작게 잡는다. 14,336은 정확히 3.5d로, 파라미터를 4d FFN과 맞추는 기준값 8d/3 ≈ 10,923보다 크다. 신경망 레이어 8편 「피드포워드 층의 진화: GELU에서 SwiGLU까지」 참고.
- 위치 정보: 쿼리와 키를 위치에 비례하는 각도로 회전해 상대 위치를 내적에 담는다. 기저 θ를 라마 2의 10,000에서 500,000으로 키워 회전을 느리게 했고, 라마 3 논문은 이것이 긴 문맥을 다루는 데 도움이 된다고 설명한다. 어텐션 3편 「위치 정보: 사인 위치 인코딩에서 RoPE까지」 참고.
- 어텐션: 쿼리 헤드 4개가 KV 헤드 1개를 공유해 KV 캐시가 4분의 1로 준다. 토큰당 128KiB라는 계산은 어텐션 4편 「KV 캐시와 MQA·GQA·MLA」에 있다.
- 편향: 모든 선형 층이 `y = xW` 꼴이다. 신경망 레이어 1편 「선형 층: 모든 신경망의 기본 부품」 참고.

## 파라미터 80억 개 세기
설정값만으로 행렬 크기를 모두 알 수 있으니 파라미터 수도 정확히 나온다. 어텐션은 쿼리·출력 투영이 d × (32 × 128), 키·값 투영이 d × (8 × 128)이고, FFN은 d × 14,336 행렬 3개다.
```python
d, L, V = 4096, 32, 128256          # hidden_size, 층 수, 어휘 크기
h, kv, hd = 32, 8, 128              # 쿼리 헤드, KV 헤드, 헤드 차원
f = 14336                           # SwiGLU 은닉 크기

attn = d * (h * hd) + 2 * d * (kv * hd) + (h * hd) * d   # Wq, Wk·Wv, Wo
ffn = 3 * d * f                                          # W_gate, W_up, W_down
norm = 2 * d                                             # RMSNorm 게인 2개
block = attn + ffn + norm
emb = 2 * V * d                     # 입력 임베딩 + 출력 헤드(공유 안 함)
total = L * block + emb + d         # 마지막 RMSNorm 포함

print(f"어텐션 {attn:,} / FFN {ffn:,} / 블록 {block:,}")
print(f"블록 32개 {L * block / 1e9:.3f}B, 임베딩 {emb / 1e9:.3f}B")
print(f"전체 {total:,} ≈ {total / 1e9:.2f}B")
print(f"BF16 가중치 {total * 2 / 2**30:.1f} GiB")
```
```text
어텐션 41,943,040 / FFN 176,160,768 / 블록 218,112,000
블록 32개 6.980B, 임베딩 1.051B
전체 8,030,261,248 ≈ 8.03B
BF16 가중치 15.0 GiB
```

블록 하나는 어텐션 2.5d²와 FFN 10.5d², 합쳐 약 13d²다. 신경망 레이어 6편의 원조 블록(어텐션 4d² + FFN 8d² = 12d²)과 비교하면, GQA 덕분에 어텐션은 4d²에서 2.5d²로 줄고 SwiGLU 때문에 FFN은 8d²에서 10.5d²로 늘었다. 그래서 블록 파라미터의 약 81%가 FFN에 있다. 어휘가 128K로 커서 임베딩과 출력 헤드가 전체의 약 13%를 차지하는 것도 눈에 띈다. 두 행렬을 공유했다면(tied embedding) 약 7.50B였을 것이다.

## 토큰 하나가 블록을 지나는 순서
블록은 **잔차 스트림**(residual stream) 위에서 일한다. 토큰 벡터 x가 줄기처럼 흐르고, 각 서브층은 x의 정규화된 사본을 읽어 계산한 결과를 x에 더하기만 한다.
```text
x (토큰 벡터, d = 4096)
 ├→ RMSNorm → Wq·Wk·Wv → RoPE(q, k)
 │   → 인과 GQA 어텐션
 │   → Wo ─────────────────────┐
 + ←───────────────────────────┘
 ├→ RMSNorm → SiLU(x·Wg) ⊙ (x·Wu)
 │   → Wd ─────────────────────┐
 + ←───────────────────────────┘
 ↓ 32번 반복 → RMSNorm → 출력 헤드
```

같은 순서를 작은 크기(d = 16, 쿼리 헤드 4개, KV 헤드 2개)로 그대로 옮겨 보자. 끝에서는 마지막 토큰만 바꿔서, 인과 마스크 덕분에 앞 토큰들의 출력이 전혀 변하지 않는지 확인한다.
```python
import numpy as np

rng = np.random.default_rng(0)
d, h, kv, hd, f, n = 16, 4, 2, 4, 40, 5
W = {k: rng.normal(0, 0.2, s) for k, s in {
    "q": (d, h * hd), "k": (d, kv * hd), "v": (d, kv * hd),
    "o": (h * hd, d), "gate": (d, f), "up": (d, f), "down": (f, d)}.items()}

def rmsnorm(x, eps=1e-5):
    return x / np.sqrt((x**2).mean(-1, keepdims=True) + eps)  # 게인은 1로 둠

def rope(x, theta=500000.0):                 # x: (헤드, 토큰, hd)
    pos = np.arange(x.shape[1])[:, None]
    ang = pos * theta ** (-np.arange(0, hd, 2) / hd)
    c, s = np.cos(ang), np.sin(ang)
    x1, x2 = x[..., ::2], x[..., 1::2]
    out = np.empty_like(x)
    out[..., ::2], out[..., 1::2] = x1 * c - x2 * s, x1 * s + x2 * c
    return out

def block(x):
    a = rmsnorm(x)                                   # ① Pre-RMSNorm
    q = (a @ W["q"]).reshape(n, h, hd).transpose(1, 0, 2)
    k = (a @ W["k"]).reshape(n, kv, hd).transpose(1, 0, 2)
    v = (a @ W["v"]).reshape(n, kv, hd).transpose(1, 0, 2)
    q, k = rope(q), rope(k)                          # ② RoPE
    k, v = np.repeat(k, h // kv, 0), np.repeat(v, h // kv, 0)  # ③ GQA
    s = q @ k.transpose(0, 2, 1) / np.sqrt(hd)
    s += np.triu(np.full((n, n), -np.inf), 1)        # 인과 마스크
    p = np.exp(s - s.max(-1, keepdims=True))
    p /= p.sum(-1, keepdims=True)
    o = (p @ v).transpose(1, 0, 2).reshape(n, h * hd)
    x = x + o @ W["o"]                               # ④ 잔차
    b = rmsnorm(x)                                   # ⑤ Pre-RMSNorm
    g = b @ W["gate"]
    return x + ((g / (1 + np.exp(-g))) * (b @ W["up"])) @ W["down"]  # ⑥ SwiGLU

x = rng.normal(size=(n, d))
y = block(x)
x2 = x.copy(); x2[-1] += 1.0                         # 마지막 토큰만 바꾼다
y2 = block(x2)
print(y.shape)
print(np.allclose(y[:-1], y2[:-1]), np.abs(y[-1] - y2[-1]).max().round(3))
```
```text
(5, 16)
True 2.18
```

출력 모양은 입력과 같은 (토큰 수, d)라서 같은 블록을 32번 쌓을 수 있다. 앞 토큰 4개의 출력은 그대로이고 마지막 토큰만 바뀌었다. 이 성질 덕분에 생성할 때 앞 토큰의 키와 값을 KV 캐시에 저장해 두고 재사용할 수 있다. GQA는 `np.repeat`로 KV 헤드를 쿼리 헤드 수만큼 복제하는 것과 같지만, 실제 구현은 복제 없이 같은 KV를 여러 쿼리 헤드가 읽는다.

## 어디에 쓰이나
- AI 기초 4편 「컴퓨터 사이언스로 보는 AI 모델: 텐서, 연산, 메모리」: 가중치 메모리 8.03B × 2바이트 ≈ 15GiB와 토큰당 추론 연산 약 2 × 8.03B ≈ 16 GFLOPs가 이 글의 파라미터 수에서 바로 나온다.
- 신경망 레이어 6편 「트랜스포머의 인코더와 디코더」: 원조 블록의 12d²가 GQA와 SwiGLU를 거쳐 13d²로 바뀐 과정을 비교할 수 있다.
- 어텐션 4편 「KV 캐시와 MQA·GQA·MLA」: KV 헤드 8개라는 설정 하나가 토큰당 128KiB라는 KV 캐시 크기를 정한다.

## 정리
- 오픈 웨이트는 가중치와 구조를 공개한 것이고, 오픈 소스는 학습 코드와 데이터 정보까지 요구하는 더 넓은 개념이다.
- 라마 3 8B = 디코더 블록 32개 + Pre-RMSNorm, RoPE(θ = 500,000), GQA(32 : 8), SwiGLU(14,336), 편향 없는 선형 층.
- 블록당 약 13d², 전체 8,030,261,248개(임베딩 비공유)를 설정값만으로 정확히 계산할 수 있다.
- 2~4편의 모델들은 이 블록에서 어텐션 배치, FFN, 층 종류를 하나씩 바꾼 변형이다.
