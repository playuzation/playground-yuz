# [오픈 웨이트 모델 4/5] 하이브리드 모델: 리니어 어텐션과 어텐션 섞기

> **한 줄 요약** — 하이브리드 모델은 고정 크기 상태만 갖는 맘바·리니어 어텐션 층을 대부분에 쓰고 소프트맥스 어텐션 층을 몇 개만 남겨 정확한 검색 능력을 지키며, 잼바(1 : 7), 미니맥스-01(1 : 7), Qwen3-Next(1 : 3)처럼 KV 캐시는 남긴 어텐션 층 비율만큼만 자란다.

## 왜 섞나
2편의 윈도 층은 최근 토큰만 보는 대신 그 안에서는 정확하다. 반대쪽 극단은 어텐션 6편 「리니어 어텐션: 소프트맥스 없이 순서를 바꾸기」의 리니어 어텐션과 신경망 레이어 10편 「상태 공간 모델과 맘바」의 맘바다. 이들은 과거 전체를 고정 크기 상태 하나에 눌러 담으므로 토큰당 계산과 메모리가 문맥 길이와 무관하다. 대신 상태 크기에 한계가 있어 "앞에서 본 전화번호를 그대로 꺼내 오기" 같은 정확한 검색에 약하다. 소프트맥스 어텐션은 모든 토큰을 KV 캐시에 그대로 남기므로 검색에 강하지만, 캐시가 문맥에 비례해 자란다.

하이브리드는 둘을 층 단위로 섞는다. 대부분의 층은 싼 순환형 층이 맡고, 몇 층마다 한 번씩 넣은 어텐션 층이 필요할 때 과거 토큰을 정확히 찾아온다. 2편의 로컬·글로벌 배치에서 로컬 층 자리에 고정 상태 층을 넣은 셈이다.

## 잼바: 맘바 + 어텐션 + MoE
AI21 랩스가 2024년 공개한 잼바(Jamba)는 맘바 층 7개마다 어텐션 층 1개를 두고(1 : 7), 두 층에 한 번씩 FFN을 MoE(전문가 16개 중 2개)로 바꿨다. 전체 52B, 활성 12B이고 256K 토큰 문맥을 지원하며, 단일 80GB GPU에 들어가도록 설계했다. 공개 설정은 32층이고 어텐션이 8층 주기의 다섯 번째 자리에 있어서, 실제 배치는 아래 코드의 `MMMMAMMM` 반복이 된다.

## 미니맥스-01: 라이트닝 어텐션
미니맥스(MiniMax)가 2025년 1월 공개한 미니맥스-01의 텍스트 모델은 리니어 어텐션 계열인 **라이트닝 어텐션**(lightning attention) 층 7개 뒤에 소프트맥스 어텐션 층 1개를 두는 패턴을 80층에 걸쳐 반복한다. KV 캐시를 갖는 층은 10개뿐이다. 라이트닝 어텐션은 리니어 어텐션을 GPU에서 효율적으로 계산하도록 구현한 변형이다. FFN은 전문가 32개의 MoE이고, 전체 456B 중 토큰당 45.9B가 활성이다. 학습은 100만 토큰 문맥까지 했고, 추론 때는 400만 토큰까지 늘릴 수 있다고 보고했다.

## Qwen3-Next: Gated DeltaNet 3 : 게이트 어텐션 1
알리바바가 2025년 9월 공개한 Qwen3-Next-80B-A3B는 48층을 "Gated DeltaNet 3층 → 게이트 어텐션 1층" 묶음 12개로 쌓았고, 모든 층 뒤에 MoE가 붙는다.
- Gated DeltaNet: 델타 규칙으로 상태를 고쳐 쓰고 게이트로 잊는 선형 순환 층이다(신경망 레이어 11편 「델타 규칙과 Gated DeltaNet」). 쿼리·키 헤드 16개, 값 헤드 32개, 헤드 차원 128이다.
- 게이트 어텐션: 어텐션 출력에 게이트를 곱해 수치 문제를 줄인 GQA다. 쿼리 16 : KV 2, 헤드 차원 256이고, RoPE는 256차원 중 64차원에만 건다.
- 초세분화 MoE: 층마다 전문가 512개 중 10개 + 공유 1개를 쓰고, 전문가 하나의 은닉 크기는 512에 불과하다(딥시크-V3는 2,048). 전체 80B 중 토큰당 약 3B만 활성이다.
- 문맥은 기본 262,144토큰이고, 3편의 딥시크-V3처럼 다중 토큰 예측(MTP)도 쓴다.

## 키미 리니어: KDA 3 : MLA 1
문샷 AI의 키미 리니어(Kimi Linear, 2025)도 3 : 1 구성이다. Gated DeltaNet에 더 세밀한 게이트를 단 KDA(Kimi Delta Attention) 층 3개마다 MLA 층 1개를 두었다. 전체 48B, 활성 3B 규모에서, 같은 방식으로 학습한 전체 MLA 모델보다 KV 캐시를 최대 75% 줄였다고 보고했다.

| 모델 | 섞는 층 | 어텐션 : 나머지 | 전체 / 활성 |
|---|---|---|---|
| 잼바 | 맘바 + 어텐션 | 1 : 7 | 52B / 12B |
| 미니맥스-01 | 라이트닝 + 소프트맥스 | 1 : 7 | 456B / 45.9B |
| Qwen3-Next | DeltaNet + 게이트 어텐션 | 1 : 3 | 80B / 약 3B |
| 키미 리니어 | KDA + MLA | 1 : 3 | 48B / 3B |

## 고정 크기 상태 vs KV 캐시
KV 캐시는 어텐션 층에만 생기므로, 층 배치를 문자열로 만들어 어텐션 층만 세면 된다. 잼바는 같은 크기의 KV 헤드(8 × 128)를 쓰는 믹스트랄과 256K 문맥에서 비교하고, Qwen3-Next는 상태 크기까지 함께 계산한다. 모두 BF16 기준이다.
```python
GiB, MiB = 2**30, 2**20
def kv(attn_layers, kv_heads, hd, ctx, nbytes=2):     # K+V, BF16
    return 2 * attn_layers * kv_heads * hd * nbytes * ctx

jamba = "".join("A" if i % 8 == 4 else "M" for i in range(32))
qnext = "DDDA" * 12                    # D: Gated DeltaNet, A: 어텐션
print("잼바      ", jamba[:16], "... 어텐션", jamba.count("A"), "층")
print("Qwen3-Next", qnext[:16], "... 어텐션", qnext.count("A"), "층")

ctx = 256 * 1024
print("믹스트랄 32층", kv(32, 8, 128, ctx) / GiB, "GiB")
print("잼바 4층     ", kv(jamba.count("A"), 8, 128, ctx) / GiB, "GiB")

state = 36 * 32 * 128 * 128            # 층 × V 헤드 × d_k × d_v
print("DeltaNet 상태", state * 2 / MiB, "MiB (문맥과 무관)")
for n in (4096, 32768, 262144):
    print(f"{n:>7} 토큰: 어텐션 12층 KV {kv(12, 2, 256, n) / MiB:>5.0f} MiB"
          f" / 48층 전부 어텐션이면 {kv(48, 2, 256, n) / MiB:>5.0f} MiB")
```
```text
잼바       MMMMAMMMMMMMAMMM ... 어텐션 4 층
Qwen3-Next DDDADDDADDDADDDA ... 어텐션 12 층
믹스트랄 32층 32.0 GiB
잼바 4층      4.0 GiB
DeltaNet 상태 36.0 MiB (문맥과 무관)
   4096 토큰: 어텐션 12층 KV    96 MiB / 48층 전부 어텐션이면   384 MiB
  32768 토큰: 어텐션 12층 KV   768 MiB / 48층 전부 어텐션이면  3072 MiB
 262144 토큰: 어텐션 12층 KV  6144 MiB / 48층 전부 어텐션이면 24576 MiB
```

잼바의 KV 캐시 4GiB는 믹스트랄의 8분의 1이고, 잼바 논문이 보고한 값(256K 토큰, 16비트에서 4GB 대 32GB)과 같다. 맘바 층은 문맥과 무관한 작은 상태만 가진다.

Qwen3-Next의 DeltaNet 층은 층마다 값 헤드 32개 × (128 × 128) 행렬 하나씩을 상태로 들고 다니며, 36층을 합쳐도 36MiB로 고정이다. 같은 36층이 어텐션이었다면 토큰당 72KiB씩 쌓였을 테니 문맥이 512토큰만 넘어도 상태 쪽이 작다. 262K 문맥의 KV 캐시는 6GiB로, 48층 전부 어텐션일 때(24GiB)의 4분의 1이다. 결국 하이브리드의 KV 캐시는 "어텐션 층 비율 × 전체 어텐션일 때의 크기"이고, 나머지 층의 비용은 상수다.

## 정리
- 순환형 층(맘바, 리니어 어텐션, Gated DeltaNet)은 고정 크기 상태로 싸게 돌고, 소프트맥스 어텐션 층은 정확한 검색을 맡는다.
- 잼바와 미니맥스-01은 어텐션 1 : 나머지 7, Qwen3-Next와 키미 리니어는 1 : 3으로 섞었고, 모두 MoE와 함께 쓴다.
- KV 캐시는 남긴 어텐션 층에만 생기고 나머지 층의 상태는 문맥과 무관하다. 잼바는 256K에서 4GiB(믹스트랄 32GiB), Qwen3-Next는 262K에서 6GiB에 상태 36MiB다.
