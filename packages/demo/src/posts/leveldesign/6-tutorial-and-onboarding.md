# [레벨 디자인과 콘텐츠 제공 6/16] 튜토리얼과 온보딩: 레벨이 가르치게 하기

> **한 줄 요약** — 조작법을 글로 먼저 늘어놓기보다 실패해도 잃을 것이 없는 곳에서 한 가지씩 보여 주고 응용·비틀기·마무리로 이어 가면, 같은 도전을 놓더라도 순서만으로 이탈이 크게 줄어든다는 것을 학습 곡선 모델로 계산할 수 있다.

## 이 글에서 다루는 것
- 글로 설명하는 튜토리얼이 잘 안 먹히는 이유와 "레벨이 가르치게" 하는 원리
- 기승전결로 기술 하나를 가르치는 네 단계와 슈퍼 마리오 브라더스 1-1의 첫 화면
- 스킬 원자: 가르칠 단위를 쪼개고 순서 정하기
- 학습 곡선 모델로 배치 순서별 이탈률 계산: 정확한 분포 대 몬테카를로, 학습이 없을 때의 기하 분포 식

## 설명서를 읽지 않는 플레이어
게임을 켜자마자 조작법 창이 다섯 개 뜨면 대부분 넘기고, 읽은 사람도 "B로 대시"라는 글을 손가락의 감각으로 옮기지 못한 채 잊는다. 그렇다고 아무 설명 없이 어려운 구간에 던지면 처음 해 보는 사람은 몇 번 죽고 게임을 끈다. 둘 다 같은 원리를 어긴다. 사람은 직접 해 보고 결과를 보면서 배우고, 배울 것은 필요한 순간에 하나씩 와야 한다. **온보딩**(onboarding)은 처음 온 플레이어가 게임의 규칙을 몸으로 익히고 계속하고 싶어지게 만드는 과정 전체이고, 레벨 디자이너가 가장 많이 쓰는 도구는 글이 아니라 배치 순서다.

## 기승전결: 기술 하나를 가르치는 네 단계
『슈퍼 마리오 3D 랜드』의 디렉터 하야시다 고이치는 2012년 가마수트라(현 게임 디벨로퍼) 인터뷰에서 레벨마다 핵심 아이디어 하나를 정하는 것이 중요하다고 말하고, 그 아이디어를 소개하고 익히게 한 뒤 비틀어 다르게 쓰게 하는 흐름을 동아시아 이야기 구조인 기승전결에 빗대어 설명했다.
```text
기: 안전한 곳에서 처음 보여 준다
  ↓  실패해도 잃는 것이 거의 없다
승: 같은 동작을 위험과 함께 응용한다
  ↓
전: 새 맥락에서 비틀어 쓰게 한다
  ↓
결: 앞의 것을 섞어 확인하고 마무리
```
핵심은 첫 단계다. 새 동작을 처음 만나는 자리에서 실패의 비용이 크면, 플레이어는 배우기도 전에 지친다.

## 슈퍼 마리오 브라더스 1-1이 첫 화면에서 하는 일
닌텐도의 『슈퍼 마리오 브라더스』(1985) 1-1은 이 원리의 교과서로 자주 거론된다. 미야모토 시게루는 1-1에 플레이어가 알아야 할 것을 담아 차근차근 이해하게 하려 했다고 설명해 왔다. 2015년 유로게이머 영상 인터뷰를 옮긴 기사들에 따르면, 첫 적으로 거북 엉금엉금(Koopa Troopa)을 두려다 밟고 차는 동작이 처음에는 어렵다고 보고 더 단순한 굼바를 만들었고, 버섯은 플레이어가 피하기 어려운 자리에 나오도록 배치했다. 첫 굼바는 레벨 맨 앞에 있어서 부딪혀 죽어도 잃는 진행이 거의 없다. 기승전결의 "기"가 정확히 이 자리다.

## 스킬 원자: 가르칠 단위 쪼개기
대니얼 쿡은 2007년 가마수트라 글 「The Chemistry of Game Design」에서 플레이어가 기술 하나를 익히는 피드백 고리를 **스킬 원자**(skill atom)라고 불렀다. 플레이어가 행동하고, 게임이 반응하고, 그 결과를 보고 머릿속 규칙을 고치는 고리다. 원자들은 앞의 것을 알아야 다음 것을 배울 수 있는 사슬로 이어진다. 점프를 알아야 밟기를, 달리기와 점프를 알아야 멀리뛰기를 배운다. 실무에서는 가르칠 원자를 목록으로 적고 선행 관계대로 순서를 정한 뒤, 원자마다 기승전결 한 벌을 배치한다. 순서가 정말 중요한지 모델로 확인해 보자.

## 학습 곡선 모델: 같은 도전, 다른 순서
플레이어가 n번 시도해 봤을 때 난이도 d인 도전에 성공할 확률을 로지스틱 함수 `p = 1/(1 + e^(d − 0.3n))`로 둔다. 시도할 때마다 실력이 η = 0.3씩 오르는 학습 곡선이다. 실패하면 확률 q(여기서는 0.1)로 게임을 그만두고, 아니면 다시 도전한다. 난이도 −1.5부터 2.0까지 도전 8개를 순서만 바꿔 놓고 끝까지 가지 못하는 비율(이탈률)을 정확히 계산한다. 시도 수 n이 매번 하나씩 늘기 때문에 상태 (도전 번호, 시도 수)의 확률을 n 순서로 한 번씩 밀어 가면 된다.
```python
import math, random

def p_win(d, n, eta):                 # n번 시도해 본 플레이어의 성공 확률
    return 1 / (1 + math.exp(d - eta * n))

def exact(course, eta=0.3, nmax=600):
    """정확한 분포: 상태 (도전 i, 지금까지 시도 n)의 확률을 밀어 간다."""
    prob, quits, done, tries = {(0, 0): 1.0}, [0.0] * len(course), 0.0, 0.0
    for n in range(nmax):
        for i, (d, q) in enumerate(course):    # q: 실패했을 때 그만둘 확률
            m = prob.pop((i, n), 0.0)
            if m == 0:
                continue
            tries += m
            p = p_win(d, n, eta)
            if i + 1 == len(course):
                done += m * p
            else:
                prob[i + 1, n + 1] = prob.get((i + 1, n + 1), 0) + m * p
            quits[i] += m * (1 - p) * q
            prob[i, n + 1] = prob.get((i, n + 1), 0) + m * (1 - p) * (1 - q)
    return 1 - done, quits, tries

ramp = [(d / 2, 0.1) for d in range(-3, 5)]   # 난이도 -1.5 ~ 2.0
rng = random.Random(6)
courses = {"쉬운 순": ramp, "어려운 순": ramp[::-1],
           "안전 연습+쉬운 순": [(0.5, 0.0)] + ramp}
for name, c in courses.items():
    drop, quits, tries = exact(c)
    print(f"{name}: 이탈 {drop:.1%}, 평균 시도 {tries:.1f},"
          f" 첫 도전 이탈 {quits[0]:.1%}")
shuffled = [rng.sample(ramp, len(ramp)) for _ in range(200)]
print(f"무작위 순서 200개 평균: 이탈"
      f" {sum(exact(c)[0] for c in shuffled) / 200:.1%}")
```
```text
쉬운 순: 이탈 23.4%, 평균 시도 9.4, 첫 도전 이탈 2.1%
어려운 순: 이탈 40.7%, 평균 시도 9.0, 첫 도전 이탈 27.7%
안전 연습+쉬운 순: 이탈 15.3%, 평균 시도 11.2, 첫 도전 이탈 0.0%
무작위 순서 200개 평균: 이탈 32.6%
```
똑같은 도전 8개인데 쉬운 순이면 23.4%, 무작위면 32.6%, 어려운 순이면 40.7%가 떠난다. 평균 시도 수는 9.0~9.4로 거의 같다. 차이는 실패가 "언제" 오느냐에서 난다. 어려운 순에서는 실력이 가장 낮은 첫 도전에서 실패가 몰려 27.7%가 첫 관문에서 떠난다. 쉬운 순에서는 성공 확률이 높은 도전에서 연습량을 쌓은 뒤에 어려운 도전을 만난다. 맨 앞에 실패해도 그만두지 않는 안전한 연습 구간(q = 0, 난이도 0.5) 하나를 붙이면 시도가 1.8번 늘어나는 대신 이탈이 15.3%로 떨어진다. 1-1의 첫 굼바가 하는 일이 이것이다.

## 대조: 기하 분포 식과 몬테카를로
학습이 없으면(η = 0) 한 도전의 시도 수는 확률과 분포 6편의 기하 분포가 된다. 시도 한 번이 끝날(통과하거나 포기할) 확률은 `p + (1 − p)q`이므로 다음 식이 나온다.
```text
통과 확률 = p / (p + (1 − p)q)
기대 시도 수 = 1 / (p + (1 − p)q)
코스 통과 = 각 도전 통과 확률의 곱
```
앞 코드에 이어서, 학습이 없을 때 동적 계획법의 결과를 이 식과 무작위 코스 300개로 대조하고, 학습이 있을 때는 플레이어 2만 명을 직접 굴린 몬테카를로와 비교한다.
```python
def formula(course):                  # 학습 없음(eta=0): 기하 분포의 식
    reach, tries = 1.0, 0.0
    for d, q in course:
        p = p_win(d, 0, 0)
        stop = p + (1 - p) * q        # 한 번 시도로 끝날(통과·포기) 확률
        tries += reach / stop         # 끝날 때까지 시도 수의 기댓값
        reach *= p / stop             # 포기보다 통과가 먼저 올 확률
    return 1 - reach, tries

ok = 0
for _ in range(300):
    c = [(rng.uniform(-2, 2), rng.uniform(0.05, 0.3))
         for _ in range(rng.randint(1, 8))]
    drop, _, tries = exact(c, eta=0)
    f_drop, f_tries = formula(c)
    ok += abs(drop - f_drop) < 1e-9 and abs(tries - f_tries) < 1e-9
print(f"학습 없음, 무작위 300개: 식과 {ok}개 일치")

def monte_carlo(course, players, eta=0.3):
    left = 0
    for _ in range(players):
        n = 0
        for d, q in course:
            while True:
                win = rng.random() < p_win(d, n, eta)
                n += 1
                if win or rng.random() < q:   # 통과하거나 포기하면 끝
                    break
            if not win:
                left += 1
                break
    return left / players

for name, c in courses.items():
    e, mc = exact(c)[0], monte_carlo(c, 20000)
    se = (e * (1 - e) / 20000) ** 0.5
    print(f"{name}: 정확 {e:.1%}, 몬테카를로 {mc:.1%}"
          f" (차이 {abs(mc - e) / se:.1f} SE)")
```
```text
학습 없음, 무작위 300개: 식과 300개 일치
쉬운 순: 정확 23.4%, 몬테카를로 23.2% (차이 0.8 SE)
어려운 순: 정확 40.7%, 몬테카를로 40.9% (차이 0.7 SE)
안전 연습+쉬운 순: 정확 15.3%, 몬테카를로 15.7% (차이 1.4 SE)
```
학습이 없는 경우 동적 계획법은 기하 분포 식과 300개 모두 일치했고(시도 수 기댓값까지), 학습이 있는 경우 몬테카를로는 정확한 값에서 표준 오차(SE) 1.4배 안쪽에 있다. 계산이 맞으니 남는 질문은 모델의 가정이 맞느냐다.

## 실무에서의 의미와 한계
- 모델에서 안전 구간은 q = 0이지만, 실제로는 너무 쉽고 긴 연습도 지루해서 떠나게 한다. 5편의 몰입 채널처럼 연습도 짧고 곧바로 응용으로 넘어가야 한다.
- 실력을 숫자 하나로 뒀지만 실제 기술은 원자마다 따로 오르고, 잊히고, 서로 옮겨 간다. 학습률 0.3과 로지스틱 모양은 가정이라서 실제 플레이 로그로 다시 맞춰야 한다.
- 경험 많은 플레이어에게 긴 강제 튜토리얼은 그 자체로 이탈 요인이다. 건너뛸 수 있게 하거나, 아는 사람은 빨리 지나가는 배치(예: 굼바를 그냥 뛰어넘어도 되는 길)를 쓴다.
- 모델은 순서가 이탈에 미치는 방향을 보여 줄 뿐이다. 플레이어가 무엇을 오해했는지는 처음 해 보는 사람의 플레이를 옆에서 보는 플레이테스트로만 알 수 있다.

## 어디에 쓰이나
- 확률과 분포 6편 「이산 분포: 베르누이, 이항, 기하, 포아송」: 학습이 없을 때 한 도전의 시도 수는 기하 분포이고, 통과 확률과 기대 시도 수가 그 식에서 나온다.
- 이산수학 10편 「그래프 탐색: BFS, DFS, 위상 정렬」: 스킬 사슬의 선행 관계에서 가르칠 순서를 정하는 일은 위상 정렬이다.
- 통계학 9편 「로지스틱 회귀: 확률을 예측하는 회귀」: 난이도와 연습량으로 성공 확률을 정하는 이 모델의 계수는 실제 시도 로그에 로지스틱 회귀를 맞춰 추정할 수 있다.
- 15편 「데이터로 판단하기: 텔레메트리, 퍼널, 히트맵, A/B 테스트」: 도전별 이탈률은 진행 퍼널로 재서 모델의 예측과 비교한다.

## 정리
- 레벨이 가르치게 하려면 기술 하나를 안전한 곳에서 처음 보여 주고, 응용하고, 비틀고, 섞어서 마무리한다(기승전결).
- 가르칠 단위는 스킬 원자로 쪼개고 선행 관계대로 배치한다.
- 모델에서 같은 도전 8개의 이탈률은 쉬운 순 23.4%, 어려운 순 40.7%였고, 실패해도 잃을 것이 없는 연습 구간 하나가 15.3%까지 낮췄다.
- 계산은 기하 분포 식(300개 일치)과 몬테카를로(1.4 SE 이내)로 확인했고, 모델의 가정은 플레이테스트와 로그로 확인해야 한다.
