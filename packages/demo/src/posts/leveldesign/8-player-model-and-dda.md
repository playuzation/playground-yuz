> **한 줄 요약** — 실력은 직접 볼 수 없으니 승패로 추정해야 하고, 엘로 레이팅은 기대 승률 식과 한 줄짜리 갱신으로 실력을 따라가며, 그 추정으로 상대나 난이도를 고르면 목표 승률을 맞출 수 있지만 K값의 속도와 잡음, 실력이 오르는 동안 생기는 지연을 함께 설계해야 한다.

## 이 글에서 다루는 것
- 고정 난이도 선택의 한계와 동적 난이도 조절(DDA): 러버밴딩, 레지던트 이블 4의 숨은 등급
- 숨김 조절의 장단점
- 엘로 레이팅: 기대 승률 식과 갱신, K값의 속도와 잡음, 글리코의 아이디어
- 목표 승률을 맞추는 상대 고르기: 오프셋 공식과 성장하는 플레이어의 지연 공식

## 쉬움·보통·어려움으로는 부족한 이유
게임을 시작할 때 난이도를 고르게 하면 플레이어는 아직 해 보지도 않은 게임에서 자기 실력을 맞혀야 한다. 고른 뒤에도 실력은 계속 오르고, 구간마다 요구하는 기술이 다르다. 그래서 게임이 플레이를 보며 난이도를 바꾸는 **동적 난이도 조절**(dynamic difficulty adjustment, DDA)이 나왔다. 가장 순진한 DDA는 "지면 쉽게, 이기면 어렵게"다. 이 방식은 운 한 번에 출렁이고, 잘하는 사람을 벌주고, 일부러 져서 쉽게 만드는 요령을 부른다. 필요한 것은 승패 하나가 아니라 승패의 누적에서 실력을 추정하는 **플레이어 모델**이다.

## 동적 난이도 조절의 예
- **러버밴딩**(rubber banding): 레이싱 게임에서 뒤처진 차를 빠르게 하거나 앞선 차를 늦춰 무리를 고무줄처럼 묶는 기법이다. 마리오 카트 시리즈는 뒤 순위일수록 강한 아이템이 잘 나온다고 널리 알려져 있지만, 정확한 가중치는 공개된 적이 없다.
- **레지던트 이블 4**(캡콤, 2005): 팬들의 분석과 마크 브라운의 2015년 「게임 메이커스 툴킷」 영상에 따르면, 1~10의 숨은 등급이 피격을 피하고 정확히 쏘면 오르고 자주 맞거나 죽으면 내려가며, 적의 공격력과 공격성, 상자에서 나오는 탄약의 양을 바꾼다. 이 글에서는 캡콤의 공식 설명을 확인하지 못했다.

두 예는 모두 **숨김 조절**이다. 플레이어가 "쉬움"을 고르는 부담 없이 자기 수준에 맞는 경험을 하고 몰입이 깨지지 않는 것이 장점이다. 대신 들키면 "내가 이긴 게 아니었나" 하는 불신이 생기고, 잘할수록 어려워지니 숙련자가 벌을 받는 느낌을 받는다. 반대쪽 끝에는 플레이어가 직접 켜고 끄는 보조 옵션처럼 조절을 드러내는 방식이 있다.

## 실력은 승패로 추정한다: 엘로 레이팅
아르파드 엘로가 만든 엘로 레이팅은 미국 체스 연맹이 1960년에, 국제 체스 연맹(FIDE)이 1970년에 채택했다. 레이팅 차이로 기대 점수(이길 확률)를 정하고, 결과가 기대보다 좋으면 올리고 나쁘면 내린다.
```text
E_A = 1 / (1 + 10^((R_B − R_A)/400))
R_A ← R_A + K·(S_A − E_A)
S_A: 이기면 1, 지면 0
```
레이팅이 400 높으면 기대 승률이 10:1, 곧 0.909다. A가 얻은 만큼 B가 잃으므로 레이팅의 합은 변하지 않는다. K는 한 판에 얼마나 크게 움직일지 정하는 보폭이다. 마크 글릭먼의 **글리코**(Glicko)는 여기에 레이팅이 얼마나 불확실한지를 나타내는 **레이팅 편차**(rating deviation)를 더해, 처음 왔거나 오래 쉰 플레이어는 크게, 판이 쌓인 플레이어는 조금씩 움직인다. 체스닷컴은 글리코를, 리체스는 글리코-2를 쓴다.

선수 200명의 실제 실력을 평균 1500, 표준 편차 200으로 뽑고, 실제 실력 사이의 승률이 위 식을 그대로 따르는 세계를 만든다. 레이팅은 모두 1500에서 시작하고 매 라운드 무작위로 짝지어 300라운드를 치른다. 레이팅은 상대적인 값이므로 평균을 뺀 뒤 실제 실력과의 평균 절대 오차를 잰다. 101라운드부터는 경기 직전 레이팅으로 계산한 예측 승률과 실제 결과를 모아, 예측 구간별로 비교한다.
```python
import random

def expect(ra, rb):                    # 엘로 기대 점수: A가 이길 확률
    return 1 / (1 + 10 ** ((rb - ra) / 400))

def league(K, rounds=300, n=200, seed=8):
    rng = random.Random(seed)
    true = [rng.gauss(1500, 200) for _ in range(n)]   # 실제 실력(모름)
    rate = [1500.0] * n                                # 레이팅(추정)
    err, calib = [], []
    for rd in range(rounds):
        order = rng.sample(range(n), n)
        for a, b in zip(order[::2], order[1::2]):
            e = expect(rate[a], rate[b])
            s = 1 if rng.random() < expect(true[a], true[b]) else 0
            if rd >= 100:
                calib.append((e, s))
            rate[a] += K * (s - e)
            rate[b] -= K * (s - e)                     # 합은 그대로
        mt, mr = sum(true) / n, sum(rate) / n
        err.append(sum(abs((r - mr) - (t - mt))
                       for r, t in zip(rate, true)) / n)
    return err, calib, sum(rate)

for K in (16, 32, 64):
    err, calib, total = league(K)
    print(f"K={K}: 오차", " → ".join(f"{err[i]:.0f}" for i in (0, 9, 49, 299)),
          "/ 합 보존", abs(total - 200 * 1500) < 1e-6)
    pred, real = [], []
    for lo in (0.1, 0.3, 0.5, 0.7):               # 예측 승률 구간별로
        b = [(e, s) for e, s in calib if lo <= e < lo + 0.2]
        pred.append(sum(e for e, _ in b) / len(b))
        real.append(sum(s for _, s in b) / len(b))
    print("  예측:", " ".join(f"{x:.3f}" for x in pred))
    print("  실제:", " ".join(f"{x:.3f}" for x in real))
```
```text
K=16: 오차 160 → 141 → 87 → 31 / 합 보존 True
  예측: 0.200 0.400 0.600 0.799
  실제: 0.177 0.390 0.596 0.816
K=32: 오차 157 → 126 → 62 → 45 / 합 보존 True
  예측: 0.196 0.399 0.602 0.805
  실제: 0.207 0.399 0.585 0.782
K=64: 오차 153 → 107 → 64 → 66 / 합 보존 True
  예측: 0.195 0.398 0.602 0.807
  실제: 0.245 0.404 0.572 0.748
```
오차는 1, 10, 50, 300라운드 뒤의 값이다. K=16은 느리지만 300라운드 뒤 31까지 내려가고, K=64는 10라운드 만에 107로 빨리 내려가지만 66 근처에서 더 줄지 않는다. 한 판마다 크게 움직이니 운에 흔들리는 잡음이 남는 것이다. 식과 경험 승률의 대조(구간마다 약 3,400~4,400판, 표준 오차 약 0.007)도 같은 이야기를 한다. K=64는 예측이 0.807인 판에서 실제로 0.748만 이겨 예측이 지나치게 확신에 차 있고, K=16은 레이팅이 아직 덜 퍼져서 실제가 예측보다 극단적이다. 그래서 처음에는 크게 움직이고 판이 쌓일수록 보폭을 줄이는 방식이 자연스럽고, 글리코의 레이팅 편차가 이것을 원리 있게 한다.

## 목표 승률 맞추기: 상대를 고르는 식
대전 게임의 매치메이킹은 레이팅이 비슷한 사람끼리 붙여 승률 50%를 노린다. 혼자 하는 게임이라면 AI의 강함을 같은 척도에 놓고 원하는 승률 p가 나오게 고를 수 있다. 기대 점수 식을 거꾸로 풀면 AI를 플레이어 레이팅보다 `400·log₁₀(p/(1 − p))`만큼 낮추면 된다. 앞 코드에 이어서, 실제 실력 1300에서 시작해 판마다 2씩 느는 플레이어 300명이 500판씩 하는 동안 고정 AI(1500)와 목표 승률 70%의 DDA를 비교한다.
```python
import math

TARGET, K, G = 0.7, 32, 2.0           # 목표 승률, K, 판당 실력 성장
OFF = 400 * math.log10(TARGET / (1 - TARGET))   # expect(R, R - OFF) = 0.7

def campaign(dda, seed, games=500):
    rng = random.Random(seed)
    true, rate, wins = 1300.0, 1500.0, []
    for g in range(games):
        ai = rate - OFF if dda else 1500.0
        s = 1 if rng.random() < expect(true, ai) else 0
        rate += K * (s - expect(rate, ai))   # AI 레이팅은 고정, 내 것만
        true += G                            # 플레이어가 배운다
        wins.append(s)
    return wins

print(f"오프셋 {OFF:.1f}, 식으로 본 승률 {expect(1500, 1500 - OFF):.3f}")
for dda in (False, True):
    runs = [campaign(dda, seed) for seed in range(300)]
    win = [sum(sum(w[i:i + 100]) for w in runs) / (100 * len(runs))
           for i in range(0, 500, 100)]
    print("DDA" if dda else "고정", " ".join(f"{x:.2f}" for x in win))
late = sum(sum(w[100:]) for w in runs) / (400 * len(runs))
print(f"지연 공식 {TARGET + G / K:.3f}, 시뮬레이션 {late:.3f}")
```
```text
오프셋 147.2, 식으로 본 승률 0.700
고정 0.36 0.64 0.84 0.94 0.98
DDA 0.68 0.76 0.76 0.76 0.76
지연 공식 0.762, 시뮬레이션 0.761
```
고정 AI에서 승률은 0.36에서 0.98로 간다. 처음에는 좌절, 끝에는 지루함이다(5편의 몰입 채널). DDA는 0.76 근처에 머물지만 목표 0.70이 아니다. 이유는 지연이다. 실력이 판마다 g만큼 오르면 레이팅도 평균적으로 판마다 g씩 올라야 따라가고, 한 판의 기대 상승은 `K·(실제 승률 − 0.7)`이므로 정상 상태에서 실제 승률은 `0.7 + g/K = 0.762`가 된다. 시뮬레이션은 0.761로 공식과 맞았다. 첫 100판이 0.68인 것은 시작 레이팅 1500이 실제 1300보다 높아 처음에 AI가 너무 강했기 때문이다. 처음 레이팅을 보수적으로 잡거나 배치 경기를 두는 이유다.

## 모델이 말해 주지 않는 것
- 이 세계는 승률이 엘로 식을 그대로 따르도록 만들었으니 식이 잘 맞는 것은 당연한 면이 있다. 실제 게임에서는 로그로 예측 승률과 실제 승률을 같은 방식으로 대조해 봐야 한다(15편).
- 실력은 한 숫자가 아니다. 조준과 전략, 맵 지식이 따로 오르고, 팀 게임에서는 개인의 기여를 승패에서 떼어 내기 어렵다.
- 숨김 조절은 악용될 수 있다. 이 모델에서도 일부러 지면 레이팅이 내려가 AI가 약해진다.
- 목표 승률 70%가 좋은지는 모델이 말해 주지 않는다. 어떤 플레이어는 지는 판이 많아도 도전을 원한다. 목표는 플레이테스트와 선택지로 정한다.

## 어디에 쓰이나
- 통계학 9편 「로지스틱 회귀: 확률을 예측하는 회귀」: 기대 점수는 레이팅 차이를 입력으로 하는 로지스틱 함수이고, 엘로 갱신은 그 로그 우도를 한 판씩 올라가는 확률적 경사 상승과 같은 꼴이다.
- 미적분 10편 「경사 하강법의 수학」: K는 학습률이어서, 크면 빨리 움직이지만 잡음에 흔들리고 작으면 느리게 수렴하는 같은 균형이 나타난다.
- 통계학 10편 「베이즈 추론: 사전 분포에서 사후 분포로」: 글리코의 레이팅 편차는 실력에 대한 불확실성을 판이 쌓일수록 줄여 가는 베이즈식 생각이다.
- 5편 「페이싱과 난이도 곡선: 긴장과 이완의 리듬」: AI 디렉터가 지금의 긴장도를 조절한다면, 레이팅은 긴 시간에 걸친 실력을 따라간다.

## 정리
- 고정 난이도는 한 시점의 한 실력에만 맞고, 승패 하나에 반응하는 DDA는 출렁이므로 승패의 누적에서 실력을 추정하는 플레이어 모델이 필요하다.
- 엘로 레이팅은 기대 승률 식과 `K·(S − E)` 갱신으로 실력을 따라간다. 모델에서 K=64는 빨랐지만 오차 66에 머물고 예측이 과신했고, K=16은 느렸다.
- 목표 승률 p의 상대는 레이팅을 `400·log₁₀(p/(1 − p))`만큼 낮춰 고르고, 성장하는 플레이어에게는 승률이 `p + g/K`로 밀린다(공식 0.762, 시뮬레이션 0.761).
- 숨김 조절은 몰입을 지키지만 들켰을 때의 불신과 악용을 함께 설계해야 한다.
