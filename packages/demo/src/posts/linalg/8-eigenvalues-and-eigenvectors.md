# [선형대수 8/12] 고유값과 고유벡터

> **한 줄 요약** — 고유벡터는 행렬을 곱해도 방향이 바뀌지 않고 길이만 λ배가 되는 특별한 벡터이며, 행렬을 여러 번 거듭 곱했을 때 무슨 일이 일어나는지는 이 고유값과 고유벡터가 결정한다.

## 이 글에서 다루는 것
- 정의 `Av = λv`: 방향이 바뀌지 않는 벡터
- 특성 방정식으로 2×2를 손으로 풀고 NumPy로 확인하기
- 대칭 행렬의 좋은 성질
- 거듭제곱 `Aᵏ`의 장기 거동과 거듭제곱법

## 방향이 바뀌지 않는 벡터
4편 「선형 변환으로서의 행렬」에서 본 것처럼 행렬은 벡터를 늘이고 돌린다. 대부분의 벡터는 변환 후 방향이 바뀐다. 그런데 어떤 벡터는 변환 후에도 같은 직선 위에 남고 길이만 바뀐다. 이런 벡터를 **고유벡터**(eigenvector), 늘어난 배율을 **고유값**(eigenvalue)이라고 한다.
```text
Av = λv      (v ≠ 0)
```

`A = [[2, 1], [1, 2]]`로 확인해 보자.
```text
A·(1, 0)  = (2, 1)              방향이 바뀌었다 → 고유벡터 아님
A·(1, 1)  = (3, 3)  = 3·(1, 1)   방향 그대로, 3배 → 고유값 3
A·(1, −1) = (1, −1) = 1·(1, −1)  방향 그대로, 1배 → 고유값 1
```

고유값이 음수면 방향이 정반대로 뒤집히고, 0이면 그 방향이 원점으로 눌린다. 고유벡터에 0이 아닌 수를 곱해도 여전히 고유벡터이므로, 고유벡터는 하나의 벡터라기보다 "하나의 방향"이다. 행렬이 하는 복잡한 일을 고유벡터 방향으로 보면 단순한 늘이기로 바뀐다는 것이 핵심이다.

## 특성 방정식으로 손으로 풀기
`Av = λv`를 옮기면 `(A − λI)v = 0`이다. 0이 아닌 v가 이 식을 만족하려면 `A − λI`가 공간을 눌러 버리는 행렬이어야 하고, 7편 「행렬식: 부피가 변하는 비율」에 따르면 그 조건은 행렬식이 0인 것이다. 이 식을 **특성 방정식**이라고 한다.
```text
A − λI = [ 2−λ    1  ]
         [  1   2−λ  ]

det(A − λI) = (2 − λ)² − 1
            = λ² − 4λ + 3
            = (λ − 1)(λ − 3) = 0   →   λ = 1, 3

λ = 3:  (A − 3I)v = [ −1   1 ] v = 0  →  v = (1, 1)
                    [  1  −1 ]
λ = 1:  (A − I)v  = [  1   1 ] v = 0  →  v = (1, −1)
                    [  1   1 ]
```

덤으로 확인할 수 있는 성질이 있다. 고유값의 합 1 + 3 = 4는 대각선 원소의 합(**대각합**, trace) 2 + 2와 같고, 고유값의 곱 1·3 = 3은 행렬식 2·2 − 1·1과 같다. 복소수 고유값과 중복까지 세면 이는 모든 정사각 행렬에서 성립한다. NumPy로 확인해 보자.
```python
import numpy as np

A = np.array([[2, 1],
              [1, 2]], dtype=float)

vals, vecs = np.linalg.eigh(A)   # 대칭 행렬 전용: 고유값을 오름차순으로 준다
print(vals)                      # [1. 3.]
print(vecs)                      # [[-0.70710678  0.70710678]
                                 #  [ 0.70710678  0.70710678]]
```

`vecs`의 각 열이 고유벡터이며, 길이 1로 정규화되어 있다. 첫 열은 (1, −1)의 −1배를 정규화한 것인데, 고유벡터는 방향만 의미가 있으므로 부호가 바뀌어 나와도 같은 답이다. 대칭이 아닌 일반 행렬에는 `np.linalg.eig`를 쓴다. 참고로 90° 회전 행렬은 모든 벡터의 방향을 바꾸므로 실수 고유값이 없고, `eig`는 복소수 ±i를 돌려준다.

## 대칭 행렬은 특별하다
`Aᵀ = A`인 **대칭 행렬**은 특히 좋은 성질을 가진다.
- 고유값이 모두 **실수**다.
- 서로 다른 고유값의 고유벡터는 **직교**한다. 위 예에서도 `(1, 1) · (1, −1) = 0`이다.
- 따라서 고유벡터를 정규직교 기저로 골라 `A = QΛQᵀ`로 쓸 수 있다. Q의 열은 고유벡터, Λ는 고유값을 대각선에 놓은 행렬이다.

마지막 식은 "대칭 행렬은 서로 직각인 몇 방향으로 각각 늘이기만 하는 변환"이라는 뜻이다. 공분산 행렬처럼 데이터 분석에서 만나는 중요한 행렬은 대부분 대칭이라서, 이 성질이 11편 「주성분 분석(PCA): 차원 축소」의 기반이 된다.

## 거듭 곱하면 무슨 일이 생기나
벡터 x를 고유벡터의 조합 `x = c₁v₁ + c₂v₂`로 쓰면 A를 k번 곱한 결과가 간단해진다.
```text
Aᵏx = c₁·λ₁ᵏ·v₁ + c₂·λ₂ᵏ·v₂
```

위 예에서 `x = (1, 0) = ½·(1, 1) + ½·(1, −1)`이므로 `Aᵏx = ½·3ᵏ·(1, 1) + ½·(1, −1)`이다. k = 5면 (122, 121), k = 10이면 (29525, 29524)로, 고유값 3의 방향 (1, 1)이 점점 모든 것을 압도한다. 일반적으로 절댓값이 가장 큰 고유값의 방향이 살아남는다.

이 현상을 거꾸로 이용하면 가장 큰 고유값과 그 고유벡터를 구할 수 있다. 아무 벡터에서 시작해 A를 계속 곱하고 길이를 1로 맞추면 된다. 이것이 **거듭제곱법**(power iteration)이다.
```python
def power_iteration(A, steps=50):      # 앞 코드에 이어서
    v = np.array([1.0, 0.0])           # 아무 벡터에서 시작
    for _ in range(steps):
        v = A @ v
        v = v / np.linalg.norm(v)      # 폭주하지 않게 길이를 1로 맞춘다
    return v @ A @ v, v                # 고유값 추정, 고유벡터

lam, v = power_iteration(A)
print(round(lam, 6), v.round(6))       # 3.0 [0.707107 0.707107]
```

행렬이 아주 커서 고유값을 전부 구할 수 없을 때도 행렬-벡터 곱만으로 가장 중요한 방향을 찾을 수 있다. 웹 페이지의 중요도를 매기는 PageRank도 이런 반복으로 계산하는 것으로 알려져 있다.

고유값의 크기는 장기적인 운명을 정한다. `∣λ∣ > 1`인 방향은 기하급수적으로 커지고, `∣λ∣ < 1`인 방향은 0으로 사라진다. 1.1⁵⁰ ≈ 117이지만 0.9⁵⁰ ≈ 0.005다.

## 정리
- 고유벡터는 `Av = λv`를 만족하는 방향으로, 행렬이 그 방향으로는 λ배 늘이기만 한다.
- 고유값은 특성 방정식 `det(A − λI) = 0`의 해이며, 합은 대각합, 곱은 행렬식과 같다.
- 대칭 행렬은 실수 고유값과 서로 직교하는 고유벡터를 가진다.
- 거듭 곱하면 가장 큰 고유값의 방향이 지배하며, 이를 이용한 것이 거듭제곱법이다.
