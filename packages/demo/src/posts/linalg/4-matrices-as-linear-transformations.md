# [선형대수 4/12] 선형 변환으로서의 행렬

> **한 줄 요약** — 행렬은 공간을 늘이고 돌리고 기울이는 함수이며, 그 행렬의 열은 "기저 벡터가 어디로 가는지"를 적어 둔 것이고, 변환을 이어 붙이는 것은 행렬을 곱하는 것과 같다.

## 이 글에서 다루는 것
- 행렬을 함수로 보기: 선형성의 정의
- 행렬의 열 = 기저 벡터의 행선지
- 회전, 확대, 전단의 2×2 예
- 합성 = 행렬 곱, 그리고 순서
- 선형 층을 아무리 쌓아도 하나의 행렬인 이유

## 행렬은 함수다
3편 「행렬과 행렬 곱」에서는 행렬을 숫자 표로 보고 곱셈 규칙을 익혔다. 이번에는 관점을 바꿔 행렬 A를 **벡터를 받아 벡터를 돌려주는 함수** `x ↦ Ax`로 본다. m×n 행렬은 n차원 벡터를 m차원 벡터로 보내는 함수다.

이런 함수 중에서 다음 두 성질을 만족하는 것을 **선형 변환**(linear transformation)이라고 한다.
```text
T(u + v) = T(u) + T(v)      더한 뒤 변환 = 변환한 뒤 더하기
T(c·v)   = c·T(v)           늘인 뒤 변환 = 변환한 뒤 늘이기
```

그림으로 말하면 선형 변환은 원점을 제자리에 두고, 격자의 직선을 직선으로, 평행한 선을 평행하게, 간격은 고르게 유지하는 변환이다. 휘거나 구부러지는 일은 없다. 모든 행렬 곱 `x ↦ Ax`는 선형이고, 거꾸로 유한 차원의 모든 선형 변환은 행렬 하나로 쓸 수 있다.

## 열은 기저 벡터의 행선지다
2차원의 모든 벡터는 `e₁ = (1, 0)`과 `e₂ = (0, 1)`의 조합으로 쓸 수 있다. `v = (x, y) = x·e₁ + y·e₂`이다. 선형성을 적용하면 다음을 얻는다.
```text
T(v) = x·T(e₁) + y·T(e₂)
```

e₁과 e₂가 어디로 가는지만 알면 모든 벡터의 행선지가 정해진다는 뜻이다. 그리고 이 식은 3편에서 본 행렬-벡터 곱의 열 관점과 똑같다. 그래서 **T(e₁)을 첫째 열, T(e₂)를 둘째 열로 쓴 것이 곧 T의 행렬**이다. 낯선 행렬을 만나면 "각 열은 기저 벡터가 도착한 곳"이라고 읽으면 된다.

## 회전, 확대, 전단
이 원리로 대표적인 변환의 행렬을 바로 쓸 수 있다.

| 변환 | e₁의 행선지 | e₂의 행선지 | 효과 |
|---|---|---|---|
| 90° 회전 | (0, 1) | (−1, 0) | 반시계로 돌린다 |
| 확대 | (2, 0) | (0, 0.5) | 가로 2배, 세로 절반 |
| 전단 | (1, 0) | (1, 1) | 위로 갈수록 오른쪽으로 민다 |

행선지를 열로 세우면 행렬이 된다. 일반적인 각도 θ의 회전도 같은 방법으로 얻는다.
```text
90° 회전 R       확대 D
[ 0  −1 ]        [ 2   0  ]
[ 1   0 ]        [ 0  0.5 ]

전단 S           θ 회전
[ 1  1 ]         [ cos θ  −sin θ ]
[ 0  1 ]         [ sin θ   cos θ ]
```

확대 행렬 D는 `(1, 1)`을 `(2, 0.5)`로 보내 정사각형을 납작한 직사각형으로 만든다. 전단 S는 정사각형을 평행사변형으로 기울인다. 반면 모든 점을 `(1, 0)`만큼 옮기는 평행 이동은 원점을 움직이므로 선형 변환이 아니다. 선형 변환 뒤에 평행 이동을 더한 `Ax + b`는 **아핀 변환**이라고 부른다.

## 합성은 행렬 곱이다
벡터에 먼저 B를, 그다음 A를 적용하면 `A(Bx) = (AB)x`이다. 두 변환을 이어 붙인 결과가 행렬 AB 하나로 표현된다. 수학 표기에서는 **오른쪽 행렬이 먼저** 적용된다는 점에 주의한다.

3편에서 본 것처럼 행렬 곱은 교환 법칙이 성립하지 않으므로 변환의 순서가 중요하다.
```python
import numpy as np

R = np.array([[0, -1],
              [1,  0]])    # 90° 회전
S = np.array([[1, 1],
              [0, 1]])     # 전단
v = np.array([1, 0])

print(S @ (R @ v))   # [1 1]  회전 먼저, 그다음 전단
print(R @ (S @ v))   # [0 1]  전단 먼저, 그다음 회전
```

책을 90° 돌린 뒤 옆으로 미는 것과, 옆으로 민 뒤 돌리는 것은 다른 결과를 낳는다. 행렬 곱의 비교환성은 이 당연한 사실의 계산 버전이다.

## 선형 층은 쌓아도 하나다
AI 기초 1편 「딥러닝: 특징까지 스스로 배우는 머신러닝」은 "선형 변환은 아무리 겹쳐도 하나의 선형 변환이라서 비선형 활성화가 필요하다"고 했다. 이제 이 말을 행렬로 확인할 수 있다. 수학 표기로 `W₂(W₁x) = (W₂W₁)x`이다. 코드에서는 샘플을 행으로 쌓는 관례 때문에 순서가 바뀌어 `(X @ W1) @ W2 = X @ (W1 @ W2)`가 된다.
```python
import numpy as np

rng = np.random.default_rng(0)
X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], dtype=float)
W1 = rng.normal(size=(2, 8))     # 은닉층 가중치
W2 = rng.normal(size=(8, 1))     # 출력층 가중치

two_layers = (X @ W1) @ W2       # 활성화 함수 없이 두 층
W = W1 @ W2                      # 두 행렬을 미리 곱하면
print(W.shape)                   # (2, 1)  하나의 2×1 행렬
print(np.allclose(two_layers, X @ W))     # True  두 층 = 한 층

with_relu = np.maximum(0, X @ W1) @ W2   # 사이에 ReLU를 넣으면
print(np.allclose(with_relu, X @ W))     # False 더는 하나로 합쳐지지 않는다
```

은닉 뉴런이 8개든 800개든, 층이 둘이든 백 개든 활성화 함수가 없으면 결과는 행렬 하나다. 편향을 더해도 `(xW₁ + b₁)W₂ + b₂ = x(W₁W₂) + (b₁W₂ + b₂)`로 아핀 변환 하나로 합쳐진다. 실제로 XOR의 네 점에 아핀 함수 `w₁x₁ + w₂x₂ + c`를 가장 잘 맞춰 보면(9편 「직교성과 사영」의 최소제곱법) 계수가 `w₁ = w₂ = 0, c = 0.5`로 나와 네 입력 모두에 0.5를 출력한다. 직선 하나로는 XOR을 나눌 수 없다는 사실이 숫자로 드러난다. ReLU나 tanh가 격자를 구부려야 깊이가 의미를 가진다.

## 어디에 쓰이나
- AI 기초 1편 「딥러닝: 특징까지 스스로 배우는 머신러닝」: 신경망의 각 층은 선형 변환(`X @ W + b`)과 비선형 활성화의 조합이며, 활성화가 빠지면 층 전체가 행렬 하나로 무너진다.
- AI 기초 4편 「컴퓨터 사이언스로 보는 AI 모델: 텐서, 연산, 메모리」: 모델 파일 속 4096×4096 가중치 배열 하나하나가 4096차원 공간을 다른 4096차원 공간으로 보내는 선형 변환이다.
- 미적분 8편 「다변수 연쇄 법칙과 야코비 행렬」: 휘어진 함수도 한 점 근처를 확대하면 선형 변환처럼 보이며, 그 선형 변환의 행렬이 야코비 행렬이다.

## 정리
- 선형 변환은 덧셈과 스칼라 곱을 보존하는 함수이고, 모든 행렬 곱 `x ↦ Ax`가 그렇다.
- 행렬의 각 열은 기저 벡터가 변환 후 도착하는 곳이다.
- 변환의 합성은 행렬 곱이며, 순서를 바꾸면 결과가 달라진다.
- 선형 층은 몇 개를 쌓아도 행렬 하나와 같으므로, 신경망에는 비선형 활성화가 반드시 필요하다.
