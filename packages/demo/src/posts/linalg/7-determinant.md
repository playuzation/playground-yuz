# [선형대수 7/12] 행렬식: 부피가 변하는 비율

## 2×2 행렬식: 넓이가 몇 배가 되나
4편 「선형 변환으로서의 행렬」에서 행렬의 열은 기저 벡터의 행선지라고 했다. 한 변이 1인 정사각형은 e₁과 e₂가 만드는 도형이므로, 변환 후에는 두 열 벡터가 만드는 평행사변형이 된다. 이 평행사변형의 넓이가 바로 **행렬식**(determinant)의 크기다.
```text
A = [ a  b ]      det(A) = ad − bc
    [ c  d ]
```

선형 변환은 격자를 고르게 유지하므로 정사각형뿐 아니라 모든 도형의 넓이가 똑같은 비율로 바뀐다. 그래서 행렬식은 "이 변환이 넓이를 몇 배로 만드는가"라는 **배율**이다.
```text
[ 3  1 ]  det = 3·2 − 1·1 = 5     넓이 5배
[ 1  2 ]

[ 2  0 ]  det = 6                 가로 2배 × 세로 3배
[ 0  3 ]

[ 1  1 ]  det = 1                 전단: 기울기만 하고 넓이는 그대로
[ 0  1 ]

[ 0  1 ]  det = −1                e₁과 e₂를 맞바꿈: 넓이는 그대로, 거울상
[ 1  0 ]

[ 1  2 ]  det = 0                 두 열이 한 직선 위: 평면이 직선으로 눌림
[ 2  4 ]
```

3차원에서는 단위 정육면체가 세 열 벡터가 만드는 평행육면체로 바뀌고, 행렬식은 **부피 배율**이 된다. n차원에서도 같은 의미가 유지된다.

## 부호: 공간이 뒤집혔는가
넓이는 음수일 수 없는데 행렬식은 음수가 될 수 있다. 부호는 **방향**(orientation)을 나타낸다. 평면에서 e₁에서 e₂로 반시계 방향으로 도는 관계가 변환 후에도 유지되면 양수, 시계 방향으로 바뀌면 음수다. 종이를 뒤집어 거울상을 만드는 변환이 음수다. 위 예에서 두 열을 맞바꾼 행렬의 행렬식이 −1인 이유가 이것이다. 실제 넓이 배율은 절댓값 `∣det(A)∣`이다.

## det = 0: 납작하게 눌린 공간
행렬식이 0이면 넓이(부피)가 0이 된다. 평면 전체가 직선이나 점으로, 3차원 공간이 평면 이하로 눌린 것이다. 이렇게 차원이 줄면 서로 다른 많은 점이 같은 점으로 겹쳐서 원래 위치를 되돌릴 방법이 없다. 그래서 정사각 행렬 A에 대해 다음은 모두 같은 말이다.
```text
det(A) = 0
⇔ 역행렬이 없다
⇔ 열이 일차 종속이다
⇔ 랭크 < n
⇔ Ax = 0에 0이 아닌 해가 있다
```

5편 「연립일차방정식과 역행렬」의 2×2 역행렬 공식에서 `1/(ad − bc)`가 나온 것도 우연이 아니다. 넓이를 det배로 바꾼 변환을 되돌리려면 넓이를 1/det배로 바꿔야 한다. 6편 「일차 독립, 기저, 차원, 랭크」의 랭크와 행렬식은 같은 현상을 각각 "남은 차원의 수"와 "부피 배율"로 본 것이다.

## 곱의 행렬식
변환 B를 한 뒤 A를 하면 넓이는 먼저 det(B)배, 그다음 det(A)배가 된다. 그러므로 다음이 성립한다.
```text
det(AB) = det(A) · det(B)
```

여기서 바로 `det(A⁻¹) = 1/det(A)`가 나온다. `AA⁻¹ = I`이고 단위 행렬은 아무것도 바꾸지 않으므로 `det(I) = 1`이기 때문이다.

## 3×3 행렬식과 NumPy
3×3은 첫 행을 따라 펼치는 공식(여인수 전개)으로 계산할 수 있다.
```text
A = [ 2  1  0 ]
    [ 1  3  1 ]   det(A) = 2·(3·4 − 1·1) − 1·(1·4 − 1·0) + 0·(…) = 22 − 4 = 18
    [ 0  1  4 ]
```

이 방식은 n이 커지면 계산량이 폭발하므로, 컴퓨터는 5편의 LU 분해로 삼각 행렬을 만든 뒤 대각선 원소를 곱해 행렬식을 구한다. 그 과정에서 나눗셈이 들어가므로 정수 행렬이어도 결과에 부동소수점 오차가 섞인다.
```python
import numpy as np

A = np.array([[2, 1, 0],
              [1, 3, 1],
              [0, 1, 4]], dtype=float)
B = np.array([[1, 2, 0],
              [3, 1, 0],
              [0, 0, 1]], dtype=float)

print(np.linalg.det(A))        # 17.999999999999996  (정확한 값은 18)
print(np.linalg.det(B))        # -5.000000000000001  (정확한 값은 −5)
print(np.linalg.det(A @ B))    # -90.0
print(np.isclose(np.linalg.det(A @ B), np.linalg.det(A) * np.linalg.det(B)))  # True
```

그래서 실무에서는 두 가지를 조심한다.
- `det(A) == 0`으로 특이 행렬을 판정하지 않는다. `np.isclose`로 비교하거나 `np.linalg.matrix_rank`를 쓴다.
- 행렬식의 크기는 "역행렬을 구하기 쉬운 정도"를 알려 주지 않는다. 100×100 행렬 `0.1·I`의 행렬식은 10⁻¹⁰⁰이지만 모든 방향을 똑같이 줄일 뿐이라 완벽하게 되돌릴 수 있다. 수치적으로 위험한지는 5편에서 말한 조건수로 판단한다.

## 어디에 쓰이나
- AI 기초 4편 「컴퓨터 사이언스로 보는 AI 모델: 텐서, 연산, 메모리」: `0.1 + 0.2`가 정확히 0.3이 아니듯, 정수 행렬의 행렬식도 계산 과정의 부동소수점 반올림 때문에 17.999999999999996처럼 나온다.
- AI 기초 3편 「데이터 분포로 보는 AI 모델」: 생성 모델의 한 종류인 정규화 흐름(normalizing flow)은 변환이 공간을 얼마나 늘이고 줄였는지를 야코비 행렬의 행렬식으로 재서 `p(x)`를 정확히 계산한다(야코비 행렬은 미적분 8편 「다변수 연쇄 법칙과 야코비 행렬」).
- 8편 「고유값과 고유벡터」: 고유값은 `det(A − λI) = 0`, 즉 "A − λI가 공간을 눌러 버리는 λ"를 찾는 특성 방정식으로 구한다.

## 정리
- 행렬식은 선형 변환의 넓이·부피 배율이며, 2×2에서는 `ad − bc`다.
- 부호가 음수면 공간의 방향이 뒤집힌 것이고, 0이면 차원이 눌려 역행렬이 없다.
- `det(AB) = det(A)·det(B)`이며, NumPy의 행렬식에는 부동소수점 오차가 섞이므로 0과 정확히 비교하지 않는다.
