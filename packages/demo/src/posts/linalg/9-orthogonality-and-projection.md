## 정규직교 기저: 가장 다루기 쉬운 기저
2편 「내적과 코사인 유사도」에서 내적이 0인 두 벡터를 직교한다고 했다. 서로 모두 직교하고 길이가 각각 1인 벡터 묶음 q₁, …, qₙ을 **정규직교**(orthonormal)라고 한다.
```text
qᵢ · qⱼ = 0   (i ≠ j),     qᵢ · qᵢ = 1
```

정규직교 기저의 장점은 좌표 구하기가 쉽다는 것이다. 6편 「일차 독립, 기저, 차원, 랭크」에서 일반적인 기저의 좌표를 구하려면 연립방정식을 풀어야 했다. 정규직교 기저에서는 각 기저 벡터와 내적만 하면 된다. 다른 기저 벡터와의 내적이 모두 0이라 서로 간섭하지 않기 때문이다.
```text
x = (x · q₁) q₁ + (x · q₂) q₂ + … + (x · qₙ) qₙ
```

## 직선으로의 사영
벡터 a를 u 방향의 직선 위로 수직으로 내린 그림자를 a의 u 위로의 **사영**(projection)이라고 한다. 사영 p는 u의 상수배 `c·u`이고, 남는 부분 `a − c·u`가 u와 직교해야 한다는 조건으로 c를 정한다.
```text
(a − c·u) · u = 0   →   c = (a · u) / (u · u)

proj_u(a) = (a · u) / (u · u) · u
```

예를 들어 `a = (2, 3)`을 `u = (1, 1)` 위로 사영하면 `c = 5/2`이므로 사영은 (2.5, 2.5), 남는 부분은 (−0.5, 0.5)다. 남는 부분과 u의 내적은 `−0.5 + 0.5 = 0`으로 확실히 직교한다. 피타고라스 정리에 따라 직선 위의 다른 어떤 점보다 사영 p가 a에 가장 가깝다. **사영은 가장 가까운 점**이라는 이 사실이 이 글의 핵심이다.

## 부분 공간으로의 사영과 정규 방정식
직선 대신 행렬 A의 열들이 생성하는 공간(열 공간) 위로 벡터 y를 사영해 보자. 3편 「행렬과 행렬 곱」에 따르면 열 공간의 점은 `Ax` 꼴이다. 사영 `p = Ax̂`의 조건은 남는 부분 `y − Ax̂`가 열 공간의 모든 방향, 즉 A의 **모든 열과 직교**하는 것이다. A의 모든 열과 내적한 결과를 한꺼번에 쓰면 `Aᵀ(y − Ax̂) = 0`이다.
```text
Aᵀ(y − Ax̂) = 0   →   AᵀA x̂ = Aᵀy      (정규 방정식)
```

이것을 **정규 방정식**(normal equation)이라고 한다. 여기서 "normal"은 "수직"이라는 뜻이다. 직선 사영 공식은 A가 열 하나 u뿐인 특수한 경우다.

## 최소제곱법: 풀 수 없는 방정식의 최선의 답
점 네 개 (0, 1), (1, 2), (2, 2), (3, 4)를 지나는 직선 `y = c + m·t`를 찾고 싶다고 하자. 방정식은 네 개인데 미지수는 c, m 두 개뿐이라 모든 점을 정확히 지나는 직선은 없다. 열 관점으로 말하면 y가 A의 열 공간 밖에 있다.

그렇다면 오차의 제곱합 `‖y − Ax‖²`을 가장 작게 하는 x를 고르자. 이것이 **최소제곱법**(least squares)이다. 그런데 열 공간에서 y와 가장 가까운 점이 바로 사영이므로, 최소제곱 해는 정규 방정식의 해와 같다.
```python
import numpy as np

t = np.array([0, 1, 2, 3], dtype=float)
y = np.array([1, 2, 2, 4], dtype=float)
A = np.column_stack([np.ones_like(t), t])    # 열: [1, t]  →  y ≈ c + m·t

coef = np.linalg.solve(A.T @ A, A.T @ y)     # 정규 방정식
print(coef)                                  # [0.9 0.9]  →  y = 0.9 + 0.9·t
p = A @ coef                                 # 열 공간으로의 사영
print(p)                                     # [0.9 1.8 2.7 3.6]
print(A.T @ (y - p))                         # [ 0.0000000e+00 -4.4408921e-16]  사실상 0
print(np.linalg.lstsq(A, y, rcond=None)[0])  # [0.9 0.9]  같은 답
```

셋째 출력은 오차 벡터가 두 열과 직교한다는 확인이다. 정확히 0이 아니라 10⁻¹⁶ 수준인 것은 부동소수점 오차다. 실무에서는 `AᵀA`를 직접 만들면 조건이 나빠질 수 있어서, `AᵀA`를 만들지 않고 아래의 QR 분해나 10편의 SVD로 푸는 방법을 권한다. `np.linalg.lstsq`는 내부적으로 SVD를 쓴다. 오차를 왜 제곱해서 재는지, 그 계수를 통계적으로 어떻게 해석하는지는 통계학 8편 「선형 회귀와 최소제곱법」에서 다룬다.

## 직교 행렬: 길이를 보존하는 변환
열들이 정규직교인 정사각 행렬 Q를 **직교 행렬**이라고 한다. 열끼리의 내적을 모두 모으면 단위 행렬이 되므로 `QᵀQ = I`, 즉 `Q⁻¹ = Qᵀ`이다. 역행렬을 전치 한 번으로 얻는 셈이다.

직교 행렬은 벡터의 길이와 각도를 바꾸지 않는다. `‖Qx‖² = xᵀQᵀQx = xᵀx = ‖x‖²`이기 때문이다. 4편 「선형 변환으로서의 행렬」의 회전 행렬과 거울 반사가 대표적인 예다. 길이를 늘이거나 줄이지 않으므로 오차도 키우지 않아서, 수치 계산에서 매우 환영받는다.

아무 일차 독립 벡터 묶음이 주어지면 **그람-슈미트 과정**으로 정규직교 기저를 만들 수 있다. 벡터를 하나씩 보면서 앞서 만든 방향들로의 사영을 빼고 길이를 1로 맞추는 방법이다. 그 결과를 행렬로 쓴 것이 `A = QR` 분해이며, NumPy의 `np.linalg.qr`은 같은 분해를 수치적으로 더 안정된 방법으로 계산한다.

## 정리
- 정규직교 기저에서는 좌표가 내적 한 번으로 구해진다.
- 사영은 수직으로 내린 그림자이자 부분 공간에서 가장 가까운 점이며, 남는 부분이 부분 공간과 직교한다는 조건으로 구한다.
- 최소제곱법은 열 공간으로의 사영이고, 그 조건이 정규 방정식 `AᵀA x̂ = Aᵀy`다.
- 직교 행렬은 `QᵀQ = I`를 만족하며 길이와 각도를 보존한다.
