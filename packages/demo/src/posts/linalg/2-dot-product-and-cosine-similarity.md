# [선형대수 2/12] 내적과 코사인 유사도

> **한 줄 요약** — 내적은 같은 자리끼리 곱해 모두 더하는 단순한 계산이지만, 그 값은 두 벡터의 길이와 사이 각도를 담고 있어서 "얼마나 같은 방향인가"를 재는 도구가 된다.

## 이 글에서 다루는 것
- 내적의 정의: 곱해서 더하기
- 기하적 의미: 길이 × 길이 × cos θ
- 직교: 내적이 0인 두 벡터
- 코사인 유사도로 문서 비교하기

## 정의: 곱해서 더하기
같은 차원의 두 벡터 a, b의 **내적**(dot product)은 같은 자리 성분끼리 곱한 뒤 모두 더한 값이다.
```text
a · b = a₁b₁ + a₂b₂ + … + aₙbₙ = Σ aᵢbᵢ

(1, 2, 3) · (4, 5, 6) = 1·4 + 2·5 + 3·6 = 32
```

결과는 벡터가 아니라 숫자 하나다. 그래서 스칼라곱(scalar product)이라고도 부른다. 자기 자신과의 내적은 성분의 제곱합이므로 `a · a = ‖a‖²`, 즉 길이의 제곱이다. NumPy에서는 `a @ b` 또는 `np.dot(a, b)`로 계산한다.

## 기하적 의미: 길이 × 길이 × cos θ
내적의 진짜 힘은 다음 등식에서 나온다. θ는 두 화살표 사이의 각도다.
```text
a · b = ‖a‖ ‖b‖ cos θ
```

이 식은 코사인 법칙에서 바로 나온다. 두 벡터 a, b와 그 차이 a − b로 삼각형을 만들면 다음이 성립한다.
```text
코사인 법칙:  ‖a − b‖² = ‖a‖² + ‖b‖² − 2‖a‖‖b‖ cos θ
성분 전개:    ‖a − b‖² = Σ (aᵢ − bᵢ)² = ‖a‖² + ‖b‖² − 2 Σ aᵢbᵢ
두 식 비교:   Σ aᵢbᵢ = ‖a‖‖b‖ cos θ
```

성분끼리의 단순한 곱셈과 덧셈이 각도라는 기하적 정보를 담고 있다는 뜻이다. 예를 들어 `a = (1, 0)`, `b = (1, 1)`이면 내적은 1, 길이는 1과 √2이므로 `cos θ = 1/√2 ≈ 0.707`, θ는 45°다.

또 하나의 해석은 그림자다. a를 b 방향으로 비췄을 때 생기는 그림자의 길이는 `‖a‖ cos θ`이고, 내적은 이 그림자 길이에 ‖b‖를 곱한 값이다. 이 관점은 9편 「직교성과 사영」에서 사영 공식으로 이어진다.

## 부호가 알려 주는 것: 직교
길이는 항상 0 이상이므로 내적의 부호는 cos θ가 정한다.

| 각도 θ | cos θ | 내적 | 의미 |
|---|---|---|---|
| 0° ≤ θ < 90° | 양수 | 양수 | 대체로 같은 방향 |
| θ = 90° | 0 | 0 | 직교 |
| 90° < θ ≤ 180° | 음수 | 음수 | 대체로 반대 방향 |

내적이 0인 두 벡터를 **직교**(orthogonal)한다고 한다. `(2, 1) · (−1, 2) = −2 + 2 = 0`이므로 두 벡터는 직각을 이룬다. 2차원, 3차원에서는 직각이라는 그림이 있지만, 1000차원에서도 "내적이 0"이라는 계산 하나로 직교를 정의할 수 있다. 직교는 서로 아무 성분도 공유하지 않는다는 뜻이라서, 9편에서 보듯 계산을 크게 단순하게 만든다.

## 코사인 유사도: 방향만 비교하기
내적은 방향뿐 아니라 길이에도 영향을 받는다. 같은 방향이라도 긴 벡터끼리는 내적이 크다. 길이의 영향을 빼고 방향만 비교하고 싶으면 내적을 두 길이로 나눈다. 이것이 **코사인 유사도**(cosine similarity)다.
```text
cos_sim(a, b) = (a · b) / (‖a‖ ‖b‖)      범위: −1 ~ 1
```

1이면 완전히 같은 방향, 0이면 무관(직교), −1이면 정반대다. 문서를 단어 빈도 벡터로 바꿔 비교해 보자.
```python
import numpy as np

def cos_sim(a, b):
    return a @ b / (np.linalg.norm(a) * np.linalg.norm(b))

# 단어 순서: [고양이, 강아지, 사료, 주식, 금리]
pet1 = np.array([3, 2, 1, 0, 0])   # 반려동물 글
pet2 = np.array([1, 3, 2, 0, 0])   # 다른 반려동물 글
econ = np.array([0, 0, 1, 4, 3])   # 경제 기사 (사료 회사 주가 이야기)
long = 2 * pet1                    # pet1을 두 번 이어 붙인 글

print(round(cos_sim(pet1, pet2), 3))   # 0.786  주제가 비슷하다
print(round(cos_sim(pet1, econ), 3))   # 0.052  "사료" 하나만 겹친다
print(round(cos_sim(pet1, long), 3))   # 1.0    길이만 다르고 방향은 같다
print(pet1 @ pet2, pet1 @ long)        # 11 28  내적은 길이에 끌려간다
```

마지막 줄이 핵심이다. `long`은 내용이 pet1과 똑같은데도 내적은 pet2보다 훨씬 크다. 코사인 유사도는 글의 길이를 무시하고 주제의 방향만 보므로 1.0이 나온다.

실제 검색 시스템은 단어 빈도 대신 1편 「벡터: 숫자의 목록이자 공간의 화살표」에서 본 임베딩 벡터를 쓴다. 이때 모든 임베딩을 미리 단위 벡터로 정규화해 두면 분모가 1이 되어 코사인 유사도가 곧 내적이 된다. 수백만 개의 문서 벡터와 비교할 때 나눗셈을 생략할 수 있어서 벡터 검색에서 흔히 쓰는 방법이다.

## 정리
- 내적은 `Σ aᵢbᵢ`로 계산하고, 그 값은 `‖a‖‖b‖ cos θ`와 같다.
- 내적의 부호는 두 벡터가 같은 쪽인지 반대쪽인지 알려 주며, 0이면 직교다.
- 코사인 유사도는 내적을 두 길이로 나눠 방향만 비교하는 척도로, 문서·단어·임베딩 비교에 널리 쓰인다.
