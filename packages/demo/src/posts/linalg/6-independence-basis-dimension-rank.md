## 선형 결합과 생성
벡터들에 각각 숫자를 곱해 더한 `c₁v₁ + c₂v₂ + … + cₖvₖ`를 **선형 결합**이라고 한다. 벡터 몇 개로 만들 수 있는 모든 선형 결합의 모임을 그 벡터들이 **생성**(span)하는 공간이라 한다.

3차원에서 영벡터가 아닌 벡터 하나가 생성하는 것은 원점을 지나는 직선이다. 방향이 다른 벡터 두 개는 원점을 지나는 평면을 생성한다. 세 번째 벡터가 그 평면 밖을 가리키면 셋은 3차원 공간 전체를 생성한다. 하지만 세 번째 벡터가 평면 안에 있으면 아무것도 늘지 않는다.

## 일차 독립과 일차 종속
다음 세 벡터를 보자.
```text
v₁ = (1, 0, 1)    v₂ = (0, 1, 1)    v₃ = (1, 1, 2) = v₁ + v₂
```

v₃은 v₁과 v₂로 만들 수 있으므로 새로운 정보가 없다. 이처럼 어떤 벡터가 나머지의 선형 결합으로 표현되면 그 묶음은 **일차 종속**(linearly dependent)이고, 그런 벡터가 하나도 없으면 **일차 독립**(linearly independent)이다. 정확한 정의는 다음과 같다.
```text
c₁v₁ + c₂v₂ + … + cₖvₖ = 0 을 만족하는 c가 c₁ = c₂ = … = cₖ = 0 뿐이면 일차 독립
```

위 예에서는 `1·v₁ + 1·v₂ − 1·v₃ = 0`이라는 0이 아닌 조합이 있으므로 종속이다. 일차 독립은 "묶음 안에 군더더기가 없다"는 뜻이다.

## 기저, 좌표, 차원
어떤 공간을 생성하면서 일차 독립인 벡터 묶음을 그 공간의 **기저**(basis)라고 한다. 군더더기 없이 공간 전체를 만들어 내는 최소한의 재료다. `ℝ²`의 표준 기저는 `e₁ = (1, 0)`, `e₂ = (0, 1)`이지만, 기저는 하나가 아니다. `b₁ = (1, 1)`, `b₂ = (1, −1)`도 기저다.

기저가 정해지면 모든 벡터는 기저의 선형 결합으로 **딱 한 가지** 방법으로 쓸 수 있고, 그 계수를 **좌표**라고 한다. `(3, 1) = 2·b₁ + 1·b₂`이므로 기저 {b₁, b₂}에서 (3, 1)의 좌표는 (2, 1)이다. 같은 화살표라도 기저에 따라 좌표가 달라진다. 좌표를 구하는 일은 5편 「연립일차방정식과 역행렬」의 `Ax = b`를 푸는 일과 같다.

한 공간의 기저는 여러 가지지만, 기저를 이루는 벡터의 **개수**는 항상 같다. 이 개수가 그 공간의 **차원**이다. `ℝⁿ`은 n차원이고, 3차원 공간 속에서 원점을 지나는 평면은 2차원이다. 위의 v₁, v₂, v₃이 생성하는 공간도 2차원 평면이다.

## 랭크: 진짜 정보의 개수
행렬의 열들이 생성하는 공간을 **열 공간**이라 하고, 그 차원을 행렬의 **랭크**(rank)라고 한다. 쉽게 말해 일차 독립인 열의 최대 개수다. 놀랍게도 일차 독립인 행의 최대 개수도 항상 랭크와 같다.
```python
import numpy as np

v1 = np.array([1, 0, 1])
v2 = np.array([0, 1, 1])
v3 = np.array([1, 1, 2])          # v1 + v2
A = np.column_stack([v1, v2, v3])
print(np.linalg.matrix_rank(A))   # 2  열은 3개지만 랭크는 2
```

랭크는 연립방정식과 직결된다. 3편에서 본 열 관점에 따르면 `Ax = b`는 b가 A의 열 공간 안에 있을 때만 해가 있다. 미지수가 n개일 때 랭크가 n이면 해는 많아야 하나이고, 랭크가 n보다 작으면 `n − 랭크`개의 자유 변수가 생겨 해가 무수히 많아지거나 아예 없다. 5편의 표에서 본 세 가지 경우가 랭크로 정리되는 것이다. n×n 정사각 행렬은 랭크가 n일 때(**풀 랭크**) 역행렬을 가진다.

## 저랭크 행렬은 압축할 수 있다
랭크가 r인 m×n 행렬은 언제나 (m×r) 행렬과 (r×n) 행렬의 곱으로 쓸 수 있다. 원래는 m·n개의 숫자가 필요하지만, 곱으로 쓰면 r·(m + n)개면 된다. r이 작으면 엄청난 절약이다.
```python
rng = np.random.default_rng(0)     # 앞 코드에 이어서
u = rng.normal(size=(1000, 1))
v = rng.normal(size=(1, 1000))
M = u @ v                          # 1000×1000 행렬, 원소 100만 개
print(np.linalg.matrix_rank(M))    # 1  숫자 2000개로 전부 표현된다
```

실제 데이터 행렬은 정확히 저랭크인 경우가 드물지만 "거의" 저랭크인 경우가 많다. 주어진 행렬에 가장 가까운 저랭크 행렬을 찾는 방법이 10편 「특이값 분해(SVD)」다. 큰 언어 모델을 미세조정하는 **LoRA**(Low-Rank Adaptation)도 이 아이디어를 쓴다. 원래 가중치 W는 얼려 두고, 변화량을 랭크 r인 두 얇은 행렬의 곱 `B·A`(d×r과 r×d)로만 학습한다.

## 정리
- 선형 결합으로 만들 수 있는 모든 벡터의 모임이 생성(span)이고, 군더더기가 없는 묶음이 일차 독립이다.
- 기저는 공간을 생성하는 일차 독립 묶음이며, 그 개수가 차원이고, 기저에 대한 계수가 좌표다.
- 랭크는 열 공간의 차원, 즉 행렬 속 진짜 정보의 개수이며, 연립방정식의 해의 개수를 결정한다.
- 랭크 r인 m×n 행렬은 숫자 r·(m + n)개로 표현할 수 있고, 이것이 SVD 압축과 LoRA의 바탕이다.
