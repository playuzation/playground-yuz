## 행렬: 숫자의 직사각형
**행렬**(matrix)은 숫자를 가로줄(**행**)과 세로줄(**열**)로 늘어놓은 것이다. 행이 m개, 열이 n개면 m×n 행렬이라 하고, i행 j열의 원소를 `aᵢⱼ`로 쓴다. NumPy에서는 2차원 배열이며 `shape`가 `(m, n)`이다.
```text
M = [ 1  2  0 ]     2×3 행렬 (행 2개, 열 3개)
    [ 0  1  3 ]
```

행렬은 두 가지로 읽을 수 있다. 행 하나하나를 벡터로 보면 "벡터 m개를 쌓은 것", 열을 벡터로 보면 "벡터 n개를 나란히 세운 것"이다. 데이터에서는 보통 행 하나가 샘플 하나, 열 하나가 특징 하나다.

행과 열을 뒤바꾼 것을 **전치**(transpose)라 하고 `Mᵀ`로 쓴다. 2×3 행렬의 전치는 3×2 행렬이고, NumPy에서는 `M.T`다. 뒤에서 자주 나오므로 `(AB)ᵀ = BᵀAᵀ`처럼 순서가 뒤집힌다는 것만 기억해 두자.

## 행렬-벡터 곱: 두 가지 관점
`M`에 벡터 `x = (3, 1, 2)`를 곱해 보자. 같은 계산을 두 방향에서 볼 수 있다.

**행 관점**: 결과의 각 성분은 M의 행과 x의 내적이다.
```text
1행 · x = 1·3 + 2·1 + 0·2 = 5
2행 · x = 0·3 + 1·1 + 3·2 = 7        →  Mx = (5, 7)
```

**열 관점**: 결과는 M의 열들을 x의 성분만큼 섞은 것, 즉 열의 **선형 결합**이다.
```text
Mx = 3·(1, 0) + 1·(2, 1) + 2·(0, 3) = (3, 0) + (2, 1) + (0, 6) = (5, 7)
```

행 관점은 계산할 때, 열 관점은 의미를 생각할 때 편하다. "Mx로 만들 수 있는 결과는 M의 열들을 섞어 만들 수 있는 벡터뿐"이라는 사실은 열 관점에서 바로 보이며, 5편과 6편에서 연립방정식의 해와 랭크를 이해하는 열쇠가 된다.

## 행렬 곱의 정의와 크기 규칙
행렬 A와 B의 곱 C = AB의 i행 j열 원소는 **A의 i행과 B의 j열의 내적**이다.
```text
cᵢⱼ = Σₖ aᵢₖ bₖⱼ

크기 규칙:  (m×k) · (k×n) = (m×n)
안쪽 k가 같아야 곱할 수 있고, 바깥쪽 m, n이 결과의 크기가 된다
```

A의 행 길이와 B의 열 길이가 같아야 내적을 할 수 있으므로 안쪽 크기가 일치해야 한다. 다른 관점으로는, AB는 B의 각 열에 A를 곱한 결과(행렬-벡터 곱)를 나란히 세운 것이다.

## 법칙: 순서는 바꿀 수 없다
숫자의 곱셈과 달리 행렬 곱은 **교환 법칙이 성립하지 않는다**. 크기가 달라 한쪽만 정의되는 경우가 많고, 둘 다 정사각 행렬이어도 결과가 보통 다르다.
```python
import numpy as np

A = np.array([[1, 2],
              [3, 4]])
B = np.array([[0, 1],
              [1, 0]])
C = np.array([[2, 0],
              [0, 3]])

print(A @ B)   # [[2 1]
               #  [4 3]]   AB: A의 두 열을 맞바꾼다
print(B @ A)   # [[3 4]
               #  [1 2]]   BA: A의 두 행을 맞바꾼다
print(np.array_equal((A @ B) @ C, A @ (B @ C)))   # True  결합 법칙
```

반면 **결합 법칙** `(AB)C = A(BC)`와 분배 법칙 `A(B + C) = AB + AC`는 성립한다. 대각선이 1이고 나머지가 0인 **단위 행렬** I는 숫자 1처럼 `AI = IA = A`를 만족한다.

## 곱셈 횟수 세기
(m×k) · (k×n)의 결과에는 원소가 m·n개 있고, 원소 하나마다 길이 k짜리 내적을 하므로 곱셈이 k번 필요하다. 전체 곱셈 횟수는 **m·k·n**이고 덧셈도 거의 같은 횟수다.

결합 법칙 덕분에 곱하는 순서를 고를 수 있는데, 순서에 따라 비용이 크게 달라진다. A, B가 1000×1000이고 x가 1000×1일 때를 비교해 보자.
```text
(AB)x : AB 계산 1000·1000·1000 + (AB)x 계산 1000·1000·1
      = 1,001,000,000번
A(Bx) : Bx 계산 1000·1000·1    + A(Bx) 계산 1000·1000·1
      = 2,000,000번
```

결과는 같지만 비용은 약 500배 차이 난다. 벡터에 행렬 여러 개를 곱할 때는 벡터 쪽부터 곱하는 것이 유리하다.

- 언어 기초 1편 「프로그래밍 언어란 무엇인가」: 같은 행렬 곱도 고수준 파이썬의 삼중 반복문으로 짜느냐, 하드웨어에 맞춰 저수준에서 최적화된 수치 라이브러리(NumPy가 부르는 BLAS)에 맡기느냐에 따라 속도가 수백 배 이상 달라진다.

## 정리
- m×n 행렬은 행 m개, 열 n개의 숫자 배열이며, 전치는 행과 열을 맞바꾼다.
- 행렬-벡터 곱은 "행과의 내적"으로 계산하고 "열의 선형 결합"으로 이해한다.
- (m×k)(k×n) = (m×n)이고 곱셈은 m·k·n번이며, 교환 법칙은 성립하지 않고 결합 법칙은 성립한다.
