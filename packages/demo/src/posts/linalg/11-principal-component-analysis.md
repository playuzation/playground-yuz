## 분산이 가장 큰 방향을 찾자
특징이 수백 개인 데이터를 다루다 보면 특징끼리 서로 강하게 얽혀 있는 경우가 많다. 키와 다리 길이처럼 하나를 알면 다른 하나를 거의 알 수 있다면, 둘을 따로 저장하는 것은 낭비다. **주성분 분석**(PCA, principal component analysis)은 데이터를 새로운 축으로 다시 표현해, 앞쪽 몇 개 축에 정보 대부분이 몰리도록 만든다.

여기서 "정보"는 **분산**, 즉 데이터가 퍼진 정도로 잰다. 2차원 점들이 비스듬한 타원 모양으로 퍼져 있다면, 타원의 긴 축 방향으로 사영했을 때 점들이 가장 넓게 퍼져 서로 잘 구분된다. 짧은 축 방향은 거의 변화가 없으니 버려도 잃는 것이 적다. PCA는 이 긴 축을 찾는 일이다.

## 중심화와 공분산 행렬
먼저 각 특징에서 평균을 빼 데이터의 중심을 원점으로 옮긴다. 이것을 **중심화**(centering)라고 한다. 방향을 찾을 때 원점을 지나는 직선만 고려하면 되도록 하는 준비 작업이다.

중심화한 데이터 행렬 `X_c`(n개 샘플 × d개 특징)로 **공분산 행렬**을 만든다.
```text
C = X_cᵀ X_c / (n − 1)        크기 d×d, 대칭 행렬
```

대각선 원소는 각 특징의 분산이고, 나머지 원소는 두 특징이 함께 변하는 정도인 공분산이다. 공분산의 확률적 의미는 확률과 분포 5편 「분산, 공분산, 상관계수」에서 다룬다. 여기서 중요한 것은 이 행렬이 **대칭**이라는 점이다.

## 주성분 = 공분산 행렬의 고유벡터
단위 벡터 w 방향으로 데이터를 사영하면, 사영된 값들의 분산은 `wᵀCw`다. 이 값을 가장 크게 하는 w를 찾으면 된다. 8편 「고유값과 고유벡터」에서 대칭 행렬은 `C = QΛQᵀ`로 쓸 수 있다고 했다. 이를 대입하면 다음과 같다.
```text
wᵀCw = λ₁(q₁·w)² + λ₂(q₂·w)² + … + λ_d(q_d·w)²
       (가중치 (qᵢ·w)²의 합은 ‖w‖² = 1)
```

고유값들의 가중 평균이므로, 가장 큰 고유값 λ₁에 모든 가중치를 주는 `w = q₁`일 때 최대가 되고 그 최댓값은 λ₁이다. 정리하면 다음과 같다.
- **첫 번째 주성분**은 공분산 행렬에서 고유값이 가장 큰 고유벡터다. 두 번째 주성분은 그다음 고유벡터이며, 첫 번째와 직교한다.
- 각 **고유값**은 그 주성분 방향의 분산이다. 고유값의 합은 전체 분산(대각합)과 같으므로 `λᵢ / Σλ`를 **설명된 분산 비율**이라 부른다.

## 예제: 2차원을 1차원으로
두 특징이 강하게 연관된 2차원 데이터 200개를 만들어 1차원으로 줄여 보자.
```python
import numpy as np

rng = np.random.default_rng(42)
x = rng.normal(0, 2, size=200)
X = np.column_stack([x, 0.5 * x + rng.normal(0, 0.5, size=200)]) + [10, 5]  # 200×2 데이터

Xc = X - X.mean(axis=0)                  # ① 중심화
C = Xc.T @ Xc / (len(X) - 1)             # ② 공분산 행렬 (2×2, 대칭)
vals, vecs = np.linalg.eigh(C)           # ③ 고유값 분해 (오름차순)
vals, vecs = vals[::-1], vecs[:, ::-1]   #    큰 것부터 정렬

print(vals.round(3))                     # [3.878 0.207]  각 주성분 방향의 분산
print(vecs[:, 0].round(3))               # [-0.889 -0.457]  첫 번째 주성분
print((vals / vals.sum()).round(3))      # [0.949 0.051]  설명된 분산 비율

z = Xc @ vecs[:, 0]                      # ④ 1차원으로 사영: 숫자 200개
print(z.shape, z.var(ddof=1).round(3))   # (200,) 3.878
```

첫 번째 주성분 하나가 전체 분산의 94.9%를 설명한다. 점 하나를 숫자 두 개 대신 하나로 표현해도 정보의 95% 가까이가 남는다는 뜻이다. 주성분 (−0.889, −0.457)의 기울기는 약 0.51로, 데이터를 만들 때 쓴 0.5와 거의 같다. 부호가 음수인 것은 신경 쓰지 않아도 된다. 고유벡터는 방향만 의미가 있어서 (0.889, 0.457)과 같은 축이다. 1차원 좌표 z에 주성분 벡터를 곱하고 평균을 더하면 원래 공간으로 근사 복원할 수 있는데, 이는 9편 「직교성과 사영」의 사영 그 자체다.

## SVD로 계산하기
실무에서는 공분산 행렬을 만들지 않고 중심화한 데이터에 바로 10편 「특이값 분해(SVD)」를 적용한다. `X_c = UΣVᵀ`라면 `C = VΣ²Vᵀ/(n − 1)`이므로 V의 열이 주성분이고 `σᵢ²/(n − 1)`이 고유값이다.
```python
U, s, Vt = np.linalg.svd(Xc, full_matrices=False)   # 앞 코드에 이어서
print(Vt[0].round(3))                    # [-0.889 -0.457]  같은 주성분
print((s**2 / (len(X) - 1)).round(3))    # [3.878 0.207]    같은 분산
```

결과는 같지만, 공분산 행렬을 만드는 과정의 반올림 오차를 피할 수 있어 수치적으로 더 안정하다. 널리 쓰이는 라이브러리의 PCA 구현도 SVD를 쓴다.

주의할 점도 있다.
- **단위를 맞춘다**: 센티미터와 킬로그램처럼 단위가 다른 특징을 그대로 넣으면 숫자가 큰 특징이 분산을 독차지한다. 보통 각 특징을 표준편차로 나눈 뒤 PCA를 한다.
- **선형 방법이다**: 데이터가 휘어진 곡면 위에 놓여 있으면 직선 축으로는 잘 요약되지 않는다.
- **분산이 크다고 중요한 것은 아니다**: 분류에 결정적인 정보가 분산이 작은 방향에 숨어 있을 수도 있다.

## 정리
- PCA는 중심화한 데이터에서 분산이 가장 큰 방향들을 찾아, 그 방향으로 사영해 차원을 줄인다.
- 주성분은 공분산 행렬의 고유벡터이고, 고유값은 그 방향의 분산이며, `λᵢ / Σλ`가 설명된 분산 비율이다.
- 실무에서는 중심화한 데이터의 SVD로 계산하며, 특징의 단위를 먼저 맞춰야 한다.
