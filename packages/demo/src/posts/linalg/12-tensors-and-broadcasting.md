## 텐서: 축과 shape
**텐서**(tensor)는 숫자를 여러 방향으로 늘어놓은 배열이다. 방향 하나를 **축**(axis)이라 하고, 축마다의 길이를 모은 튜플을 **shape**라고 한다. 축의 개수는 `ndim`이다.

| 축 개수 | 이름 | shape 예 | 예 |
|---|---|---|---|
| 0 | 스칼라 | () | 손실 값 하나 |
| 1 | 벡터 | (768,) | 임베딩 하나 |
| 2 | 행렬 | (4, 3) | 샘플 4개 × 특징 3개 |
| 3 | 3차원 텐서 | (8, 128, 768) | 문장 8개의 토큰 임베딩 |
| 4 | 4차원 텐서 | (32, 224, 224, 3) | 컬러 이미지 32장 |

수학에서 말하는 "n차원 벡터"는 길이가 n인 축 하나짜리 배열이고, 코드에서 말하는 "4차원 텐서"는 축이 4개인 배열이다. 같은 "차원"이라는 말이 다른 뜻으로 쓰이니 주의하자.

신경망 코드에서는 맨 앞 축이 보통 **배치 축**이다. 샘플 하나에 할 계산을 여러 샘플에 동시에 하려고 샘플들을 첫 축으로 쌓은 것이다. `imgs.mean(axis=0)`은 배치 축을 따라 평균을 내어 shape `(224, 224, 3)`의 평균 이미지를 만들고, `imgs.mean(axis=(1, 2))`는 높이와 너비 축을 없애 이미지마다 채널별 평균 `(32, 3)`을 만든다. `axis`에 적은 축이 사라진다고 기억하면 된다.

## 브로드캐스팅 규칙
shape가 다른 두 배열에 덧셈 같은 원소별 연산을 하면 NumPy는 **브로드캐스팅**(broadcasting)으로 shape를 맞춘다. 규칙은 세 줄이다.
1. 두 shape를 **오른쪽 끝부터** 한 축씩 짝짓는다. 축이 모자란 쪽은 왼쪽에 길이 1인 축이 있다고 본다.
2. 짝지은 두 길이는 **같거나, 한쪽이 1**이어야 한다. 아니면 오류다.
3. 길이가 1인 축은 상대 길이만큼 **늘어난 것처럼** 계산한다. 실제로 복사하지는 않아서 메모리를 쓰지 않는다.
```text
X      : (4, 3)
b      :    (3,)  → (1, 3) → (4, 3)    가능: 결과 (4, 3)
col    : (4, 1)          → (4, 3)      가능: 결과 (4, 3)
v      :    (4,)  → (1, 4)             불가: 오른쪽 끝 3과 4가 다르다
```

코드로 확인해 보자.
```python
import numpy as np

X = np.arange(12).reshape(4, 3)      # (4, 3)
b = np.array([100, 200, 300])        # (3,)
print(X + b)                          # b가 네 행에 각각 더해진다
# [[100 201 302]
#  [103 204 305]
#  [106 207 308]
#  [109 210 311]]

col = np.array([[1], [2], [3], [4]]) # (4, 1)
print((X * col).shape)               # (4, 3)  행마다 다른 배율

X + np.array([1, 2, 3, 4])           # (4, 3) + (4,)
# ValueError: operands could not be broadcast together with shapes (4,3) (4,)
```

AI 기초 1편의 XOR 코드에 있던 `X @ W1 + b1`이 바로 이 규칙으로 동작한다. `X @ W1`은 (4, 2) · (2, 8) = (4, 8)이고 b1은 (8,)이므로, 같은 편향 8개가 샘플 4개 각각에 더해진다. 이미지에서도 마찬가지다. (32, 224, 224, 3) 텐서에서 채널별 평균 (3,)을 빼면 모든 이미지의 모든 픽셀에서 R, G, B 평균이 각각 빠진다.

## 배치 행렬 곱
`@`는 3차원 이상에서 **마지막 두 축을 행렬로 보고**, 앞쪽 축은 배치로 취급한다. 앞쪽 축끼리도 브로드캐스팅 규칙이 적용된다.
```python
rng = np.random.default_rng(0)       # 앞 코드에 이어서
A = rng.normal(size=(32, 5, 4))      # 행렬 32개, 각각 5×4
B = rng.normal(size=(32, 4, 3))      # 행렬 32개, 각각 4×3
print((A @ B).shape)                 # (32, 5, 3)  32쌍을 한 번에 곱한다
```

3편 「행렬과 행렬 곱」의 크기 규칙 (m×k)(k×n) = (m×n)이 마지막 두 축에 그대로 적용된다. 트랜스포머의 어텐션은 shape가 (배치, 헤드, n, d)인 쿼리와 (배치, 헤드, d, n)으로 전치한 키를 이렇게 곱해 (배치, 헤드, n, n) 점수 텐서를 만든다.

## einsum: 축에 이름 붙이기
축이 많아지면 `@`와 전치만으로는 헷갈린다. `np.einsum`은 축마다 글자를 붙이고, 결과에 남길 축만 적는 방식으로 계산을 표현한다. 결과에서 빠진 글자의 축은 곱한 뒤 더해진다.
```python
C = np.einsum('bik,bkj->bij', A, B)  # 배치 행렬 곱: k 축을 곱해서 더한다
print(np.allclose(A @ B, C))         # True
```

같은 표기로 `'i,i->'`는 내적, `'ij,jk->ik'`는 행렬 곱, `'ij->ji'`는 전치다. 식에 축의 의미가 드러나서 복잡한 텐서 연산을 읽고 검증하기 쉽다.

## 흔한 축 실수
브로드캐스팅은 편리한 만큼 위험하다. shape가 맞지 않아도 규칙에만 맞으면 **오류 없이 엉뚱한 결과**를 낸다. 가장 흔한 예가 (n, 1)과 (n,)의 혼동이다.
```python
y = np.array([1.0, 2.0, 3.0, 4.0])             # 정답: (4,)
pred = np.array([[1.1], [1.9], [3.2], [3.8]])  # 모델 출력: (4, 1)

diff = pred - y
print(diff.shape)                       # (4, 4)  ← 의도와 다르다!
print(np.mean(diff ** 2))               # 2.375   오류 없이 엉뚱한 값
print(np.mean((pred.ravel() - y) ** 2)) # 0.025000000000000043  올바른 평균제곱오차
```

(4, 1)과 (4,)를 빼면 (4, 1)과 (1, 4)로 맞춰져 모든 쌍의 차이가 담긴 4×4 행렬이 된다. 손실이 조용히 틀리면 학습이 잘 안 되는 이유를 찾기 매우 어렵다. 그 밖에도 자주 하는 실수가 있다.
- `axis`를 잘못 지정해 샘플 방향이 아닌 특징 방향으로 평균을 낸다.
- `reshape`를 전치로 착각한다. `reshape`는 원소의 순서를 그대로 두고 shape만 다시 자르므로, (배치, 채널, 높이, 너비)를 (배치, 높이, 너비, 채널)로 바꾸려면 `transpose(0, 2, 3, 1)`을 써야 한다.

예방법은 단순하다. 중요한 지점마다 `print(x.shape)`나 `assert x.shape == (n, d)`로 shape를 확인하는 습관을 들인다.

## 정리
- 텐서는 축과 shape를 가진 배열이며, 신경망 코드에서는 첫 축이 보통 배치 축이다.
- 브로드캐스팅은 shape를 오른쪽부터 맞추고, 길이가 1이거나 없는 축을 늘려 계산한다.
- `@`는 마지막 두 축으로 행렬 곱을 하고 앞쪽 축은 배치로 다루며, `einsum`은 축에 이름을 붙여 같은 계산을 명확히 적는다.
- 브로드캐스팅은 오류 없이 틀릴 수 있으므로 shape를 수시로 확인한다.
