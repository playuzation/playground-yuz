# [선형대수 5/12] 연립일차방정식과 역행렬

> **한 줄 요약** — 연립일차방정식은 `Ax = b` 한 줄로 쓸 수 있고, 가우스 소거법으로 풀며, 역행렬은 그 해를 개념적으로 표현하는 도구지만 실제 계산에서는 역행렬을 만들지 않고 바로 푸는 것이 정석이다.

## 이 글에서 다루는 것
- 연립일차방정식을 `Ax = b`로 쓰기
- 가우스 소거법을 단계별로 따라가기
- 해가 하나, 없음, 무수히 많음
- 역행렬의 정의와 2×2 공식
- 실무에서는 `np.linalg.solve`를 쓰는 이유

## Ax = b: 방정식 세 개를 한 줄로
다음 연립방정식을 보자.
```text
 x +  y +  z = 6
2x +  y −  z = 1
 x −  y + 2z = 5
```

계수를 모아 행렬 A로, 미지수를 벡터 x로, 우변을 벡터 b로 쓰면 `Ax = b` 한 줄이 된다. 3편 「행렬과 행렬 곱」의 열 관점으로 읽으면 이 식은 "A의 세 열을 각각 몇 배씩 섞어야 b가 되는가?"라는 질문이다.
```text
[ 1   1   1 ] [ x ]   [ 6 ]
[ 2   1  −1 ] [ y ] = [ 1 ]
[ 1  −1   2 ] [ z ]   [ 5 ]
```

## 가우스 소거법
**가우스 소거법**(Gaussian elimination)은 학교에서 배운 "식끼리 빼서 미지수 없애기"를 체계화한 것이다. A와 b를 나란히 붙인 **첨가 행렬**에 세 가지 연산만 쓴다. 한 행에 다른 행의 상수배를 더하기, 두 행 바꾸기, 한 행에 0이 아닌 수 곱하기. 이 연산들은 해를 바꾸지 않는다.
```text
시작
[ 1   1   1 ∣   6 ]
[ 2   1  −1 ∣   1 ]
[ 1  −1   2 ∣   5 ]

① R2 ← R2 − 2·R1,  R3 ← R3 − R1   (1열의 아래를 0으로)
[ 1   1   1 ∣   6 ]
[ 0  −1  −3 ∣ −11 ]
[ 0  −2   1 ∣  −1 ]

② R3 ← R3 − 2·R2                  (2열의 아래를 0으로)
[ 1   1   1 ∣   6 ]
[ 0  −1  −3 ∣ −11 ]
[ 0   0   7 ∣  21 ]
```

왼쪽 아래가 모두 0인 계단 모양이 되었다. 이제 맨 아래 식부터 거꾸로 대입한다(**후진 대입**).
```text
7z = 21            →  z = 3
−y − 3·3 = −11     →  y = 2
x + 2 + 3 = 6      →  x = 1
```

n개의 미지수에 대해 소거에 드는 계산량은 약 n³에 비례한다. 컴퓨터는 이 과정을 행렬 A를 아래·위 삼각 행렬의 곱으로 쪼개는 **LU 분해** 형태로 수행한다.

## 해가 하나, 없음, 무수히 많음
미지수가 두 개면 방정식 하나는 평면 위의 직선이고, 해는 두 직선의 교점이다.

| 경우 | 예 | 두 직선 | 소거 결과 |
|---|---|---|---|
| 해가 하나 | x + y = 2, x − y = 0 | 한 점에서 만남 | 계단이 끝까지 내려감 |
| 해가 없음 | x + y = 2, 2x + 2y = 5 | 평행 | `0 = 1` 같은 모순 |
| 무수히 많음 | x + y = 2, 2x + 2y = 4 | 겹침 | `0 = 0`, 자유 변수가 남음 |

뒤의 두 경우는 둘째 식의 좌변이 첫째 식의 2배다. 즉 A의 행(또는 열)이 서로 독립적이지 않다. 이 "독립성"을 정확히 다루는 것이 6편 「일차 독립, 기저, 차원, 랭크」이고, 행렬 하나로 판정하는 숫자가 7편 「행렬식: 부피가 변하는 비율」의 행렬식이다.

## 역행렬
숫자 방정식 `3x = 6`은 양변에 1/3을 곱해 푼다. 행렬에서 1/3 역할을 하는 것이 **역행렬** `A⁻¹`로, `A⁻¹A = AA⁻¹ = I`를 만족하는 행렬이다. 역행렬이 있으면 해는 `x = A⁻¹b` 하나로 정해진다. 4편의 관점으로는 A가 한 변환을 되돌리는 변환이다.

2×2 행렬은 공식이 간단하다.
```text
A = [ a  b ]      A⁻¹ = 1/(ad − bc) · [  d  −b ]
    [ c  d ]                          [ −c   a ]

예: A = [ 2  1 ]    ad − bc = 2·3 − 1·5 = 1
        [ 5  3 ]

    A⁻¹ = [  3  −1 ]
          [ −5   2 ]
```

곱해 보면 `AA⁻¹ = I`임을 확인할 수 있다. 분모 `ad − bc`가 0이면 역행렬이 없다. 정사각 행렬이면서 역행렬이 없는 행렬을 **특이 행렬**(singular matrix)이라 하고, 위 표의 "해가 없음"과 "무수히 많음"이 바로 이런 경우다.

## 실무: 역행렬을 만들지 말고 풀어라
수식에서는 `x = A⁻¹b`라고 쓰지만 코드에서는 `np.linalg.solve(A, b)`를 쓴다. 이유는 두 가지다.
- **속도**: 역행렬 전체를 구하는 데는 LU 분해 한 번보다 대략 3배의 계산이 든다. 해 하나가 필요할 뿐이라면 낭비다.
- **정확도**: 역행렬을 거치면 반올림 오차가 한 번 더 쌓인다. 작은 입력 변화에 해가 크게 흔들리는 **조건이 나쁜**(ill-conditioned) 행렬에서는 차이가 커진다.

조건이 나쁘기로 유명한 힐베르트 행렬로 비교해 보자.
```python
import numpy as np

n = 10
H = np.array([[1 / (i + j + 1) for j in range(n)] for i in range(n)])  # 힐베르트 행렬
x_true = np.ones(n)
b = H @ x_true                       # 정답이 (1, 1, …, 1)이 되도록 b를 만든다

x1 = np.linalg.solve(H, b)
x2 = np.linalg.inv(H) @ b
print(f"{np.abs(x1 - x_true).max():.1e}")   # 4.4e-05  solve의 최대 오차
print(f"{np.abs(x2 - x_true).max():.1e}")   # 8.1e-03  inv의 최대 오차
```

같은 문제인데 역행렬을 거친 쪽의 오차가 약 180배 크다. 정확한 값은 실행 환경의 수치 라이브러리에 따라 조금 다를 수 있지만 경향은 같다. 특이 행렬을 넣으면 `solve`는 `LinAlgError: Singular matrix` 예외를 낸다.

## 어디에 쓰이나
- 통계학 8편 「선형 회귀와 최소제곱법」: 회귀 계수는 정규 방정식 `(XᵀX)β = Xᵀy`라는 연립방정식의 해이며, 코드에서는 역행렬 대신 `solve`나 `lstsq`로 구한다.
- AI 기초 4편 「컴퓨터 사이언스로 보는 AI 모델: 텐서, 연산, 메모리」: 같은 계산도 순서에 따라 부동소수점 결과가 달라진다는 이야기가, 역행렬을 거치느냐 마느냐로 오차가 180배 달라지는 이 예에서 극단적으로 드러난다.
- 6편 「일차 독립, 기저, 차원, 랭크」, 7편 「행렬식: 부피가 변하는 비율」: 해가 하나로 정해지는 조건을 랭크와 행렬식으로 판정한다.

## 정리
- 연립일차방정식은 `Ax = b`이고, "A의 열을 어떻게 섞어야 b가 되는가"라는 질문이다.
- 가우스 소거법은 행 연산으로 계단 모양을 만든 뒤 후진 대입으로 푼다.
- 해는 하나, 없음, 무수히 많음 중 하나이며, 역행렬이 있을 때만 해가 하나로 정해진다.
- 코드에서는 `inv(A) @ b` 대신 `np.linalg.solve(A, b)`가 더 빠르고 정확하다.
