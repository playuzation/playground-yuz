# [선형대수 10/12] 특이값 분해(SVD)

> **한 줄 요약** — 특이값 분해는 모든 행렬을 "회전, 축 방향 늘이기, 회전"의 세 단계로 쪼개며, 큰 특이값만 남기면 원래 행렬에 가장 가까운 저랭크 근사를 얻을 수 있다.

## 세 행렬로 쪼개기
8편 「고유값과 고유벡터」의 고유값 분해는 정사각 행렬에만, 그리고 깔끔한 형태 `A = QΛQᵀ`는 대칭 행렬에만 쓸 수 있었다. **특이값 분해**(SVD, singular value decomposition)는 크기와 모양에 관계없이 **모든 행렬**에 존재한다.
```text
A  =  U  ·  Σ  ·  Vᵀ
(m×n) (m×m) (m×n) (n×n)

U : 직교 행렬, 열은 왼쪽 특이벡터
Σ : 대각선에 특이값 σ₁ ≥ σ₂ ≥ … ≥ 0, 나머지는 0
V : 직교 행렬, 열은 오른쪽 특이벡터
```

**특이값**(singular value) σᵢ는 항상 0 이상이고 큰 것부터 정렬한다. 0이 아닌 특이값의 개수가 6편 「일차 독립, 기저, 차원, 랭크」의 랭크다. 실제로 `np.linalg.matrix_rank`는 SVD를 구한 뒤 아주 작은 값보다 큰 특이값의 개수를 센다.

## 회전, 늘이기, 회전
9편 「직교성과 사영」에서 직교 행렬은 길이와 각도를 보존하는 회전(또는 반사)이라고 했다. 그러므로 벡터 x에 A를 곱하는 일 `UΣVᵀx`는 세 단계로 읽힌다.
1. **Vᵀ**: 공간을 돌려서 특별한 방향들(V의 열)을 좌표축에 맞춘다.
2. **Σ**: 각 축 방향으로 σᵢ배씩 늘이거나 줄인다.
3. **U**: 다시 돌려서 결과를 제자리에 놓는다.

그래서 2차원에서 A는 단위 원을 반지름이 σ₁, σ₂인 타원으로 바꾼다. 4편 「선형 변환으로서의 행렬」에서 본 전단처럼 복잡해 보이는 변환도 사실은 "돌리고, 축 방향으로 늘이고, 돌리기"라는 뜻이다.
```python
import numpy as np

A = np.array([[3, 0],
              [4, 5]], dtype=float)
U, s, Vt = np.linalg.svd(A)
print(s)                                     # [6.70820393 2.23606798]  = 3√5, √5
print(np.allclose(U @ np.diag(s) @ Vt, A))   # True  A = UΣVᵀ
```

이 행렬은 단위 원을 긴 반지름 약 6.71, 짧은 반지름 약 2.24인 타원으로 만든다. 넓이 배율은 두 특이값의 곱 `3√5 · √5 = 15`이고, 7편 「행렬식: 부피가 변하는 비율」의 행렬식 `3·5 − 0·4 = 15`와 같다.

## 고유값 분해와의 관계
`AᵀA`를 계산하면 `VΣᵀUᵀUΣVᵀ = V(ΣᵀΣ)Vᵀ`가 된다. 이는 대칭 행렬 AᵀA의 고유값 분해다. 즉 V의 열은 AᵀA의 고유벡터이고, **특이값의 제곱이 AᵀA의 고유값**이다. 위 예에서 AᵀA의 고유값은 45와 5이고, 그 제곱근이 6.708과 2.236이다. 마찬가지로 U의 열은 AAᵀ의 고유벡터다. 다만 실제로 SVD를 계산할 때는 AᵀA를 만들지 않는 더 정확한 알고리즘을 쓴다.

## 저랭크 근사: 중요한 것만 남기기
SVD를 펼쳐 쓰면 A는 랭크 1짜리 행렬들의 합이 된다. 각 항은 열 벡터와 행 벡터의 곱이고, 특이값이 그 항의 중요도다.
```text
A = σ₁·u₁v₁ᵀ + σ₂·u₂v₂ᵀ + σ₃·u₃v₃ᵀ + …
```

앞의 k개 항만 남긴 것을 `A_k`라고 하자. **에카르트-영 정리**(Eckart–Young theorem)에 따르면 `A_k`는 랭크가 k 이하인 모든 행렬 중에서 A에 **가장 가까운** 행렬이다. 오차의 크기(프로베니우스 노름, 모든 원소 차이의 제곱합의 제곱근)는 버린 특이값들의 제곱합의 제곱근과 정확히 같다. 랭크 2의 구조에 잡음을 섞은 행렬로 확인해 보자.
```python
rng = np.random.default_rng(0)                   # 앞 코드에 이어서
# 랭크 2짜리 구조(6×5)에 작은 잡음을 더한 행렬
A = rng.normal(size=(6, 2)) @ rng.normal(size=(2, 5)) + 0.1 * rng.normal(size=(6, 5))

U, s, Vt = np.linalg.svd(A, full_matrices=False)
print(s.round(3))                                # [5.151 2.124 0.228 0.161 0.046]

for k in (1, 2, 3):
    A_k = U[:, :k] @ np.diag(s[:k]) @ Vt[:k]     # 상위 k개만 남긴 근사
    err = np.linalg.norm(A - A_k)                 # 근사 오차(프로베니우스 노름)
    rest = np.sqrt((s[k:] ** 2).sum())            # 버린 특이값들의 제곱합의 제곱근
    print(k, f"{err:.4f}", f"{rest:.4f}", f"{err / np.linalg.norm(A):.1%}")
# 1 2.1428 2.1428 38.4%
# 2 0.2833 0.2833 5.1%
# 3 0.1676 0.1676 3.0%
```

특이값이 둘째 이후 뚝 떨어진다. 원래 구조가 랭크 2였기 때문이다. k = 2에서 오차가 5.1%로 급감하고, 그 이후로는 잡음을 조금씩 더 따라갈 뿐이다. 오차와 버린 특이값으로 계산한 값이 소수점 넷째 자리까지 일치하는 것이 에카르트-영 정리의 확인이다.

이 근사는 저장 공간을 줄인다. m×n 행렬에는 숫자 m·n개가 필요하지만 `A_k`는 u, v 벡터와 특이값을 합쳐 `k·(m + n + 1)`개면 된다. 1000×1000 행렬을 k = 50으로 근사하면 100만 개가 약 10만 개로 줄어든다. 특이값이 빠르게 줄어드는 행렬일수록 적은 k로도 정확하다.

## 정리
- SVD `A = UΣVᵀ`는 모든 행렬에 존재하며, 회전-늘이기-회전으로 행렬의 작용을 분해한다.
- 특이값은 늘이는 배율이고, 그 제곱은 AᵀA의 고유값이며, 0이 아닌 특이값의 개수가 랭크다.
- 상위 k개 특이값만 남긴 `A_k`는 랭크 k 이하의 행렬 중 가장 좋은 근사이며(에카르트-영 정리), 오차는 버린 특이값으로 정확히 계산된다.
