## 모집단과 표본
**모집단**(population)은 알고 싶은 대상 전체이고, **표본**(sample)은 그중 실제로 관측한 일부다. "이 플랫폼 사용자의 평균 세션 길이"가 궁금하다면 모든 사용자의 모든 세션이 모집단이고, 오늘 로그에서 뽑아 본 세션 100개가 표본이다. 모집단 전체를 조사하기는 비싸거나 불가능하므로, 통계학은 대부분 표본으로 모집단을 추측하는 일, 즉 **추론**을 다룬다.

## 모수와 통계량
모집단의 특성을 나타내는 값을 **모수**(parameter), 표본으로 계산한 값을 **통계량**(statistic)이라고 한다. 관례상 모수는 그리스 문자, 통계량은 알파벳이나 모자(^)를 씌워 쓴다.

| 무엇 | 모수 | 통계량 |
|---|---|---|
| 평균 | μ | x̄ |
| 분산 | σ² | s² |
| 비율 | p | p̂ |

핵심 차이는 이렇다. 모수는 정해져 있지만 모르는 값이고, 통계량은 계산할 수 있지만 **표본을 다시 뽑으면 달라지는 값**이다. 즉 통계량은 확률 변수다.

## 무작위 표본
표본이 모집단을 닮으려면 모집단의 모든 원소가 같은 확률로, 서로 독립적으로 뽑혀야 한다. 이것이 **무작위 표본**이고, 이렇게 뽑은 값들은 같은 분포를 따르는 독립인 값, 즉 i.i.d.가 된다. 무작위가 아니면 아무리 많이 모아도 모집단과 다른 것을 재게 된다(아래 표집 편향 참고).

## 표본 분포와 표준 오차
통계량이 표본마다 어떻게 흩어지는지 나타낸 분포를 **표본 분포**(sampling distribution)라고 한다. 현실에서는 표본을 한 번만 뽑지만, 시뮬레이션에서는 모집단을 직접 만들어 놓고 표본을 수천 번 뽑아 볼 수 있다.
```python
import numpy as np

rng = np.random.default_rng(0)
population = rng.exponential(scale=10, size=1_000_000)  # 모집단: 세션 길이(분) 100만 개
mu, sigma = population.mean(), population.std()
print(f"모수: μ = {mu:.2f}, σ = {sigma:.2f}")

for n in [10, 100, 1000]:
    # 크기 n인 표본을 2,000번 뽑아 표본 평균의 분포를 만든다
    means = np.array([rng.choice(population, n).mean() for _ in range(2000)])
    print(f"n={n:<5} 표본 평균들의 평균 {means.mean():.2f}  표준편차 {means.std():.3f}  σ/√n {sigma / np.sqrt(n):.3f}")

# 오래 머문 사용자일수록 설문에 응답할 확률이 높다면?
weights = population / population.sum()   # 응답 확률 ∝ 세션 길이
for n in [100, 10_000]:
    survey = rng.choice(population, n, p=weights)
    print(f"편향된 표본 n={n:<6} 평균 {survey.mean():.2f}")
```
```text
모수: μ = 10.00, σ = 10.01
n=10    표본 평균들의 평균 9.94  표준편차 3.208  σ/√n 3.167
n=100   표본 평균들의 평균 9.98  표준편차 1.013  σ/√n 1.001
n=1000  표본 평균들의 평균 10.01  표준편차 0.329  σ/√n 0.317
편향된 표본 n=100    평균 18.29
편향된 표본 n=10000  평균 19.72
```

앞의 세 줄에서 두 가지를 읽을 수 있다.
- **표본 평균들의 평균은 μ에 붙어 있다.** 표본 평균은 평균적으로 모수를 맞힌다.
- **흩어짐은 σ/√n으로 줄어든다.** 표본 평균의 표준편차를 **표준 오차**(standard error)라고 하며, 독립인 값 n개를 평균 내면 분산이 `σ²/n`이 되기 때문에 `SE = σ/√n`이다. 표본을 100배 늘리면 오차는 10배 줄어든다. 정밀도를 2배로 올리려면 데이터가 4배 필요하다는 뜻이기도 하다.

모집단은 오른쪽으로 크게 치우친 지수 분포인데도, 표본 평균의 분포는 n이 커질수록 종 모양의 정규 분포에 가까워진다. 이것이 확률과 분포 10편 「큰 수의 법칙과 중심 극한 정리」의 내용이다. 실제로는 σ도 모르므로 표본 표준편차 s로 바꿔 `s/√n`을 쓰며, 이 값으로 5편에서 신뢰 구간을 만든다.

## 표집 편향: 많이 모아도 틀린다
마지막 두 줄은 다른 이야기다. 설문 응답 확률이 세션 길이에 비례하도록, 즉 오래 머문 사용자가 더 잘 응답하도록 표본을 뽑았더니 평균이 참값 10이 아니라 20 근처로 나왔다. 그리고 표본을 100배로 늘려도 19.72로, 10에 가까워지기는커녕 틀린 값에 더 정확히 다가갔다. 뽑는 방식 자체가 모집단을 고르게 대표하지 못하는 것을 **표집 편향**(sampling bias)이라고 한다. 표본 크기를 늘리면 줄어드는 것은 흩어짐(분산)이지 치우침(편향)이 아니다. 이 둘의 구분은 3편에서 정식으로 다룬다.

**생존 편향**은 표집 편향의 흔한 형태로, 어떤 과정을 "통과한" 대상만 관측될 때 생긴다.
- 앱 만족도 설문: 불만이 큰 사용자는 이미 앱을 지웠으므로 설문에 응답할 기회조차 없다.
- 성공 사례 분석: 살아남은 회사나 프로젝트만 모아 공통점을 찾으면, 같은 방식으로 일하다 사라진 대상은 보이지 않는다.
- 장애 원인 분석: 로그를 남기기 전에 죽은 요청은 로그 통계에 잡히지 않는다.

## 정리
- 모수는 고정되어 있지만 모르는 모집단의 값이고, 통계량은 표본마다 달라지는 확률 변수다.
- 표본 평균의 표본 분포는 μ를 중심으로 표준 오차 `σ/√n`만큼 퍼지며, n이 커지면 정규 분포에 가까워진다.
- 표본을 늘리면 분산은 줄지만, 뽑는 방식이 치우친 표집 편향(생존 편향 포함)은 줄지 않는다.
