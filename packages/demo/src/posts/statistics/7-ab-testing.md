# [통계학 7/11] A/B 테스트: 실험으로 결정하기

> **한 줄 요약** — A/B 테스트는 사용자를 무작위로 두 그룹에 나눠 한 가지만 다르게 보여 준 뒤 지표의 차이를 가설 검정으로 판단하는 실험이며, 표본 크기를 미리 정하고 중간에 결과를 엿보지 않아야 결론을 믿을 수 있다.

## 이 글에서 다루는 것
- 무작위 배정이 "원인"을 말할 수 있게 해 주는 이유
- 지표 정하기: 전환율
- 두 비율을 비교하는 z 검정을 직접 계산하기
- 검정력과 필요한 표본 크기
- 미리 정하고, 중간에 엿보지 않기

## 실험 설계: 좋아요 버튼 바꾸기
이 플랫폼의 좋아요 버튼을 새 디자인으로 바꾸면 좋아요가 늘어날까? 가장 쉬운 방법은 버튼을 바꾸고 지난주와 이번 주를 비교하는 것이지만, 그 사이에 인기 글이 올라왔거나 연휴가 끼었다면 차이가 버튼 때문인지 알 수 없다.

A/B 테스트는 같은 기간에 사용자를 **무작위로** 두 그룹으로 나눈다. A 그룹은 기존 버튼(대조군), B 그룹은 새 버튼(실험군)을 본다. 배정이 무작위이면 두 그룹은 사용 습관, 기기, 접속 시간 같은 모든 특성이 평균적으로 같아지고, 남는 체계적인 차이는 버튼 하나뿐이다. 그래서 지표 차이를 버튼의 효과, 즉 인과로 해석할 수 있다. 실무에서는 사용자 ID의 해시값으로 그룹을 정해, 같은 사용자가 접속할 때마다 같은 버튼을 보게 한다.

## 지표: 전환율
무엇을 잴지도 실험 전에 정한다. 여기서는 **전환율**, 즉 "포스트를 본 사용자 중 좋아요를 누른 사용자의 비율"을 주 지표로 삼는다. 사용자 한 명은 누르거나(1) 안 누르는(0) 베르누이 시행이고, 그룹 전체의 누른 사람 수는 이항 분포를 따른다. 버튼이 너무 눈에 띄어 댓글이 줄어드는 부작용은 없는지 같은, 나빠지면 안 되는 보조 지표도 함께 정해 둔다.

## 두 비율의 z 검정
일주일 뒤 결과가 이렇게 나왔다고 하자. A는 1,000명 중 100명(10.0%), B는 1,000명 중 125명(12.5%)이 좋아요를 눌렀다. 상대적으로 25%나 늘었으니 바로 B를 적용하면 될까? 6편의 틀로 검정한다. 귀무 가설은 `H₀: p_A = p_B`다.
```text
p̂_A = 100/1000 = 0.100,  p̂_B = 125/1000 = 0.125
공통 비율 p̂ = (100 + 125)/(1000 + 1000) = 0.1125      ← H₀가 참이면 둘은 같은 비율
SE = √( p̂(1 − p̂) · (1/n_A + 1/n_B) )
z  = (p̂_B − p̂_A) / SE
```
```python
import numpy as np
from scipy import stats

n_a, x_a = 1000, 100        # A(기존 버튼): 1,000명 중 100명이 좋아요
n_b, x_b = 1000, 125        # B(새 버튼):   1,000명 중 125명이 좋아요
p_a, p_b = x_a / n_a, x_b / n_b

p_pool = (x_a + x_b) / (n_a + n_b)              # H₀(차이 없음) 아래의 공통 비율
se = np.sqrt(p_pool * (1 - p_pool) * (1 / n_a + 1 / n_b))
z = (p_b - p_a) / se
p_value = 2 * stats.norm.sf(abs(z))             # 양측 검정
print(f"차이 {p_b - p_a:.3f}  SE {se:.4f}  z {z:.3f}  p {p_value:.4f}")

se_diff = np.sqrt(p_a * (1 - p_a) / n_a + p_b * (1 - p_b) / n_b)  # 구간용 SE(그룹별 비율 사용)
lo, hi = p_b - p_a - 1.96 * se_diff, p_b - p_a + 1.96 * se_diff
print(f"차이의 95% 신뢰 구간 [{lo:.3f}, {hi:.3f}]")
```
```text
차이 0.025  SE 0.0141  z 1.769  p 0.0769
차이의 95% 신뢰 구간 [-0.003, 0.053]
```

z = 1.77, p = 0.077로 α = 0.05에서 유의하지 않다. 5편의 방식으로 만든 차이의 신뢰 구간도 0을 포함한다. 새 버튼이 좋아요를 5%p 넘게 늘릴 수도 있지만, 오히려 약간 줄일 가능성도 아직 배제할 수 없다는 뜻이다. 25% 상승이라는 숫자는 인상적이지만, 그룹당 1,000명으로는 이 정도 차이를 우연과 구별하기 어렵다.

## 검정력과 표본 크기
그렇다면 몇 명이 필요했을까? 6편에서 본 검정력, 즉 실제 효과가 있을 때 그것을 잡아낼 확률을 80%로 맞추는 것이 관례다. 그룹당 필요한 인원은 다음 식으로 어림한다(1.96은 α = 0.05 양측, 0.84는 검정력 80%에 해당하는 정규 분포의 지점).
```python
import numpy as np
from scipy import stats

def n_per_group(p1, p2, alpha=0.05, power=0.8):
    z_a, z_b = stats.norm.ppf(1 - alpha / 2), stats.norm.ppf(power)
    p_bar = (p1 + p2) / 2
    num = z_a * np.sqrt(2 * p_bar * (1 - p_bar)) + z_b * np.sqrt(p1 * (1 - p1) + p2 * (1 - p2))
    return int(np.ceil(num**2 / (p2 - p1) ** 2))

print(n_per_group(0.10, 0.125))   # 10% → 12.5%를 검정력 80%로 잡으려면
print(n_per_group(0.10, 0.11))    # 10% → 11%
```
```text
2507
14751
```

10%에서 12.5%로 오르는 효과를 놓치지 않으려면 그룹당 약 2,500명이 필요하다. 그룹당 1,000명이었던 위 실험의 검정력은 약 42%라서, 효과가 진짜 있어도 절반 넘게 놓치는 설계였다. 잡고 싶은 차이가 1%p로 작아지면 필요한 인원은 약 15,000명으로 늘어난다. 필요한 표본은 차이의 제곱에 반비례하므로, 실험 전에 "이 정도 차이는 놓치지 않겠다"는 최소 효과 크기를 정하고 거기서 기간과 인원을 역산한다.

## 중간에 엿보지 않기
실험을 시작하면 매일 대시보드를 열어 p값을 확인하고 싶어진다. 그러다 p < 0.05가 되는 순간 실험을 멈추면 무슨 일이 생길까? 두 버튼이 사실은 똑같은 A/A 실험으로 시뮬레이션해 보자.
```python
import numpy as np
from scipy import stats

rng = np.random.default_rng(0)

def p_value(x_a, x_b, n):                     # 그룹당 n명일 때 두 비율 z 검정
    pool = (x_a + x_b) / (2 * n)
    se = np.sqrt(pool * (1 - pool) * 2 / n)
    return 2 * stats.norm.sf(np.abs(x_b - x_a) / n / se)

# A와 B가 사실은 똑같은(전환율 10%) A/A 실험을 2,000번
peek_hits = final_hits = 0
for _ in range(2000):
    a = rng.random(3000) < 0.10               # 그룹당 3,000명까지 모은다
    b = rng.random(3000) < 0.10
    checks = range(100, 3001, 100)            # 100명 모일 때마다 결과를 엿본다
    peek_hits += any(p_value(a[:n].sum(), b[:n].sum(), n) < 0.05 for n in checks)
    final_hits += p_value(a.sum(), b.sum(), 3000) < 0.05   # 끝까지 기다렸다 한 번만 본다
print(f"엿보기: {peek_hits / 2000:.3f}  한 번만: {final_hits / 2000:.3f}")
```
```text
엿보기: 0.275  한 번만: 0.049
```

정해 둔 인원을 다 모은 뒤 한 번만 검정하면 거짓 양성이 약속대로 5% 근처다. 하지만 30번 엿보다가 처음 유의해질 때 멈추면 27.5%의 실험에서 "효과 있음"이라는 틀린 결론이 나온다. 엿볼 때마다 6편의 다중 비교가 한 번씩 늘어나는 셈이다. 그래서 A/B 테스트의 기본 규칙은 다음과 같다.
- 주 지표, 유의 수준, 최소 효과 크기, 표본 크기(기간)를 **시작 전에** 정한다.
- 요일에 따라 사용 패턴이 다르므로 기간은 보통 주 단위로 잡는다.
- 정해 둔 시점에 한 번 검정한다. 중간 확인이 꼭 필요하면 처음부터 여러 번 보도록 설계된 순차 검정 방법을 쓴다.

## 어디에 쓰이나

- 확률과 분포 6편 「이산 분포: 베르누이, 이항, 기하, 포아송」: 사용자 한 명의 좋아요는 베르누이, 그룹 전체의 좋아요 수는 이항 분포이고, 그 분산에서 표준 오차가 나온다.

- AI 기초 2편 「강화학습: 보상으로 배우는 머신러닝」: A/B 테스트가 탐색 기간을 고정해 두고 끝난 뒤에 좋은 쪽을 쓰는 방식이라면, ε-탐욕은 탐색과 활용을 실시간으로 섞는 방식이다.

## 정리
- 무작위 배정은 두 그룹을 버튼 하나만 빼고 평균적으로 같게 만들어, 지표 차이를 인과로 해석할 수 있게 한다.
- 두 전환율의 차이는 공통 비율로 표준 오차를 구한 z 검정으로 판단하며, 10%와 12.5%도 그룹당 1,000명으로는 유의하지 않다.
- 지표와 표본 크기를 검정력으로 미리 정하고, 중간에 엿보다 멈추지 않아야 거짓 양성이 α로 유지된다.
