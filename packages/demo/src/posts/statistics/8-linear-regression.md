# [통계학 8/11] 선형 회귀와 최소제곱법

> **한 줄 요약** — 선형 회귀는 데이터에 가장 잘 맞는 직선 `y = wx + b`를 잔차 제곱합이 가장 작아지도록 찾는 방법이며, 그 해는 정규 방정식 `XᵀXw = Xᵀy`를 풀어 한 번에 구할 수 있다.

## 이 글에서 다루는 것
- 모델 `y = wx + b`와 잔차
- 잔차 제곱합을 최소화하는 w와 b 유도하기
- 행렬로 쓴 정규 방정식과 NumPy `lstsq`로 확인하기
- 결정계수 R²: 직선이 얼마나 설명하나
- 한계: 선형성 가정과 이상치

## 모델과 잔차
포스트 길이와 평균 읽기 시간 사이의 관계를 알고 싶다고 하자. 다섯 개 글의 데이터가 있다.

| 글 길이 x (천 자) | 읽기 시간 y (분) |
|---|---|
| 1 | 2.3 |
| 2 | 3.9 |
| 3 | 6.1 |
| 4 | 7.4 |
| 5 | 9.8 |

이 점들을 지나는 직선 `ŷ = wx + b`로 관계를 요약하는 것이 **선형 회귀**다. w는 기울기(글이 천 자 길어질 때 늘어나는 시간), b는 절편이다. 점들이 정확히 한 직선 위에 있지는 않으므로, 실제 값과 직선의 예측값 사이에 차이가 남는다. 이 차이 `eᵢ = yᵢ − (w·xᵢ + b)`를 **잔차**(residual)라고 한다.

## 잔차 제곱합 최소화
"가장 잘 맞는 직선"은 잔차를 전체적으로 가장 작게 만드는 직선이다. 잔차를 그냥 더하면 양수와 음수가 상쇄되므로, 제곱해서 더한 **잔차 제곱합**(SSE)을 최소화한다. 이것이 **최소제곱법**이다. 제곱을 쓰면 미분으로 해를 정확히 구할 수 있고, 4편에서 봤듯이 노이즈가 정규 분포를 따른다는 가정 아래에서는 최대 우도 추정과 같아진다.
```text
SSE(w, b) = Σ (yᵢ − w·xᵢ − b)²

∂SSE/∂b = −2 Σ (yᵢ − w·xᵢ − b) = 0        ⇒  b = ȳ − w·x̄
∂SSE/∂w = −2 Σ xᵢ(yᵢ − w·xᵢ − b) = 0      ⇒  w = Σ(xᵢ − x̄)(yᵢ − ȳ) / Σ(xᵢ − x̄)²
```

예시 데이터에서는 x̄ = 3, ȳ = 5.9이고, `Σ(xᵢ − x̄)(yᵢ − ȳ) = 18.5`, `Σ(xᵢ − x̄)² = 10`이다. 따라서 `w = 1.85`, `b = 5.9 − 1.85 × 3 = 0.35`다. 첫 번째 조건에서 알 수 있듯이 최소제곱 직선은 항상 평균점 (x̄, ȳ)를 지나고, 잔차의 합은 0이 된다.

## 행렬로 쓰면: 정규 방정식
입력이 여러 개일 때도 같은 방법을 쓰려면 행렬로 쓰는 편이 낫다. 각 행이 `[xᵢ, 1]`인 행렬 X와 파라미터 벡터 `β = [w, b]ᵀ`를 두면, 예측값 전체가 `Xβ`이고 SSE는 `‖y − Xβ‖²`이다. 이를 β로 미분해 0으로 놓으면 **정규 방정식**이 나온다.
```text
∇SSE = −2 Xᵀ(y − Xβ) = 0
⇒ XᵀX β = Xᵀy

예시:  XᵀX = [[55, 15],     Xᵀy = [107, 29.5]
              [15,  5]]
```

입력 특징이 늘어나면 X에 열만 추가하면 된다. 식 `Xᵀ(y − Xβ) = 0`은 "잔차 벡터가 X의 모든 열과 직교한다"는 뜻이기도 하다. 즉 최소제곱 예측 `Xβ̂`은 y를 X의 열들이 만드는 공간에 수직으로 내린 그림자, 곧 사영이다. NumPy로 확인해 보자.
```python
import numpy as np

x = np.array([1, 2, 3, 4, 5], dtype=float)       # 글 길이(천 자)
y = np.array([2.3, 3.9, 6.1, 7.4, 9.8])          # 평균 읽기 시간(분)

X = np.column_stack([x, np.ones_like(x)])        # 각 행이 [xᵢ, 1]
w, b = np.linalg.lstsq(X, y, rcond=None)[0]
print(f"w = {w:.3f}, b = {b:.3f}")

print(np.linalg.solve(X.T @ X, X.T @ y).round(3))  # 정규 방정식 XᵀXβ = Xᵀy

residual = y - (w * x + b)
r2 = 1 - (residual**2).sum() / ((y - y.mean()) ** 2).sum()
print(residual.round(3), f"R² = {r2:.4f}")
```
```text
w = 1.850, b = 0.350
[1.85 0.35]
[ 0.1  -0.15  0.2  -0.35  0.2 ] R² = 0.9932
```

손으로 계산한 값과 일치한다. 실무에서는 `XᵀX`의 역행렬을 직접 구하면 수치적으로 불안정할 수 있어서, `lstsq`처럼 분해 기법을 쓰는 함수를 주로 쓴다.

## 결정계수 R²
직선이 데이터를 얼마나 잘 설명하는지는 **결정계수** R²로 잰다. y가 평균 주위로 흩어진 정도(총제곱합 SST) 가운데, 직선으로도 설명하지 못하고 남은 부분(SSE)의 비율을 1에서 뺀 값이다.
```text
R² = 1 − SSE / SST,   SST = Σ (yᵢ − ȳ)²
예시: 1 − 0.235 / 34.46 ≈ 0.9932
```

R² = 0.9932는 읽기 시간의 변동 중 99% 이상을 글 길이로 설명한다는 뜻이다. 다만 R²가 높다고 인과 관계가 있다거나 직선이 올바른 모델이라는 보장은 없다. 또 학습 데이터에서 계산한 R²는 특징을 추가할수록 절대 줄어들지 않으므로, 모델 비교에는 11편의 검증 방법을 함께 써야 한다.

## 한계: 선형성과 이상치
- **선형성 가정**: 실제 관계가 곡선이면 직선은 체계적으로 빗나가고, 잔차에 패턴(가운데는 음수, 양 끝은 양수 등)이 남는다. 이럴 때는 x² 같은 특징을 추가해도 된다. 선형 회귀의 "선형"은 x가 아니라 파라미터 w, b에 대해 선형이라는 뜻이기 때문이다.
- **이상치**: 제곱은 큰 잔차를 아주 크게 벌하므로, 멀리 떨어진 점 하나가 직선 전체를 끌어당긴다. 예시에 "6천 자인데 1분 만에 닫은" 점 (6, 1.0)을 하나 추가하면 기울기가 1.85에서 0.357로 무너지고 R²는 0.04로 떨어진다. 1편에서 평균이 이상치에 민감했던 것과 같은 이유다. 잔차를 직접 그려 보고, 필요하면 큰 잔차를 덜 벌하는 손실(후버 손실 등)을 쓰는 로버스트 회귀를 고려한다.

## 정리
- 선형 회귀는 `y = wx + b`의 w, b를 잔차 제곱합이 최소가 되도록 정하며, 해는 `w = Σ(xᵢ − x̄)(yᵢ − ȳ)/Σ(xᵢ − x̄)²`, `b = ȳ − w·x̄`이다.
- 행렬로 쓰면 정규 방정식 `XᵀXβ = Xᵀy`이고, 이는 y를 X의 열 공간으로 사영하는 것과 같다.
- R²는 설명된 변동의 비율이며, 선형성 가정과 이상치에 대한 민감성은 잔차를 보며 늘 확인해야 한다.
