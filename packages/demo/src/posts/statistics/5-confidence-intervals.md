## 점추정과 구간 추정
API 응답 시간 30개를 재서 평균 48.2ms를 얻었다고 하자. 이렇게 값 하나로 모수를 어림하는 것이 **점추정**이다. 그런데 48.2ms만으로는 이 값을 얼마나 믿어도 되는지 알 수 없다. 표본 3개의 평균일 수도, 3만 개의 평균일 수도 있기 때문이다. 그래서 "μ는 대략 43.9ms에서 52.5ms 사이"처럼 범위로 말하는 **구간 추정**을 함께 쓴다.

## 95% 신뢰 구간 만들기
2편에서 봤듯이 표본 평균 x̄는 μ를 중심으로 표준 오차 `SE = σ/√n`만큼 퍼진 정규 분포에 가깝다. 표준 정규 분포에서 −1.96과 1.96 사이의 확률이 95%이므로 다음이 성립한다.
```text
P(μ − 1.96·SE ≤ x̄ ≤ μ + 1.96·SE) = 0.95
⇔ P(x̄ − 1.96·SE ≤ μ ≤ x̄ + 1.96·SE) = 0.95

95% 신뢰 구간:  x̄ ± 1.96 · s/√n      (모르는 σ 대신 표본 표준편차 s)
```

예시에서 n = 30, x̄ = 48.2ms, s = 12.0ms라면 `SE = 12.0/√30 ≈ 2.19`이고, `1.96 × 2.19 ≈ 4.29`이므로 95% 신뢰 구간은 [43.9, 52.5]ms다. 1.96 자리에 1.645를 넣으면 90%, 2.576을 넣으면 99% 신뢰 구간이 된다. 더 확신하고 싶으면 구간이 넓어지고, 구간을 좁히려면 n을 늘려야 한다.

## 95%는 무엇의 확률인가
가장 흔한 오해는 "μ가 [43.9, 52.5] 안에 있을 확률이 95%"라고 읽는 것이다. 이 글의 관점(빈도주의)에서 μ는 모르지만 고정된 값이다. 구간을 계산하고 나면 μ는 그 안에 있거나 없거나 둘 중 하나이고, 더는 확률이 개입할 여지가 없다.

확률적인 것은 **구간 쪽**이다. 표본이 바뀌면 x̄와 s가 바뀌고 구간도 움직인다. 95%는 "이런 방식으로 구간을 만들면, 표본을 새로 뽑아 반복할 때 100번 중 약 95번은 μ를 덮는다"는 절차의 성질이다. 고리 던지기에 비유하면, 95%는 던지는 사람의 실력이지 이미 던져진 고리 하나가 막대에 걸려 있을 확률이 아니다. "모수가 이 구간에 있을 확률"을 직접 말하고 싶다면 모수 자체를 확률 변수로 보는 10편의 신용 구간이 필요하다.

## 시뮬레이션으로 확인하기
참 평균 μ = 100을 알고 있는 모집단에서 표본을 1만 번 뽑아, 매번 만든 구간이 실제로 μ를 포함하는지 세어 보자.
```python
import numpy as np
from scipy import stats

rng = np.random.default_rng(0)
mu, sigma, trials = 100, 15, 10_000              # 참 평균 μ = 100 (실제로는 모른다)

for n in [30, 5]:
    x = rng.normal(mu, sigma, size=(trials, n))  # 크기 n인 표본 1만 개
    m, se = x.mean(axis=1), x.std(axis=1, ddof=1) / np.sqrt(n)
    for name, c in [("1.96", 1.96), ("t", stats.t.ppf(0.975, df=n - 1))]:
        covered = (m - c * se <= mu) & (mu <= m + c * se)
        print(f"n={n:<2} 배수 {name:<4}({c:.3f})  μ를 포함한 비율 {covered.mean():.3f}")
```
```text
n=30 배수 1.96(1.960)  μ를 포함한 비율 0.939
n=30 배수 t   (2.045)  μ를 포함한 비율 0.948
n=5  배수 1.96(1.960)  μ를 포함한 비율 0.882
n=5  배수 t   (2.776)  μ를 포함한 비율 0.951
```

n = 30에서 1.96을 쓰면 95%에 조금 못 미치고, n = 5에서는 88%까지 떨어진다. "95% 구간"이라고 불러 놓고 실제로는 열 번에 한 번 넘게 틀리는 셈이다.

## 작은 표본은 t 분포
문제는 σ 자리에 s를 넣은 데 있다. s도 표본마다 흔들리는 추정값이라, 표본이 작으면 그 불확실성이 무시할 수 없을 만큼 크다. 모집단이 정규 분포일 때 `(x̄ − μ)/(s/√n)`은 표준 정규 분포가 아니라 꼬리가 더 두꺼운 자유도 n−1의 **t 분포**를 따른다. 그래서 1.96 대신 t 분포의 97.5% 지점을 쓰면 구간이 넓어지고, 위의 시뮬레이션처럼 포함 비율이 95%로 돌아온다.

| n | 자유도 | 95% 배수 |
|---|---|---|
| 5 | 4 | 2.776 |
| 10 | 9 | 2.262 |
| 30 | 29 | 2.045 |
| 100 | 99 | 1.984 |

n이 커지면 배수는 1.96에 다가가므로, 표본이 크면 둘의 차이는 사라진다.

## 비율의 신뢰 구간과 모델 정확도
정답/오답처럼 0과 1로 나뉘는 데이터의 평균은 비율 p̂이고, 표준 오차는 `√(p̂(1 − p̂)/n)`이다.
```text
95% 신뢰 구간:  p̂ ± 1.96 · √(p̂(1 − p̂)/n)

테스트 1,000개 중 870개 정답:  0.870 ± 1.96 × 0.0106 ≈ 0.870 ± 0.021  →  [0.849, 0.891]
테스트   100개 중  87개 정답:  0.870 ± 1.96 × 0.0336 ≈ 0.870 ± 0.066  →  [0.804, 0.936]
```

같은 87%라도 테스트 문제가 100개뿐이면 실제 실력은 80%일 수도 94%일 수도 있다. 1,000문제에서 87%와 88%를 받은 두 모델은 구간이 크게 겹치므로 "더 낫다"고 말하기 어렵다. 이 근사식은 n이 작거나 p̂이 0이나 1에 가까우면 부정확해서, 그럴 때는 윌슨 구간 같은 보정된 방법을 쓴다.

## 정리
- 신뢰 구간은 점추정에 불확실성을 붙인 것으로, 평균의 95% 신뢰 구간은 `x̄ ± 1.96·s/√n`이다.
- 95%는 구간을 만드는 절차가 모수를 덮는 비율이지, 계산된 구간 하나에 모수가 있을 확률이 아니다.
- 표본이 작으면 t 분포의 배수를 써야 실제 포함 비율이 95%가 되고, 비율의 구간은 모델 정확도를 보고할 때 바로 쓰인다.
