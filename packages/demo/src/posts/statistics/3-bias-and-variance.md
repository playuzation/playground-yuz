# [통계학 3/11] 추정량의 성질: 편향과 분산

> **한 줄 요약** — 추정량이 얼마나 좋은지는 평균적으로 과녁에서 얼마나 비켜 가는가(편향)와 표본마다 얼마나 흔들리는가(분산)로 나뉘고, 전체 오차는 `MSE = 편향² + 분산`이라서 하나를 줄이면 다른 하나가 늘어나는 트레이드오프가 생긴다.

## 이 글에서 다루는 것
- 추정량, 편향, 분산의 정의
- 평균제곱오차의 분해 `MSE = 편향² + 분산`
- 표본 분산을 n−1로 나누는 이유를 시뮬레이션으로 확인하기
- 일치성: 데이터가 많아지면 정답에 다가가는가
- 편향-분산 트레이드오프와 모델 복잡도

## 추정량도 확률 변수다
**추정량**(estimator)은 표본으로 모수를 어림하는 규칙이다. 표본 평균 x̄는 모평균 μ의 추정량이고, 일반적으로 `θ̂ = g(x₁, …, xₙ)`처럼 표본의 함수로 쓴다. 2편에서 봤듯이 표본이 바뀌면 θ̂도 바뀌므로, 추정량은 자기만의 분포를 가진 확률 변수다. 그러니 "좋은 추정량"은 한 번의 결과가 아니라 그 분포의 모양으로 판단해야 한다.

## 편향, 분산, MSE
다트를 여러 번 던지는 장면을 떠올리면 쉽다. 화살들의 평균 위치가 과녁 중심에서 벗어난 정도가 **편향**(bias), 화살끼리 흩어진 정도가 **분산**(variance)이다.
```text
편향(θ̂) = E[θ̂] − θ
분산(θ̂) = E[(θ̂ − E[θ̂])²]
MSE(θ̂)  = E[(θ̂ − θ)²]          ← 과녁 중심에서 떨어진 거리의 제곱, 그 평균
```

**평균제곱오차**(MSE)는 정확히 두 성분으로 쪼개진다.
```text
θ̂ − θ = (θ̂ − E[θ̂]) + (E[θ̂] − θ)
양변을 제곱하고 기댓값을 취하면 교차항은 E[θ̂ − E[θ̂]] = 0 때문에 사라진다.
⇒ MSE = E[(θ̂ − E[θ̂])²] + (E[θ̂] − θ)² = 분산 + 편향²
```

편향이 0인 추정량을 **불편 추정량**(unbiased estimator)이라고 한다. 표본 평균은 `E[x̄] = μ`이므로 불편 추정량이다.

## 표본 분산은 왜 n−1로 나누나
모분산 σ²를 추정할 때 1편처럼 n으로 나누면 평균적으로 조금 작게 나온다. 시뮬레이션으로 확인해 보자. 참 분산이 4인 정규 분포에서 크기 5인 표본을 10만 번 뽑아, 두 가지 방식으로 분산을 추정한다.
```python
import numpy as np

rng = np.random.default_rng(0)
sigma2 = 4.0                                   # 참 분산(모수)
samples = rng.normal(0, 2, size=(100_000, 5))  # 크기 5인 표본 10만 개

for ddof, name in [(0, "n으로 나눔  "), (1, "n−1로 나눔")]:
    est = samples.var(axis=1, ddof=ddof)       # 표본마다 분산 추정값
    bias = est.mean() - sigma2
    var = est.var()
    mse = ((est - sigma2) ** 2).mean()
    print(f"{name} 평균 {est.mean():.3f}  편향 {bias:+.3f}  분산 {var:.3f}  MSE {mse:.3f}")
```
```text
n으로 나눔   평균 3.210  편향 -0.790  분산 5.176  MSE 5.800
n−1로 나눔 평균 4.012  편향 +0.012  분산 8.087  MSE 8.087
```

n으로 나누면 평균이 4가 아니라 3.2 근처다. 이유는 편차를 μ가 아니라 x̄에서 쟀기 때문이다. x̄는 `Σ(xᵢ − c)²`를 가장 작게 만드는 점 c이므로, 언제나 `Σ(xᵢ − x̄)² ≤ Σ(xᵢ − μ)²`가 된다. 계산해 보면 정확히 `E[Σ(xᵢ − x̄)²] = (n−1)·σ²`이고, 그래서 n으로 나누면 기댓값이 `σ²·(n−1)/n = 4 × 4/5 = 3.2`가 된다. n−1로 나누면 이 치우침이 사라진다. 편차들의 합은 항상 0이라 n개 중 n−1개만 자유롭게 정해진다는 뜻에서 n−1을 **자유도**라고 부른다.

그런데 표의 오른쪽 끝을 보자. MSE는 오히려 편향된 쪽(5.800)이 불편 추정량(8.087)보다 작다. 조금 작게 추정하는 대신 흔들림이 줄어서 전체 오차는 이득을 본 것이다. 두 줄 모두 `MSE = 편향² + 분산`도 성립한다(0.790² + 5.176 ≈ 5.800). **불편 추정량이 늘 최선은 아니다**. 이것이 아래 편향-분산 트레이드오프의 축소판이다.

## 일치성
표본 크기 n이 커질수록 추정량이 참값에 한없이 가까워지는 성질을 **일치성**(consistency)이라고 한다. n으로 나눈 분산은 편향이 `−σ²/n`이라 n이 커지면 사라지고 분산도 줄어들므로, 불편은 아니지만 일치 추정량이다. 반대로 2편의 치우친 설문은 표본을 늘려도 20 근처로 수렴했으니 일치성이 없다. 실무에서는 불편성보다 일치성이 더 기본적인 요구 조건이다.

## 편향-분산 트레이드오프와 모델 복잡도
머신러닝 모델이 데이터로 함수 f(x)를 배우는 것도 추정이다. 학습 데이터를 새로 뽑을 때마다 모델이 달라지므로, 예측값에도 편향과 분산이 있다. 참 함수가 `sin(2πx)`이고 노이즈가 섞인 점 12개로 다항식을 맞추는 실험을 500번 반복해 보자.
```python
import numpy as np

rng = np.random.default_rng(0)
x = np.linspace(0, 1, 12)                 # 학습 입력 12개
grid = np.linspace(0.05, 0.95, 50)        # 예측을 비교할 지점
truth = np.sin(2 * np.pi * grid)          # 참 함수

for degree in [1, 3, 9]:
    preds = []
    for _ in range(500):                  # 학습 데이터를 500번 새로 뽑아 매번 다시 학습
        y = np.sin(2 * np.pi * x) + rng.normal(0, 0.3, x.size)
        preds.append(np.polyval(np.polyfit(x, y, degree), grid))
    preds = np.array(preds)
    bias2 = ((preds.mean(axis=0) - truth) ** 2).mean()
    var = preds.var(axis=0).mean()
    print(f"차수 {degree}: 편향² {bias2:.3f}  분산 {var:.3f}  합 {bias2 + var:.3f}")
```
```text
차수 1: 편향² 0.205  분산 0.012  합 0.217
차수 3: 편향² 0.007  분산 0.024  합 0.031
차수 9: 편향² 0.000  분산 0.091  합 0.091
```

| 모델 | 편향 | 분산 | 상태 |
|---|---|---|---|
| 직선(차수 1) | 크다 | 작다 | 과소적합 |
| 3차 | 작다 | 적당하다 | 적정 |
| 9차 | 거의 0 | 크다 | 과적합 |

직선은 데이터가 바뀌어도 늘 비슷한 직선이지만(분산 작음) 곡선을 표현하지 못해 체계적으로 빗나간다(편향 큼). 9차 다항식은 평균적으로는 참 함수를 맞히지만 노이즈까지 따라가느라 데이터마다 모양이 크게 바뀐다. 실제 새 데이터에서의 기대 오차는 `편향² + 분산 + 노이즈`이고, 노이즈는 어떤 모델로도 줄일 수 없으므로 앞의 둘의 합이 가장 작은 복잡도를 고르게 된다.

## 정리
- 추정량은 확률 변수이며, 그 품질은 편향(평균적인 치우침)과 분산(흔들림)으로 나뉘고 `MSE = 편향² + 분산`이다.
- 표본 분산은 x̄를 기준으로 재기 때문에 n으로 나누면 작게 나오고, n−1로 나누면 불편 추정량이 된다.
- 불편성보다 MSE와 일치성이 더 중요할 때가 많으며, 모델 복잡도를 고르는 일은 편향과 분산의 균형점을 찾는 일이다.
