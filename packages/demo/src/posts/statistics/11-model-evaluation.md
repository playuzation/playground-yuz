# [통계학 11/11] 모델 평가: 교차 검증과 평가 지표

> **한 줄 요약** — 모델 평가는 학습에 쓰지 않은 데이터로 성능을 재는 일이며, 데이터를 올바르게 나누고(교차 검증, 누수 방지) 문제에 맞는 지표(정밀도, 재현율, F1)를 골라야 숫자가 실제 성능을 말해 준다.

## 왜 따로 떼어 두나
모델은 학습 데이터에 맞추도록 만들어졌으므로, 학습 데이터에서 잰 점수는 실제보다 좋게 나온다. 3편에서 9차 다항식이 학습 데이터의 노이즈까지 따라간 것처럼, 복잡한 모델일수록 이 차이가 커진다. 우리가 알고 싶은 것은 처음 보는 데이터에서의 성능이므로, 학습에 쓰지 않은 데이터를 따로 떼어 두고 거기서 잰다.

## 학습·검증·테스트 분할
| 세트 | 용도 | 비유 |
|---|---|---|
| 학습 | 파라미터 학습 | 교과서 |
| 검증 | 모델과 하이퍼파라미터 선택 | 모의고사 |
| 테스트 | 마지막에 한 번 성능 보고 | 본시험 |

검증 세트가 따로 필요한 이유는, 모델 구조나 학습률을 고르는 것도 일종의 학습이기 때문이다. 테스트 세트를 보며 이것저것 고르면 6편의 다중 비교처럼 테스트 점수가 낙관적으로 부풀려지고, 테스트 세트는 더 이상 "처음 보는 데이터"가 아니게 된다. 그래서 테스트 세트는 모든 선택을 마친 뒤 한 번만 쓴다.

## k겹 교차 검증
데이터가 적으면 검증 세트도 작아지고, 2편에서 봤듯이 작은 표본으로 잰 점수는 크게 흔들린다. **k겹 교차 검증**(k-fold cross-validation)은 데이터를 k개 겹(fold)으로 나눈 뒤, 각 겹을 한 번씩 검증용으로 쓰고 나머지로 학습하는 일을 k번 반복해 평균을 낸다. 모든 데이터가 한 번씩 검증에 쓰이므로 추정이 더 안정적이다. 3편의 다항식 예제를 데이터 20개로 다시 해 보자.
```python
import numpy as np

rng = np.random.default_rng(0)
x = rng.uniform(0, 1, 20)
y = np.sin(2 * np.pi * x) + rng.normal(0, 0.3, 20)   # 데이터 20개
folds = np.array_split(rng.permutation(20), 5)        # 섞어서 5겹(4개씩)으로 나눈다

for degree in [1, 3, 9]:
    train_err, val_err = [], []
    for k in range(5):
        val = folds[k]                                # k번째 겹은 검증용
        tr = np.concatenate([f for j, f in enumerate(folds) if j != k])
        coef = np.polyfit(x[tr], y[tr], degree)
        train_err.append(np.mean((np.polyval(coef, x[tr]) - y[tr]) ** 2))
        val_err.append(np.mean((np.polyval(coef, x[val]) - y[val]) ** 2))
    print(f"차수 {degree}: 학습 오차 {np.mean(train_err):.3f}  검증 오차 {np.mean(val_err):.3f}")
```
```text
차수 1: 학습 오차 0.320  검증 오차 0.452
차수 3: 학습 오차 0.034  검증 오차 0.050
차수 9: 학습 오차 0.016  검증 오차 0.206
```

학습 오차는 차수가 높을수록 계속 줄지만, 검증 오차는 3차에서 가장 낮고 9차에서 다시 커진다. 3편에서는 참 함수를 알아서 편향과 분산을 직접 계산했지만, 현실에서는 참 함수를 모른다. 교차 검증은 데이터만으로 그 균형점을 찾게 해 준다. 차수를 고른 뒤에는 전체 데이터로 다시 학습한다. 대가는 학습을 k번 해야 한다는 것이라, 데이터가 충분히 크면 검증 세트 하나로 대신하기도 한다.

## 데이터 누수
**데이터 누수**(data leakage)는 검증·테스트 데이터의 정보가 학습 과정에 새어 들어가, 실전에서는 낼 수 없는 점수가 나오는 실수다. 교차 검증을 해도 막아 주지 않는다.
- **전처리를 전체 데이터로 하기**: 평균과 표준편차로 정규화할 때 전체 데이터의 값을 쓰면 검증 데이터의 통계가 학습에 섞인다. 전처리 값은 학습 데이터에서만 계산한다.
- **같은 대상이 양쪽에 들어가기**: 같은 사용자의 기록이나 중복 샘플이 학습과 테스트에 나뉘면 모델은 외운 것을 맞히게 된다. 사용자 단위로 나눈다.
- **미래로 과거를 예측하기**: 시계열에서 무작위로 섞어 나누면 미래 정보로 과거를 맞히게 된다. 시간 순서대로 나눈다.
- **정답이 새는 특징**: "환불 처리 일자"로 "환불 여부"를 예측하는 것처럼, 정답이 정해진 뒤에야 생기는 값은 특징으로 쓰면 안 된다.

## 혼동 행렬과 평가 지표
분류 결과는 예측과 실제의 조합으로 네 칸에 나뉜다. 이것이 **혼동 행렬**이다.

| 예측 | 실제 양성 | 실제 음성 |
|---|---|---|
| 양성 | TP (참 양성) | FP (거짓 양성) |
| 음성 | FN (거짓 음성) | TN (참 음성) |
```text
정확도 = (TP + TN) / 전체
정밀도 = TP / (TP + FP)     양성이라고 한 것 중 진짜 양성의 비율
재현율 = TP / (TP + FN)     진짜 양성 중 잡아낸 비율
F1     = 2 · 정밀도 · 재현율 / (정밀도 + 재현율)     (둘의 조화 평균)
```

"음성"을 귀무 가설로 보면 FP는 6편의 1종 오류, FN은 2종 오류에 해당한다. **정밀도**는 "경보를 울렸을 때 믿을 만한가", **재현율**은 "놓치지 않는가"를 잰다. F1은 둘 중 하나가 낮으면 함께 낮아지도록 조화 평균을 쓴다.

## 불균형 데이터에서 정확도의 함정
거래 1,000건 중 사기가 10건(1%)뿐인 데이터를 생각하자. 사기 8건을 잡고 정상 거래 20건을 잘못 의심한 모델과, 무조건 "정상"이라고만 답하는 모델을 비교한다.
```python
import numpy as np

y_true = np.array([1] * 10 + [0] * 990)                       # 거래 1,000건 중 사기(1) 10건
y_model = np.array([1] * 8 + [0] * 2 + [1] * 20 + [0] * 970)  # 사기 8건을 잡고 정상 20건을 오탐
y_lazy = np.zeros(1000, dtype=int)                            # 늘 "정상(0)"이라고 답한다

def report(y_true, y_pred):
    tp = np.sum((y_pred == 1) & (y_true == 1))
    fp = np.sum((y_pred == 1) & (y_true == 0))
    fn = np.sum((y_pred == 0) & (y_true == 1))
    tn = np.sum((y_pred == 0) & (y_true == 0))
    acc = (tp + tn) / len(y_true)
    prec = tp / (tp + fp) if tp + fp else 0.0
    rec = tp / (tp + fn) if tp + fn else 0.0
    f1 = 2 * prec * rec / (prec + rec) if prec + rec else 0.0
    print(f"TP={tp} FP={fp} FN={fn} TN={tn}  정확도 {acc:.3f} 정밀도 {prec:.3f} 재현율 {rec:.3f} F1 {f1:.3f}")

report(y_true, y_model)
report(y_true, y_lazy)
```
```text
TP=8 FP=20 FN=2 TN=970  정확도 0.978 정밀도 0.286 재현율 0.800 F1 0.421
TP=0 FP=0 FN=10 TN=990  정확도 0.990 정밀도 0.000 재현율 0.000 F1 0.000
```

아무것도 하지 않는 모델의 정확도가 99.0%로, 사기의 80%를 잡아낸 모델(97.8%)보다 높다. 99%가 정상인 데이터에서는 늘 "정상"이라고만 답해도 99%가 나오기 때문이다. 불균형 데이터에서는 정확도 대신 정밀도·재현율·F1을 보고, 무조건 다수 클래스로 답하는 기준선과 비교해야 한다.

정밀도와 재현율은 서로 맞바꾸는 관계다. 9편의 로지스틱 회귀처럼 확률을 내는 모델은 분류 기준을 0.5에서 낮추면 더 많이 의심해 재현율이 오르고 정밀도가 떨어진다. 어느 쪽을 중시할지는 오류의 비용이 정한다. 스팸 필터는 진짜 메일을 버리지 않도록 정밀도를, 사기 탐지나 질병 선별 검사는 놓치지 않도록 재현율을 중시하는 경우가 많다.

## 정리
- 성능은 학습에 쓰지 않은 데이터로 재고, 검증 세트로 고르며, 테스트 세트는 마지막에 한 번만 쓴다.
- k겹 교차 검증은 적은 데이터로도 안정적으로 모델을 고르게 해 주지만, 데이터 누수는 막아 주지 않는다.
- 불균형 데이터에서는 정확도가 무의미할 수 있으므로 혼동 행렬, 정밀도, 재현율, F1을 오류의 비용에 맞춰 본다.
