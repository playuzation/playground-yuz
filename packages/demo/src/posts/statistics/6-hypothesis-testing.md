# [통계학 6/11] 가설 검정과 p값

> **한 줄 요약** — 가설 검정은 "차이가 없다"는 귀무 가설을 세워 두고, 그 가설이 맞다면 지금 같은 데이터가 얼마나 드물게 나오는지(p값)를 재서 판단하는 절차이며, p값은 귀무 가설이 참일 확률이 아니다.

## 이 글에서 다루는 것
- 귀무 가설, 대립 가설, 검정 통계량
- p값의 정확한 정의와 동전 예제 계산
- 유의 수준 α, 1종 오류와 2종 오류
- p값에 대한 흔한 오해
- 여러 번 검정할 때 생기는 다중 비교 문제

## 검정의 논리
동전을 100번 던졌더니 앞면이 60번 나왔다. 이 동전은 앞면이 잘 나오도록 조작된 것일까, 아니면 공정한 동전에서도 이 정도는 나올 수 있을까?

가설 검정은 증명하고 싶은 주장의 반대편을 먼저 세운다.
- **귀무 가설** H₀: 효과가 없다. 동전은 공정하다(θ = 0.5).
- **대립 가설** H₁: 효과가 있다. 동전은 공정하지 않다(θ ≠ 0.5).

그다음 H₀가 참이라고 가정하고 데이터를 본다. 그 가정 아래에서 관측 결과가 매우 드물다면 "가정이 틀렸을 가능성이 크다"며 H₀를 기각한다. 귀류법과 닮았지만, 모순 대신 "드물다"는 확률적 판단을 쓴다는 점이 다르다.

데이터를 숫자 하나로 요약해 판단에 쓰는 값을 **검정 통계량**이라고 한다. 여기서는 앞면 수 X다. H₀ 아래에서 X는 이항 분포 B(100, 0.5)를 따르므로 평균 50 근처에 몰려 있어야 하고, 표준편차는 `√(100 × 0.5 × 0.5) = 5`다. 이항 분포 자체는 확률과 분포 6편에서 다룬다.

## p값의 정의
**p값**은 다음과 같이 정의한다.
```text
p값 = P(지금 관측한 것만큼, 또는 그보다 더 극단적인 검정 통계량 ∣ H₀가 참)
```

H₁이 "θ ≠ 0.5"이므로 양쪽 극단을 모두 센다. 즉 `P(X ≥ 60 또는 X ≤ 40 ∣ θ = 0.5)`다.
```python
import numpy as np
from scipy import stats

result = stats.binomtest(60, n=100, p=0.5)                 # H₀: θ = 0.5, 양측 검정
print(f"{result.pvalue:.4f}")
print(f"{stats.binomtest(60, n=100, p=0.5, alternative='greater').pvalue:.4f}")  # 단측

# 같은 p값을 시뮬레이션으로: 공정한 동전을 100번 던지는 실험을 10만 번
rng = np.random.default_rng(0)
heads = rng.binomial(100, 0.5, size=100_000)
print(np.mean(np.abs(heads - 50) >= 10))                   # 60 이상 또는 40 이하
```
```text
0.0569
0.0284
0.05655
```

공정한 동전으로도 이 정도로 치우친 결과는 약 5.7%의 확률로 나온다. 시뮬레이션 결과도 정의대로 같은 값을 보여 준다. "앞면이 더 잘 나온다"는 한쪽 방향만 대립 가설로 세우는 단측 검정이라면 p값은 절반인 0.0284가 된다. 방향은 데이터를 보기 전에 정해야 한다.

## 유의 수준과 두 가지 오류
기각 기준이 되는 확률 **유의 수준** α는 데이터를 보기 전에 정한다. 관례적으로 0.05를 많이 쓴다. p ≤ α이면 H₀를 기각하고 "통계적으로 유의하다"고 말한다. 앞면 60번은 p = 0.057이라 α = 0.05에서 기각하지 못하고, 61번이었다면 p = 0.035로 기각한다. 기각하지 못했다는 것은 "H₀가 참"이라는 뜻이 아니라 "H₀를 버릴 만큼 증거가 충분하지 않다"는 뜻이다.

판단은 두 방향으로 틀릴 수 있다.

| 판단 | H₀가 참 | H₀가 거짓 |
|---|---|---|
| 기각 | 1종 오류 (확률 α) | 올바른 검출 (검정력) |
| 기각 안 함 | 올바른 판단 | 2종 오류 (확률 β) |

**1종 오류**는 효과가 없는데 있다고 하는 거짓 양성, **2종 오류**는 효과가 있는데 놓치는 거짓 음성이다. 효과가 있을 때 제대로 잡아낼 확률 `1 − β`를 **검정력**(power)이라 한다. 동전이 실제로 θ = 0.6으로 조작되어 있다면, 100번 던지는 검정은 이를 얼마나 잡아낼까? α = 0.05에서 기각되는 결과는 앞면 61번 이상 또는 39번 이하이므로, 앞의 코드에 이어서 그 확률을 계산한다.
```python
b = stats.binom(100, 0.6)              # 실제로는 θ = 0.6인 동전
print(round(b.sf(60) + b.cdf(39), 3))  # 61번 이상 또는 39번 이하가 나와 기각될 확률
```
```text
0.462
```

절반도 안 된다. α를 낮추면 1종 오류는 줄지만 2종 오류가 늘어나고, 둘을 함께 줄이려면 표본을 늘려야 한다. 7편에서 이 계산으로 실험 규모를 정한다.

## 흔한 오해
- **p값은 H₀가 참일 확률이 아니다.** p값은 `P(데이터 ∣ H₀)` 쪽이고, `P(H₀ ∣ 데이터)`를 구하려면 사전 확률과 베이즈 정리가 필요하다.
- **p > 0.05는 "차이가 없다"는 증거가 아니다.** 위처럼 검정력이 낮으면 실제 효과도 자주 놓친다.
- **작은 p값이 큰 효과를 뜻하지는 않는다.** 동전을 100만 번 던져 앞면이 50.2%만 나와도 p ≈ 0.00006이다. 표본이 크면 실용적으로 의미 없는 차이도 유의해진다. 효과 크기와 신뢰 구간을 함께 봐야 한다.
- **0.049와 0.051은 본질적으로 다르지 않다.** 0.05는 관례적인 선일 뿐이다.

## 다중 비교 문제
효과가 전혀 없는 지표 20개를 각각 α = 0.05로 검정하면, 적어도 하나가 우연히 유의하게 나올 확률은 `1 − 0.95²⁰ ≈ 0.64`다. 이것저것 검정해 보다가 유의한 것만 보고하면 거짓 발견이 거의 확실해진다(p-해킹). 가장 단순한 대책은 검정 횟수 m으로 기준을 나눠 각 검정에 `α/m`을 쓰는 **본페로니 보정**이다. 20개라면 0.0025다. 더 근본적으로는 무엇을 어떻게 검정할지 데이터를 보기 전에 정해 두어야 한다.

## 정리
- 가설 검정은 H₀를 가정했을 때 관측 데이터가 얼마나 극단적인지를 p값으로 재고, p ≤ α이면 H₀를 기각한다.
- p값은 "H₀ 아래에서 이만큼 극단적인 결과가 나올 확률"이지, H₀가 참일 확률도 효과의 크기도 아니다.
- 1종 오류(α)와 2종 오류(β)는 서로 맞물려 있고, 여러 번 검정하면 거짓 발견이 급격히 늘어난다.
