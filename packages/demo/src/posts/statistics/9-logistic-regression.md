# [통계학 9/11] 로지스틱 회귀: 확률을 예측하는 회귀

> **한 줄 요약** — 로지스틱 회귀는 선형 결합 `w·x + b`를 시그모이드 함수에 통과시켜 0과 1 사이의 확률로 바꾸는 분류 모델이며, 교차 엔트로피 손실의 기울기가 `(p − y)·x`라는 단순한 형태라서 신경망 출력층의 원형이 된다.

## 이 글에서 다루는 것
- 시그모이드 함수로 확률 만들기
- 오즈와 로짓: 로지스틱 회귀가 실제로 선형인 부분
- 결정 경계는 직선이다
- 교차 엔트로피 손실과 기울기 `(p − y)·x` 유도
- NumPy로 학습하기, 그리고 XOR을 풀지 못하는 이유

## 확률을 예측하고 싶다
스팸인가 아닌가, 사용자가 좋아요를 누를 것인가처럼 답이 0 또는 1인 문제에서는 "1일 확률" `P(y = 1 ∣ x)`를 예측하고 싶다. 8편의 선형 회귀 `w·x + b`는 −∞에서 ∞까지 아무 값이나 내놓으므로 확률로 쓸 수 없다. 그래서 이 값을 (0, 1) 구간으로 눌러 담는 함수를 씌운다.

## 시그모이드 함수
```text
σ(z) = 1 / (1 + e^(−z))

σ(0) = 0.5,   σ(2) ≈ 0.881,   σ(−2) ≈ 0.119,   z → ∞이면 1,  z → −∞이면 0
```

**시그모이드** 함수는 S자 모양으로 증가하며 어떤 실수든 0과 1 사이로 보낸다. **로지스틱 회귀**는 선형 결합을 여기에 넣어 확률을 얻는다.
```text
z = w·x + b        (선형 부분, 로짓)
p = σ(z)           (1일 확률)
```

## 오즈와 로짓
어떤 일이 일어날 확률과 일어나지 않을 확률의 비 `p/(1 − p)`를 **오즈**(odds)라고 한다. p = 0.8이면 오즈는 4, 즉 "4 대 1"이다. 오즈에 로그를 씌운 것이 **로짓**(logit)이고, 로짓은 시그모이드의 역함수다.
```text
logit(p) = log( p / (1 − p) )
logit(σ(z)) = z   ⇒   log( p / (1 − p) ) = w·x + b
```

즉 로지스틱 회귀는 "로그 오즈가 x에 대해 선형"이라고 가정하는 모델이다. 특징 xⱼ가 1 늘면 로그 오즈가 wⱼ만큼 늘고, 오즈는 e^(wⱼ)배가 된다. 아래 예제에서 w₁ ≈ 1.67이 나오는데, x₁이 1 늘 때마다 오즈가 약 5.31배가 된다는 뜻이다. 신경망에서 소프트맥스에 들어가기 전의 출력을 "로짓"이라고 부르는 것도 여기서 온 이름이다.

## 결정 경계는 직선이다
확률이 0.5 이상이면 1로 분류한다고 하자. σ는 증가 함수이고 σ(0) = 0.5이므로 `p ≥ 0.5 ⇔ w·x + b ≥ 0`이다. 두 클래스를 가르는 **결정 경계** `w·x + b = 0`은 입력이 2개면 직선, 3개면 평면이다. 확률은 곡선으로 변하지만, 경계 자체는 언제나 곧다. 로지스틱 회귀가 **선형 분류기**라고 불리는 이유다.

## 손실과 기울기: p − y
정답 y ∈ {0, 1}에 대한 손실로는 4편에서 본 대로 베르누이 분포의 음의 로그 가능도, 즉 이진 교차 엔트로피를 쓴다. 미분의 연쇄 법칙으로 기울기를 구하면 놀랄 만큼 깔끔해진다.
```text
ℓ = −[ y·log p + (1 − y)·log(1 − p) ],   p = σ(z),   z = w·x + b

σ′(z)   = σ(z)·(1 − σ(z)) = p(1 − p)
∂ℓ/∂p   = −y/p + (1 − y)/(1 − p)
∂ℓ/∂z   = ∂ℓ/∂p · p(1 − p) = −y(1 − p) + (1 − y)p = p − y
∂ℓ/∂w   = (p − y)·x,     ∂ℓ/∂b = p − y
```

예측 확률과 정답의 차이에 입력을 곱한 것이 기울기다. 정답이 1인데 p = 0.2라고 예측했다면 `p − y = −0.8`이라 w를 x 방향으로 크게 움직이고, 거의 맞혔다면 거의 움직이지 않는다. 선형 회귀와 달리 정규 방정식 같은 닫힌 해가 없어 경사 하강법으로 반복해서 풀지만, 이 손실은 w와 b에 대한 볼록 함수라서 지역 최솟값에 갇힐 걱정은 없다.

## NumPy로 학습하기
두 무리로 나뉜 2차원 점 100개를 분류하고, 같은 코드로 XOR도 시도해 보자.
```python
import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def train(X, y, lr=0.5, steps=2000):
    w, b = np.zeros(X.shape[1]), 0.0
    for _ in range(steps):
        p = sigmoid(X @ w + b)              # 예측 확률
        w -= lr * X.T @ (p - y) / len(y)    # 기울기: (p − y)·x 의 평균
        b -= lr * (p - y).mean()
    return w, b

rng = np.random.default_rng(0)
X = np.vstack([rng.normal(-1, 1, (50, 2)), rng.normal(1, 1, (50, 2))])  # 두 무리, 50개씩
y = np.array([0] * 50 + [1] * 50)

w, b = train(X, y)
p = sigmoid(X @ w + b)
loss = -np.mean(y * np.log(p) + (1 - y) * np.log(1 - p))   # 교차 엔트로피
print(w.round(3), round(b, 3), round(loss, 3), ((p > 0.5) == y).mean())

X_xor = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], dtype=float)
y_xor = np.array([0, 1, 1, 0])
w, b = train(X_xor, y_xor)
print(sigmoid(X_xor @ w + b).round(2))
```
```text
[1.67  1.768] -0.148 0.244 0.89
[0.5 0.5 0.5 0.5]
```

첫 번째 데이터에서는 경계 `1.67·x₁ + 1.768·x₂ − 0.148 = 0`을 찾아 89%를 맞혔다. 두 무리가 일부 겹치게 만들었으므로 직선으로는 이 정도가 한계다.

## XOR은 풀지 못한다
XOR에서는 네 점 모두 0.5를 내놓았다. (0, 1)과 (1, 0)은 1, (0, 0)과 (1, 1)은 0인 배치는 어떤 직선으로도 가를 수 없다. 손실이 볼록이고 네 점이 대칭이라, 직선 경계를 가진 모델이 낼 수 있는 최선이 "모두 반반"이다.

AI 기초 1편의 XOR 코드를 다시 보면 이 글의 내용이 그대로 들어 있다. 출력층 `p = sigmoid(h @ W2 + b2)`는 은닉층 출력 h를 입력으로 받는 로지스틱 회귀이고, 역전파의 첫 줄 `dz2 = (p - y) / len(X)`는 위에서 유도한 `∂ℓ/∂z = p − y`를 샘플 수로 평균한 것이다. 차이는 은닉층이다. 은닉층이 입력을 새로운 공간 h로 옮겨 그 공간에서는 직선 하나로 XOR을 가를 수 있게 만들고, 마지막 로지스틱 회귀가 그 직선을 긋는다. 클래스가 셋 이상이면 시그모이드 대신 소프트맥스를 쓰는데, 이때도 로짓에 대한 기울기는 `p − y`(정답을 원-핫 벡터로 쓴 경우) 꼴로 똑같다.

## 어디에 쓰이나
- AI 기초 1편 「딥러닝: 특징까지 스스로 배우는 머신러닝」: XOR 예제의 출력층과 `dz2 = (p - y)`가 바로 로지스틱 회귀와 그 기울기이며, 로지스틱 회귀 하나로는 결정 경계가 직선이라 XOR을 풀 수 없어서 은닉층이 필요하다.
- 미적분 4편 「지수 함수와 로그 함수」: 시그모이드의 `e^(−z)`, 로그 오즈, 오즈가 e^(wⱼ)배가 된다는 해석의 바탕이다.
- 정보 이론 2편 「교차 엔트로피」: 여기서 쓴 손실이 왜 "교차 엔트로피"라는 이름을 갖는지 정보 이론의 관점에서 설명한다.
- 11편 「모델 평가: 교차 검증과 평가 지표」: 0.5라는 분류 기준을 바꾸면 정밀도와 재현율이 달라지는데, 그 평가 방법을 다룬다.

## 정리
- 로지스틱 회귀는 `p = σ(w·x + b)`로 1일 확률을 예측하며, 로그 오즈 `log(p/(1 − p))`가 x에 대해 선형인 모델이다.
- 결정 경계 `w·x + b = 0`은 직선(초평면)이라, XOR처럼 직선으로 나눌 수 없는 데이터는 풀지 못한다.
- 교차 엔트로피 손실의 기울기는 `(p − y)·x`이며, 이것이 신경망 분류 출력층의 역전파 첫 단계와 똑같다.
