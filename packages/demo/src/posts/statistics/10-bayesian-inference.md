# [통계학 10/11] 베이즈 추론: 사전 분포에서 사후 분포로

> **한 줄 요약** — 베이즈 추론은 모수를 확률 변수로 보고, 데이터를 보기 전의 믿음(사전 분포)에 가능도를 곱해 데이터를 본 뒤의 믿음(사후 분포)을 얻는 방법이며, 결과가 값 하나가 아니라 분포라서 "모수가 이 범위에 있을 확률"을 직접 말할 수 있다.

## 이 글에서 다루는 것
- 모수를 확률 변수로 보기: 사전, 가능도, 사후
- 베타-이항 켤레: Beta(1, 1)에서 7번 중 6번 앞면이면 Beta(7, 2)
- 사후 평균, MAP와 최대 우도 추정의 차이
- 가우시안 사전을 둔 MAP = L2 가중치 감쇠
- 신용 구간과 신뢰 구간의 차이

## 모수를 확률 변수로 보기
2~7편의 방법은 **빈도주의** 관점이다. 모수 θ는 모르지만 고정된 값이고, 무작위인 것은 데이터다. **베이즈 추론**은 θ에 대한 불확실성 자체를 확률 분포로 나타낸다. 동전의 앞면 확률을 모른다면 "θ는 0과 1 사이 어디든 비슷하게 그럴듯하다" 같은 믿음을 분포로 적어 두고, 데이터를 볼 때마다 그 분포를 고쳐 나간다.

## 사전, 가능도, 사후
확률과 분포 3편의 베이즈 정리를 모수에 적용하면 된다. 데이터를 D라 하면 다음과 같다.
```text
p(θ ∣ D) = p(D ∣ θ) · p(θ) / p(D)

사후 분포 ∝ 가능도 × 사전 분포
```

- **사전 분포** `p(θ)`: 데이터를 보기 전 θ에 대한 믿음.
- **가능도** `p(D ∣ θ)`: 4편의 그 가능도. θ가 이렇다면 이 데이터가 나올 확률.
- **사후 분포** `p(θ ∣ D)`: 데이터를 본 뒤 고쳐진 믿음. 분모 `p(D)`는 θ와 무관한 상수라 전체 넓이를 1로 맞추는 역할만 한다.

## 동전 예: 베타-이항 켤레
0과 1 사이 값의 분포로 자주 쓰는 **베타 분포** Beta(α, β)의 밀도는 `θ^(α−1)·(1 − θ)^(β−1)`에 비례한다. Beta(1, 1)은 0과 1 사이의 균등 분포, 즉 "아무것도 모른다"는 사전 분포다. 동전을 n번 던져 앞면이 k번 나왔다면 가능도는 `θ^k·(1 − θ)^(n−k)`이고, 둘을 곱하면 지수끼리 더해진다.
```text
사전  Beta(α, β)          ∝ θ^(α−1) · (1 − θ)^(β−1)
가능도                      θ^k · (1 − θ)^(n−k)
사후  Beta(α + k, β + n − k) ∝ θ^(α+k−1) · (1 − θ)^(β+n−k−1)

Beta(1, 1)에서 7번 중 6번 앞면  →  Beta(1 + 6, 1 + 1) = Beta(7, 2)
```

사후 분포가 사전 분포와 같은 베타 분포로 나오는데, 이런 짝을 **켤레 사전 분포**(conjugate prior)라고 한다. 갱신이 "α에 앞면 수, β에 뒷면 수를 더하기"로 끝나므로, α와 β를 미리 관측해 둔 가상의 앞면·뒷면 수처럼 읽을 수 있다. 켤레가 아닐 때도 θ를 촘촘한 격자로 나눠 "사전 × 가능도"를 직접 계산하면 사후 분포를 얻을 수 있다. 격자 계산이 Beta(7, 2)와 맞는지 확인해 보자.
```python
import numpy as np
from scipy import stats

heads, n = 6, 7
theta = np.linspace(0, 1, 10_001)                    # θ 후보를 촘촘한 격자로
prior = stats.beta(1, 1).pdf(theta)                  # 사전: 균등 분포 Beta(1, 1)
likelihood = theta**heads * (1 - theta) ** (n - heads)
post = prior * likelihood
post /= post.sum()                                   # 정규화 → 사후 분포

print(f"격자 사후 평균 {np.sum(theta * post):.4f}, Beta(7, 2) 평균 {7 / 9:.4f}")
print(f"MAP {theta[post.argmax()]:.4f}, MLE {heads / n:.4f}")
print(stats.beta(7, 2).ppf([0.025, 0.975]).round(3))   # 95% 신용 구간
print(round(stats.beta(7, 2).sf(0.5), 3))              # P(θ > 0.5 ∣ 데이터)
```
```text
격자 사후 평균 0.7778, Beta(7, 2) 평균 0.7778
MAP 0.8571, MLE 0.8571
[0.473 0.968]
0.965
```

## 사후 분포를 요약하기: 평균, MAP, MLE
사후 분포 전체가 답이지만, 값 하나가 필요하면 요약한다. **사후 평균**은 Beta(α, β)에서 `α/(α + β) = 7/9 ≈ 0.778`이다. 사후 분포가 가장 높은 지점인 **MAP**(최대 사후 확률) 추정은 `(α − 1)/(α + β − 2) = 6/7 ≈ 0.857`이다. 균등 사전에서는 MAP가 최대 우도 추정 k/n과 정확히 같다. 사전 분포가 평평하면 사후는 가능도와 모양이 같기 때문이다.

사전 분포를 바꾸면 결과가 달라진다. "웬만한 동전은 공정하다"는 믿음을 Beta(5, 5)로 나타내면 같은 데이터에서 다음과 같다.

| 사전 | 사후 | 사후 평균 | MAP |
|---|---|---|---|
| Beta(1, 1) | Beta(7, 2) | 0.778 | 0.857 |
| Beta(5, 5) | Beta(11, 6) | 0.647 | 0.667 |

사전 믿음이 강할수록 추정이 0.5 쪽으로 당겨진다. 단 7번 던진 결과로 "앞면 확률 86%"라고 단정하는 것보다 합리적일 때가 많다. 데이터가 쌓이면 k와 n − k가 α, β를 압도하므로 사전 분포의 영향은 점점 사라진다.

## 가우시안 사전을 둔 MAP = L2 가중치 감쇠
MAP는 로그를 씌우면 "로그 가능도 + 로그 사전"을 최대화하는 문제가 된다. 모델 가중치 w에 평균 0, 분산 τ²인 정규 분포 사전을 두면 로그 사전은 `−‖w‖²/(2τ²)`에 상수를 더한 것이다.
```text
ŵ_MAP = argmax [ log p(D ∣ w) + log p(w) ]
      = argmin [ −log p(D ∣ w) + λ·‖w‖² ],    λ = 1/(2τ²)
```

앞의 항은 4편에서 본 손실(교차 엔트로피나 제곱 오차)이고, 뒤의 항은 바로 **L2 규제**, 딥러닝에서 말하는 가중치 감쇠다(일반 경사 하강법에서는 둘이 같다). "가중치는 0 근처의 작은 값일 것"이라는 사전 믿음이 규제의 정체이고, τ가 작을수록(믿음이 강할수록) λ가 커진다. 최대 우도 추정은 이 사전 항이 없는 경우, 즉 MAP에서 사전을 평평하게 둔 특수한 경우다. 같은 논리로 라플라스 분포 사전은 L1 규제가 된다.

## 신용 구간과 신뢰 구간
사후 분포에서 가운데 95%를 잘라낸 구간을 **신용 구간**(credible interval)이라고 한다. 위 예에서 Beta(7, 2)의 95% 신용 구간은 [0.473, 0.968]이고, 이는 "이 사전과 데이터라면 θ가 이 구간에 있을 확률이 95%"라는 뜻이다. 5편에서 신뢰 구간에는 허용되지 않았던 바로 그 해석이다. 같은 방식으로 `P(θ > 0.5 ∣ 데이터) ≈ 0.965`처럼 궁금한 질문에 확률로 바로 답할 수 있다.

| 구분 | 신뢰 구간 (5편) | 신용 구간 |
|---|---|---|
| 모수 | 고정된 상수 | 확률 변수 |
| 95%의 뜻 | 절차가 모수를 덮는 비율 | 모수가 구간에 있을 확률 |
| 필요한 것 | 표본 분포 | 사전 분포 |

데이터가 많고 사전 분포가 약하면 두 구간은 수치상 거의 같아진다. 베이즈 방법의 약점은 사전 분포를 고르는 데 주관이 들어간다는 점과, 켤레가 아닌 복잡한 모델에서는 사후 분포를 계산하기 어렵다는 점이다. 후자는 사후 분포에서 표본을 뽑아 근사하는 방법으로 해결한다.

## 정리
- 베이즈 추론은 θ를 확률 변수로 보고 `사후 ∝ 가능도 × 사전`으로 믿음을 갱신한다.
- 베타-이항 켤레에서는 앞면·뒷면 수를 α, β에 더하기만 하면 되고, Beta(1, 1)과 7번 중 6번 앞면은 Beta(7, 2)가 된다.
- 균등 사전의 MAP는 최대 우도 추정과 같고, 가우시안 사전의 MAP는 L2 가중치 감쇠와 같으며, 신용 구간은 "모수가 구간에 있을 확률"로 읽을 수 있다.
