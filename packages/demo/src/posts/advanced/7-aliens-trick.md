# [심화 알고리즘 7/14] Aliens 트릭: 개수 제약을 벌점으로 바꾸는 라그랑주 완화

> **한 줄 요약** — "정확히 k개로 나누는 최소 비용" f(k)가 k에 대해 볼록이면, 개수 제약을 없애고 묶음 하나마다 벌점 λ를 붙인 DP를 한 번 푼 뒤 λ를 이분 탐색해 최적 개수를 k에 맞추면 되므로, DP에서 k 차원이 사라져 O(k·n²)이 O(n² log C)로, 볼록 껍질 트릭과 합치면 O(n log C)로 줄어든다.

## 이 글에서 다루는 것
- 예제: 정확히 k개 묶음으로 나누는 최소 비용과 k 차원의 부담
- 벌점 λ를 붙인 DP와 λ 이분 탐색, 답 g(λ) − λk
- 왜 볼록이어야 하나: 접선의 기하와 볼록이 아닌 반례
- 같은 값이 여러 k에서 나올 때(경계 tie)의 처리
- 볼록성 실험, 무작위 대조, 볼록 껍질 트릭과 합치기

## 예제 문제: 정확히 k개 묶음
음이 아닌 수 n개를 연속된 정확히 k개 묶음으로 나누고 묶음 비용 (묶음 합)²의 합을 최소로 한다. 동적 계획법 11편 「분할 정복 최적화와 크누스 최적화」의 예제와 같다. 층 DP `dp[t][i] = min dp[t−1][j] + (S[i] − S[j])²`는 O(k·n²)이고, 분할 정복 최적화로 O(k·n log n)이 되지만 여전히 k배다. k가 n에 가까우면 n² log n이다. 문제는 "개수 k"라는 차원 자체다.

## 아이디어: 개수 대신 벌점
개수 제약을 지우고, 대신 묶음을 하나 만들 때마다 벌점 λ를 낸다고 하자.
```text
g(λ) = min (f(k) + λ·k)
       k
```
g(λ)는 개수 제한 없는 DP 한 번으로 구한다. 묶음 비용에 λ만 더하면 되고, 이때 최적해가 쓴 묶음 수 cnt(λ)도 함께 기록한다. λ가 크면 묶음을 적게, 작으면 많이 쓰니 cnt(λ)는 λ가 커질수록 줄어든다. 그러니 cnt(λ) = k가 되는 λ를 이분 탐색으로 찾으면, 그 최적해는 정확히 k묶음이면서 비용 f(k) + λk가 최소이므로 `f(k) = g(λ) − λ·k`다. 제약을 목적 함수의 벌점 항으로 옮기는 이 방법은 최적화에서 말하는 **라그랑주 완화**(Lagrangian relaxation)이고, λ는 라그랑주 승수다.

경시 프로그래밍에서는 IOI 2016의 문제 「Aliens」로 널리 알려져 **Aliens 트릭**이라고 부르고, **WQS 이분 탐색**이라고도 한다. 학계에서는 1990년대 초 아가르왈(Aggarwal)·시버(Schieber)·도쿠야마(Tokuyama)가 몽주(Monge) 성질 그래프에서 "간선 k개짜리 최소 경로"를 구할 때 간선 무게에 매개 변수를 더해 간선 수를 맞추는 같은 생각을 썼다.

## 왜 볼록이어야 하나
점 (k, f(k))들을 찍고 기울기 −λ인 직선을 아래에서 밀어 올린다고 생각하자. g(λ)는 그 직선이 처음 닿는 점에서의 절편이고, 닿는 점이 cnt(λ)다. f가 볼록이면 점들이 아래로 볼록한 껍질 위에 있어서 모든 k가 어떤 λ에서 닿는다. 정확히는 `f(k) − f(k+1) ≤ λ ≤ f(k−1) − f(k)`인 λ면 k가 최적이다. f가 정수면 이 구간의 양 끝이 정수라 λ도 정수에서만 찾으면 된다. 볼록이 아니면 껍질 안쪽에 들어간 k에는 어떤 직선도 먼저 닿지 않는다.
```text
k      1   2   3   4
f(k)  10   4   3   0   볼록 아님
k=3이 최적이려면
  3 + 3λ ≤ 4 + 2λ → λ ≤ 1
  3 + 3λ ≤ 0 + 4λ → λ ≥ 3
→ 그런 λ가 없다
```
그래서 Aliens 트릭을 쓰기 전에 f가 볼록인지 확인해야 한다. 구간 나누기에서 비용이 동적 계획법 11편의 사각 부등식(몽주 성질)을 만족하면 f가 볼록이라는 것이 알려져 있지만, 작은 입력에서 f를 직접 계산해 차분이 늘어나는지 보는 것이 가장 확실하다.

## 구현
벌점 DP는 (값, 묶음 수) 튜플의 최솟값을 취해, 값이 같으면 묶음 수가 **작은** 쪽을 고르게 한다. λ는 0부터 (합)² + 1까지에서 "cnt(λ) ≤ k인 가장 작은 λ"를 찾는다. λ가 (합)²보다 크면 묶음 1개가 최적이므로 이 범위면 충분하다. 정답 확인용으로 모든 k의 f(k)를 O(n³)에 구하는 함수도 둔다.
```python
import random
from collections import deque

def exact_all(c):                   # f[k] = 정확히 k묶음 최소 비용, O(n³)
    n, S, INF = len(c), [0], float("inf")
    for x in c: S.append(S[-1] + x)
    dp, f = [0] + [INF] * n, [INF]
    for t in range(1, n + 1):       # dp[i] = 앞 i개를 t묶음으로
        dp = [INF] + [min(dp[j] + (S[i] - S[j]) ** 2 for j in range(i))
                      for i in range(1, n + 1)]
        f.append(dp[n])
    return f

def penalized(c, lam):              # 묶음마다 벌점 λ: (값, 묶음 수), O(n²)
    S = [0]
    for x in c: S.append(S[-1] + x)
    best = [(0, 0)]
    for i in range(1, len(c) + 1):  # 값이 같으면 묶음 수가 작은 쪽
        best.append(min((best[j][0] + (S[i] - S[j]) ** 2 + lam,
                         best[j][1] + 1) for j in range(i)))
    return best[-1]

def aliens(c, k, solve=penalized):
    lo, hi, calls = 0, sum(c) ** 2 + 1, 0
    while lo < hi:                  # cnt(λ) ≤ k인 가장 작은 λ
        mid = (lo + hi) // 2; calls += 1
        if solve(c, mid)[1] <= k: hi = mid
        else: lo = mid + 1
    val, cnt = solve(c, lo)
    return val - lo * k, lo, cnt, calls + 1     # 답, λ, cnt(λ), DP 호출 수

c = [3, 1, 4, 1, 5, 9, 2, 6]
f = exact_all(c)
print("f(k)", f[1:])
print("차분", [f[k + 1] - f[k] for k in range(1, len(c))])
print(aliens(c, 3), f[3])
print(aliens([1, 1, 1, 1], 3), exact_all([1, 1, 1, 1])[3])
```
```text
f(k) [961, 485, 341, 245, 211, 187, 179, 173]
차분 [-476, -144, -96, -34, -24, -8, -6]
(341, 96, 3, 11) 341
(6, 2, 2, 5) 6
```
차분이 −476, −144, −96, …으로 계속 커지니 f는 볼록이다. k = 3이면 구간 [f(3) − f(4), f(2) − f(3)] = [96, 144]의 가장 작은 정수 λ = 96을 찾았고, 341 = f(3)이 나왔다.

## 경계 tie: 묶음 수가 k와 달라도 답은 맞다
둘째 예제 [1, 1, 1, 1]에서 f = 16, 8, 6, 4로 차분이 −8, −2, −2다. f(2), f(3), f(4)가 한 직선 위에 있어서 λ = 2에서는 k = 2, 3, 4가 모두 같은 값 g(2) = 12를 낸다. 묶음 수가 작은 쪽을 고르게 했으니 cnt(2) = 2이고, k = 3인 λ는 끝내 나오지 않는다. 그래도 k = 3도 λ = 2에서 최적인 개수 중 하나이므로 f(3) + 2·3 = g(2), 곧 f(3) = 12 − 6 = 6이 맞다.

규칙은 두 가지다. ① 동점일 때 묶음 수를 일관되게 최소(또는 최대)로 고른다. ② 최소로 골랐다면 "cnt(λ) ≤ k인 가장 작은 λ"를, 최대로 골랐다면 "cnt(λ) ≥ k인 가장 큰 λ"를 찾는다. 그러면 찾은 λ에서 k가 최적 개수 구간 안에 들어 있어 g(λ) − λk가 정확히 f(k)다. 동점 처리를 섞어 쓰면 cnt가 λ에 대해 단조가 아니게 되어 이분 탐색이 엉뚱한 곳으로 간다.

## 볼록 껍질 트릭과 합치기
벌점 DP를 다시 보면 묶음 비용이 (합)² + λ다. 이것은 동적 계획법 10편 「볼록 껍질 트릭: 직선들의 최솟값으로 DP 가속하기」의 예제에서 M을 λ로 바꾼 것 그대로라, 단조 덱으로 λ마다 O(n)에 풀린다. 동점에서 묶음 수가 작은 쪽을 고르려면 (값, 묶음 수)를 정수 하나 `값·M + 묶음 수`(M > n)로 합쳐 직선에 실으면 된다. 앞 코드에 이어서, 작은 무작위 입력 300개에서 f의 볼록성을 세고 모든 k에 대해 두 Aliens 구현을 정확한 값과 비교한다. 값 범위 2짜리(0과 1뿐)를 섞어 동점을 일부러 많이 만든다.
```python
def penalized_cht(c, lam):          # 같은 벌점 DP를 단조 덱 CHT로 O(n)
    M = len(c) + 1                  # (값, 묶음 수) → 값·M + 묶음 수
    def at(ln, x): return ln[0] * x + ln[1]
    def bad(l1, l2, l3):            # l2가 l1, l3에 가려지나
        return ((l3[1] - l1[1]) * (l1[0] - l2[0])
                <= (l2[1] - l1[1]) * (l1[0] - l3[0]))
    dq, S, key = deque([(0, 0)]), 0, 0
    for x in c:
        S += x
        while len(dq) > 1 and at(dq[0], S) >= at(dq[1], S): dq.popleft()
        key = at(dq[0], S) + (S * S + lam) * M + 1
        ln = (-2 * S * M, key + S * S * M)   # 기울기 −2Sⱼ, 절편 dpⱼ + Sⱼ²
        while len(dq) > 1 and bad(dq[-2], dq[-1], ln): dq.pop()
        dq.append(ln)
    return key // M, key % M

rng, ok, convex = random.Random(8), 0, 0
for _ in range(300):
    m = rng.choice([2, 6, 20])
    c = [rng.randrange(m) for _ in range(rng.randint(1, 9))]
    f = exact_all(c)
    convex += all(f[k - 1] - f[k] >= f[k] - f[k + 1] for k in range(2, len(c)))
    lam = rng.randrange(50)
    same = penalized(c, lam) == penalized_cht(c, lam)
    for k in range(1, len(c) + 1):
        same &= aliens(c, k)[0] == f[k] == aliens(c, k, penalized_cht)[0]
    ok += same
print(f"무작위 300개: 볼록 {convex}개, 모든 k에서 일치 {ok}개")

n, k = 2000, 100
c = [rng.randrange(1000) for _ in range(n)]
ans, lam, cnt, calls = aliens(c, k, penalized_cht)
print("λ", lam, "묶음 수", cnt, "DP 호출", calls)
print("전이 수: Aliens + CHT", calls * n, "/ 층 DP", k * n * (n + 1) // 2)
```
```text
무작위 300개: 볼록 300개, 모든 k에서 일치 300개
λ 99051898 묶음 수 100 DP 호출 41
전이 수: Aliens + CHT 82000 / 층 DP 200100000
```
300개 모두 f가 볼록이었고, 0이 섞여 동점이 많은 입력에서도 모든 k의 답이 맞았다. n = 2000, k = 100에서 Aliens + CHT는 DP를 41번(λ 범위 약 10¹²의 log₂) 돌려 전이 8.2만 번, 층 DP는 약 2억 번이다.

## 자주 하는 실수와 변형
- 동점 처리 없이 아무 최적해의 개수를 쓰는 실수. 위의 [1, 1, 1, 1]처럼 cnt가 k를 건너뛰는 입력에서 이분 탐색 판정이 흔들린다.
- 답을 `g(λ) − λ·cnt(λ)`로 계산하는 실수. 반드시 원래의 k를 곱해 뺀다.
- λ 범위를 너무 좁게 잡기: 한 묶음 더 쓸 때 줄어드는 비용의 최댓값보다 커야 한다. 위에서는 (합)² + 1로 잡았다.
- 최대화 문제(정확히 k개 골라 이익 최대)는 f가 오목일 때 같은 방법을 쓴다. 고를 때마다 λ를 빼고 cnt가 k 이하가 되는 λ를 찾는다.
- "k개 이하" 제약은 λ = 0에서 cnt(0) ≤ k면 g(0)이 답이고, 아니면 정확히 k개와 같다(f가 감소하는 구간이므로).
- 비용이 실수면 λ도 실수 이분 탐색이 되고, 동점 판정에 오차가 끼므로 정수로 바꿀 수 있으면 바꾼다.

## 복잡도
| 방법 | 시간 | 비고 |
|---|---|---|
| 층 DP | O(k·n²) | 정의 그대로 |
| 분할 정복 최적화 | O(k·n log n) | 11편 |
| Aliens + O(n²) DP | O(n² log C) | k와 무관 |
| Aliens + CHT | O(n log C) | 10편 단조 덱 |

- C는 λ의 범위로, 여기서는 (합)² + 1이라 log₂ C는 값 크기의 로그 정도다. 공간은 층이 사라져 O(n)이다.

## 어디에 쓰이나
- 동적 계획법 10편 「볼록 껍질 트릭: 직선들의 최솟값으로 DP 가속하기」: 그 글의 "묶음마다 M을 더하는" 문제가 곧 벌점 문제이고, M을 이분 탐색하는 것이 Aliens 트릭이다.
- 동적 계획법 11편 「분할 정복 최적화와 크누스 최적화」: 같은 k묶음 문제를 k 차원을 남긴 채 가속하는 방법이고, 그 글의 사각 부등식이 이 글의 볼록성의 근거가 된다.
- 미적분 9편 「최적화: 극값과 볼록 함수」: 제약 조건을 승수 λ와 함께 목적 함수로 옮기는 라그랑주 승수법의 이산 판이며, 볼록이어야 제약 있는 최적과 완화한 최적이 일치한다는 보장이 생긴다.
- 운영 연구: 정수 계획법에서 다루기 힘든 제약을 벌점으로 옮겨 하한을 구하는 라그랑주 완화가 같은 발상이고, 14편 「선형 계획법과 심플렉스: 부등식 제약 아래 최적화」의 쌍대성과 이어진다.

## 정리
- 개수 제약을 벌점 λ로 바꾸면 DP에서 k 차원이 사라지고, cnt(λ)가 k가 되도록 λ를 이분 탐색한 뒤 f(k) = g(λ) − λk로 답한다.
- f가 k에 대해 볼록이어야 모든 k가 어떤 λ에서 최적이 된다. 볼록성은 작은 입력에서 차분으로 확인한다.
- 동점은 개수를 일관되게 최소로 고르고 "cnt ≤ k인 가장 작은 λ"를 찾으면, cnt가 k와 달라도 답이 맞다.
- 볼록 껍질 트릭과 합치면 O(n log C)로, n = 2000, k = 100에서 전이가 2억 번에서 8.2만 번이 됐다.
