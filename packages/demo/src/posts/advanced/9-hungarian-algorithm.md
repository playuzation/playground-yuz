# [심화 알고리즘 9/14] 헝가리안 알고리즘: 할당 문제를 O(n³)에

> **한 줄 요약** — 행과 열에 쌍대 변수(퍼텐셜) u, v를 두고 uᵢ + vⱼ ≤ cᵢⱼ를 지키면서 등호가 성립하는 간선만으로 증가 경로를 찾고, 막히면 퍼텐셜을 최소 여유만큼 옮겨 새 등호 간선을 만드는 일을 행마다 반복하면 할당 문제가 O(n³)에 풀리고, 남은 (u, v)가 최적임을 보이는 증명서가 된다.

## 이 글에서 다루는 것
- 할당 문제와 단순한 방법들(순열 전수, 비트마스크 DP, 최소 비용 유량)
- 쌍대 변수 uᵢ + vⱼ ≤ cᵢⱼ와 "등호 간선만 쓰면 최적"인 이유
- 행을 하나씩 추가하는 O(n³) 구현과 퍼텐셜 조정
- 순열 전수·최소 비용 최대 유량과의 대조, 조정 횟수 실험
- 최대화·직사각형·금지 배정 변형

## 예제 문제: 네 사람, 네 가지 일
사람 W0~W3이 일 J0~J3을 하나씩 맡는다. 비용이 다음과 같을 때 총비용의 최솟값은?
```text
      J0  J1  J2  J3
W0     9   2   7   8
W1     6   4   3   7
W2     5   8   1   8
W3     7   6   9   4
```
사람 순서대로 남은 일 중 가장 싼 것을 고르면 2 + 3 + 5 + 4 = 14다. W1이 J2(3)를 가져가는 바람에 W2가 J2(1) 대신 J0(5)을 맡았기 때문이다. 정답은 W1이 J0을 맡는 2 + 6 + 1 + 4 = 13이다.

모든 순열을 보면 n!가지이고, 동적 계획법 6편 「비트마스크 DP: 외판원 순회 문제」의 `dp[mask]`는 O(2ⁿ·n)이라 n ≤ 20 정도까지다. 그래프 알고리즘 13편 「최소 비용 최대 유량: 유량에 가격 붙이기」처럼 유량으로 바꾸면 다항 시간이지만, 벨만-포드 계열로 증가 경로를 n번 찾으면 한 번에 O(VE) = O(n³), 전체 O(n⁴)다.

**헝가리안 알고리즘**(Hungarian algorithm)은 쿤(Harold Kuhn)이 1955년 발표하며 쾨니그와 에게르바리의 연구에 기댔다고 붙인 이름이고, 먼크레스(James Munkres)가 1957년 다항 시간임을 보였다. 처음 형태는 O(n⁴)였고, 에드몬즈·카프와 도미자와가 독립적으로 O(n³)으로 줄였다. 2000년대에 야코비(Jacobi)의 사후 원고(1890년 라틴어 출판)에 본질적으로 같은 방법이 있었음이 알려지기도 했다.

## 쌍대 변수: 비용을 행과 열에 나눠 싣기
행 i에 uᵢ, 열 j에 vⱼ라는 수를 두고 모든 칸에서 `uᵢ + vⱼ ≤ cᵢⱼ`를 지킨다. 차이 `cᵢⱼ − uᵢ − vⱼ ≥ 0`을 그 칸의 **여유**(reduced cost)라 하자.
- 아무 완전 배정 σ에 대해 `Σ cᵢσ(i) ≥ Σ (uᵢ + vσ(i)) = Σu + Σv`다. 각 행과 각 열이 한 번씩 더해지기 때문이다. 즉 Σu + Σv는 모든 배정 비용의 하한이다.
- 여유가 0인 칸(**등호 간선**, tight edge)만으로 완전 배정을 만들면 위 부등식이 등호가 되어, 그 배정은 최적이고 (u, v)가 그 증명서다.

그래서 목표는 "여유가 음수가 되지 않게 u, v를 움직이며 등호 간선만으로 완전 배정 만들기"다. 이것은 할당 문제를 선형 계획으로 쓴 것의 쌍대 문제이고, 14편 「선형 계획법과 심플렉스: 부등식 제약 아래 최적화」에서 쌍대성으로 다시 만난다.

## 행을 하나씩 추가하는 O(n³) 구현
행 1~(i − 1)이 등호 간선으로 배정되어 있을 때 행 i를 넣는다. 행 i에서 출발해 "행 → 등호 간선 → 열 → 배정 → 행"으로 교대 트리를 키운다. 다익스트라처럼 트리 밖 각 열까지의 최소 여유 `minv[j]`를 유지하고, 가장 작은 값 δ를 가진 열을 끌어들이며 퍼텐셜을 이렇게 옮긴다.

| 칸 | 트리 안 열 | 트리 밖 열 |
|---|---|---|
| 트리 안 행 | 그대로 | 여유 −δ |
| 트리 밖 행 | 여유 +δ | 그대로 |

트리 안 행은 u += δ, 트리 안 열은 v −= δ다. 트리 안의 배정 간선과 등호 간선은 여유가 그대로이고, 트리에서 밖으로 나가는 칸은 여유가 δ씩 줄어 최솟값이던 칸이 새 등호 간선이 된다. δ가 최솟값이므로 음수가 되는 칸은 없다. 끌어들인 열이 비어 있으면 증가 경로를 찾은 것이고, `way`를 따라 배정을 뒤집는다. 한 행에서 열을 최대 m개 끌어들이고 그때마다 O(m)이라, 행 n개에 O(n²m)이다.
```python
INF = float("inf")
stat = [0]                                # 퍼텐셜 조정 횟수(실험용)

def hungarian(c):                         # 행 n ≤ 열 m, 최소 비용 배정
    n, m = len(c), len(c[0])
    u, v = [0] * (n + 1), [0] * (m + 1)   # 쌍대 변수(퍼텐셜), 1부터
    p, way = [0] * (m + 1), [0] * (m + 1) # p[j] = 열 j를 맡은 행(0 = 없음)
    for i in range(1, n + 1):             # 행을 하나씩 추가한다
        p[0], j0 = i, 0
        minv, used = [INF] * (m + 1), [False] * (m + 1)
        while True:
            used[j0] = True
            i0, delta, j1 = p[j0], INF, 0
            for j in range(1, m + 1):
                if not used[j]:
                    cur = c[i0 - 1][j - 1] - u[i0] - v[j]   # 여유
                    if cur < minv[j]:
                        minv[j], way[j] = cur, j0
                    if minv[j] < delta:
                        delta, j1 = minv[j], j
            for j in range(m + 1):        # 등호 간선이 하나 더 생기게 조정
                if used[j]:
                    u[p[j]] += delta; v[j] -= delta
                else:
                    minv[j] -= delta
            stat[0] += 1
            j0 = j1
            if p[j0] == 0:                # 빈 열에 닿았다 = 증가 경로
                break
        while j0:                         # 경로를 따라 배정을 뒤집는다
            j1 = way[j0]; p[j0] = p[j1]; j0 = j1
    a = [0] * n
    for j in range(1, m + 1):
        if p[j]:
            a[p[j] - 1] = j - 1
    return sum(c[i][a[i]] for i in range(n)), a, u[1:], v[1:]

c = [[9, 2, 7, 8],
     [6, 4, 3, 7],
     [5, 8, 1, 8],
     [7, 6, 9, 4]]
cost, a, u, v = hungarian(c)
print("비용", cost, "배정", a)
print("u", u, "v", v, "Σu+Σv", sum(u) + sum(v))
ok = all(u[i] + v[j] <= c[i][j] for i in range(4) for j in range(4))
print("모든 칸에서 uᵢ+vⱼ ≤ cᵢⱼ:", ok)
print("배정 칸의 여유:", [c[i][a[i]] - u[i] - v[a[i]] for i in range(4)])
```
```text
비용 13 배정 [1, 0, 2, 3]
u [4, 6, 4, 4] v [0, -2, -3, 0] Σu+Σv 13
모든 칸에서 uᵢ+vⱼ ≤ cᵢⱼ: True
배정 칸의 여유: [0, 0, 0, 0]
```
W0–J1, W1–J0, W2–J2, W3–J3으로 13이다. Σu + Σv도 13이고 모든 칸이 부등식을 지키므로, 순열 24개를 보지 않아도 13보다 싼 배정이 없다는 것이 증명된다. 배정 칸의 여유는 모두 0, 곧 등호 간선만 썼다.

## 무작위 대조 검사
앞 코드에 이어서, 행 ≤ 열인 직사각형 비용(음수 포함) 500개를 모든 순열과 비교하고, 그래프 알고리즘 13편의 최소 비용 최대 유량(증가 경로는 벨만-포드)과도 비교한다. 매번 쌍대 조건과 `Σu + Σv = 비용`도 확인한다.
```python
import random
from itertools import permutations

def mcmf(c):                              # s → 행 → 열 → t, 용량 1
    n, m = len(c), len(c[0])
    N, s, t = n + m + 2, n + m, n + m + 1
    to, cap, w, g = [], [], [], [[] for _ in range(N)]
    def add(x, y, cost):                  # 정방향과 역간선(비용 −cost)
        for a, b, k, d in ((x, y, 1, cost), (y, x, 0, -cost)):
            g[a].append(len(to)); to.append(b); cap.append(k); w.append(d)
    for i in range(n):
        add(s, i, 0)
        for j in range(m):
            add(i, n + j, c[i][j])
    for j in range(m):
        add(n + j, t, 0)
    total = 0
    for _ in range(n):                    # 가장 싼 증가 경로를 n번
        d, pe = [INF] * N, [-1] * N
        d[s] = 0
        for _ in range(N):                # 벨만-포드
            for x in range(N):
                for e in g[x]:
                    if cap[e] and d[x] + w[e] < d[to[e]]:
                        d[to[e]], pe[to[e]] = d[x] + w[e], e
        x = t
        while x != s:
            e = pe[x]; cap[e] -= 1; cap[e ^ 1] += 1; x = to[e ^ 1]
        total += d[t]
    return total

rng = random.Random(9)
for _ in range(500):
    n = rng.randint(1, 6)
    m = rng.randint(n, 7)
    c = [[rng.randint(-5, 20) for _ in range(m)] for _ in range(n)]
    cost, a, u, v = hungarian(c)
    brute = min(sum(c[i][q[i]] for i in range(n))
                for q in permutations(range(m), n))
    assert cost == brute == mcmf(c) and len(set(a)) == n
    assert all(u[i] + v[j] <= c[i][j] for i in range(n) for j in range(m))
    assert sum(u) + sum(v) == cost
print("무작위 500개: 순열 전수·MCMF·쌍대 조건 모두 일치")
```
```text
무작위 500개: 순열 전수·MCMF·쌍대 조건 모두 일치
```
직사각형에서도 그대로 맞는다. 배정되지 않은 열은 트리에 들어간 적이 없어 v가 0으로 남고, 그래서 `Σu + Σv = 비용`이 성립한다.

## 퍼텐셜 조정 횟수 세기
조정 한 번은 O(m)이므로 조정 횟수 × (m + 1)이 연산량이다. 앞 코드에 이어서, 무작위 비용과 `cᵢⱼ = i·j` 비용에서 센다. 후자는 최적 배정이 반대 대각선이라 새 행을 넣을 때마다 앞 행들의 배정이 모두 한 칸씩 밀린다.
```python
rng = random.Random(1)
for n in [25, 50, 100, 200]:
    out = []
    for c in ([[rng.randint(0, 10**6) for _ in range(n)] for _ in range(n)],
              [[i * j for j in range(n)] for i in range(n)]):
        stat[0] = 0
        hungarian(c)
        out += [stat[0], round(stat[0] * (n + 1) / n**3, 2)]
    print(f"n={n:<3} 무작위 {out[0]:>4}번 ({out[1]}·n³)",
          f" i·j {out[2]:>5}번 ({out[3]}·n³)")
```
```text
n=25  무작위   94번 (0.16·n³)  i·j   325번 (0.54·n³)
n=50  무작위  194번 (0.08·n³)  i·j  1275번 (0.52·n³)
n=100 무작위  885번 (0.09·n³)  i·j  5050번 (0.51·n³)
n=200 무작위 1849번 (0.05·n³)  i·j 20100번 (0.51·n³)
```
`i·j`에서는 조정이 정확히 n(n + 1)/2번이라 연산량이 0.5·n³으로 세제곱 경계에 붙는다. 무작위 비용에서는 증가 경로가 금방 빈 열에 닿아 훨씬 적다. 최악은 O(n³)이고, 이 상한은 실제로 닿는다.

## 자주 하는 실수와 변형
- **최대화**: 비용을 −cᵢⱼ로 바꿔 최소화한다. 음수 비용도 그대로 동작한다.
- **직사각형**: 행이 열보다 많으면 전치해서 행 ≤ 열로 만든다. 일부만 배정해도 되는 문제는 비용 0인 가짜 열을 붙인다.
- **금지 배정**: `float("inf")`를 넣으면 `inf − inf`가 nan이 되어 깨진다. n × (최대 비용)보다 큰 유한한 수를 쓰고, 답이 그 이상이면 불가능으로 판정한다.
- 실수 비용은 δ 비교에서 오차가 쌓인다. 가능하면 정수로 스케일한다.
- 인덱스가 1부터이고 `p[0]`에 새 행을 넣어 두는 트릭이라, 0부터로 고치다 경계를 틀리기 쉽다.

## 복잡도
| 방법 | 시간 | 비고 |
|---|---|---|
| 순열 전수 | O(n!·n) | n ≤ 10 |
| 비트마스크 DP | O(2ⁿ·n) | n ≤ 20 |
| MCMF(벨만-포드) | O(n⁴) | 증가 n번 |
| 헝가리안 | O(n²m) | n = m이면 O(n³) |

헝가리안은 행 하나에 열 끌어들이기가 최대 m번, 한 번에 O(m)이다. 추가 공간은 O(n + m)이다.

## 어디에 쓰이나
- 그래프 알고리즘 13편 「최소 비용 최대 유량: 유량에 가격 붙이기」: 그 글의 포텐셜로 비용을 재조정하는 기법을 할당 문제에 맞게 다듬은 것이 이 글의 (u, v)이고, 행 하나 추가가 최단 증가 경로 한 번이다.
- 물체 검출: DETR(2020년)은 예측 상자와 정답 상자를 일대일로 짝짓는 손실에 헝가리안 매칭을 쓴다.
- 14편 「선형 계획법과 심플렉스: 부등식 제약 아래 최적화」: 할당 문제의 선형 계획 완화는 정수 최적해를 가지며, (u, v)는 그 쌍대 문제의 최적해다.

## 정리
- 할당 문제는 uᵢ + vⱼ ≤ cᵢⱼ인 퍼텐셜을 두면 Σu + Σv가 모든 배정의 하한이 되고, 등호 간선만으로 배정하면 최적이다.
- 행을 하나씩 넣으며 다익스트라식으로 교대 트리를 키우고, 막히면 최소 여유 δ만큼 퍼텐셜을 옮겨 새 등호 간선을 만든다.
- 행마다 O(nm), 전체 O(n³)이고, `cᵢⱼ = i·j`에서 조정 n(n + 1)/2번으로 상한에 닿았다.
- 순열 전수·MCMF와 500개 모두 일치했고, 매번 쌍대 해가 비용과 같아 최적성이 따로 증명되었다.
