# [정보 이론 3/4] KL 발산

> **한 줄 요약** — KL 발산 `D(p‖q)`는 실제 분포 p 대신 q를 믿었을 때 더 드는 비용(교차 엔트로피 − 엔트로피)으로, 항상 0 이상이고 두 분포가 같을 때만 0이지만 방향에 따라 값이 달라 거리는 아니다.

## 이 글에서 다루는 것
- KL 발산의 정의와 "낭비한 비트"라는 해석
- 항상 0 이상이고, 두 분포가 같을 때만 0
- 비대칭: 왜 거리가 아닌가
- `D(p‖q)`를 줄일 때와 `D(q‖p)`를 줄일 때의 차이
- 학습 목표로 쓰이는 KL: 최대 우도, RLHF, 지식 증류

## 정의: 잘못 믿은 대가
2편 「교차 엔트로피」에서 실제 분포 p의 데이터를 q에 맞춘 부호로 압축하면 평균 `H(p, q)` 비트가 들고, 이는 최적인 `H(p)`보다 작을 수 없다고 했다. 그 차이가 **KL 발산**(쿨백-라이블러 발산)이다.
```text
D(p‖q) = Σ p(x) log( p(x) / q(x) )
       = H(p, q) − H(p)
```

`KL(p‖q)`로 쓰기도 한다. 기호마다 "q를 믿어서 더 쓴 비트" `log(p/q)`를 실제 분포 p로 평균 낸 값이다. 2편의 표에서 균등 분포로 부호를 맞추면 0.25비트(2 − 1.75), 거꾸로 맞추면 0.875비트(2.625 − 1.75)를 낭비했다.

KL 발산은 항상 `D(p‖q) ≥ 0`이고, 등호는 p = q일 때만 성립한다. 이를 **깁스 부등식**이라고 한다. 어떤 분포를 믿든 진짜 분포를 믿을 때보다 압축이 나아질 수 없다는 뜻이며, 2편의 `H(p, q) ≥ H(p)`와 같은 말이다. 그래서 KL 발산은 두 분포가 얼마나 다른지 재는 척도로 쓰인다.

## 거리가 아니다: 비대칭
보통의 거리는 A에서 B까지와 B에서 A까지가 같다. KL 발산은 그렇지 않다.
```python
import math

def kl(p, q):
    total = 0.0
    for pi, qi in zip(p, q):
        if pi > 0:
            if qi == 0:
                return math.inf     # p에서는 일어나는데 q는 불가능하다고 한 경우
            total += pi * math.log2(pi / qi)
    return total

p, q = [0.5, 0.5], [0.9, 0.1]       # 공정한 동전, 앞면이 90%인 동전
print(round(kl(p, q), 3), round(kl(q, p), 3))   # 0.737 0.531
r = [1.0, 0.0]                      # 앞면만 나온다고 믿는 분포
print(kl(p, r), kl(r, p))                       # inf 1.0
```

공정한 동전 p와 앞면이 90%인 동전 q 사이에서 `D(p‖q)`는 0.737비트, `D(q‖p)`는 0.531비트다. 극단적인 경우는 더 분명하다. 앞면만 나온다고 믿는 r로 공정한 동전을 설명하면, r이 불가능하다고 한 뒷면이 절반이나 나오므로 `D(p‖r)`은 무한대다. 반대 방향 `D(r‖p)`는 1비트에 그친다. 삼각 부등식도 성립하지 않는다. 앞면 확률이 0.5, 0.7, 0.9인 동전을 a, b, c라 하면 `D(a‖c)` = 0.737이 `D(a‖b) + D(b‖c)` = 0.347보다 크다. 그래서 "거리" 대신 "발산"이라고 부른다.

## 어느 방향을 줄이느냐
모델 q를 실제 분포 p에 맞출 때, 어느 방향을 줄이느냐에 따라 결과의 성격이 달라진다.
- `D(p‖q)`를 줄이면: p가 확률을 주는 곳에서 q가 0에 가까우면 벌점이 폭발한다. 그래서 q는 p가 있는 곳을 빠짐없이 덮으려고 넓게 퍼진다(**평균 덮기**).
- `D(q‖p)`를 줄이면: q가 확률을 주는 곳에서 p가 0에 가까우면 벌점이 폭발한다. 그래서 q는 p가 확실히 큰 곳 하나에 몰린다(**모드 찾기**).

봉우리가 −3과 3에 있는 분포 p(표준편차 1인 정규 분포 두 개를 반씩 섞은 것)에 정규 분포 q 하나를 맞춰 보면 차이가 뚜렷하다. 아래는 수치 적분으로 계산한 값이다(내트).

| 후보 q (평균, 표준편차) | D(p‖q) | D(q‖p) |
|---|---|---|
| 가운데에 넓게 (0, 3.16) | 0.46 | 0.93 |
| 한 봉우리에 (3, 1) | 8.31 | 0.69 |

`D(p‖q)` 기준으로는 두 봉우리를 모두 덮는 넓은 분포가 낫고, `D(q‖p)` 기준으로는 한 봉우리에 붙은 좁은 분포가 낫다. 실제로 최적화해 보면 앞쪽의 최적은 평균 0, 표준편차 √10 ≈ 3.16이고, 뒤쪽의 최적은 평균 약 ±2.98, 표준편차 약 1.02다. 어느 쪽이 옳다기보다 목적이 다르다.

## 학습 목표로서의 KL
**최대 우도**: `D(p_data‖p_θ) = H(p_data, p_θ) − H(p_data)`에서 뒤 항은 모델과 무관하다. 따라서 이 KL을 줄이는 것은 교차 엔트로피를 줄이는 것, 곧 최대 우도 추정이다. 방향이 `D(p‖q)`이므로 모델은 데이터가 있는 곳 어디에도 확률 0을 주지 않으려 한다.

**RLHF의 KL 벌점**: 프롬프트 x에 대한 답 y의 보상 `r(x, y)`를 키우되, 학습 중인 모델 `π_θ`가 원래 모델 `π_ref`에서 너무 멀어지지 않게 KL을 뺀다.
```text
최대화할 값 = E[ r(x, y) ] − β · D( π_θ(·∣x) ‖ π_ref(·∣x) )
```

β가 벌점의 세기다. 벌점이 없으면 모델이 보상 모델의 허점만 파고들어 이상한 문장을 만들 수 있다. 원래 모델이 가진 언어 능력을 지키는 안전줄인 셈이다.

**지식 증류**: 큰 교사 모델의 출력 분포를 작은 학생 모델이 흉내 내도록 `D(교사‖학생)`을 줄인다. "고양이 0.7, 호랑이 0.25, 자동차 0.05" 같은 분포는 원-핫 정답보다 "고양이는 호랑이와 닮았다"는 정보를 더 담고 있다. 교사 분포는 고정이므로 이는 교사 분포를 정답으로 둔 교차 엔트로피를 줄이는 것과 같다. 힌턴 등의 2015년 논문 「Distilling the Knowledge in a Neural Network」는 소프트맥스 온도를 높여 분포를 부드럽게 만든 뒤 맞추는 방법을 제안했다.

## 어디에 쓰이나
- AI 기초 3편 「데이터 분포로 보는 AI 모델」: 그 글의 `KL(p_data ‖ p_θ)` 식에서 "모델과 상관없는 상수"라고 한 첫 항이 바로 `−H(p_data)`이며, 그래서 KL 최소화와 교차 엔트로피 최소화와 최대 우도가 하나로 묶인다.
- AI 기초 2편 「강화학습: 보상으로 배우는 머신러닝」: RLHF에서 원래 모델과의 KL 벌점은 그 글이 말한 보상 해킹, 즉 보상 모델의 허점을 노리는 행동을 억누르는 장치다.
- 정보 이론 4편 「상호 정보량」: 상호 정보량은 결합 분포와 "독립이라고 가정한 분포" 사이의 KL 발산으로 정의된다.

## 정리
- `D(p‖q) = Σ p log(p/q) = H(p, q) − H(p)`는 p 대신 q를 믿어서 낭비한 평균 비트다.
- 깁스 부등식에 따라 항상 0 이상이고 p = q일 때만 0이지만, 비대칭이고 삼각 부등식도 성립하지 않아 거리가 아니다.
- `D(p‖q)` 최소화는 넓게 덮는 쪽, `D(q‖p)` 최소화는 한 봉우리에 몰리는 쪽으로 기운다.
- 최대 우도, RLHF의 KL 벌점, 지식 증류가 모두 KL 발산을 학습 목표로 쓴다.
