# [정보 이론 2/4] 교차 엔트로피

> **한 줄 요약** — 교차 엔트로피 `H(p, q)`는 실제 분포가 p인 데이터를 분포 q에 맞춘 부호로 압축할 때의 평균 비트 수이며, 분류 모델과 언어 모델이 학습하며 줄이는 손실이 바로 이 값이다.

## 이 글에서 다루는 것
- 교차 엔트로피의 정의와 "잘못 맞춘 부호로 압축하기"라는 해석
- 교차 엔트로피는 엔트로피보다 작아질 수 없다
- 분류 손실: 정답이 원-핫이면 `−log q(정답)`
- 소프트맥스와 함께 쓰면 기울기가 `q − p`가 되는 이유
- 퍼플렉시티: 언어 모델의 성적표

## 잘못 맞춘 부호로 압축하기
1편 「정보량과 엔트로피」에서 확률 p인 기호에 `−log₂ p` 비트짜리 부호를 주면 평균 길이가 엔트로피 `H(p)`가 된다고 했다. 그런데 실제 분포 p를 모른 채 추측한 분포 q에 맞춰 부호를 만들었다면 어떨까? 기호 x의 부호 길이는 `−log₂ q(x)`가 되고, 기호는 실제로 p의 비율로 나오므로 평균 길이는 다음과 같다.
```text
H(p, q) = −Σ p(x) log q(x) = E_{x~p}[ −log q(x) ]
```

이것이 **교차 엔트로피**(cross entropy)다. 평균을 내는 분포는 실제 분포 p이고, 로그 안에 들어가는 것은 추측한 분포 q다. 두 자리를 바꾸면 값이 달라진다. 1편의 예처럼 A, B, C, D가 1/2, 1/4, 1/8, 1/8의 확률로 나온다고 하자.

| 부호를 맞춘 q | 부호 길이 A, B, C, D | H(p, q) |
|---|---|---|
| q = p | 1, 2, 3, 3 | 1.75비트 |
| 균등 분포 | 2, 2, 2, 2 | 2비트 |
| 거꾸로 추측 | 3, 3, 2, 1 | 2.625비트 |

q가 p와 다를수록 평균 길이가 늘어난다. 일반적으로 `H(p, q) ≥ H(p)`이고, 등호는 q = p일 때만 성립한다. 차이 `H(p, q) − H(p)`는 "분포를 잘못 알아서 낭비한 비트"이며, 3편 「KL 발산」의 주제다.

## 분류 손실로서의 교차 엔트로피
분류 모델은 입력마다 클래스별 확률 q를 출력한다. 정답이 클래스 k라면 정답 분포 p는 k에만 1이 있는 **원-핫 벡터**이고, 합에서 정답 항 하나만 남는다.
```text
H(p, q) = −log q(k)
```

정답 클래스에 준 확률의 음의 로그다. 모델이 [0.7, 0.2, 0.1]을 출력했을 때 정답이 0번이면 손실은 0.357, 정답이 2번이면 2.303이다(자연로그, 내트 단위). 틀린 답을 확신할수록 손실이 치솟고, 정답에 확률 0을 주면 무한대가 된다. 정답이 0 또는 1이고 모델이 1일 확률 q 하나만 출력하는 이진 분류에서는 같은 식이 **이진 교차 엔트로피**가 된다.
```text
L = −[ y log q + (1 − y) log(1 − q) ]
```

## 소프트맥스와 만나면 기울기가 q − p
신경망은 마지막 층의 점수(로짓) z를 소프트맥스로 확률로 바꾼다. 여기에 교차 엔트로피를 붙이면 놀랄 만큼 간단한 기울기가 나온다.
```text
qᵢ = e^{zᵢ} / Σⱼ e^{zⱼ}   →   log qᵢ = zᵢ − log Σⱼ e^{zⱼ}
L = −Σᵢ pᵢ log qᵢ = −Σᵢ pᵢ zᵢ + log Σⱼ e^{zⱼ}      (Σ pᵢ = 1이므로)
∂L/∂zₖ = −pₖ + e^{zₖ} / Σⱼ e^{zⱼ} = qₖ − pₖ
```

"예측 분포 − 정답 분포"가 그대로 기울기다. 정답 클래스의 로짓은 올리고, 나머지는 받은 확률만큼 내리라는 뜻이다. 유도에 쓴 미분 규칙은 미적분 3편 「미분 규칙과 연쇄 법칙」에서 다룬다. 수치 미분으로 확인해 보자.
```python
import numpy as np

def softmax(z):
    e = np.exp(z - z.max())
    return e / e.sum()

def loss(z, y):                     # y: 정답 원-핫 벡터
    return -np.sum(y * np.log(softmax(z)))

z = np.array([2.0, 1.0, 0.1])       # 로짓
y = np.array([0.0, 1.0, 0.0])       # 정답은 1번 클래스
h = 1e-5                            # 중앙 차분: (L(z+h) − L(z−h)) / 2h
numeric = np.array([(loss(z + h * e, y) - loss(z - h * e, y)) / (2 * h) for e in np.eye(3)])
print(softmax(z).round(4))          # [0.659  0.2424 0.0986]   q
print(numeric.round(4))             # [ 0.659  -0.7576  0.0986]  수치 미분
print((softmax(z) - y).round(4))    # [ 0.659  -0.7576  0.0986]  q − p
```

두 결과가 일치한다. PyTorch의 `CrossEntropyLoss`가 확률이 아니라 로짓을 받아 소프트맥스와 교차 엔트로피를 한 번에 계산하는 것도 이 깔끔한 기울기와 수치 안정성 때문이다.

## 퍼플렉시티: 언어 모델의 성적표
언어 모델은 위치마다 다음 토큰의 분포를 내놓으므로, 실제 문장의 각 토큰에 준 확률로 교차 엔트로피를 잴 수 있다. 이를 지수로 되돌린 값이 **퍼플렉시티**(perplexity)다.
```text
퍼플렉시티 = exp( −(1/N) Σₜ log q(xₜ ∣ x₁, …, xₜ₋₁) )
```
```python
import math

probs = [0.5, 0.25, 0.1, 0.8]       # 모델이 각 위치의 실제 다음 토큰에 준 확률
ce = sum(-math.log(q) for q in probs) / len(probs)
print(round(ce, 3), round(math.exp(ce), 3))   # 1.151 3.162
```

3.162는 확률의 역수 2, 4, 10, 1.25의 기하평균이다. 퍼플렉시티는 "모델이 매번 평균 몇 개의 후보 사이에서 고민하는 셈인가"로 읽는다. 어휘 5만 개에 똑같은 확률을 주는 모델은 50,000이고, 다음 토큰을 언제나 확신하며 맞히는 모델은 1이다. 낮을수록 좋다.

## 어디에 쓰이나
- AI 기초 3편 「데이터 분포로 보는 AI 모델」: 교차 엔트로피 손실 `−E[ log p_θ(y∣x) ]`는 데이터 분포 `p_data`를 실제 분포 p로, 모델 `p_θ`를 부호를 맞춘 분포 q로 둔 교차 엔트로피를 학습 데이터 평균으로 계산한 것이다.
- AI 기초 1편 「딥러닝: 특징까지 스스로 배우는 머신러닝」: XOR 예제의 `dz2 = (p - y)`는 시그모이드와 이진 교차 엔트로피를 합친 기울기로, 클래스가 두 개일 때의 `q − p`다(그 코드의 p가 이 글의 q, y가 이 글의 p이고, `/ len(X)`는 네 데이터의 평균을 내는 부분).
- 통계학 4편 「최대 우도 추정」: 학습 데이터에서 평균 교차 엔트로피를 최소화하는 것은 로그 우도를 최대화하는 것과 같은 일이다.
- 통계학 9편 「로지스틱 회귀: 확률을 예측하는 회귀」: 로지스틱 회귀의 손실이 이진 교차 엔트로피이며, 가중치에 대한 기울기도 같은 원리로 (예측 − 정답) × 입력이 된다.

## 정리
- 교차 엔트로피 `H(p, q) = −Σ p log q`는 q에 맞춘 부호로 p를 압축할 때의 평균 길이이고, 항상 `H(p)` 이상이다.
- 정답이 원-핫이면 교차 엔트로피는 `−log q(정답)`이 되어 분류 손실로 쓰인다.
- 소프트맥스와 교차 엔트로피를 합치면 로짓에 대한 기울기가 `q − p`로 단순해진다.
- 퍼플렉시티는 `exp(교차 엔트로피)`로, 언어 모델이 평균 몇 개의 후보 사이에서 헷갈리는지를 나타낸다.
