# [정보 이론 4/4] 상호 정보량

> **한 줄 요약** — 상호 정보량 `I(X; Y)`는 Y를 알게 되었을 때 X의 불확실성(엔트로피)이 평균적으로 얼마나 줄어드는지를 잰 값으로, 독립일 때만 0이며 상관계수가 놓치는 비선형 관계까지 잡아낸다.

- 2×2 결합 분포 표로 직접 계산하기
- 상관계수가 0이어도 상호 정보량은 0이 아닐 수 있다
- 결정 트리의 정보 이득과 특징 선택

## 조건부 엔트로피: 알고 난 뒤 남은 불확실성
1편 「정보량과 엔트로피」에서 엔트로피 `H(X)`를 "결과를 보기 전의 불확실성"이라고 했다. 그렇다면 관련 있는 다른 변수 Y를 먼저 보고 나면 X의 불확실성은 얼마나 남을까? `Y = y`를 관측한 뒤 X의 분포는 조건부 분포 `p(x∣y)`이고, 그 엔트로피를 y의 확률로 평균한 것이 **조건부 엔트로피**다.
```text
H(X∣Y) = Σ_y p(y) · H(X ∣ Y = y) = −Σ p(x, y) log p(x∣y)
```

평균적으로 정보를 더 알아서 불확실성이 늘어나는 일은 없으므로 `H(X∣Y) ≤ H(X)`다. Y가 X를 완전히 정하면 `H(X∣Y) = 0`, 둘이 독립이면 `H(X∣Y) = H(X)`다. 결합 분포와 조건부 분포 자체는 확률과 분포 9편 「결합 분포, 주변 분포, 조건부 분포」에서 다룬다.

## 상호 정보량
Y를 앎으로써 줄어든 X의 불확실성이 **상호 정보량**(mutual information)이다.
```text
I(X; Y) = H(X) − H(X∣Y)
        = H(Y) − H(Y∣X)
        = H(X) + H(Y) − H(X, Y)
        = D( p(x, y) ‖ p(x)·p(y) )
```

둘째 줄에서 보듯 X와 Y를 바꿔도 값이 같다. "Y가 X에 대해 알려 주는 정보"와 "X가 Y에 대해 알려 주는 정보"는 같은 양이다. 마지막 줄은 3편 「KL 발산」의 언어로, 실제 결합 분포가 독립이라고 가정한 분포 `p(x)·p(y)`와 얼마나 다른지를 잰다는 뜻이다. KL 발산은 0 이상이고 두 분포가 같을 때만 0이므로, 상호 정보량은 항상 0 이상이고 **X와 Y가 독립일 때만 0**이다.

## 2×2 표로 계산해 보기
100일 동안 날씨와 우산을 챙겼는지를 기록했다고 하자. 칸의 숫자를 100으로 나누면 결합 분포다.

| 날씨 | 우산 챙김 | 안 챙김 | 합 |
|---|---|---|---|
| 비 | 25 | 5 | 30 |
| 맑음 | 10 | 60 | 70 |
| 합 | 35 | 65 | 100 |

- 날씨만 보면 비 30%, 맑음 70%이므로 `H(날씨)` = 0.881비트다.
- 우산을 챙긴 35일 중 비는 25일(약 71%), 안 챙긴 65일 중 비는 5일(약 8%)이다. 각각의 엔트로피는 0.863, 0.391비트이고, 35 : 65로 평균하면 `H(날씨∣우산)` = 0.556비트다.
- 따라서 `I(날씨; 우산)` = 0.881 − 0.556 = 0.325비트다. 우산을 보면 날씨에 대한 불확실성이 약 37% 줄어든다.

같은 계산을 코드로 일반화하면 다음과 같다.
```python
import math

def H(probs):
    return sum(p * math.log2(1 / p) for p in probs if p > 0)

def mutual_info(joint):             # joint[i][j] = P(X = i, Y = j)
    px = [sum(row) for row in joint]
    py = [sum(col) for col in zip(*joint)]
    h_x_given_y = sum(py[j] * H([joint[i][j] / py[j] for i in range(len(px))])
                      for j in range(len(py)) if py[j] > 0)
    return H(px), h_x_given_y, H(px) - h_x_given_y

# 행: 비, 맑음 / 열: 우산 챙김, 안 챙김
weather = [[0.25, 0.05],
           [0.10, 0.60]]
print([round(v, 3) for v in mutual_info(weather)])   # [0.881, 0.556, 0.325]

# 행: X = −1, 0, 1 / 열: Y = X² = 0, 1
square = [[0, 1/3],
          [1/3, 0],
          [0, 1/3]]
print([round(v, 3) for v in mutual_info(square)])    # [1.585, 0.667, 0.918]
```

출력은 차례로 `H(X)`, `H(X∣Y)`, `I(X; Y)`다. 둘째 줄은 다음 절의 예다.

## 상관계수가 놓치는 관계
확률과 분포 5편 「분산, 공분산, 상관계수」에서 보았듯, Y = X²처럼 Y가 X로 완전히 정해지는데도 상관계수가 0일 수 있다. X가 −1, 0, 1을 같은 확률로 가지면 `Cov(X, Y) = E[X³] − E[X]·E[X²] = 0 − 0·(2/3) = 0`이다. 상관계수는 **직선 관계**의 세기만 재기 때문이다.

상호 정보량은 관계의 모양을 가리지 않는다. 위 코드의 둘째 결과처럼 `I(X; Y)` = 0.918비트로 0보다 크다. Y를 보면 X가 0인지(Y = 0), ±1 중 하나인지(Y = 1)를 알게 되어 불확실성이 1.585비트에서 0.667비트로 줄어든다. 반대로 X를 알면 Y가 완전히 정해지므로 `H(Y∣X) = 0`이고, `I(X; Y) = H(Y)` = 0.918비트다. 상관계수 0은 "직선 관계가 없다"는 뜻일 뿐이고, 독립인지는 상호 정보량이 0인지로 판단해야 한다.

## 결정 트리의 정보 이득과 특징 선택
**결정 트리**는 "우산을 챙겼는가?" 같은 질문으로 데이터를 반복해서 나누는 분류 모델이다. 어떤 질문으로 나눌지 고를 때 흔히 쓰는 기준이 **정보 이득**(information gain)이다.
```text
정보 이득 = H(라벨) − H(라벨 ∣ 질문의 답) = I(라벨; 특징)
```

나누기 전 라벨의 엔트로피에서, 나눈 뒤 각 가지의 엔트로피를 데이터 비율로 평균한 값을 뺀 것으로, 라벨과 특징의 상호 정보량을 데이터로 계산한 값과 정확히 같다. 위 표에서 날씨를 맞히려고 "우산을 챙겼는가?"로 나누면 정보 이득은 0.325비트이고, 날씨와 무관한 질문(예: "오늘이 홀수 날인가?")은 0에 가깝다. 트리는 단계마다 정보 이득이 가장 큰 질문을 고른다.

같은 아이디어가 **특징 선택**에도 쓰인다. 특징이 수백 개일 때 각 특징과 라벨의 상호 정보량을 계산해 큰 것부터 남기면, 상관계수로는 놓칠 비선형 관계까지 고려할 수 있다. scikit-learn의 `mutual_info_classif`가 이런 용도의 함수다.

## 어디에 쓰이나
- 확률과 분포 9편 「결합 분포, 주변 분포, 조건부 분포」: 상호 정보량은 결합 분포가 주변 분포의 곱에서 얼마나 벗어나는지를 숫자 하나로 요약하므로, 독립의 정의 `p(x, y) = p(x)·p(y)`를 정량화한 것이다.
- 확률과 분포 5편 「분산, 공분산, 상관계수」: 상관계수 0이 독립을 뜻하지 않는다는 사실을, 상관계수는 0이지만 상호 정보량은 양수인 예로 숫자로 확인할 수 있다.
- AI 기초 3편 「데이터 분포로 보는 AI 모델」: 판별 모델 `p_θ(y∣x)`가 데이터 분포 `p_data`에서 받는 교차 엔트로피 손실은 아무리 잘 학습해도 `H(Y∣X)` 밑으로 내려갈 수 없고, 입력을 무시하고 정답 비율만 맞히는 모델의 손실 `H(Y)`와의 차이인 `I(X; Y)`가 입력을 봐서 줄일 수 있는 손실의 최대치다.

## 정리
- 조건부 엔트로피 `H(X∣Y)`는 Y를 안 뒤 X에 남은 평균 불확실성이다.
- 상호 정보량 `I(X; Y) = H(X) − H(X∣Y)`는 대칭이고, 결합 분포와 주변 분포 곱 사이의 KL 발산과 같다.
- 독립일 때만 0이며, 상관계수와 달리 비선형 관계도 잡아낸다.
- 결정 트리의 정보 이득과 특징 선택은 상호 정보량을 데이터로 계산해 쓰는 대표적인 예다.
