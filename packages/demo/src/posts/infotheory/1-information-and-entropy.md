# [정보 이론 1/4] 정보량과 엔트로피

> **한 줄 요약** — 정보량은 어떤 일이 일어났을 때 "얼마나 놀라운가"를 `−log p`로 잰 값이고, 엔트로피는 그 평균으로, 데이터를 아무리 잘 압축해도 넘을 수 없는 평균 비트 수의 하한이다.

## 이 글에서 다루는 것
- 놀람의 크기로 정의하는 정보량 `−log p`
- 로그의 밑과 단위: 비트와 내트
- 엔트로피: 평균 정보량, 언제 최대이고 언제 0인가
- 원천 부호화 정리와 허프만 부호로 보는 압축의 한계

## 정보량: 드문 일일수록 정보가 많다
"내일 아침에도 해가 뜬다"는 소식은 아무것도 알려 주지 않는다. 반면 "복권 1등에 당첨됐다"는 소식은 많은 것을 바꾼다. 정보 이론은 이 직관을 숫자로 만든다. 확률이 p인 사건이 일어났을 때 얻는 **정보량**(자기 정보, self-information)은 다음과 같다.
```text
I(x) = −log p(x) = log( 1 / p(x) )
```

이 정의는 세 가지 바람을 만족한다.
- 반드시 일어나는 일(p = 1)의 정보량은 0이다.
- 확률이 작을수록 정보량이 크다.
- 독립인 두 사건이 함께 일어나면 확률은 곱해지고 정보량은 더해진다: `−log(p·q) = −log p − log q`.

세 번째 성질이 로그를 쓰는 이유이며, 연속성까지 요구하면 이런 함수는 상수배를 빼면 로그뿐이다. 로그 함수 자체의 성질은 미적분 4편 「지수 함수와 로그 함수」에서 다룬다.

## 비트와 내트
로그의 밑이 단위를 정한다. 밑이 2이면 **비트**(bit), 자연로그 ln이면 **내트**(nat)이고, 1내트는 약 1.443비트다. 1비트는 확률이 반반인 예/아니오 질문 하나의 답에 담긴 정보다.

| 사건 | 확률 | 정보량 |
|---|---|---|
| 공정한 동전이 앞면 | 1/2 | 1비트 |
| 주사위가 6 | 1/6 | log₂6 ≈ 2.585비트 |
| 카드 52장 중 특정 한 장 | 1/52 | ≈ 5.700비트 |
| 32바이트 난수 토큰 맞히기 | 2⁻²⁵⁶ | 256비트 |

머신러닝의 손실 함수는 주로 내트를 쓰지만, 둘은 비례하므로 어느 쪽을 써도 결론은 같다.

## 엔트로피: 평균 정보량
확률 변수 X가 여러 값을 가질 때, 각 결과의 정보량을 확률로 가중 평균한 것이 **엔트로피**다.
```text
H(X) = −Σ p(x) log p(x) = E[ −log p(X) ]
```

엔트로피는 "결과를 보기 전의 불확실성"이자 "결과 하나를 알려 줄 때 평균적으로 필요한 정보량"이다. 기댓값 자체는 확률과 분포 4편 「확률 변수와 기댓값」을 참고하자.
```python
import math

def entropy(p, base=2):
    return sum(x * math.log(1 / x, base) for x in p if x > 0)   # 0·log 0 = 0으로 약속

print(round(entropy([0.5, 0.5]), 3))           # 1.0    공정한 동전
print(round(entropy([0.9, 0.1]), 3))           # 0.469  앞면이 90% 나오는 동전
print(round(entropy([1.0, 0.0]), 3))           # 0.0    결과가 정해진 동전
print(round(entropy([1/6] * 6), 3))            # 2.585  공정한 주사위
print(round(entropy([0.5, 0.5], math.e), 3))   # 0.693  공정한 동전, 내트 단위
```

결과에서 두 성질이 보인다.
- 결과가 하나로 정해져 있으면 놀랄 일이 없으므로 H = 0이다. 엔트로피는 음수가 되지 않는다.
- 값이 n가지일 때 엔트로피는 모두 같은 확률(균등 분포)일 때 최대 `log₂ n`이다. 한쪽으로 치우칠수록 결과를 짐작하기 쉬워져 엔트로피가 줄어든다.

## 원천 부호화 정리: 엔트로피는 압축의 한계
섀넌은 1948년 논문 「A Mathematical Theory of Communication」에서 엔트로피가 압축의 한계임을 보였다. 기호를 0과 1로 된 부호로 바꿔 저장할 때, 원래대로 복원할 수 있는 부호라면 기호당 평균 길이는 엔트로피 H보다 짧을 수 없다. 대신 여러 기호를 묶어 부호화하면 평균 길이를 H에 얼마든지 가깝게 만들 수 있다. 이것이 **원천 부호화 정리**의 핵심이다.

직관은 이렇다. 자주 나오는 기호에는 짧은 부호를, 드문 기호에는 긴 부호를 주면 평균 길이가 줄어든다. 이상적인 부호 길이가 바로 그 기호의 정보량 `−log₂ p` 비트이고, 그 평균이 엔트로피다. 1952년 허프만이 제안한 **허프만 부호**는 확률이 가장 작은 두 묶음을 반복해서 합치는 방법으로, 기호를 하나씩 부호화할 때 가능한 가장 짧은 평균 길이를 만든다.
```python
import heapq, math

def huffman(probs):
    # (확률, 순번, {기호: 부호}) 묶음을 확률이 작은 것부터 두 개씩 합친다
    heap = [(p, i, {s: ''}) for i, (s, p) in enumerate(probs.items())]
    heapq.heapify(heap)
    n = len(heap)
    while len(heap) > 1:
        p1, _, c1 = heapq.heappop(heap)
        p2, _, c2 = heapq.heappop(heap)
        merged = {s: '0' + c for s, c in c1.items()} | {s: '1' + c for s, c in c2.items()}
        heapq.heappush(heap, (p1 + p2, n, merged))
        n += 1
    return heap[0][2]

probs = {'A': 0.4, 'B': 0.3, 'C': 0.2, 'D': 0.1}
code = huffman(probs)
L = sum(p * len(code[s]) for s, p in probs.items())
H = -sum(p * math.log2(p) for p in probs.values())
print(dict(sorted(code.items())))
print(f'평균 부호 길이 {L:.3f}비트, 엔트로피 {H:.3f}비트')
```
```text
{'A': '0', 'B': '10', 'C': '111', 'D': '110'}
평균 부호 길이 1.900비트, 엔트로피 1.846비트
```

네 기호를 고정 길이로 쓰면 기호당 2비트다. 허프만 부호는 이를 1.9비트로 줄이지만 엔트로피 1.846비트보다 짧아질 수는 없다. 두 기호씩 묶은 16가지 쌍에 같은 방법을 쓰면 기호당 1.865비트로 엔트로피에 더 다가간다. 확률이 1/2, 1/4, 1/8, 1/8처럼 모두 2의 거듭제곱 꼴이면 부호 길이가 정확히 `−log₂ p`가 되어 평균 길이와 엔트로피가 1.75비트로 같아진다.

엔트로피는 문자열 하나가 아니라 그것을 **만드는 과정**의 성질이다. 무작위로 보이는 비밀번호도 사람들이 흔히 고르는 패턴에서 나왔다면 공격자에게는 엔트로피가 작다. 반대로 진짜 균등 난수는 엔트로피가 이미 최대여서 평균적으로 어떤 압축기로도 줄어들지 않는다.

## 어디에 쓰이나
- 이 플랫폼의 로그인 토큰: 32바이트 균등 난수를 16진수 64글자로 쓴 것이므로 엔트로피는 256비트(글자당 4비트)이고, 무작위 추측으로 맞히려면 평균 약 2²⁵⁵번을 시도해야 한다.
- 이산수학 7편 「비둘기집 원리와 포함·배제의 원리」: 비둘기집 원리가 "모든 파일을 줄이는 무손실 압축은 불가능하다"를 보인다면, 엔트로피는 "평균적으로 어디까지 줄일 수 있는가"에 숫자로 답한다.
- AI 기초 3편 「데이터 분포로 보는 AI 모델」: 온도를 높이면 다음 토큰 분포가 평평해져 엔트로피가 커진다. 로짓 [2, 1, 0]에 소프트맥스를 씌우면 온도 0.5, 1, 2에서 엔트로피가 0.636, 1.201, 1.472비트로 최대값 log₂3 ≈ 1.585에 다가간다.

## 정리
- 확률 p인 사건의 정보량은 `−log p`이고, 독립 사건의 정보량은 더해진다. 밑이 2이면 비트, e이면 내트다.
- 엔트로피 `H = −Σ p log p`는 평균 정보량이며, 결과가 정해져 있으면 0, 균등 분포일 때 최대 `log₂ n`이다.
- 원천 부호화 정리에 따르면 엔트로피는 무손실 압축의 평균 길이 하한이고, 허프만 부호 같은 방법으로 그 하한에 다가갈 수 있다.
