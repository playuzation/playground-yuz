# [양자화 8/13] 왜 드문 지식이 먼저 사라지나: 데이터 분포와 롱테일

> **한 줄 요약** — 학습은 자주 본 사실에 큰 로짓 마진을, 드물게 본 사실에 작은 마진을 주고(마진 ≈ ln 빈도 + 상수) 양자화 잡음은 모든 사실에 같은 크기로 더해지므로, 뒤집힘 확률 Φ(−m/σ)는 마진이 경계 근처인 롱테일 지식에 몰리고, 빈도로 가중한 평균 지표는 이 붕괴를 거의 보여 주지 않는다.

## 이 글에서 다루는 것
- 학습 데이터의 지프 분포와 롱테일 지식(Kandpal 등)
- 빈도가 마진을 정하는 이유: 마진 ≈ ln 빈도 + 상수
- 뒤집힘 확률 Φ(−m/σ)와 "경계에 있는 것이 무너진다"
- 지프 빈도로 학습한 메모리의 양자화 실험(가상 데이터)
- 평가 함정, 그리고 지식의 차이가 벌어질 수밖에 없는 이유

## 지프 분포와 롱테일 지식
단어의 빈도는 순위 r에 대해 대략 `f(r) ∝ r^(−s)`, s ≈ 1인 **지프 분포**(Zipf distribution)를 따른다. 사실(어떤 인물의 출생지, 어떤 화합물의 녹는점)이 데이터에 나오는 횟수도 이렇게 꼬리가 길다고 보는 것이 이 글의 출발점이다. 소수의 유명한 사실이 언급의 대부분을 차지하고, 대부분의 사실은 몇 번 나오지 않는 긴 꼬리(long tail)에 있다.

Kandpal 등의 「Large Language Models Struggle to Learn Long-Tail Knowledge」(ICML 2023)는 질문-답 쌍의 엔터티가 함께 나오는 사전 학습 문서 수를 엔터티 연결로 세어, 관련 문서가 많은 질문일수록 정답률이 높다는 강한 상관을 여러 모델과 데이터셋(TriviaQA, Natural Questions, 176B BLOOM 계열 등)에서 보였다. 관련 문서를 지우고 다시 학습한 모델에서 해당 질문의 정답률이 떨어져 인과 관계도 뒷받침했다. 모델이 클수록 롱테일을 더 잘 배우지만, 관련 문서가 적은 질문에서 경쟁력 있는 정확도에 이르려면 모델을 여러 자릿수 키워야 한다고 추정했고, 검색 증강이 이 의존을 줄인다고 제안했다. 양자화 전부터 롱테일 지식은 약하게 저장되어 있다는 뜻이다.

## 빈도가 마진을 정한다
사실 i의 **마진**(margin)을 정답 로짓과 가장 큰 오답 로짓의 차이 `mᵢ = z_정답 − max z_오답`로 두자. 빈도 wᵢ로 가중한 교차 엔트로피 `Σ wᵢ·CEᵢ`를 줄이는 학습에서, 마진 mᵢ를 늘릴 때 손실이 줄어드는 속도는 `wᵢ·(1 − pᵢ)`다. 용량이 한정된 모델에서 마진 한 단위를 사는 비용이 사실마다 비슷하다고 보면, 최적점에서는 이 값이 모든 사실에서 같아진다. 마진이 클 때 `1 − pᵢ ≈ c·e^(−mᵢ)`(c는 경쟁 값의 수에 따른 상수)이므로 다음이 된다.
```text
wᵢ · c·e^(−mᵢ) ≈ λ (공통)   ⇒   mᵢ ≈ ln wᵢ + ln(c/λ)
```

마진은 빈도의 로그를 따라 커진다. 지프 분포에서 빈도는 여러 자릿수에 걸쳐 있으니 마진도 넓게 퍼지고, 꼬리의 사실일수록 마진이 0에 가깝다. 아래 실험에서 이 근사를 확인한다.

## 뒤집힘 확률 Φ(−m/σ)
양자화는 가중치에 잡음을 더하고, 정답과 경쟁 값의 로짓 차이에는 평균 0, 표준편차 σ의 정규 잡음에 가까운 오차가 더해진다(5편과 같은 계산). 잡음이 −m보다 작으면 답이 바뀐다.
```text
P(뒤집힘) = Φ(−m / σ)
σ ≈ √((Δ_정답² + Δ_경쟁² ) / 12) · ‖x‖    Δ: 그 행의 격자 간격
```

σ는 빈도와 상관없이 모든 사실에 같은 규모로 더해지고, 비트를 하나 줄이면 Δ와 σ가 2배가 된다. m/σ별로 계산해 보자.
```python
from scipy.stats import norm

for z in (4, 2, 1, 0.5):                  # z = m/σ, 비트를 하나 줄이면 σ가 2배
    print(f"m/σ = {z:<3}: 뒤집힘 {norm.cdf(-z):.4f} → 1비트 덜 쓰면"
          f" {norm.cdf(-z / 2):.4f} (+{norm.cdf(-z / 2) - norm.cdf(-z):.3f})")
```
```text
m/σ = 4  : 뒤집힘 0.0000 → 1비트 덜 쓰면 0.0228 (+0.023)
m/σ = 2  : 뒤집힘 0.0228 → 1비트 덜 쓰면 0.1587 (+0.136)
m/σ = 1  : 뒤집힘 0.1587 → 1비트 덜 쓰면 0.3085 (+0.150)
m/σ = 0.5: 뒤집힘 0.3085 → 1비트 덜 쓰면 0.4013 (+0.093)
```

m/σ가 4인 넉넉한 사실은 비트를 하나 줄여도 2%만 뒤집힌다. 이미 0.5 근처인 사실은 원래 30%가 틀려 있어 더 잃을 것이 적다. 가장 많이 잃는 것은 m/σ가 1~2인 경계의 사실이다(+14~15%p). σ에 대한 변화율 `∂Φ(−m/σ)/∂ln σ = φ(z)·z`(z = m/σ)가 z = 1에서 가장 크기 때문이다. 빈도가 마진을 정하므로, 이 경계 구간을 채우는 것은 꼬리의 사실들이다.

## 실험: 지프 빈도로 학습한 메모리
가상의 데이터로 재현한다. 7편의 연상 메모리와 같은 구조에 사실 1,280개(값 16종, 파라미터당 1.25비트)를 넣되, 사실마다 지수 1.2의 지프 빈도를 손실의 가중치로 준다(빈도에 비례해 샘플링하는 학습의 기댓값과 같다). 빈도 순위 구간별로 마진, 정확도, 4비트에서 FP 정답이 뒤집힌 비율과 Φ(−m/σ) 예측을 비교하고, 빈도로 가중한 정확도·퍼플렉서티와 사실별 평균 정확도를 함께 본다.
```python
import numpy as np
from scipy.stats import norm

rng = np.random.default_rng(0)

def quant(W, bits):                       # 행(값)마다 대칭 absmax
    s = np.abs(W).max(axis=1, keepdims=True) / (2 ** (bits - 1) - 1)
    return np.round(W / s) * s

def softmax(Z):
    P = np.exp(Z - Z.max(axis=1, keepdims=True))
    return P / P.sum(axis=1, keepdims=True)

def train(X, y, w, K=16, steps=3000, lr=0.05):  # 빈도 w로 가중한 교차 엔트로피
    W, m, v = (np.zeros((K, X.shape[1])) for _ in range(3))
    Y = np.eye(K)[y]
    for t in range(1, steps + 1):
        G = ((softmax(X @ W.T) - Y) * w[:, None]).T @ X
        m = 0.9 * m + 0.1 * G
        v = 0.999 * v + 0.001 * G ** 2
        W -= lr * (m / (1 - 0.9 ** t)) / (np.sqrt(v / (1 - 0.999 ** t)) + 1e-8)
    return W

N, d = 1280, 256                          # 사실 1,280개(4비트씩), 파라미터 4,096개
X = rng.normal(size=(N, d)) / np.sqrt(d)
y = rng.integers(0, 16, N)
w = np.arange(1, N + 1) ** -1.2           # 지프 빈도: 순위 r의 비중 ∝ r^(−1.2)
w /= w.sum()
W = train(X, y, w)

def margin(W):                            # 정답 로짓 − 가장 큰 오답 로짓
    Z = X @ W.T
    i = np.arange(N)
    zc = Z[i, y].copy()
    Z[i, y] = -np.inf
    return zc - Z.max(axis=1), Z.argmax(axis=1)

m, k = margin(W)
D = np.abs(W).max(axis=1) / 7             # 4비트 격자 간격
sig = np.sqrt((D[y] ** 2 + D[k] ** 2) / 12) * np.linalg.norm(X, axis=1)
B = [(0, 20), (20, 80), (80, 320), (320, N)]   # 빈도 순위 구간
print("구간      비중  ln빈도  마진  FP   8비트 4비트 3비트  뒤집힘/Φ(4비트)")
acc = {b: margin(quant(W, b) if b else W)[0] > 0 for b in (0, 8, 4, 3)}
for lo, hi in B:
    g = slice(lo, hi)
    ok = m[g] > 0                         # FP에서 맞힌 사실
    flip = np.mean(~acc[4][g][ok])
    pred = np.mean(norm.cdf(-m[g][ok] / sig[g][ok]))
    print(f"{lo + 1:>4}~{hi:<4} {w[g].sum():.3f} {np.median(np.log(w[g])):6.2f}",
          f"{np.median(m[g]):5.2f} ",
          " ".join(f"{acc[b][g].mean():.2f}" for b in (0, 8, 4, 3)),
          f"   {flip:.2f}/{pred:.2f}")
for b in (0, 4, 3):
    Wq = quant(W, b) if b else W
    ce = -np.log(softmax(X @ Wq.T)[np.arange(N), y])
    print(f"{b or 'FP'}{'비트' if b else ''}: 가중 정확도 {np.sum(w * acc[b]):.3f},",
          f"가중 퍼플렉서티 {np.exp(np.sum(w * ce)):.3f},",
          f"사실별 평균 정확도 {acc[b].mean():.3f}")
```
```text
구간      비중  ln빈도  마진  FP   8비트 4비트 3비트  뒤집힘/Φ(4비트)
   1~20   0.650  -4.30  7.05  1.00 1.00 1.00 0.95    0.00/0.00
  21~80   0.149  -6.19  4.82  1.00 1.00 1.00 0.80    0.00/0.00
  81~320  0.114  -7.84  3.25  1.00 1.00 0.94 0.69    0.06/0.04
 321~1280 0.087  -9.50  1.57  0.89 0.89 0.72 0.48    0.21/0.18
FP: 가중 정확도 0.994, 가중 퍼플렉서티 1.049, 사실별 평균 정확도 0.916
4비트: 가중 정확도 0.975, 가중 퍼플렉서티 1.096, 사실별 평균 정확도 0.781
3비트: 가중 정확도 0.890, 가중 퍼플렉서티 1.476, 사실별 평균 정확도 0.540
```

- 마진이 ln 빈도를 따른다. 구간 사이 ln 빈도의 차이(1.89, 1.65, 1.66)와 마진의 차이(2.23, 1.57, 1.68)가 비슷하다. FP에서도 꼬리는 89%만 맞힌다. Kandpal 등이 본 롱테일 현상의 축소판이다.
- 4비트에서 상위 80개 사실은 하나도 잃지 않고, 꼬리 960개는 89%에서 72%로 떨어진다. 꼬리에서 뒤집힌 비율 21%를 Φ(−m/σ)가 18%로 예측한다. 예측이 조금 낮은 것은 가장 큰 경쟁 값 하나만 셌기 때문이다.
- 평가 함정: 빈도로 가중한 정확도는 99.4%에서 97.5%로 2%p도 안 떨어지고 퍼플렉서티는 1.049에서 1.096으로 약 4.5% 오른다. 같은 순간 사실별 평균 정확도는 91.6%에서 78.1%로 떨어진다. 꼬리 960개(전체의 75%)가 평가 데이터에서는 8.7%의 비중밖에 없어서다.

## 평가 함정은 실제 모델에서도 보인다
- Dutta 등의 「Accuracy is Not All You Need」(NeurIPS 2024)는 양자화한 모델의 정확도가 원래와 비슷해도 맞던 답이 틀리고 틀리던 답이 맞는 **뒤집힘**(flips)이 거의 같은 수로 일어나 정확도에 가려진다는 것을 보였다. GPTQ W8A16을 빼면 시험한 방식 모두에서 뒤집힘이 많았고, 정확도와 함께 뒤집힘과 KL 발산을 보고하자고 제안했다.
- Marchisio 등의 「How Does Quantization Affect Multilingual LLMs?」(Findings of EMNLP 2024)는 80억~1,030억 파라미터 모델 4개를 23개 언어로 평가해, 자동 지표가 사람 평가의 손상을 크게 과소평가한다고 보고했다. 일본어에서 자동 과제 평균 1.7% 하락이 사람 평가로는 현실적인 프롬프트에서 16.0% 하락이었다. 라틴 문자를 쓰지 않는 언어가 가장 크게 손상되었고, 수학 추론처럼 어려운 과제가 가장 빨리 나빠졌다.

그래서 양자화한 모델은 평균 지표만이 아니라 빈도 구간별 정확도, 뒤집힘, 원래 모델과의 KL 발산, 여러 언어(특히 라틴 문자가 아닌 언어)와 롱테일 질문 세트로 따로 평가해야 한다.

## 차이가 벌어질 수밖에 없는 이유
7편과 이 글을 묶으면 논리는 네 단계다.
1. 용량: 지식은 파라미터의 비트를 나눠 쓴다. 비트를 줄이면 상한이 줄고 σ가 비트당 2배가 되어, 모든 사실의 m/σ가 작아진다(7편).
2. 배분: 학습은 빈도에 따라 마진을 산다(m ≈ ln w + 상수). 지프 분포에서는 대부분의 사실이 꼬리에 있고, 그 마진이 경계 근처에 있다. 적게 노출된 지식은 저장 효율부터 낮고(7편: 100번 노출이면 파라미터당 약 1비트), 잠재 공간에서도 드문 특징이 중첩되어 여유가 얇다(6편).
3. 비선형성: 잡음이 커질 때 Φ(−m/σ)가 가장 많이 늘어나는 곳은 m/σ ≈ 1 근처다. 같은 잡음이 넉넉한 머리에는 아무 일도 하지 않고 경계의 꼬리만 무너뜨린다.
4. 측정: 평균 지표는 빈도로 가중되어 머리가 지배하므로 그 붕괴가 거의 보이지 않는다.

1~3은 학습과 양자화의 구조에서 나오는 결과라 기법을 바꿔도 없어지지 않고 줄어들 뿐이다. 9편부터의 기법들은 σ를 줄이거나(더 좋은 격자, 오차 보정, 이상치 처리) 학습 중에 마진을 확보해(QAT) 경계를 뒤로 미룰 뿐이다.

## 어디에 쓰이나
- 확률과 분포 8편 「정규 분포: 종 모양 곡선의 정체」: 뒤집힘 확률 Φ(−m/σ)는 표준 정규 분포의 꼬리 넓이이고, σ가 커질 때 이 넓이가 가장 빨리 느는 곳이 m/σ = 1이다.
- 통계학 11편 「모델 평가: 교차 검증과 평가 지표」: 빈도로 가중한 평균이 드문 구간의 붕괴를 가리는 것은 클래스 불균형에서 정확도가 성능을 속이는 것과 같은 문제다.
- AI 기초 3편 「데이터 분포로 보는 AI 모델」: 학습은 p_data에 맞춰지므로, 데이터에 적게 나온 사실일수록 마진이 작은 것은 최대 우도 학습의 자연스러운 결과다.
- 13편 「양자화 인식 학습과 극단적 저비트: QAT, QLoRA, BitNet」: 양자화한 모델을 고르고 평가할 때 롱테일 구간과 뒤집힘까지 보라는 실전 가이드로 이어진다.

## 정리
- 학습 데이터의 사실 빈도는 지프 분포처럼 치우쳐 있고, 데이터에 적게 나온 사실일수록 모델이 잘 모른다(Kandpal 등).
- 빈도 가중 학습에서 마진은 대략 ln 빈도를 따르고, 양자화 잡음은 모든 사실에 같게 더해지므로 뒤집힘 Φ(−m/σ)가 꼬리에 몰린다.
- 가상 실험 4비트에서 상위 사실은 그대로, 꼬리는 89% → 72%였지만 빈도 가중 정확도는 2%p도 안 떨어졌다. 평균 지표만 보면 손상을 놓친다.
- 용량(7편), 빈도에 따른 마진 배분, Φ의 비선형성, 평균 지표의 가중이 겹쳐 양자화에 따른 지식의 차이는 벌어질 수밖에 없다.
