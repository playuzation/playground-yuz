## 지식을 비트로 세기
"홍길동의 출생지는 어디인가" 같은 사실 하나를 생각하자. 답이 K개 도시 중 하나로 고르게 퍼져 있다면 이 사실의 정보량은 log₂ K비트다(정보 이론 1편). N명의 출생지를 모두 알면 N·log₂ K비트를 아는 것이다. 모델이 정답에 확률 p를 준다면 남은 불확실성은 −log₂ p비트이므로, 모델이 실제로 알아낸 양은 다음처럼 셀 수 있다.
```text
저장한 비트 ≈ Σ_사실 ( log₂ K − (−log₂ p_정답) )
             = N·log₂ K − 교차 엔트로피 합(비트)
```

정답에 확률 1을 주면 사실 하나에 log₂ K비트를 다 얻고, 찍는 수준(p = 1/K)이면 0이다. 퍼플렉서티 같은 평균 손실과 달리 "몇 비트를 기억하나"를 직접 센다는 점이 중요하다.

## 파라미터당 2비트
Allen-Zhu와 Li의 「Physics of Language Models: Part 3.3」(2024)은 가상 인물의 생일·출생 도시·대학·전공·직장 같은 합성 전기 데이터로 GPT-2·라마·미스트랄 구조의 여러 크기 모델을 사전 학습시키고, 위와 같은 정보 이론적 방법으로 저장된 지식의 비트 수를 쟀다. 보고된 결과 중 이 시리즈에 중요한 것은 다음과 같다.
- 지식 하나를 사전 학습 중 1,000번 노출하면 모델 크기·깊이와 관계없이 파라미터당 약 2비트를 저장한다. 100번 노출이면 약 1비트로 떨어진다.
- 저자들의 추정으로 7B 모델이면 140억 비트로, 영어 위키백과와 교과서를 합친 것보다 많다.
- 16비트로 학습한 모델을 int8로 양자화하면 용량이 거의 줄지 않는다. 8비트 중 2비트를 지식에 쓰니, 저장 한계의 4분의 1 넘게 쓰는 셈이다.
- int4로 양자화하면(auto_gptq 사용) 용량이 2배 넘게 줄었다. 저자들은 양질의 int4 모델을 얻으려면 학습 중에 양자화를 넣어야 할 수 있다고 적었다.

## 상한: 파라미터 × 비트
b비트 파라미터 P개로 만들 수 있는 서로 다른 모델은 2^(P·b)가지다. 서로 다른 사실 집합을 구별해 기억하려면 서로 다른 모델이 필요하므로, 저장할 수 있는 정보는 P·b비트를 넘지 못한다(비둘기집 원리). 파라미터당 2비트의 지식을 이 상한과 나란히 놓으면 다음과 같다(그룹 스케일이 차지하는 비트는 무시).

| 형식 | 상한(비트/파라미터) | 2비트 지식의 비율 |
|---|---|---|
| BF16 | 16 | 12.5% |
| INT8 | 8 | 25% |
| INT4 | 4 | 50% |
| INT3 | 3 | 67% |
| INT2 | 2 | 100% |

INT8은 여유가 넉넉하지만 INT4에서는 상한의 절반을 지식이 차지하고, INT2에서는 상한과 같아진다. 실제 신경망은 비트를 이렇게 효율적으로 쓰지 못하므로 저비트로 갈수록 무언가를 버려야 한다. 고전적인 퍼셉트론 결과도 같은 이야기를 한다. 무작위 이진 라벨을 실수 가중치 퍼셉트론에 저장하면 파라미터당 2개까지 들어가지만(Gardner·Derrida), 가중치를 ±1로 제한하면 약 0.83개로 준다(Krauth·Mézard, 1989).

## 꽉 찰수록 여유가 준다
퍼셉트론 이론에는 이 시리즈의 질문에 더 직접적인 답도 있다. 라벨마다 정규화 마진(w·x를 그 전형적인 크기로 나눈 값)이 κ 이상이기를 요구하면, 가드너(Gardner, 1988)의 계산으로 저장할 수 있는 라벨 수가 `α_c(κ) = 1 / ∫_(−κ)^∞ (t + κ)²·Dt`로 줄어든다(Dt는 표준 정규 측도, κ = 0이면 2). 거꾸로 읽으면 파라미터당 α비트를 저장했을 때 보장할 수 있는 최대 여유가 정해진다.
```python
import numpy as np
from scipy.integrate import quad
from scipy.optimize import brentq
from scipy.stats import norm

def alpha_c(kappa):                       # 가드너: 여유 κ를 보장하는 용량
    f = lambda t: (t + kappa) ** 2 * norm.pdf(t)
    return 1 / quad(f, -kappa, np.inf)[0]

for a in (0.25, 0.5, 1.0, 1.5, 1.9):      # 파라미터당 저장한 라벨 수(=비트)
    k = brentq(lambda x: alpha_c(x) - a, 0, 10)
    print(f"파라미터당 {a:4.2f}비트 → 보장 가능한 최대 여유 κ = {k:.2f}")
```
```text
파라미터당 0.25비트 → 보장 가능한 최대 여유 κ = 1.74
파라미터당 0.50비트 → 보장 가능한 최대 여유 κ = 1.03
파라미터당 1.00비트 → 보장 가능한 최대 여유 κ = 0.47
파라미터당 1.50비트 → 보장 가능한 최대 여유 κ = 0.19
파라미터당 1.90비트 → 보장 가능한 최대 여유 κ = 0.03
```

파라미터당 0.25비트만 저장하면 모든 라벨에 1.74의 여유를 줄 수 있지만, 1비트면 0.47, 1.9비트면 0.03으로 줄어든다. 가중치에 상대 크기 r의 잡음이 섞이면 정규화 마진에도 대략 표준편차 r의 잡음이 더해진다. 행별 absmax 4비트의 상대 잡음이 아래 실험에서 약 0.1(상대 MSE 0.0092의 제곱근)이니, 여유가 그 수준으로 내려가는 순간부터 라벨이 뒤집히기 시작한다. 용량 근처까지 채운 메모리는 정의상 여유가 없는 메모리다.

## 율-왜곡 이론의 직관
**율-왜곡 이론**(rate-distortion theory)은 값 하나를 R비트로 적을 때 피할 수 없는 최소 오차를 준다. 분산 σ²인 가우시안 값이면 다음과 같다.
```text
D(R) = σ² · 2^(−2R)     비트 하나를 줄이면 오차 4배(약 6dB)
```

1편의 "비트당 약 6dB"는 이 한계의 기울기와 같다. 어떤 양자화기도 이 선 아래로 내려갈 수 없다. 그런데 지식은 MSE에 비례해 줄지 않는다. 사실 하나는 잡음이 그 사실의 마진을 넘기 전까지는 멀쩡하다가 넘는 순간 틀린다. 그래서 같은 MSE라도 마진이 얇은 메모리가 훨씬 많이 잃는다.

## 실험: 꽉 찬 메모리일수록 약하다
가상의 데이터로 재현한다. 무작위 키(이름) N개에 16가지 값(속성) 중 하나를 무작위로 붙이고, 파라미터 1,024개짜리 선형 메모리 `p = softmax(W x)`를 교차 엔트로피로 학습한다. 사실 하나가 4비트이므로 N·4/1,024가 파라미터당 정보량이다. 학습한 W를 행마다 양자화해 회상률을 재고, 정답과 가장 가까운 경쟁 값의 로짓 차이(마진)를 4비트 양자화 잡음의 표준편차로 나눈 z의 중앙값도 출력한다.
```python
import numpy as np

rng = np.random.default_rng(0)

def quant(W, bits):                       # 행(값)마다 대칭 absmax
    s = np.abs(W).max(axis=1, keepdims=True) / (2 ** (bits - 1) - 1)
    return np.round(W / s) * s

def softmax(Z):
    P = np.exp(Z - Z.max(axis=1, keepdims=True))
    return P / P.sum(axis=1, keepdims=True)

def train(X, y, K, steps=4000, lr=0.05):  # 교차 엔트로피 + Adam, 전체 배치
    W, m, v = (np.zeros((K, X.shape[1])) for _ in range(3))
    Y = np.eye(K)[y]
    for t in range(1, steps + 1):
        G = (softmax(X @ W.T) - Y).T @ X / len(y)
        m = 0.9 * m + 0.1 * G
        v = 0.999 * v + 0.001 * G ** 2
        W -= lr * (m / (1 - 0.9 ** t)) / (np.sqrt(v / (1 - 0.999 ** t)) + 1e-8)
    return W

d, K = 64, 16                             # 키 64차원, 값 16종(사실당 4비트)
print("N   비트/파라미터  회상률 FP·8·4·3·2비트       4비트 z 중앙값")
for N in (64, 128, 192, 256, 320, 384):
    X = rng.normal(size=(N, d)) / np.sqrt(d)  # 무작위 키(이름)
    y = rng.integers(0, K, N)                 # 무작위 값(속성)
    W = train(X, y, K)                        # 파라미터 64 × 16 = 1,024개
    acc = [np.mean((X @ (quant(W, b) if b else W).T).argmax(1) == y)
           for b in (0, 8, 4, 3, 2)]
    Z = X @ W.T
    i = np.arange(N)
    zc = Z[i, y]
    Z[i, y] = -np.inf
    k = Z.argmax(axis=1)                      # 가장 가까운 경쟁 값
    D = np.abs(W).max(axis=1) / 7             # 4비트 격자 간격(행별)
    sig = np.sqrt((D[y] ** 2 + D[k] ** 2) / 12) * np.linalg.norm(X, axis=1)
    z = np.median((zc - Z[i, k]) / sig)       # 마진 ÷ 4비트 잡음
    print(f"{N:<4} {N * 4 / W.size:.2f}     ", " ".join(f"{a:.3f}" for a in acc),
          f"   {z:5.1f}")
```
```text
N   비트/파라미터  회상률 FP·8·4·3·2비트       4비트 z 중앙값
64   0.25      1.000 1.000 1.000 1.000 1.000     23.6
128  0.50      1.000 1.000 1.000 1.000 0.922     12.0
192  0.75      1.000 1.000 1.000 1.000 0.776      7.9
256  1.00      1.000 1.000 1.000 0.871 0.496      3.6
320  1.25      1.000 1.000 0.812 0.519 0.278      1.2
384  1.50      0.753 0.742 0.542 0.388 0.260      0.4
```

파라미터당 0.75비트까지는 3비트로 양자화해도 하나도 잊지 않는다. 마진이 4비트 잡음의 8~24배라 여유가 넉넉하다. 1비트를 채우면 3비트에서 13%를 잊고, 1.25비트를 채우면 FP로는 여전히 100%를 기억하는데도 4비트에서 19%, 3비트에서 48%를 잊는다. z 중앙값이 23.6에서 1.2로 줄어든 것이 이유다. 사실을 더 많이 넣으면 모델은 모든 제약을 만족시키려고 마진을 깎아 쓰고, 그 결과 FP 정확도는 그대로인데 양자화 잡음에 견딜 여유만 사라진다. 1.5비트에서는 FP로도 75%만 기억한다. 이 작은 선형 메모리의 용량이 그 근처라는 뜻이다. 마지막 W의 양자화 오차를 율-왜곡 한계와 비교해 보자.
```python
for b in (8, 4, 3, 2):                    # 마지막 W의 상대 MSE와 D(R)/σ²
    mse = np.mean((quant(W, b) - W) ** 2) / np.mean(W ** 2)
    print(f"{b}비트: 상대 MSE {mse:.1e}, 가우시안 한계 2^(−2b) {2.0 ** (-2 * b):.1e}")
```
```text
8비트: 상대 MSE 2.8e-05, 가우시안 한계 2^(−2b) 1.5e-05
4비트: 상대 MSE 9.2e-03, 가우시안 한계 2^(−2b) 3.9e-03
3비트: 상대 MSE 5.0e-02, 가우시안 한계 2^(−2b) 1.6e-02
2비트: 상대 MSE 4.5e-01, 가우시안 한계 2^(−2b) 6.2e-02
```

8비트에서 4비트까지는 비트당 오차가 4배 남짓씩 늘어 한계와 비슷한 기울기를 따르지만, 행별 absmax 격자는 한계보다 2~7배 나쁘고 저비트일수록 격차가 벌어진다. 2비트에서는 상대 오차가 45%다. 9편부터의 기법들(클리핑, 비균일 격자, GPTQ)은 이 격차를 줄이는 방법이다.

## 많이 학습할수록 양자화에 약하다
실험에서 N을 늘린 것(파라미터당 정보량 증가)은 실제 모델에서 학습 데이터를 늘리는 것과 같은 방향이다. Kumar 등의 「Scaling Laws for Precision」(2024)은 3~16비트로 사전 학습한 언어 모델 465개를 여러 정밀도로 학습 후 양자화해, 양자화로 인한 손실 증가가 사전 학습 토큰 수와 함께 커진다는 것을 보였다(17억 파라미터, 260억 토큰까지 검증). 그래서 데이터가 어느 수준을 넘으면 더 많은 사전 학습이 양자화 후 성능에는 오히려 해로울 수 있다. 저자들은 데이터를 많이 볼수록 가중치에 더 많은 정보가 압축되기 때문이라는 직관을 든다. Ouyang 등의 「Low-Bit Quantization Favors Undertrained LLMs」(ACL 2025)도 양자화한 체크포인트 1,500개 이상에서 같은 방향을 보고했다. 큰 모델이나 적게 학습한 모델보다, 작은 모델을 많은 토큰으로 학습했을 때 양자화로 인한 성능 저하가 컸다. 이 법칙을 100조 토큰 학습까지 외삽하면 저비트 양자화의 성능이 만족스럽지 않을 수 있다고 전망했다. 위 실험과 같은 그림이다. 파라미터마다 정보가 꽉 찰수록 마진이 얇아진다.

## 어디에 쓰이나
- 정보 이론 2편 「교차 엔트로피」: 모델이 저장한 비트 수는 log₂ K에서 정답에 대한 교차 엔트로피를 뺀 양으로 센다.
- 이산수학 7편 「비둘기집 원리와 포함·배제의 원리」: 가중치 P·b비트로는 2^(P·b)가지 모델밖에 못 만드니, 그보다 많은 사실 조합을 구별해 기억할 수 없다.
- 8편 「왜 드문 지식이 먼저 사라지나: 데이터 분포와 롱테일」: 꽉 찬 메모리에서 모든 사실이 같은 마진을 갖지는 않는다. 어느 사실의 마진이 가장 얇은지가 다음 글의 주제다.
- 13편 「양자화 인식 학습과 극단적 저비트: QAT, QLoRA, BitNet」: 비트가 용량을 정한다면 극단적 저비트는 학습 후에 깎기보다 처음부터 그 비트로 학습해야 한다는 결론으로 이어진다.

## 정리
- 지식은 "N·log₂ K − 교차 엔트로피"로 비트 단위로 셀 수 있고, Physics of Language Models 3.3은 파라미터당 약 2비트(충분히 노출된 지식 기준)를 보고했다.
- b비트 가중치의 정보 상한은 파라미터당 b비트다. 2비트 지식은 INT8 상한의 25%, INT4 상한의 50%를 차지한다. 보고된 결과도 int8은 거의 무손실, int4는 용량이 절반 아래였다.
- 저장량이 용량에 다가갈수록 보장할 수 있는 여유가 0으로 줄어든다(가드너). 가상 실험에서도 사실을 더 넣으면 FP 정확도는 그대로인데 4비트 손실이 0%에서 19%로 늘었다.
- 많이 학습한 모델일수록 학습 후 양자화의 손해가 크다는 정밀도 스케일링 법칙도 같은 원리로 읽힌다.
