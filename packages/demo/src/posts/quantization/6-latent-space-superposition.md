# [양자화 6/15] 잠재 공간과 중첩: 표현에 남은 여유가 줄어들 때

> **한 줄 요약** — 고차원 잠재 공간에는 거의 직교하는 방향이 차원보다 훨씬 많아서 모델은 특징을 차원보다 많이 겹쳐 담지만(중첩), 그 대가인 간섭이 읽기 여유를 이미 깎아 두었기 때문에 양자화 잡음이 더해지면 중첩된 드문 특징과 약한 특징부터 읽히지 않는다.

## 이 글에서 다루는 것
- 은닉 상태 = 잠재 공간, 선형 표현 가설
- 거의 직교하는 방향은 차원보다 훨씬 많다(무작위 벡터 실험)
- 중첩, 간섭, 읽기 여유(margin)
- 양자화가 중첩된 드문·약한 특징부터 지우는 실험(가상 데이터)
- 이상치 차원의 역할, 잠재 공간의 부피를 비트로 세기

## 잠재 공간과 선형 표현 가설
트랜스포머의 층과 층 사이를 흐르는 은닉 상태 h(잔차 스트림)는 모델이 입력에서 알아낸 것을 담는 **잠재 공간**(latent space)의 한 점이다. 5편의 임베딩이 토큰의 좌표라면 잠재 공간은 문맥까지 반영한 중간 표현의 좌표다. **선형 표현 가설**(linear representation hypothesis)은 개념 하나가 이 공간의 방향 하나에 대응하고, 개념의 세기는 그 방향으로의 사영으로 읽힌다고 본다. word2vec 논문의 "king − man + woman ≈ queen" 같은 벡터 산술과, 은닉 상태에 선형 분류기 하나만 붙여 개념을 읽어 내는 선형 탐침(linear probe)이 자주 드는 근거다.
```text
h = Σᵢ aᵢ·wᵢ                          aᵢ: 특징 i의 세기, wᵢ: 단위 방향
âⱼ = wⱼ·h = aⱼ + Σ_(i≠j) aᵢ·(wᵢ·wⱼ)     읽기 = 내적
```

둘째 식의 뒤 항이 **간섭**(interference)이다. 방향들이 서로 직교하면 0이지만, d차원에서 정확히 직교하는 방향은 d개뿐이다(선형대수 6편).

## 거의 직교하는 방향은 차원보다 훨씬 많다
"정확히 직교"를 "거의 직교"(∣cos∣ ≤ ε)로 바꾸면 사정이 달라진다. d차원 무작위 단위 벡터 두 개의 내적은 평균 0, 표준편차 1/√d인 정규 분포에 가깝다. 그래서 `P(∣cos∣ > ε) ≈ 2·exp(−dε²/2)`이고, N개 방향의 모든 쌍(약 N²/2개)에 합집합 상한을 쓰면 `N < exp(dε²/4)`까지는 모든 쌍을 ε 안에 넣을 수 있다. 들어가는 방향의 수가 차원에 대해 지수적이다.
```python
import numpy as np

rng = np.random.default_rng(0)
N = 4096                                  # 방향의 개수
for d in (64, 256, 1024):
    W = rng.normal(size=(N, d))
    W /= np.linalg.norm(W, axis=1, keepdims=True)
    cos = (W @ W.T)[np.triu_indices(N, 1)]   # 서로 다른 쌍 약 838만 개
    print(f"d={d:<4} N/d={N // d:<3} 표준편차 {cos.std():.4f} (1/√d {d**-0.5:.4f})"
          f"  최대 ∣cos∣ {np.abs(cos).max():.3f}"
          f"  ∣cos∣>0.2 비율 {np.mean(np.abs(cos) > 0.2):.4f}")
```
```text
d=64   N/d=64  표준편차 0.1250 (1/√d 0.1250)  최대 ∣cos∣ 0.601  ∣cos∣>0.2 비율 0.1103
d=256  N/d=16  표준편차 0.0625 (1/√d 0.0625)  최대 ∣cos∣ 0.328  ∣cos∣>0.2 비율 0.0013
d=1024 N/d=4   표준편차 0.0313 (1/√d 0.0312)  최대 ∣cos∣ 0.158  ∣cos∣>0.2 비율 0.0000
```

표준편차가 정확히 1/√d를 따른다. d = 1024에 차원의 4배인 4,096개 방향을 무작위로 뿌려도 약 838만 쌍 가운데 가장 많이 겹치는 쌍의 ∣cos∣가 0.158이다. 위 상한으로 계산하면 d = 4096(라마 3 8B의 은닉 차원)에서 ε = 0.1이면 약 2.8만 개, ε = 0.2면 약 6 × 10¹⁷개의 방향이 들어간다. 존슨-린덴슈트라우스(Johnson–Lindenstrauss) 보조정리 계열이 말하는 고차원의 여유다.

## 중첩과 읽기 여유
Elhage 등의 「Toy Models of Superposition」(2022)은 희소한 입력 특징을 작은 ReLU 네트워크로 압축하게 했을 때, 모델이 차원보다 많은 특징을 거의 직교하는 방향에 겹쳐 담는 현상을 **중첩**(superposition)이라 불렀다. 열쇠는 희소성이다. 특징이 드물게 켜지면 한 번에 켜지는 특징이 적어 간섭의 합이 작고, 남은 간섭은 비선형으로 걸러 낼 수 있다. 논문의 상전이 그림에서 특징 하나의 운명(전용 차원을 받는다, 다른 특징과 겹친다, 버려진다)은 그 특징의 상대적 중요도와 희소성으로 정해진다.

특징 j를 켜짐/꺼짐으로 읽는다면 임계값을 세기의 절반에 두고, 잡음 `n = âⱼ − aⱼ`의 크기가 aⱼ/2를 넘으면 틀린다. 이 aⱼ/2가 **여유**(margin)다. 간섭과 양자화 잡음은 서로 독립이라 분산이 더해진다.
```text
σ² = σ²(간섭) + σ²(양자화),   σ²(간섭) ≈ Σ_(켜진 i) aᵢ² / d
P(읽기 실패) ≈ 2·Φ(−(aⱼ/2) / σ)
```

세기가 절반인 특징은 여유도 절반이다. 간섭으로 σ가 이미 큰 특징, 즉 중첩된 특징은 양자화 잡음이 조금만 더해져도 경계를 넘는다.

## 실험: 중첩된 드문 특징부터 무너진다
가상의 잠재 공간을 만든다. d = 256 중 64축은 자주 켜지는 특징 64개(확률 0.1)가 하나씩 전용으로 쓰고, 다음 191축에는 드물게 켜지는 특징 1,536개(확률 0.002, 축 수의 8배)가 무작위 방향으로 중첩된다. 드문 특징의 절반은 세기 1, 절반은 0.5다. 마지막 1축은 이상치 실험에 쓴다. 은닉 상태를 토큰마다 absmax로 양자화하고, 켜진 특징을 잘못 읽은 비율과 0으로 반올림된 중첩 좌표의 비율을 잰다.
```python
def quant(h, bits):                       # 토큰(벡터)마다 대칭 absmax
    s = np.abs(h).max(axis=1, keepdims=True) / (2 ** (bits - 1) - 1)
    return np.round(h / np.maximum(s, 1e-12)) * s

d, nf, nr = 256, 64, 1536                 # 차원, 자주 쓰는 특징, 드문 특징
F = np.zeros((nf + nr, d))
F[:nf, :nf] = np.eye(nf)                  # 자주 쓰는 특징: 전용 축 64개
R = rng.normal(size=(nr, d - nf - 1))     # 드문 특징: 나머지 191축에 중첩
F[nf:, nf:-1] = R / np.linalg.norm(R, axis=1, keepdims=True)
amp = np.r_[np.ones(nf + nr // 2), 0.5 * np.ones(nr // 2)]  # 세기: 강/약
p = np.r_[0.1 * np.ones(nf), 0.002 * np.ones(nr)]           # 켜질 확률
A = (rng.random((20000, nf + nr)) < p) * amp   # 샘플마다 켜진 특징의 세기
H = A @ F                                 # 잠재 벡터 = 특징 방향의 합
groups = {"자주": slice(0, nf), "드문·강": slice(nf, nf + nr // 2),
          "드문·약": slice(nf + nr // 2, None)}
mid = H[:, nf:-1] != 0                    # 중첩 구역의 0이 아닌 좌표

def report(name, Hq):                     # 켜진 특징을 잘못 읽은 비율
    bad = np.abs(Hq @ F.T - A) >= amp / 2     # 잡음이 여유(세기/2)를 넘음
    errs = [bad[:, g][A[:, g] > 0].mean() for g in groups.values()]
    zero = np.mean(Hq[:, nf:-1][mid] == 0)    # 0으로 반올림된 중첩 좌표
    print(name, ", ".join(f"{k} {e:.4f}" for k, e in zip(groups, errs)),
          f"/ 0이 된 좌표 {zero:.0%}")

report("FP:   ", H)
for bits in (8, 6, 4, 3):
    report(f"{bits}비트:", quant(H, bits))
Ho = H.copy()
Ho[:, -1] = 40.0                          # 입력과 무관한 거대 활성값 하나
report("8비트+이상치:", quant(Ho, 8))
report("4비트+이상치:", quant(Ho, 4))
report("8비트+이상치 분리:", np.c_[quant(Ho[:, :-1], 8), Ho[:, -1:]])
```
```text
FP:    자주 0.0000, 드문·강 0.0002, 드문·약 0.0245 / 0이 된 좌표 0%
8비트: 자주 0.0000, 드문·강 0.0002, 드문·약 0.0246 / 0이 된 좌표 4%
6비트: 자주 0.0000, 드문·강 0.0002, 드문·약 0.0246 / 0이 된 좌표 15%
4비트: 자주 0.0000, 드문·강 0.0003, 드문·약 0.0634 / 0이 된 좌표 57%
3비트: 자주 0.0000, 드문·강 0.1472, 드문·약 0.4088 / 0이 된 좌표 89%
8비트+이상치: 자주 0.0000, 드문·강 0.1077, 드문·약 0.3549 / 0이 된 좌표 88%
4비트+이상치: 자주 1.0000, 드문·강 1.0000, 드문·약 1.0000 / 0이 된 좌표 100%
8비트+이상치 분리: 자주 0.0000, 드문·강 0.0002, 드문·약 0.0246 / 0이 된 좌표 4%
```

- FP에서도 드문 약한 특징은 2.5%를 틀린다. 간섭이 이미 여유를 깎아 둔 것이다. 전용 축을 가진 특징은 한 번도 틀리지 않는다.
- 4비트에서 약한 특징의 오류가 2.6배(6.3%)로 느는 동안 나머지는 거의 그대로다. 3비트에서는 드문 강한 특징도 15%, 약한 특징은 41%를 틀리지만 자주 쓰는 특징은 여전히 0%다.
- 반올림 자체도 한몫한다. 전용 축의 특징은 좌표 하나에 세기 1이 몰려 있고 absmax 스케일은 그 큰 좌표에 맞춰진다. 중첩된 특징은 191개 좌표에 약 0.07씩 흩어져 있어 격자 간격(4비트 1/7, 3비트 1/3)보다 작다. 그래서 중첩 좌표의 57%(4비트), 89%(3비트)가 0이 된다.

## 이상치 차원의 역할
실제 LLM의 은닉 상태에는 극소수 차원에 유난히 큰 값이 나타난다(3편). Massive Activations 논문(Sun 등, 2024)은 라마2-7B에서 가장 큰 활성값(약 2,000)이 중앙값(약 0.2)의 약 1만 배이고, 이런 값이 입력과 거의 무관하게 일정해 모델 안에서 꼭 필요한 편향처럼 동작한다고 보고했다. 위 실험의 마지막 세 줄이 이 경우다. 값이 40인 상수 차원 하나가 들어오자 8비트 격자 간격이 40/127 ≈ 0.31로 3비트(1/3)와 비슷해져 오류도 3비트 수준이 되었고, 4비트에서는 모든 좌표가 0이 되었다. 이상치 차원만 높은 정밀도로 빼 두면 8비트 결과로 돌아온다. LLM.int8()의 혼합 정밀도 분해와 회전 기법이 이 문제를 푼다(10편).

## 잠재 공간의 부피를 비트로 세기
좌표 d개를 b비트씩 저장한 벡터가 가질 수 있는 상태는 2^(d·b)개이므로 정보량의 상한은 d·b비트이고, 비트 하나를 내리면 상한이 d비트 준다. 위 실험의 벡터는 256 × 4 = 1,024비트인데, 1,600개 특징 가운데 어떤 10개가 켜졌는지 적는 데는 log₂ C(1600, 10) ≈ 85비트면 된다. 부피는 남아도는데도 읽기가 실패하는 것은 모델이 이 부피를 내적이라는 선형 읽기로 쓰기 때문이다. 선형 읽기는 칸의 수가 아니라 방향마다의 여유에 묶여 있고, 양자화는 그 여유를 모든 방향에서 똑같이 깎는다. 여유가 처음부터 얇은 특징이 먼저 넘어가는 이유다.

## 정리
- 은닉 상태는 개념을 방향으로 담는 잠재 공간이고, 특징은 방향과의 내적으로 읽는다.
- 무작위 방향의 내적은 표준편차가 1/√d라서 거의 직교하는 방향을 차원보다 지수적으로 많이 넣을 수 있고, 모델은 이를 이용해 특징을 중첩한다.
- 중첩의 대가인 간섭이 여유를 깎아 두어서, 양자화 잡음이 더해지면 중첩된 드문 특징과 약한 특징부터 실패한다(가상 실험 3비트: 자주 0%, 드문·약 41%).
- 이상치 차원 하나가 absmax 격자를 넓혀 8비트를 3비트처럼 만들 수 있다.
