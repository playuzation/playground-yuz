# [양자화 3/15] 가중치와 활성값의 분포: 이상치가 비트를 낭비하는 이유

> **한 줄 요약** — absmax 스케일에서는 최댓값이 격자 간격을 정하므로 SQNR이 최대/RMS 비율만큼 깎이고, 꼬리가 두꺼운 가중치나 채널별 이상치가 있는 활성값에서는 이상치 하나가 나머지 값을 0 근처 몇 칸에 몰아넣기 때문에, 스케일을 채널·그룹 단위로 잘게 나누고(값당 0.1~0.5비트 추가) 분포에 맞는 격자를 골라야 한다.

## 이 글에서 다루는 것
- 최댓값이 비트를 먹는 식: SQNR ≈ 상수 − 20·log₁₀(최대/σ)
- 가중치의 분포: 0 중심 종 모양, 첨도
- 활성값의 이상치: LLM.int8()의 창발적 이상치, Massive Activations
- 세분도 비교(텐서별·채널별·그룹별)와 스케일 저장 비용
- 분포를 보고 격자 고르기: INT4, E2M1, NF4

## 최댓값이 격자를 정한다
대칭 absmax 양자화는 M = max∣x∣를 격자 끝 qmax에 맞추므로 Δ = M/qmax다. 1편의 균등 잡음 모델(MSE = Δ²/12)에 넣으면 SQNR이 두 항으로 갈린다.
```text
SQNR = 10·log₁₀(σ² / (Δ²/12))
     = 10·log₁₀(12·qmax²) − 20·log₁₀(M/σ)
INT4(qmax = 7):   27.7dB − 20·log₁₀(M/σ)
INT8(qmax = 127): 52.9dB − 20·log₁₀(M/σ)
```

첫 항은 비트 수만의 함수이고, 둘째 항은 분포의 **최대/RMS 비율**(파고율, crest factor) M/σ에만 달려 있다. M/σ가 2배가 되면 6dB, 즉 비트 하나를 잃는다. 값 대부분이 몇 σ 안에 있어도 가장 큰 값 하나가 격자 전체의 간격을 정하기 때문이다. M/σ는 꼬리가 두꺼울수록, 표본이 많을수록 커진다. 꼬리의 두께는 **첨도**(kurtosis) `E[(x − μ)⁴]/σ⁴`로 잰다. 정규 분포는 3이고, 3을 뺀 초과 첨도로 라플라스 분포는 3, 자유도 ν인 t 분포는 6/(ν − 4)다(ν > 4). 가상의 가중치 백만 개로 확인하자.
```python
import numpy as np
from scipy.stats import kurtosis

def q_sym(x, bits, axis=None):            # 대칭 absmax 양자화 → 역양자화
    qmax = 2 ** (bits - 1) - 1
    s = np.abs(x).max(axis=axis, keepdims=True) / qmax
    return np.clip(np.round(x / s), -qmax, qmax) * s

def sqnr(x, xh):
    return 10 * np.log10(np.mean(x**2) / np.mean((xh - x) ** 2))

rng = np.random.default_rng(0)
n = 1_000_000
for name, w in [("정규", rng.normal(size=n)),
                ("라플라스", rng.laplace(size=n)),
                ("t(ν=5)", rng.standard_t(5, size=n))]:
    crest = np.abs(w).max() / w.std()     # 최대 / RMS
    pred = 10 * np.log10(12 * 7**2) - 20 * np.log10(crest)
    print(f"{name:6s} 초과 첨도 {kurtosis(w):5.2f}, 최대/σ {crest:5.1f}, "
          f"INT4 {sqnr(w, q_sym(w, 4)):5.2f}dB (예측 {pred:5.2f})")
```
```text
정규     초과 첨도  0.00, 최대/σ   4.7, INT4 14.19dB (예측 14.20)
라플라스   초과 첨도  3.01, 최대/σ  10.9, INT4  7.55dB (예측  6.97)
t(ν=5) 초과 첨도  4.85, 최대/σ  21.5, INT4  2.59dB (예측  1.04)
```

꼬리가 두꺼워질수록 최대/σ가 4.7 → 10.9 → 21.5로 커지고 INT4 SQNR이 14.2 → 7.6 → 2.6dB로 떨어진다. 정규 분포에서는 식이 0.01dB까지 맞는다. 두꺼운 꼬리에서 측정값이 예측보다 높은 것은 Δ가 분포의 봉우리만큼 넓어져 많은 값이 0으로 가고, 그 오차 ∣x∣가 Δ²/12 가정보다 작기 때문이다(1편의 2비트와 같은 현상). t(5)의 표본 첨도가 이론값 6보다 작은 것은 꼬리가 두꺼우면 4차 모멘트 추정이 느리게 수렴해서다. QLoRA 논문은 사전 학습된 가중치가 대체로 0 중심 정규 분포를 따른다는 관찰에서 NF4를 설계했다. 하지만 실제 가중치는 출력 채널마다 크기가 다르고 드물게 큰 값이 섞여, 텐서 하나를 통째로 보면 정규 분포보다 파고율이 크다.

## 활성값의 이상치
활성값은 사정이 더 나쁘다. 이상치가 무작위가 아니라 특정 **채널**(특징 차원)에 모인다.
- **LLM.int8()**(Dettmers 등, 2022)은 크기 6.0 이상, 층의 25% 이상, 시퀀스 위치의 6% 이상에서 나타나는 특징을 이상치 특징으로 정의했다. 이 이상치는 늘 같은 차원에 나타나고, 파라미터 6.7B 규모부터 모든 층에 퍼지면서 일반적인 8비트 양자화가 무너진다고 보고했다. 해법은 이상치 차원만 16비트로 따로 곱하는 혼합 정밀도 분해로, 99.9% 이상의 값은 그대로 8비트로 계산한다(10편).
- **Massive Activations**(Sun 등, 2024)는 이보다 훨씬 큰 극소수 활성값을 보고했다. 라마 2 7B에서 가장 큰 활성값은 약 2,000으로 중앙값(약 0.2)의 약 1만 배였다. 이런 값은 몇 개의 고정된 차원(라마 2 13B는 2100번과 4743번)에 주로 시작 토큰에서 나타나고, 입력과 거의 무관하게 일정해 편향처럼 작동한다.

모든 토큰에서 7번 채널만 값이 A인 가상의 활성값으로, 토큰별 스케일(행마다 하나)과 채널별 스케일(열마다 하나)의 INT8 양자화를 비교한다. 평가는 7번 채널을 뺀 나머지 값으로 한다. 위 코드에 이어서 실행한다.
```python
X = rng.normal(size=(256, 4096))           # 토큰 256개 × 채널 4096
other = np.arange(4096) != 7               # 7번 채널을 뺀 나머지
for A in [0, 20, 100, 1000]:
    Xo = X.copy()
    if A:
        Xo[:, 7] = A                   # 7번 채널: 모든 토큰에서 큰 값
    tok = q_sym(Xo, 8, axis=1)             # 토큰별 스케일
    ch = q_sym(Xo, 8, axis=0)              # 채널별 스케일
    used = len(np.unique(tok[0, other]))  # 토큰 0에서 쓰인 격자 값 수
    zero = np.mean(tok[:, other] == 0)
    print(f"A={A:4d}: 토큰별 {sqnr(X[:, other], tok[:, other]):4.1f}dB "
          f"(값 {used:3d}개, 0 {zero:4.0%}), "
          f"채널별 {sqnr(X[:, other], ch[:, other]):4.1f}dB")
```
```text
A=   0: 토큰별 41.2dB (값 192개, 0   1%), 채널별 43.1dB
A=  20: 토큰별 26.8dB (값  47개, 0   6%), 채널별 43.1dB
A= 100: 토큰별 12.9dB (값  10개, 0  31%), 채널별 43.1dB
A=1000: 토큰별  0.0dB (값   2개, 0 100%), 채널별 43.1dB
```

A = 100이면 Δ = 100/127 ≈ 0.79σ라 토큰 하나의 나머지 4,095개 값이 255칸 중 10칸에 몰리고, 전체의 31%가 0이 된다. 8비트를 쓰고도 SQNR은 4비트 수준(12.9dB)이다. Massive Activations 규모인 A = 1000에서는 Δ ≈ 7.9σ라 사실상 모든 값이 0이 되어 정보가 전부 사라진다. 채널별 스케일은 이상치를 자기 열에 가두므로 A와 무관하게 43.1dB다.

문제는 채널별 활성값 스케일을 행렬 곱에서 공짜로 쓸 수 없다는 것이다. `y_j = Σ_k x_k · W_kj`에서 활성값의 채널은 합의 인덱스 k이므로, 1편에서 본 것처럼 k에 따라 달라지는 스케일은 정수 합 밖으로 빼낼 수 없다. 그래서 이상치 채널만 따로 16비트로 곱하거나(LLM.int8()), 채널 스케일을 가중치 쪽으로 옮기거나(SmoothQuant), 회전으로 이상치를 여러 채널에 퍼뜨린다(QuaRot 등). 모두 10편 「이상치 다루기: LLM.int8(), SmoothQuant, 회전」의 주제다.

## 세분도: 텐서별, 채널별, 그룹별
가중치는 형편이 낫다. `W_kj`의 출력 채널 j는 합 밖에 있으므로 채널별 스케일은 정수 행렬 곱에서도 공짜다. 더 잘게, 입력 방향 g개마다 스케일을 두는 **그룹별** 양자화도 많이 쓴다. 이 스케일은 합 안에 있지만, 가중치 전용(W4A16) 커널은 어차피 가중치를 그룹 단위로 BF16으로 되돌려 곱하므로 문제가 없다. 출력 채널마다 크기가 다르고 꼬리가 조금 두꺼운(t 분포, ν = 6) 가상의 가중치로 INT4 세분도를 비교한다. 스케일은 FP16(16비트)으로 저장한다고 보고 값당 비트를 함께 적는다.
```python
row = np.exp(0.5 * rng.normal(size=(1024, 1)))   # 출력 채널마다 다른 크기
W = rng.standard_t(6, size=(1024, 4096)) * row * 0.02

def q_group(W, g):                         # 입력 방향 g개마다 스케일 하나
    return q_sym(W.reshape(-1, g), 4, axis=1).reshape(W.shape)

print(f"텐서별   4.0000비트 {sqnr(W, q_sym(W, 4)):5.2f}dB")
print(f"채널별   {4 + 16 / 4096:.4f}비트 {sqnr(W, q_sym(W, 4, axis=1)):5.2f}dB")
for g in [256, 128, 64, 32]:
    print(f"그룹 {g:3d} {4 + 16 / g:.4f}비트 "
          f"{sqnr(W, q_group(W, g)):5.2f}dB")
```
```text
텐서별   4.0000비트  1.98dB
채널별   4.0039비트 10.50dB
그룹 256 4.0625비트 14.76dB
그룹 128 4.1250비트 15.96dB
그룹  64 4.2500비트 17.25dB
그룹  32 4.5000비트 18.65dB
```

텐서별 스케일은 큰 채널의 최댓값에 끌려 2dB에 그치고, 채널별로 나누면 10.5dB, 그룹 128이면 16.0dB다. 그룹을 절반으로 줄일 때마다 1.2~1.4dB씩 오르지만 비용 16/g는 두 배가 되어 이득이 점점 줄어든다. 그룹이 작을수록 최댓값이 전형적인 값에 가까워지는 효과가 천천히 포화하기 때문이다. 저장 비용을 계산하면 이렇다.
- 그룹 128, FP16 스케일: 값당 16/128 = 0.125비트. 8B 모델이면 4.0GB가 4.125GB가 된다(+125MB). 그룹 32면 +0.5비트(+500MB)다.
- 비대칭이라 4비트 영점까지 저장하면 4 + (16 + 4)/128 ≈ 4.156비트다.
- QLoRA는 값 64개마다 FP32 상수를 두어 0.5비트를 더 쓰는 대신, 그 상수를 다시 8비트(블록 256)로 양자화하는 이중 양자화로 8/64 + 32/(64·256) ≈ 0.127비트까지 줄였다. 논문이 말하는 약 0.37비트 절약이 이 차이다.

GPTQ·AWQ(11편) 같은 4비트 가중치 양자화에서는 그룹 128이 흔히 쓰는 기본값이다. 0.125비트로 SQNR을 몇 dB 사는 거래가 대체로 이득이기 때문이다.

## 분포를 보고 격자 고르기
균일 격자는 모든 구간에 같은 칸을 준다. 값이 몰린 곳에 칸을 더 주면 같은 비트로 오차가 준다. 1편의 MSE가 칸마다 Δ²/12이므로, 격자 밀도를 λ(x), 데이터 밀도를 p(x)라 하면 전체 MSE는 `≈ (1/12)·∫ p(x)/λ(x)² dx`이고, 칸 수를 고정한 채 이를 최소화하면 λ ∝ p^(1/3)이 나온다. 정규 분포처럼 0 근처가 빽빽한 분포에는 0 근처가 촘촘한 격자가, 균일 분포에는 균일 격자가 맞는다. 2편의 4비트 격자 세 가지를 블록 64개 absmax로 세 분포에 적용해 보자.
```python
grids = {"INT4": np.arange(-7, 8) / 7,
         "E2M1": np.array([-6, -4, -3, -2, -1.5, -1, -.5, 0,
                           .5, 1, 1.5, 2, 3, 4, 6]) / 6,
         "NF4": np.array([-1, -.6962, -.5251, -.3949, -.2844, -.1848,
                          -.0911, 0, .0796, .1609, .2461, .3379,
                          .4407, .5626, .7230, 1])}
def q_lut(x, grid, g=64):                  # 블록 absmax로 [−1, 1]에 맞춘 뒤
    b = x.reshape(-1, g)                   # 가장 가까운 격자 값으로
    s = np.abs(b).max(axis=1, keepdims=True)
    i = np.abs(b[..., None] / s[..., None] - grid).argmin(axis=-1)
    return (grid[i] * s).ravel()

for name, x in [("균일", rng.uniform(-1, 1, 2**18)),
                ("정규", rng.normal(size=2**18)),
                ("라플라스", rng.laplace(size=2**18))]:
    r = "  ".join(f"{k} {sqnr(x, q_lut(x, g)):5.2f}" for k, g in grids.items())
    print(f"{name:4s} {r}")
```
```text
균일   INT4 23.13  E2M1 19.35  NF4 20.79
정규   INT4 19.33  E2M1 19.55  NF4 20.73
라플라스 INT4 17.06  E2M1 18.99  NF4 19.69
```

균일 분포에서는 INT4가 23.1dB로 가장 좋고, 정규 분포에서는 NF4가 INT4보다 1.4dB, 라플라스 분포에서는 2.6dB 앞선다. 고르는 법을 정리하면 이렇다.
- 0 중심 종 모양(가중치): NF4나 E2M1처럼 0 근처가 촘촘한 격자. NF4는 조회 표로 역양자화하므로 주로 가중치 전용 저장에 쓴다.
- 균일에 가까운 분포: INT 격자. 정수 텐서 코어로 바로 곱할 수 있다는 장점도 있다.
- 크기가 여러 자릿수에 걸친 분포(활성값, 기울기): FP8 같은 부동소수점 격자(2편).
- 어떤 격자든 이상치는 따로 다뤄야 한다. 격자 모양보다 최대/σ가 SQNR을 더 크게 좌우한다.

## 어디에 쓰이나
- 통계학 1편 「기술 통계: 데이터를 숫자 몇 개로 요약하기」: 이상치 하나가 평균을 크게 흔들듯, absmax 스케일은 최댓값 하나에 전체 격자가 끌려간다.
- 확률과 분포 8편 「정규 분포: 종 모양 곡선의 정체」: 가중치 분포의 기준이 정규 분포이고, NF4는 그 분위수로 만든 격자다.
- 10편 「이상치 다루기: LLM.int8(), SmoothQuant, 회전」: 합의 인덱스에 걸린 채널별 이상치를 정수 행렬 곱 안에서 처리하는 방법들이다.

## 정리
- absmax 양자화의 SQNR은 `10·log₁₀(12·qmax²) − 20·log₁₀(M/σ)`라, 최대/RMS 비율이 2배가 될 때마다 비트 하나를 잃는다.
- 가중치는 0 중심 종 모양이지만 채널마다 크기가 다르고, 활성값은 특정 채널에 큰 이상치(LLM.int8(), Massive Activations)가 있어 토큰별 스케일로는 나머지 값이 0으로 뭉개진다.
- 가중치는 채널별·그룹별 스케일로 해결하고(그룹 128 = 값당 +0.125비트), 활성값의 채널별 스케일은 정수 합 밖으로 뺄 수 없어 별도 기법이 필요하다.
- 종 모양에는 NF4·E2M1, 균일에는 INT, 넓은 범위에는 FP 격자가 맞는다.
