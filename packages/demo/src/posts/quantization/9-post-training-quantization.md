# [양자화 9/15] 학습 후 양자화의 기본: 반올림, 클리핑, 비균일 격자

> **한 줄 요약** — 학습 후 양자화(PTQ)는 다 학습한 모델을 적은 보정 데이터만으로 양자화하는 방법이고, 그 기본 부품은 가장 가까운 격자점으로 반올림하기(RTN), 클리핑 오차와 반올림 오차가 맞서는 지점에서 범위를 고르기(MSE 최소 탐색), 그리고 값이 많은 곳에 격자점을 촘촘히 두는 비균일 격자(로이드-맥스, NF4)다.

- 비균일 격자: 로이드-맥스와 NF4를 직접 만들어 균일 격자와 비교

## PTQ와 QAT
**학습 후 양자화**(post-training quantization, PTQ)는 학습이 끝난 가중치를 그대로 두고 양자화 방법만 고른다. 역전파가 없어서 큰 모델도 GPU 몇 시간이면 끝난다. **양자화 인식 학습**(quantization-aware training, QAT)은 순전파에 양자화를 넣고 학습을 계속해 가중치가 격자에 맞게 움직이게 한다. 정확도는 더 좋지만 학습 데이터와 학습 비용이 든다(13편).

PTQ에도 데이터가 조금 필요하다. 활성값의 범위는 입력이 들어와 봐야 알 수 있고, 11편의 GPTQ·AWQ는 층의 입력 통계를 쓴다. 이 용도로 쓰는 수백~수천 개 샘플을 **보정 데이터**(calibration data)라 한다. 보정 데이터의 분포가 실제 사용 분포와 다르면 고른 범위와 통계도 어긋난다.

## RTN과 클리핑 범위 고르기
가장 단순한 PTQ는 **RTN**(round-to-nearest)이다. 범위 [−c, c]를 정하고 1편의 대칭 양자화를 그대로 한다.
```text
s = c / Q,  q = clip(round(x/s), −Q, Q),  x̂ = s·q     (b비트면 Q = 2^(b−1) − 1)
```

c를 정하는 순간 오차가 두 종류로 갈린다. ∣x∣ ≤ c인 값은 간격 Δ = c/Q의 반올림 오차(1편의 Δ²/12)를, ∣x∣ > c인 값은 c로 잘리는 클리핑 오차를 받는다.
```text
MSE(c) ≈ (c/Q)²/12 · P(∣x∣ ≤ c) + E[(∣x∣ − c)² ; ∣x∣ > c]
```

c를 키우면 앞 항이 c²에 비례해 커지고, 줄이면 뒤 항이 커진다. 꼬리가 두꺼운 라플라스 분포에서 4비트로 c를 고르는 네 가지 방법을 비교한다. 데이터는 현상을 보이기 위한 가상의 값이다.
```python
import numpy as np

rng = np.random.default_rng(0)
x = rng.laplace(size=200_000)               # 꼬리가 두꺼운 가상의 가중치

def quant(x, c, bits=4):                    # 대칭 균일 격자, 범위 [−c, c]
    qmax = 2 ** (bits - 1) - 1
    s = c / qmax
    return np.clip(np.round(x / s), -qmax, qmax) * s

def parts(x, c):
    e = quant(x, c) - x
    out = np.abs(x) > c
    return (e[out] ** 2).sum() / x.size, (e[~out] ** 2).sum() / x.size

amax = np.abs(x).max()
cands = {"absmax": amax,
         "99.99%": np.quantile(np.abs(x), 0.9999),
         "99.9%": np.quantile(np.abs(x), 0.999)}
grid = np.linspace(0.05, 1, 400) * amax     # MSE 최소 탐색
mse = [np.mean((quant(x, c) - x) ** 2) for c in grid]
cands["MSE 탐색"] = grid[np.argmin(mse)]
for name, c in cands.items():
    clip, rnd = parts(x, c)
    print(f"{name:7s} c={c:5.2f}  클리핑 {clip:.4f} + 반올림 {rnd:.4f}"
          f" = {clip + rnd:.4f}")
```
```text
absmax  c=13.50  클리핑 0.0000 + 반올림 0.2778 = 0.2778
99.99%  c= 9.64  클리핑 0.0002 + 반올림 0.1499 = 0.1501
99.9%   c= 7.02  클리핑 0.0023 + 반올림 0.0814 = 0.0837
MSE 탐색  c= 4.85  클리핑 0.0173 + 반올림 0.0391 = 0.0564
```

absmax는 20만 개 중 가장 큰 값 13.5에 맞추느라 간격이 1.93이 되어 반올림 오차만 0.278이다. MSE 탐색은 c = 4.85(표준편차 √2의 약 3.4배)에서 일부러 0.0173만큼 잘라 내고 반올림 오차를 0.0391로 줄여 전체 오차를 absmax의 약 5분의 1로 만든다. 이때 Δ = 4.85/7 = 0.693이고 Δ²/12 = 0.0400에 P(∣x∣ ≤ c) ≈ 0.992를 곱하면 0.0397로 측정값과 맞는다. 엔비디아의 정수 양자화 백서(Wu 등, 2020)도 보정 방법으로 최댓값, KL 발산을 최소화하는 엔트로피 방법, 백분위를 비교한다.

단, MSE는 값 하나하나를 똑같이 취급한다. 3편에서 본 활성값의 이상치처럼 드물지만 출력에 결정적인 값을 잘라 내면 MSE는 작아도 모델은 망가진다. 이상치를 따로 다루는 방법이 10편, 값이 아니라 층의 출력 오차를 줄이는 방법이 11편이다.

## 확률적 반올림
**확률적 반올림**(stochastic rounding)은 소수 부분 f = x − ⌊x⌋의 확률로 올리고 1 − f의 확률로 내린다. 기댓값이 `E[SR(x)] = (1 − f)⌊x⌋ + f(⌊x⌋ + 1) = x`라 편향이 없다. 대신 분산이 생겨 제곱 오차의 기댓값은 f(1 − f)로, RTN의 min(f, 1 − f)²보다 크다.
```python
def stoch_round(x):                         # 올림 확률 = 소수 부분
    f = np.floor(x)
    return f + (rng.random(x.shape) < x - f)

x = np.full(100_000, 0.3)                   # 격자 간격의 0.3배인 값
for name, q in [("RTN", np.round(x)), ("확률적", stoch_round(x))]:
    print(f"{name}: 평균 {q.mean():.4f}, MSE {np.mean((q - x) ** 2):.4f}")
```
```text
RTN: 평균 0.0000, MSE 0.0900
확률적: 평균 0.3000, MSE 0.2100
```

RTN은 0.3을 모두 0으로 만들어 평균까지 사라지고, 확률적 반올림은 평균 0.3000을 지키는 대신 MSE가 0.21(= 0.3 × 0.7)로 두 배를 넘는다. 그래서 추론용 가중치에는 RTN을 쓰고, 확률적 반올림은 작은 갱신이 반올림에 계속 지워지는 저정밀 학습의 가중치 갱신처럼 편향이 쌓이는 곳에 쓴다.

## 비균일 격자: 로이드-맥스와 NF4
값이 0 근처에 몰려 있는데 격자 간격이 일정하면 드문 큰 값 쪽 칸이 낭비된다. 레벨 수가 정해졌을 때 MSE를 최소로 하는 격자는 두 조건을 만족한다. 경계는 이웃한 두 레벨의 중점이고(가장 가까운 레벨로 보내야 하므로), 각 레벨은 자기 칸에 들어온 값들의 평균이다(칸 안에서 제곱 오차를 최소로 하는 점). 두 조건을 번갈아 적용하는 것이 **로이드-맥스 양자화기**(Lloyd-Max quantizer)이고, 1차원 k-평균과 같은 알고리즘이다.

**NF4**(4-bit NormalFloat)는 QLoRA 논문(Dettmers 등, 2023)이 정규 분포 가중치를 위해 만든 고정 격자다. 표준 정규 분포의 분위수에 레벨을 놓아 각 레벨이 비슷한 확률을 갖게 하고, 0을 정확히 표현하려고 양수 쪽 8개, 음수 쪽 7개 분위수와 0을 합친 뒤 [−1, 1]로 정규화한다. 가중치는 64개 블록마다 absmax로 나눠 [−1, 1]에 맞춘 뒤 이 16개 값 중 가장 가까운 것으로 보낸다. `scipy.stats.norm.ppf`(누적 분포의 역함수)로 직접 만들어 비교한다.
```python
from scipy.stats import norm

off = 0.5 * (1 - 1 / 30 + 1 - 1 / 32)       # ≈ 0.9677, 맨 끝 분위수
pos = norm.ppf(np.linspace(off, 0.5, 9)[:-1])
neg = -norm.ppf(np.linspace(off, 0.5, 8)[:-1])
nf4 = np.sort(np.concatenate([pos, [0.0], neg]))
nf4 /= nf4.max()
print(len(nf4), nf4[:3].round(4), nf4[-3:].round(4))

def lloyd_max(x, k, iters=100):             # 1차원 k-평균
    c = np.quantile(x, (np.arange(k) + 0.5) / k)
    for _ in range(iters):
        idx = np.abs(x[:, None] - c).argmin(1)    # 경계 = 중점
        c = np.array([x[idx == j].mean() for j in range(k)])  # 무게중심
    return np.sort(c)

def snap(x, levels):                        # 가장 가까운 격자점
    edges = (levels[1:] + levels[:-1]) / 2
    return levels[np.searchsorted(edges, x)]

w = rng.normal(size=(4096, 64))             # 가상의 가중치, 블록 64개씩
s = np.abs(w).max(1, keepdims=True)         # 블록별 absmax 스케일
u = w / s                                   # [−1, 1]로 정규화
grids = {"INT4 대칭": np.arange(-7, 8) / 7,
         "균일 16칸": np.linspace(-1, 1, 16),
         "NF4": nf4,
         "로이드-맥스": lloyd_max(u.ravel()[:60000], 16)}
for name, g in grids.items():
    err = np.mean((snap(u, g) * s - w) ** 2)
    print(f"{name}: 칸 {len(g)}, MSE {err:.5f}")
```
```text
16 [-1.     -0.6962 -0.5251] [0.5626 0.723  1.    ]
INT4 대칭: 칸 15, MSE 0.01161
균일 16칸: 칸 16, MSE 0.01015
NF4: 칸 16, MSE 0.00846
로이드-맥스: 칸 16, MSE 0.00767
```

만든 값 −0.6962, −0.5251, 0.5626, 0.7230은 QLoRA가 공개한 NF4 표의 값과 같다. 같은 16칸에서 NF4의 MSE는 균일 격자의 83%이고, 이 데이터에 맞춰 학습한 로이드-맥스는 76%로 더 낮다. NF4가 최적이 아닌 이유는 "칸마다 같은 확률"이 MSE 최소 조건과 다르기 때문이다. 같은 확률은 코드의 엔트로피를 4비트에 가깝게 채우는 기준이고, 로이드-맥스는 값과 레벨의 거리까지 따진다. 그래도 NF4는 데이터와 무관한 고정 표라 블록마다 코드북을 저장할 필요가 없다.

비균일 격자의 대가는 계산이다. 균일 격자는 정수끼리 곱하고 스케일만 되돌리면 되지만(1편), NF4 같은 표는 정수 연산에 바로 쓸 수 없어 조회 표로 역양자화한 뒤 16비트로 곱한다. 그래서 비균일 격자는 메모리를 줄이는 가중치 전용(W4A16) 양자화에 주로 쓰이고, 행렬 곱 자체를 빠르게 하는 W8A8에는 균일 정수나 FP8을 쓴다(12편).

## 벡터 양자화와 코드북
지금까지는 값 하나씩 격자에 올리는 **스칼라 양자화**였다. **벡터 양자화**(vector quantization)는 값 d개를 묶어 2^(b·d)개짜리 코드북의 가장 가까운 벡터로 보낸다. 같은 비트로도 공간을 더 촘촘히 채울 수 있고 값 사이의 상관도 이용한다. QuIP#는 무작위 아다마르 변환으로 가중치를 공 모양 분포로 고르게 만든 뒤 8차원 격자 E8로 만든 코드북을 써서 값당 2비트까지 내려가고, AQLM은 여러 코드북의 코드워드를 더해 한 묶음을 표현하는 가산 양자화를 쓴다. 회전으로 분포를 고르게 만드는 원리는 10편에서 본다.

## 어디에 쓰이나
- 확률과 분포 8편 「정규 분포: 종 모양 곡선의 정체」: NF4는 정규 분포의 누적 분포 함수를 거꾸로 읽어(분위수) 레벨을 정한 격자다.
- 확률과 분포 4편 「확률 변수와 기댓값」: 확률적 반올림이 편향이 없다는 것은 E[SR(x)] = x라는 기댓값 계산 한 줄로 증명된다.
- 정보 이론 1편 「정보량과 엔트로피」: 칸마다 확률이 같으면 코드의 엔트로피가 최대가 되어 4비트를 모두 정보로 쓴다는 것이 NF4의 설계 기준이다.
- 13편 「양자화 인식 학습과 극단적 저비트: QAT, QLoRA, BitNet」: QLoRA는 이 글의 NF4로 기반 모델을 얼려 두고 어댑터만 학습한다.

## 정리
- PTQ는 학습 없이 보정 데이터 몇백 개로 양자화하고, QAT는 양자화를 넣고 학습을 계속한다.
- 클리핑 범위는 반올림 오차(∝ c²)와 클리핑 오차의 절충이다. 라플라스 데이터 4비트에서 MSE 탐색은 absmax보다 오차가 약 5분의 1이었다.
- 확률적 반올림은 편향이 없지만 MSE가 RTN보다 커서 학습의 누적 갱신에 맞다.
- 비균일 격자(NF4, 로이드-맥스)는 같은 16칸에서 균일 격자보다 MSE가 17~24% 작지만, 조회 표로 역양자화해야 해서 주로 가중치 전용 양자화에 쓴다.
