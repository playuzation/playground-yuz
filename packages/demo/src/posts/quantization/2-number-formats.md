# [양자화 2/15] 수 형식의 지도: FP32에서 FP4까지

> **한 줄 요약** — 부동소수점은 지수 비트로 범위를, 가수 비트로 상대 정밀도를 사는 형식이라 값의 간격이 크기에 비례해 커지는 로그형 격자이고, 정수는 간격이 일정한 균일 격자이며, FP4처럼 비트가 아주 적은 형식은 블록마다 스케일을 붙여(MXFP4, NVFP4) 좁은 범위를 보완한다.

## 이 글에서 다루는 것
- 부동소수점의 구조: 부호, 지수, 가수, 바이어스, 서브노멀
- FP32·FP16·BF16·FP8(E4M3, E5M2)·FP4(E2M1)의 값을 직접 나열하기
- 간격(ULP)이 지수적으로 커지는 격자 vs 정수의 균일 격자
- 4비트 격자 세 가지: INT4, FP4, NF4
- 블록 스케일 형식: MXFP4와 NVFP4

## 부동소수점의 구조
부호 1비트, 지수 E비트, 가수 M비트인 형식을 ExMy로 적는다. 지수 필드 e와 가수 필드 m은 부호 없는 2진 정수이고, 값은 이렇게 정해진다.
```text
노멀(e ≠ 0):     (−1)ˢ × 2^(e − bias) × (1 + m/2ᴹ)
서브노멀(e = 0): (−1)ˢ × 2^(1 − bias) × (m/2ᴹ)
bias = 2^(E−1) − 1
```

노멀 값은 맨 앞의 1을 저장하지 않는다(숨은 비트). 구간 [2ᵏ, 2ᵏ⁺¹) 하나에 값이 2ᴹ개 같은 간격으로 놓이므로 간격(ULP, unit in the last place)은 2^(k−M)이고, 상대 간격은 구간 안에서 2^(−M−1)과 2^(−M) 사이에 머문다. 지수 비트는 구간의 개수(범위)를, 가수 비트는 구간 안의 촘촘함(상대 정밀도)을 정한다. 가장 작은 노멀 값 아래는 서브노멀이 균일한 간격으로 0까지 메운다.

특수 값은 형식마다 다르다. FP32·FP16·BF16·E5M2는 IEEE 754처럼 최상위 지수를 무한대와 NaN에 쓰고, FP8 형식 논문(Micikevicius 등, 2022)의 E4M3는 무한대를 버리고 S.1111.111만 NaN으로 남겨 범위를 넓혔다. FP4 E2M1에는 특수 값이 없다.

## 값을 직접 나열해 보기
모든 비트 패턴을 위 식에 넣어 값을 전부 만들고, FP16은 NumPy의 `float16`과 맞춰 본다.
```python
import numpy as np

def fp_values(E, M, special="ieee"):
    # 부호를 뺀 유한 값 전부(0 포함)
    bias, top = 2 ** (E - 1) - 1, 2 ** E - 1
    vals = []
    for e in range(2 ** E):
        for m in range(2 ** M):
            if special == "ieee" and e == top:
                continue                      # 최상위 지수는 ∞·NaN
            if special == "fn" and e == top and m == 2 ** M - 1:
                continue                      # E4M3: S.1111.111만 NaN
            if e == 0:                        # 서브노멀
                vals.append(2.0 ** (1 - bias) * m / 2 ** M)
            else:                             # 노멀
                vals.append(2.0 ** (e - bias) * (1 + m / 2 ** M))
    return np.array(sorted(vals))

fmts = {"FP16": (5, 10, "ieee"), "BF16": (8, 7, "ieee"),
        "E5M2": (5, 2, "ieee"), "E4M3": (4, 3, "fn"), "E2M1": (2, 1, "none")}
G = {k: fp_values(*v) for k, v in fmts.items()}
for k, (E, M, _) in fmts.items():
    v = G[k]
    print(f"{k}: 양수 {len(v) - 1:5d}개, 최댓값 {v[-1]:.6g}, "
          f"최소 노멀 {2.0 ** (2 - 2 ** (E - 1)):.3g}, 최소 {v[1]:.3g}")
f16 = np.finfo(np.float16)
print("float16:", float(f16.max), float(f16.smallest_normal),
      float(f16.smallest_subnormal))
```
```text
FP16: 양수 31743개, 최댓값 65504, 최소 노멀 6.1e-05, 최소 5.96e-08
BF16: 양수 32639개, 최댓값 3.38953e+38, 최소 노멀 1.18e-38, 최소 9.18e-41
E5M2: 양수   123개, 최댓값 57344, 최소 노멀 6.1e-05, 최소 1.53e-05
E4M3: 양수   126개, 최댓값 448, 최소 노멀 0.0156, 최소 0.00195
E2M1: 양수     7개, 최댓값 6, 최소 노멀 1, 최소 0.5
float16: 65504.0 6.103515625e-05 5.960464477539063e-08
```

FP16의 세 값이 NumPy와 일치하고, E4M3의 최댓값 1.75 × 2⁸ = 448과 E5M2의 1.75 × 2¹⁵ = 57,344도 FP8 논문의 정의대로 나온다. FP32까지 정리하면 이렇다.

| 형식 | 지수·가수 | 최댓값 | 2⁻ᴹ |
|---|---|---|---|
| FP32 | 8·23 | 3.40×10³⁸ | 1.2×10⁻⁷ |
| FP16 | 5·10 | 65,504 | 9.8×10⁻⁴ |
| BF16 | 8·7 | 3.39×10³⁸ | 7.8×10⁻³ |
| E5M2 | 5·2 | 57,344 | 0.25 |
| E4M3 | 4·3 | 448 | 0.125 |
| E2M1 | 2·1 | 6 | 0.5 |

같은 16비트라도 FP16은 정밀도를, BF16은 범위를 택했다. BF16은 FP32의 위쪽 16비트와 같은 구조라, 큰 값이 65,504를 넘어 무한대가 되는 FP16의 넘침 문제가 없다. FP8 논문은 정밀도가 높은 E4M3를 가중치와 활성값에, 범위가 넓은 E5M2를 기울기에 쓰라고 권한다. INT8(−128~127)과 INT4(−8~7)는 지수가 없는 고정 간격 격자이고 실제 크기는 1편의 스케일이 정한다.

## 간격이 크기에 비례한다
E4M3에서 이웃 값 사이의 간격을 크기별로 본다. 위 코드에 이어서 실행한다.
```python
v = G["E4M3"]
gap = np.diff(v)                          # 이웃 값 사이 간격(ULP)
for lo in [2.0 ** -9, 2.0 ** -6, 1, 2, 128, 256]:
    i = np.searchsorted(v, lo)
    print(f"x = {v[i]:<9.6g} 다음 값까지 {gap[i]:<9.6g} "
          f"상대 간격 {gap[i] / v[i]:.3f}")
```
```text
x = 0.00195312 다음 값까지 0.00195312 상대 간격 1.000
x = 0.015625  다음 값까지 0.00195312 상대 간격 0.125
x = 1         다음 값까지 0.125     상대 간격 0.125
x = 2         다음 값까지 0.25      상대 간격 0.125
x = 128       다음 값까지 16        상대 간격 0.125
x = 256       다음 값까지 32        상대 간격 0.125
```

절대 간격은 0.002에서 32까지 구간마다 2배씩 커지지만, 각 구간 시작에서의 상대 간격은 2⁻³ = 0.125로 같다. 로그 눈금에 가까운 격자다. 서브노멀 영역(0.0156 아래)만 간격이 0.00195로 균일하다. 정수 격자는 반대로 절대 간격 Δ가 일정해서 상대 간격 Δ/∣x∣가 0에 가까울수록 커진다. 크기가 네 자릿수에 걸쳐 고르게 퍼진 값과, 정규 분포·두꺼운 꼬리 분포를 INT8과 E4M3로 각각 양자화해 비교하자. 둘 다 최대 ∣x∣를 격자 끝(127, 448)에 맞춘다.
```python
def to_grid(x, pos):                     # 가장 가까운 표현 가능 값으로
    g = np.concatenate([-pos[::-1], pos])
    i = np.clip(np.searchsorted(g, x), 1, len(g) - 1)
    return np.where(x - g[i - 1] < g[i] - x, g[i - 1], g[i])

def q_int8(x):
    s = np.abs(x).max() / 127
    return np.round(x / s) * s

def q_fp8(x):
    s = np.abs(x).max() / 448
    return to_grid(x / s, G["E4M3"]) * s

rng = np.random.default_rng(0)
x = rng.choice([-1, 1], 200_000) * 10 ** rng.uniform(-4, 0, 200_000)
for lo in range(-4, 0):                  # 크기 구간별 상대 오차 중앙값
    m = (np.abs(x) >= 10.0 ** lo) & (np.abs(x) < 10.0 ** (lo + 1))
    ri = np.median(np.abs(q_int8(x)[m] - x[m]) / np.abs(x[m]))
    rf = np.median(np.abs(q_fp8(x)[m] - x[m]) / np.abs(x[m]))
    print(f"∣x∣ ∈ [1e{lo}, 1e{lo + 1}): INT8 {ri:7.2%}  E4M3 {rf:6.2%}")

sq = lambda x, xh: 10 * np.log10(np.mean(x**2) / np.mean((xh - x) ** 2))
for name, y in [("정규", rng.normal(size=200_000)),
                ("t(ν=2)", rng.standard_t(2, size=200_000))]:
    print(f"{name}: INT8 {sq(y, q_int8(y)):.1f}dB, "
          f"E4M3 {sq(y, q_fp8(y)):.1f}dB")
```
```text
∣x∣ ∈ [1e-4, 1e-3): INT8 100.00%  E4M3  2.14%
∣x∣ ∈ [1e-3, 1e-2): INT8 100.00%  E4M3  2.19%
∣x∣ ∈ [1e-2, 1e-1): INT8   5.35%  E4M3  2.17%
∣x∣ ∈ [1e-1, 1e0): INT8   0.52%  E4M3  2.17%
정규: INT8 39.7dB, E4M3 31.6dB
t(ν=2): INT8 13.5dB, E4M3 31.9dB
```

E4M3의 상대 오차는 네 자릿수 내내 약 2.2%로 일정하다. INT8은 큰 값에서 0.52%로 훨씬 정확하지만 Δ/2 = 1/254보다 작은 값은 모두 0이 된다. 그래서 FP8이 INT8보다 항상 낫지는 않다. 값이 몇 σ 안에 모인 정규 분포에서는 INT8이 8dB 앞서고, 아주 큰 값이 드물게 섞인 t 분포(자유도 2)에서는 INT8이 거대한 최댓값 때문에 13.5dB로 무너지는 반면 E4M3는 31.9dB를 유지한다. 격자 모양을 분포에 맞추는 문제는 3편 「가중치와 활성값의 분포: 이상치가 비트를 낭비하는 이유」에서 이어진다.

## 4비트 격자 세 가지
4비트면 값이 16개뿐이라 어디에 놓느냐가 전부다. [−1, 1]로 정규화한 세 격자를 비교한다. **NF4**(4-bit NormalFloat)는 QLoRA 논문(Dettmers 등, 2023)이 제안한 형식으로, 표준 정규 분포의 분위수에 값을 놓아, 정규 분포를 따르는 가중치라면 각 칸에 같은 수의 값이 들어가게 만든 격자다. 정확한 0을 포함하고 음수 7개, 양수 8개다. 만드는 법은 9편 「학습 후 양자화의 기본: 반올림, 클리핑, 비균일 격자」에서 다룬다.
```python
nf4 = np.array([-1, -.6962, -.5251, -.3949, -.2844, -.1848, -.0911, 0,
                .0796, .1609, .2461, .3379, .4407, .5626, .7230, 1])
int4 = np.arange(-7, 8) / 7
fp4 = np.concatenate([-G["E2M1"][:0:-1], G["E2M1"]]) / 6
for name, g in [("INT4", int4), ("FP4 E2M1", fp4), ("NF4", nf4)]:
    d = np.diff(g)
    print(f"{name:8s} 값 {len(g)}개, 간격 {d.min():.3f} ~ {d.max():.3f}")
```
```text
INT4     값 15개, 간격 0.143 ~ 0.143
FP4 E2M1 값 15개, 간격 0.083 ~ 0.333
NF4      값 16개, 간격 0.080 ~ 0.304
```

INT4는 균일하고, E2M1({0, 0.5, 1, 1.5, 2, 3, 4, 6})과 NF4는 0 근처가 촘촘하고 끝으로 갈수록 성기다. NF4 값은 산술 형식이 아니라서 조회 표로 역양자화한 뒤 BF16으로 곱한다.

## 블록 스케일 형식: MXFP4와 NVFP4
E2M1의 0이 아닌 값은 0.5~6으로 최대/최소 비율이 12배(2배 구간 약 3.6개)뿐이다. 범위가 이렇게 좁으면 스케일이 데이터를 가까이 따라가야 하므로 작은 블록마다 스케일을 둔다.
- **MXFP4**: OCP의 마이크로스케일링(MX) 규격(MX 형식 논문, Rouhani 등, 2023). 값 32개가 E8M0 스케일 하나를 공유한다. E8M0는 지수만 있는 8비트라 2의 거듭제곱만 표현한다. 논문의 변환 절차는 `X = 2^(floor(log₂ max∣v∣) − 2)`(2는 E2M1의 최대 지수)로 스케일을 정하고, v/X를 E2M1로 반올림하되 넘는 값은 최댓값으로 포화시킨다. 값당 4 + 8/32 = 4.25비트다.
- **NVFP4**: 엔비디아 블랙웰(Blackwell) GPU의 형식. 값 16개가 FP8 E4M3 스케일을 공유하고, 텐서 전체에 FP32 스케일이 하나 더 있다. E4M3 스케일은 2의 거듭제곱이 아닌 값도 되며, 값당 4 + 8/16 = 4.5비트다.

행(채널)마다 크기가 다른 가상의 가중치로 비교한다.
```python
e2m1 = G["E2M1"]
def fp4_tensor(x):                         # 텐서 전체에 스케일 하나
    s = np.abs(x).max() / 6
    return to_grid(x / s, e2m1) * s

def mxfp4(x):                              # 32개 블록, 2의 거듭제곱 스케일
    b = x.reshape(-1, 32)
    amax = np.abs(b).max(axis=1, keepdims=True)
    X = 2.0 ** (np.floor(np.log2(amax)) - 2)
    return (to_grid(b / X, e2m1) * X).ravel()  # 6 초과는 6으로

def nvfp4(x):                              # 16개 블록, E4M3 스케일
    b = x.reshape(-1, 16)
    g = np.abs(x).max() / (448 * 6)        # FP32 텐서 스케일
    amax = np.abs(b).max(axis=1, keepdims=True)
    s = to_grid(amax / 6 / g, G["E4M3"]) * g
    return (to_grid(b / s, e2m1) * s).ravel()

row = np.exp(rng.normal(size=4096))        # 행마다 다른 크기
w = (rng.normal(size=(4096, 256)) * row[:, None]).ravel()
for name, f, bits in [("FP4 텐서별", fp4_tensor, 4), ("MXFP4", mxfp4, 4.25),
                      ("NVFP4", nvfp4, 4.5)]:
    print(f"{name:9s} 값당 {bits:.2f}비트, SQNR {sq(w, f(w)):.1f}dB")
```
```text
FP4 텐서별   값당 4.00비트, SQNR 4.4dB
MXFP4     값당 4.25비트, SQNR 18.7dB
NVFP4     값당 4.50비트, SQNR 20.4dB
```

스케일이 텐서 하나뿐이면 작은 행의 값이 거의 다 0이 되어 SQNR이 4.4dB에 그친다. 블록 스케일은 0.25~0.5비트를 더 써서 14~16dB를 얻는다. NVFP4가 MXFP4보다 나은 이유는 둘이다. 블록이 작아 최댓값이 전형적인 값에 더 가깝고, 스케일이 2의 거듭제곱으로 제한되지 않는다. MX의 내림 규칙에서는 max∣v∣/X가 [4, 8)에 놓여, 6을 넘는 최댓값은 6으로 잘리고 4 근처면 맨 위 칸을 쓰지 못한다. gpt-oss의 MXFP4 가중치와 FP8 학습은 12편에서 다룬다.

## 정리
- 부동소수점은 구간마다 값 2ᴹ개를 같은 간격으로 놓은 로그형 격자다. 지수 비트는 범위를, 가수 비트는 상대 정밀도(약 2⁻ᴹ)를 정한다.
- BF16은 FP32의 범위를 지키고 정밀도를 버렸고, FP8은 E4M3(최대 448)와 E5M2(최대 57,344)로 정밀도와 범위를 나눠 맡는다.
- 정수 격자는 몇 σ 안에 모인 분포에, 부동소수점 격자는 크기가 여러 자릿수에 걸친 분포에 유리하다.
- FP4는 범위가 좁아 블록 스케일이 필수다. MXFP4는 32개당 E8M0(4.25비트), NVFP4는 16개당 E4M3 + 텐서 FP32(4.5비트)다.
