# [양자화 11/13] 오차를 보정하는 양자화: GPTQ와 AWQ

> **한 줄 요약** — GPTQ는 층의 출력 오차 ‖WX − ŴX‖²를 2차 형식으로 보고 열을 하나씩 양자화할 때마다 생긴 오차를 역헤시안으로 남은 열에 떠넘겨 입력이 거의 쓰지 않는 방향으로 오차를 몰아넣고, AWQ는 활성값이 큰 소수 채널의 가중치를 스케일로 키워 상대 오차를 줄이며, 둘 다 보정 데이터 몇백 개로 4비트 가중치 전용 양자화를 실용적으로 만든다.

## 층별 재구성 목표
9편의 RTN은 가중치 하나하나의 오차를 최소로 하지만, 정작 중요한 것은 층의 출력이다. W를 d_out × d_in, 보정 입력 X를 d_in × n(열이 샘플)이라 하면 층별 목표는 이렇다.
```text
min_Ŵ ‖WX − ŴX‖²_F = Σ_행 (w − ŵ)ᵀ (XXᵀ) (w − ŵ)
```

행(출력 채널)마다 독립인 2차 형식이고, 모든 행이 같은 헤시안 H = 2XXᵀ을 공유한다. 4편의 `ΔL ≈ ½ δᵀHδ`가 층 하나에서 정확히 성립하는 경우다. H의 고유값이 작은 방향은 입력이 거의 쓰지 않는 방향이라 그쪽 가중치 오차는 출력에 거의 나타나지 않는다. 오차를 그쪽으로 옮길 수 있다면 같은 비트로 출력이 더 정확해진다.

## OBS/OBQ에서 GPTQ로
OBQ(Frantar 등, 2022의 OBC 논문)는 1990년대 초의 가지치기 기법인 OBS(Optimal Brain Surgeon)를 양자화에 옮겼다. 아직 양자화하지 않은 가중치 집합을 F라 할 때, 가중치 w_q 하나를 격자에 고정하면 나머지를 이렇게 바꾸는 것이 2차 목표에서 최적이다.
```text
δ_F = −(w_q − quant(w_q)) / [H_F⁻¹]_qq · (H_F⁻¹)_:,q
늘어나는 오차 = (w_q − quant(w_q))² / [H_F⁻¹]_qq
```

OBQ는 행마다 늘어나는 오차가 가장 작은 가중치부터 탐욕적으로 고르고, 하나를 고를 때마다 H_F⁻¹에서 그 행·열을 지운다. 정확하지만 행마다 순서가 달라 역행렬을 따로 갱신해야 해서 수십억 파라미터 모델에는 너무 느리다. GPTQ(Frantar 등, 2022)는 세 가지를 바꿨다.
- **고정 순서**: 모든 행이 열 순서대로 양자화한다. 그러면 H_F⁻¹가 행과 무관해져 열마다 한 번만 구하면 된다. 큰 층에서는 탐욕적 순서와 결과가 거의 같다.
- **지연 배치 갱신**(lazy batch update): 열 128개(B = 128) 블록 안에서만 갱신을 바로 반영하고, 블록 뒤의 열들은 블록이 끝날 때 한꺼번에 갱신한다. 결과는 같고, 메모리 대역폭에 묶이던 작은 갱신이 큰 행렬 곱으로 바뀐다.
- **촐레스키 분해**: H⁻¹의 위삼각 촐레스키 인자 U(H⁻¹ = UᵀU)의 i번째 행이, 앞 열들을 지운 뒤의 H_F⁻¹ 첫 행을 √[H_F⁻¹]_qq로 나눈 것과 같다. 역행렬을 매번 갱신하지 않고 U를 한 번 구해 차례로 읽는다. 대각 평균의 1% 같은 작은 감쇠 λI를 H에 더해 수치적으로 안정시킨다.

논문은 175B 파라미터 GPT 모델을 약 4 GPU 시간에 가중치당 3~4비트로 줄이면서 정확도 손실이 거의 없다고 보고했다. 실제로는 열 128개마다 스케일을 따로 두는 그룹 양자화(그룹 크기 128)와 함께 많이 쓴다.

## NumPy로 GPTQ 구현하기
입력의 공분산이 고르게 퍼진 경우(p = 0)와 몇 방향에 에너지가 몰린 경우(p = 1, 고유값이 k⁻²로 감소)를 가상의 데이터로 만든다. 5편에서 본 비등방성처럼 실제 언어 모델의 은닉 상태도 몇 방향에 에너지가 몰려 있다. 보정 입력과 평가 입력은 따로 뽑는다.
```python
import numpy as np

rng = np.random.default_rng(0)
d_out, d_in, n = 256, 256, 2048
W = rng.normal(size=(d_out, d_in)) / np.sqrt(d_in)

def quant(w, s, bits):                      # 행(출력 채널)별 대칭 격자
    qmax = 2 ** (bits - 1) - 1
    return np.clip(np.round(w / s), -qmax - 1, qmax) * s

def scale(W, bits):
    return np.abs(W).max(1) / (2 ** (bits - 1) - 1)

def gptq(W, X, bits, damp=0.01):
    W, s = W.copy(), scale(W, bits)
    H = 2 * X @ X.T                         # 층별 목표의 헤시안
    H += damp * np.mean(np.diag(H)) * np.eye(len(H))   # 감쇠: 대각 평균의 1%
    U = np.linalg.cholesky(np.linalg.inv(H)).T  # H⁻¹ = UᵀU, U는 위삼각
    Q = np.zeros_like(W)
    for i in range(W.shape[1]):             # 모든 행이 같은 열 순서
        Q[:, i] = quant(W[:, i], s, bits)
        err = (W[:, i] - Q[:, i]) / U[i, i]
        W[:, i:] -= np.outer(err, U[i, i:])  # 남은 열이 오차를 떠안음
    return Q

def inputs(p):                              # 고유값이 k^(−2p)로 줄어드는 입력
    U0 = np.linalg.qr(rng.normal(size=(d_in, d_in)))[0]
    M = U0 * np.arange(1, d_in + 1) ** -p
    return lambda k: M @ rng.normal(size=(d_in, k))

for p in [0.0, 1.0]:                        # 0: 상관 없음, 1: 강한 상관
    sample = inputs(p)
    Xc, Xt = sample(n), sample(n)           # 보정용, 평가용(새 입력)
    for bits in [4, 3]:
        rtn = quant(W, scale(W, bits)[:, None], bits)
        r = []
        for Q in [rtn, gptq(W, Xc, bits)]:
            out = np.linalg.norm((Q - W) @ Xt) / np.linalg.norm(W @ Xt)
            wt = np.linalg.norm(Q - W) / np.linalg.norm(W)
            r.append(f"{out:.4f}({wt:.3f})")
        print(f"p={p} {bits}비트  출력(가중치) 오차  RTN {r[0]}  GPTQ {r[1]}")
```
```text
p=0.0 4비트  출력(가중치) 오차  RTN 0.1277(0.128)  GPTQ 0.1317(0.132)
p=0.0 3비트  출력(가중치) 오차  RTN 0.2969(0.297)  GPTQ 0.3059(0.306)
p=1.0 4비트  출력(가중치) 오차  RTN 0.1253(0.128)  GPTQ 0.0246(0.156)
p=1.0 3비트  출력(가중치) 오차  RTN 0.2945(0.297)  GPTQ 0.0579(0.363)
```

H_F⁻¹를 매번 새로 구해 위의 δ_F 식을 그대로 쓰는 구현과도 결과가 완전히 같음을 따로 확인했다. 입력에 상관이 있으면(p = 1) GPTQ의 출력 오차가 4비트에서 12.5% → 2.5%, 3비트에서 29.5% → 5.8%로 약 5분의 1이 된다. 그런데 가중치 오차는 오히려 0.128 → 0.156, 0.297 → 0.363으로 커졌다. 가중치를 원래 값에서 더 멀리 보내되, 입력이 거의 쓰지 않는 방향으로 보냈기 때문이다. 입력이 고르게 퍼진 p = 0에서는 H가 단위 행렬에 가까워 오차를 옮길 곳이 없고, 보정 표본의 우연한 상관에 맞춘 갱신과 격자 밖으로 밀린 값의 클리핑 때문에 새 입력에서는 RTN보다 조금 나쁘다. GPTQ의 이득은 입력의 상관 구조에서 나온다.

## AWQ: 중요한 채널을 스케일로 보호하기
AWQ(Lin 등, 2023, MLSys 2024 최우수 논문상)는 가중치의 0.1~1%만 특히 중요하고, 그만큼의 채널을 FP16으로 남기기만 해도 양자화 오차가 크게 준다는 관찰에서 출발한다. 중요도는 가중치 크기가 아니라 그 채널에 들어오는 **활성값의 크기**로 정해야 한다. 하지만 일부 채널만 FP16으로 두는 혼합 정밀도는 하드웨어에 불편하다. AWQ는 대신 중요 채널의 가중치에 s > 1을 곱하고 입력을 s로 나눈다.
```text
Q(w)·x 의 오차         ≈ Δ · RoundErr · x
Q(w·s)·(x/s) 의 오차   ≈ Δ′ · RoundErr · x / s
```

그룹 최댓값이 그대로면 Δ′ ≈ Δ이므로 그 채널의 오차는 1/s로 준다. 하지만 s가 너무 커지면 그 채널이 그룹의 최댓값이 되어 Δ′이 커지고 같은 그룹의 다른 채널이 손해를 본다. 그래서 AWQ는 채널별 평균 활성값 크기 s_X로 `s = s_X^α`를 만들고 α ∈ [0, 1]을 격자 탐색(보통 20개 점)해 보정 데이터의 출력 오차가 최소인 값을 고른다. 역전파나 재구성 최적화가 없어 보정 데이터에 과적합할 여지가 작다. 위 코드에 이어서, 활성값이 큰 채널을 1% 심은 가상의 데이터로 INT4(그룹 128, 비대칭) 가중치 전용 양자화를 비교한다.
```python
n, d_in, d_out, g = 1024, 1024, 256, 128
mag = np.ones(d_in)
hot = rng.choice(d_in, 10, replace=False)   # 활성값이 큰 채널 약 1%
mag[hot] = rng.uniform(10, 30, size=10)
sample = lambda k: rng.normal(size=(k, d_in)) * mag   # 가상의 활성값
Xc, Xt = sample(n), sample(n)               # 보정용, 평가용
W = rng.normal(size=(d_in, d_out)) / np.sqrt(d_in)

def q4_group(W):                            # INT4 비대칭, 입력 방향 g개씩
    Wg = W.reshape(-1, g, W.shape[1])
    lo, hi = Wg.min(1, keepdims=True), Wg.max(1, keepdims=True)
    s = (hi - lo) / 15
    z = np.round(-lo / s)
    q = np.clip(np.round(Wg / s) + z, 0, 15)
    return ((q - z) * s).reshape(W.shape)

def err(Wh, X):
    return np.linalg.norm(X @ (Wh - W)) / np.linalg.norm(X @ W)

def awq(alpha):                             # s = s_X^α, Ŵ = Q(diag(s)·W)/s
    s = (np.abs(Xc).mean(0) ** alpha)[:, None]
    return q4_group(W * s) / s

alphas = np.arange(20) / 20                 # 0, 0.05, …, 0.95
best = min(alphas, key=lambda a: err(awq(a), Xc))
keep = q4_group(W)
keep[hot] = W[hot]                          # 1% 채널만 FP16으로
top_w = np.argsort(-np.abs(W).sum(1))[:10]  # 가중치 크기로 고른 1%
keep_w = q4_group(W)
keep_w[top_w] = W[top_w]
print(f"RTN(α=0)            {err(q4_group(W), Xt):.4f}")
print(f"1% FP16(활성값 기준) {err(keep, Xt):.4f}")
print(f"1% FP16(가중치 기준) {err(keep_w, Xt):.4f}")
print(f"AWQ α={best:.2f}         {err(awq(best), Xt):.4f}")
for a in [0.25, 0.5, 0.75, 0.95]:
    print(f"  α={a:.2f}: {err(awq(a), Xt):.4f}")
```
```text
RTN(α=0)            0.1002
1% FP16(활성값 기준) 0.0452
1% FP16(가중치 기준) 0.1001
AWQ α=0.35         0.0637
  α=0.25: 0.0662
  α=0.50: 0.0708
  α=0.75: 0.1125
  α=0.95: 0.1791
```

활성값이 큰 1% 채널만 FP16으로 남기면 출력 오차가 10.0%에서 4.5%로 절반 아래가 되지만, 가중치 크기로 고른 1%를 남기면 10.0% 그대로다. 중요도는 활성값이 정한다는 AWQ의 관찰과 같다. 스케일만 쓰는 AWQ는 탐색으로 고른 α = 0.35에서 6.4%로, 혼합 정밀도 없이 RTN 대비 오차를 3분의 1 넘게 줄였다. α가 너무 크면(0.75 이상) 중요 채널이 그룹 최댓값이 되어 다른 채널의 격자가 거칠어지므로 RTN보다도 나빠진다. 논문은 여기에 가중치 클리핑 범위 탐색을 더해 오차를 더 줄인다.

## GPTQ와 AWQ 비교
| 항목 | GPTQ | AWQ |
|---|---|---|
| 원리 | 역헤시안 보정 | 채널 스케일 |
| 보정 데이터 | 입력 2차 통계 | 채널 평균 크기 |
| 계산 | 열마다 갱신 | α 격자 탐색 |
| 과적합 | 위험 있음 | 작음 |

둘 다 결과물은 같은 꼴, 즉 4비트 정수 가중치와 그룹(보통 128개)마다의 스케일·영점이다. 추론 때는 가중치를 읽어 16비트로 역양자화하며 곱하는 W4A16 커널을 쓰므로, 메모리 대역폭이 병목인 디코드(1편)에서 이득이 크다. 원리가 겹치지 않아 AWQ 스케일을 적용한 뒤 GPTQ로 반올림하는 식으로 함께 쓸 수도 있다. 활성값까지 4비트로 내리려면 10편의 회전이 먼저 필요하다.

## 어디에 쓰이나
- 통계학 8편 「선형 회귀와 최소제곱법」: 층별 목표 ‖WX − ŴX‖²는 최소제곱 문제이고, H = 2XXᵀ는 정규 방정식에 나오는 그 행렬이다.
- 선형대수 5편 「연립일차방정식과 역행렬」: GPTQ는 역행렬을 매번 갱신하는 대신 촐레스키 인자를 한 번 구해 차례로 읽는다.
- 4편 「양자화 오차의 전파: 잡음은 층을 지나며 어떻게 커지나」: 손실의 2차 근사 ½δᵀHδ와 헤시안이 큰 방향이 민감하다는 그 글의 결론을 알고리즘으로 만든 것이 GPTQ다.
- 10편 「이상치 다루기: LLM.int8(), SmoothQuant, 회전」: AWQ의 채널 스케일은 SmoothQuant와 같은 등가 변환이지만, 활성값 양자화가 아니라 가중치의 중요 채널 보호에 쓴다.

## 정리
- 층별 목표 ‖WX − ŴX‖²는 행마다 헤시안 H = 2XXᵀ을 공유하는 2차 형식이다.
- GPTQ는 고정 순서·지연 배치 갱신·촐레스키로 OBQ의 보정을 대형 모델에 맞게 바꿨다. 상관된 입력에서 출력 오차가 RTN의 약 5분의 1이었고, 상관이 없으면 이득도 없었다.
- AWQ는 활성값 기준 중요 채널을 `s = s_X^α`로 키워 보호하고 α를 격자 탐색한다.
- 둘 다 W4A16(그룹 128) 가중치를 만들며, 디코드처럼 메모리 바운드인 추론에서 효과가 크다.
