> **한 줄 요약** — 활성값의 이상치는 특정 입력 채널에 몰려 있어 정수 행렬 곱의 스케일로는 따로 처리할 수 없는데, LLM.int8()은 그 채널만 FP16으로 떼어 계산하고, SmoothQuant는 채널별 스케일로 난이도를 가중치 쪽에 옮기고, 회전(아다마르)은 곱을 바꾸지 않는 직교 변환으로 이상치를 모든 채널에 고르게 퍼뜨린다.

## 왜 채널 이상치가 곤란한가
3편에서 본 것처럼 큰 언어 모델의 활성값에는 몇몇 특징 차원(채널)에서 모든 토큰에 걸쳐 수십 배 큰 값이 나온다. 스케일을 어느 방향으로 둘 수 있는지가 문제의 핵심이다.
```text
Y_tj = Σ_k X_tk · W_kj
X_tk ≈ a_t · X̂_tk (토큰별),  W_kj ≈ b_j · Ŵ_kj (출력 채널별)
⇒ Y_tj ≈ a_t · b_j · Σ_k X̂_tk · Ŵ_kj    정수 곱 하나 + 스케일 두 개
```

토큰별 스케일 a_t와 출력 채널별 스케일 b_j는 합 Σ_k 밖으로 나오므로 정수 행렬 곱 하나로 끝난다. 하지만 이상치는 입력 채널 k를 따라 생기고, 입력 채널별 스케일 c_k는 Σ 안에 남아 정수 곱 하나로 묶이지 않는다. 그래서 토큰별 스케일을 써도 모든 토큰에 이상치가 섞여 있으면 모든 토큰의 격자가 거칠어진다. 아래 세 방법은 이 제약을 각자 다른 방식으로 피한다.

## LLM.int8(): 이상치 차원만 FP16으로
LLM.int8() 논문(Dettmers 등, 2022)은 두 단계를 쓴다. 먼저 **벡터별 양자화**(vector-wise quantization)로 X는 행(토큰)마다, W는 열(출력)마다 absmax 스케일을 둔다. 위 식의 a_t, b_j다. 다음으로 **혼합 정밀도 분해**(mixed-precision decomposition)를 한다. 크기가 임계값 6.0을 넘는 값이 하나라도 있는 특징 차원의 집합 O를 FP16으로 따로 곱하고, 나머지만 INT8로 곱해 더한다.
```text
XW ≈ Σ_(k∈O) X_:k W_k: (FP16) + a ⊙ b · Σ_(k∉O) X̂_:k Ŵ_k: (INT8)
```

논문은 임계값 6.0이면 성능 저하가 거의 사라지고, 그래도 값의 99.9% 이상이 8비트로 곱해진다고 보고했다. 또 이런 이상치 특징이 6.7B 규모부터 모든 층에 나타나 일반 8비트 양자화가 무너진다고 밝혔다. 이상치 채널 6개를 심은 가상의 활성값으로 세 방식을 비교한다.
```python
import numpy as np

rng = np.random.default_rng(0)
T, d, m = 256, 1024, 512                    # 토큰, 입력 차원, 출력 차원
X = rng.normal(size=(T, d))                 # 가상의 활성값
out = rng.choice(d, 6, replace=False)       # 이상치 채널 6개
X[:, out] *= rng.uniform(15, 40, size=6)
W = rng.normal(size=(d, m)) / np.sqrt(d)
Y = X @ W

def q8(a, axis):                            # absmax INT8, axis 방향 스케일
    s = np.abs(a).max(axis=axis, keepdims=True) / 127
    return np.round(a / s) * s

f16 = lambda a: a.astype(np.float16).astype(np.float64)
rel = lambda Yh: np.linalg.norm(Yh - Y) / np.linalg.norm(Y)

print(f"텐서별 INT8  {rel(q8(X, None) @ q8(W, None)):.4f}")
print(f"벡터별 INT8  {rel(q8(X, 1) @ q8(W, 0)):.4f}")
O = np.abs(X).max(0) > 6.0                  # 임계값 6을 넘는 특징 차원
Yd = f16(X[:, O]) @ f16(W[O]) + q8(X[:, ~O], 1) @ q8(W[~O], 0)
print(f"LLM.int8()   {rel(Yd):.4f}  FP16 차원 {O.sum()}개 ({O.mean():.2%})")
```
```text
텐서별 INT8  0.1070
벡터별 INT8  0.0494
LLM.int8()   0.0049  FP16 차원 6개 (0.59%)
```

벡터별 스케일만으로 오차가 10.7%에서 4.9%로 줄지만, 이상치가 모든 토큰의 스케일을 키우는 문제는 그대로다. 임계값으로 고른 6개 차원(0.59%)만 FP16으로 빼면 오차가 0.49%로 10분의 1이 된다. 대가는 이상치 차원을 찾아 따로 곱하는 추가 작업이고, FP16 경로가 남아 있어 행렬 곱 전체를 INT8 텐서 코어에 맡기지는 못한다.

## SmoothQuant: 난이도를 가중치로 옮기기
SmoothQuant(Xiao 등, 2022)는 활성값은 채널 이상치 때문에 양자화가 어렵고 가중치는 비교적 쉽다는 비대칭을 이용한다. 입력 채널마다 스케일 s_j를 정해 활성값은 나누고 가중치는 곱한다.
```text
Y = (X · diag(s)⁻¹) · (diag(s) · W),   s_j = max∣X_j∣^α / max∣W_j∣^(1−α)
```

곱은 수학적으로 그대로다. s는 보정 데이터로 미리 정하고, X를 나누는 일은 앞 층(LayerNorm 게인이나 앞 선형 층)의 가중치에 접어 넣을 수 있어 추론 때 추가 연산이 없다. **이전 강도**(migration strength) α는 난이도를 얼마나 옮길지 정한다. α = 0.5면 두 쪽의 채널별 최대가 `√(max∣X_j∣ · max∣W_j∣)`로 같아진다. 논문은 α = 0.5를 기본값으로, 이상치가 더 심한 모델에는 더 큰 α를 권하며, 그 뒤 활성값과 가중치를 모두 INT8로 곱하는 W8A8로 FP16 대비 최대 1.56배 속도와 절반의 메모리를 보고했다(FasterTransformer 기준). 위 데이터로 α를 바꿔 본다. 활성값은 텐서별 스케일 하나, 가중치는 출력 채널별 스케일이다.
```python
for a in [0.0, 0.25, 0.5, 0.75, 1.0]:       # SmoothQuant 이전 강도 α
    s = np.abs(X).max(0) ** a / np.abs(W).max(1) ** (1 - a)
    Xs, Ws = X / s, W * s[:, None]          # X·diag(s)⁻¹, diag(s)·W
    same = np.abs(Xs @ Ws - Y).max()
    e = rel(q8(Xs, None) @ q8(Ws, 0))       # 활성값 텐서별, 가중치 열별
    r = np.abs(Xs).max() / np.abs(Ws).max()
    print(f"α={a:.2f} 곱 차이 {same:.0e}  W8A8 오차 {e:.4f}  범위비 {r:.1f}")
```
```text
α=0.00 곱 차이 5e-15  W8A8 오차 0.1115  범위비 11.0
α=0.25 곱 차이 4e-15  W8A8 오차 0.0461  범위비 3.3
α=0.50 곱 차이 5e-15  W8A8 오차 0.0220  범위비 1.0
α=0.75 곱 차이 4e-15  W8A8 오차 0.0235  범위비 0.3
α=1.00 곱 차이 4e-15  W8A8 오차 0.0493  범위비 0.1
```

어느 α에서도 곱의 차이는 10⁻¹⁵ 수준으로 부동소수점 반올림뿐이다. α = 0은 가중치만 평평하게 만들어 난이도가 전부 활성값에 남고(11.2%), α = 1은 반대로 가중치에 이상치를 넘겨 4.9%다. 범위비(활성값 최대 ÷ 가중치 최대)가 1이 되는 α = 0.5에서 2.2%로 가장 작다. 활성값에 텐서별 스케일 하나만 쓰고도 벡터별 INT8(4.9%)보다 좋아서, 정적 스케일 하나로 빠르게 돌리는 W8A8에 맞는다.

## 회전: 이상치를 모든 채널에 퍼뜨리기
직교 행렬 Q(QQᵀ = I)를 끼워 넣어도 곱은 그대로다: `XW = (XQ)(QᵀW)`. Q를 잘 고르면 XQ의 각 좌표는 원래 모든 채널의 가중합이 되어, 한 채널에 몰렸던 이상치가 d개 좌표에 ±x_k/√d씩 나뉜다. 중심 극한 정리에 따라 회전된 좌표는 정규 분포에 가까워지고 첨도와 최대/RMS 비율이 떨어진다. **아다마르 행렬**(Hadamard matrix) H는 성분이 ±1이고 HHᵀ = d·I라서 H/√d가 직교 행렬이며, 빠른 월시-아다마르 변환으로 O(d log d)에 곱할 수 있다. 무작위 부호 대각 행렬을 곱해 특정 입력과 운 나쁘게 맞물리는 일을 막는다. 위 코드에 이어서 4비트(W4A4)로 비교한다.
```python
from scipy.linalg import hadamard
from scipy.stats import kurtosis

def q4(a, axis):                            # absmax INT4(−7~7)
    s = np.abs(a).max(axis=axis, keepdims=True) / 7
    return np.round(a / s) * s

signs = rng.choice([-1.0, 1.0], size=d)     # 무작위 부호
Q = hadamard(d) * signs[:, None] / np.sqrt(d)   # 직교 행렬: QQᵀ = I
print("QQᵀ = I:", np.allclose(Q @ Q.T, np.eye(d)))
Xr, Wr = X @ Q, Q.T @ W                     # (XQ)(QᵀW) = XW
print("곱 차이:", f"{np.abs(Xr @ Wr - Y).max():.0e}")
for name, a, b in [("원래", X, W), ("회전", Xr, Wr)]:
    peak = np.abs(a).max(1) / np.sqrt((a ** 2).mean(1))   # 토큰별 최대/RMS
    e = rel(q4(a, 1) @ q4(b, 0))            # 활성값 토큰별, 가중치 열별
    print(f"{name}: 첨도 {kurtosis(a.ravel()):6.1f}  최대/RMS {peak.mean():5.1f}"
          f"  W4A4 오차 {e:.3f}")
```
```text
QQᵀ = I: True
곱 차이: 2e-14
원래: 첨도  401.5  최대/RMS  20.1  W4A4 오차 0.452
회전: 첨도    0.0  최대/RMS   2.9  W4A4 오차 0.186
```

회전 전 활성값의 초과 첨도는 401.5로 극단적인 꼬리를 보이고, 토큰마다 최댓값이 RMS의 20배라 4비트 격자 15칸 중 대부분이 비어 오차가 45%다. 회전하면 첨도가 정규 분포의 0이 되고 최대/RMS가 2.9로 떨어져 오차가 18.6%로 준다. 정규 분포 자체의 4비트 오차는 남아 있으므로, 실제 방법들은 회전 위에 9편의 클리핑 탐색이나 11편의 GPTQ를 더한다.

- **QuaRot**(Ashkboos 등, 2024): 잔차 스트림 전체를 아다마르 계열 직교 행렬로 회전하고 앞뒤 가중치에 접어 넣는다. FFN 출력 투영의 입력과 어텐션의 키·값에는 실행 중 아다마르 변환을 더해 KV 캐시까지 4비트로 만든다. 논문은 가중치·활성값·KV 캐시를 모두 4비트로 한 LLaMA2-70B가 WikiText-2 퍼플렉서티 손실 0.47 이하, 영샷 성능 99%를 유지했다고 보고했다.
- **SpinQuant**(Liu 등, 2024): 무작위 회전마다 결과가 크게 달라서(영샷 정확도 최대 13점 차이), 회전 행렬을 직교성을 유지하는 케일리(Cayley) SGD로 학습한다. W4A4KV4 LLaMA-2 7B에서 전정밀 대비 평균 정확도 차이를 2.9점으로 줄였다고 보고했다.
- **QuIP#**(Tseng 등, 2024): 가중치 전용이다. 무작위 아다마르 변환으로 가중치를 비간섭(incoherent) 상태로 만든 뒤 E8 격자 코드북(9편)으로 값당 2비트까지 줄인다.

## 세 방법 비교
| 방법 | 원리 | 주 용도 |
|---|---|---|
| LLM.int8() | 이상치만 FP16 | W8A8 |
| SmoothQuant | 채널 스케일 이전 | W8A8 |
| 회전 | 직교 변환 | W4A4·KV4 |

추론 때 드는 추가 비용은 LLM.int8()이 이상치 차원을 나눠 따로 곱하는 분해 작업, SmoothQuant는 앞 층에 접어 넣어 사실상 없음, 회전은 앞뒤 가중치에 접어 넣지 못한 일부 아다마르 변환이다.

## 어디에 쓰이나
- 선형대수 9편 「직교성과 사영」: 직교 행렬은 길이와 내적을 보존하므로 (XQ)(QᵀW) = XW이고, 회전 기반 방법은 이 성질 하나에 기대어 있다.
- 선형대수 3편 「행렬과 행렬 곱」: 행렬 곱의 합 Σ_k 밖으로 꺼낼 수 있는 스케일(토큰별·출력별)과 꺼낼 수 없는 스케일(입력 채널별)의 구분이 세 방법이 존재하는 이유다.
- 어텐션 8편 「세이지 어텐션: 양자화로 더 빠르게」: K에서 평균을 빼도 softmax가 변하지 않는 smoothing은 결과를 바꾸지 않는 변환으로 분포를 고르게 만든다는 점에서 SmoothQuant·회전과 같은 발상이다.
- 3편 「가중치와 활성값의 분포: 이상치가 비트를 낭비하는 이유」: 이 글이 다루는 채널 이상치와 거대 활성값의 관찰이 그 글에 있다.

## 정리
- 입력 채널을 따라 생기는 이상치는 정수 행렬 곱의 스케일(토큰별·출력별)로 따로 처리할 수 없다.
- LLM.int8()은 임계값 6.0을 넘는 특징 차원만 FP16으로 계산한다. 실험에서 0.59%의 차원을 빼자 오차가 10분의 1이 되었다.
- SmoothQuant는 `s_j = max∣X_j∣^α / max∣W_j∣^(1−α)`로 곱을 바꾸지 않고 난이도를 옮기며, 실험에서 α = 0.5가 가장 좋았다.
- 아다마르 회전은 첨도를 401에서 0으로 낮춰 W4A4 오차를 45%에서 19%로 줄였고, QuaRot·SpinQuant·QuIP#의 기반이 된다.
