# [양자화 1/15] 양자화의 기본: 실수를 정수 격자에 올리기

> **한 줄 요약** — 양자화는 실수 x를 스케일 s와 영점 z로 정수 격자 `q = clip(round(x/s) + z)`에 올리고 `x̂ = s·(q − z)`로 되돌리는 근사이며, 격자 간격 Δ가 분포보다 충분히 작으면 반올림 오차는 [−Δ/2, Δ/2]의 균등 분포라 평균 제곱 오차가 Δ²/12이고, 비트를 하나 늘릴 때마다 신호 대 잡음비가 약 6dB씩 좋아진다.

## 이 글에서 다루는 것
- 왜 양자화하나: 디코드는 메모리 바운드다
- 양자화·역양자화 식, 스케일과 영점, 대칭 vs 비대칭
- 반올림 오차가 균등 분포인 이유, MSE = Δ²/12, 비트당 약 6dB
- 정수 행렬 곱과 INT32 누적, 스케일 되돌리기
- W4A16, W8A8 같은 표기

## 왜 양자화하나
언어 모델이 토큰을 하나씩 만드는 디코드 단계에서는 토큰마다 가중치 전체를 메모리에서 한 번 읽는다. 배치가 1이면 가중치 하나를 읽어 곱셈-덧셈 한 번(2 FLOPs)만 하므로 계산 장치는 놀고 메모리 대역폭이 속도를 정한다(어텐션 9편의 메모리 바운드). 80억(8B) 파라미터 모델은 BF16이면 16GB라, 대역폭 1TB/s인 GPU에서 토큰 생성 속도의 상한이 62.5토큰/초다. 가중치를 4비트로 줄이면(그룹 스케일까지 값당 4.125비트, 3편) 약 4.1GB가 되어 상한이 약 242토큰/초로 오른다. 더 작은 GPU에 올라가고, 같은 GPU에서는 KV 캐시와 배치에 메모리를 더 줄 수 있다. 반면 프리필이나 큰 배치처럼 연산 바운드인 구간은 가중치만 줄여서는 빨라지지 않는다. 행렬 곱 자체를 INT8·FP8 같은 저정밀 텐서 코어로 돌려야 한다. 이 차이가 마지막 절의 W4A16과 W8A8 구분이다.

## 양자화와 역양자화
**양자화**(quantization)는 실수 x를 b비트 정수 q로, **역양자화**(dequantization)는 q를 다시 실수 x̂로 바꾸는 사상이다. 가장 흔한 균일 아핀(affine) 양자화는 이렇다(Jacob 등, 2018의 정수 전용 추론 논문과 같은 꼴).
```text
q  = clip(round(x / s) + z, q_min, q_max)
x̂ = s · (q − z)
```

- 스케일(scale) s > 0: 격자 간격 Δ다. 정수 한 칸이 실수로 얼마인지 나타낸다.
- 영점(zero point) z: 실수 0이 대응하는 정수다. 정수라서 x = 0이면 q = z, x̂ = s·(z − z) = 0으로 0이 오차 없이 표현된다. 0은 패딩, ReLU 출력, 희소한 값으로 아주 자주 나오므로 정확해야 한다.
- clip: 격자 범위 밖의 값은 끝 값으로 잘린다. 클리핑 오차와 반올림 오차의 절충은 9편 「학습 후 양자화의 기본: 반올림, 클리핑, 비균일 격자」에서 다룬다.

**대칭**(symmetric) 양자화는 z = 0으로 두고 `s = max∣x∣ / (2^(b−1) − 1)`로 정한다. INT8이면 흔히 −127~127을 쓰고(−128은 대칭을 위해 버린다), INT4면 −7~7이다. **비대칭**(asymmetric) 양자화는 [min, max]를 0~2ᵇ−1 전체에 맞춘다: `s = (max − min)/(2ᵇ − 1)`, `z = round(−min/s)`. 대칭은 영점 보정 항이 없어 계산이 단순하고 0 중심인 가중치에 잘 맞는다. 비대칭은 한쪽으로 치우친 값(ReLU 뒤 활성값 등)에서 격자를 낭비하지 않는다.

## 반올림 오차는 균등 분포다
e = x̂ − x라 하자. 클리핑이 없으면 x는 가장 가까운 격자점으로 가므로 ∣e∣ ≤ Δ/2다. Δ가 x의 밀도가 눈에 띄게 변하는 폭보다 훨씬 작으면, 한 칸 [kΔ − Δ/2, kΔ + Δ/2] 안에서 밀도는 거의 평평하다. 그러면 칸 안에서의 위치인 e도 [−Δ/2, Δ/2]에서 균등하고 x와 거의 무관하다. 균등 분포의 분산이 곧 MSE다.
```text
E[e²] = (1/Δ) ∫ e² de  (−Δ/2부터 Δ/2까지)
      = (1/Δ) · (Δ³/24 + Δ³/24) = Δ²/12
```

백만 개의 정규 분포 값을 대칭 INT8로 양자화해 확인하자. 이 시리즈의 실험은 모두 가상의 데이터로 현상을 재현한 것이다.
```python
import numpy as np

def quantize(x, bits, symmetric=True):
    if symmetric:                         # z = 0, 부호 있는 격자
        qmax = 2 ** (bits - 1) - 1
        s, z, lo, hi = np.abs(x).max() / qmax, 0, -qmax, qmax
    else:                                 # [min, max]를 0~2ᵇ−1에
        lo, hi = 0, 2 ** bits - 1
        s = (x.max() - x.min()) / hi
        z = np.round(-x.min() / s)        # 영점: 실수 0이 가는 정수
    q = np.clip(np.round(x / s) + z, lo, hi)
    return s * (q - z), s                 # 역양자화 값 x̂, 간격 Δ = s

rng = np.random.default_rng(0)
x = rng.normal(size=1_000_000)
xh, d = quantize(x, 8)
e = xh - x
print(f"Δ = {d:.5f}, 최대 ∣e∣/Δ = {np.abs(e).max() / d:.4f}")
print(f"평균 {e.mean():.1e}, MSE/(Δ²/12) = {np.mean(e**2) / (d**2 / 12):.4f}")
print("e/Δ 분위수:", np.quantile(e / d, [.1, .25, .5, .75, .9]).round(3))
print(f"corr(x, e) = {np.corrcoef(x, e)[0, 1]:.4f}")
```
```text
Δ = 0.03726, 최대 ∣e∣/Δ = 0.5000
평균 5.2e-06, MSE/(Δ²/12) = 0.9998
e/Δ 분위수: [-0.4  -0.25  0.    0.25  0.4 ]
corr(x, e) = -0.0004
```

최대 오차는 정확히 Δ/2, MSE는 Δ²/12의 0.9998배이고, e/Δ의 분위수는 균등 분포 U(−½, ½)의 분위수와 같으며, x와의 상관은 사실상 0이다. 그래서 양자화를 "신호와 독립인 균등 잡음을 더하는 것"으로 모델링할 수 있다. 4편 「양자화 오차의 전파: 잡음은 층을 지나며 어떻게 커지나」는 이 모델 위에서 잡음이 층을 지나는 과정을 계산한다.

## 비트 하나에 약 6dB
신호 대 양자화 잡음비(SQNR)는 `10·log₁₀(E[x²] / E[e²])` dB다. 범위가 같을 때 비트를 하나 늘리면 격자 점이 약 2배라 Δ가 절반, MSE = Δ²/12가 1/4이 된다. 10·log₁₀4 ≈ 6.02이므로 비트당 약 6dB다. 위 코드에 이어서 실행한다.
```python
def sqnr(x, xh):
    return 10 * np.log10(np.mean(x**2) / np.mean((xh - x) ** 2))

prev = None
for b in range(2, 9):
    xh, d = quantize(x, b)
    pred = 10 * np.log10(np.mean(x**2) / (d**2 / 12))   # Δ²/12 가정
    gain = "" if prev is None else f"  +{sqnr(x, xh) - prev:.2f}dB"
    print(f"{b}비트: 측정 {sqnr(x, xh):5.2f}dB, 예측 {pred:5.2f}dB{gain}")
    prev = sqnr(x, xh)

r = np.maximum(x, 0)                      # ReLU 출력: 0 이상만
for sym in (True, False):
    rh, _ = quantize(r, 4, symmetric=sym)
    print(f"{'대칭' if sym else '비대칭'} 4비트: 쓰인 값",
          f"{len(np.unique(rh))}개, SQNR {sqnr(r, rh):.2f}dB")
```
```text
2비트: 측정  0.26dB, 예측 -2.70dB
3비트: 측정  6.84dB, 예측  6.84dB  +6.58dB
4비트: 측정 14.19dB, 예측 14.20dB  +7.35dB
5비트: 측정 20.82dB, 예측 20.82dB  +6.63dB
6비트: 측정 27.12dB, 예측 27.12dB  +6.30dB
7비트: 측정 33.28dB, 예측 33.28dB  +6.15dB
8비트: 측정 39.37dB, 예측 39.37dB  +6.10dB
대칭 4비트: 쓰인 값 8개, SQNR 14.19dB
비대칭 4비트: 쓰인 값 16개, SQNR 20.82dB
```

3비트 이상에서 측정값과 Δ²/12 예측이 0.01dB 안에서 맞는다. 증가폭이 6.02dB보다 큰 것은 대칭 격자의 끝이 2^(b−1) − 1이라 Δ가 정확히 절반이 되지 않아서다. 3→4비트는 Δ가 3/7배라 20·log₁₀(7/3) = 7.36dB이고, 비트가 늘수록 비율이 2에 가까워져 8비트에서 6.10dB까지 내려온다. 2비트에서는 예측이 3dB 빗나간다. 격자가 {−M, 0, M}뿐이라 Δ가 표준편차의 약 5배이고, 대부분의 값이 0으로 가서 e가 x 자체와 비슷해진다. "칸 안에서 밀도가 평평하다"는 가정이 깨진 것이다. 극단적 저비트에서 단순한 잡음 모델이 맞지 않는 이유이고, 13편에서 다시 만난다.

마지막 두 줄은 ReLU 출력처럼 0 이상인 값이다. 대칭 4비트는 음수 쪽 7칸을 한 번도 쓰지 못해 값 8개만 쓰고, 비대칭은 16개를 모두 쓴다. 비대칭의 Δ = max/15는 대칭 5비트의 Δ와 같아서 SQNR도 5비트 값(20.82dB)이 그대로 나온다. 분포에 맞지 않는 격자는 비트 하나를 통째로 버린다.

## 정수 행렬 곱과 스케일 되돌리기
양자화한 가중치를 매번 실수로 되돌려 곱할 수도 있지만, 큰 이득은 정수끼리 곱할 때 난다. 토큰별 스케일 s_x[i]와 출력 채널별 스케일 s_w[j]를 쓰면 스케일이 합 밖으로 빠진다.
```text
y_ij = Σ_k x_ik · W_kj
     ≈ Σ_k (s_x[i]·qx_ik) · (s_w[j]·qw_kj)
     = s_x[i] · s_w[j] · Σ_k qx_ik · qw_kj   ← 정수 곱의 합
```

합 안은 순수한 정수 연산이고 스케일 곱은 출력 원소마다 한 번이다. INT8 곱 하나는 최대 127² = 16,129라 15비트면 되지만, 4,096개를 더하면 최악의 경우 6,600만을 넘으므로 누적은 INT32로 한다.
```python
import numpy as np

rng = np.random.default_rng(0)
X = rng.normal(size=(4, 4096))                    # 토큰 4개
W = rng.normal(size=(4096, 1024)) * 0.02
sx = np.abs(X).max(axis=1, keepdims=True) / 127   # 토큰별 스케일
sw = np.abs(W).max(axis=0, keepdims=True) / 127   # 출력 채널별 스케일
qx = np.round(X / sx).astype(np.int8)
qw = np.round(W / sw).astype(np.int8)

acc = qx.astype(np.int32) @ qw.astype(np.int32)   # INT32 누적
Y = acc * sx * sw                                 # 스케일 두 개를 곱해 복원
fake = (qx * sx) @ (qw * sw)                      # 역양자화 후 실수 곱
ref = X @ W
rel = lambda a, b: np.linalg.norm(a - b) / np.linalg.norm(b)
print("정수 경로 = 역양자화 경로:", np.allclose(Y, fake, rtol=1e-12))
print(f"FP64 대비 상대 오차 {rel(Y, ref):.4f}")
print(f"누적값 최대 {np.abs(acc).max():,}, 최악 127²·4096 = {127**2 * 4096:,}")
a16 = qx.astype(np.int16) @ qw.astype(np.int16)   # INT16 누적이면?
print(f"INT16 누적: 넘친 원소 {np.mean(a16 != acc):.0%}, "
      f"상대 오차 {rel(a16 * sx * sw, ref):.2f}")
```
```text
정수 경로 = 역양자화 경로: True
FP64 대비 상대 오차 0.0125
누적값 최대 271,992, 최악 127²·4096 = 66,064,384
INT16 누적: 넘친 원소 64%, 상대 오차 1.03
```

정수로 누적한 뒤 스케일을 곱한 결과는 역양자화한 행렬끼리 곱한 결과와 같고, FP64 대비 상대 오차는 1.25%다. 부호가 섞여 상쇄되므로 실제 누적값 최대(약 27만)는 최악보다 훨씬 작지만 INT16 한계 32,767은 크게 넘는다. INT16으로 누적하면 64%의 원소가 넘쳐 결과가 무의미해진다. 활성값이 비대칭이면 `Σ_k (qx_ik − z_x)·qw_kj = Σ_k qx_ik·qw_kj − z_x·Σ_k qw_kj`로 풀어 뒤 항을 열마다 미리 계산해 둔다. 스케일이 합의 인덱스 k에 따라 달라지면 이렇게 밖으로 뺄 수 없다는 점이 3편에서 중요해진다.

## W4A16, W8A8: 무엇을 양자화했나
| 표기 | 가중치 | 활성값 | 주로 얻는 것 |
|---|---|---|---|
| W8A16 | INT8 | BF16 | 메모리 절반 |
| W4A16 | INT4 | BF16 | 메모리, 디코드 속도 |
| W8A8 | INT8·FP8 | INT8·FP8 | 연산 처리량 |
| W4A8 | INT4 | INT8·FP8 | 둘 다 |

W는 가중치, A는 활성값의 비트 수다. **가중치 전용** 양자화(W4A16 등)는 커널 안에서 가중치를 BF16으로 되돌려 곱하므로 연산량은 그대로지만 읽는 바이트가 줄어 메모리 바운드인 디코드가 빨라진다. GPTQ·AWQ(11편)가 주로 이 형태다. **가중치·활성값** 양자화(W8A8)는 위 식처럼 정수나 FP8 텐서 코어로 곱해 연산 바운드인 프리필과 큰 배치에서 이득이 크다. 대신 입력마다 분포가 달라지는 활성값을 실시간으로 양자화해야 해서 더 어렵다(12편). KV 캐시의 비트 수를 덧붙여 적기도 한다.

## 어디에 쓰이나
- AI 기초 4편 「컴퓨터 사이언스로 보는 AI 모델: 텐서, 연산, 메모리」: 그 글의 "모델 크기 = 파라미터 수 × 바이트 수"와 "생성 속도 ≈ 대역폭 ÷ 모델 크기"가 비트 수를 줄이는 동기다.
- 이산수학 12편 「수 체계와 모듈러 연산: 2진수에서 해시까지」: 고정 폭 정수는 넘치면 2¹⁶을 법으로 감기므로 INT16 누적 실험의 결과가 무의미해졌다.
- 어텐션 8편 「세이지 어텐션: 양자화로 더 빠르게」: 블록별 스케일로 QKᵀ를 INT8로 곱하고 INT32로 누적한 뒤 스케일을 곱하는 것이 이 글의 정수 행렬 곱 그대로다.

## 정리
- 균일 양자화는 `q = clip(round(x/s) + z)`, `x̂ = s·(q − z)`이고 정수 영점 덕분에 0은 정확히 표현된다. 대칭은 z = 0, 비대칭은 [min, max]를 격자 전체에 맞춘다.
- Δ가 분포보다 충분히 작으면 반올림 오차는 [−Δ/2, Δ/2]의 균등 분포라 MSE = Δ²/12이고, 비트 하나에 SQNR이 약 6dB 오른다. 2비트처럼 격자가 거칠면 이 모델이 깨진다.
- 정수 행렬 곱은 스케일을 합 밖으로 빼고 INT32로 누적한다.
- W4A16은 메모리 바운드인 디코드를, W8A8은 연산 바운드인 프리필을 빠르게 한다.

1. **양자화의 기본: 실수를 정수 격자에 올리기** ← 지금 읽는 글
2. 수 형식의 지도: FP32에서 FP4까지
3. 가중치와 활성값의 분포: 이상치가 비트를 낭비하는 이유
4. 양자화 오차의 전파: 잡음은 층을 지나며 어떻게 커지나
5. 임베딩 공간의 기하: 양자화가 이웃 관계를 흔드는 방식
6. 잠재 공간과 중첩: 표현에 남은 여유가 줄어들 때
7. 지식은 몇 비트에 저장되나: 용량과 압축의 한계
8. 왜 드문 지식이 먼저 사라지나: 데이터 분포와 롱테일
9. 학습 후 양자화의 기본: 반올림, 클리핑, 비균일 격자
10. 이상치 다루기: LLM.int8(), SmoothQuant, 회전
11. 오차를 보정하는 양자화: GPTQ와 AWQ
12. KV 캐시·활성값·FP8: 추론과 학습의 저정밀화
13. 양자화 인식 학습과 극단적 저비트: QAT, QLoRA, BitNet
14. GGUF: 양자화 모델을 담는 파일과 k-quant
15. CPU 오프로드: GPU 메모리보다 큰 모델 돌리기
