# [양자화 13/15] 양자화 인식 학습과 극단적 저비트: QAT, QLoRA, BitNet

> **한 줄 요약** — 양자화 인식 학습(QAT)은 순전파에서 가중치를 격자에 올린 값으로 계산하고 역전파에서는 반올림을 항등 함수로 취급(STE)해, 모델이 양자화된 상태에서 손실이 작아지도록 가중치를 옮기며, 이 원리가 NF4 기반 모델 위에 어댑터만 학습하는 QLoRA와 가중치를 {−1, 0, 1}로 처음부터 학습하는 BitNet b1.58까지 이어진다.

## 가짜 양자화와 STE
QAT는 실수 가중치 W를 그대로 들고 있으면서, 순전파에서는 양자화했다가 되돌린 값 Q(W)를 쓴다. 이를 **가짜 양자화**(fake quantization)라 한다. 문제는 역전파다. round는 거의 모든 점에서 미분이 0이라 기울기가 W까지 오지 않는다. **직선 통과 추정기**(straight-through estimator, STE)는 이 미분을 1로 바꿔 계산한다. 벤지오(Bengio) 등이 2013년 확률적 뉴런의 기울기 추정을 다룬 논문에서 이름 붙인 방법이다.
```text
순전파:  ŷ = f(x; Q(W))
역전파:  ∂L/∂W ≈ ∂L/∂Q(W)      (∂Q/∂W를 1로 취급)
갱신:    W ← W − η · ∂L/∂Q(W)
```

W는 격자 사이를 자유롭게 움직이다가 격자점의 경계를 넘을 때만 Q(W)가 바뀐다. 손실은 언제나 양자화된 모델에서 재므로, 학습은 "양자화한 뒤에 손실이 작은 W"를 찾는다. 11편의 GPTQ가 층 하나의 출력 오차를 2차 근사로 보정했다면, QAT는 비선형성과 여러 층을 거친 최종 손실을 직접 줄인다. 같은 구조의 교사망이 만든 가상의 데이터로 2층 MLP를 FP로 학습한 뒤, 같은 비트에서 PTQ(그냥 반올림)와 QAT(가짜 양자화로 2,000스텝 이어 학습)를 비교한다.
```python
import numpy as np

rng = np.random.default_rng(0)
d, h, o = 32, 64, 8
T1, T2 = rng.normal(size=(d, h)), rng.normal(size=(h, o)) / 4   # 가상의 교사망
def data(n):
    X = rng.normal(size=(n, d))
    return X, np.maximum(X @ T1, 0) @ T2

def quant(W, bits):                         # 출력 채널(열)별 대칭 격자
    if bits == 1.58:                        # 삼진 absmean: {−1, 0, 1}·γ
        g = np.abs(W).mean(0, keepdims=True)
        return np.clip(np.round(W / g), -1, 1) * g
    s = np.abs(W).max(0, keepdims=True) / (2 ** (bits - 1) - 1)
    return np.round(W / s) * s

def train(W, steps, bits=None, lr=1e-3):    # Adam; bits가 있으면 가짜 양자화
    m, v = [0 * w for w in W], [0 * w for w in W]
    for t in range(1, steps + 1):
        X, Y = data(256)
        W1, W2 = [quant(w, bits) if bits else w for w in W]  # 순전파는 Q(W)
        H = np.maximum(X @ W1, 0)
        G = 2 * (H @ W2 - Y) / Y.size
        grads = [X.T @ ((G @ W2.T) * (H > 0)), H.T @ G]  # ∂L/∂Q(W)
        for i, g in enumerate(grads):       # STE: ∂L/∂W ≈ ∂L/∂Q(W)
            m[i] = 0.9 * m[i] + 0.1 * g
            v[i] = 0.999 * v[i] + 0.001 * g * g
            mh, vh = m[i] / (1 - 0.9**t), v[i] / (1 - 0.999**t)
            step = mh / (np.sqrt(vh) + 1e-8)
            W[i] -= lr * (1 - t / steps) * step   # 학습률 선형 감소
    return W

def init(h):
    return [rng.normal(size=(d, h)) / np.sqrt(d), rng.normal(size=(h, o)) / 8]

Xt, Yt = data(4096)                         # 평가 데이터
def loss(W, bits=None):                     # 상대 MSE
    W1, W2 = [quant(w, bits) if bits else w for w in W]
    return np.mean((np.maximum(Xt @ W1, 0) @ W2 - Yt) ** 2) / np.mean(Yt ** 2)

W = train(init(h), 8000, lr=1e-2)
print(f"FP 학습: {loss(W):.4f}")
for bits in [4, 3, 1.58]:
    Wq = train([w.copy() for w in W], 2000, bits)   # FP 모델에서 이어 학습
    print(f"{bits}비트  PTQ {loss(W, bits):.4f}  QAT {loss(Wq, bits):.4f}")
```
```text
FP 학습: 0.0003
4비트  PTQ 0.0143  QAT 0.0127
3비트  PTQ 0.0767  QAT 0.0546
1.58비트  PTQ 0.4137  QAT 0.0937
```

FP 모델은 교사망을 거의 완벽히 따라 하지만(0.03%), 반올림만 하면 4비트에서 1.4%, 3비트에서 7.7%, 삼진에서 41%의 오차가 생긴다. QAT는 모든 비트에서 PTQ보다 낫고, 비트가 적을수록 차이가 크다. 4비트에서는 1.4% → 1.3%로 조금, 3비트에서는 7.7% → 5.5%, 삼진에서는 41% → 9.4%로 4분의 1이 된다. 비트가 넉넉하면 9~11편의 PTQ로 충분하고, 비트가 극단적으로 적을수록 학습이 필요하다는 뜻이다.

## QLoRA: 얼린 NF4 모델 위의 어댑터
QLoRA(Dettmers 등, 2023)는 미세 조정의 메모리를 줄인다. 기반 모델의 가중치를 9편의 NF4(블록 64개마다 absmax 스케일)로 얼려 두고, 학습은 BF16의 저랭크 어댑터 LoRA(`W + L₁L₂`, 랭크 r ≪ d)만 한다. 순전파마다 NF4를 BF16으로 역양자화해 곱하고, 기울기는 얼린 4비트 모델을 통과해 어댑터로만 흐른다. 여기에 두 가지를 더했다.
- **이중 양자화**(double quantization): 블록 64개마다 둔 FP32 스케일 자체가 파라미터당 32/64 = 0.5비트다. 이 스케일들을 다시 256개 블록 단위의 FP8로 양자화한다.
- **페이지드 옵티마이저**(paged optimizer): 긴 시퀀스에서 메모리가 순간적으로 튈 때 옵티마이저 상태를 CPU 메모리로 넘긴다.
```python
dq0 = 32 / 64                               # FP32 스케일, 블록 64개마다
dq1 = 8 / 64 + 32 / (64 * 256)              # FP8 스케일 + 2단계 FP32 스케일
print(f"스케일 비용 {dq0:.3f} → {dq1:.3f}비트/파라미터, 절약 {dq0 - dq1:.3f}")
for n in [7e9, 65e9]:
    print(f"{n / 1e9:.0f}B: NF4 + 이중 양자화 {n * (4 + dq1) / 8 / 1e9:.1f}GB,"
          f" BF16 {n * 2 / 1e9:.0f}GB")
```
```text
스케일 비용 0.500 → 0.127비트/파라미터, 절약 0.373
7B: NF4 + 이중 양자화 3.6GB, BF16 14GB
65B: NF4 + 이중 양자화 33.5GB, BF16 130GB
```

이중 양자화로 스케일 비용이 파라미터당 0.5비트에서 0.127비트로 약 0.37비트 준다. 65B 모델의 가중치는 BF16 130GB에서 33.5GB가 된다. 논문은 이렇게 65B 모델을 48GB GPU 한 장에서 16비트 미세 조정과 같은 성능으로 미세 조정할 수 있다고 보고했다. 이렇게 만든 Guanaco는 GPU 한 장에서 24시간 미세 조정해 비쿠냐(Vicuna) 벤치마크에서 ChatGPT의 99.3%에 이르렀다고 하는데, 논문 스스로 당시의 챗봇 벤치마크는 믿을 만하지 않다고 덧붙였다.

## BitNet b1.58: 가중치를 {−1, 0, 1}로
BitNet b1.58(Ma 등, 2024)은 가중치를 세 값 {−1, 0, 1}로 제한한다. 값 하나의 정보량이 log₂3 ≈ 1.58비트라 붙은 이름이다. 가중치 행렬마다 평균 절댓값 γ로 나눈 뒤 반올림해 [−1, 1]로 자르는 **absmean 양자화**를 쓰고, 활성값은 토큰별 absmax로 8비트 양자화한다.
```text
γ = (1/nm) Σ∣W_ij∣,   W̃ = RoundClip(W / (γ + ε), −1, 1)
RoundClip(x, a, b) = max(a, min(b, round(x)))
```

absmean이 왜 absmax가 아닌지, 그리고 삼진 가중치의 곱셈이 어떻게 사라지는지 확인한다.
```python
rng = np.random.default_rng(0)
W = rng.normal(size=(1024, 1024)) * 0.02    # 가상의 가중치
x = rng.normal(size=1024)

def ternary(W, gamma):                      # RoundClip(W/(γ+ε), −1, 1)
    return np.clip(np.round(W / (gamma + 1e-6)), -1, 1)

rel = lambda a: np.linalg.norm(a - W) / np.linalg.norm(W)
for name, g in [("absmean", np.abs(W).mean()), ("absmax", np.abs(W).max())]:
    T = ternary(W, g)
    best = (T * W).sum() / (T * T).sum()    # 같은 T에서 오차 최소 스케일
    print(f"{name}: 0의 비율 {np.mean(T == 0):.3f},"
          f" 오차(γ) {rel(T * g):.3f}, 오차(최적 스케일) {rel(T * best):.3f}")

T, g = ternary(W, np.abs(W).mean()), np.abs(W).mean()
y_add = np.array([x[c == 1].sum() - x[c == -1].sum() for c in T.T])  # 곱셈 없음
print("덧셈·뺄셈만으로 x·T:", np.allclose(y_add, x @ T))
print(f"log2(3) = {np.log2(3):.3f}, 3^5 = {3**5} ≤ 256 → 값당 {8 / 5}비트")
```
```text
absmean: 0의 비율 0.310, 오차(γ) 0.513, 오차(최적 스케일) 0.461
absmax: 0의 비율 0.987, 오차(γ) 0.979, 오차(최적 스케일) 0.949
덧셈·뺄셈만으로 x·T: True
log2(3) = 1.585, 3^5 = 243 ≤ 256 → 값당 1.6비트
```

absmean은 가중치의 31%를 0으로, 나머지를 ±γ로 보낸다. 정규 분포라면 γ = 0.80σ이고 ∣w∣ < γ/2 = 0.40σ일 확률이 0.31이다. absmax로 나누면 98.7%가 0이 되어 정보가 거의 남지 않는다. absmean이어도 가중치 오차가 51%(최적 스케일이어도 46%)라 반올림만으로는 쓸 수 없고, 학습 중에 이 제약에 맞춰야 한다. 대신 x·W̃는 x의 원소를 더하고 빼기만 하면 되어 곱셈기가 필요 없다. 값 다섯 개를 한 바이트에 담으면(3⁵ = 243 ≤ 256) 값당 1.6비트로 log₂3에 가깝다. 논문은 처음부터 이렇게 학습한 BitNet b1.58이 3B 크기부터 FP16 LLaMA와 퍼플렉서티가 비슷해지고, 그 크기에서 2.71배 빠르며 GPU 메모리를 3.55배 적게 쓴다고 보고했다.

## 왜 학습으로 만들어야 하나
QAT 실험에서 삼진 PTQ는 41%로 무너졌고 학습을 거치자 9.4%가 되었다. 비트가 극단적으로 적으면 반올림 자체가 모델을 크게 바꾸므로, 양자화된 상태에서 손실을 줄이는 학습이 필요하다. 또 하나는 용량이다. 7편에서 본 것처럼 모델이 담는 정보는 파라미터 수 × 파라미터당 비트에 묶이므로, 파라미터당 비트를 1.58로 줄이면 같은 것을 담는 데 파라미터가 더 필요하다. 처음부터 학습하면 처음부터 그 크기로 설계할 수 있다. 첫 코드에 이어서, 삼진 가중치로 처음부터 학습하며 은닉 폭을 늘려 본다.
```python
kib = lambda h, b: (d * h + h * o) * b / 8 / 1024
print(f"FP16 폭 64: {kib(64, 16):.1f}KiB")
for hh in [64, 128, 256]:                   # 삼진 가중치로 처음부터 학습
    Wt = train(init(hh), 8000, 1.58, lr=3e-3)
    print(f"삼진 폭 {hh}: {loss(Wt, 1.58):.4f}, 가중치 {kib(hh, 1.58):.1f}KiB")
```
```text
FP16 폭 64: 5.0KiB
삼진 폭 64: 0.1083, 가중치 0.5KiB
삼진 폭 128: 0.0647, 가중치 1.0KiB
삼진 폭 256: 0.0407, 가중치 2.0KiB
```

같은 폭 64에서 처음부터 학습한 삼진 모델은 10.8%로, FP 모델에서 이어 학습한 QAT(9.4%)와 비슷하다. 폭을 4배로 늘리면 4.1%로 절반 아래가 되는데, 가중치는 2.0KiB로 FP16 폭 64 모델(5.0KiB)의 40%다. 비트를 줄인 만큼 파라미터를 늘려 메우는 것이 극단적 저비트의 설계 방식이다. 이 장난감 예에서는 교사망이 폭 64라 FP 모델이 거의 완벽해서, 삼진 모델이 FP를 따라잡지는 못했다.

## 실전 선택 가이드
| 상황 | 방법 | 형식 |
|---|---|---|
| GPU 한 장 추론 | GPTQ·AWQ | W4A16 g128 |
| 큰 배치 서빙 | SmoothQuant·FP8 | W8A8 |
| 긴 문맥 | KV 양자화 | K·V 4~2비트 |
| 활성값도 4비트 | 회전 + GPTQ | W4A4 |
| 저메모리 미세 조정 | QLoRA | NF4 + LoRA |
| 2비트 이하 | QAT·처음부터 학습 | 삼진 |

위에서부터 차례로 11편, 10·12편, 12편, 10편, 이 글(QLoRA), 이 글(QAT·삼진)에서 다뤘다.

표는 출발점일 뿐이고 결론은 평가가 낸다. 4편에서 본 것처럼 층마다 민감도가 달라 임베딩과 출력 헤드는 높은 정밀도로 남기는 경우가 많다(5편). 8편에서 본 것처럼 퍼플렉서티나 평균 정확도는 그대로인데 드문 지식만 무너질 수 있으므로, 롱테일 사실·저자원 언어·긴 문맥 과제를 따로 확인해야 한다.

## 지금까지의 정리
1~4편은 기본(격자와 오차, 수 형식, 분포, 오차 전파), 5~8편은 양자화가 표현과 지식에 남기는 차이(임베딩 이웃, 중첩과 여유, 비트로 센 용량, 롱테일), 9~13편은 그 차이를 줄이는 기술(클리핑과 비균일 격자, 이상치 처리, 오차 보정, KV 캐시와 FP8, 학습)을 다뤘다. 이어지는 14·15편은 이렇게 양자화한 모델을 실제로 받아 돌릴 때 만나는 GGUF 파일 형식과 CPU 오프로드를 다룬다. 한 문장으로 줄이면, 양자화 오차는 피할 수 없는 잡음이고, 좋은 양자화는 그 잡음을 모델이 덜 쓰는 곳(작은 헤시안 방향, 덜 중요한 채널, 고르게 퍼진 좌표)으로 보내거나 학습으로 모델을 잡음에 맞추는 일이다.

## 어디에 쓰이나
- AI 기초 1편 「딥러닝: 특징까지 스스로 배우는 머신러닝」: QAT는 그 글의 역전파와 경사 하강법을 그대로 쓰되, 미분이 0인 반올림만 STE로 건너뛴다.
- 선형대수 10편 「특이값 분해(SVD)」: LoRA 어댑터 L₁L₂는 랭크 r 행렬이라, 미세 조정에 필요한 변화가 특이값 몇 개로 표현된다는 가정 위에 있다.
- 7편 「지식은 몇 비트에 저장되나: 용량과 압축의 한계」: 삼진 모델이 폭을 늘려야 했던 이유가 파라미터 수 × 비트로 센 용량이다.
- 8편 「왜 드문 지식이 먼저 사라지나: 데이터 분포와 롱테일」: 양자화 결과를 평균 지표가 아니라 드문 지식까지 평가해야 하는 이유다.

## 정리
- QAT는 순전파에 가짜 양자화를 넣고 STE로 기울기를 통과시켜 양자화된 모델의 손실을 직접 줄인다. 실험에서 삼진 오차가 PTQ 41%에서 QAT 9.4%로 줄었다.
- QLoRA는 NF4로 얼린 모델에 LoRA만 학습하고, 이중 양자화로 스케일 비용을 0.5에서 0.127비트로 줄였다.
- BitNet b1.58은 absmean으로 가중치를 {−1, 0, 1}로 만들어 곱셈을 덧셈으로 바꾸고, 처음부터 학습해 3B부터 FP16 모델에 맞먹었다고 보고됐다.
- 비트가 적을수록 학습이, 줄인 비트만큼 파라미터가 필요하며, 결과는 롱테일 지식까지 평가해야 한다.
