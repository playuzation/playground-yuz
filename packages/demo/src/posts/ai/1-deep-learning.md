## 머신러닝에서 출발하기
전통적인 프로그래밍에서는 사람이 규칙을 코드로 쓰고, 컴퓨터는 그 규칙대로 데이터를 처리한다. **머신러닝**은 반대로 데이터와 정답을 주고 컴퓨터가 규칙을 찾게 한다.
```text
전통적 프로그래밍: 규칙 + 데이터 → 답
머신러닝:          데이터 + 답   → 규칙(모델)
```

머신러닝 모델은 입력 x를 받아 예측 ŷ을 내놓는 함수 `f(x; θ)`이고, θ는 학습으로 정해지는 숫자들, 즉 **파라미터**다. 학습이란 예측 ŷ과 정답 y의 차이(**손실**)가 작아지도록 θ를 고쳐 나가는 과정이다.

딥러닝 이전에는 모델에 무엇을 입력으로 줄지, 즉 **특징**을 사람이 설계하는 것이 성능을 좌우했다. 사진에서 고양이를 찾으려면 "모서리가 어디 있는가", "털 질감이 있는가" 같은 값을 뽑아내는 코드를 사람이 먼저 짜야 했다. 딥러닝은 원본 픽셀을 그대로 넣고, 여러 층을 거치며 특징까지 함께 학습한다. 앞쪽 층은 선과 모서리 같은 단순한 패턴을, 뒤쪽 층은 눈·귀·얼굴 같은 복잡한 패턴에 반응하는 경향이 있다.

## 신경망의 구성
### 뉴런 하나
인공 뉴런은 입력마다 가중치를 곱해 더하고, 그 결과를 **활성화 함수**에 통과시킨다.
```text
출력 = 활성화(w₁·x₁ + w₂·x₂ + … + wₙ·xₙ + b)
```

### 층을 쌓기
뉴런을 여러 개 나란히 모은 것이 **층**이고, 층을 깊게 쌓은 것이 **심층 신경망**이다. 딥러닝의 "딥(deep)"은 바로 이 층의 깊이를 뜻한다.

### 활성화 함수가 필요한 이유
선형 변환(곱하고 더하기)은 아무리 여러 번 겹쳐도 결국 하나의 선형 변환이다. 층 사이에 ReLU(`max(0, x)`)나 tanh 같은 **비선형** 함수를 넣어야 깊이가 의미를 가지고, 곡선처럼 복잡한 경계도 표현할 수 있다.

## 학습: 손실을 따라 내려가기
1. **순전파**: 입력을 넣어 예측을 계산한다.
2. **손실 계산**: 예측과 정답의 차이를 숫자 하나로 만든다. 회귀에는 평균제곱오차, 분류에는 교차 엔트로피를 주로 쓴다.
3. **역전파**: 미분의 연쇄 법칙으로 손실에 대한 각 파라미터의 기울기(gradient)를 출력층에서부터 거꾸로 계산한다.
4. **경사 하강법**: 기울기의 반대 방향으로 파라미터를 조금 옮긴다. 식으로 쓰면 `θ ← θ − η·∇L(θ)`이고, η는 한 번에 얼마나 움직일지 정하는 **학습률**이다.

이 네 단계를 데이터 묶음(미니배치)을 바꿔 가며 수없이 반복한다. 아래는 NumPy만으로 작성한 2층 신경망이 XOR 문제를 배우는 전체 코드다. XOR은 직선 하나로는 나눌 수 없어서, 은닉층과 비선형 활성화가 왜 필요한지 보여 주는 고전적인 예다.
```python
import numpy as np

rng = np.random.default_rng(0)
X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], dtype=float)
y = np.array([[0], [1], [1], [0]], dtype=float)   # XOR: 직선 하나로는 나눌 수 없다

W1, b1 = rng.normal(size=(2, 8)), np.zeros(8)     # 은닉층: 뉴런 8개
W2, b2 = rng.normal(size=(8, 1)), np.zeros(1)     # 출력층: 뉴런 1개

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

for step in range(5000):
    h = np.tanh(X @ W1 + b1)          # 순전파: 은닉층 (비선형 활성화)
    p = sigmoid(h @ W2 + b2)          # 순전파: 출력 = 1일 확률
    dz2 = (p - y) / len(X)            # 역전파: 교차 엔트로피 손실의 기울기
    dW2, db2 = h.T @ dz2, dz2.sum(0)
    dz1 = (dz2 @ W2.T) * (1 - h**2)   # 연쇄 법칙으로 한 층 더 거꾸로
    dW1, db1 = X.T @ dz1, dz1.sum(0)
    for param, grad in ((W1, dW1), (b1, db1), (W2, dW2), (b2, db2)):
        param -= 0.5 * grad           # 경사 하강법 (학습률 0.5)

print(p.round(2).ravel())  # [0. 1. 1. 0.]
```

실제 프레임워크(PyTorch 등)는 3~5단계의 기울기 계산을 자동으로 해 준다. 그 원리는 4편 「컴퓨터 사이언스로 보는 AI 모델」의 자동 미분에서 다룬다.

## 대표적인 구조
| 구조 | 핵심 아이디어 | 잘하는 일 |
|---|---|---|
| CNN (합성곱 신경망) | 작은 필터를 이미지 전체에 밀며 같은 가중치를 공유한다 | 이미지 분류, 객체 탐지 |
| RNN · LSTM | 이전 시점의 상태를 다음 시점으로 넘긴다 | 시계열 예측, (예전의) 번역·음성 인식 |
| 트랜스포머 | 어텐션으로 모든 위치가 서로를 직접 참조한다 | 언어 모델, 번역, 이미지·음성으로도 확장 |

트랜스포머는 2017년 논문 「Attention Is All You Need」에서 제안되었고, 지금의 대규모 언어 모델은 대부분 이 구조를 쓴다.

## 왜 2010년대에 급성장했나
신경망이라는 아이디어는 1958년 퍼셉트론까지 거슬러 올라간다. 흐름이 크게 바뀐 것은 2012년 이미지 인식 대회(ImageNet)에서 딥러닝 모델 AlexNet이 기존 방법을 큰 차이로 앞서면서다. 그 배경에는 세 가지가 함께 맞물려 있었다.
- **데이터**: 인터넷 덕분에 수백만 장 규모의 라벨 붙은 데이터가 생겼다.
- **연산**: 행렬 곱을 대량으로 병렬 처리하는 GPU를 학습에 쓰기 시작했다.
- **알고리즘**: ReLU, 드롭아웃, 더 나은 초기화와 최적화 기법이 깊은 망의 학습을 가능하게 했다.

## 한계와 주의할 점
- **데이터와 연산이 많이 든다.** 표 형태의 작은 데이터에서는 그래디언트 부스팅 같은 전통적 방법이 더 나은 경우도 많다.
- **설명하기 어렵다.** 수많은 파라미터가 왜 그런 답을 냈는지 사람이 이해하기 어렵다.
- **학습 때 보지 못한 데이터에 약하다.** 이 문제는 3편 「데이터 분포로 보는 AI 모델」에서 자세히 다룬다.

## 정리
- 딥러닝은 데이터로 함수를 배우는 머신러닝 가운데, 깊은 신경망으로 특징까지 학습하는 방법이다.
- 학습은 순전파 → 손실 계산 → 역전파 → 경사 하강법의 반복이다.
- 데이터, GPU, 알고리즘의 발전이 함께 맞물려 2010년대 이후 급격히 발전했다.
