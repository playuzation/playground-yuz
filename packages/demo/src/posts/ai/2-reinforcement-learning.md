# [AI 기초 2/4] 강화학습: 보상으로 배우는 머신러닝

> **한 줄 요약** — 강화학습은 정답 대신 보상을 받으며 시행착오를 거쳐, 앞으로 받을 보상의 합이 가장 커지는 행동 방식(정책)을 스스로 찾아가는 머신러닝 방법이다.

## 이 글에서 다루는 것

- 에이전트와 환경, 마르코프 결정 과정(MDP)
- 정책, 가치 함수, 탐험과 활용
- 예제: Q-러닝으로 길 찾기
- 딥 강화학습과 실제 사례, 어려운 점

## 머신러닝의 세 갈래
| 갈래 | 학습 신호 | 예시 |
|---|---|---|
| 지도 학습 | 입력마다 붙은 정답 라벨 | 스팸 분류, 집값 예측 |
| 비지도 학습 | 정답 없이 데이터의 구조만 | 고객 군집화, 차원 축소 |
| 강화학습 | 행동의 결과로 받는 보상 | 게임 플레이, 로봇 제어 |

지도 학습은 "이 사진은 고양이"처럼 입력마다 정답을 알려 준다. 강화학습에는 그런 정답이 없다. 바둑에서 어떤 수가 좋은 수였는지는 대국이 끝나 이겼는지 졌는지로만 드러난다. 이렇게 **늦게 도착하는 보상**을 보고, 그 전에 한 수많은 행동 중 무엇이 좋았는지 거꾸로 따져야 한다는 점이 강화학습의 핵심 난제다. 이를 **신용 할당 문제**라고 부른다.

## 에이전트와 환경
```text
에이전트 ──(행동 a)──────────→ 환경
에이전트 ←──(다음 상태 s′, 보상 r)── 환경
```

학습하는 주체를 **에이전트**, 에이전트가 행동하는 세계를 **환경**이라고 한다. 에이전트가 행동하면 환경은 다음 상태와 보상을 돌려주고, 이 주고받기가 반복된다. 이 상호작용은 보통 **마르코프 결정 과정**(MDP)으로 정의한다.
- **상태 s**: 지금 상황 (게임 화면, 로봇 관절의 각도)
- **행동 a**: 에이전트가 고를 수 있는 선택지
- **전이 확률 P(s′ | s, a)**: 상태 s에서 행동 a를 했을 때 다음 상태가 s′이 될 확률
- **보상 r**: 행동의 결과로 받는 숫자
- **할인율 γ**(0~1): 미래의 보상을 지금 가치로 얼마나 깎아서 볼지

"마르코프"는 다음 상태가 지금 상태와 행동에만 달려 있고, 그보다 이전의 역사는 필요 없다는 가정이다.

## 정책과 가치
- **정책 π(a | s)**: 상태 s에서 행동 a를 고를 확률. 강화학습이 최종적으로 얻고 싶은 것이다.
- **반환값 G**: 앞으로 받을 보상의 할인된 합. `G = r₁ + γ·r₂ + γ²·r₃ + …`
- **상태 가치 V(s)**: 상태 s에서 시작해 정책을 따를 때 기대되는 반환값
- **행동 가치 Q(s, a)**: 상태 s에서 행동 a를 한 뒤 정책을 따를 때 기대되는 반환값

Q를 정확히 알고 있다면 좋은 정책을 만드는 것은 쉽다. 각 상태에서 Q가 가장 큰 행동을 고르면 된다.

## 탐험과 활용
지금까지 가장 좋았던 행동만 고르면(**활용**) 더 좋은 행동을 영영 발견하지 못할 수 있다. 그래서 가끔은 일부러 새로운 행동을 시도해야 한다(**탐험**). 가장 단순한 방법은 **ε-탐욕** 전략이다. 확률 ε로는 무작위 행동을 하고, 나머지 확률로는 지금까지 가장 좋았던 행동을 한다.

## 예제: Q-러닝으로 길 찾기
다섯 칸짜리 복도의 왼쪽 끝(칸 0)에서 출발해 오른쪽 끝(칸 4)에 도착하면 보상 1을 받는 환경이다. 에이전트는 처음에는 아무것도 모른 채 움직이면서 Q 표를 채워 나간다.
```python
import random

N, GOAL = 5, 4                      # 칸 0~4, 칸 4에 도착하면 끝
ACTIONS = (-1, +1)                  # 왼쪽, 오른쪽
Q = [[0.0, 0.0] for _ in range(N)]  # Q[상태][행동]
alpha, gamma, epsilon = 0.5, 0.9, 0.1

random.seed(0)
for episode in range(200):
    s = 0
    while s != GOAL:
        if random.random() < epsilon:                # 탐험: 무작위 행동
            a = random.randrange(2)
        else:                                        # 활용: Q가 큰 행동 (같으면 무작위)
            a = max((0, 1), key=lambda i: (Q[s][i], random.random()))
        s2 = min(max(s + ACTIONS[a], 0), N - 1)
        r = 1.0 if s2 == GOAL else 0.0
        target = r if s2 == GOAL else r + gamma * max(Q[s2])
        Q[s][a] += alpha * (target - Q[s][a])        # Q-러닝 갱신
        s = s2

print([round(max(q), 2) for q in Q])  # [0.73, 0.81, 0.9, 1.0, 0.0]
```

핵심은 한 줄짜리 갱신식이다.
```text
Q(s, a) ← Q(s, a) + α · [ r + γ · max Q(s′, ·) − Q(s, a) ]
```

"방금 받은 보상 + 다음 상태에서 기대할 수 있는 최선의 가치"를 목표로 삼아, 현재 추정치를 학습률 α만큼 그쪽으로 끌어당긴다. 목표값 자체도 아직 학습 중인 추정치로 만든다는 점(**부트스트래핑**)이 특징이다. 출력을 보면 목표에 가까운 칸일수록 가치가 크고, 한 칸 멀어질 때마다 γ(0.9)배씩 작아진다(1.0 → 0.9 → 0.81 → 0.73). 도착 칸(칸 4)은 거기서 끝나므로 가치가 0이다.

## 딥 강화학습
상태가 바둑판이나 게임 화면처럼 셀 수 없이 많으면 Q를 표에 담을 수 없다. 그래서 Q나 정책을 **신경망으로 근사**한다(1편 「딥러닝」 참고).
- **DQN**(2013~2015): 딥마인드가 화면 픽셀만 보고 아타리 게임을 배우게 해, 여러 게임에서 사람 수준을 넘었다.
- **AlphaGo**(2016): 지도 학습, 강화학습, 트리 탐색을 결합해 이세돌 9단을 4대 1로 이겼다.
- **RLHF**: 사람이 매긴 선호를 학습한 보상 모델을 만들고, 그 보상으로 언어 모델을 강화학습해 더 유용하고 안전한 답을 하도록 조정한다.

## 어려운 점
- **표본 효율**: 사람이라면 몇 판이면 익힐 게임도 수백만 번 시행해야 할 수 있다. 그래서 실제 로봇 대신 시뮬레이터 안에서 학습하는 경우가 많다.
- **보상 설계**: 보상을 잘못 정하면 에이전트가 의도와 다른 허점을 파고든다(**보상 해킹**). 결승선 대신 점수 아이템만 노리고 같은 자리를 빙빙 도는 보트 경주 게임 에이전트가 유명한 예다.
- **불안정한 학습**: 학습 데이터를 에이전트 자신이 행동하며 만들기 때문에, 정책이 바뀌면 데이터의 분포도 함께 바뀐다. 이 점은 3편 「데이터 분포로 보는 AI 모델」과 이어진다.

## 정리
- 강화학습은 정답 대신 보상을 받으며, 시행착오로 누적 보상을 최대화하는 정책을 배운다.
- MDP, 정책, 가치 함수, 탐험과 활용이 기본 개념이다.
- 신경망과 결합한 딥 강화학습이 게임, 로봇, 언어 모델 조정(RLHF)에까지 쓰인다.
