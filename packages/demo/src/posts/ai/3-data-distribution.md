# [AI 기초 3/4] 데이터 분포로 보는 AI 모델

> **한 줄 요약** — AI 모델은 학습 데이터가 나온 확률 분포를 근사한 것이며, 모델이 잘하는 일과 실패하는 일의 대부분은 "학습할 때 본 분포와 실제로 쓸 때 만나는 분포가 얼마나 같은가"로 설명된다.

## 이 글에서 다루는 것
- 데이터를 확률 분포에서 뽑은 표본으로 보기
- 판별 모델과 생성 모델: 각각 무엇의 분포를 배우나
- 학습은 분포를 맞추는 일: 최대 우도와 교차 엔트로피
- 일반화와 과적합
- 분포가 바뀔 때와 분포 밖 입력
- 언어 모델을 분포로 이해하기

## 데이터는 분포에서 뽑은 표본이다
세상에 존재할 수 있는 모든 고양이 사진을 떠올려 보자. 우리가 모은 학습 데이터는 그 거대한 모집단에서 뽑힌 일부일 뿐이다. 이 모집단이 따르는 확률 분포를 **데이터 분포**라고 하고 `p_data`로 쓴다. 모델이 정말로 배워야 하는 것은 우리가 가진 사진 몇만 장이 아니라, 그 뒤에 있는 `p_data`다.

머신러닝의 기본 가정은 **i.i.d.**(독립 동일 분포)다. 학습 데이터와 나중에 모델이 실제로 만날 데이터가 모두 같은 분포에서, 서로 독립적으로 뽑혔다고 보는 것이다. 이 가정이 성립하면 학습 데이터에서 잘하는 모델은 실전에서도 잘한다. 성립하지 않으면 그런 보장이 사라진다.

## 무엇의 분포를 배우나
| 종류 | 배우는 분포 | 모델이 답하는 질문 | 예 |
|---|---|---|---|
| 판별 모델 | `p(y∣x)` | 이 입력의 정답은 무엇일 가능성이 큰가? | 스팸 분류, 이미지 분류 |
| 생성 모델 | `p(x)` 또는 `p(x, y)` | 이런 데이터가 나올 가능성은 얼마인가? 새 표본을 만들 수 있는가? | 이미지 생성, 언어 모델 |

판별 모델은 "x가 주어졌을 때 y의 분포"만 배운다. 고양이 사진이 어떻게 생겼는지 전부 알 필요 없이 고양이와 개를 가르는 경계만 알면 된다. 생성 모델은 데이터 자체가 어떻게 생겼는지를 배우므로, 그 분포에서 새로운 표본을 뽑아 그럴듯한 이미지나 문장을 만들어 낼 수 있다.

## 학습은 분포를 맞추는 일이다
모델이 나타내는 분포 `p_θ`를 데이터 분포 `p_data`에 가깝게 만들려면 두 분포가 얼마나 다른지 잴 방법이 필요하다. 대표적인 척도가 **KL 발산**이다.
```text
KL(p_data ‖ p_θ) = E_{x~p_data}[ log p_data(x) − log p_θ(x) ]
```

괄호 안의 첫 항은 모델과 상관없는 상수다. 따라서 KL을 줄이는 것은 `E[ log p_θ(x) ]`를 키우는 것, 즉 학습 데이터에 높은 확률을 주도록 θ를 고르는 **최대 우도 추정**(MLE)과 같다. 실제로는 `p_data`를 모르므로 기댓값 대신 학습 데이터의 평균을 쓴다.

분류 모델을 학습할 때 쓰는 **교차 엔트로피 손실**은 이 식의 조건부 버전인 `−E[ log p_θ(y∣x) ]`다. 우리가 매일 쓰는 손실 함수가 사실은 "모델의 분포를 데이터 분포에 맞추라"는 명령인 셈이다.

## 일반화와 과적합
우리가 가진 것은 `p_data` 자체가 아니라 거기서 뽑은 유한한 표본(경험적 분포)뿐이다. 모델이 표본의 우연한 특징까지 외워 버리면 학습 데이터에서는 점수가 높지만 새 데이터에서는 성능이 떨어진다. 이것이 **과적합**이다.

| 상태 | 학습 오차 | 검증 오차 | 해석 |
|---|---|---|---|
| 과소적합 | 높음 | 높음 | 모델이 너무 단순해 분포를 담지 못한다 |
| 적정 | 낮음 | 낮음 | 분포를 잘 배웠다 |
| 과적합 | 매우 낮음 | 높음 | 분포가 아니라 표본을 외웠다 |

과적합을 막는 방법도 분포 관점으로 이해할 수 있다.
- **학습·검증·테스트 분할**: 학습에 쓰지 않은 데이터로 재야 `p_data`에서의 성능을 추정할 수 있다.
- **규제**: 가중치 감쇠, 드롭아웃, 데이터 증강은 모델이 표본보다 분포를 배우도록 유도한다.
- **데이터 양**: 표본이 많을수록 경험적 분포가 실제 분포에 가까워진다.

## 분포가 바뀔 때
실제 서비스에서는 i.i.d. 가정이 자주 깨진다. 학습 때와 쓸 때의 분포가 달라지는 것을 **분포 변화**(distribution shift)라고 한다.

| 유형 | 무엇이 바뀌나 | 예 |
|---|---|---|
| 공변량 변화 | 입력 분포 `p(x)` | 낮에 찍은 사진으로 학습한 모델에 밤 사진이 들어온다 |
| 라벨 변화 | 정답 비율 `p(y)` | 독감 유행기에 독감 환자 비율이 갑자기 늘어난다 |
| 개념 변화 | 입력과 정답의 관계 `p(y∣x)` | 사기 수법이 바뀌어 예전 패턴이 더는 사기가 아니다 |

학습 분포에서 아주 드물거나 아예 없던 입력은 **분포 밖**(OOD, out-of-distribution) 입력이라고 한다. 문제는 모델이 이런 입력에도 자신 있게 답한다는 점이다. 고양이와 개만 배운 분류기에 자동차 사진을 넣어도 "개일 확률 97%"처럼 높은 확신을 보일 수 있다. 분류기는 어떤 입력이든 고양이와 개 중 하나에 확률을 나눠 줄 수밖에 없기 때문이다. 모델의 확신도는 학습 분포 안에서만 의미가 있다.

대응 방법은 다음과 같다.
- 배포 후에도 입력 분포와 성능을 계속 모니터링한다.
- 새로 모인 데이터로 주기적으로 다시 학습한다.
- 확신도가 낮거나 분포 밖으로 보이는 입력은 사람이 검토하게 넘긴다.

## 언어 모델을 분포로 이해하기
대규모 언어 모델은 문장의 분포 `p(x)`를 배우는 생성 모델이다. 문장 전체의 확률을 한 번에 다루는 대신, 확률의 연쇄 법칙으로 "앞의 토큰들이 주어졌을 때 다음 토큰의 분포"로 쪼개서 배운다.
```text
p(x₁, x₂, …, xₙ) = p(x₁) · p(x₂ ∣ x₁) · p(x₃ ∣ x₁, x₂) ⋯ p(xₙ ∣ x₁, …, xₙ₋₁)
```

글을 생성할 때는 이 분포에서 토큰을 하나씩 **표본 추출**한다. 이렇게 보면 언어 모델의 여러 현상이 자연스럽게 설명된다.
- **온도**(temperature): 분포를 뾰족하게(낮은 온도) 또는 평평하게(높은 온도) 바꿔 답의 다양성을 조절한다.
- **환각**: 모델이 배운 것은 "사실"이 아니라 "그럴듯한 문장의 분포"다. 학습 데이터에 드문 주제에서는 그럴듯하지만 틀린 문장도 높은 확률을 받을 수 있다.
- **데이터 편향**: 학습 데이터에 많이 등장한 관점과 표현이 더 높은 확률을 받는다. 모델의 편향은 대체로 데이터 분포의 편향이다.

## 정리
- AI 모델은 데이터 분포 `p_data`를 근사하며, 판별 모델은 `p(y∣x)`를, 생성 모델은 `p(x)`를 배운다.
- 교차 엔트로피 최소화, 최대 우도 추정, KL 발산 최소화는 모두 "모델 분포를 데이터 분포에 맞추기"다.
- 모델 실패의 대부분은 과적합(표본을 외움)이나 분포 변화(쓸 때의 분포가 다름)로 설명된다.
