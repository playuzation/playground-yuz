# [확률과 분포 2/12] 조건부 확률과 독립

> **한 줄 요약** — 조건부 확률은 "B가 일어났다"는 정보를 받아 표본 공간을 B로 좁힌 뒤 다시 잰 확률이고, 독립은 그 정보가 A의 확률을 전혀 바꾸지 않는 특별한 경우다.

- 독립의 정의, 그리고 독립과 배반의 차이

## 정보가 들어오면 확률이 바뀐다
주사위를 던졌는데 친구가 결과를 보고 "짝수야"라고만 알려 주었다. 이제 4 이상일 확률은 얼마일까? 처음에는 {4, 5, 6}이라 3/6이었지만, 짝수라는 정보를 들은 순간 가능한 결과는 {2, 4, 6} 세 개로 줄고 그중 4 이상은 {4, 6} 두 개다. 답은 2/3이다.

이렇게 사건 B가 일어났다는 조건에서 A의 확률을 **조건부 확률**이라 하고 `P(A∣B)`로 쓴다.
```text
P(A∣B) = P(A ∩ B) / P(B)      (단, P(B) > 0)
```

P(B)로 나누는 이유는 표본 공간이 Ω에서 B로 줄었기 때문이다. B 안에서 A가 차지하는 비율을 다시 재는 것이고, 줄어든 세계에서 확률의 합이 다시 1이 되도록 맞추는 정규화이기도 하다. 위 예에 대입하면 `P(4 이상∣짝수) = (2/6) / (3/6) = 2/3`이다. 순서를 바꾼 `P(B∣A)`는 일반적으로 다른 값이라는 점에 주의하자. `P(4 이상∣눈이 6) = 1`이지만 `P(눈이 6∣4 이상) = 1/3`이다.

## 곱셈 법칙과 전확률 법칙
정의의 양변에 P(B)를 곱하면 **곱셈 법칙**이 된다.
```text
P(A ∩ B) = P(B) · P(A∣B) = P(A) · P(B∣A)
```

"둘 다 일어날 확률"을 단계별로 계산하게 해 주는 식이다. 52장 카드에서 두 장을 연달아 뽑을 때(돌려놓지 않음) 둘 다 에이스일 확률은, 첫 장이 에이스일 확률 4/52에 그 조건에서 둘째 장도 에이스일 확률 3/51을 곱한 `1/221 ≈ 0.0045`다. 사건이 셋 이상이어도 `P(A ∩ B ∩ C) = P(A) · P(B∣A) · P(C∣A ∩ B)`처럼 이어 붙이면 되고, 이것이 9편에서 다룰 확률의 연쇄 법칙이다.

표본 공간을 겹치지 않는 경우 B₁, …, Bₙ으로 나눌 수 있으면, 경우마다의 기여를 더해 A의 전체 확률을 구할 수 있다. 이것이 **전확률 법칙**이다.
```text
P(A) = P(A∣B₁)·P(B₁) + P(A∣B₂)·P(B₂) + … + P(A∣Bₙ)·P(Bₙ)
```

예를 들어 제품의 60%는 공장 1(불량률 2%), 40%는 공장 2(불량률 5%)에서 만든다면, 무작위로 고른 제품이 불량일 확률은 `0.6 × 0.02 + 0.4 × 0.05 = 0.032`다. 반대로 "불량품이 나왔는데 공장 2에서 왔을 확률"을 묻는 것이 3편 「베이즈 정리: 증거로 믿음을 고치기」의 주제다.

## 독립: 정보가 아무것도 바꾸지 않을 때
B가 일어났다는 정보가 A의 확률을 바꾸지 않으면, 즉 `P(A∣B) = P(A)`이면 A와 B는 **독립**이다. 이를 곱셈 법칙에 넣은 대칭적인 형태를 보통 정의로 쓴다(P(B) = 0인 경우까지 다룰 수 있어서다).
```text
A와 B가 독립  ⇔  P(A ∩ B) = P(A) · P(B)
```

동전을 두 번 던지는 것처럼 서로 영향을 주지 않는 시행은 독립으로 모형화한다. 하지만 독립은 물리적인 분리가 아니라 숫자에 대한 성질이다. 주사위 하나에서 A = 짝수 {2, 4, 6}, B = 2 이하 {1, 2}로 두면 `P(A ∩ B) = P({2}) = 1/6`이고 `P(A) · P(B) = 1/2 × 1/3 = 1/6`이므로, 같은 주사위의 두 사건인데도 독립이다. B를 4 이상 {4, 5, 6}으로 바꾸면 `P(A ∩ B) = 2/6`인데 `P(A) · P(B) = 1/4`이므로 독립이 아니다.

### 독립과 배반은 다르다
흔한 혼동이 "배반이면 독립"이라는 생각이다. 실제로는 정반대에 가깝다.

| 성질 | 정의 | 한쪽이 일어났다는 정보 |
|---|---|---|
| 배반 | `P(A ∩ B) = 0` | 다른 쪽은 절대 안 일어난다 |
| 독립 | `P(A ∩ B) = P(A)·P(B)` | 다른 쪽의 확률을 바꾸지 않는다 |

주사위의 "1이 나옴"과 "2가 나옴"은 배반이다. 1이 나왔다는 것을 알면 2일 확률이 1/6에서 0으로 떨어지니, 둘은 강하게 영향을 주고받는다. 두 사건의 확률이 모두 0보다 크면 배반인 사건은 결코 독립일 수 없다.

## 생일 문제
방에 23명이 있을 때 생일이 같은 사람이 적어도 한 쌍 있을 확률은 얼마일까? 1년이 365일이니 작을 것 같지만 실제로는 절반을 넘는다. (윤년은 무시하고, 모든 날이 같은 가능성이며 사람들의 생일은 서로 독립이라고 가정한다.)

"적어도 한 쌍"은 경우가 너무 많으니 1편의 여사건 규칙으로 "모두 다름"을 계산한다. 한 사람씩 방에 들어온다고 생각하면, 이미 있는 k명의 생일이 모두 다를 때 다음 사람이 그들과 다른 날일 조건부 확률은 `(365 − k)/365`이고, 곱셈 법칙으로 이를 모두 곱한다.
```python
import random

def birthday(n):
    p_all_different = 1.0
    for k in range(n):
        p_all_different *= (365 - k) / 365   # k명과 모두 다른 날일 조건부 확률
    return 1 - p_all_different

for n in (10, 23, 30, 50, 70):
    print(n, round(birthday(n), 4))

random.seed(0)
trials = 100_000
hits = sum(len(set(random.randrange(365) for _ in range(23))) < 23 for _ in range(trials))
print("시뮬레이션(23명):", hits / trials)
```

```text
10 0.1169
23 0.5073
30 0.7063
50 0.9704
70 0.9992
시뮬레이션(23명): 0.50901
```

23명이면 약 50.7%, 50명이면 97%다. 직관이 빗나가는 이유는 "나와 생일이 같은 사람"이 아니라 "아무 두 사람"을 묻기 때문이다. 23명이면 두 사람 쌍이 `23 × 22 / 2 = 253`개나 된다. 시뮬레이션 값 0.509도 정확한 값 0.5073과 표본 오차 범위 안에서 맞는다.

## 정리
- `P(A∣B) = P(A ∩ B) / P(B)`는 표본 공간을 B로 좁혀 다시 잰 확률이다.
- 곱셈 법칙은 결합 확률을 단계별 조건부 확률의 곱으로, 전확률 법칙은 경우별 확률의 가중합으로 계산하게 해 준다.
- 독립은 `P(A ∩ B) = P(A)·P(B)`이며, 배반(동시에 못 일어남)과는 전혀 다른 개념이다.
- 생일 문제처럼 "적어도 하나"는 여사건과 곱셈 법칙으로 계산하면 쉽다.
