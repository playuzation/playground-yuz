# [확률과 분포 8/12] 정규 분포: 종 모양 곡선의 정체

> **한 줄 요약** — 정규 분포는 평균 μ와 표준편차 σ 두 숫자로 정해지는 좌우 대칭의 종 모양 분포로, 값의 약 68%, 95%, 99.7%가 평균에서 1σ, 2σ, 3σ 안에 들어가며, 작은 요인이 많이 더해진 양이 이 모양을 띠기 때문에 어디서나 나타난다.

## 밀도 식 읽기
**정규 분포**(가우스 분포라고도 한다) N(μ, σ²)의 밀도는 다음과 같다.
```text
f(x) = 1 / (σ√(2π)) · exp( −(x − μ)² / (2σ²) )
```

부분으로 나누어 읽으면 어렵지 않다.
- `(x − μ)²`: 평균에서 떨어진 거리의 제곱. 좌우 대칭이 여기서 나온다.
- `/ (2σ²)`: 떨어진 거리를 σ 단위로 잰다. σ가 크면 같은 거리도 "가깝게" 취급되어 곡선이 넓게 퍼진다.
- `exp(−…)`: 멀어질수록 밀도가 매우 빠르게 0으로 줄어든다(지수 함수는 미적분 4편 「지수 함수와 로그 함수」 참고).
- `1 / (σ√(2π))`: 곡선 아래 전체 넓이를 1로 맞추는 정규화 상수다.

μ는 곡선의 중심이자 평균이고, σ²는 분산이다. σ가 작으면 좁고 높은 종, 크면 낮고 넓은 종이 된다. 7편에서 본 것처럼 밀도는 확률이 아니므로, σ가 작으면 꼭대기가 1을 넘기도 한다(σ = 0.1이면 꼭대기 높이가 약 3.99).

## 68-95-99.7 규칙
정규 분포에서는 평균에서 σ 단위로 몇 칸 떨어졌는지만 알면 확률이 정해진다.

| 구간 | 안에 들어갈 확률 | 밖으로 벗어날 확률 |
|---|---|---|
| μ ± 1σ | 약 68.27% | 약 31.73% |
| μ ± 2σ | 약 95.45% | 약 4.55% |
| μ ± 3σ | 약 99.73% | 약 0.27% |

3σ 밖으로 벗어나는 일은 약 370번에 한 번이다. SciPy와 NumPy로 확인해 보자.
```python
import numpy as np
from scipy import stats

z = stats.norm(loc=0, scale=1)                # 표준 정규 분포 N(0, 1)
for k in (1, 2, 3):
    print(f"μ ± {k}σ 안: {z.cdf(k) - z.cdf(-k):.4f}")

score = stats.norm(loc=70, scale=10)          # 평균 70, 표준편차 10인 시험 점수
print("85점 초과 비율:", round(score.sf(85), 4), " z =", (85 - 70) / 10)

rng = np.random.default_rng(0)
x = rng.normal(loc=70, scale=10, size=100_000)
print("표본 1σ 안 비율:", np.mean(np.abs(x - 70) <= 10))
```

```text
μ ± 1σ 안: 0.6827
μ ± 2σ 안: 0.9545
μ ± 3σ 안: 0.9973
85점 초과 비율: 0.0668  z = 1.5
표본 1σ 안 비율: 0.68391
```

## 표준화: 모든 정규 분포를 하나로
X가 N(μ, σ²)를 따를 때 `Z = (X − μ) / σ`로 바꾸면 Z는 평균 0, 표준편차 1인 **표준 정규 분포** N(0, 1)을 따른다. 이것을 **표준화**라 하고, Z 값을 **z 점수**라고 부른다. "평균에서 표준편차 몇 개만큼 떨어졌나"라는 뜻이다. 평균 70, 표준편차 10인 시험에서 85점은 z = 1.5이고, 위 코드처럼 그보다 높은 점수는 약 6.7%다. 키와 몸무게, 서로 다른 과목 점수처럼 척도가 다른 값도 z 점수로 바꾸면 비교할 수 있다.

정규 분포는 선형 변환과 덧셈에 닫혀 있다. X가 정규 분포면 aX + b도 정규 분포 `N(aμ + b, a²σ²)`이고(5편의 분산 성질), 독립인 정규 분포 둘의 합도 정규 분포 `N(μ₁ + μ₂, σ₁² + σ₂²)`다.

## 왜 이렇게 흔한가
사람의 키는 수많은 유전자와 환경 요인이 조금씩 더해진 결과이고, 측정 오차도 여러 작은 오차의 합이다. 독립적인 작은 요인이 많이 더해지면, 각 요인의 분포가 무엇이든 합은 정규 분포에 가까워진다. 이것이 10편 「큰 수의 법칙과 중심 극한 정리」에서 다룰 중심 극한 정리이며, 정규 분포가 어디서나 보이는 이유다.

다만 실제 데이터는 정규 분포보다 꼬리가 두꺼운 경우가 많다. 정규 분포에서 4σ 밖은 약 0.006%(약 1만 6천 번에 한 번)지만, 주가 폭락 같은 극단적인 사건은 그보다 훨씬 자주 일어난다. 정규 가정은 편리한 출발점이지 사실이 아니다.

변수가 여러 개면 **다변량 정규 분포** `N(μ, Σ)`를 쓴다. μ는 평균 벡터, Σ는 5편의 분산과 공분산을 모은 공분산 행렬이며, 2차원이면 밀도의 등고선이 타원 모양이 된다.

## 어디에 쓰이나
- AI 기초 1편 「딥러닝: 특징까지 스스로 배우는 머신러닝」: XOR 예제의 `rng.normal(size=(2, 8))`은 가중치를 표준 정규 분포에서 뽑아 초기화하는 코드로, 모든 가중치가 같으면 은닉 뉴런들이 똑같이 학습되므로 서로 다른 무작위 값으로 대칭을 깨는 것이다(분산 크기의 의미는 5편).
- 통계학 4편 「최대 우도 추정」: 오차가 정규 분포를 따른다고 가정하면 로그 우도가 `−(y − ŷ)²/(2σ²) + 상수`들의 합이 되어, 최대 우도 추정이 곧 오차 제곱합을 최소화하는 최소제곱법이 된다.
- 선형대수 11편 「주성분 분석(PCA): 차원 축소」: 다변량 정규 분포의 타원형 등고선에서 가장 긴 축의 방향이 PCA가 찾는 첫 번째 주성분이다.

## 정리
- 정규 분포 N(μ, σ²)는 μ와 σ로 정해지는 좌우 대칭의 종 모양 분포다.
- 값의 약 68%, 95%, 99.7%가 μ ± 1σ, 2σ, 3σ 안에 들어간다.
- 표준화 `z = (x − μ)/σ`로 모든 정규 분포를 N(0, 1) 하나로 바꿔 비교할 수 있다.
- 작은 독립 요인의 합이 정규 분포에 가까워진다는 중심 극한 정리가 정규 분포가 흔한 이유다.
