# [확률과 분포 7/12] 연속 분포와 확률 밀도 함수

> **한 줄 요약** — 연속 확률 변수는 한 점의 확률이 0이므로 확률을 구간의 넓이로 재며, 그 넓이를 만드는 곡선이 확률 밀도 함수이고, 밀도는 확률이 아니어서 1을 넘을 수도 있다.

## 이 글에서 다루는 것
- 연속 확률 변수에서 한 점의 확률이 0인 이유
- 확률 밀도 함수: 넓이가 확률이다
- 누적 분포 함수
- 균등 분포, 지수 분포와 무기억성

## 한 점의 확률은 0이다
키, 대기 시간, 온도처럼 값이 연속적인 확률 변수를 생각해 보자. 버스를 기다리는 시간이 "정확히 5.000…분"일 확률은 얼마일까? 0분과 10분 사이의 모든 실수가 가능하다면 값이 무한히 많으므로, 점마다 양의 확률을 주면 합이 1을 넘어 버린다. 그래서 연속 확률 변수는 모든 x에서 `P(X = x) = 0`이다. 의미 있는 질문은 "4분에서 6분 사이일 확률"처럼 구간에 대한 것이다.

## 확률 밀도 함수: 넓이가 확률이다
연속 확률 변수 X의 **확률 밀도 함수**(PDF) f(x)는 그래프 아래의 넓이가 확률이 되는 함수다.
```text
P(a ≤ X ≤ b) = ∫ₐᵇ f(x) dx      (a에서 b까지 곡선 아래 넓이)
조건: f(x) ≥ 0,  전체 넓이 ∫ f(x) dx = 1
```

적분이 낯설다면 "곡선 아래 넓이"라고 읽으면 충분하다(적분 자체는 미적분 5편 「적분: 넓이와 누적」에서 다룬다). 이산 분포와 비교하면 합이 넓이로 바뀌었을 뿐 구조는 같다.

| 구분 | 이산 | 연속 |
|---|---|---|
| 확률을 주는 함수 | 확률 질량 함수 p(x) | 확률 밀도 함수 f(x) |
| 한 점의 확률 | p(x) | 0 |
| 구간의 확률 | 합 Σ | 넓이 ∫ |
| 기댓값 | `Σ x·p(x)` | `∫ x·f(x) dx` |

### 밀도는 확률이 아니다
f(x) 값 자체는 확률이 아니라 "x 근처에 확률이 얼마나 빽빽한가"다. 아주 좁은 폭 Δx에 대해 `P(x ≤ X ≤ x + Δx) ≈ f(x)·Δx`이므로, 밀도에 폭을 곱해야 확률이 된다. 그래서 밀도는 1을 넘을 수 있다. 0과 0.5 사이에서 고르게 나오는 값은 전체 넓이가 1이 되도록 밀도가 2여야 한다(폭 0.5 × 높이 2 = 1).

## 누적 분포 함수
**누적 분포 함수**(CDF) `F(x) = P(X ≤ x)`는 x까지 쌓인 넓이다. 0에서 출발해 줄어들지 않고 올라가 1에 도달하며, 구간 확률을 뺄셈 한 번으로 준다: `P(a < X ≤ b) = F(b) − F(a)`. 반대로 F를 미분하면 밀도 f가 된다. 연속이면 한 점의 확률이 0이라 `<`와 `≤`를 구별할 필요가 없다. 누적 분포 함수는 이산 분포에도 똑같이 정의되며, 그때는 값마다 뛰어오르는 계단 모양이다.

## 균등 분포
구간 [a, b]의 모든 값이 똑같이 그럴듯하면 밀도는 그 구간에서 상수 `1/(b − a)`이고, 이를 **균등 분포**라고 한다. 평균은 가운데 `(a + b)/2`, 분산은 `(b − a)²/12`다. 프로그래밍 언어의 `random()`이 주는 0과 1 사이의 난수가 균등 분포이며, 11편에서 보듯 다른 모든 분포의 표본을 만드는 재료가 된다.

## 지수 분포와 무기억성
6편의 포아송 분포가 "한 시간에 몇 건"을 센다면, **지수 분포**는 "다음 건까지 얼마나 기다리나"를 잰다. 사건이 단위 시간당 평균 λ번 일어날 때 대기 시간 T의 분포는 다음과 같다.
```text
f(t) = λ·e^(−λt),    F(t) = 1 − e^(−λt),    t ≥ 0
평균 1/λ,    분산 1/λ²
```

시간당 평균 4건(평균 간격 15분)이면 10분 안에 다음 문의가 올 확률은 `F(1/6) = 1 − e^(−2/3) ≈ 0.487`이다.

지수 분포의 가장 독특한 성질은 **무기억성**이다. 이미 s만큼 기다렸다는 조건에서 t만큼 더 기다려야 할 확률은, 처음부터 t를 기다릴 확률과 같다.
```text
P(T > s + t ∣ T > s) = e^(−λ(s+t)) / e^(−λs) = e^(−λt) = P(T > t)
```

20분째 기다리고 있다고 해서 "이제 곧 오겠지"라고 기대할 근거가 없다는 뜻이다. 시뮬레이션으로 확인해 보자.
```python
import numpy as np
from scipy import stats

narrow = stats.uniform(loc=0, scale=0.5)      # 0~0.5 사이 균등 분포
print("밀도:", narrow.pdf(0.3), " 전체 넓이:", narrow.cdf(0.5))

wait = stats.expon(scale=1/4)                 # λ = 시간당 4건 → 평균 간격 1/4시간
print("10분 안에 올 확률:", round(wait.cdf(10/60), 4))

rng = np.random.default_rng(0)
t = rng.exponential(scale=1/4, size=1_000_000) * 60   # 분 단위 대기 시간 100만 개
print("P(T > 10)          =", round(np.mean(t > 10), 4))
print("P(T > 30 ∣ T > 20) =", round(np.mean(t[t > 20] > 30), 4))
```

```text
밀도: 2.0  전체 넓이: 1.0
10분 안에 올 확률: 0.4866
P(T > 10)          = 0.5131
P(T > 30 ∣ T > 20) = 0.5133
```

10분 넘게 기다릴 확률(이론값 `e^(−2/3) ≈ 0.5134`)과, 이미 20분을 기다린 사람이 30분을 넘길 확률이 같다. 연속 분포 중 무기억성을 가진 것은 지수 분포뿐이며, 이산 분포에서는 6편의 기하 분포가 같은 역할을 한다. 이 성질은 방사성 붕괴나 무작위 도착처럼 "나이를 먹지 않는" 현상에는 잘 맞지만, 부품처럼 낡을수록 고장 나기 쉬운 경우에는 맞지 않는다.

## 정리
- 연속 확률 변수는 `P(X = x) = 0`이고, 확률은 밀도 곡선 아래의 넓이로 잰다.
- 밀도 f(x)는 확률이 아니라 단위 길이당 확률이어서 1을 넘을 수 있다.
- 누적 분포 함수 `F(x) = P(X ≤ x)`는 구간 확률을 `F(b) − F(a)`로 준다.
- 지수 분포는 대기 시간을 모형화하며, 이미 기다린 시간과 무관한 무기억성을 가진다.
