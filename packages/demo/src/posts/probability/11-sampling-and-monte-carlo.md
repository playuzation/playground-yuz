## 의사 난수와 시드
컴퓨터는 결정적인 기계라서 진짜 무작위 수를 만들지 못한다. 대신 **의사 난수 생성기**가 정해진 계산 규칙으로 무작위처럼 보이는 수열을 만든다. 파이썬의 `random` 모듈은 메르센 트위스터, NumPy의 `default_rng`는 PCG64라는 알고리즘을 쓴다. 출발점인 **시드**(seed)가 같으면 언제나 같은 수열이 나온다.
```python
import random

random.seed(2024)
first = [random.random() for _ in range(3)]
random.seed(2024)
second = [random.random() for _ in range(3)]
print(first == second, [round(u, 4) for u in first])   # True [0.4701, 0.7283, 0.3038]
```

이 시리즈의 예제가 모두 시드를 고정한 이유다. 실험 결과를 다른 사람이, 또는 내일의 내가 똑같이 재현하려면 시드를 기록해 두어야 한다. 반대로 로그인 토큰처럼 예측되면 안 되는 값에는 이런 생성기 대신 운영체제가 제공하는 암호학적 난수(파이썬의 `secrets` 모듈 등)를 쓴다. 이 플랫폼의 로그인 토큰도 WebCrypto의 `crypto.getRandomValues`로 만든 32바이트 난수다.

## 역변환 샘플링: 균등 난수로 다른 분포 만들기
생성기가 기본으로 주는 것은 0과 1 사이의 균등 난수 U다. 다른 분포의 표본은 U를 변환해서 만든다. 가장 기본적인 방법이 **역변환 샘플링**이다. 누적 분포 함수 F(7편)의 역함수에 U를 넣으면 `X = F⁻¹(U)`는 분포 F를 따른다. U는 0과 1 사이에 고르게 퍼져 있으므로, F가 가파르게 올라가는 곳(밀도가 큰 곳)으로 더 많은 표본이 모이는 원리다.

지수 분포는 `F(t) = 1 − e^(−λt)`이므로 `u = F(t)`를 t에 대해 풀면 `t = −ln(1 − u) / λ`다. 균등 난수 하나에 로그를 씌우는 것만으로 대기 시간 표본이 나온다.

## 범주형 분포: 누적합으로 뽑기
확률이 [0.5, 0.3, 0.2]인 세 범주 중 하나를 뽑으려면, 누적합 [0.5, 0.8, 1.0]으로 0~1 구간을 길이가 각 확률인 칸으로 나누고 U가 떨어진 칸을 고른다. U < 0.5면 0번, 0.5 ≤ U < 0.8이면 1번, 나머지는 2번이다. 언어 모델이 다음 토큰을 뽑을 때도 원리는 같다. 아래 코드는 두 방법과 다음 절의 원주율 추정을 함께 확인한다.
```python
import numpy as np

rng = np.random.default_rng(0)
u = rng.random(1_000_000)                     # 0~1 균등 난수 100만 개

# 역변환 샘플링: 지수 분포 F(t) = 1 − e^(−λt)의 역함수에 u를 넣는다
lam = 4
t = -np.log(1 - u) / lam
print("지수 분포 표본 평균:", round(t.mean(), 4), " 이론값 1/λ =", 1 / lam)

# 범주형 분포: 누적합 [0.5, 0.8, 1.0]의 어느 구간에 u가 떨어지는지 본다
probs = np.array([0.5, 0.3, 0.2])
idx = np.searchsorted(np.cumsum(probs), u, side="right")
print("범주별 비율:", np.bincount(idx) / len(u))

# 몬테카를로로 원주율 추정: 사분원 안에 떨어진 점의 비율 × 4, 실험을 100번씩 반복
for n in (100, 10_000, 1_000_000):
    est = np.array([4 * np.mean(rng.random(n) ** 2 + rng.random(n) ** 2 <= 1) for _ in range(100)])
    rmse = np.sqrt(np.mean((est - np.pi) ** 2))
    print(f"n={n:>9,}  추정값 예={est[0]:.4f}  평균 오차={rmse:.4f}  1.64/√n={1.64 / np.sqrt(n):.4f}")
```

```text
지수 분포 표본 평균: 0.2503  이론값 1/λ = 0.25
범주별 비율: [0.500194 0.299659 0.200147]
n=      100  추정값 예=3.1600  평균 오차=0.1680  1.64/√n=0.1640
n=   10,000  추정값 예=3.1244  평균 오차=0.0173  1.64/√n=0.0164
n=1,000,000  추정값 예=3.1412  평균 오차=0.0015  1.64/√n=0.0016
```

## 몬테카를로 방법
**몬테카를로 방법**은 무작위 표본의 평균으로 기댓값이나 넓이를 근사하는 방법이다. 이름은 카지노로 유명한 모나코의 몬테카를로에서 따왔다. 원주율을 예로 들면, 한 변이 1인 정사각형에 점을 고르게 뿌릴 때 반지름 1인 사분원 안에 떨어질 확률은 넓이의 비 π/4다. 그러므로 "안에 떨어진 비율 × 4"가 π의 추정값이 된다. 이 비율은 지표 변수(4편)의 표본 평균이므로 10편의 큰 수의 법칙에 따라 π로 수렴하고, 표준 오차는 `4·√(p(1 − p)/n) ≈ 1.64/√n`(p = π/4)이다.

위 출력에서 실험을 100번 반복해 잰 평균 오차(오차 제곱 평균의 제곱근)가 이론값 1.64/√n과 잘 맞는다. 표본을 100배 늘려야 오차가 10분의 1로 줄어드니 빠르지는 않다. 대신 이 1/√n 속도가 문제의 차원과 무관하다는 것이 몬테카를로의 강점이다. 격자를 촘촘히 나누어 계산하는 방법은 차원이 늘면 칸 수가 폭발하지만, 표본 평균은 그렇지 않아 고차원 적분이나 복잡한 시뮬레이션에서 위력을 발휘한다.

## 온도: 분포를 바꿔서 뽑기
언어 모델은 토큰마다 점수(로짓) z를 내고, 소프트맥스 `exp(zᵢ/T) / Σ exp(zⱼ/T)`로 확률을 만든 뒤 위의 범주형 분포처럼 다음 토큰을 뽑는다. 여기서 T가 **온도**다(소프트맥스와 온도의 다른 측면은 미적분 4편 「지수 함수와 로그 함수」와 정보 이론 1편 「정보량과 엔트로피」에서 다룬다).
```python
import numpy as np

logits = np.array([2.0, 1.0, 0.5, 0.0])       # 토큰 네 개의 점수
for T in (0.5, 1.0, 2.0):
    p = np.exp(logits / T) / np.exp(logits / T).sum()
    print(f"T={T}: {p.round(3)}")
```

```text
T=0.5: [0.831 0.112 0.041 0.015]
T=1.0: [0.579 0.213 0.129 0.078]
T=2.0: [0.409 0.248 0.193 0.15 ]
```

T가 낮으면 1등 토큰에 확률이 몰려(0.831) 거의 항상 같은 답을 내고, T → 0이면 매번 최댓값만 고르는 탐욕적 선택이 된다. T가 높으면 분포가 평평해져(0.409) 다양한 답이 나오지만 엉뚱한 토큰도 자주 뽑힌다. 점수의 순위는 그대로 두고 분포의 뾰족한 정도만 바꾸는 손잡이다.

## 정리
- 의사 난수는 시드로 정해지는 결정적 수열이며, 시드를 고정하면 실험을 재현할 수 있다.
- 균등 난수 U를 누적 분포 함수의 역함수에 넣거나(역변환 샘플링) 누적합 구간에 대응시키면(범주형) 원하는 분포의 표본을 얻는다.
- 몬테카를로 방법은 표본 평균으로 값을 근사하며, 오차는 차원과 무관하게 1/√n으로 줄어든다.
- 소프트맥스 온도는 낮을수록 분포를 뾰족하게, 높을수록 평평하게 만든다.
