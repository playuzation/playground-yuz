# [확률과 분포 3/12] 베이즈 정리: 증거로 믿음을 고치기

> **한 줄 요약** — 베이즈 정리는 알고 싶은 `P(가설∣증거)`를 측정하기 쉬운 반대 방향의 확률 `P(증거∣가설)`과 사전 확률로 계산하는 공식으로, 새 증거가 들어올 때마다 믿음을 얼마나 고쳐야 하는지 정확히 알려 준다.

## 이 글에서 다루는 것
- 곱셈 법칙에서 베이즈 정리 유도하기
- 사전 확률, 가능도, 사후 확률
- 의료 검사 예: 양성인데 환자일 확률이 17%인 이유
- 증거가 쌓일 때의 반복 갱신
- 나이브 베이즈 스팸 필터의 직관

## 공식 유도하기
2편의 곱셈 법칙은 결합 확률을 두 방향으로 쓸 수 있다고 말한다: `P(H ∩ E) = P(H∣E)·P(E) = P(E∣H)·P(H)`. 가운데와 오른쪽을 P(E)로 나누면 **베이즈 정리**가 된다.
```text
            P(E∣H) · P(H)
P(H∣E) = ─────────────────
                P(E)
```

H는 가설(환자다, 스팸이다), E는 관찰한 증거(검사가 양성, 메일에 "당첨"이 있음)다. 알고 싶은 것은 `P(H∣E)`인데, 쉽게 측정할 수 있는 것은 대개 반대 방향인 `P(E∣H)`다. 환자들을 모아 검사하면 양성 비율은 잴 수 있지만, 양성이 나온 사람이 환자일 확률은 그렇게 바로 잴 수 없다. 베이즈 정리는 이 방향을 뒤집는 도구이며, 18세기 영국의 토머스 베이즈의 이름을 땄다.

| 항 | 이름 | 뜻 |
|---|---|---|
| `P(H)` | 사전 확률 | 증거를 보기 전의 믿음 |
| `P(E∣H)` | 가능도 | 가설이 참일 때 이 증거가 나올 확률 |
| `P(E)` | 증거 | 모든 가설을 통틀어 이 증거가 나올 확률 |
| `P(H∣E)` | 사후 확률 | 증거를 본 뒤의 믿음 |

분모 P(E)는 보통 2편의 전확률 법칙으로 구한다: `P(E) = P(E∣H)·P(H) + P(E∣Hᶜ)·P(Hᶜ)`. 분모는 사후 확률들의 합을 1로 맞추는 정규화 상수일 뿐이므로, 가설끼리 비교할 때는 `P(H∣E) ∝ P(E∣H)·P(H)`(∝는 "비례한다")만 봐도 된다.

## 의료 검사: 양성이면 정말 환자일까
어떤 병의 유병률이 1%이고, 검사는 환자의 99%를 양성으로 잡아내며(민감도), 건강한 사람의 5%도 양성으로 잘못 판정한다(위양성률). 검사 결과가 양성일 때 실제로 환자일 확률은 얼마일까?
```text
P(양성) = 0.99 × 0.01 + 0.05 × 0.99 = 0.0099 + 0.0495 = 0.0594
P(환자∣양성) = 0.0099 / 0.0594 = 1/6 ≈ 0.167
```

민감도 99%짜리 검사인데, 양성 판정을 받은 사람 가운데 실제 환자는 6명 중 1명뿐이다. 10,000명을 검사한다고 생각하면 이유가 보인다.

| 집단 | 인원 | 양성 | 음성 |
|---|---|---|---|
| 환자 | 100 | 99 | 1 |
| 건강 | 9,900 | 495 | 9,405 |
| 합계 | 10,000 | 594 | 9,406 |

양성 594명 중 환자는 99명이다. 건강한 사람이 압도적으로 많아서, 그중 5%만 잘못 걸려도 진짜 환자 수를 크게 넘는다. 사전 확률(기저율)을 빼먹고 "검사가 99% 정확하니 환자일 확률도 99%"라고 생각하는 실수를 **기저율 무시**라고 한다.

## 증거가 쌓일 때: 반복 갱신
양성이 나온 사람이 다시 검사를 받아 또 양성이 나왔다면? 방금 얻은 사후 확률을 새 사전 확률로 넣고 같은 공식을 한 번 더 쓰면 된다. (환자 여부가 정해지면 두 검사 결과는 서로 독립이라고 가정한다.)
```python
def update(prior, sensitivity=0.99, false_positive=0.05):
    evidence = sensitivity * prior + false_positive * (1 - prior)   # 전확률 법칙: P(양성)
    return sensitivity * prior / evidence                           # 베이즈 정리: P(환자∣양성)

p = 0.01                       # 사전 확률: 유병률 1%
for test in range(1, 4):
    p = update(p)
    print(f"양성 {test}번 뒤 P(환자) = {p:.4f}")
```

```text
양성 1번 뒤 P(환자) = 0.1667
양성 2번 뒤 P(환자) = 0.7984
양성 3번 뒤 P(환자) = 0.9874
```

증거 하나하나가 믿음을 조금씩 옮긴다. 이 과정은 **오즈**(odds, 일어날 확률 대 일어나지 않을 확률의 비)로 쓰면 더 깔끔하다. 사후 오즈는 사전 오즈에 가능도 비 `P(E∣H) / P(E∣Hᶜ) = 0.99 / 0.05 = 19.8`을 곱한 것이다. 처음 오즈 1:99에 19.8을 곱하면 19.8:99 = 1:5, 확률로는 1/6이다. 양성이 한 번 나올 때마다 오즈가 19.8배씩 커진다.

## 나이브 베이즈 스팸 필터
메일이 스팸인지 판단할 때 가설은 "스팸"과 "정상", 증거는 메일에 든 단어들이다. 단어가 여러 개면 `P(단어들∣스팸)`을 직접 세기 어렵기 때문에, **나이브 베이즈**는 "스팸인지 정상인지 정해지면 단어들은 서로 독립"이라고 과감하게(naive) 가정한다. 그러면 가능도가 단어별 확률의 곱이 된다.
```text
P(스팸∣단어들) ∝ P(스팸) · P(단어₁∣스팸) · P(단어₂∣스팸) ⋯
```

설명을 위한 가상의 수치로, 스팸 비율이 40%이고 "무료"가 스팸에 나올 확률은 0.3, 정상 메일에는 0.02, "당첨"은 스팸에 0.2, 정상 메일에 0.01이라고 하자. 두 단어가 모두 든 메일의 점수는 스팸이 `0.4 × 0.3 × 0.2 = 0.024`, 정상이 `0.6 × 0.02 × 0.01 = 0.00012`이고, 둘의 합으로 나누어 정규화하면 `P(스팸∣무료, 당첨) = 0.024 / 0.02412 ≈ 0.995`다. 단어들이 서로 독립이라는 가정은 현실과 맞지 않지만, 어느 쪽이 더 그럴듯한지 순위를 매기는 데는 꽤 잘 작동한다.

## 어디에 쓰이나
- AI 기초 3편 「데이터 분포로 보는 AI 모델」: 생성 모델이 `p(x∣y)`와 `p(y)`를 배우면 베이즈 정리 `p(y∣x) ∝ p(x∣y)·p(y)`로 판별 모델의 답인 `p(y∣x)`를 얻을 수 있으며, 나이브 베이즈는 그 가장 단순한 예다.
- AI 기초 3편 「데이터 분포로 보는 AI 모델」: 라벨 변화(독감 유행기에 환자 비율이 늘어남)는 사전 확률 `p(y)`가 바뀐 경우라서, 의료 검사 예처럼 같은 입력에 대한 사후 확률도 달라진다.
- 통계학 10편 「베이즈 추론: 사전 분포에서 사후 분포로」: 이 글의 공식을 가설 두 개가 아니라 모수가 가질 수 있는 모든 값에 적용하면, 사전 분포가 데이터를 보고 사후 분포로 바뀌는 베이즈 추론이 된다.

## 정리
- 베이즈 정리 `P(H∣E) = P(E∣H)·P(H) / P(E)`는 곱셈 법칙을 두 방향으로 쓴 식에서 나온다.
- 사후 확률은 가능도와 사전 확률의 곱에 비례하며, 분모 P(E)는 정규화 상수다.
- 정확한 검사라도 기저율이 낮으면 양성의 대부분이 위양성일 수 있다(유병률 1% 예에서 1/6).
- 사후 확률을 다음 사전 확률로 쓰면 증거가 쌓일 때마다 믿음을 계속 갱신할 수 있다.
