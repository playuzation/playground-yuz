## 현재만 기억한다
지금까지는 확률 변수 한두 개를 다뤘다. 시간에 따라 이어지는 확률 변수의 열 X₀, X₁, X₂, …을 **확률 과정**이라고 한다. 매일의 날씨, 웹 서핑 중 방문하는 페이지, 문장 속 단어의 열이 모두 확률 과정이다.

9편의 연쇄 법칙에 따르면 이런 열의 확률은 `p(x₀)·p(x₁∣x₀)·p(x₂∣x₀, x₁)⋯`처럼 점점 긴 과거를 조건으로 하는 항들의 곱이다. **마르코프 성질**은 여기에 과감한 가정을 하나 더한다. 내일은 오늘에만 달려 있고, 오늘을 알면 어제 이전의 역사는 더 필요 없다는 것이다.
```text
P(Xₙ₊₁ = j ∣ Xₙ = i, Xₙ₋₁, …, X₀) = P(Xₙ₊₁ = j ∣ Xₙ = i)
```

이 성질을 가진 확률 과정을 **마르코프 연쇄**라 한다. 러시아의 수학자 안드레이 마르코프의 이름을 땄으며, 그는 푸시킨의 운문 소설 「예브게니 오네긴」에서 글자가 모음인지 자음인지가 바로 앞 글자에 따라 어떻게 달라지는지 세어 보기도 했다. 다음 글자를 앞 글자로 예측한다는 점에서 언어 모델의 먼 조상인 셈이다.

## 상태와 전이 행렬
날씨가 맑음, 흐림, 비라는 세 **상태** 중 하나이고, 내일 날씨의 확률이 오늘 날씨에 따라 다음과 같다고 하자.

| 오늘 / 내일 | 맑음 | 흐림 | 비 |
|---|---|---|---|
| 맑음 | 0.7 | 0.2 | 0.1 |
| 흐림 | 0.3 | 0.4 | 0.3 |
| 비 | 0.2 | 0.4 | 0.4 |

이 표를 행렬로 쓴 것이 **전이 행렬** P다. i행 j열은 `P(내일 j∣오늘 i)`이고, 각 행이 하나의 조건부 분포(9편)이므로 행의 합은 1이다. 마르코프 연쇄는 처음 분포와 이 행렬만 있으면 완전히 정해진다.

## n단계 전이는 행렬 거듭제곱
오늘 맑으면 모레 비가 올 확률은? 내일 날씨로 경우를 나누어 더하면 된다(2편의 전확률 법칙).
```text
P(모레 비 ∣ 오늘 맑음) = 0.7 × 0.1 + 0.2 × 0.3 + 0.1 × 0.4 = 0.17
```

이 계산은 정확히 P의 첫 행과 셋째 열의 내적, 즉 행렬 곱 P²의 (맑음, 비) 성분이다. 일반적으로 n일 뒤의 전이 확률은 Pⁿ이고, 오늘의 분포를 행 벡터 π₀로 쓰면 n일 뒤의 분포는 `πₙ = π₀·Pⁿ`이다(행렬 곱은 선형대수 3편 「행렬과 행렬 곱」 참고).

## 정상 분포: 오래 지나면
n을 키워 가며 계산하면 분포가 어떤 값으로 수렴한다. 수렴한 분포 π는 한 단계 더 진행해도 변하지 않아야 하므로 다음을 만족한다.
```text
π·P = π,     π의 원소 합 = 1
```

이런 π를 **정상 분포**(stationary distribution)라고 한다. 양변을 전치하면 `Pᵀπᵀ = πᵀ`이므로, π는 Pᵀ의 고유값 1에 대한 고유벡터를 합이 1이 되게 맞춘 것이다.
```python
import numpy as np

P = np.array([[0.7, 0.2, 0.1],     # 오늘 맑음 → 내일 맑음/흐림/비
              [0.3, 0.4, 0.3],     # 오늘 흐림 →
              [0.2, 0.4, 0.4]])    # 오늘 비   →

start = np.array([1.0, 0.0, 0.0])                    # 오늘은 맑음
for n in (1, 2, 3, 10):
    print(f"{n}일 뒤:", (start @ np.linalg.matrix_power(P, n)).round(4))

# 정상 분포: πP = π  ⇔  Pᵀπᵀ = πᵀ, 즉 Pᵀ의 고유값 1에 대한 고유벡터
vals, vecs = np.linalg.eig(P.T)
pi = np.real(vecs[:, np.argmin(abs(vals - 1))])
pi = pi / pi.sum()
print("정상 분포:", pi.round(4), " πP:", (pi @ P).round(4))

rng = np.random.default_rng(0)                       # 10만 일 동안 날씨를 시뮬레이션
s, visits = 0, np.zeros(3)
for _ in range(100_000):
    s = rng.choice(3, p=P[s])
    visits[s] += 1
print("방문 비율:", (visits / visits.sum()).round(4))
```

```text
1일 뒤: [0.7 0.2 0.1]
2일 뒤: [0.57 0.26 0.17]
3일 뒤: [0.511 0.286 0.203]
10일 뒤: [0.4617 0.3076 0.2307]
정상 분포: [0.4615 0.3077 0.2308]  πP: [0.4615 0.3077 0.2308]
방문 비율: [0.4644 0.3058 0.2298]
```

정상 분포는 정확히 (6/13, 4/13, 3/13)이다. 오늘 맑아도 10일 뒤에는 시작 상태의 영향이 거의 사라져 정상 분포와 소수 셋째 자리까지 같아지고, 10만 일을 시뮬레이션한 방문 비율도 정상 분포에 가깝다. 즉 정상 분포는 "아주 오래 지켜볼 때 각 상태에 머무는 시간의 비율"이기도 하다. 이렇게 수렴하려면 모든 상태끼리 서로 오갈 수 있고(기약), 일정한 주기로 맴돌지 않아야(비주기) 한다. 상태가 유한하고 이 두 조건이 맞으면 정상 분포는 하나뿐이고, 어디서 시작하든 그리로 간다.

초기 구글 검색의 핵심 알고리즘인 페이지랭크도 이 원리다. 링크를 무작위로 따라가는 사용자를 마르코프 연쇄로 보고, 정상 분포에서 확률이 큰 페이지를 중요한 페이지로 친다.

## 정리
- 마르코프 성질은 "다음 상태는 현재 상태에만 달려 있다"는 가정이며, 전이 행렬 P가 연쇄를 완전히 기술한다.
- n단계 전이 확률은 Pⁿ이고, n일 뒤의 분포는 `π₀·Pⁿ`이다.
- 정상 분포는 `πP = π`를 만족하며, Pᵀ의 고유값 1에 대한 고유벡터로 구한다.
- 기약·비주기 조건이 맞으면 어디서 시작하든 분포는 정상 분포로 수렴한다.
