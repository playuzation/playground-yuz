## 분산: 평균에서 얼마나 떨어져 있나
기댓값이 같아도 성격이 전혀 다른 확률 변수가 있다. 항상 3.5원을 주는 게임과 주사위 눈만큼 주는 게임은 기댓값이 같지만, 뒤의 것은 1원이 나올 수도 6원이 나올 수도 있다. 이 퍼짐을 재는 것이 **분산**이다. 기댓값을 μ라 할 때 다음과 같다.
```text
Var(X) = E[(X − μ)²] = E[X²] − μ²
```

편차 X − μ를 그대로 평균하면 양수와 음수가 상쇄되어 항상 0이 되므로 제곱해서 평균한다. 두 번째 식은 첫 식을 전개하고 4편의 선형성을 쓰면 나오며, 계산할 때 편하다. 주사위는 `E[X²] = 91/6`, `μ = 3.5`이므로 `Var(X) = 91/6 − 49/4 = 35/12 ≈ 2.92`다.

분산은 단위가 제곱이 된다(키가 cm면 분산은 cm²). 원래 단위로 돌아오도록 제곱근을 씌운 것이 **표준편차** `σ = √Var(X)`이고, 주사위는 약 1.71이다.

## 분산의 성질
| 식 | 뜻 |
|---|---|
| `Var(X + b) = Var(X)` | 전체를 옮겨도 퍼짐은 그대로 |
| `Var(aX) = a²·Var(X)` | 크기를 a배 하면 분산은 a²배 |
| `Var(X + Y) = Var(X) + Var(Y)` | X, Y가 독립일 때만 |

앞의 두 줄을 합치면 `Var(aX + b) = a²·Var(X)`다. 기댓값과 달리 분산의 덧셈은 독립(정확히는 아래의 공분산이 0)일 때만 성립한다. 주사위 두 개의 합은 분산이 `35/12 + 35/12 = 35/6 ≈ 5.83`이다. 반대로 Y = 7 − X처럼 정반대로 움직이면 X + Y는 항상 7이라 분산이 0이다. 일반식은 다음과 같다.
```text
Var(X + Y) = Var(X) + Var(Y) + 2·Cov(X, Y)
```

## 공분산과 상관계수
**공분산**은 두 변수의 편차를 곱해 평균한 것이다.
```text
Cov(X, Y) = E[(X − μ_X)(Y − μ_Y)] = E[XY] − E[X]·E[Y]
```

X가 평균보다 클 때 Y도 평균보다 큰 경향이 있으면 곱이 주로 양수라 공분산이 양수, 반대로 움직이면 음수, 아무 경향이 없으면 0 근처다. X와 Y가 독립이면 `E[XY] = E[X]·E[Y]`이므로 공분산은 0이다. `Cov(X, X) = Var(X)`이니 분산은 공분산의 특수한 경우다.

공분산은 단위에 따라 크기가 달라진다(키를 cm에서 mm로 바꾸면 10배). 그래서 두 표준편차로 나눈 **상관계수**를 쓴다.
```text
ρ = Cov(X, Y) / (σ_X · σ_Y),     −1 ≤ ρ ≤ 1
```

ρ = 1이면 Y가 X의 증가하는 일차 함수, ρ = −1이면 감소하는 일차 함수이고, 0에 가까울수록 직선 관계가 약하다. NumPy로 확인해 보자.
```python
import numpy as np

rng = np.random.default_rng(0)
x = rng.normal(size=100_000)
noise = rng.normal(size=100_000)

for name, y in [("2x + 잡음", 2 * x + noise), ("−x + 잡음", -x + noise), ("x²", x**2)]:
    cov = np.cov(x, y)[0, 1]
    corr = np.corrcoef(x, y)[0, 1]
    print(f"y = {name}: 공분산 {cov:.3f}, 상관계수 {corr:.3f}")
```

```text
y = 2x + 잡음: 공분산 2.002, 상관계수 0.894
y = −x + 잡음: 공분산 -0.998, 상관계수 -0.706
y = x²: 공분산 -0.007, 상관계수 -0.005
```

x와 잡음이 모두 분산 1인 정규 분포(8편)이므로 이론값은 첫째가 `Cov = 2`, `ρ = 2/√5 ≈ 0.894`, 둘째가 `Cov = −1`, `ρ = −1/√2 ≈ −0.707`이다.

## 상관이 말해 주지 않는 것
### 상관은 인과가 아니다
아이스크림 판매량과 물놀이 사고 건수는 양의 상관이 있지만, 아이스크림이 사고를 일으키지는 않는다. 더운 날씨라는 공통 원인이 둘을 함께 늘린다. 상관계수는 "함께 움직인다"는 사실만 말하고 이유는 말하지 않는다. 원인을 확인하려면 통계학 7편 「A/B 테스트: 실험으로 결정하기」처럼 무작위로 나눈 실험이 필요하다.

### 상관 0이어도 독립이 아니다
위 출력의 셋째 줄을 보자. y = x²는 x로 완전히 결정되는데도 상관계수가 0에 가깝다. 손으로도 확인할 수 있다. X가 −1, 0, 1을 각각 1/3 확률로 갖고 Y = X²라면 `E[XY] = E[X³] = 0`, `E[X] = 0`이므로 `Cov(X, Y) = 0`이다. 그러나 X = 0이면 Y는 반드시 0이므로 둘은 독립이 아니다. 포물선의 왼쪽 절반은 음의 관계, 오른쪽 절반은 양의 관계라 서로 상쇄된 것이다. 독립이면 상관이 0이지만, 그 역은 성립하지 않는다.

## 신경망 초기화와 분산
평균이 0이고 서로 독립인 가중치 w와 입력 x에 대해 `Var(w·x) = Var(w)·Var(x)`이므로, 입력 n개를 받는 뉴런의 가중합 `w₁x₁ + … + wₙxₙ`의 분산은 독립인 합의 성질로 `n·Var(w)·Var(x)`다. 층을 하나 지날 때마다 분산이 `n·Var(w)`배가 되는 셈이라, 이 값이 1에서 벗어나면 깊은 망에서 분산이 폭발하거나 사라진다.
```python
import numpy as np

rng = np.random.default_rng(0)
n = 256                                    # 층마다 뉴런 256개
x = rng.normal(size=(1000, n))             # 분산 1인 입력 1,000개
for std in (1.0, 1 / np.sqrt(n), 0.5 / np.sqrt(n)):
    h = x
    for _ in range(10):                    # 활성화 없는 선형 층 10개
        h = h @ rng.normal(scale=std, size=(n, n))
    print(f"가중치 표준편차 {std:.4f} → 10층 뒤 분산 {h.var():.3g}")
```

```text
가중치 표준편차 1.0000 → 10층 뒤 분산 1.32e+24
가중치 표준편차 0.0625 → 10층 뒤 분산 0.921
가중치 표준편차 0.0312 → 10층 뒤 분산 9.77e-07
```

이론값 `256¹⁰ ≈ 1.2 × 10²⁴`, `1`, `0.25¹⁰ ≈ 9.5 × 10⁻⁷`과 맞는다. 실제 초기화 기법들은 활성화 함수의 영향까지 따져서 이 배율이 1 근처가 되도록 가중치 분산을 정한다.

## 정리
- 분산 `Var(X) = E[(X − μ)²] = E[X²] − μ²`는 퍼짐의 척도이고, 표준편차는 그 제곱근이다.
- `Var(aX + b) = a²·Var(X)`이며, 분산의 덧셈은 독립(공분산 0)일 때만 성립한다.
- 상관계수는 공분산을 두 표준편차로 나눈 −1에서 1 사이의 값으로, 직선 관계의 강도를 잰다.
- 상관은 인과가 아니고, 상관이 0이어도 독립이 아닐 수 있다(X와 X²).
