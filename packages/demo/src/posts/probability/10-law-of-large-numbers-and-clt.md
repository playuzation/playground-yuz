## 표본 평균의 기댓값과 분산
평균이 μ, 분산이 σ²인 분포에서 서로 독립으로 n개를 뽑아(i.i.d.) 평균을 낸다고 하자.
```text
X̄ₙ = (X₁ + X₂ + … + Xₙ) / n
```

4편의 선형성으로 `E[X̄ₙ] = μ`이고, 5편의 성질(독립이면 분산이 더해지고, `Var(aX) = a²·Var(X)`)로 `Var(X̄ₙ) = n·σ² / n² = σ²/n`이다. 표본 평균은 μ를 중심으로 흔들리고, 흔들림은 n이 커질수록 줄어든다. 이 흔들림의 표준편차를 **표준 오차**라고 한다.
```text
표준 오차 = σ / √n
```

√n이 분모에 있다는 점이 중요하다. 오차를 절반으로 줄이려면 표본이 두 배가 아니라 네 배 필요하고, 10분의 1로 줄이려면 100배가 필요하다.

## 큰 수의 법칙
**큰 수의 법칙**은 n이 커질수록 표본 평균 X̄ₙ이 기댓값 μ에 한없이 가까워진다는 정리다. 분산 σ²/n이 0으로 다가가니 직관적으로도 그럴듯하다. 1편에서 동전 앞면의 비율이 0.5로 모인 것도, 앞면이면 1인 지표 변수(4편)의 평균이므로 같은 현상이다.

흔한 오해는 "평균으로 돌아가기 위해 앞으로는 반대 결과가 더 많이 나온다"는 생각이다(도박사의 오류). 동전은 과거를 기억하지 않는다. 앞에서 생긴 치우침은 보정되는 것이 아니라, 뒤따르는 수많은 시행 속에 희석될 뿐이다. 처음 몇 번에서 앞면이 기대보다 10번 더 나왔어도, n = 100,000이면 비율로는 10/100,000 = 0.0001 차이에 불과하다.

## 중심 극한 정리
큰 수의 법칙이 "어디로 가는가"를 말한다면, **중심 극한 정리**는 "그 근처에서 어떤 모양으로 흔들리는가"를 말한다. 원래 분포가 무엇이든(분산만 유한하면) n이 충분히 크면 표본 평균의 분포는 정규 분포에 가까워진다.
```text
X̄ₙ ≈ N(μ, σ²/n)     또는     (X̄ₙ − μ) / (σ/√n) ≈ N(0, 1)
```

주사위 눈은 1부터 6까지 고르게 나오는 평평한 분포인데, 그 평균을 여러 번 모으면 종 모양이 나타난다. 8편에서 정규 분포가 흔한 이유로 예고한 것이 이 정리다.

## 주사위로 확인하기
주사위는 μ = 3.5, σ² = 35/12다(5편). 30번 던진 평균의 표준 오차는 `√(35/12/30) ≈ 0.312`이므로, 중심 극한 정리에 따르면 30번 평균의 약 68%는 3.5 ± 0.31 안에, 약 95%는 3.5 ± 0.62 안에 들어가야 한다.
```python
import numpy as np

rng = np.random.default_rng(0)

# 큰 수의 법칙: 던진 횟수가 늘수록 표본 평균이 3.5로 다가간다
rolls = rng.integers(1, 7, size=100_000)
for n in (10, 100, 1_000, 10_000, 100_000):
    print(f"n={n:>7,}  평균={rolls[:n].mean():.4f}")

# 중심 극한 정리: "30번 던져 평균 내기"를 10만 번 반복한다
means = rng.integers(1, 7, size=(100_000, 30)).mean(axis=1)
se = np.sqrt(35 / 12 / 30)                     # σ/√n, 주사위 분산은 35/12
print(f"평균들의 평균={means.mean():.4f}  표준편차={means.std():.4f}  σ/√n={se:.4f}")
print(f"±1SE 안 {np.mean(abs(means - 3.5) <= se):.3f}, ±2SE 안 {np.mean(abs(means - 3.5) <= 2 * se):.3f}")

edges = np.round(np.arange(2.6, 4.5, 0.2), 1)
counts, _ = np.histogram(means, bins=edges)
for c, left in zip(counts, edges):
    print(f"{left:.1f}~{left + 0.2:.1f} {'█' * round(c / 1000)}")
```

던진 횟수가 늘수록 평균이 3.5에 다가간다(큰 수의 법칙). 30번 평균 10만 개의 표준편차는 이론값 σ/√n과 소수 셋째 자리까지 맞고, ±1SE 안과 ±2SE 안의 비율도 각각 0.68, 0.95에 가깝다. 막대그래프는 평평한 주사위 분포에서 나왔는데도 종 모양이다(중심 극한 정리).

주의할 점도 있다.
- "충분히 큰 n"의 기준은 원래 분포에 따라 다르다. 주사위처럼 대칭이면 몇십 개로 충분하지만, 한쪽으로 크게 치우친 분포는 더 많이 필요하다.
- 평균조차 정의되지 않는 분포(예: 코시 분포)에서는 표본을 아무리 모아도 표본 평균이 수렴하지 않는다.
- 표본이 서로 독립이 아니면 평균의 분산이 σ²/n보다 클 수 있다.

## 정리
- 표본 평균은 기댓값이 μ이고, 표준편차(표준 오차)가 σ/√n이다.
- 큰 수의 법칙: n이 커질수록 표본 평균은 기댓값으로 수렴하며, 과거의 치우침은 보정되지 않고 희석된다.
- 중심 극한 정리: 원래 분포와 상관없이 표본 평균의 분포는 `N(μ, σ²/n)`에 가까워진다.
- 오차를 절반으로 줄이려면 표본이 네 배 필요하다.
