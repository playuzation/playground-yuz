## 확률 변수는 함수다
동전을 세 번 던지면 표본 공간에는 앞앞앞, 앞앞뒤, …, 뒤뒤뒤의 8가지 결과가 있다. 우리가 궁금한 것은 대개 결과 그 자체보다 "앞면이 몇 번 나왔나" 같은 숫자다. 이렇게 각 결과에 숫자 하나를 대응시키는 함수를 **확률 변수**(random variable)라 하고 대문자 X로 쓴다.
```text
X: Ω → 실수        X(앞앞뒤) = 2,  X(뒤뒤뒤) = 0
```

이름과 달리 확률 변수는 "변수"가 아니라 함수이고, 무작위인 것은 함수가 아니라 입력으로 들어오는 결과다(함수는 이산수학 1편 「집합과 함수: 수학의 기본 언어」 참고). 확률 변수를 쓰면 "앞면이 두 번 나오는 사건"을 `{X = 2}`처럼 짧게 쓸 수 있다.

## 확률 질량 함수
X가 띄엄띄엄한 값만 가질 때, 각 값이 나올 확률을 모은 함수 `p(x) = P(X = x)`를 **확률 질량 함수**(PMF)라고 한다. 동전 세 번의 앞면 수는 다음과 같다.

| x (앞면 수) | 해당하는 결과 | p(x) |
|---|---|---|
| 0 | 뒤뒤뒤 | 1/8 |
| 1 | 앞뒤뒤, 뒤앞뒤, 뒤뒤앞 | 3/8 |
| 2 | 앞앞뒤, 앞뒤앞, 뒤앞앞 | 3/8 |
| 3 | 앞앞앞 | 1/8 |

확률 질량 함수는 모든 값이 0 이상이고 합이 1이다(1편의 공리). 확률 변수에 대해 알아야 할 것은 대부분 이 표 하나에 담기며, 이 표의 모양을 X의 **분포**라고 부른다. 자주 나오는 분포들은 6편 「이산 분포: 베르누이, 이항, 기하, 포아송」에서 정리한다.

## 기댓값: 확률로 가중한 평균
**기댓값**은 값마다 그 확률을 곱해 더한 것이다.
```text
E[X] = Σ x · p(x)
```

공정한 주사위의 기댓값은 `(1 + 2 + 3 + 4 + 5 + 6) × 1/6 = 3.5`다. 3.5는 주사위에서 절대 나올 수 없는 값이므로, 기댓값은 "가장 나올 법한 값"이 아니라 아주 많이 던졌을 때의 평균으로 이해해야 한다(10편의 큰 수의 법칙). 동전 세 번의 앞면 수는 `0 × 1/8 + 1 × 3/8 + 2 × 3/8 + 3 × 1/8 = 1.5`다. 막대 위 각 위치에 확률만큼의 무게를 올렸을 때 균형이 잡히는 점, 즉 무게 중심이라고 생각해도 좋다.

X의 함수 g(X)도 확률 변수이고, 그 기댓값은 `E[g(X)] = Σ g(x) · p(x)`다. 확률은 그대로 두고 값만 바꿔 더하면 된다. 주의할 점은 일반적으로 `E[g(X)] ≠ g(E[X])`라는 것이다. 주사위에서 `E[X²] = 91/6 ≈ 15.17`이지만 `(E[X])² = 12.25`다. 이 차이가 5편에서 다룰 분산이다.

## 선형성: 독립이 아니어도 된다
기댓값의 가장 쓸모 있는 성질은 **선형성**이다. 상수 a, b, c와 어떤 확률 변수 X, Y에 대해서도 다음이 성립한다.
```text
E[aX + bY + c] = a·E[X] + b·E[Y] + c
```

핵심은 X와 Y가 독립일 필요가 없다는 점이다. 주사위 두 개의 합의 기댓값은 3.5 + 3.5 = 7이다. 극단적으로 Y = 7 − X처럼 Y가 X에 완전히 묶여 있어도 `E[X + Y] = 3.5 + 3.5 = 7`은 여전히 맞다. 반면 곱의 기댓값 `E[XY] = E[X]·E[Y]`는 독립일 때만 보장된다.

## 지표 확률 변수 트릭
사건 A가 일어나면 1, 아니면 0인 확률 변수를 **지표 확률 변수** `I_A`라고 한다. 그 기댓값은 `1 × P(A) + 0 × (1 − P(A)) = P(A)`, 즉 확률 그 자체다. 복잡한 개수를 지표 변수들의 합으로 쪼개고 선형성을 쓰면, 사건끼리 얽혀 있어도 기댓값을 쉽게 구할 수 있다.

고전적인 예가 **모자 문제**다. n명이 모자를 맡겼다가 무작위로 돌려받을 때, 자기 모자를 받는 사람은 평균 몇 명일까? i번째 사람이 자기 모자를 받으면 1인 지표 변수 Iᵢ를 두면, 그 수는 `I₁ + I₂ + … + Iₙ`이다. 각 사람이 자기 모자를 받을 확률은 1/n이므로 기댓값은 `n × 1/n = 1`이다. 사람들의 사건은 서로 독립이 아니지만(내가 남의 모자를 받으면 그 사람에게 영향이 간다) 선형성에는 상관없다. n이 10이든 1,000이든 답은 1이다.
```python
import random
from fractions import Fraction

die = {x: Fraction(1, 6) for x in range(1, 7)}
E = sum(x * p for x, p in die.items())
E_sq = sum(x**2 * p for x, p in die.items())
print(E, E_sq, E**2)          # E[X], E[X²], (E[X])²

random.seed(0)
n, trials = 10, 100_000
total = 0
for _ in range(trials):
    hats = list(range(n))
    random.shuffle(hats)                                  # 모자를 무작위로 돌려준다
    total += sum(hats[i] == i for i in range(n))          # 지표 변수의 합 = 제 모자를 받은 사람 수
print(total / trials)         # 이론값: n × (1/n) = 1
```

```text
7/2 91/6 49/4
0.9995
```

같은 방법으로, 성공 확률이 p인 시행을 n번 할 때 성공 횟수의 기댓값이 np라는 것도 지표 변수 n개의 합으로 한 줄에 나온다.

## 정리
- 확률 변수는 표본 공간의 결과를 숫자로 보내는 함수이고, 확률 질량 함수는 각 값의 확률을 모은 것이다.
- 기댓값 `E[X] = Σ x·p(x)`는 확률로 가중한 평균이며, 실제로 나올 수 없는 값일 수도 있다.
- 선형성 `E[aX + bY + c] = a·E[X] + b·E[Y] + c`는 독립이 아니어도 성립한다.
- 지표 확률 변수의 기댓값은 확률이며, 개수를 지표의 합으로 쪼개면 기댓값 계산이 쉬워진다.
