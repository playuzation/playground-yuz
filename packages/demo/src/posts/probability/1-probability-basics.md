## 표본 공간과 사건
동전 던지기나 주사위 굴리기처럼 결과가 미리 정해지지 않은 행위를 **시행**이라 하고, 시행에서 나올 수 있는 모든 결과의 집합을 **표본 공간**(sample space)이라 하며 Ω(오메가)로 쓴다.
- 주사위 한 번: `Ω = {1, 2, 3, 4, 5, 6}`
- 동전 두 번: `Ω = {앞앞, 앞뒤, 뒤앞, 뒤뒤}`
- 다음 버스가 올 때까지 걸리는 시간: `Ω = [0, ∞)` (이런 연속인 경우는 7편에서 다룬다)

**사건**(event)은 표본 공간의 부분집합이다. "짝수가 나온다"는 사건은 `A = {2, 4, 6}`이고, 실제 결과가 A 안에 들어가면 "A가 일어났다"고 말한다. 사건이 집합이므로 집합 연산이 그대로 사건의 논리가 된다(집합 자체는 이산수학 1편 「집합과 함수: 수학의 기본 언어」 참고).

| 표기 | 뜻 | 주사위 예 |
|---|---|---|
| `A ∪ B` | A 또는 B | 짝수 또는 4 이상: {2, 4, 5, 6} |
| `A ∩ B` | A 그리고 B | 짝수이면서 4 이상: {4, 6} |
| `Aᶜ` | A가 아님(여사건) | 홀수: {1, 3, 5} |
| `A ∩ B = ∅` | 동시에 못 일어남(배반) | {1}과 {2} |

## 콜모고로프의 공리
1933년 소련의 수학자 콜모고로프는 확률을 다음 세 규칙(공리)을 만족하는 함수 P로 정의했다. 동전이든 날씨든 언어 모델의 출력이든, 이 규칙을 지키는 숫자 매김이면 모두 확률이다.
```text
공리 1 (음이 아님)  모든 사건 A에 대해 P(A) ≥ 0
공리 2 (전체는 1)   P(Ω) = 1
공리 3 (더하기)     A₁, A₂, …가 서로 배반이면
                    P(A₁ ∪ A₂ ∪ …) = P(A₁) + P(A₂) + …
```

세 번째 공리가 핵심이다. 겹치지 않는 사건들의 확률은 그냥 더하면 된다. 공정한 주사위라면 각 눈의 확률이 1/6이고, 짝수의 확률은 `P({2}) + P({4}) + P({6}) = 3/6`이다.

## 공리에서 따라 나오는 규칙
공리는 세 개뿐이지만 자주 쓰는 계산 규칙이 모두 여기서 나온다.
- **여사건 규칙**: A와 Aᶜ는 배반이고 합치면 Ω이므로 `P(A) + P(Aᶜ) = 1`, 즉 `P(Aᶜ) = 1 − P(A)`다. A = Ω로 두면 `P(∅) = 0`도 나온다.
- **포함 관계**: `A ⊂ B`이면 `P(A) ≤ P(B)`다. 따라서 모든 확률은 0과 1 사이에 있다.
- **합의 법칙**: `P(A ∪ B) = P(A) + P(B) − P(A ∩ B)`. 겹치는 부분을 두 번 더했으니 한 번 뺀다. 배반이면 마지막 항이 0이다.

위 표의 예에 합의 법칙을 쓰면 `P(짝수 ∪ 4 이상) = 3/6 + 3/6 − 2/6 = 4/6`이고, 실제로 {2, 4, 5, 6}은 네 개다. 여사건 규칙은 "적어도 하나"를 물을 때 특히 쓸모 있다. 주사위 두 개를 던져 적어도 하나가 6일 확률은 경우를 나누어 세는 것보다 "둘 다 6이 아님"의 여사건으로 보는 편이 쉽다: `1 − (5/6)² = 11/36 ≈ 0.306`. (두 주사위가 서로 독립이라는 가정을 썼다. 독립은 2편에서 정의한다.)

## 같은 가능성으로 세기
모든 결과가 똑같이 일어날 법하다면 확률은 세기 문제가 된다.
```text
P(A) = (A에 속한 결과의 수) / (Ω에 속한 결과의 수)
```

파이썬으로 표본 공간을 직접 만들어 세어 보면 위의 11/36을 확인할 수 있다.
```python
from itertools import product
from fractions import Fraction

omega = list(product(range(1, 7), repeat=2))   # 주사위 두 개: 36가지 결과
A = [w for w in omega if 6 in w]               # 사건: 적어도 하나가 6
print(len(omega), len(A), Fraction(len(A), len(omega)))  # 36 11 11/36
print(1 - Fraction(5, 6) ** 2)                 # 여사건으로 계산: 11/36
```

세는 방법(순열과 조합)은 이산수학 6편 「경우의 수: 순열과 조합」에서 다룬다. 주의할 점은 "모든 결과가 같은 가능성을 가진다"는 가정이다. 주사위 두 개의 합은 2부터 12까지 11가지지만, 합이 7일 확률(6/36)은 합이 2일 확률(1/36)의 여섯 배이므로, 합을 결과로 삼아 11가지로 나누어 세면 틀린다.

## 빈도로 해석하기
공리는 확률이 "무엇"인지는 말하지 않는다. 가장 직관적인 해석은 **빈도 해석**이다. 같은 시행을 아주 많이 반복할 때 사건이 일어나는 비율이 그 사건의 확률이라는 것이다. 시드를 고정해 동전과 주사위를 던져 보자.
```python
import random

random.seed(42)
for n in (10, 100, 1_000, 10_000, 100_000):
    heads = sum(random.random() < 0.5 for _ in range(n))
    print(f"n={n:>7,}  앞면 비율={heads / n:.4f}")

counts = [0] * 6
for _ in range(60_000):
    counts[random.randrange(6)] += 1
print([round(c / 60_000, 3) for c in counts])  # 이론값 1/6 ≈ 0.167
```

```text
n=     10  앞면 비율=0.6000
n=    100  앞면 비율=0.4900
n=  1,000  앞면 비율=0.4820
n= 10,000  앞면 비율=0.5017
n=100,000  앞면 비율=0.5001
[0.167, 0.168, 0.166, 0.166, 0.166, 0.167]
```

열 번 던지면 60%가 나오기도 하지만, 횟수가 늘수록 비율이 0.5 근처로 모인다. 왜 그런지는 10편 「큰 수의 법칙과 중심 극한 정리」에서 정리한다. 한편 "내일 비가 올 확률 30%"처럼 똑같이 반복할 수 없는 일에는 빈도 해석이 어색하다. 이때는 확률을 **믿음의 정도**로 보는 베이즈 해석이 자연스러우며, 3편 「베이즈 정리: 증거로 믿음을 고치기」로 이어진다. 어느 해석을 택하든 계산은 같은 공리를 따른다.

## 정리
- 표본 공간 Ω는 가능한 모든 결과의 집합이고, 사건은 그 부분집합이다.
- 확률은 콜모고로프의 세 공리(음이 아님, 전체는 1, 배반이면 더하기)를 만족하는 함수다.
- 여사건 규칙 `P(Aᶜ) = 1 − P(A)`와 합의 법칙은 공리에서 바로 나온다.
- 빈도 해석에서는 반복 횟수가 늘수록 상대 빈도가 확률에 가까워진다.
